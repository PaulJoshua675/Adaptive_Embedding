(3) The historical attribute is one for a superseded version and zero when no later source exists. Both the value and its provenance remain in memory. A missed retrieval of the latest version therefore cannot make an older record appear current. The label identifies a record as historical; its source index places it among the earlier versions. All records at the maximum source index are treated as current. This rule leaves conflicting values within the same session unresolved. 3.3 Relevance Retrieval and Temporal Evidence Retrieval selects facts by relevance without penalising older versions for their age.
