28 Proposition A.3 (Worst-case step bound). Let p = 2256 −232 −977. For every 0 ≤w < p, the walk in Equation (A1) reaches g = 0 within 590 active steps. If w > 0, its final coefficients satisfy Equation (A6); if w = 0, the walk starts frozen. Proof. The worst-case analysis of Wuille [36] guarantees that every 0 < w < p reaches g = 0 within 590 divsteps. The case w = 0 starts with g = 0. For 0 < w < p, gcd(p, w) = 1 because p is prime, so once the walk terminates, the remaining claims follow from Proposition A.2. We now recover the bits s and b of an active step from its updated state. The bit s, and b in two special cases, can be read from a few bits of that state. Lemma A.4 (Locally visible decisions). Every active step has the following properties: 1. The swap is visible from the updated coefficient: s = 1 ⇐⇒ f ′ v ≡2 (mod 4) ⇐⇒ v2(f ′ v) = 1. (A7) If s = 0, then 4 | f ′ v; moreover, s = 1 implies b = 1. 2. If s = 0 and z′ ≥1, then b = 0. 3. If g′ = 0, then b = 1. Proof. On a swap step, the incoming g is odd, so b = 1; the update also gives f ′ = g, preserving the oddness of f. Moreover, f ′ v = 2gv, which is twice an odd integer by Lemma A.1. On a nonswap step, f ′ v = 2fv, which is divisible by four. This proves part 1. For part 2, a nonswap has z = z′ −1 ≥0. Since the swap condition nevertheless failed, the incoming value g was even, and hence b = 0. Finally, on a nonswap, g′ = (g + bf)/2. If b = 0 and g′ = 0, then g = 0, contrary to the step being active; a swap already has b = 1 by part 1. This proves part 3. The steps these tests leave undecided, apart from a terminating step, are the nonswaps entered with z < 0; we call them negative-counter nonswaps. Their decisions are the ambiguous decisions of SI II.1: the preceding tests do not determine b, but the coefficients still retain it. Whenever fv̸ = 0, put j = v2(fv) and write fv = 2jq with q odd. On an updated state, j is the excursion depth defined in the main text, and a swap followed by a run of ambiguous decisions is an excursion. The j low-order bits of gvq−1, which we call the window, accumulate successive decisions. Lemma A.5 (Window invariant). Every reachable state satisfies the following conditions: 1. If z ≥0, then 2z+1 | fv. 2. If z < 0, then fv̸ = 0 and, with j = v2(fv) and q = fv/2j, there is an integer c such that 0 ≤c < 2j and gv ≡qc (mod 2j−z). (A8) Because q is odd, part 2 says that gvq−1 mod 2j−z fits in j bits: the −z bits above position j −1 vanish. Proof. Proceed by induction along the walk. A frozen step changes nothing. At the initial state, z = 0, fv = 0, and 2 | fv. Suppose first that a nonswap begins with z ≥0. Then z′ = z + 1 and f ′ v = 2fv, so 2z′+1 | f ′ v. Suppose next that a swap occurs at z = D ≥0. Then z′ = −D and f ′ v = 2gv. By Lemma A.1, gv is odd, so v2(f ′ v) = 1 and the odd part of f ′ v is gv. Moreover, g′ v = gv −fv, while the induction hypothesis gives 2D+1 | fv. Hence g′ v ≡gv (mod 2D+1). (A9) If D > 0, part 2 holds with j = 1 and c = 1; if D = 0, part 1 asks only that 2 | f′ v. Finally, suppose that a nonswap begins with z < 0. Let j = v2(fv) and let c be the witness from part 2. Then z′ = z + 1, f ′ v = 2fv, and the odd part q is unchanged. Since g′ v = gv + bfv, g′ v ≡q(c + b2j) (mod 2j−z), 0 ≤c + b2j < 2j+1. (A10) The required modulus after the step is unchanged because 2(j+1)−z′ = 2j−z. If z′ < 0, this proves part 2; if z′ = 0, then part 1 asks only that 2 | f ′ v. The invariant makes the bit b of every negative-counter nonswap an exact function of the updated state.
