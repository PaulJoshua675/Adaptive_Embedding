A generation condition fixes the transition family, grid shape, alphabet, target workload, and policies for initial states and event proposals. Starting from a sampled W0, the simulator executes candidate events and selects among them using realized workload and resulting occupancy. Accepted trajectories remain nonempty and satisfy bounds on density, mean workload, and the fraction of core events that change the state. Settings were frozen before formal evaluation; Appendix B.7 gives the generation settings and the selection and acceptance procedures. Each accepted trajectory supplies instances at selected prefix lengths. A length-T request contains the original state W0 and the first T events (e1, . . . , eT ), with the target WT computed by Equation 1. These prefixes are queried separately, allowing comparison across progressively longer histories from the same initial world. The shared reference trace records intermediate states and event statistics for exact replay. 3.4 Evaluating complete-state predictions Complete predictions support evaluation of both exact recovery and cell-level agreement with the reference. The primary measure is semantic full-world exact match (EM). For request i, let Wi be the reference final state and vi indicate validity of the extracted prediction c Wi. A prediction is valid if it decodes to a grid satisfying the output specification. Set yi = 1 when the prediction is valid and equals Wi at every coordinate, and yi = 0 otherwise. For requests I, EM(I) = 1 |I| P i∈I yi. (2) Semantic equality compares cell values, including implicit zeros, regardless of list ordering. Invalid or absent states score zero in the full denominator. Exact match treats all incorrect states alike; cell-level comparisons distinguish a few wrong values from errors across the grid. For a valid prediction on domain Xi, the error set Ei = {x ∈Xi : c Wi(x)̸ = Wi(x)} gives the wrong-cell count |Ei|. For the valid subset V = {i ∈I : vi = 1}, cell accuracy averages the fraction of correct cells in each returned world: CA(I) = 1 |V | P i∈V  1 −|Ei| |Xi|  . (3) This macro-average gives each valid prediction equal weight. Error-extent summaries instead use valid in- correct predictions, V −= {i ∈V : yi = 0}, and report the subset size, median wrong-cell count, and 90th percentile. We further distinguish errors on cells that must change from errors on cells whose final values must match the initial world. With W0,i denoting the initial state, define Ci = {x ∈Xi : Wi(x)̸ = W0,i(x)}, Ui = Xi \ Ci. (4) This partition uses initial and final values; a cell in Ui may change during the history and later return to its original value. Each valid incorrect prediction is classified as changed-only if its errors lie entirely in Ci, unchanged-only if they lie entirely in Ui, or both if they intersect both sets.
