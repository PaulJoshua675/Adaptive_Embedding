Semantic segmentation performance deltas between VesperMUSE LLIE and VesperMUSE trained and tested on low-light images, highlighting the role of LLIE enhancement on the CART dataset [25]. 4.5.2 Modality choices and their rank The inputs of VesperMUSE can be configured in a large number of ways. Although the standard and recommended configuration is composed of three inputs: RGB, thermal, and surface normals, the model can be run using any number of modalities as inputs with very little changes as the Fusion Self-Attention was specifically designed to structurally support any number of modalities. The only constraint, however, is that one modality has to be declared as the main modality while the others are auxiliaries. The main modality is used as the main source of information in the en- coding stage and also has a larger backbone responsible for extracting the features from it. In all the configurations presented until now, the main modality was the RGB (normal or synthetically low-light adapted and then enhanced), but the purpose of this ablation study is to show how the model behaves under different number of inputs and what are the effects of modifying the rank of the modalities. Table 4.6 presents different input configurations and provides evidence for why RGB was chosen as a primary modality even when running under a LLIE configuration and the enhanced images present noise and colour distortions, while the thermal is left unaffected. Furthermore, LLIE RGB is shown to also validate the primary modality advantage when interchangeably switched with the surface normal representations. Thermal and Surface Normals as Auxiliaries.
