B Supplementary Experiments The following studies examine how component ad- ditions, model choice for System One and System Two, and candidate inspection depth affect rank- ing quality and resource use on the 105 NeuCLIR- Bench topics. B.1 Ablation Study Table 5 extends the cumulative ablation in Table 3 to ranking. With GPT-5.6 Terra as System Two at medium reasoning effort, we add Hybrid BM25, Relevance Assessment, and Evidence Discovery to Pi-Serini in sequence. Relevance Assessment uses Jev with adaptive reading and evidence memory. Evidence Discovery inspects whole documents at K = 60. Hybrid BM25 leaves ranking quality nearly un- changed. Relevance Assessment provides the largest observed gain on both metrics, at higher API cost. Adding Evidence Discovery slightly low- ers nDCG@20 and raises F1@20, while reducing elapsed time, System Two token use, and estimated total API cost. In this sequence, targeted source as- sessment contributes most to ranking quality, while proactive discovery improves efficiency. B.2 Performance across System Two Models Table 6 examines how the choice of System Two affects ranking quality, elapsed time, and API cost. We compare five models on the same 105 Neu- CLIRBench topics, holding Jev as System One, Hybrid BM25, prompts, and the evaluation bud- get fixed. All System Two models use medium reasoning effort. GPT-5.5 achieves the highest ranking quality. GPT-5.6 Terra approaches its effectiveness and completes research fastest, while GPT-5.4 mini minimizes total API cost with lower ranking qual- ity. The preferred System Two model therefore depends on whether quality, elapsed time, or API spending is the priority. B.3 System One Models and Inspection Depth Table 7 compares Jev and GPT-5.5 as Sys- tem One at candidate inspection depths K ∈ {0, 20, 60, 120} on all 105 NeuCLIRBench top- ics. This study examines how the local judgment model and proactive inspection depth affect rank- ing quality and efficiency. System Two remains fixed at GPT-5.5, which uses medium reasoning ef- fort in either role. The selected System One model performs requested Relevance Assessment and Ev- idence Discovery. For each search, K is the largest retrieved rank eligible for Evidence Discovery. The two System One models yield broadly simi- lar final ranking quality, with no consistent advan- tage for GPT-5.5. Jev matches or exceeds GPT-5.5 in nDCG@20 at every matched K and achieves higher F1@20 at three of the four depths. At K = 60, both configurations reach nDCG@20 of 0.5358, while GPT-5.5 achieves F1@20 of 36.33%, compared with 35.82% for Jev. The efficiency difference is more pronounced. At every matched K, Jev’s mean elapsed time for the full research process per topic is less than one quarter of that with GPT-5.5. Its System One API cost per topic is also below one percent of the cor- responding GPT-5.5 cost. When GPT-5.5 serves as System One, local judgment costs exceed System Two costs at every tested depth. Together with the ranking results, these measurements support Jev as an efficient model for local evidence judgments under the tested settings. At K = 0, Evidence Discovery is disabled, while Relevance Assessment requested by System Two remains enabled. Thus, K controls proactive inspection rather than the total number of docu- ments that can be read during research. Increasing K raises System One API cost for both models, but neither nDCG@20 nor F1@20 improves monoton- ically. Deeper proactive inspection therefore incurs additional local judgment cost without a consistent gain in final ranking quality. 13
