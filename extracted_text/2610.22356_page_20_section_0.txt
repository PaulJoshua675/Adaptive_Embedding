From each SPAR-7M view_change_infer annotation with decodable structured camera-motion fields (Zhang et al., 2025b), the parser extracts the source and target view identifiers and the yaw component. Yaw is converted to the same clockwise-positive angular convention; pitch and translation fields are not used in RC. Repeated records for the same directed view pair are deduplicated. For three available relations A→B, B →C, and A→C, triangle closure requires d◦(θAC, ⟨θAB + θBC⟩360) ≤5◦. (18) Accepted directed relations are connected when the target view of one edge matches the source view of the next; paths with repeated views are rejected. For transition vk−1 →vk, δSPAR k = θvk−1vk; cumulative headings follow the recurrence in Section 3.2. SPAR-RC applies no facing-to-traversal 180◦correction. Its prompt provides the ordered views and their images and uses the first view as the heading origin while withholding the target sequence. Supervision Targets. RC produces four target types: VSI angle contains exact turn sequences; VSI action contains the corresponding discrete actions for eligible chains; SPAR delta contains local yaw increments; and SPAR heading contains cumulative headings relative to the initial view. Each target sequence is serialized as a JSON array in the assistant response of a separate training sample. No sample jointly emits two target types. The validator independently reconstructs these arrays and checks their provenance against the source relations before they enter autoregressive SFT. A.5 Output Projection and Gate Initialization At each selected layer, we initialize the shared output projection ϕℓ g by copying the native output projection. The two projections have separate parameters. At positions with valid geometry, both kernel outputs use ϕℓ g; at other positions, the semantic output uses the native output projection. We initialize gℓ= 0, giving both kernels an initial mixing weight of 0.5. This avoids strongly suppressing the geometric branch at the start of training and keeps the sigmoid gate away from saturation. Each selected layer then learns its own mixing ratio. A.6 Implementation Details and Parameter Counts We introduce Dual-Kernel Attention at layers 4, 9, 14, 19, and 24 for DK-VLM-7B and at layers 6, 12, 18, 27, and 33 for DK-VLM-8B, using zero-based indices. The pairwise prediction head reads the pre-fusion geometric features at layer 19 for the 7B model and layer 27 for the 8B model. For both models, the pairwise loss weight increases linearly to 0.1 over the first 5% of training steps. Both models are trained on 32 NVIDIA H200 GPUs for one epoch.
