3.1 Unified Reasoning Embedding To ground reasoning-conditioned retrieval within a unified framework, AURA utilizes an autoregres- sive language model as its unified backbone fθ. To enable a single language model to simultaneously optimize autoregressive token generation and ex- tract high-quality dense retrieval representations, we propose a structured sequence format. Given a query x, the format is as follows: Unified Sequence Format: [User]: Input: x. Generate step-by-step reasoning. [Assistant]: <think> r1, r2, . . . , rT </think> where r = (r1, . . . , rT ) represents the generated reasoning trajectory parsed at sentence boundaries. Embedding extraction. At each sentence bound- ary t, we construct a prefix-conditioned embedding by passing the query and reasoning prefix through the backbone and extracting the final-layer hidden state at the last token position of rt: zt = proj(LastHiddenθ(x, r≤t)), (1) where LastHiddenθ(·) returns the final layer’s hid- den state at the last token of the input, and proj(·) is a linear projection to the embedding space. Retrieval Specificity Scoring. To supervise inter- mediate reasoning states, AURA defines a retrieval specificity score that measures how well a given reasoning state separates relevant documents from distractors.
