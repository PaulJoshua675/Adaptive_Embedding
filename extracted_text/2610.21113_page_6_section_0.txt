RQ2: Retrieval Effectiveness and Efficiency RQ2 evaluates SSR on naturally occurring text using the MS MARCO Passage Ranking collection [35], which con- tains 8,841,823 passages. Because MS MARCO does not provide native Agent Cards, each passage is treated as an ab- stract document-derived Agent Card, each query as an agent- discovery request, and positively judged passages as relevant Agent Cards under this abstraction. All 6,980 development queries with at least one positive relevance judgment are used for effectiveness evaluation. Retrieval depth is fixed at K = 10, and effectiveness is measured using Recall@1, Recall@3, Recall@5, Recall@10, and MRR@10. Five configurations are evaluated: 1) TF-IDF, using an unnormalized lexical dot product; 2) BM25 [11], over the same normalized unigram repre- sentation; 3) Structural Overlap + ISI, using equal weights for matched structural signals; 4) Structural + IDF (full scan), using SSR scoring with- out the ISI; and 5) SSR, combining field-derived signals, IDF weighting, and the ISI. Structural Overlap + ISI isolates the contribution of IDF weighting, whereas Structural + IDF (full scan) isolates the contribution of the ISI. Effectiveness for indexed methods is evaluated on all 6,980 eligible queries. Online latency and direct exhaustive Structural+IDF execution are measured on a common deterministic 200-query subset sampled with seed 42. For each query in this subset, exhaustive Structural+IDF scores all 8,841,823 passages, discards zero-score results, and returns the unpadded top-K positive-scoring candidates. As established in Section III, the ISI excludes only zero-scoring candidates; direct comparison with SSR therefore verifies top- K agreement while quantifying the computational cost of exhaustive scoring. Index construction and IDF computation are treated as offline operations. D. RQ3: End-to-End Agent Discovery RQ3 evaluates the complete LLM selection pipeline at N ∈{100, 500, 1000, 5000} using 200 MS MARCO development queries sampled uni- formly with seed 42. Sampling occurs before SSR retrieval and is independent of SSR ranks, candidate pools, and LLM outcomes. For each query, relevant document-derived Agent Cards are retained and deterministic distractor Agent Cards form nested registries, A100 ⊂A500 ⊂A1000 ⊂A5000. Three configurations are evaluated: full-catalog orchestra- tion, SSR candidate pre-selection, and BM25 candidate pre- selection. SSR and BM25 use the same maximum candidate budget, query-specific registries, LLM prompt, and parser.
