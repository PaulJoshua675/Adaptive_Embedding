By continuously processing an input video stream and responding to user queries, a streaming vision-language model (VLM) must reason over what has already happened, interpret what is happening now, and remain attentive to what may happen next. Such capabilities are central to key tasks ranging from streaming video understanding (Niu et al., 2025) to interactive AI assistants (Lab, 2026) and robotic planning (Li et al., 2025), where responses and decisions must be made online under latency and memory constraints. Streaming VLMs have thus emerged as an important research frontier. Recent work has shown that offline VLMs can be adapted to describe ongoing activities in streaming videos (Shen et al., 2026; Lu et al., 2026), while instruction fine-tuning can further enable models to monitor future events (Li et al., 2026; Wang et al., 2026). Despite these efforts, a fundamental open problem remains: how should a streaming VLM remember? As in the offline setting, an effective memory mechanism must preserve important visual information within a bounded memory footprint. The streaming setting, however, introduces additional challenges. First, memory must evolve incrementally as new observations arrive, rather than being repeatedly recomputed from the full history. Second, historical information must be incorporated without crowding out the current observation (see Fig. 1-2). Finally, a practical memory mechanism should introduce minimal inference overhead. To address these challenges, we propose MaLoW (Memory as LoRA Weights), a framework that internalizes historical context into evolving lightweight parameter updates of a streaming VLM, as illustrated in Fig. 1-1. MaLoW incrementally consolidates incoming observations into fixed-size LoRA weights, allowing accumulated history to be carried forward without revisiting the full video stream. The base VLM architecture and parameters stay unchanged and only the lightweight LoRA memory evolves over time.
