A team of Gemini 4 Argon agents beats Minecraft programs. Players talk through the game’s chat, which reaches every bot and appears in the output of each player’s next program. The server records chat, deaths and advancements in its log, keeps every program with its output, and saves the world every five minutes; after a failure, it restarts from the latest save. 2.2. Instructions Each agent’s instructions combine a general part, the same for every environment, with a short description of the environment and of the objective. The general part for players asks them to observe the environment before acting and verify the result afterwards, to validate new tools on short tasks before trusting them, to build and refine their own tools when manual actions limit their speed or reliability, to record mechanics, strategies and workarounds in memory so that no obstacle is met twice, to keep working while background jobs run, to be honest about their actions and outcomes, and to pursue the objective rather than exploit flaws of the environment or of its evaluation. The description of the environment explains how to run code with the bot, how the chat works, where the server records the game and where to find the documentation of Mineflayer; it contains no game strategy. A brief note lists the other members of the team. 2.3. Monitoring A fifth agent, the Observer, followed the session as an independent witness and never played. Its instructions ask it to check the players’ claims against the record before reporting them, to report specification gaming, such as an exploited flaw in the evaluation, and fabricated results, to leave the game unchanged, and to intervene only on failures of the environment, such as a broken tool or a quota ceiling, never on the players’ strategy. It published a live report of the session, with a summary of progress, a log of verified events and its findings about the infrastructure. It flagged no specification gaming, and it never joined the game or ran a program in it. The run didn’t contain any safety incidents, according to the Observer agent and our manual reviews of the logs. 3. The 27-hour run From the first program to the dragon’s defeat took 27 hours and 14 minutes. The four agents wrote and ran 2,783 programs, exchanged 229 messages and died 605 times along the way. That time includes 6 server restarts, which paused the world for about 20 minutes in all, and spans about 81 in-game days. For human players, HowLongToBeat’s median for Minecraft’s main story is 45 hours and the random-seed speedrun record is under seven minutes; the agents played as a team of four on Easy difficulty, through programs rather than a screen and keyboard. 4
