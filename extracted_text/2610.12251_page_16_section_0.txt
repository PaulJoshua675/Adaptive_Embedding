Theorem 6.9 (Universal construction). For every τ ∈R the instance (Nhost, mP , τ) halts and Out(Nhost, mP , τ) = δ(τ); by Lemma 6.5, every byte string is the output of an instance with host Nhost and memory image mP . Proof. Write τ = t1 · · · tkEND, and let Ij assert that control reaches 0x00 with the head at the first byte of tj+1 and the output word δ(t1 · · · tj), with Z, ONE, NEG1 and Rout holding 0, 1, 255 and 0, all request bits 0 and the bytes of P unmodified; I0 holds at the start. For a literal token, 1 ≤χ ≤127, the loop at 0x1B reads each payload byte x, emits ν(x) through Rout and the write request, and counts T2 down to 0. For a repeat token, 129 ≤χ ≤255, T1 = 256 −χ is positive, and the loop at 0x2D reads x once and emits ν(x) while it counts T1 down. Both loops return to 0x00 with Ij+1.
