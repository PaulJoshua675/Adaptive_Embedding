The count includes repeated neighborhood incidences, so equal support sizes need not imply equal read counts. Conservation and ordering. The following properties hold for individual valid core events and provide checks on execution. Reflection permutes the inclusive box, preserving every label count; applying the same reflection twice restores the state because its coordinate map is an involution. MIX preserves the occupied set: every updated value remains in {1, . . . , K} and every updated coordinate was already occupied. MOVE preserves label counts and ordering along each axis-parallel line. If selected-label positions before and after the event are ordered as a1 < · · · < am and b1 < · · · < bm, then 0 ≤s(bi −ai) ≤k. Occupied cells prevent overtaking, while front-to-back execution lets later entities enter vacated space. COMPRESS preserves each line’s sum: deleting zeros, replacing a, a by 2a, and packing all preserve that sum. Its occupied-cell count cannot increase. These event-specific identities do not extend unchanged through arbitrary SET assignments. Synchronous aggregation. Index the world lexicographically and write its values as w ∈ZN M. For a fixed STENCIL event, let A be the grid adjacency matrix and DS the diagonal indicator of its update support. Then w′ = (I + DSA)w (mod M). (15) Rows outside S preserve their old values; rows inside add the old neighbors. This is linear over the residue ring ZM, including the evaluated Z4. Sequential in-place updates would define a different map. MIX instead reduces modulo K = M −1 and adds one: on a fully updated three-cell line [1, 1, 1], the two rules yield [2, 3, 2] and [3, 1, 3], respectively.
