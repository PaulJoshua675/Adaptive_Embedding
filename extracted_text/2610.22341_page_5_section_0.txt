Each record s = (f, e, C, o, m) stores provenance, license, and available verification results in m, keeping execution, geometric, and visual checks separate; source files, pre-conversion programs, and URDF files are retained, and meshes and videos are linked when available. 4 3DCODEVERSE HARNESS: A DATA ENGINE FOR 3D CODING Generating high-quality 3D programs often requires iterative refinement, but reliance on human feedback makes this process difficult to scale. To address this bottleneck, we develop 3DCodeVerse Harness, a multi-agent framework that automates 3D code generation and refinement for data curation and agent-driven content creation (Figure 3). It coordinates coding and assembly through a DAG and combines execution checks, spatial tools, and rubric-guided VLM judgments to identify defects and guide targeted revisions without human feedback. Because the reliability of this feedback depends on how we configure its prompts, tools, and rubrics, we further refine the judge and generation workflow through an alternating development-time adversarial loop. Multi-Agent Directed Acyclic Graph (DAG) Framework. Given a condition c and a target execution environment e, an LLM planner first produces P = Aplan(c; e), specifying the target components, dimensions, materials, spatial relations, and acceptance criteria. The harness translates P into a DAG G = (V, E) of coding and assembly tasks, with edges encoding prerequisites. Within this graph, explicit file ownership allows independent coding tasks to be carried out concurrently by sub- agents. Once their prerequisites are satisfied, assembly tasks integrate the resulting code, ultimately producing the initial program f (0) for subsequent evaluation and feedback-driven refinement. Automated Feedback and Iterative Refinement. At each round t, the harness executes the current program f (t) and collects three types of feedback: 1⃝Execution feedback. Build and runtime logs ℓ(t). If execution fails, no artifact is produced, and this is the only feedback. 2⃝Measured feedback. Measurement tools Me check the artifact a(t) for dimensions, contacts, collisions, kinematics, and placement, and return component-level violations with numerical correction hints. 5
