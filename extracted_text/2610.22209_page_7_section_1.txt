We introduced FEB-30, the first benchmark designed for in- trinsic evaluation of agent memory systems. By constructing trajectories where the expected memory state is known at ev- ery step, we demonstrated that intrinsic and extrinsic evalua- tion diverge by an average of 16 percentage points, with 44% of trajectories showing meaningful disagreement, revealing false positives and false negatives invisible to response-based benchmarks. Diagnostic decomposition showed the system correctly classifies memory operations only 20% of the time (degrading from 34% at L1 to 10% at L3), a dimension ex- trinsic evaluation cannot measure. We argue that intrinsic evaluation should become standard practice alongside extrinsic benchmarks, analogous to how intrinsic evaluation of embeddings complemented down- stream task evaluation in NLP. We release FEB-30, the gen- eration pipeline, and the scoring framework for reproducible evaluation of agent memory.
