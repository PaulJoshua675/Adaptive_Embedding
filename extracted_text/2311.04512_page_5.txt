(8) Observation Interaction Module. The observation inter- action module is leveraged to capture the observed relative correlation between agents and surroundings with the rela- tive relationships and extracted features in Eq.(8). Equipped with our relative interaction block, we follow LaneGCN [19] to construct four types of interactions, including Agents to Lanes (A2L), Lanes to Lanes (L2L), Lanes to Agents (L2A), and Agents to Agents (A2A). According to Eq.(5), it can be formulated as: A2L : oξ = I(eξ, ei, ∆pξi, θξi), ∀i ∈Gξ a2l, L2L : oξ = ϕ(oξ, oζ, ∆pξζ, θξζ), ∀ζ ∈Gξ l2l, L2A : oi = I(ei, oξ, ∆piξ, θiξ), ∀ξ ∈Gi l2a, A2A : oi = I(oi, oj, ∆pij, θij), ∀j ∈Gi a2a, (9) where ϕ denotes the LaneGCN which has the same architec- ture of lane vector encoder. Future Feedback Module. To capture the possible fu- ture interactions and feed them back to the observations, we propose a future feedback module to exert the feedback influence of future interactions on the feed-forward prediction. Specifically, with the vector features of agents obtained from Eq.(2), we first utilize an initial predictor to forecast a single trajectory prediction of each agent on future Tp timestamps. Subsequently, a future encoder is used to embed those initial predictions, which can be formulized as, ˆpc i = Linear(MLP1(ev i )), e f i = Linear(Conv(ˆpc i)), (10) where ˆpc i indicates the predicted initial trajectory, and e f i represents the future feature of agent i. The future encoder has the same structure as our trajectory vector encoder. After obtaining the future feature of agents, we integrate them with the corresponding observation interaction features obtained from Eq.(9) with three types of interactions: (i) Feedback Interaction. We first integrate the observation interaction features of the target agent with the future features of corresponding surrounding agents. According to Eq.(5), this process can be denoted as f b i = I(1)(oi, e f j , ∆pij, θij), ∀j ∈ Gi a2a, where Gi a2a denotes all agents around the agent i within a certain distance threshold, including the target agent itself. (ii) Future Interaction. We subsequently design a future interaction to explore the plausible interaction behaviors be- tween agents, which are vital clues for feedback refinement. Similarly, it can be denoted as f u i = I(2)(f b i , f b j , ∆pij, θij), ∀j ∈Gi a2a. (iii) Feedforward Interaction. We further update the obser- vation interaction features to the future interaction features in a feedforward way, which forms a closed-loop infor- mation propagation between historical and future informa- tion. We obtain the feedforward interaction features f f i = I(3)(f u i , oj, ∆pij, θij), ∀j ∈Gi a2a. Finally, for a given agent i, we add the updated feedforward interaction feature f f i up to the observation interaction features, so as to generate a cross-temporal fusion features for each agent as follows: fi = oi + f f i . (11) Global Fusion. We introduce a simple global fusion module to propagate the context feature into the obtained cross- temporal features of each agent, which can provide a compre- hensive representation of each agent for reasonable trajectory prediction. In particular, taking the observation lane feature oξ in Eq.(9) as well as the cross-temporal fusion feature fi in Eq.(11), we employ the same network architecture with the observation interaction module, and generate the final feature gi for a given agent i. E. Final Prediction Taking the final feature gi as input, our final predictor can generate normalized coordinates of multi-modal trajectories for multiple agents in a single shot. They can be transformed to absolute coordinates with the inverse operations in Eq.(1). Specifically, for providing K possible future trajectories and their probabilities of best-predicted trajectory, we equip the prediction head with K regression branches and a classifica- tion branch. The process can be formulated as follows: ˆpk i = MLP3(gi), sk i = MLP3([MLP4(ˆpk,Tp i ), gi)]), (12) where MLP3 consists of the MLP Block following a linear layer; and MLP4 is the stack of a linear layer, a ReLU function and a linear layer. Besides, ˆpk,Tp i denote the endpoint of the kth predicted trajectory of agent i. Model Training. Unlike the two-stage goal-based meth- ods [6], [32], our FFINet obtains the initial and final pre- dictions in a single shot. Therefore, we calculate the error of initial and final predictions simultaneously. Specifically, we employ Smooth l1 loss Lc reg to measure the regression distance error between the initial predictions and ground- truth trajectories. As for the final multi-modal predictions, we take the winner-takes-all (WTA) [33] strategy and back- propagate the loss of the best-predicted trajectory. Besides, we measure the regression loss Lreg across all time steps, calculate the endpoint loss Lend with the smooth l1 loss and the classification loss Lcls with the max-margin loss, as done in [19]. The total loss L can be denote as follows: L = Lreg + λLend + βLcls + γLc reg, (13) where λ, β and γ are three constant weights.
