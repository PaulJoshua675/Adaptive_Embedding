Motivation. The PCA results (Figure 2) show that task vectors for different objectives are dispersed across a high-dimensional space rather than concentrated in a shared linear subspace, indicat- ing a complex task vector manifold that cannot be effectively cap- tured by linear combinations. This motivates the need for adaptive merging to learn preference-conditional coefficients that navigate this manifold. At the same time, sequential recommendation models exhibit heterogeneous parameter importance: although approxi- mately 30% of parameters can be removed without severe degra- dation (Figure 3), pruning affects objectives differently. Accuracy- oriented updates are highly sensitive, while diversity-oriented ones are robust. This asymmetry suggests that naively merging dense vectors risks suppressing critical parameters and retaining interfer- ing updates, making preference-based merging unstable and less controllable. Together, these observations motivate a two-stage design: first, conflict mitigation via pruning reduces interfer- ence and preserves task-critical parameters, and second, adaptive merging explores the complex manifold to achieve controllable multi-objective trade-offs. 4 RecSoup: The Proposed Approach In this section, we present RecSoup, a novel controllable multi- objective recommendation framework that decouples the merging process into two stages: determining which parameters to combine and defining how to weight them. This is realized through two modules–conflict mitigation via pruning and adaptive merging with learnable coefficients. 4.1 Approach Overview Figure 4 illustrates RecSoup’s two-stage architecture: (1) Conflict Mitigation via Pruning. This stage sparsifies task vectors by filtering parameters based on importance and relevance, thereby mitigating interference. (2) Adaptive Model Merging. This stage dynamically optimizes coefficients within a learned Pareto manifold to balance competing metrics (e.g., accuracy and diversity). By distinguishing parameter selection from coefficient determination, RecSoup ensures robust control. At inference, a gating network generates coefficients for any preference vector in a single forward pass, enabling efficient control without retraining.
