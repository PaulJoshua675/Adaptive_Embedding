A brief overview of naspaclust This package contains the function to perform clustering using FGWC. Furthermore, we add several improvements to address the disadvantages in fuzzy clustering by using a nature-inspired optimisation algorithm. (fgwc and optimisation) This package also provides data sets from the 2010 Indonesian Population Census which are aggregated into 33 provinces and contain 110 characteristics. This data has been implemented by (Wijayanto et al., 2016) in evaluating the performance of FGWC using the optimisation algorithm. The detail can be seen in (Wijayanto, 2015).
