The following lemma presents the expected runtime required to fully cover the Pareto front of LOTZ based on the assumption that two extreme Pareto front points and at least one non-extreme Pareto front point of LOTZ is cov- ered. The proof is analogous to that of Lemma 9. Specifically, an individual, as described in Lemma 14, w.r.t. the LOTZ problem, is paired with any individual w.r.t. the DLTB problem, and then only the mutation operator is applied to generate an offspring corresponding to some uncovered Pareto front point. Lemma 16. Let n ∈[2, +∞) ∩N. Consider using the MO-MFEA with binary tournament selection, one-point crossover, standard bitwise mutation and population size N ≥8(n + 1) to optimize (LOTZ, DLTB) problem. Let V and eV be defined as in Lemma 14. Assume that eV ⊊V always holds. Then within 72eNn2 1−prm expected function evaluations, the Pareto front of LOTZ is covered (by the individuals corresponding to this task). Proof. Let V + in and V − in be defined as in Lemma 14. From Lemma 14, we know that when eV ⊊V and V̸ = M 1, there is an individual X ∈St,1 with f 1(X) ∈V \ ((V + in ∩V − in ) ∪eV ) and φ(X) ≥ 5 18(n+1). Let f 1(X) = (k, n −k) with some k ∈[1..n −1]. Assume that (k, n −k) /∈V + in , that is, (k + 1, n −k −1) /∈V (or (k, n −k) /∈V − in , that is, (k −1, n −k + 1) /∈V ). Starting from a population with (k, n−k) ∈V \V + in (or (k, n−k) ∈V \V − in ), let p+ k denote the lower bound of the probability of generating an offspring Y + with f 1(Y +) = (k + 1, n −k −1) and τ(Y +) = 1 in one iteration (or p− k for the lower bound of the probability of generating an offspring Y −with f 1(Y −) = (k −1, n −k + 1) and τ(Y −) = 1 in one iteration). Since (k, n −k) is a Pareto front point w.r.t. LOTZ, from Lemma 3, we know that it will be covered by the set of individuals for task LOTZ in all future iterations. Therefore, we know that the expected number of iterations to reach Pareto front point (k + 1, n −k −1) (or (k −1, n −k + 1)) is 1 p+ k (or 1 p− k ). Also note that any Pareto front point once reached will be kept in all future iterations from Lemma 3.
