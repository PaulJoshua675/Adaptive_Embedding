2.1 Encoding functions 2.1.1 Preprocessing of raw data The event-based datasets used here are extracted from audio, Google Speech Command dataset (GSC) (Warden, 2018), and video, Neuromorphic-MNIST (N-MNIST) (Orchard et al., 2015) datasets. Note that the GSC dataset constitutes a demanding purely temporal dataset because it requires analysing an audio signal, with dynamics of the order of few milliseconds, tenth of milliseconds and hundreds of milliseconds. An event represents a change and the time at which it occurs. It consists of three coordinates (t, p, x) where t is the time of the event, p ∈{−1, +1} is the polarity of the change (+1 for an increase and -1 for a decrease), and x is the index of the change. In the audio dataset, the index is a frequency of the spectrogram and the event indicates a change in the amplitude of the frequency. The audio dataset was converted to events using the speech2spikes algorithm (Stewart et al., 2023). In the video dataset, the index is a pixel coordinate in the image, and the event indicates a change in the brightness of the pixel. Different encoding representations are achieved by applying the event2time algorithm (Dagang, 2022), depend- ing on the audio or video dataset and the network selected. The event2time algorithm creates T arrays (either two- dimensional arrays for videos or one-dimensional arrays for audios). The algorithm scans the events in temporal order, and, when it reaches some proportion p of activated pixels, it creates a new array Is. The full sequence is encoded by T arrays, each with a proportion p of activated pixels. Applying this algorithm reduces the activity of neurons over several timesteps to only one value. Depending on the objective this value can ignore the time dimension (i.e. a simple accumulation of the spikes) or use (i.e. a function of the spike timings). This allows for lower number of computations and thus energy consumption. 2.1.2 Encoding raw data to network inputs In DeNN, the temporal encoding function populates the cells in array Is with the average Inter-Spike Interval (ISI) of each neuron. For the ANN, to allow for comparisons, we chose to use the opposite of the DeNN’s input (i.e. with a negative sign). Note that both DeNN and ANN activations are normalized with mean and standard deviation. For SNNs models’ activations, described in Section 2.2.2, the non-temporal encoding function outputs the number of events scanned by the algorithm for array Is. For all networks, one array Is now constitutes a timestep and will be referred to with variable t. 2.2 Activation functions 2.2.1 ANN activations We define a non-temporal activation with weighted activations as a classic neural network, omitting the biases for simplicity: oj[t] = X i wijf(zi[t]) zj[t] = std(oj[t]) (1) where std is the standardization process with mean and standard deviation applied on the layer, LayerNorm (Ba et al., 2016) with no learning. To allow for comparison with the activation functions defined in 2.2.3, f is here the exponential function. 2.2.2 SNNs activations Neurons in SNNs are represented by a variable called a membrane potential, updated at each timestep t, u(t). SNNs are used to better extract the dynamic information in data sets. Whenever this membrane potential crosses some threshold θ, the neuron sends a spike.
