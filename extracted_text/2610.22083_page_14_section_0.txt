The drive produced by a trained value 𝑗is therefore the inner product ⟨𝑡𝑗, ∑ 𝑖𝑡𝑖 ⟩= 𝑊+ ∑ 𝑖≠𝑗 (𝑊−2𝐻𝑖𝑗 ), (12) where 𝐻𝑖𝑗is the Hamming distance between the two code words. Each pair contributes its full width less twice the dis- tance between them: bits on which the two agree reinforce, and bits on which they disagree cancel. The homeostatic factor must make every trained value fire, so it is set by the weakest of them: it is inversely proportional to the smallest such drive over the trained set, and its ratio to the coherent value 𝑓(1)∕𝑛is 𝑛𝑊divided by that minimum. This requires no measurement, only the pairwise distances of the trained code words.
