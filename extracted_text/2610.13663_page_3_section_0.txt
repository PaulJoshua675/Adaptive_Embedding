A Multi-Agent LLM System for Automated Tuning Studies in which LLM agents are used as a general tool for automatic tuning of individual functional blocks of a model with a fixed architecture and training procedure are almost absent from the open literature (see Section 2). Existing systems focus either on programming tasks and the general ML cycle or on constructing a network from a textual task description. In contrast, the proposed framework does not build a network but modifies its predefined blocks using a single agent interaction pattern that does not depend on the particular application task. The main contributions are as follows. 1. We propose a multi-agent LLM framework for the automatic tuning of individual functional blocks of a neural network model (Section 3). 2. We show that the same framework transfers across five tasks with different types of information representation without changes to its internal structure (Section 5, Table 1). 3. We show that a detailed prompt improves the performance of less capable LLMs, bringing it closer to that of more advanced models (Section 5.2, Table 2). 4. The multi-agent framework improves the baseline models: on the spiking neural network (SNN) tasks (Tables 2 and 19), accuracy increases by 13% on MNIST and by 6% on the scikit-learn digits; on the physics-informed neural network (PINN) tasks (Section 5.4–5.6), the relative error decreases approximately 2500-fold for the generalized nonlinear Schrödinger equation (GNLSE) problem with a known analytical solution, and for problems without analytical solutions, the conservation error decreases approximately 325-fold in the selected GNLSE soliton–Gaussian run (more than 100-fold on average over repeated initializations) and the mass drift decreases 14-fold for the Kuramoto–Sivashinsky (KS) wave with a Gaussian perturbation.
