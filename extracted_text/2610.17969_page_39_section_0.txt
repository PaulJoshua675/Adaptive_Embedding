The evaluation uses lm-evaluation-harness-compatible prompts and log-likelihood scoring under the training tokenizer. H.3 Vision, optimizer, width, and multi-loss evaluations First vision benchmark. The benchmark on the 100-class Canadian Institute for Advanced Research (CIFAR) dataset uses ViTs at the scale of the tiny Data-efficient Image Transformer (DeiT) variant, denoted DeiT-Ti, with d = 192, L = 12, and patch size 4. Models train from scratch for 300 epochs with the standard heavy-augmentation recipe (Touvron et al., 2021a). The recipe uses AdamW with learning rate 10−3, batch size 512, weight decay 0.05, a 10-epoch warmup, cosine decay, RandAugment(2, 9), mixup 0.8, CutMix 1.0, label smoothing 0.1, and random erasing 0.25. Variants are Pre-LN, QK-Norm, nGPT, UCT, and GCT. Evaluation covers clean top-1 accuracy, the Gaussian-noise, contrast, and brightness corruptions of the standard common-corruption robustness protocol (Hendrycks and Dietterich, 2019), and multiplicative rescaling of the normalized input as an input-unit shift. Vision benchmark on Tiny-ImageNet. A second benchmark trains small ViT (ViT-S) models from scratch on Tiny-ImageNet-200 for 200 epochs. These models use d = 384, L = 12, patch size 8, images of size 64 × 64, 100k training images, and 10k validation images. All eight architectures use the same optimizer and augmentation recipe with a 15-epoch warmup. Optimizer and width evaluations. Two further axes test generality beyond one optimizer and one width. The optimizer-pairing axis uses a 51M experiment that replaces AdamW on hidden matrices with the shape-aware orthogonalized Muon optimizer (Jordan et al., 2024). We test ηMuon ∈{0.01, 0.02} for GCT, Pre-LN, and QK-Norm, while auxiliary parameters retain the AdamW recipe. This comparison tests compatibility with a duality-map optimizer. The width axis repeats the learning-rate robustness protocol at d ∈{256, 1024} with L = 8 and fixed dh = 64. The same axis also composes a learning-rate-only µP rule with GCT and Pre-LN at the respective d = 512-tuned learning rates (Yang et al., 2021). Hidden-matrix learning rates scale by 512/d, while initialization and multipliers remain unchanged. PINN multi-loss.
