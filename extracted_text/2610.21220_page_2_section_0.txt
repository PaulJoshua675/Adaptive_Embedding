The result- ing merged model directly generates recommendations based on users’ historical interactions. Notably, this model merging paradigm achieves both high efficiency and a high-quality Pareto front, while avoiding the costs associated with joint multi-objective retraining. However, directly applying existing model merging approaches to recommender systems is non-trivial. Unlike settings where task- specific updates reside in a shared linear regime and can be com- posed through task arithmetic [14, 25], objective-specialized rec- ommendation models exhibit heterogeneous parameter updates driven by structurally conflicting objectives such as accuracy and diversity. As analyzed in Section 3.2, recommendation task vectors substantially deviate from the linear regime hypothesis that under- pins most task-vector merging approaches. The absence of a shared low-dimensional linear subspace renders naive linear interpolation ineffective and prone to cross-objective interference, motivating the need for a merging strategy tailored to the complex parameter geometry of recommendation models. To address these challenges, we propose RecSoup, a two-stage framework for controllable multi-objective recommendation. In the first stage, RecSoup employs a fine-grained pruning strategy to resolve parameter interference. Unlike magnitude-based ap- proaches, we jointly consider objective-specific importance and cross-objective relevance, which establishes a harmonious param- eter foundation for merging. In the second stage, RecSoup moves beyond linear interpolation. We integrate a learnable mechanism that captures the mapping from user preference vectors to merg- ing coefficients, allowing the model to dynamically navigate the parameter space. The synergy between pruning-driven conflict mitigation and adaptive merging enables RecSoup to generate high- quality Pareto solutions with superior controllability, bypassing the optimization instability and architectural overhead of generative approaches. The key contributions are summarized as follows: • We present RecSoup, the first framework to integrate model merging into CMOR, adjusting objective trade-offs directly in the parameter space. • We propose a pruning strategy that jointly considers objective- specific and cross-objective importance and can be integrated with existing dynamic merging mechanisms to substantially improve controllable multi-objective recommendation. • We provide theoretical analysis showing that model merging is a more effective and efficient paradigm for CMOR. • Extensive experiments conducted on various backbones and datasets validate that RecSoup achieves higher-quality Pareto fronts while maintaining comparable controllability to state- of-the-art baselines. 2
