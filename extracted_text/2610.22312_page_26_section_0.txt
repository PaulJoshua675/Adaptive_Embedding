Targets guide candidate selection; realized operation sizes vary with the state and geometry. A cells target selects the shape tier, whose volume is 252 or 256. Density bands guide initialization and event selection. Initial states. A density ρ is drawn uniformly from the family’s band [l, h], giving max(1, min(N − 1, round(Nρ))) occupied cells. Uniform initialization samples coordinates without replacement and assigns independent nonzero labels. Small-tile initialization uses the two smallest positive tile values with probabil- ities 0.9 and 0.1. Region initialization grows connected sets through empty axis neighbors, choosing their typical size to approximate the component-plus-boundary target. Regions receive a label absent from their external neighbors when possible. The latter initializer allows workload to vary both initial component structure and later operations. Event schedule. At rate s, position t is a SET event when ⌊ts⌋> ⌊(t −1)s⌋. The first event is therefore a core operation. Assignments clear cells above the density band, fill below it, and otherwise change a value. The region families prefer nonzero labels distinct from neighboring labels; COMPRESS spawns tiles of value 1 or 2, with probabilities 0.9 and 0.1, and clears a cell when occupancy is too high. At T = 64, most families contain 52 core events and 12 assignments; MOVE contains 45 and 19, and COMPRESS 32 and 32. Assignments enter the supplied history because they can alter the state used by subsequent operations. Reference reads and changed-cell counts separately describe operation scale.
