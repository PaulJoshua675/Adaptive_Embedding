We next describe how FeaTok uses these features to train the tokenizer with feature losses (Fig. 2). 2.1 Learning discrete tokens with feature loss only Conventional discrete tokenizers (Van Den Oord et al., 2017; Jia et al., 2025; Bachmann et al., 2025; Zheng et al., 2026a; Yu et al., 2026) consist of an encoder E, a quantizer Q, and a pixel decoder Dpix. Given an image x partitioned into N patches, the encoder E produces N feature vectors, one per patch, which the quantizer Q maps to discrete tokens z1:N = Q(E(x)). The pixel decoder Dpix then reconstructs the image as ˆx = Dpix(z1:N). Tokenizers are typically trained as an autoencoder with a pixel-level objective Lpix that combines pixel reconstruction losses (ℓ1, ℓ2), perceptual losses (LPIPS (Zhang et al., 2018), GRAM (Lu et al., 2026a)), and adversarial losses (Goodfellow et al., 2014). Once the tokenizer is trained, an autoregressive model conditioned on class labels or text prompts c learns the distribution pϕ(z1:N | c) of the resulting token sequences using the cross-entropy loss. Shaping discrete tokens with feature losses. FeaTok follows the autoencoder-style tokenizer design, but learns the discrete tokens by reconstructing features rather than pixels (see Fig. 2). Concretely, we add a feature decoder Dfeat that maps the discrete tokens z1:N to a prediction ˆy1:N = Dfeat(z1:N) of a feature target y1:N. We train the encoder, quantizer, and feature decoder to match this prediction to the target using a loss Lfeat that combines ℓ1, ℓ2, and cosine distances. For the feature target, following the insights in Singh et al. (2026), we use an average of features from multiple layers of the frozen vision encoder ˆE, y1:N(x) = |K|−1 P k∈K LNk( ˆE(k)(x)1:N), where K contains four evenly spaced encoder layers and LayerNorm (Ba et al., 2016) normalizes each layer’s features before averaging. This target is intended to combine visual detail from earlier layers with semantic information from later layers, balancing expressivity and generative learnability. While we retain the pixel decoder Dpix and its pixel-level loss Lpix during training, we stop the gradients at the decoder input. This preserves the ability to decode tokens back into images while preventing the pixel reconstruction losses from shaping the token distribution. Leveraging global tokens. In addition to patch features, various vision encoders supply a global representation, e.g., a CLS token in DINO (Caron et al., 2021; Oquab et al., 2024; Siméoni et al., 2026) or a global pooling token in SigLIP (Zhai et al., 2023; Tschannen et al., 2025). Replacing pixel reconstruction with feature reconstruction losses naturally suggests discretizing this global feature along with patches. The benefit of doing so is that it allows us to define a hierarchical generative model that first generates the global token and then the patch tokens conditioned on it which simplifies the conditional distributions of the patch tokens by providing a global context.
