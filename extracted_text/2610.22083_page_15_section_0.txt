The derivation uses only the code width and the re- ciprocal wiring of a single output neuron, so it applies to any neuron receiving a dual-rail input in this way: in a layer of neurons trained on different values, each would accept its own ball of radius ℎ(𝑚) about its own trained code word. (12), of which Eq. (13) is the special case. What the network computes is an inner product between its input and the accumulated weight vector, and Hamming distance governs its behaviour because, when that vector is a single code word with weights of uniform magnitude, the two determine each other. The derivation also assumes that a neuron’s firing depends only on its own drive, so it would not survive lateral inhibition or any competitive mechanism between output neurons. Neither case is tested here. Table 12 compares this prediction with the hardware. The accepted set has exactly the predicted size in 238 of the 256 measured conditions. Where the accepted values were few enough to be recorded individually, agreement in size always meant agreement in content: all 140 such sets are identical to the prediction, value for value. Johnson and three of the four hybrids match in every condition. The remaining 18 conditions depart from the prediction by at most one bit of tolerance, and always towards ac- cepting more rather than less. In 16 of them the network also accepted the next Hamming shell, that is every code word at exactly one further bit of distance. Twelve occur in Thermometer and four in the linear hybrid at 𝐵= 4, and the cause is the resolution of the measurement rather than of the network. The minimum factor is located to within 0.01 and rounded upwards, so the gain actually applied can exceed the nominal multiple by up to 0.01∕𝑓(1), about 0.4–0.5% here. By Eq. Wherever the predicted radius falls just short of an integer, that is enough to admit the next shell: the linear hybrid at 𝐵= 4 departs only at ×1.1, where its predicted radius is 2.95. Because the factor is rounded upwards, the error is always on the tolerant side. The last two conditions occur where Eq. (13) evaluates to an exact integer, placing the threshold on a shell boundary: Binary at target 128 and Gray at target 255, both at ×2 tolerance, where 𝑊(1 −1∕𝑚)∕2 = 2. There the network accepts every code word within one bit of the target and seven of the twenty-eight at distance two. The seven are not arbitrary: they are precisely those code words containing the same number of set bits as the target, while the twenty-one rejected ones each contain two more. This is the asymmetry reported in Section 4.2.1. Because the two rails are presented at different times relative to the teacher spike, their synapses acquire slightly different weights, so a code word with more set bits requires marginally more gain to reach threshold. The effect is of order one percent and has no consequence except where the threshold falls exactly on a shell boundary, as it does here. Finally, the measurement is reproducible. The target 240 trained alone in this experiment is the 𝑛 = 1 case of Section 4.3, and the two independent hardware runs return identical minimum factors for all eight encodings. 4.4.2. The encoding determines what the radius means Since the gain controls a radius in code space, the se- mantic meaning of tolerance is fixed entirely by the encoding (Table 13). Thermometer and Johnson accept a single contiguous interval at every tolerance and at every target, and it grows smoothly: from the target 240, the furthest accepted value lies 12 semantic units away at ×1.1 and 111 away at ×8 for Thermometer, and 5 then 56 for Johnson.
