We optimize Equation 1 with Group Relative Policy Optimization (GRPO) (Shao et al., 2024): for each x, we sample G rollouts {y1, . . . , yG} ∼πθ(· | x), score each with R(x, yg), and update the policy using each rollout’s advantage relative to the group’s mean reward, with no learned critic. 2.2 SET-LEVEL OBJECTIVE In our setting, each prompt x is answered by a set of K outputs U = {u1, . . . , uK} written in a single generation, after a shared reasoning prefix. This set is the rollout y in Eq. 1, so GRPO scores it with one scalar and computes one advantage per set. All K outputs therefore share that single credit signal. Our goal is a set that is high-quality and whose outputs are mutually distinct. Then we train the model using a set-level objective using the definition below: Rset(x, U) = K X i=1 q(ui) · min j<i d(ui, uj), min j<i d(ui, uj) := 1 if i = 1 (2) For each item in the generation, we multiply its quality by how far it is from its nearest predecessor and aggregate over the set to get the reward. A redundant but high quality item earns almost nothing (Fig 1). The objective has two components: a quality function q(ui) ∈[0, 1] that scores an output for the prompt, and a distance d(·, ·) ∈[0, 1] between two outputs. Any task with a quality signal and a notion of diversity fits, such as instruction following, creative writing, or ideation; we instantiate both for document-grounded ideation in Section 3.1. Relation to Creative Utility. Eq. 2 is adapted from Creative Utility (CU) (Wadhwa et al., 2026), which scores a set of ideas by the quality each one adds beyond the ideas already selected. We make two design choices in adapting it to a training reward. First, CU applies a patience discount (γ) to later ideas; we drop it for training, so every idea in the set is weighted equally and a model cannot fall back on generating weak ideas later in the set. Second, CU takes the best ordering of the set; we instead use the order in which the model writes them. Our prompt asks the model to list ideas from most to least promising, and it lets the reward be computed directly from a single rollout. At evaluation we report CU as is (Section 4). Relation to multi-answer RL. Our proposed objective can be viewed as a generalized form of the set-level objective introduced by Puri et al. (2026). Their formulation however has no notion of distance and instead only checks for coverage against an established ground truth answer set. Their objective can be defined as a special case of Eq 2, by setting d(ui, uj) = 1 and q to a coverage metric. 3 DOCUMENT GROUNDED IDEATION As mentioned in Section 1, we study the task of document-grounded ideation i.e. given a body of related literature, an agent needs to generate a set of ideas worth pursuing next, and we evaluate the set of ideas for its quality and diversity. Task definition. An instance is a corpus of documents D = {d1, . . . , dn} (each a scientific paper, given as a summary). An agent must produce a set of K ideas U = {u1, . . . , uK}, where each idea ui is a structured idea card with four fields: a problem gap, a core claim, a method, and an inspiration field that names the specific source documents the idea draws on and how. Why a set of K? We make the set the primary unit, generating all K ideas in one pass so each is written conditioned on those already emitted. The agent can actively avoid repeating itself, steering later ideas toward directions its earlier ones left uncovered, rather than relying on independent draws to spread apart by chance (Puri et al., 2026; Bahlous-Boldi et al., 2026; Zhang et al., 2026).
