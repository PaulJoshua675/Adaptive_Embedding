Algorithm 3 Generate-Offspring(P, τ(P)) Input: a population P = {X1, ..., XN} Output: a population Q = {Y1, ..., YN} 1: Q = ∅ 2: Generate the parent population P ′ = {X′ 1, ..., X′ N} by performing bi- nary tournament selection (based on their scalar fitness φ) N times on population P 3: for each parent pair (X′ 2j−1, X′ 2j), j = 1, 2, ..., N 2 do 4: Generate a random number a ∈[0, 1] 5: if τ(X′ 2j−1) == τ(X′ 2j) or a < prm then 6: Generate (Y2j−1, Y2j) via applying crossover and mutation operators on (X′ 2j−1, X′ 2j) 7: Uniformly at random assign τ(Y2j−1) and τ(Y2j) from {τ(X′ 2j−1), τ(X′ 2j)} 8: else 9: Generate Y2j−1 and Y2j via applying mutation operator on X′ 2j−1 and X′ 2j separately 10: τ(Y2j−1) = τ(X′ 2j−1), τ(Y2j) = τ(X′ 2j) 11: end if 12: Q = Q ∪{Y2j−1, Y2j} 13: end for 7
