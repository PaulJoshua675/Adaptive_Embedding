The write support also includes intermediate coordinates traversed and later cleared during an entity’s move, even when their final value equals their initial value. The read count is the number of processed entities plus all in-bounds destination checks, including checks that encounter an obstacle. The direction is s ∈{−1, +1} and k is a nonnegative integer. At k = 0 the scan is the selected entity count and the state is unchanged. An entity already at the leading wall makes no in-bounds destination check; an entity immediately behind an obstacle makes one. Original entities are processed once: moving an entity into another coordinate does not add it again to the processing list. Ties on the moving-axis coordinate occur only on distinct lines and do not affect the result. The selected generator uses 1 ≤k ≤min(4, Lj −1) rather than treating k as the workload parameter. COMPRESS(j, s). On each line parallel to axis j, list the nonzero values starting at the destination edge. Read this list in order, replacing each adjacent equal pair by its sum and continuing after the pair. Write the resulting list from that edge and set the remaining line to zero. A newly merged value cannot merge again during the same event. For example, [2, 2, 4] toward coordinate zero becomes [4, 4, 0], not [8, 0, 0]; a second event produces the latter. Core events conserve each line’s sum. Generated values are zero or powers of two through 212; an out-of-alphabet merge is invalid and rejected by replay validation. Every core event reads the entire world, making world size its workload parameter. The order is stable before pairing: zeros are removed without sorting the remaining values. The one-pass pairing rule also distinguishes [4, 2, 2, 0] 7→[4, 4, 0, 0] from an unrestricted repeated-merging process. Opposite directions can choose different pairs when there are three equal tiles. A core event cannot create an additional nonzero tile, but the interleaved SET policy can inject small tiles, so the core conservation properties are not claims about the whole event sequence.
