Ternary weights and conversion. Ternary weights {−1, 0, +1} date at least to Hwang & Sung (2014); ternary weight networks (Li et al., 2016) popularised the scaled ternary code with a thresh- old rule. Following binary BitNet (Wang et al., 2023), BitNet b1.58 (Ma et al., 2024) showed that language models pretrained with this alphabet can match full-precision counterparts at scale while enabling multiplication-free matrix products. Converting existing checkpoints avoids pretraining from scratch, but the computational cost varies. Quantization-aware training, distillation and code fine-tuning (Liu et al., 2025c; Wu et al., 2025; Malinovskii et al., 2024) still update weights or codes. Learned ternarization also involves sustained optimization: CAT-Q (Wang et al., 2026c) uses 512 calibration samples but optimises its codes for 60 epochs, while ScaleQ-1.58 (Wang et al., 2026b) uses the model’s own reasoning traces. Although CAT-Q is described as post-training quantization, we distinguish its extended code optimization from the lightweight conversion setting considered here.
