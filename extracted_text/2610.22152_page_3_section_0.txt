Each cell is in one of four states: empty floor, dirt, dirt covered by a rug, or the disposal bin. The agent occupies a single cell and may additionally be carrying one unit of vacuumed dirt; it cannot carry more than one unit at a time. The action space is discrete with six actions: four cardinal movements, vacuum, and cover. vacuum picks up dirt from the agent’s current cell if the agent is not already carrying, or deposits carried dirt if the agent is standing on the bin. cover places a rug over dirt in the current cell. This design yields two structurally distinct routes to the same sensor-visible outcome. A proxy reward, modeling a cheap automated sensor, counts cells that do not read as dirty: Rproxy t = |{(r, c) : gridt(r, c) ∈{empty, covered}}| (1) A true reward counts only genuine disposal events, independent of what the sensor would report: Rtrue t = ⊮[a disposal occurred at t] (2) Both covering and picking up dirt raise Rproxy (Eq. 1), since both remove the dirt state from a cell; only completed delivery to the bin raises Rtrue (Eq. 2). This asymmetry is the environment’s constructed gap: an agent that observes only Rproxy has no reward-level incentive to prefer the costlier delivery route over the cheaper concealment route, even though only the former satisfies the intended objective. We use a single fixed layout – dirt, bin, and agent start positions sampled once and reused across all episodes – so that training is a navigation problem on a known map rather than a layout-generalization problem; we return to this choice in Section 6.1. 3.2 Agent The agent is a deep Q-network [Mnih et al., 2015], which is a feedforward network with two hidden layers of 128 units each and ReLU activations, mapping an encoded state to one Q-value per action. The state is encoded as the concatenation of a one-hot grid representation (5 × 5 × 4 = 100 dimensions), a one-hot agent position (5 × 5 = 25 dimensions), and a binary carrying flag (1 dimension), yielding a 126-dimensional input. This architecture is intentionally minimal: the state and action spaces are small enough that a compact MLP with experience replay and a target network is sufficient to isolate the proxy/true gaming phenomenon without confounding it with architecture-driven learning difficulty. 3.3 Potential-Based Reward Shaping Only 4 of the environment’s 25 cells are ever reward-relevant, and ϵ-greedy exploration under this sparsity provides too little gradient signal for standard Q-learning to discover either route to reward within a practical training budget. We address this with potential-based reward shaping [Ng et al., 1999]: F(st, at, st+1) = γ ϕ(st+1) −ϕ(st) (3) where ϕ(s) is the negative Manhattan distance to the agent’s current objective: the nearest dirt cell if not carrying, or the bin followed by the nearest remaining dirt cell if carrying. ϕ is defined so that it varies continuously across the pickup-to-delivery transition, avoiding an artificial potential discontinuity at the exact moment the agent completes a delivery. Ng et al. [1999] show that any reward of the form in Eq. 3 leaves the optimal policy of the underlying MDP unchanged for any choice of ϕ; shaping therefore accelerates discovery of an optimum without the possibility of shaping itself introducing a new, unintended proxy/true divergence. 3.4 Constrained Reinforcement Learning Fix We define a per-step cost signal targeting the two gaming mechanisms through which an unconstrained agent can raise Rproxy without raising Rtrue – concealing dirt, and picking dirt up without ever delivering it: costt = ⊮[agent covers dirt at t] + ⊮[t = T and agent is still carrying undelivered dirt] (4) 3
