Interventions type - Code quarantine of exposed contacts or travelers as Quarantine and tracing or notifying contacts as Contact tracing; record both when the model represents both, but code isolation alone as Other. - Code a modeled hospital infection-control intervention as Hospitals and a dedicated treatment-centre intervention as Treatment centres; hospitalization, hospital setting, or a hospital case group alone is not an intervention. - Code an explicitly modeled antiviral or other medical intervention as Treatment, and a modeled public-awareness or adherence intervention as Behaviour changes; a changing contact or transmission rate alone does not establish Behaviour changes. - Code modeled interventions with no matching listed option as Other, including isolation alone, border control, school or workplace closure, and general hygiene or infection-control measures that are not represented as Hospitals or Behaviour changes. Model type - Models that represent transmission through offspring or secondary-case distributions, renewal equations, transmission chains, or Hawkes/self-exciting processes are Branching process; stochastic simulation alone does not determine this category. - Code Agent / Individual based only when individuals are simulated explicitly; a contact network that only structures contacts does not by itself make a model Agent / Individual based. - Phenomenological growth models such as Richards are Other; a regression, neural-network, or risk model is not a dynamic transmission model unless it itself represents transmission dynamics. Code available - Code True when the paper provides code for at least one dynamic transmission model or identifies an accessible repository or archive containing it; code available only on request does not establish accessibility. - Data availability, an open-access publication license, or authors' use of code without a report that model code is provided or accessible is coded False. Transmission route - Sexual contact between people is coded Sexual, not Human to human (direct contact). - Transmission from mosquitoes or another animal to people is coded Vector/Animal to human; nonsexual transmission between people, including blood transfusion, breastfeeding, or vertical transmission, is coded Human to human (direct contact). - Airborne, droplet, or other modeled close-proximity spread is coded Airborne or close contact; do not code a route that the model explicitly excludes.
