Such rules therefore refreshe at different nodes for different prompts, whereas a fixed schedule applies one refresh pattern to all of them. Either way, each node, or token, makes one binary choice between a full evaluation and reuse. SoftCache refreshes on the same spectral signal (Chung et al., 2026), but also reads its headroom below the threshold to make reuse soft rather than binary. 2.3 PREDICTIVE CACHING Between refreshes, most caches hold the stored quantity fixed (Ma et al., 2024; Selvaraju et al., 2024; Liu et al., 2025a; Chung et al., 2026), so the reuse error grows with the time since the last refresh. Predictive caches extrapolate from recent history instead. Some forecast what the network returns, the output of the block stack (Cui et al., 2026), its increment over the input (Bu et al., 2025), or the velocity itself (Wang et al., 2026). Others forecast the increment each attention and MLP branch adds to its input, which the current node applies to its own activations, with Taylor (Liu et al., 2025b) or Hermite (Feng et al., 2026) coefficients built from several stored past values. Multistep formulas (Yu et al., 2025; Zheng et al., 2025a) and a check on the prediction (Liu et al., 2025c) extend how far it can be carried. All of them predict only at the nodes of the sampler’s schedule, so the schedule itself is untouched. We extrapolate an increment as well, a single one for the entire stack, along the straight line through the two most recent fresh evaluations. Written in the flow time, that line is defined between nodes, which is what lets the sampler leave the schedule rather than only skip evaluations along it. 2.4 ADAPTIVE STEP SIZE CONTROL Adaptive ODE solvers set each step at runtime from an estimate of the local error, obtained by comparing two solutions of different order (Dormand & Prince, 1980), and the same control has been applied to diffusion sampling in both its SDE (Jolicoeur-Martineau et al., 2021) and ODE (Lu et al., 2022) forms. The estimate costs several network evaluations per step, which is the computation a cache exists to avoid. SoftCache takes its step size from the refresh signal the cache already computes, so the schedule adapts at no evaluations beyond those the cache spends anyway. 3 PRELIMINARIES Diffusion and flow models generate a sample by transporting noise to data along a differential equa- tion. In diffusion models this is a reverse-time SDE or, equivalently, its probability-flow ODE, whose drift is built from a learned score (Song et al., 2021b), while in flow matching the network regresses the transporting velocity directly (Lipman et al., 2022; Liu et al., 2022; Albergo & Vanden-Eijnden, 2022). We present the method in the ODE form, which covers the rectified-flow transformers we evaluate (Esser et al., 2024). Writing xt ∈Rd for the state at time t ∈[0, 1], with x0 ∼p0 a sample from the prior and x1 the generated data sample, sampling integrates dxt dt = vθ(xt, t), vθ : Rd × [0, 1] →Rd, (1) from t = 0 to t = 1 over a grid 0 = t0 < t1 < · · · < tN = 1 that the scheduler fixes before sampling, independently of the prompt and of the trajectory. With the explicit Euler solver, one step reads xi+1 = xi + ∆i vθ(xi, ti), ∆i := ti+1 −ti, (2) so a sample costs N evaluations of vθ, one at every node of the grid. 3.1 RESIDUAL CACHING A cache removes most of the cost of a step by reusing what an earlier evaluation produced. Which part is reused follows from how a diffusion transformer (Peebles & Xie, 2023; Esser et al., 2024; Black Forest Labs, 2024; Kong et al., 2024) computes vθ, in three stages.
