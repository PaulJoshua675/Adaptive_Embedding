A Models Table 3 lists the seven configurations. All frozen- retrieval runs go through OpenRouter, with the serving provider pinned because providers serve different quantisations. Temperature is 0 where the provider exposes it, and Luna runs at the provider default. The layer-wise readouts in Section 5 use the open weights of gpt-oss-20b, gemma-4-31b and qwen3-8b. Frozen retrieval. The open models have no provider-native search tool, so our tool loop sup- plies one, and Luna uses the same loop under frozen retrieval. It offers three functions in standard function-calling format, search, open page and find in page, which each model’s own chat template renders; in the closed-book condition no tools are offered. Every search call returns the fact’s frozen menu, so the query is recorded but has no effect. A menu always has exactly ten entries, each with a title, URL and snippet. Where the ground-truth page is not in the organic top ten, it is inserted at a seeded position and the tenth entry is dropped (62 of the 223 menus), and the tool result gives no sign of this. Opening a page returns its frozen text in windows of 40,000 characters, and pages not on the menu are refused. Each episode allows at most five searches, five page opens and eight assistant turns. Deployed run. Luna’s deployed run uses Ope- nAI’s Responses API with the provider’s own web search at default settings. Luna searched in every one of the 1,747 treatment episodes with search enabled, 1.58 times on average with 23 results per search, and opened at least one page in 46.4% of them. B Fact Sources Table 4 lists the six sources. The pipeline generates facts using a single cutoff of 1 February 2026; the evaluated set then keeps only changes after the evaluated model’s reported cutoff. GLM-5.3-Flash discloses no training cutoff, so contamination is ruled out by behaviour instead. Closed book, it judges post-cutoff claims correctly 53.6% of the time, within the 45.7–58.4% of the other models (Table 7), and with search it answers 98.3% of control questions correctly, against 97.0–100% for the others. Facts are stratified by how predictable the change is. Deaths and transfers cannot be announced in advance. Earnings, officer changes and la- bel changes are partly predictable. IPO listings and ticker changes are usually announced, so the announcement-date gate removes most of them. For FDA facts, each label’s Recent Major Changes field certifies the drug, the section and the month of revision. We fetch the current sec- tion and compare it, sentence by sentence, with the latest archived version from before the cutoff; the clause that is new becomes the fact. A clause already present in the earlier label becomes a con- trol, and a claim answerable from standard medical knowledge is excluded. Control facts. Control facts did not change across the cutoff, so their failure rates give each model’s floor. Sports controls are players who have been at the same club since 31 March 2024 or ear- lier, matched to the treatment players by league tier, tenure and prominence. People controls are living people, matched to the treatment people by prominence. FDA controls are label clauses already present before the cutoff. The deployed run uses 120 control facts (people 47, sports 39, FDA 34), and frozen retrieval uses 119. Exclusions. Of the 233 treatment facts run, eight were withdrawn after review: four had malformed before or after values, two named people who could not be pinned to a single individual, and two had unreliable ground truth. This leaves 225. Narrower exclusions apply only to the prompts they affect: 27 people fact sheets whose planted line stays true after the death, so it is not false; one finance fact whose false claim reads the same as its true claim, in the false-claim prompts only; two FDA control claims that drop a qualifier the label itself carries, in the claim prompts only; and a few prompts with known rendering or grading defects. An early pilot run is excluded entirely. C Prompt Types Table 5 lists the six prompt types.
