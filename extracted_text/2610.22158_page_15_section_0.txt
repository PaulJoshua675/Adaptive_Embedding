C Failure-Mechanism Attribution C.1 Mechanism Definitions and Annotation Protocol This analysis builds on the behavioral labels previ- ously assigned by GPT-5.4 and Claude Opus 4.6. We use their existing SQL Behavior, Detection, and Type Identification judgments to identify eligi- ble failures. For mechanism attribution, a separate evaluator pair, GPT-6.1-Sol and Claude Opus 5.5, assigns M01–M04 to these selected failures with- out re-evaluating the three behavioral dimensions. Each sampled response is annotated indepen- dently by the two mechanism-attribution judges using the same final attribution prompt. The task is multi-label rather than four-way classification: each judge must assess M01–M04 exactly once, and a response may receive multiple mechanisms or none.
