We use n = 500 training input functions and ntest = 50 testing input functions, consistent with prior PI- DeepONet studies (e.g. 26, 32, 25), which is suﬀicient to ensure generalisation. More complex problems may require larger datasets; for instance, [11] employ ∼104 input functions. Each input function was discretised using m = 50(d−1) sensor points per (spatiotemporal) dimension. Although we consider Gaussian inputs with varying amplitudes, this resolution reflects more general settings where inputs may contain finer-scale variations while keeping training costs manageable. In the 2D and 3D linear advection problems there are multiple input functions, corresponding to the inflow boundaries xi = 0 for i = 1, . . . , d −1. Each boundary condition is parametrised by an independent amplitude Ai, and therefore defines a distinct input function. To handle the multiple independent boundary condition inputs, we employ the Multiple-Input DeepONet (MIONet) structure [31], which uses separate Branch networks to process each input function. In all our experiments, both Branch networks adopt either the Vanilla or the ATenH architecture. The outputs from the separate Branch networks and the Trunk network are then combined via an inner product across all Branch networks and the Trunk network. As an illustrative example, in the 2D linear advection problem with spatial coordinates (x1, x2), there are two boundary inputs corresponding to x1 = 0 and x2 = 0. For n = 500 samples, each boundary condition is discretised using 50 points per spatial and temporal dimension, yielding m = 502 = 2500 input degrees of freedom per boundary. The boundary and initial condition losses are evaluated at 102 collocation points each, while the interior physics loss is evaluated at 103 collocation points. Subnetwork depths and widths were selected via grid searches on the 1D and 2D advection problems, which can be seen in Fig 3. To avoid overcomplicating the hyperparameter space, both subnetworks used the same width and depth. In both cases, four hidden layers provided the best compromise between computational cost and accuracy. Similarly, we select widths of 40 neurons per hidden layer for 1D and 60 for 2D. A ded- icated grid search for 3D advection was not performed due to the prohibitive computational cost; instead, we heuristically inferred subnetwork widths from the lower-dimensional results, setting 80 neurons for the 3D problem. All hidden and output layers were kept at the same width to avoid unnecessarily complication of the hyperparameter space. A large proportion of computational resources was not devoted to extensive hyperparameter optimisation, as the primary objective of this study is to assess the computational perfor- mance of different architectures rather than to maximise predictive accuracy. The configurations used were suﬀicient to reliably learn the solutions of all test problems, as demonstrated in the following section. All models were trained in PyTorch using the Adam optimiser [33], with a learning rate of 10−4 and tanh activation functions, on an NVIDIA A100 GPU.
