E.4 Native 3D Baselines We additionally evaluate two native point-cloud language models under the same binary verification interface, as shown in Table E7. PointLLM-v1.2-7B (Xu et al., 2025) collapses to all-True predictions, yielding 50.0% Balanced Accuracy with zero False recall. PointLLM-R-7B (Chen et al., 2026) achieves only 8.3% Balanced Accuracy, largely because most responses fail to emit the required binary judgment. These responses typically terminate normally with EOS but instead produce empty answer fields or free-form object descriptions.
