The serializer maps symbols back to original labels and creates the response object. Consequently, schema-conforming output does not depend on a free-text decoder generating valid JSON. It also does not guarantee semantic correctness or agreement between related fields. The service can return the probability of yes for Boolean questions and an expected numeric value for ordinal questions. These quantities differ from the discrete argmax label used for decision accuracy. For all types, candidate probabilities and maximum probability remain available to downstream controllers. 3.5. Computational scope The method removes iterative answer decoding and avoids separate field-by-field forward passes. It does not eliminate the cost of processing the input: longer states, more image tokens, and larger schemas still increase computation and memory. One request may yield multiple decisions, so request rate and decision rate are different quantities. Causal ordering also means fields can have different contextual prefixes even when they share a forward pass; the construction does not enforce permutation invariance or a jointly constrained output distribution. 4.
