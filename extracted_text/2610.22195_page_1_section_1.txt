Orchestrating multiple agents on a complex task requires reconciling local subtask execution with global task planning. Dynamic dispatch ap- proaches provide execution flexibility but do not explicitly model subtask hierarchies or depen- dencies, while predefined workflows impose this structure but fix the decomposition before exe- cution begins. Therefore, we introduce HTN- Orchestrate, a two-layer framework that separates these responsibilities through a hierarchical task network (HTN). The Planner maintains subtask hierarchies and dependencies, deferring decom- position until prerequisite results become avail- able, while local Orchestrators schedule workers to execute each leaf subtask. Results propagate upward under AND semantics, and accumulated findings inform a rebuilt task network when the current decomposition cannot resolve the task. On five benchmarks spanning web research, sci- entific reasoning, and research workflows, HTN- Orchestrate outperforms ReAct, Agent Team, and DeepSeek Harness using the same base model, achieving 89.73% accuracy on BrowseComp and 73.44% on SUPERChem, exceeding Agent Team by 2.45 and 4.69 percentage points, respectively.
