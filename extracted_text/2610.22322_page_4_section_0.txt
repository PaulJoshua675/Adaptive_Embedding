Starting from the same state, two alternative bids from the same agent induce different turn allocations. The alternative branch is continued from the restored state, and both branches are evaluated, producing returns that determine which bid is preferred. Preference learning then increases the relative likelihood of the bid associated with the better outcome, teaching the agent when to participate. Learning to self-orchestrate requires feedback about participation: would the trajectory have im- proved if another agent had acted at the same turn? We obtain this feedback by comparing counter- factual rollouts from the same state, as illustrated in Figure 4. We define a turn as contested if the runner-up submits a nonzero bid. The original branch is the collected trajectory, in which the selected agent acts at the contested turn. To construct the alternative branch, we restore the environment and agent states at the contested turn in a replica and resample the selected agent’s bid up to three times until it falls below the runner-up’s bid, so that the runner- up acts instead. If no such bid is obtained, the contested turn is discarded from bidding training. The alternative branch is then continued until the episode terminates. Each branch is scored by its sum of environment rewards from the contested turn onward. The bidding response associated with the higher-scoring branch becomes the preferred response yw, and the other becomes the rejected response yl. Pairs with equal branch returns are discarded. We train the agent on these response pairs using a Bradley–Terry preference objective (Bradley & Terry, 1952): Lbid = −log σ(log πi(yw | hi,t) −log πi(yl | hi,t)), (3) where σ is the logistic function. Minimizing this loss increases the relative likelihood of the bid associated with the better outcome.
