3 Problem Setup We address the problem of learning a reward function from human input when the teaching signal leaves some features underspecified. Recent work shows that robots can detect underspecified fea- tures from statistical patterns in the teaching data [3]. We use this detection and ask: how should the robot resolve underspecified features? We propose using that knowledge in two ways: to correct the imperfect posterior into an informed prior, and to direct human attention during preference queries. 3.1 Preliminaries The robot’s goal is to learn a reward function that captures how the human wants the task performed. We adopt a linear reward parameterization [10, 11] over state features. Let ϕ : S →Rk be a feature mapping that extracts a k-dimensional vector from each state s ∈S, and let w ∈Rk be the reward weight vector with ∥w∥2 ≤1. The per-state reward is Rw(s) = w⊤ϕ(s), and the cumulative reward of a trajectory ξ = (s0, s1, . . . , sT ) ∈Ξ aggregates state-level contributions Rw(ξ) = P st∈ξ w⊤ϕ(st) = w⊤ϕ(ξ), where ϕ(ξ) = P st∈ξ ϕ(st) accumulates features along the trajectory. We write w⋆for the human’s true preference weights, which are unknown to the robot. The features ϕ may be hand-crafted [11], learned [19], or extracted from a large language model given a high-level task description [20]; we assume access to a candidate feature set. 3.2 An Imperfect Posterior We assume the robot has access to a dataset D of human teaching data, and maintains a posterior P(w | D) ∝P(D | w) P(w) over the reward weights. In general, the likelihood P(D | w) can be instantiated for any teaching modality D, including demonstrations [10, 11], preferences [5, 8], corrections [21], or natural language [22]. For exposition, we follow DemPref [8] and initialize the reward belief from Boltzmann-rational demonstrations [23, 24, 25], which we then refine with pref- erence queries. The resulting posterior P(w | D) is rarely uniform in quality across the components of w. Teaching a task that requires attending to multiple objectives at once is cognitively demanding; humans inevitably focus on some features at the expense of others. The demonstrations are thus not driven by w⋆equally across all features, leaving the posterior misleading along the underspecified dimensions. Prior work [3, 4] showed how the robot can detect, from D, which features were well- optimized and which were underspecified. The candidate feature set may also contain task-irrelevant features, whose posterior reflects spurious correlations rather than the human’s intent. Feature Partition From Merker et al. [3] we inherit the variance-based detection of underspecified features and the LLM-based filtering of task-irrelevant ones, which together partition the k features into three disjoint subsets, collectively denoted by the partition o: 1) ϕo: the task-relevant features that are well-optimized in D, 2) ϕu: the task-relevant features that are underspecified, and 3) ϕε: the features irrelevant to the task. We write wo, wu, wε for the blocks of w corresponding to ϕo, ϕu, ϕε. Refining the Prior with Active Feedback The partition o summarizes what D reveals: P(w | D) is trustworthy on ϕo, misleading on ϕu, and uninformative on ϕε. Our goal is to elicit additional human feedback that sharpens our estimate of w⋆along the underspecified dimensions. One ap- proach is to passively request additional demonstrations of the features in ϕu, returning the burden of producing behavior that exercises those features to the human [3]. Instead, we adopt an active preference learning framework [6], where the robot itself generates queries to resolve its uncertainty. Standard active preference learning [6] uses P(w | D) as the prior; however, its deficiencies in ϕu and ϕε force early queries to first correct the prior before they can resolve the underspecified features. We use o in two ways to address this. First, we construct a corrected distribution P(w | o) by modifying P(w | D) block-wise: retaining what D revealed about ϕo, flattening the prior on ϕu, and concentrating it near zero on ϕε (see Sec. 4.1). We use P(w | o) as the prior for active preference learning, directing the robot’s queries at its uncertainty along ϕu (Sec. 4.2). Second, we adapt the explanation of Merker et al. [3], reframed to instruct the human to attend to ϕu when answering queries, so that their responses inform the specific features that need resolving (Sec. 4.3). 3
