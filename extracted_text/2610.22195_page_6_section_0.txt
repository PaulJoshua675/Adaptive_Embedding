Empirical Evaluations 4.1. Experimental Setup We evaluate HTN-Orchestrate on five benchmarks covering web research, scientific reasoning, and research workflows. BrowseComp (BC) (Wei et al., 2025) tests an agent’s ability to locate hard-to-find information through persistent web browsing. For scientific reasoning and research, we use both tracks of FrontierScience (Wang et al., 2026), with FrontierScience-Research (FSR) comprising open-ended re- search subproblems and FrontierScience-Olympiad (FSO) assessing olympiad-level reasoning in physics, chemistry, and biology. We use the text-only subset of 256 questions from SUPERChem (Zhao et al., 2025) to further evalu- ate multistep reasoning across chemistry subfields, while PRL-Bench (Miao et al., 2026) extends the evaluation to theoretical and computational physics research tasks derived from published papers. We report accuracy for BC, FSO, and SUPERChem, where answers can be directly verified against ground truth. For the rubric-based benchmarks, we report the success rate for FSR, defined as the fraction of responses earning at least seven of ten rubric points, and the mean percentage of satisfied rubric criteria on a 0–100 scale for PRL-Bench. We compare HTN-Orchestrate with the ReAct and Agent Team workflows implemented in FrontierAgent (Apodex Team, 2026).2 The ReAct baseline (Yao et al., 2023) uses a single agent that alternates reasoning and tool use, incor- porating observations into subsequent actions. Agent Team uses a main agent to decompose the task, dispatch subagents in parallel, and integrate their reports as execution proceeds. We also include DeepSeek Harness (DSH) (DeepSeek-AI, 2026a), DeepSeek’s official agent runtime in Minimal Mode, a single-agent configuration with a persistent shell and file editor, to which we add web search tools for BrowseComp. All four methods use DeepSeek-V4.1-Flash as the back- bone model with high reasoning effort. In HTN-Orchestrate, workers instead use low reasoning effort and operate in two complementary roles for research and verification. Their available tools include web search, webpage retrieval, schol- arly search, Python execution, file reading, and report 2https://github.com/ApodexAI/ FrontierAgent submission, though search and retrieval are disabled for FSR, FSO, SUPERChem, and PRL-Bench. To bound net- work growth and execution cost, we set the maximum task- network depth to two (counting the root at depth zero) with at most four children per node, and within each executable subtask allow up to three concurrent workers over at most twelve orchestration rounds per epoch, while the Planner can rebuild the task network once during execution. Main Results HTN-Orchestrate outperforms all three controlled baselines on every benchmark and is competitive with frontier propri- etary models despite using DeepSeek-V4.1-Flash, an open- weight model, as its backbone (Table 2). On BrowseComp, it achieves 89.73% accuracy, exceeding ReAct by 15.80 percentage points and Agent Team by 2.45 points. Only GPT-6 Astra (91.50%), Kimi K3 (91.20%), and GPT-5.6 Sol (90.40%) score higher, all of which are frontier-scale mod- els. Agent Team, which dispatches subagents without hier- archical planning, already exceeds ReAct by 13.35 points, confirming that multi-agent execution is broadly beneficial for persistent web research. The additional 2.45-point gain from HTN-Orchestrate over Agent Team reflects the con- tribution of structured decomposition and result-informed planning. On the two open-ended research benchmarks, HTN- Orchestrate achieves the highest scores among all models in Table 2. On FSR, it reaches a success rate of 43.33%, sur- passing Meta Muse Spark (38.00%), GPT-5.5 (33.90%), and Agent Team (40.00%). The 18.33-point margin over ReAct and 3.33-point margin over Agent Team suggest that sepa- rating global task planning from local worker coordination allows the framework to manage the iterative hypothesis refinement that open-ended research demands. PRL-Bench reinforces this pattern, with a mean rubric score of 46.00 exceeding the next-best result from Gemini 3.1 Pro (44.27) by 1.73 points, while the 10.19-point gain over Agent Team is the largest on any benchmark. On the two accuracy-based science benchmarks, HTN- Orchestrate remains competitive with much larger pro- prietary systems. On FSO, it reaches 79.00% accuracy, matching Gemini 3.1 Pro and improving over Agent Team (75.00%) and DeepSeek Harness (76.00%) by 4.00 and 3.00 points. On SUPERChem, it scores 73.44%, falling only 0.16 points short of GPT-5.6 Sol (73.60%), the overall best, while exceeding Agent Team and ReAct by 4.69 and 8.21 points. Across all five benchmarks, gains over Agent Team range from 2.45 points on BC to 10.19 points on PRL-Bench, with the largest improvements appearing on tasks that reward structured decomposition and iterative refinement. 6
