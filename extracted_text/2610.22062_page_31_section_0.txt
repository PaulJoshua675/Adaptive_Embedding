11 Supplementary Note S7. Prompt-Level and Variable-Decomposition Sensitivity Analyses Note S2 describes how the architecture was selected. Holding that architecture fixed, we ran three further experiments on the refreshed corpus and the corrected exposure anchor to ask which component of the configuration the remaining error is attributable to. The first varied the prompt wording, and it is where the reported configuration comes from. The second replaced the single extraction question with two simpler questions combined by an explicit rule. The third left the extraction untouched and realigned each patient’s sequence of predictions in time. The main text carries the prompt comparison as Table 2, while the realignment appears only here, because it presumes that onset falls at the first on-treatment visit and is therefore a diagnostic of where the error sits rather than a deployable comparator. The version identifiers used in this supplement and in the released code correspond to the main-text names as follows. V0 is uncontrolled diarrhea, the deployed prompt; V1 is any diarrhea; V2 is severe diarrhea, the reported prompt; V3 is severe diarrhea with rules; V4 is any diarrhea with rules; and S1 is the onset-aligned variant. Severe denotes the clinical-significance bar quoted verbatim in Note S3, that the diarrhea be active and either causing ongoing concern or prompting a change in management. With rules denotes the pair of rules that treat resolved diarrhea, and diarrhea attributed to another cause, as absent. Prompt wording Five prompt versions were compared on the same 183 annotated diarrhea cells, with the two agents, the consensus gate, the keyword pre-filter and the output schema all unchanged. Two elements were varied. The first is the severity threshold, specifically whether diarrhea being controlled with medication counts as present. The second is a pair of explicit reasoning rules stating that a resolution later in a note governs an earlier onset, and that a finding attributed to another cause is absent. Version V0 is the deployed prompt and serves as the base case. Each version was run three times. Table S10 reports the results, and three findings follow. First, the severity threshold is the only element that moves accuracy. Restating the deployed exclusion explicitly and adding a severity bar raised accuracy from 79.6% to 84.2% (V0 to V2), the largest movement anywhere in the family. The mechanism is precision. False positives fall from 21 to 12 while true positives are essentially unchanged at 31 and 30, so the added bar suppresses calls on documented but managed diarrhea without giving up detections. The difference is nonetheless not established, as it rests on 9 cells won against 1 lost, which is p = 0.021 before correction and p = 0.15 after Holm correction across the seven comparisons in this family. Second, the explicit reasoning rules add nothing. V3, which is V2 plus those rules, scores 83.1% against V2’s 84.2%, differing on two cells of 183 (p = 0.50), and V0 to V3 changes 12 cells for a net of six (p = 0.35 after correction). The reason is that the deployed prompt already carried both instructions in weaker form, stating that historical references where the finding has clearly resolved are absent, and that findings attributed to another cause are absent (Note S3). The added rules therefore restated existing guidance rather than supplying a new criterion. The residual temporal errors in main-text Table 4 reflect inconsistent application of a rule the prompt already contained, and restating that rule more forcefully did not correct them. Third, reclassifying medication-controlled diarrhea as present made performance worse, by 4.4 points in V1 and 4.6 points in V4, consistently across all three runs. The mechanism is a poor trade, adding 14 false positives to remove 6 false negatives.
