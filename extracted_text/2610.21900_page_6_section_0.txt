Symbols v and s denote a fact version and its source session. 3.5 Event Memory and Original-Text Evidence Some information does not fit a structured fact value, including event context and conditions on behaviour. TEM stores event summaries, free-text memories and original turns for this purpose. Source-session links connect these records to fact versions. Hybrid retrieval draws on both sources of evidence. We use the fact-memory configuration TEM-Status for state-update experiments and TEM-Hybrid-State for public question answering. The hybrid configuration combines the evidence sources under a common budget. Its unmarked control uses the same candidates in the same order (Sections 4.1 and 4.6). 4 Experiments and Results 4.1 Experimental Setup The state-update benchmark contains 60 personas, 600 sessions and 420 questions involving residence, occupation and drinks. There are 180 current-state questions, 180 other historical questions and 60 questions about residence immediately before the latest move. For a historical question, the reference answer is the most recent applicable fact before the target update. Running six memory configurations with four backbones produced 10,080 answers. We compared TEM with naive RAG, session-aware RAG and full context. Session- aware RAG keeps retrieved source turns in session order. The fact-memory comparison uses three configurations. Overwrite keeps only the latest version. Unmarked keeps all versions in source order, and TEM-Status adds historical labels to the same content without changing that order. Experiments used an A100 40 GB GPU. Extraction and answering within a con- figuration used the same frozen backbone. We retrieved at most 15 candidates with all-mpnet-base-v2 and set temperature to zero and the random seed to 42. Llama and Qwen ran in BF16 with a 512-token answer limit; Qwen thinking was disabled.
