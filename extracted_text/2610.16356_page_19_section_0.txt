Experimental Setup To make an easier introduction of the R package, this study attempts to implement the naspaclust package into several data benchmarks that the analyses was implemented using FGWC as follows: • Case 1: 2010 Indonesia population census (Wijayanto et al., 2016): This data contains 110 characteristics which represents the demographic condition in Indonesia at provincial level. The data was obtained from 2010 Indonesia population census. This data represents the condition where the number of regions is small with high dimensionality. • Case 2: East Java dengue fever (Putra and Kurniawan, 2017): This data consists of 9 dengue fever indicators in East Java, Indonesia at district level. The variables in this study includes the percentage of dengue fever cases, bamboo walls, poor households, unhealthy homes, non-healthy households, larva-free houses, rainwater storage, number of flood events, and houses with palm fiber roofs. This data represents the condition where the number of regions is slightly larger than the variables. • Case 3: Indonesia social vulnerability (Nasution et al., 2020; Kurni- awan et al., 2022): This data consists of 16 characteristics of social vulnerability of Indonesia in district level, namely the socioeconomic, demography, and the housing conditions. This data represents the con- dition where the number of regions is much larger than the dimensions. We compared each algorithms performance by using the three datasets mentioned before. Despite the objective function, we also compare the vali- dation indices using each combination. Considering the stochastic nature of metaheuristic optimisation, we run the simulation 100 times for each combi- nation of dataset, algorithm, and number of clusters, which are from 2 to 6. After running the algorithms, we used the following evaluations: • Success final cluster output: We evaluated the final cluster output to assess whether the algorithms produced the expected results.
