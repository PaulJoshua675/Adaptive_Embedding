To partially mitigate this problem, the Fusion Self-Attention Module adheres to the solution proposed by Restormer [53], where the attention scores produce a feature map in RC×C, hence the complexity of the the self-attention module becoming O(HWC), where C represents the projection size of the Query (Q), Key (K), and Value (V ) components. Besides computational complexity, most self-attention modules fail to integrate both local and global features from the image, treating the projection of the images as a unitary feature. The ac- curacy of the down-stream task on which VesperMUSE focuses on, image semantic segmentation, heavily relies on local components such as edges, isolated illumination patterns, and noise. The proposed Fusion Self-Attention Module aims to achieve a both global and local feature extraction, which allows the model to adapt the latent representations considering a wider range of information.
