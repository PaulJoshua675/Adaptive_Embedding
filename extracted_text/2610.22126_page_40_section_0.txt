L Residual-dependence diagnostics under non-additive mechanisms Our surrogate models each feature’s mechanism as additive across parents (Section 3.3); when the true mechanism is non-additive, this can misallocate attribution between the direct and indirect terms (Section 5). We diagnose and quantify this bias directly, using the synthetic SCM/CATE benchmark (Section 4.1), restricted to nodes whose mechanism is either the explicit two-parent interaction term w1x1 + w2x2 + w1w2x1x2 or a matched linear control (eligibility criteria below). Since ground truth is known for every node, we compare directly rather than inferring statistically. A diagnostic based on the residual hj = xj −ˆsj(parents) conflates the systematic mechanism misfit with injected exogenous noise, making it an inherently noisy signal of the bias itself. Instead, we isolate the same systematic misallocation without this contamination by comparing CIG’s indirect- effect attribution computed with the oracle mechanism against the same attribution computed with the learned surrogate: both quantities are deterministic functions of the parents, so no noise term enters at all. We test two scenarios: the interacting variable present as a graph node (“in-graph”), and the interacting variable removed from the graph entirely (“omitted-variable”). A node is eligible if its true mechanism matches the target type (interaction, or a matched linear control) and it is read directly by the downstream model, so that its attribution is nonzero; the linear control is further restricted to nodes with at least two parents (in-graph) or exactly two parents (omitted-variable), matching interaction’s structural requirement of two active parents. The omitted- variable setting additionally restricts both types to exactly two total parents, so that removing one parent’s edge deletes an equal share of each node’s explanatory input regardless of mechanism type. Eligible nodes are found by searching randomly generated graphs per setting, not fixed in advance, and pooled across 5 seeds (in-graph) and 15 seeds (omitted-variable). For each eligible node, we compute the discrepancy between the oracle and surrogate indirect effects across sampled instances, and derive two statistics from that same discrepancy. The indirect effect is a path integral from a zero baseline, so along a linear path the source feature’s own value enters via dxi/dα = xi; the discrepancy is therefore expected to scale with the product of the two parents, xixk, rather than either parent alone (confirmed empirically: correlating against the co-parent alone gives r = −0.16, p = 0.12; against the product, r = 0.83, p ≈7 × 10−27, on the same data). We report the Pearson correlation r of the discrepancy against xixk, and its relative error, RMSE(discrepancy)/RMSE(oracle indirect effect).
