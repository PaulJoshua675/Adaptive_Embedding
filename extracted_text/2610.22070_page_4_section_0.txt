Conceptually, f consists of three parts: (1) the encoding of context Ct−1; (2) the update of the hidden state ht; and (3) the decoding of the LoRA weights ∆θt. This is illustrated in Fig. 2-(2-5). Context Encoding. Videos contain substantial redundancy (Shang et al., 2025; Zhong et al., 2025). Given the observation Ct−1 consisting of a video clip and its textual context (e.g., timestamps in text format), we first compress it into a compact representation. This is done by first encoding the video and text into their embeddings Vt−1 (video) and Tt−1 (text) using the vision encoder and the text tokenizer of the VLM. We then learn a set of queries Q to compress Vt−1 and Tt−1 q_ { t-1} = g ([V_{ t-1}; T_{t-1}; Q]) (4) where qt−1 is the resulting compact representation of Ct−1. g is realized using a few self-attention layers, with the concatenated [Vt−1, Tt−1, Q] as the input (see Fig. 2-2). Hidden-State Update. In interactive settings, new observations arrive continuously over time. An effective memory mechanism should therefore capture both the temporal dependencies among observations and the global semantics accumulated throughout the interaction. To this end, we decompose the hidden state ht into two components: ht = [mt; st], where mt models local temporal dynamics in the stream, while st captures longer-term semantic information. 4
