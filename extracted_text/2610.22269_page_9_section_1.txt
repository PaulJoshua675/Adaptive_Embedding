This paper introduced X-RIC, a novel framework integrating agentic AI into O-RAN architectures to address current RL limitations. The proposed framework features several pro- gressive TLM implementation schemes and a hybrid con- trol architecture for sub-second O-RAN decision-making. We introduced BARX, a domain-specific evaluation framework assessing agentic RAN control across latency, compliance, determinism, and policy impact metrics, and developed au- tomated demonstration collection using dual-filtering behav- ioral cloning to improve sample efficiency while maintaining production-grade reliability. As a case study, we applied our proposed X-RIC framework to a three network slice system, which involves dynamic configuration and poses significant challenges for traditional RL methods to solve within the near- real-time RIC timescale. Validation on SLA-aware network slicing demonstrates that X-RIC significantly outperforms state-of-the-art baselines.
