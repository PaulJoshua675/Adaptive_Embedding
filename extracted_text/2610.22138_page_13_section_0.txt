C Item Construction and Screening Manipulated answers. COUNTERFACT pro- vides them: each record’s counterfactual is another object of the same relation. We drop the 1,945 records whose subject contains either answer. For POPQA, we pair each question with a random ques- tion of the same relation (Wikidata property) and use its answer, rejecting candidates that share an alias with the true answer or appear in the ques- tion; we do not match subject popularity. For SIM- PLEQA, after dropping 42 questions with overlong questions or answers, we assign each question a fine-grained relation with hand-written rules over the question and answer (year, full date, count, or- dinal, person, award winner, city, state or province, country, venue, political party, language, song, al- bum, tour, software patch) and drop the 2,731 ques- tions with no relation or too broad a relation. The manipulated answer comes from a question with the same topic and relation and a compatible an- swer shape (e.g., a four-digit year, an integer count, a person-like name). Screening. We ask each probe question with- out context, several times, to the screening model, deepseek-v4-flash. Each sample is labeled true, manipulated, both, neither (another concrete an- swer), or uncertain, by string matching against the answers and their aliases or by the LLM judge (§3.5). Table 8 lists the stages and thresholds. The first stage screens a random candidate pool cheaply; the second samples the survivors more often and applies stricter thresholds. SIMPLEQA uses a sin- gle stage on its 240 relation-balanced candidates. For COUNTERFACT, we apply the second stage to the stage-1 pool in ascending record order and stop once 40 items pass (71 items screened). For POPQA, 56 items pass, from which we drop the three items whose true answer appears in the ques- tion (§3.4). D Implementation Details We run one conversation per item, model, and num- ber of adversarial agents. Agents are named Al- ice through Jack, with the traits historian, scientist, journalist, teacher, analyst, librarian, researcher, en- gineer, philosopher, and student; adversarial agents are the first k agents. The speaking order is reshuf- fled every round from different random seeds, and is identical across conversations, so adversarial agents speak at the same positions in every run.
