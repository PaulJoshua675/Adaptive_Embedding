Datasets and Benchmarks for 3D Coding. Learning to generate 3D content as code benefits from supervision over its construction procedures. DeepCAD and Fusion 360 Gallery expose CAD construction sequences, and Text2CAD connects such sequences to natural language (Wu et al., 2021; Willis et al., 2021; Khan et al., 2024). This supervision has expanded to executable CadQuery and Blender programs for reconstruction and language-conditioned generation through BlendNet, CAD- Recode, CAD-Coder, and MeshCoder (Du et al., 2024; Rukhovich et al., 2025; Guan et al., 2026; Dai et al., 2026). Complementary procedural resources broaden the content represented by code: Infinigen and its extensions generate assets and scenes (Raistrick et al., 2023; 2024; Joshi et al., 2025), while Shaders21k provides programs for procedural image synthesis (Baradad et al., 2022). Existing benchmarks assess the resulting code generation, editing, and physics capabilities (Alrashedy et al., 2025; Gu et al., 2025; Gao et al., 2026b; Shen et al., 2026). However, our paper focuses on scaling executable supervision across these heterogeneous coding environments. Our 3DCodeVerse-2M provides a million-scale training corpus spanning CAD, Blender, shaders, and browser graphics, with programs that are self-contained within their respective target runtimes. Its construction combines curated existing sources with automated program generation and execution-based filtering, enabling continued data expansion for training open 3D coding models. Harness Engineering for 3D Coding. Execution and feedback allow 3D coding agents to inspect and revise the content produced by their programs. Systems such as 3D-GPT, SceneCraft, and LL3M establish language-driven planning and program generation for 3D modeling (Sun et al., 2023; Hu et al., 2024; Lu et al., 2025). Executing and rendering these programs enables visual refinement, as explored by BlenderAlchemy, CADCodeVerify, and VIGA (Huang et al., 2024; Alrashedy et al., 2025; Yin et al., 2026). Beyond rendered appearance, Articraft provides structured asset validation through a specialized SDK, while Bioinspired123D connects script quality control with a graph-based agentic workflow (Luu & Buehler, 2026b; Zhou et al., 2026). 3DHarnessBench further studies how the observation and tool interfaces available to an agent affect 3D reconstruction (Liu et al., 2026). In contrast, our 3DCodeVerse harness provides a reusable execution and verification framework across coding backends, jointly supporting inference-time refinement and scalable training data curation. Its multi-agent directed acyclic graph coordinates execution, rendering, spatial measurements, and structural checks across static and articulated objects, scenes, and visual effects. We define 3D coding as writing a program f that constructs 3D content satisfying a condition c, comprising a text request and optional reference images. The program is standalone, bundling the source files and assets needed to run in a declared environment e such as Blender (bpy) or CadQuery.
