Nevertheless, progress on personalized robotic manipulation (PeRM) remains impeded by two major gaps. First, PeRM lacks a shared formulation and standardized evaluation protocol across prior work. Existing studies define personalization through diverse problem settings, including implicit preference alignment [9, 10], multi-user style adaptation [11], user-specific object-receptacle pairing [12], and helpful action prediction [13]; they also specify preferences through natural language [13, 14], few user examples [9], explicit preference functions [15], human speech [5], or numerical preference vectors [11]. Evaluation is similarly fragmented, spanning task success, user studies [9, 11, 13, 14], and preference-based scoring functions [16, 17], making methods difficult to compare and failure modes hard to diagnose. Second, existing benchmarks typically emphasize high-level navigation or semantic selection over fine-grained manipulation preferences and multi-preference conflicts. The closest preference-based RL benchmark [18] lacks robotic preference-learning datasets and multi- preference evaluation. Other personalization benchmarks focus on object navigation or high-level receptacle selection [19, 20], while recent memory-based manipulation benchmarks [21, 22] do not distinguish task-instance memorization from genuine user-preference-driven personalization. To address these gaps, we introduce a novel Personalized Robotic Manipulation Benchmark (LIBERO-PeRM), built using the popular LIBERO [23] framework. We elevate user preferences to a fundamental building block alongside tasks and layouts. Following the taxonomy of human preferences [24], we define a controlled taxonomy of observable preferences in simulation, covering Motion Preference (trajectory constraints), Skill Preference (task strategies), and User Profile (seman- tic biases). The benchmark is restricted to preferences that can be expressed in language, instantiated without changing the original task goal, evaluated automatically, and reused across tasks. Within this scope, we provide 37 single-preference instances and 18 two-preference combinations. LIBERO-PeRM features an extensible procedural generation pipeline that automatically instantiates tasks and their preference-conditioned variants within shared layouts. To support systematic training and evaluation, the pipeline simultaneously produces explicit preference satisfaction metrics and rich subtask-level metadata, including language instructions, goal images, and physical attributes. For benchmarking, we construct five task suites with 312 preference-conditioned tasks and pipeline- generated, human-reviewed demonstrations, each targeting a core capability in personalized manipu- lation (Figure 1, top).
