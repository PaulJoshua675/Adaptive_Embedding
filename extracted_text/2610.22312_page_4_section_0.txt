3.2 Spatial transition families The eight transition families in Table 1 cover geometry, neighborhood aggregation, connected regions, and movement. Explicit rules specify how each event selects cells and transforms their values. Events may select a region geometrically, as a ball or box, or through the current world’s connectivity, occupancy, and obstacles. These dependencies make an operation’s effect sensitive to the preceding history. Every family extends to all supported dimensions under the shared state representation. Rule Spatial selection State transformation PAINT Cells with a specified source value inside a Man- hattan ball. Simultaneously replace the source value with a target value. REFLECT An axis-aligned box. Apply a bijective reflection along one axis, in- cluding zero-valued cells. STENCIL A Manhattan ball, with reads from adjacent cells beyond the ball. Replace each selected value by a modular sum over its old local neighborhood. MIX Cells reachable within a bounded number of steps through nonzero cells. Apply synchronous neighborhood aggregation while keeping updated cells nonzero. RELABEL The maximal equal-valued connected compo- nent containing a seed. Assign one target value to the entire compo- nent. LAYER A component boundary or the component cells exposed to empty space. Grow the component by one layer or erode its exposed layer. MOVE Entities of one label and the traversed positions on axis-parallel lines. Move entities in a prescribed order until ob- structed or the step limit is reached. Each trajectory uses core events from one family, interleaved with single-cell SET assignments. Full definitions, valid parameter ranges, and edge cases appear in Appendix B. For example, a LAYER growth event fills the empty cells adjacent to a selected component. Let N1(x) = {y ∈X : ∥x −y∥1 = 1} denote the in-bounds axis-neighbors of x. For an occupied seed p, let C = CW (p) be its maximal axis-connected component of value W(p). The component’s external boundary and the region written by a growth event are ∂C = {y ∈X \ C : N1(y) ∩C̸ = ∅}, S+(W, p) = {y ∈∂C : W(y) = 0}. Growth fills these empty boundary cells with W(p); erosion instead clears component cells with an in-bounds empty neighbor. The component and boundary are computed before writing, so each event acts on a single layer. Earlier events can enlarge or split the component, change its boundary, or clear its seed. The same later instruction can therefore affect a different region depending on the preceding history. Read and write regions can differ: STENCIL updates a ball using values from selected cells and their neighbors, including those outside the ball. These updates read the same pre-event state; MOVE instead processes entities front to back, exposing vacated positions to later entities within the event.
