Inference receives images, questions, and declared answer spaces only. Ground-truth values, evaluation masks, and target object counts are used by offline scoring. They do not select crops, tree branches, component thresholds, or output point counts. Original benchmark options and image order are retained, except for SAT’s explicit two-order protocol. Invalid outputs remain in the denominator. Point-Bench’s three recorded image/mask dimension anomalies are retained rather than dropped. There are two important historical measurement distinctions. First, the initial matched-head evaluation used an 8,192-token sequence cap; the extended benchmarks and later matched reruns use 32,768, with up to 1,024 visual tokens per image throughout quality evaluation. The consolidated historical matrix retains each recorded run and its original evaluation budget. Second, earlier Point-Bench summaries used the 982-question micro average. This report consistently computes the five-category macro average from retained category scores. D.2 Local Autoregressive Baseline for the 72K Pilot The unmodified post-trained Qwen3.5-4B checkpoint is evaluated locally with BF16, native Transform- ers (Wolf et al., 2020) generation, PyTorch SDPA (Paszke et al., 2019), greedy decoding, one beam, and thinking disabled. Its limits are 2,048 generated tokens for choice and pointing, 128 for numerical answers, and 32,768 total tokens with at most 1,024 visual tokens per image. Choice answers are parsed as option identifiers, and point predictions use integer coordinates in [0, 1000]. The native model can emit multiple points. Inputs are not silently truncated and incorrect or invalid cases are not retried according to their labels.
