The benchmark examples are represented as two-channel vec- tor fields. Each medium-resolution (MR) input is a 100 × 100 × 2 field paired with a 500 × 500 × 2 high-resolution (HR) ground- truth (GT) field. The SR networks operate on normalized u and v components, while topology and most domain-specific analyses are computed after denormalization on scalar wind-speed magni- tude s = √ u2 +v2. Every method is evaluated against the same benchmark ground truth. For topological analysis, we use a fixed 160 × 160 top-left crop of each 500×500 denormalized speed field (about 10% of its area). This crop is used consistently for persistence-diagram extraction, merge-tree evaluation, and the ground-truth persistence pairs used by fixed-pair supervision. It was introduced for computational tractability, not because the subregion has special physical signifi- cance. Conventional and domain-specific metrics are evaluated on the full reconstructed fields. 3.2 Evaluation benchmark and fine-tuning set The fixed evaluation benchmark constructed for this study contains 168 consecutive hourly fields from the same spatial region. It is used for the pretrained CNN/GAN comparison and for every fine- tuned model, so all reported winner counts and mean metrics are computed on the same 168 fields. Because the benchmark is also used to compare loss configurations (Sec. 6.4), it serves as both the evaluation set and the set on which the final configuration was chosen; there is no separate validation split. For fine-tuning, we build a separate set of 2688 samples using the same spatial region, variable conversion, normalization convention, and MR→HR preprocessing. It consists of sixteen non-overlapping 168-hour windows, four per season, that are temporally disjoint from the evaluation benchmark. Every fine-tuned model reported in this paper is trained on this set. 3.3 Baselines, matched control, and loss configura- tions The pretrained PhIRE CNN and GAN provide fixed baselines. We use the released MR→HR wind models of Stengel et al. [28], whose generator is a fully convolutional SRGAN-derived architecture with 16 residual blocks and skip connections; batch-normalization layers are omitted, and the wind network uses two input and output chan- nels for the horizontal wind components. The CNN baseline is this generator after content-only pretraining with a pixelwise MSE loss; GAN training then continues from the pretrained generator with an additional discriminator and adversarial loss. We use the released checkpoints without retraining them. Every fine-tuned model starts from the pretrained CNN checkpoint and is fine-tuned for three epochs with Adam, learning rate 10−5, and batch size four, on the same 2688-field training set with the same normalization. All 16 configurations fine-tune the native PhIRE (TensorFlow) CNN gen- erator itself; earlier experiments with separate PyTorch residual re- finers were development studies and are excluded from this compar- ison. The standard fine-tuning control optimizes only the original vector reconstruction loss Luv. The final topology-inspired objec- tive and the 14 other loss configurations add auxiliary losses to Luv and are otherwise identical to the control. Differences between any configuration and the control therefore isolate the effect of its aux- iliary losses from that of continued fine-tuning and additional data. 3.4 Reproducibility The source code, experiment scripts, evaluation utilities, and configuration files for this study are available in the tagged release https://github.com/Ardad2/PhIRE/releases/tag/ topoinvis-2026-arxiv-v1.1, together with a reproducibility guide that maps the reported results to their code and data. The repository includes the data-processing path, the fine-tuning imple- mentation for all configurations, and the scripts used to compute the reported fidelity, physics-oriented, distributional, and topological evaluations. The quantitative topology tables and loss-study figures are generated by script from a frozen table of per-field distances (18 methods × 168 fields), which is released with the code and can be used to check them independently. The qualitative Sample 78 visu- alization is generated separately from reconstructed fields and per- sistence diagrams, and the conceptual diagrams are authored with the manuscript source. Retraining the models and re-extracting the topological descriptors from scratch require additional computation and intermediate data that are regenerated by the released scripts. 4 TOPOLOGY-INSPIRED FINE-TUNING 4.1 Vector reconstruction and scalar wind speed PhIRE super-resolves the horizontal wind vector.
