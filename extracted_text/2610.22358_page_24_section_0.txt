Building on the independent and comonotonic completions in Section E.1, we estimate temporal dependence from target-task history while retaining each baseline’s marginal quantile forecasts. Gaussian copula fitting. For each baseline and item, four forecast windows ending before the first test origin supply standardized residuals, which we rank-transform to normal scores. We estimate a lag-one coefficient within these windows, share it across target channels, clip it to [−0.95, 0.95], and fix it before testing. Items with insufficient information use a task-pooled estimate. All eligible items are retained; 27 tasks use shorter calibration horizons without changing their test windows. The fitted coefficient defines a stationary latent AR(1) process used to generate temporally dependent ranks for the baseline’s interpolated marginal quantiles, with constant tails outside probabilities 0.1–0.9.
