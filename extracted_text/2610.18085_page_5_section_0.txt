A restart avoids this problem: If two runs resume from the same numerical state, both runs follow the same trajectory. For the weights, balancing already provides this com- mon state, because the balancing map sends every point of an orbit to the same point (Proposition 1); the map below extends this canonicalization to the moments. In other words, if the weights and moments of both checkpoints are canonicalized before training resumes, the two runs are identical from the first resumed update onward. The restart needs no equivariant optimizer, be- cause canonicalization removes the difference between the two runs before the optimizer sees either run. We now show that no standard first-order optimizer keeps two equivalent runs equiv- alent under a shared learning rate. The obstruction comes from block locality: Standard optimizers update each block using only the gradient history of that block. Theorem 5 (Block-local obstruction to orbit equivari- ance). Fix a pair p and suppose that the increment of Ap has the form ∆Ap,t := −ηtΨt(xA) −ηtωtAp,t, (9) with ηt > 0, ωt ≥0, and Ψt a function of the gradient history of the block Ap alone. If U is orbit-equivariant, then Ψt(c−1x) = cΨt(x), (10) for all c > 0 and all histories x. Consequently Ψt ≡0 whenever Ψt is positively homogeneous of some degree k̸ = −1, or is bounded on a neighborhood of the zero history. The same holds for Bp. By Eq. 10, an equivariant block-local rule must turn gra- dients that are c times smaller into an update that is c times larger, since the block itself is c times larger. Stan- dard optimizers never meet this requirement: When the gradients get smaller, their updates get smaller or stay the same. Gradient descent and heavy-ball momentum have degree 1 and scale their updates with the gradients. Degree-zero rules ignore the gradient scale: AdaGrad, RMSProp, Adam, and AdamW with a zero stabilizer ϵ = 0; the sign-based rules signSGD and Lion; and the zero-stabilizer limit of Shampoo. Adam and AdamW with ϵ > 0 keep their updates bounded as the gradients vanish. None of these optimizers is orbit-equivariant under a shared learning rate. Block locality and the homogeneity or boundedness assump- tion are both needed: A block-local rule of degree −1, or a rule that couples the two blocks of a pair, can be equivariant; Appendix C.7 gives these examples and the precise conditions for each optimizer above.
