Third- generation Spiking Neural Networks (SNNs) (Maass, 1997) add time to the model, and a rate code then costs latency: to decode a value, the network must “wait and count” spikes over an integration window. It also costs energy. Event- driven neuromorphic hardware spends its energy per event rather than per clock cycle, routing every spike as a packet and processing it at each synapse it reaches (Furber et al., 2014; Davidson and Furber, 2021), so a code that spends many spikes on each value undermines both the low latency and the low power that such hardware promises (Davies et al., 2018). Spatial encoding avoids this bottleneck by representing a value as a pattern of simultaneous spikes (Davies et al., 2025). Because neuromorphic hardware delivers informa- tion through discrete, addressable synapses, the value is first converted to a binary code word, and each bit is signalled by the presence or absence of a spike from one source (Auge et al., 2021). The input activity per decision is then fixed by the code width, and the output is delayed only by the depth of the network (Göltz et al., 2021). The conversion to binary, however, introduces a structural vulnerability, the “Hamming cliff” (Caruana and Schaffer, 1988): numerically adjacent values can have very different code words.
