The retain update of Equation (5a) is the exception: it keeps the previous discrepancy δ, while the current discrepancy ∆, which is needed to reverse the correction, remains only in a temporary register. Each retain update therefore stores ∆on the history stack. In the worst case, 35 stack entries (665 qubits) would be needed. Under the DQI input distribution, a second stack entry is required with probability 1.0 × 10−4, so the dis- covered circuit allocates only one stack entry (19 qubits instead of 665) and permits failure on these rare inputs. Together, these transformations make the arith- metically efficient BM algorithm suitable for re- versible computation. REVERSIBLE MODULAR INVERSION Modular inversion is the task of finding x such that wx ≡1 (mod p), given a nonzero input w and a prime p. It is a central arithmetic subroutine in a range of quantum algorithms [3, 14]. A standard way to compute the inverse is through the extended Euclidean algorithm. Euclidean algorithms repeatedly simplify a pair of integers while preserving their greatest common divisor. By tracking how this divisor is expressed in terms of the original inputs, they also recover coefficients α, β satisfying αp + βw = 1, so β is the inverse of w modulo p. Divsteps is a variant of the Euclidean algorithm that replaces division with conditional additions, subtractions, and halving [15]. Starting from f = p and g = w, the goal is to reduce the pair to f = ±1 and g = 0 while preserving their greatest common divisor. The basic strategy is to hold the odd integer f fixed while reducing g: if g is even, it can be halved directly; if g is odd, adding or subtracting f first makes it even. These operations preserve the great- est common divisor because f is odd. Holding f fixed indefinitely, however, would leave only one integer being reduced, so the algorithm must periodically swap their roles.
