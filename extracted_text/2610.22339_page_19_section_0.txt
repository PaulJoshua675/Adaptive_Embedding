C CASE STUDY C.1 MATHEMATICAL RETRIEVAL Dependency references improve retrieval quality. On MathlibQR, semantic search often identi- fies an object’s constructor before identifying the object itself. For the query describing “a fam- ily of morphisms between two functors that commutes with morphism action,” LeanSearch v2 retrieves the constructor NatTrans.mk but does not place CategoryTheory.NatTrans in its top 100. A type-reference edge from the constructor introduces the parent declaration, which LEANGRAPHSEARCH ranks third. The same pattern appears for a query about bases and in- dependent sets satisfying the exchange axioms: Matroid.mk leads to Matroid, ranked sec- ond by LEANGRAPHSEARCH but absent from LeanSearch v2’s top 100. For a description of a category equipped for Quillen-style homotopy theory, ModelCategory.mk’ similarly leads to HomotopicalAlgebra.ModelCategory, which LEANGRAPHSEARCH ranks first. In each case, the semantically recognizable API entry provides a path to the underlying mathematical object. References in declaration bodies also expose a complementary route. For the MathlibQR query expressing a presheafed space as (X, F : Open(X)op →C), a semantically retrieved global- sections restriction functor refers to AlgebraicGeometry.PresheafedSpace in its value. Graph expansion recovers the latter at rank four, whereas LeanSearch v2 does not return it in the top 100. For the query defining a scheme as a locally ringed space locally isomorphic to an affine spectrum, a value reference from AlgebraicGeometry.AffineScheme connects to AlgebraicGeometry.Scheme; the target moves from outside the baseline top 100 to rank eight. Finally, for “morphism between functors,” the implementation of CategoryTheory. Functor.category refers to natural transformations. Following that value reference recovers CategoryTheory.NatTrans at rank 14, again from outside the baseline top 100. These exam- ples show how implementation-level relationships can bring a relevant declaration into the candidate set when its own description is a weak semantic match.
