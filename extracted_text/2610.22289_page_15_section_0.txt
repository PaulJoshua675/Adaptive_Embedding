Reported costs cover retained evaluation blocks, including tutorials and within-run recovery. 7.3 Preventing unintended information access Coding agents can inspect files and execute programs, making unintended information channels relevant to evaluation. Our first article documents such channels in earlier development harnesses, including access to public game identifiers and apparent use of a second local client [8]. The present setup separates the agent from the environment implementation using Docker containers, restricts external connections to an allowlisted model-service proxy, and disables Codex web search. Codex runs with its own sandbox and approval prompts disabled; separation from the task implementation is provided by the surrounding container. Before an independent run, account-local Codex state is cleared apart from authentication and the minimal configuration specifying search and service-tier settings. Concurrent workers used separate local Codex state directories, including workers authenticated through the same subscription. The launcher replaces the private task identifier with a random public alias accepted by the environment server. For ARC-AGI-3, this removes the explicit public game name from the initialization interface as a cue for lookup or retrieval of memorized information. The server permits only one initialization of its configured environment. These measures are engineering controls, not a formal security guarantee. A capable agent may seek other channels or recognize a public task from its observations. Agent-side network restrictions are also distinct from capabilities intentionally exposed by a task sandbox. 7.4 Computational environment and runtime The campaign used two identically configured Linux virtual machines, each with 32 vCPUs re- ported by the guest as AMD EPYC 9454 and 64 GiB RAM, matching the hardware configuration of our earlier study [9]. Docker was version 29.4.3, and all agents used Codex 0.154.0. The reported experiments ran from 21 September to 10 October 2026 using eight subscription-backed Codex accounts; this interval excludes exploratory experiments not reported here. ARC-AGI-3 and AGI Maze used the default service tier, with at most 16 concurrent agents per server across the two benchmarks combined. They had no additional hard wall-clock or token cap; the task limits and the limit on recovery attempts still applied.
