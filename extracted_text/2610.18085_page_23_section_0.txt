D EXPERIMENTAL AND IMPLEMENTATION DETAILS D.1 Models and Training Protocols Architecture. The original small GPT-style experiments use Pre-LN, with normalization before each sub-layer, learned positional embeddings, tied input and output embeddings, bias-free linear projections, and context length 256. Later experiments specify their architecture and context-length changes. The vocabulary size |V| is 50,257, as determined by the GPT-2 byte-pair encoding (BPE) tokenizer. Linear and embedding weights in the GPT-style model use N(0, 0.022); normalization gains retain their default initialization. These GPT-style runs apply no additional 1/ √ 2L factor to residual-output projections. The four original GPT-style configurations range from 22M to 354M parameters. Table 4 lists their widths, depths, head counts, and peak learning rates under the names small, medium, deep, and xlarge. Training. We use AdamW (Loshchilov and Hutter, 2019) with β1 = 0.9, β2 = 0.95, ϵ = 10−8, weight decay 0.1, and a cosine learning rate schedule with linear warmup over the first 2,000 steps and a minimum learning-rate ratio of 0.1. Gradient clipping is applied with max norm 1.0. The default batch size is 64 for small and deep models and 32 for medium models. The xlarge configuration uses batches of 16 with gradient accumulation over 4 micro-batches, giving an effective batch size of 64. Training uses bfloat16 (BF16) mixed precision for efficiency. Datasets. WikiText-103 (Merity et al., 2017) is the primary dataset, with approximately 103M training words; GPT-2 BPE token counts and processed training-token budgets differ. OpenWebText (Gokaslan and Cohen, 2019) is used for multi-dataset validation. OpenWebText contains approximately 8B tokens, and we use a subset for training. SAGGS hyperparameters. Hard SAGGS rebalances all symmetry pairs every 100 steps. Soft SAGGS uses the reported interval and α = 0.5 unless a sweep specifies otherwise. SAGGS+P, used only in some supplementary experiments, adds to SAGGS an auxiliary penalty on the training loss: the mean of [log(∥A∥F+δ)−log(∥B∥F+δ)]2 over the rebalanced pairs, with δ := 10−8, weighted by 0.01 unless a protocol specifies otherwise. The penalty is not part of SAGGS or Soft SAGGS. We rebalance Q–K, V–O, and MLP pairs in ReLU and SwiGLU models. GELU models use only Q–K and V–O pairs, since GELU up–down rescaling is not an exact symmetry. Reparameterization procedure. The exponential reparameterization is applied after standard initialization by multiplying Aℓ←eλℓAℓand Bℓ←e−λℓBℓfor each symmetry pair. For exact pairs, this rescaling preserves the initial forward pass in exact arithmetic across all λ values. GELU MLP rescaling in the approximation diagnostic is excluded from this identity. The mathematical sections index layers from 1 to L; the training code uses 0, . . . , L −1, so its largest applied scale is cL−1 = eλ(L−1). Numerical examples use the code convention. Small and deep models use 30K steps, medium models 25K to 30K steps, and 354M models 15K to 20K steps unless their protocols specify otherwise. The logged gradients in SAGGS+P experiments include the auxiliary penalty; the exact gradient-coordinate law concerns the data loss alone.
