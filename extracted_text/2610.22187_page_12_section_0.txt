A.1 Political Leaning For political leaning, we used the MBIC (Media Bias Annotation Dataset)3 (Spinde et al., 2021). MBIC contains 1,700 sentences sampled from ap- proximately 1,000 U.S. news articles. Ten crowd- workers annotated each sentence for media bias and opinion. The left, center, and right labels indicate the political leaning of the outlet that published the article, based on AllSides and Ad Fontes Me- dia ratings. We used all 1,700 sentences in our analysis. A.2 Sentiment For sentiment, we used the publicly available anno- tated dataset published by VADER (Valence Aware Dictionary and sEntiment Reasoner) 4, a lexicon- and rule-based sentiment analysis tool (Hutto and Gilbert, 2014). Specifically, we used the movie review subset, which includes 10,605 Rotten Toma- toes reviews labeled by 20 independent human raters on a continuous scale from −4 (negative) to 4 (positive). From this dataset, we sampled 5,000 reviews for the test set. A.3 Toxicity For toxicity, we used the dataset from the Jigsaw Unintended Bias in Toxicity Classification com- petition5 (cjadams et al., 2019). The training set of this dataset contains 1,804,874 comments from the Civil Comments platform, with aggregated hu- man toxicity scores ranging from 0 to 1. Because the dataset was designed to measure toxicity in text, it may contain offensive language. Each tox- icity score reflects ratings from multiple human annotators. From this dataset, we sampled 5,000 comments for the test set. B Prompts This section outlines the prompts used for the scor- ing tasks, using political leaning as an example.
