Directing these activities toward a com- mon goal requires orchestration (Zhang et al., 2025c; Ruan et al., 2026), which must reconcile local subtask execution that responds to emerging findings with global task plan- ning that maintains a structured decomposition and tracks dependencies across subtasks. Existing approaches address orchestration through struc- tured workflows or runtime delegation, but each sacrifices one side of this tradeoff. Structured workflows organize tasks into stages connected by explicit control flow, specify- ing when agents act and how they exchange results (Hong et al., 2024; LangChain, 2026). Whether authored manu- ally or generated automatically as in AFlow (Zhang et al., 2025b), these workflows impose clear global structure but fix the decomposition before execution begins, so that find- ings from local execution cannot reshape subsequent plan- ning. Runtime delegation addresses this rigidity by having a central orchestrator determine subtasks and assign agents as execution proceeds (Fourney et al., 2024; Ruan et al., 2026), with agent-team approaches (Kimi Team, 2026a; Apodex Team, 2026) further extending this to parallel subagent dis- patch. However, this design couples task decomposition, subtask dispatch, and result synthesis within a single orches- trator (Ruan et al., 2026; Kimi Team, 2026a; Zhang et al., 2025c), without explicitly modeling subtask hierarchies or precedence dependencies among sibling subtasks. Although dynamic decomposition methods such as ADaPT (Prasad et al., 2024) and ReAcTree (Choi et al., 2026) allow the plan to evolve during execution, they too provide limited support for representing complex dependencies, leaving the tension between adaptive local execution and structured global planning unresolved. We introduce HTN-Orchestrate1, a two-layer orchestration framework that separates these responsibilities through a hierarchical task network (HTN) (Erol et al., 1994).
