Scaling Laws. Kaplan et al. [2020] established power-law scaling of transformer loss with model size, data, and compute; Hoffmann et al. [2022] (Chinchilla) revised the compute-optimal allo- cation toward scaling N and D in roughly equal proportion, using three estimators including the IsoFLOP profiles (their Approach 2) we adopt. Pearce and Song [2024] show that much of the Kaplan–Chinchilla exponent discrepancy is a parameter-counting artifact (non-embedding versus total parameters), a point central to our analysis (Section 4.3). Shen et al. [2024] extend IsoFLOP fitting to linear-complexity, non-softmax sequence models from 70M to 7B parameters, finding scaling broadly similar to transformers; we apply the same methodology to spiking RWKV models. Spiking Language Models. RWKV [Peng et al., 2023] replaces quadratic self-attention with a linear-time recurrence, removing the sequence-length term that complicates transformer FLOP accounting. Zhu et al. [2023] build SpikeGPT on this backbone, binarizing activations into discrete spikes for energy-efficient, event-driven inference on neuromorphic hardware. A separate line spikes large pretrained LLMs post hoc [Xing et al., 2024]. To our knowledge, no prior work characterizes compute-optimal scaling for spiking language models trained from scratch, which we address here. 3 Methods 3.1 Experimental Settings All models are trained with the AdamW optimizer (β1 = 0.9, β2 = 0.999) using a batch size of 16 and a context length of 1024 tokens. Text is tokenized using the EleutherAI/gpt-neox-20b tokenizer [Black et al., 2022], and training data is drawn from the FineWeb-EDU sample-100BT split [Penedo et al., 2024]. Spiking neuron dynamics follow the standard leaky integrate-and-fire (LIF) model [Gerstner and Kistler, 2002, Maass, 1997], with the arctangent (arctan) surrogate gradient [Neftci et al., 2019] used to enable backpropagation through the non-differentiable spiking threshold. The peak learning rate at each width comes from a power law LRopt(d) = k d−p fit to a pilot sweep (Appendix D), with cosine decay to one-tenth, so loss differences across the grid reflect the N/D allocation rather than learning-rate tuning. We estimate training compute as C ≈6ND [Kaplan et al., 2020]; RWKV has no attention term, so matrix multiplies dominate. 3.2 Parameter Counting With a 50,257-token vocabulary the embedding is 11–50% of all parameters, so how N is counted matters. We distinguish the strict non-embedding count (13ld2, Kaplan), the FLOP-matmul count entering C = 6ND (N\E = 13ld2 + vd, retaining the output projection), and the total count (NT = 13ld2 + 2vd), with v the vocabulary size. Following Pearce and Song [2024], total is our primary convention; Section 4.3 reports all three. Inverting a parameter budget to a width d requires solving a cubic (Appendix E). 4 Results 4.1 IsoFLOP profiles Figure 1 shows the validation loss L profiles across the grid; each model is trained single-epoch to the token budget its compute tier and width imply, and the full loss grid is tabulated in Appendix B. Every tier produces the U-shaped profile in log N that the IsoFLOP method assumes, with an interior optimum well inside the sampled widths at all four compute budgets.
