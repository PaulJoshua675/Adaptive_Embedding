Prototype adaptation with fixed kernels Each row of T is a text-derived representative vector, or prototype, for one class. LAMP-F adapts these vectors to the target task using the labeled support images. A prototype update changes both the initial query scores and the support scores used to form the residual target. We account for both effects while keeping the selected visual kernels and mixture weights fixed. The trainable matrix W ∈RC×dg is initialized to T: Γ(W) = norm2(W) −norm2(T), P(W) = T + Γ(W), (11) Here Γ(W) is the change in class directions after row-wise normalization, and P(W) is the adapted prototype matrix. With unit rows in T, P(W) equals norm2(W) in exact arithmetic. Writing the update as a difference also makes Γ(T) = 0, so initialization recovers LAMP exactly. Prototype training uses one mean descriptor per support image, ¯gi = V−1 PV v=1 g(xi,v). This mean is used directly, so its linear class scores equal the average scores across views.
