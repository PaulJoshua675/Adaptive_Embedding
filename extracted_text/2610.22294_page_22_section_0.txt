B Few-Shot Prompting Experiments This appendix documents the experiments of Section 4 and provides additional analyses of demonstration conditioning, example guidance, and length allocation. B.1 Experimental Setup Benchmarks. We study four types of few-shot transformations: classification, list trans- formation, artificial-language transformation, and information extraction. For SST-2 (Socher et al., 2013; Wang et al., 2018), sentiment labels are replaced by two resampled single-token capital-letter codes; the first two demonstrations cover both classes, and answers are graded by exact code match. List Functions–Easy (BIG-bench authors, 2023; Rule, 2020) uses 85 unconditional functions adapted from BIG-bench List Functions; the transformation rule is hidden, and parsed integer lists are matched exactly. SALT repetition (Zheng et al., 2025a,b) uses categories 5–6 with a separate dictionary for each example to translate words and repeat each verb or adjective; generated pairs pass an executable-rule check, and outputs are matched exactly. Movie Director (Liu et al., 2012; Zhao et al., 2021) extracts the Director field from audited MIT Movie queries without naming the field in the instruction; labels are fixed, and outputs are graded by exact string match. Experimental studies. We use three separately sampled studies with frozen models: a single-target demonstration sweep across four benchmarks and four model interfaces (J = 1, K = 64); a List Functions–Easy D × J grid across three DLMs (K = 16); and a cross-benchmark target-count sweep across four benchmarks and three DLMs (D = 4, K = 64). Each K specifies the number of samples per canvas, and the studies are analyzed separately. Prompt families. For single-target prompting, we draw 16 demonstrations followed by one target, then retain the first D ∈{1, 2, 4, 8, 16} demonstrations to construct five canvases with the same target. For multi-target prompting, we draw 16 demonstrations and eight targets. We first randomly interleave four demonstrations and eight targets (12 items), then extend this sequence with the remaining 12 demonstrations (24 items), preserving the relative order of the original items. Each (D, J) canvas retains the first D demonstrations and first J targets in that order. The canvases from one draw form a prompt family; all evaluation examples come from sources disjoint from development. Model interfaces and decoding. LLaDA-1.5 (Zhu et al., 2026) and dQwen3.5-9B-Base (Xue et al., 2026) directly infill masked canvases. Nemotron-Labs-Diffusion-8B (Fu et al., 2026) was trained with limited bidirectional diffusion blocks, so we use a fixed-length causal suffix for the single-target sweep and a causal prefix with a bidirectional tail for both target-count studies, including J = 1. Qwen3-8B (Yang et al., 2025) provides a free-length causal-continuation comparison for single targets only. DLMs reveal one target token at a time in ascending canvas order for both generation and likelihood scoring, using oracle lengths except in Section 4.3. Sampling, scoring, and statistics.
