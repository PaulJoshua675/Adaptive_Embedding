A Dataset construction details The evaluated dataset contains 1,195 single-label Arabic calligraphy images. It was constructed from DuwatBench [Patle et al., 2026] plus real-image supplements from RuFa [Mhmoodlan, 2026] and HICMA [HICMA Project, 2026] used to reduce the original class imbalance. Curation followed a fixed pipeline: aggregate source images, retain single-label six-style items, supplement underrep- resented classes, check image-file integrity, remove exact duplicates and undersized files, then lock the manifest used for all inference runs. The final manifest contains 106 Kufic, 218 Naskh, 216 Thu- luth, 217 Diwani, 225 Ruq’ah, and 213 Nasta’liq images. Table 2 reports the source composition by label. Thuluth and Diwani share the same DuwatBench provenance, so their central confusion in the main results is not a cross-source artifact; other labels should be interpreted with the mixed-source composition in mind. Before model evaluation, the dataset was checked for missing files, corrupted images, orphan images, undersized images, and exact duplicates. One undersized image and four duplicate images were removed. Figure 3 shows representative examples from the final six-style evaluation set.
