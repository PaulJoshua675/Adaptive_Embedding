Discussion The results support four main conclusions about spatial representation in the SNN architecture studied here. First, homeostatic scaling acts in code space rather than semantic space. For a single trained pattern, increasing the gain enlarges the set of code words whose Hamming dis- tance from the target remains within the firing threshold. Equation (13) predicts this Hamming radius from code width and gain alone, and the hardware measurements reproduce the predicted accepted set exactly in 238 of 256 conditions; of the remaining 18, sixteen admit one further Hamming shell where the predicted radius falls just short of an integer and the resolution of the homeostatic search tips it over, and two fall exactly on a shell boundary, where the small asym- metry between rail weights determines which code words fire. What this tolerance means semantically is therefore decided entirely by how the encoding embeds the underlying variable. Second, local continuity and global distance preserva- tion are distinct properties. Gray encoding guarantees a one- bit transition between adjacent values and so removes the Hamming cliff, but its global Hamming distance is only weakly related to semantic separation: 𝜌𝑠= 0.374, barely above Binary’s 0.323. Thermometer and Johnson encode lin- ear and circular distance exactly, and the hybrids retain most of this structure at much smaller widths. This explains why Gray performs well when the trained values form a compact cluster, yet needs progressively more homeostatic margin as the trained set grows, reaching 1.61 times the coherent value, whereas Thermometer, Johnson and the hybrids stay within 21%. Third, the interaction between several learned patterns can be predicted from their code geometry. In the bipolar representation of Eq. (12), agreement between two code words reinforces the accumulated synaptic drive and dis- agreement cancels it, so the additional homeostatic factor required by a trained set follows from its pairwise Hamming distances, with a maximum discrepancy of 0.03 from the measured values (Section 4.3.1). The same mechanism ex- plains the large gain that Binary encoding requires, and why its acceptances follow the bits that values share rather than their proximity: scattered across the range at 256 values, and at 1024 values the aligned block of values sharing the three highest bits of the trained values.
