Decide how the new observation relates to existing facts: - "create": New knowledge not covered by any fact. - "update": Adds new details to an existing fact. MERGE new information with existing. - "reinforce": Confirms without adding new info. - "supersede": Contradicts an existing fact. - "none": Purely procedural, no lasting value. Critical rules for "update": - MUST preserve all details from existing statement. - ADD new information (metrics, timelines, people). - PREFER updating over creating. Almost every observation matching an existing fact should be "update." If in doubt, use "update."
