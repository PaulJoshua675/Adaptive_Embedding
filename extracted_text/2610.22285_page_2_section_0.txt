Using prior work [3], the robot diagnoses from the demonstrations D which features were well-supervised (green), underspecified (red), or irrelevant (gray), and uses this partition o in two ways. (1) The robot shapes its belief P(w | D) (true weights marked by ▲) into an informed prior P(w | o): the robot stays confident about the laptop, doesn’t commit to anything about the human, and assumes the apple doesn’t matter. (2) The robot tells the user what to focus on. Since the robot is only unsure about distance to human, it asks about two trajectories that differ in exactly that, and each answer sharpens P(w | P, o) toward what it still needs to learn. Our key insight is that the same information that tells the robot what it doesn’t know can help it ask better questions. The robot’s diagnosis of what past teaching missed serves two roles. First, we use it to build an informed prior over the human’s reward: a Gaussian that is confident on the well-supervised features, flat on the underspecified ones, and near zero on irrelevant ones. This ensures preference queries are automatically directed at what needs resolving. Second, we use it to supplement each query with an explanation that tells the human which features to focus on when answering, making the robot’s learning process transparent [9]. In Fig. 1, the robot communicates uncertainty about distance to human, and its query presents two options that vary along that feature. Together, these two components align what the robot asks with what the human attends to. Our contributions are: (1) an informed prior for active preference learning that corrects what the teaching data got wrong, automatically targeting queries at the underspecified features; (2) an ex- planation mechanism that directs the human’s attention to those same features when answering, aligning what the robot asks with what the human attends to; and (3) empirical validation in two simulated 7-DoF manipulation domains and a user study, where both components independently improve reward recovery and amplify each other, with the largest gains in the low-query regime. 2
