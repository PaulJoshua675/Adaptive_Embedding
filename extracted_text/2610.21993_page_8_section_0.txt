Pretraining Setup Pretraining data comes from the SSL4EO-S12 v1.1 S1GRD subset (Blumenstiel et al., 2025): 243,968 globally distributed locations, each with four seasonal (VV, VH) backscatter acquisitions at 264×264 pixels in decibel (dB) scale. Rather than using all four acquisitions per location every iteration, we draw one season uniformly at random each time, which gives the model implicit temporal augmentation for free, without needing paired imagery. On top of that we apply per-channel normalization (using the empirically measured statistics µVV=−12.577, σVV=5.179, µVH=−20.265, σVH=5.872), a random resized crop down to 224×224, and random horizontal and vertical flips. Optimization uses AdamW with lr=10−3, weight decay 0.04, and β=[0.9, 0.999]; a global batch size of 256; 60% masking; an L2 reconstruction objective; gradient clipping at 5.0; and FP16 mixed precision, run for 50 epochs (4 of them warmup) under PyTorch 2.9.1 with CUDA 12.6.
