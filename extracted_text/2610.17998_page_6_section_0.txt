Solid and hatched bars indicate TIL and CIL, respectively; error bars show standard deviation over 3 seeds. 4.1 Hyperparameter Search All models are trained using mini-batch SGD [20] with momentum 0.9, batch size 128, weight decay 5×10−4, gradient clipping ℓ2≤1.0, and initial learning rate η ∈{0.1, 0.3}. These parameters were selected by performing a grid search on the BASELINE, varying membrane leak λmem ∈{0.95, 0.99}, learning rate η ∈{0.1, 0.3}, and dropout ∈{on, off} at a fixed memory budget (Mt = 100 samples for CIFAR10, Mt = 30 samples for CIFAR100). Subsequently, we run an ablation to choose sample selection strategy (BASE-EPR vs EPR-SP) and SAM aggregation method (mean vs last, as described in Section 3.1). Figure 1 shows that across all three benchmarks EPR-SP consistently outperforms or ties its BASE-EPR counterpart, confirming that model-validated selection improves the discriminative quality of the replay buffer. Regarding temporal aggregation, mean yields consistently higher or comparable accuracy across all benchmarks. Finally, replay-weight ablations (λr = 0.3, 0.5, 0.7, 1.0) showed that λr = 1.0 per- forms best on CIFAR10, whereas λr = 0.3 provides a better stability–plasticity trade-off on CIFAR100. These values are used in subsequent experiments. There- fore, in all subsequent experiments, we use EPR-SP with mean aggregation as the default configuration, with λr = 1.0 for CIFAR10 (in all scenarios) and CI- FAR100 with tight memory budgets (Mt = 30), and λr = 0.3 for CIFAR100 with larger memory budgets (Mt = 53).
