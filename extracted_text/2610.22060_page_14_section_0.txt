A Tokenizer implementation details This section specifies the final FeaTok tokenizer used in Sec. 3. We follow the notation presented in Sec. 2. We follow BAR (Yu et al., 2026), the previous state-of-the-art method, in our tokenizer and generator training. BAR uses bit representations for its tokens and an autoregressive model with a masked modeling head to predict the bits within each token. Ablation protocols and variants are described in App. C. Which pretrained encoders we use. FeaTok uses SigLIP-L, SigLIP2-SO400M, DINOv2-L with registers, or DINOv3-L. Tab. 6 identifies their pretrained checkpoints. Note that DINOv2-L uses a patch size of 14, whereas the other encoders use a patch size of 16. For DINOv2-L, we resize the image to 224 × 224 so that all encoders encode each image into 16 × 16 patches. We follow BAR and use finite scalar quantization (FSQ) (Mentzer et al., 2024) with 16 2-level slots for tokenizers trained on ImageNet-1k at 256×256. A trainable input projector Pin,θ : RD →Rd maps the adapted backbone features h to d = 16 scalar latents, ui = Pin,θ(E(L)(x)i), where L denotes the final encoder layer and i indexes the N image patches. These latents are quantized coordinatewise to two levels. For coordinate ℓwith output levels a− ℓ< a+ ℓand threshold bℓ, Biℓ= 1[uiℓ≥bℓ], qiℓ= a− ℓ+ (a+ ℓ−a− ℓ)Biℓ. (3) The bit vector Bi ∈{0, 1}d indexes one of 216 patch tokens. We use the straight-through variable qst i = ui + sg(qi−ui), where sg is stop-gradient. The feature decoder reads the straight-through codes through its own input projections, which carry the feature-loss gradient to Pin,θ and the encoder. A separate trainable output projector Pout,θ maps the codes to the pixel-decoder width and belongs to the pixel branch only. Its input is detached, so the two decoders share only the discrete codes. Both projections are learned; only the coordinatewise rounding rule is fixed. Other differentiable quantizers can replace this module without changing the FeaTok framework. Discrete global token. In addition to its N patch features, E emits a global feature. A separate global quantizer Qglobal maps this feature to a 16-bit global code zglobal, which is prepended to the patch codes z1:N. Given the external class label c, the generator models p(zglobal, z1:N | c) and samples zglobal first, so it supplies global context to the patch tokens. The feature decoder reconstructs both global and patch feature targets, so the global code receives direct reconstruction supervision. The patch feature target is the average of representations from four layers, whereas the global target is the last-layer representation. The pixel decoder consumes only the sampled patch tokens, allowing a fair comparison between feature-loss and pixel-loss targets. Architecture and training. The trainable encoder E and the frozen encoder ˆE are initialized from the same pretrained checkpoint (Tab. 6). The feature decoder Dfeat is a ViT matched to the encoder, and the pixel decoder Dpix is the ViT-L decoder of BAR (Yu et al., 2026), shared across all encoders. Tab. 7 lists the architectures and training hyperparameters. All tokenizers are trained on NVIDIA H200 GPUs. Losses. Lfeat sums ℓ1, ℓ2, and cosine distances and averages the patch and global terms. Lreg is the mean squared error between the last-layer features of E and ˆE. Following BAR, Lpix combines pixel, perceptual, Gram, and adversarial losses with an alignment loss that regresses the frozen last-layer features from the third pixel-decoder block through an MLP. All pixel-branch terms act on stop-gradient tokens, so they update only Dpix and the output projector Pout,θ, which no other module uses. The encoder, the input projector, and the feature decoder receive gradients only from Lfeat and Lreg. Because FSQ rounds each coordinate to fixed levels without a learned codebook, it needs no commitment or codebook loss. Tab. 7 gives all loss weights. Tokenizer at 512 × 512.
