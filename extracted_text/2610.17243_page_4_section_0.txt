These analyzers are logically parallel: each receives the normalized document, although event extraction also con- sumes the temporal output to associate a normalized time. Their outputs are combined into a ProcessedDocument. A frequency-based extractive summarizer selects a small number of high-scoring sentences while preserving their original order. Semantic resources are stored outside the processing classes as YAML files. The current resources include the energy ontology, entity gazetteers, event triggers, and English and French sentiment lexicons. This separation enables vocabulary updates without changing orchestra- tion code. 3.4 Layer 4: knowledge organization The knowledge-organization layer operates across pro- cessed documents. First, the social-graph builder creates one undirected edge for each pair of unique canonical entities that co-occurs in a document. Edge weight is the number of documents containing the pair. The result is a compact association graph that can be analyzed or visualized by downstream software. Second, the media interlinker estimates whether two documents discuss the same development. It computes Jaccard similarities over canonical entities (JE), event types (JV ), normalized calendar dates (JT ), and lexical tokens (JL): sim(di, dj) = 0.35JE + 0.25JV + 0.15JT + 0.25JL. (2) An undirected link is created when the score meets the configured alignment threshold. Connected components of this graph become document clusters. This approach is transparent and inexpensive, although its transitive closure can join documents whose pairwise similarity falls below the threshold; this limitation is discussed in Sec- tion 7.2. Finally, information fusion computes a cluster title, an extractive summary of the combined texts, the five most frequent entities, the five most frequent event types, and a confidence score. For multi-document clusters, confidence is the mean pairwise similarity expressed as a percentage. Singleton clusters receive a confidence of 100 by construction; this value indicates structural certainty rather than independent corroboration. 3.5 Layer 5: relational persistence SQLite is used as a self-contained central store. Each returns a structured object containing the question, answer, evi- dence, model identifier, and scope. 4.1 Question-driven Web QA The Web path augments a question with energy terms when necessary, then attempts multiple search providers. Candidate URLs are scraped into normalized documents. Each page must pass the same energy categorization and semantic extraction used during scheduled ingestion. Ac- cepted pages become bounded evidence items containing a title, source, URL, category, score, summary, entities, events, and excerpt. Evidence may optionally be per- sisted, thereby allowing a question-driven discovery to enrich the monitored corpus. 4.2 Database QA The database path retrieves either the full stored corpus or an explicit list of document identifiers. It then applies lexical ranking over the title, summary, and text.
