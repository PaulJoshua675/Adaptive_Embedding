Directed Node Roles Magnetic Spectral Encoding Direction-Dual Structural Attention Direction-Sensitive MoE-FFN Figure 2: The DTA-GT framework (will be updated). 3 Problem Formulation and Model Overview 3.1 Problem Formulation Following established conventions [14–16, 21, 24], let A be the candidate architecture space. Each ar- chitecture a ∈A is represented as an operation-labeled directed acyclic graph (DAG) G = (V, E, τ), where nodes represent computational operations, directed edges encode data-flow dependencies, and τ : V →O assigns an operation type to each node. We adopt the adjacency convention that Au,v = 1 indicates a directed edge u →v. Each architecture has a scalar target attribute y ∈R, such as accuracy or latency. Given a measured subset D = {(ai, yi)}N i=1 sampled from A, we learn a predictor fϑ : A →R to estimate attributes for remaining unmeasured candidates in the same architecture space, without fully training or profiling each candidate. We decompose fϑ into an encoder hϕ and a prediction head pψ: zG = hϕ(G) and ˆy = pψ(zG), with ϑ = {ϕ, ψ}. The challenge is to preserve operation semantics, graph topology, and directed computational semantics across the encoder, rather than allowing directional information to be lost after a single encoding stage. 3.2 Overall Architecture Fig. 2 illustrates DTA-GT, which maps an architecture DAG G to a graph-level representation zG = hϕ(G) under the encoder-wide directional consistency principle. Specifically, the encoder first initializes node states as H(0) = NodeEmbed(G) + DirSpecEnc(G), combining operation/local directed-role features with a global edge-orientation-sensitive spectral prior. It then applies L residual layers [30] alternating direction-dual structural attention and direction-sensitive MoE-FFN updates, using RG and A for relation-aware interaction and predecessor/successor-aware updates. Finally, attention-based readout produces zG = AttnReadout(H(L)), which is passed to pψ for prediction without altering the original architecture DAG. 4 Method 4.1 Direction- and Topology-Aware Node Initialization Before global spectral encoding and attention-based interaction, each node should carry a basic description of its computation and its directed role in the architecture DAG. Operation labels specify the computation at each node, but they do not distinguish nodes with the same operation type that appear in different local structures or input-to-output positions.
