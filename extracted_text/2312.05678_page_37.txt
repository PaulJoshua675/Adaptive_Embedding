Appendix B Estimating sampling plan utility Calculating utility using standard Markov Chain Monte Carlo (MCMC) integration is com- putationally prohibitive for many low-resource contexts. Our efficient method leverages the binary nature of PMS data to produce estimates of plan utility that are computed consider- ably faster than the utility estimates estimated through MCMC integration. Synthesis with importance sampling addresses estimate bias in settings with many nodes and many tests. B.1 MCMC integration for plan utility The utility U(n) defined in Section 3 is the difference between EL  (ˆγ(n), γ  and EL  (ˆγ(0), γ  , i.e., the utility is the difference in expected loss obtained when deploying sampling plan n versus conducting no additional tests. Each member of D(n) is a set of N test results with associated test node- supply node traces. For each set of SFP rates, γ, and new data set, d ∈D(n), the associated loss L ˜γ(dprior, d), γ  is weighted by the likelihood of the new data set given the existing data, p(d|dprior), as well as the likelihood of the SFP rates given the new data and existing data, p(γ|dprior, d). The infimum captures the use of a Bayes estimate, the loss-minimizing SFP-rate estimate under d. Calculation of EL  (ˆγ(n), γ  requires integration over possible d and γ. This integration requires posteriors p(γ|dprior) and p(γ|dprior, d). These posteriors can be challenging to calculate directly: Kleinegesse and Gutmann (2019) noted that Monte Carlo integration is standard for estimating expressions like EL  (ˆγ(n), γ  . The posterior of Wickett et al. (2023) is also computed through MCMC sampling. Our Monte Carlo integration procedure for E  L(ˆγ(n), γ)  is given in Algorithm 2. The expected loss is approximated through three key sets: an MCMC set of SFP-rate vectors drawn from the posterior for the SFP rates under existing data; a set of new data sets simulated using these posterior draws; and an MCMC set of SFP-rate vectors drawn from the posterior for the SFP rates under existing and new data. An SFP-rate draw from the posterior under existing data, p(γ|dprior), is taken as the latent truth. New data, d, are simulated under this latent truth as well as the sampling plan, n. Draws from a posterior under these new data and existing data, p(γ|dprior, d), are used to identify a Bayes estimate and the loss associated with the Bayes estimate. Averaging the loss across latent SFP-rate draws approximates the expected loss. The key algorithm parameters are the size of the sets of SFP-rates, h0, and the number of simulated new data sets, h1. Low values for h0 induce bias: Bayes estimates are identified using an insufficient representation of p(γ|dprior), such that the true expected loss is underestimated. Low values for h1 induce variance: the range of possible data sets is insufficiently explored. Accordingly, both larger PMS budgets and settings with lower levels of initial data require a higher h1 to achieve a desired variance: the range of possible data sets is larger. 37
