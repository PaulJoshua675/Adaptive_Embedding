This separates the query-level retrieval interface from the policy that determines when to invoke it. 3.2 DECLARATION DEPENDENCY GRAPH CONSTRUCTION LEANGRAPHSEARCH constructs a directed graph G = (V, E) from the structural references in Mathlib through static analysis with the jixia tool (frenzymath, 2024). Each node i ∈V repre- sents one declaration together with its formal statement and, when available, its natural-language description. A directed edge i →j indicates that declaration i references declaration j in its type or value. Edges therefore point from declarations to their dependencies, allowing traversal from a query-relevant declaration to the definitions and lemmas underlying its statement or implementation. This graph provides explicit formal dependency structure that complements embedding-based se- mantic similarity. Starting from a semantically relevant declaration, traversal can reveal potentially useful supporting declarations, including dependencies shared by declarations with different sur- face forms. The graph thus augments retrieval with formal structural relationships while leaving the underlying Mathlib corpus unchanged. 3.3 GRAPH-BASED RETRIEVAL Semantic Seed Retrieval. Given a query q, LEANGRAPHSEARCH first retrieves semanti- cally related declarations as seeds for graph propagation using the embedding–reranker retrieval pipeline (Gao et al., 2026). The query is encoded with Qwen3-Embedding-8B (Zhang et al., 2025) to retrieve an initial candidate set. Each query–declaration pair is then scored for relevance using the reranker logits produced by Qwen3-Reranker-8B (Zhang et al., 2025).
