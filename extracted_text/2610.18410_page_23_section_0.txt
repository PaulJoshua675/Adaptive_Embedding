Graph-free Retrieval with Graph-Modified Embeddings Preprint Gauss–Seidel solver. The solver initialises Z with the original embeddings and visits nodes in sorted identifier order. Each update is written immediately, so later nodes in the same sweep use the newest available neighbour vectors. This is Gauss–Seidel iteration, rather than a synchronous Jacobi update based entirely on the previous sweep. It requires no learning rate or gradient clipping, although the objective weights and stopping controls remain configuration choices. For this anchored quadratic, convergence is to the same unique minimiser; finite-sweep results and convergence speed can depend on update order. Sorted identifiers ensure a reproducible order. Stopping rule. During sweep t, the solver records the largest Euclidean displacement over all node updates, δt = max i ∥zafter update i −zbefore update i ∥2. (10) The displacement is measured before overwriting each vector. Convergence is declared when δt < 10−6; the criterion uses the maximum rather than the mean, so every node must satisfy the tolerance. On the reported development graph of 1,811 nodes, convergence took approximately forty sweeps, with a final maximum displacement of 9× 10−7. A safety cap of 200 sweeps returns the current configuration even if convergence has not been reached; the manifest records the sweep count and final displacement so that incomplete convergence remains visible. A separate early-stop setting terminates after a prescribed number of sweeps.
