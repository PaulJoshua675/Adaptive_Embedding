Our previous work, Qwen-UI-Agent, introduced a unified GUI–CLI action space with batched actions, a real-device mobile runtime, and a harness for proactive cross-platform execution (Zhou et al., 2026; 2025). To capture this broader setting, following the system-level perspective of Agents’ Last Exam (Sun et al., 2026), we use the term Generalist Computer-Use Agent (GCUA). We define a GCUA as an agent system that completes diverse computer tasks through visual interaction and programmatic access, choosing how to observe, act, and organize its work as each task requires. Open Computer-Use Infrastructure. Several projects provide open harnesses for computer-use agents. The cua project provides cross-platform desktop drivers and sandbox SDKs (trycua, 2026). The Agent S series provides open orchestration frameworks with memory, visual grounding, and increasingly code-based execution (Agashe et al., 2025a;b; Gonzalez-Pumariega et al., 2026). Open Computer Use provides an MCP-wrapped desktop-control runtime, including macOS control through Accessibility (iFurySt, 2026). These are complementary to our work. Open Generalist CUA is an ongoing project to open a full GCUA research stack that couples a trained model with a real-device harness, a cross-device SDK, and execution trajectories. 7
