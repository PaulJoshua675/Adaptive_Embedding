Paired localization results. At 4B, the pointer probe is trained on the broad-collection traces of 80% of the problems and evaluated on the 2,289 PITs of the remaining problems; the same problem split is used for every seed and both weightings of the failure-type loss. The pointer probe exceeds the length rule in 0 of 10 runs on identical held-out PITs (Table 12). Each comparison is paired on the same PITs, with intervals that resample problems. In a second comparison, on the reference PIT steps of the gold collection, a pointer probe trained without any problem that contributes a gold trace does not exceed the length rule in any of five seeds. The length rule in this comparison is fitted on broad-collection PITs that exclude the gold problems (Table 12). An untrained distance score, the distance of each step’s stored hidden state from the pooled step states of correct traces of the same problem, has an AUROC for the PIT step near 0.5 at every layer tested on 76 PIT traces at 4B (Figure 4, right). At the read site it is below t/(L −1) used as a score (Table 10). The pointer probe and the length rule disagree on about a third of the held-out PITs in every run, about equally in each direction (Table 10). Averaging the pointer probes across seeds, separately for each weighting of the failure-type loss, gives the ensemble. With inverse-frequency weights, the ensemble exceeds the length rule with an interval of the difference that excludes zero; with uniform weights, the interval of the difference contains zero (Table 12). Value probe. We call the probe trained on rollout rates of recoverable traces the value probe; it has the combined probe’s design, restricted to recoverable traces (Appendix B). Its predicted PIT step is the PIT step of Definition 1 computed from its predicted values at the evaluated prefixes in place of the rollout rates. The value probe’s prediction at the last evaluated prefix separates held-out near misses from PITs with an AUROC of 0.91 at both scales (Table 10). The comparison of near misses with PITs was not run for a baseline that uses no hidden states. By Definition 1, a near miss has a rollout rate above θ at its last evaluated prefix and a PIT does not, so the value probe’s training target itself separates the two failure types and this AUROC measures the probe’s fit to that target. The value probe’s per-step mean absolute error exceeds the error from predicting zero in every seed, so rollout supervision does not yield accurate per-step values in this experiment. Localization at 8B. At 8B, where no gold collection exists, the value probe is the only probe tested for localization. In each seed it is scored on the PIT steps of the broad collection for that seed’s held-out problems, on the same PITs as the length rule. The comparison is through the five seed means, without a paired interval, and the value probe is below the length rule in every seed with both input sets (Table 10). Final-label comparison. We compare the value probe with the final-label probe, a transformer encoder over the steps trained on final labels with a causal attention mask, a value output and a confidence output; its predicted PIT step is the step with the largest drop in its value output from the preceding step (Appendix B). The two probes differ in training label, attention mask, output head and step rule, so the comparison changes the label together with these design choices. Each probe is run with five seeds and two input sets, hidden states alone and hidden states with five next-token statistics, on the reference PIT steps. The value probe is trained on broad-collection traces, which include most gold PIT traces, so we evaluate each seed on the reference PIT steps of the problems held out from the value probe’s training. The final-label probe’s training traces are not recorded, so some of these PITs may be among them. On these PIT steps, both probes are below the length rule in every seed with both input sets (Table 12). The value probe’s advantage over the final-label probe has an interval that excludes zero in one of the five seeds with hidden states alone and in none with hidden states with the next-token statistics (Table 10). The value probe therefore gives no consistent improvement over the final-label probe on these PIT steps, and neither probe exceeds the length rule on these PIT steps or in a pooled evaluation over all reference PIT steps (Appendix B).
