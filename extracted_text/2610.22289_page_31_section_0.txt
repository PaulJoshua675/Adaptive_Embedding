Reading a terminal returns screen.txt or history.txt, together with terminal.json describing the terminal and capture. Creating a terminal returns its initial screen and metadata. The initial environment observation additionally includes session.json. Sending terminal input returns input.json, acknowledging input delivery rather than command completion. File retrieval returns the original bytes in file.bin and metadata in file.json. Upload returns transfer.json, acknowledging the source, destination, and copied contents. The workspace-access convention is described in Section 3.2; transfer implementation details are provided in the project documentation. When solving ends, the response contains a terminal flag and message.txt, not verifier scores or test diagnostics. Verification is still run after the solving time limit expires.
