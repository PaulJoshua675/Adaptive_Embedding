Figure 7 shows three selected trajectories on public websites. The Hugging Face task identifies the standard Atria-Dawn-Preview checkpoint and verifies both its configuration and default-reasoning template. The GitHub task starts from repository search, enters the official project, and locates an API-reliability issue reporting intermittent HTTP 422 and 502/503 responses. The PyTorch task verifies the evaluation-time dropout warning for scaled_dot_product_attention and follows the documented API to its pinned v2.14 implementation. The three traces reach the requested evidence in 6, 6, and 4 local decisions, respectively. Median Intern-Decision inference latency is 101.6, 109.8, and 95.3 ms (server-reported inference time, excluding planning, network, and browser execution). These examples are qualitative system demonstrations rather than a browser benchmark. Dynamic pages can occasionally produce delayed or visually unchanged outcomes; the controller therefore re-observes the interface after every action and uses explicit completion checks to avoid unnecessary continuation. This division of labor lets the larger model handle goal decomposition and cross-page reasoning while Intern-Decision handles repeated, structured action selection.
