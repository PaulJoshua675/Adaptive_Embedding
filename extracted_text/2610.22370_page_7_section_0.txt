The final source set is then given by S∗ src = Ssrc ∪Sadd src . Locality-Constrained Routing. The remaining tokens, those not assigned to S∗ src or Scon, form the destination pool D ⊂Stot, into which S∗ src is merged via bipartite soft matching. Because DiTs process tokens as a sequence without inherent spatial inductive bias [43], relying purely on feature similarity can collapse spatially distant tokens and distort local spatial structure. We therefore use spatial adjacency as the matching criterion [9], pairing each source token with its spatially nearest destination and obtaining Smerged = Merge(D, S∗ src). The final output token set is Sout = Smerged ∪Scon, with |Sout| = N −ntgt. By excluding Scon from both pools and restricting merging to local neighborhoods, DaTMe compensates for the weak spatial inductive bias of DiTs and preserves visual fidelity throughout merging. 4 Experiments Implementation Details and Evaluation Metrics. We primarily conduct experiments on PixArt- α [5] using 10k image-prompt pairs sampled from the COCO 2014 validation set [44]. We set the interpolation scale to s = 4, and for grid-based source completion, we use P = 4 grid cells. We evaluate three compression ratios: 0.3, 0.5, and 0.7. Following [9], we apply DaTMe to the middle- range self-attention layers of the DiT [2] backbone. To further evaluate scalability on a larger DiT model, we apply DaTMe to FLUX [22]. We use FLUX.1-dev and additionally apply DaTMe from the middle block to the final block within the joint-attention blocks using the same hyperparameters. More details are in the supplementary materials. For evaluation, we follow prior work [9, 10, 12, 13] and report CLIP-T and FID. In addition, we report HPSv2 [45], which complements CLIP-T by measuring preference-oriented prompt faithfulness and perceptual quality. We also report SSIM, PSNR, and LPIPS to measure image-level fidelity and detail preservation relative to the original output. We further report the Aesthetic score using Aesthetic Predictor V2.5, a SigLIP-based reference-free image aesthetic predictor. All experiments are conducted on a single RTX PRO 6000 Blackwell. 7
