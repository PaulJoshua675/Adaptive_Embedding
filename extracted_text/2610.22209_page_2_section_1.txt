Agent Memory Benchmarks. MemoryAgentBench (Hu, Wang, and McAuley 2026) defines four memory com- petencies (retention, temporal reasoning, knowledge up- dates, and information integration) evaluated through QA interactions. Memora (Uddin et al. 2026) introduces the FAMA metric that penalizes reliance on invalidated mem- ories, decomposing performance into freshness-aware com- ponents. LongMemEval-V2 (Wu et al. 2026) tests long-term memory along five temporal reasoning capabilities. AMA- Bench (Zhao et al. 2026) evaluates long-horizon memory for agentic applications. STATE-Bench (Liu and Yadav 2026) measures whether agents improve at tasks through accu- mulated experience. MEME (Jung et al. 2026) introduces controlled state trajectories with multi-entity evolution, the closest methodology to ours, though still evaluated through the response layer. All these benchmarks share a common structure: pose queries to the agent, grade responses against expected an- swers. None directly inspects the memory store. Memory Architecture Surveys. Recent surveys (Jiang et al. 2026; Du 2026; Luo et al. 2026; Hu et al. 2025; Huang et al. 2026) catalog memory architectures and operations. Du et al. (Du et al. 2025) define six core memory opera- tions (consolidation, updating, indexing, forgetting, retrieval, condensation), decisions that should be evaluated at the op- eration level, not only through downstream responses. The Anatomy of Agentic Memory survey (Jiang et al. 2026) iden- tifies benchmark saturation as a key concern, yet proposes more extrinsic benchmarks as the solution. Conflict Detection Benchmarks. ConflictBank (Su et al. 2024) benchmarks LLM behavior under knowledge conflicts but evaluates at query time, not at the memory consolidation stage. MAGIC (Lee, Lee, and Kim 2025) tests multi-hop conflict detection in retrieval-augmented generation. These address a related but distinct problem: they test whether a model can reason about conflicts in retrieved context, not whether a memory system correctly detects and resolves con- flicts during ingestion. Paradigm Inversion. RIKER (Roig 2025) introduced the concept of generating evaluation corpora from known ground truth for RAG evaluation, avoiding the expense and subjec- tivity of human annotation on real documents. Intrinsic vs. Extrinsic Evaluation. The distinction be- tween intrinsic and extrinsic evaluation is well-established in NLP for embeddings (Baroni, Dinu, and Kruszewski 2014; Schnabel et al. 2015) and parsing. The Future AGI practi- tioner framework (Future AGI 2026) explicitly argues that direct memory store inspection is an anti-pattern. A con- current survey (Toma and Matei 2026) documents this gap systematically across 15 benchmarks, arguing for comple- mentary intrinsic evaluation. We present the first benchmark and empirical results that validate this argument. 3 Benchmark Design: FEB-30 FEB-30 (Fact Evolution Benchmark, 30 trajectories) is orga- nized along diagnostic categories and difficulty levels (Sec- tion 3.4). The name is a deliberate analogy: February 30 is a date that does not exist, the calendar approaches it asymptoti- cally (February 28, sometimes 29) but never reaches 30. Sim- ilarly, recent benchmarks and surveys have moved progres- sively closer to intrinsic evaluation, introducing memory- specific tasks (Hu, Wang, and McAuley 2026), decomposing scores into memory-aware components (Uddin et al. 2026), and defining controlled state trajectories (Jung et al. 2026), yet remain on the extrinsic side of the threshold, never di- rectly inspecting the memory store, as illustrated by (Toma and Matei 2026). FEB-30 crosses it. 3.1 Diagnostic Categories Each category targets a specific gap in extrinsic-only evalu- ation (Table 1): C1 (LLM Compensation) constructs scenarios where memory state is incorrect (e.g., outdated fact not updated, contradictions unresolved) but a strong LLM still produces correct answers by reasoning over retrieved fragments, so a system that never updates its facts scores well extrinsically.
