E Implementation Details This appendix provides the full implementation details of KnowGPO and its baselines, organized into three subsections: tool environment, training configuration, and prompt formats. E.1 Tool Environment The interactive environment exposes a single search action that routes queries to Xhub Search for Chinese queries or Google Search for English queries, with language detected via Unicode char- acter ranges. The engine accepts batch inputs and returns the top-10 results per query, each compris- ing a title, URL, and snippet. To bound the context length consumed by retrieved evidence, snippets are compressed to an average of 300 tokens by a fine-tuned Qwen3-8B summarization model that preserves entities and key claims while removing boilerplate. Temporal sensitivity detection biases retrieval toward recent content for time-sensitive queries. E.2 Training Configuration Supervised fine-tuning. We first SFT Qwen3-8B on a corpus of approximately 8,100 deep search tra- jectories, constructed by combining human demon- strations with model-assisted annotation. SFT runs on 8 A100 GPUs using LLaMAFactory with stan- dard causal language modeling, for 3 epochs at learning rate 2 × 10−5 and effective batch size 64. The resulting checkpoint achieves over 98.5% for- mat accuracy on ReAct-style tool invocations and is the shared initialization for all RL methods we compare. Reinforcement learning. Following SFT, we ap- ply KnowGPO and the three RL baselines. Train- ing data is selected from the same source distri- bution as SFT but filtered to the zone of proxi- mal development, defined as queries with pass@5 ∈[0.4, 0.6] on the SFT checkpoint. This yields 649 high-quality training queries. RL runs on 64 NVIDIA H20 GPUs using verl at learning rate 1 × 10−6, batch size 32 prompts with 16 rollouts each, KL penalty β = 0.01, for 3 training epochs. All RL methods share these settings; they differ only in the advantage estimator and reward design. E.3 Prompt Formats The system prompt defines the available tools and tool-calling format. The user prompt enforces lan- guage consistency and structured answer format- ting.
