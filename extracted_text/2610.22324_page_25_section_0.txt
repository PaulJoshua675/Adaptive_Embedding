Idea Card for AutoResearch: Diagnostic Benchmark for Memory-Augmented LLMs Problem gap [Evidence Gap] The field of memory augmentation for LLMs is growing rapidly, but there is no standardized, systematic way to evaluate whether memory mechanisms actually store semantic information, support effective retrieval, or remain stable across models and tasks, so claims about a mechanism’s quality are largely unverified and the community lacks a shared benchmark for comparison. Core claim A diagnostic benchmark measuring whether memory representations preserve semantic content, support contrastive retrieval, are interpretable, and remain stable across a suite of existing memory mechanisms will reveal which mechanisms genuinely store information and expose a common failure mode shared across many proposed designs, enabling the field to audit and advance itself with measurable evidence rather than untested claims. Method [Empirical Mapping] Construct an open, modular diagnostic benchmark for memory-augmented LLMs, consisting of tasks that probe: • content fidelity: do memory vectors encode task-relevant semantics? • contrastive retrieval quality: does retrieval match ground-truth memory? • interpretability: can the stored content be inspected? • stability: does memory survive parameter perturbation and cross-model transfer? Evaluate leading memory mechanisms (DPR-style dense retrievers, SBERT-style bi-encoders, latent memory, compressed soft-prompt memory, retraining-free long-term memory) on this benchmark and release it as a public tool. Map which mechanisms succeed on which subtasks and quantify the gap between them, turning anecdotal claims into comparable, reproducible evidence. The agent sharpens the claim’s four named properties (content fidelity, contrastive retrieval, interpretability, stability) into metrics, and chooses seven CPU-runnable mechanisms from the families named in the method, plus two null controls.
