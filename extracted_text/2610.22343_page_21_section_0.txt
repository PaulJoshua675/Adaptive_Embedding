Preprint A.5.4 COMPRESSED VGGT STATE BASELINE Architecture. The representation ablation uses an autoencoder of VGGT-Ωpatch features. For each training example, the frozen GFM jointly processes four historical timestamps and one target timestamp, with FRONT, FRONT LEFT, and FRONT RIGHT at each timestamp. We retain the target FRONT features from GFM layers {4, 11, 17, 23}; each layer provides a 26 × 39 grid of 2,048-dimensional patch features. Four independent linear projections reduce each feature vector from 2,048 to 128 dimensions. The projected features are concatenated channel-wise and spatially average-pooled from 26×39 to 16×32, producing a compressed state Z ∈R512×512. To reconstruct the GFM features, the state is bilinearly upsampled to 26 × 39, split into four 128-dimensional groups, and mapped back to four 2,048-dimensional feature grids by independent linear layers. A frozen VGGT-ΩDPT head decodes the reconstructed features into FRONT depth. The compressor has 2.11M trainable parameters. Training. We follow the same two-stage training paradigm as the Scene Tokenizer. The compres- sor is first pretrained for 200k steps on the same 9,496-scene multi-view dataset, after which the best checkpoint is selected and further fine-tuned on Waymo for 50k steps. The training procedure is identical in both stages. For each training sample, we extract the VGGT-Ω features of the target image and compress them into the latent state Z. The compressor then re- constructs the original multi-layer VGGT-Ωfeatures, which are passed through the frozen VGGT-Ω DPT head to obtain the predicted depth. The prediction is supervised directly against the corre- sponding ground-truth depth using Lrep = Llog D + 0.1Lgrad. (27) The VGGT-Ωbackbone and DPT head remain frozen throughout both stages, and gradients are propagated through the DPT head to optimize only the compressor. World denotes the world model autoregressive prediction. Enc. denotes an independent target-time reconstruction from exactly three images. For Enc., a separate historical pass provides the normalization length L0 defined in Eq. 19. For Enc., raw target FRONT GFM depth is calibrated using target-time LiDAR, and the normaliza- tion scale is set to its paired scale times L0. World retains its historical-anchor calibration. Enc. is therefore an observation-based reference with priv- ileged target-time scale information. A.6.2 CAMERA PERTURBATIONS AND COVERAGE Each perturbation combines a 3D translation with an axis–angle rotation. Translation directions and rotation axes are independently sampled uniformly on the unit sphere, while their magnitudes are sampled uniformly within one of three perturbation levels. Small perturbations use translation magnitudes in [0, 0.5] m and rotation magnitudes in [0, 2]◦; Medium uses [0.5, 1.0] m and [2, 5]◦; and Large uses [1.0, 1.5] m and [5, 10]◦. Rotation magnitudes refer to the total axis–angle rotation, and translation magnitudes to Euclidean displacement. For a reference camera-to-world pose P0, the perturbed pose is Pi = P0∆i. Perturbations are expressed in the reference camera’s local coordinates, with +x right, +y down, and +z forward. Using seed 20260804, we initially sample 250 perturbations at each level. For each perturbation, we compute its mean bidirectional coverage across all evaluation windows, timestamps, and both state variants, and retain the 200 perturbations with the highest coverage within each level. This produces a fixed set of 600 perturbations from 750 initial samples. The target-three-view evaluation reuses this fixed subset. 21
