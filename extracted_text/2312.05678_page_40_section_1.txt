A single MCMC set of SFP-rate vectors and a set of of simulated data sets are used. The equivalence of (11) means that incorporating the likelihood of each SFP rate with respect to each simulated data set is sufficient for approximating the expected loss: no further MCMC sampling is needed. A key matrix for this algorithm, D, stores these likelihoods: each row corresponds to an SFP-rate vector and each column corresponds to a simulated data set. A Bayes estimate is derived for each simulated data set through a weighting of the loss corresponding to each SFP-rate vector by the binomial likelihoods in D. The set of weighted losses for each simulated data set are averaged to yield the expected loss.
