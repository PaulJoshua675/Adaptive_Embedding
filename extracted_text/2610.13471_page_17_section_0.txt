For each (dimension, function, run) the initial population is drawn uniform-randomly over [l,u] from the official CEC2022 Rand_Seeds list with the prescribed Mersenne-Twister gen- erator, and the identical population is supplied to every optimizer, so all comparisons are matched. Every objective call is counted identically across optimizers. A complete T-generation run with population N costs N(T + 1) evaluations including initialization. For a requested budget B, TB = ⌈(B−N)/N⌉sets the maximum generation count, and the final generation is truncated when necessary so that exactly B objective calls are consumed. In a truncated final generation the trial rows are evaluated in implementation order, and REMBGO does not reshuffle the copied elite rows before truncation. Per-function differences are formed per seed as d = fEMBGO −fREMBGO; exact zero differences are dropped following Wilcoxon’s rule and the effective sample size reduced accordingly; tied absolute differences receive average ranks; the test is the two-sided exact signed-rank test; the direction is taken from the signed-rank statistic; and Holm correction is applied across the twelve functions, one family per budget. Seeds are never pooled across functions. Component-removal statistical conventions. The component-removal study reported in the main paper is run at the exact 1040-evaluation budget on the same matched CEC2022 records, separately for D=10 and D=20. Eleven configurations are compared: the full REMBGO configuration and its ten implementation-level mechanism-removal variants. Each of the twelve CEC2022 functions is a statistical block; within a block the per-configuration observation is the median terminal error over the thirty matched runs. The mean rank reported for a removal is obtained by ranking the eleven configurations on each function by this median error and averaging the rank across the twelve functions, so the full REMBGO configuration also carries a rank and a removal that improves on it scores a lower rank. The displayed median ∆log10 is the median over the twelve functions of log10(removal median error)−log10(full-REMBGO median error), so a positive value means the removal degrades performance. Two Wilcoxon signed-rank families are distinguished. An exploratory per-function family applies the two-sided exact signed-rank test to the thirty matched pairs of each function, with Holm correction across the twelve functions for each removal. The suite-level family— the “Holm p” reported in Table 3 and the basis for the statement that no removal is significant after the suite-level Holm correction—applies the exact signed-rank test across the twelve per-function log10 medians for each full-versus- removal contrast and then Holm-corrects across the ten planned removal contrasts, separately for each dimension.
