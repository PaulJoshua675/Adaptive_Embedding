Action–observation environment. We implement multimodal search as a multi-turn action– observation process. At turn t, the policy receives the original question and image together with the complete interaction history. It then emits a reasoning block followed by either one structured tool call or a final response. A tool call is represented as a JSON object enclosed by <tool call> tags, and the corresponding result is appended to the trajectory inside <observation> tags. This creates an explicit sequence of policy actions and environment observations that can be processed consistently during data collection, SFT, on-policy distillation, and inference. Each newly generated image is assigned a stable identifier (img 1, img 2, ...). Subsequent tools can therefore operate on a crop, rectified view, or enhanced version without serializing the image into the textual context. The policy may execute at most one tool per turn and up to 20 interaction turns per trajectory. Model-generated reasoning, tool-call, and final-response tokens receive opti- mization masks. System instructions, user content, images, and tool observations remain visible as conditioning context but are excluded from the actor loss. Search and retrieval stack. The textual retrieval tool first submits the query to the Serper Search API and obtains the top organic results, with five results used by default. For each result, the pipeline retains its title, URL, and search snippet and uses Jina Reader to extract page-level content. The recovered passages are then compressed by a query-conditioned Qwen3-32B summarizer exposed through an OpenAI-compatible endpoint. The resulting observation preserves the source URL and the evidence relevant to the current information need while removing unrelated webpage content. This retrieval pipeline allows the agent to refine its query over multiple turns without repeatedly inserting entire webpages into the context. The language parameter is passed to Serper, enabling multilingual queries and cross-lingual retrieval through the same interface. Search observations include the result title, source URL, and a focused evidence summary, which allows later turns to verify, refine, or combine information from multiple sources. The image-retrieval tool uses the Serper Lens endpoint. It accepts either the original image or an intermediate image identifier, performs a reverse visual lookup, and returns candidate entities and visually related pages. This is particularly useful when an object, artwork, landmark, product, or document must first be identified before a factual text query can be formed. The agent prompt in- structs the policy to follow visual identification with text search whenever the requested answer depends on an externally verifiable fact.
