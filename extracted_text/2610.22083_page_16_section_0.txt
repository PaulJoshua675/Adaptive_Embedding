Their 8-bit code space admits only a few distinct radii, so tolerance is quantised into shells of 1, 9, 37 and 93 code words: the network accepts nothing beyond the target up to ×1.25, and then nine values at once. Under Binary those nine are scattered across seven disjoint runs and reach 128 semantic units from the target, and at ×8 the 93 accepted values form 35 runs; under Gray the nine reach 225 units away. Raising the factor for these encodings admits more values, but not nearer ones. The hybrids lie between the two. Their accepted sets grow smoothly with tolerance, as the unary codes do, but are broken into disjoint runs – at most four at 𝐵= 4 and eight at 𝐵= 8. The count rises to that bound and stays there, unlike Binary’s, which keeps growing, and it follows from the fine field: within a block the Gray code carries no global ordering, so the set of accepted code words crosses block boundaries unevenly. Combining the tolerance law of Eq. (13) with the block structure of Section 3.5 gives a scaling relation. The seman- tic radius detected by a hybrid encoding is the product of its block size and its Hamming tolerance, 𝑟= 𝐵ℎ(𝑚), which holds in all sixty conditions where the accepted set extends beyond the trained value. Substituting the code widths of Eq. (10) and neglecting the log2 𝐵term gives 𝑟≈𝑁 2 (1 − 1∕𝑚) for the linear family and 𝑟≈ 𝑁 4 (1 −1∕𝑚) for the cyclic one, in which the block size cancels. The detected neighbourhood therefore depends only on the value range, the gain and the topology, and not on the width of the code used to represent it: at ×8 tolerance the furthest value accepted by Thermometer and by the linear hybrids at 𝐵= 4 and 𝐵= 8 lies 111, 112 and 112 units from the target, while the three codes occupy 255, 65 and 34 bits respectively. Narrowing the code therefore leaves the size of the detected neighbourhood unchanged, though, as noted above, it does cost its contiguity. 4.4.3. Topology At the range ends the linear and cyclic families separate cleanly (Table 14). Johnson and the cyclic hybrids accept values reached only by passing the end of the range: at target 255 with ×2 tolerance, Johnson accepts 223 to 255 and 0 to 31, a symmetric interval of 32 values on either side of the target. Thermometer and the linear hybrids never do so, at any target or tolerance, and at the interior target 128 none of the structured encodings does, as expected when the range ends lie beyond reach. The topology of each code, established analytically in Section 2.4, is therefore reproduced in the behaviour of the trained network. 4.5. Extending the Range to 1024 Values At 𝑁 = 1024, Thermometer would need 1023 bits and Johnson 512. Under the default configuration of Sec- tion 3.4 neither fits on SpiNNaker, and both would be silently truncated; Johnson would just fit within SpiNNaker2’s limit of 512 input events. The buffer could be enlarged to ac- commodate them, but each decision would then occupy 1023 or 512 buffer entries and deliver as many packets. The hybrids fit within the default: 130 and 67 bits for the linear variant at 𝐵= 8 and 16, and 67 and 36 bits for the cyclic. The comparison at this range is therefore with Binary and Gray, the only established codes that also fit the default, repeating the protocol of ection 4.3 around the value 960 (11110000002, the 10-bit analogue of 240).
