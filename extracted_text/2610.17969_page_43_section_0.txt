Weights use symmetric per-output-channel absmax scaling at 8 or 4 bits, applied to every linear layer except the tied logit head. For nGPT, whose forward pass normalizes weight rows, quantization applies to the effective normalized weights that a deployment would store. W8A8 activations use symmetric per-tensor int8 at every linear input. The dynamic variant recomputes the absmax per call, while the static variant fixes per-call-site scales from absmax calibration over 8 held-out training batches. Residual-stream quantization maps h to int8 at every block input using dynamic per-tensor absmax, calibrated per-layer static absmax, or per-token absmax scales. We intercept calls at the torch-function level to treat functional and module linear calls identically across architectures. Migration variants. Automated fp32 tests check the numerical idempotency of C. The maximum coordinate error is below 10−5, and the maximum deviation of the mean square from 1 is below 10−4. The tests verify GCT block invariance under h →ch with relative error below 10−4. The same tests also verify full-network invariance at the embedding output for c = 102 and in the middle of the stream for c = 10−2, with maximum logit error below 10−3. UCT block equivariance under the tested up-scaling c = 102 has relative error below 10−3. Attention logit variance at GCT initialization remains between 0.5 and 2.0. The NDA-typed PINN objective is numerically invariant at initialization, with relative spread below 10−3 for κ ∈{10−2, 1, 102}.
