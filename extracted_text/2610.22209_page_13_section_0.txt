H Robustness Across Systems: Configuration Comparison Table 12 reports headline statistics for the four configurations discussed in Finding 5 of the main paper. All values are averaged across N=11 runs. The four configurations are: • Simpler sys.: a simpler configuration of the memory sys- tem, on the pre-release corpus. • Main sys.: the main system configuration, on the same pre-release corpus (differs from Simpler sys. only in the system). • Main (released): the main system configuration, on the publicly released corpus used for all other results in this paper (differs from Main sys. only in the corpus). • Upgraded backbone: the main system configuration with a newer-generation frontier model as the backbone, re- placing the one used in all other configurations, on the publicly released corpus. The intrinsic–extrinsic divergence holds across all four: posi- tive signed divergence, near-chance pass/fail agreement, and MAD and DivRate in a narrow range, indicating the finding is not an artifact of a single system implementation, corpus version, or backbone model. Beyond these aggregate statistics, the paper’s category- level findings are also preserved under the upgraded back- bone. Comparing per-category metrics between the main configuration and the upgraded backbone, the category rank- ings are highly stable: Spearman rank correlation across the six categories is ρ = 0.94 for MAD, ρ = 0.89 for intrin- sic accuracy, and ρ = 0.94 for classification accuracy. The named extremes the paper relies on are unchanged: C1 (LLM Compensation) has the highest MAD and the highest classi- fication accuracy, C6 (Multi-Author) has the lowest intrinsic accuracy, and C5 (Temporal) has the lowest classification ac- curacy, in both configurations. The only differences are adja- cent swaps among already-close values, never a reordering of these extremes, indicating the diagnostic category structure is not an artifact of a particular backbone model. I Per-Trajectory Results Table 13 shows individual trajectory scores averaged across N=11 runs. Intr. = fact accuracy (Eq. 2 in the main paper): mean claim coverage across all states of the trajectory. Across runs, intrinsic accuracy ranges from 56.9% to 63.3% (std = 1.6%) and extrinsic from 45.0% to 55.0% (std = 2.9%), con- firming high reproducibility despite LLM non-determinism. Intrinsic scoring is more stable than extrinsic because it eval- uates the persistent store directly rather than depending on retrieval + generation.
