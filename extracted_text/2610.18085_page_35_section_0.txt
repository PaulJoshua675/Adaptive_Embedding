We again use the 31M modern RMSNorm, RoPE, SwiGLU, and GQA T5 SentencePiece WikiText-103 setting of the state-preserved and stale-state diagnostics. For each of the seven paired seeds, one 5K-step phase-1 checkpoint is cloned into five 2.5K-step branches: control state, surgery covariant, surgery all-stale, surgery deep-stale, and surgery deep-stale + Soft SAGGS. All surgery branches receive the exact λ = 0.2 all-pairs orbit edit. The covariant branch maps every AdamW first and second moment into the new coordinates. The all-stale branch leaves every moment in the old coordinates. The deep-stale branch maps only the shallow half of layers and leaves layers 6 through 11 stale, mimicking a partially missing optimizer-state shard. The Soft branch starts from this same partial-state condition and uses Soft SAGGS at handoff and every 50 steps. Table 14 reports the seven-seed summaries. The partial-state condition changes subsequent training despite preserving the current function: The immediate handoff validation-loss change, including the initial Soft rebalance where used, is below 6.2 × 10−5, but the deep-stale branch is +0.056 ± 0.007 PPL worse than the state-preserved control over seven paired seeds, with p+ sf = 0.0078. This partial-state penalty is essentially the same penalty as leaving all moments stale, +0.056 ± 0.008 PPL. Leaving the additional shallow-half moments stale changes mean PPL by only 0.00027; this difference measures the incremental cost of stale moments, not the entire surgery penalty. Relative to the fully covariant branch, the deep-stale condition is still +0.003 ± 0.002 PPL worse, so the partial shard mismatch is measurable but much smaller than the orbit edit itself under the practical protocol. Soft SAGGS again removes the penalty. The deep-stale-minus-Soft contrast is +0.062 ± 0.008 PPL, with all seven paired seeds in the same direction, and Soft is −0.005 ± 0.002 PPL relative to the control. Together with the reset and stale-state comparisons, these results show that periodic rebalancing recovers control-level PPL across the tested optimizer-state conditions.
