Our method does not satisfy this axiom. A feature absent from F but causally upstream of a feature that does appear can receive a non-zero indirect attribution: in the two-feature example in the right panel of Figure 2, if F1 depends only on x2 and x2 depends on x1, then x1 receives the non-zero indirect term of Equation 2 even though F1 never reads x1 directly. This is a deliberate design choice — capturing such upstream influence is precisely the goal of incorporating causal dependencies — and the same behavior is exhibited by other dependency-aware methods such as conditional SHAP [Aas et al., 2021] and causal Shapley values [Heskes et al., 2020]. D Computational complexity analysis We give a theoretical, not just empirical, complexity comparison against causal Shapley values [Heskes et al., 2020] and conditional SHAP [Aas et al., 2021]. Let d be the number of input features, C the number of output classes attributed (typically 1), K the number of Riemann integration steps, M the number of SHAP permutations, and E the number of edges in the causal graph. With a dense causal graph, computing this Jacobian via autograd needs one backward pass per output feature — d passes total, each itself O(d) — giving O(d2): this is the generic cost of any dense d →d Jacobian, not specific to our method. With a sparse causal graph (low mean degree), our sparse masked surrogate’s Jacobian is computed analytically via the chain rule, evaluating derivatives only for active edges — touching only the O(d) entries that actually exist, and skipping this d-fold blow-up entirely. Our synthetic scaling experiments (right panel of Figure 3) in fact compute the full (dense) Jacobian rather than the closed-form sparse one, which is why the measured runtimes there follow the O(d2) line above rather than the O(d) sparse case. Our real graphs support the sparse regime: the OmniPath-derived network (6,941 genes) has mean degree 3.38, and the Dyngen GRN (2,300–2,500 genes) has mean degree 3.07, both low and, notably, not growing with graph size, though both also contain a small number of high-degree hub genes (up to several hundred children each), consistent with the heavy-tailed degree distributions typical of real regulatory networks; what the O(d) argument needs is the low mean, not a uniform cap on every node. Second-order indirect effects. The optional second-order extension (Appendix A), which attributes effects mediated through two successive surrogate applications rather than one, applies the same Jacobian-and-contraction step a second time and so does not change CIG’s complexity class in Table D.1 — only its constant, roughly 2× the first-order-only cost. Causal Shapley values and conditional SHAP, as commonly implemented via permutation sampling, are quadratic and cubic in d, respectively (conditional SHAP pays an extra factor of d for Gaussian conditioning per sample). The exact Shapley value is exponential, O(2d), regardless of sparsity. So CIG’s polynomial cost is exact (up to ordinary path discretization) and improves with sparsity, while the Shapley baselines’ polynomial cost is already a sampling approximation of an otherwise exponential quantity.
