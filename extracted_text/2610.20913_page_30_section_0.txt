TransX: Technical Report 6.2 Scaling Returns and Compute Allocation Behavioral Encoder Scaling at Fixed Memory Resolution. Figure 7B isolates encoder scaling while holding behavior memory resolution and candidate-conditioned fusion fixed. Across the evaluated history-support regimes and memory resolutions, increasing encoder compute improves held-out quality, with the largest gains occurring in the lower-to-middle portion of the sweep and substantially smaller returns beyond approximately four layers. Because these gains occur at fixed 𝐵𝑀and 𝜌, they cannot be attributed simply to exposing more behavioral state to online prediction. The result shows that additional behavioral computation can improve the predictive utility of a fixed- resolution interface. A stronger encoder may preserve more response-relevant information through memory construction, organize the retained information into a representation that is easier for the downstream predictor to exploit, or both. The observed saturation is also operationally important: encoder capacity affects training, bulk construction, incremental maintenance, and continuation state, so behavioral compute should be treated as one resource in a broader allocation problem rather than as the sole scaling axis. Supervision Changes the Return to Candidate-Conditioned Compute. Figure 7C shows that the return to candidate-conditioned fusion increases with response supervision. Fusion width provides sustained gains over the evaluated compute range, whereas additional cross attention depth saturates earlier. Note this does not imply that repeated memory reads are redundant, only that width is the more effective allocation over the measured configurations. Because training is end to end, increased supervision also benefits the encoder and memory construction. The results above should be interpreted as the relative return to where additional capacity is placed. Figure 7D–F makes this shift explicit.
