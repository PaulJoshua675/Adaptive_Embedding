Table 8 compares different gate configurations for Qwen3.5-35B- A3B. Runtime-only escalation achieves higher success than initial-only escalation, at higher cost, indicating that runtime monitoring provides the stronger escalation signal. The complete framework attains the best overall performance, but it also enables Shadow oversight. Its counterpart without Shadow is the Escalation configuration in Table 4 (67.94% at $0.4050), which falls below runtime-only escalation, so this ablation does not show a benefit from adding the initial gate to the runtime gate in this setting. B.4. Inference Cost Runtime uncertainty scoring reuses hidden states from the weak agent’s action generation and therefore requires no additional model call. Initial and Shadow probes require lightweight-model inference, while interventions may incur additional strong-model computation. All such costs are already included in the total workflow cost reported in Table 1. C. Figure 8–10 present three representative examples of runtime escalation. Across all three cases, the weak agent remains on an unproductive GUI-based trajectory before the runtime gate triggers handoff. After takeover, the strong agent changes the execution strategy rather than simply continuing the weak agent’s actions (Song et al., 2026). In the first case, the weak agent repeatedly interacts with an unresponsive macro interface while attempting to standardize text-box fonts.
