CTPO and DHPO use token-level (or token/response-hybrid) objectives, while GSPO and GSPO-token use one response-level ratio. None of these objectives replaces token-count weights by normalized weights over labeled GUI/code action steps within a multi-action training sample. Notation. Let i denote a training sample. Training sample i contains Ki action steps. We denote by ai,k the set of assistant-token positions that contribute to the loss for action step k, and by |ai,k| its cardinality. Thus, ai,k may include reasoning tokens, tool-format wrapper tokens, and action- content tokens. Let mi,t ∈{0, 1} indicate whether token position t contributes to the loss. For each loss-participating assistant token, define the token-level importance weight and its logarithm as wi,t(θ) = πθ(yi,t | hi,t) πold(yi,t | hi,t), δi,t = log wi,t(θ) = log πθ(yi,t | hi,t) −log πold(yi,t | hi,t). Here, yi,t is the sampled token and hi,t is its preceding causal context. The total number of valid assistant tokens in sample i is Ni = X t mi,t = Ki X k=1 |ai,k|. For each action step, we define the mean token-level log-importance weight as ¯δi,k = 1 |ai,k| X t∈ai,k δi,t. Let τi,k denote the action type of step k, e.g., τi,k ∈{GUI, code}. We assign each action type a nonnegative balancing coefficient ατi,k. At least one action type in each sample must have a positive coefficient so that the normalizer below is nonzero. E.1 GSPO The standard GSPO sample-level importance ratio for sample i is wGSPO i (θ) = exp 1 Ni X t mi,tδi,t ! . Grouping the loss-participating tokens by action step gives log wGSPO i (θ) = Ki X k=1 |ai,k| Ni ¯δi,k. Therefore, in standard GSPO, the implicit weight of action step k in the sample-level log-ratio is ωGSPO i,k = |ai,k| P j |ai,j|. This weight is determined by token count rather than by action semantics. If a sample contains two short GUI actions and one long code action, the code action can dominate log wGSPO i (θ) simply because it has more valid assistant tokens. The same ratio is then used for all tokens in the sample, so the long action also has disproportionate influence over whether the whole sample is clipped.
