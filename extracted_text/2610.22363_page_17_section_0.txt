Preprint D.2 PREDICT RGB AND HAND-REGION METRICS For full-frame and hand-region CLIP-I (Radford et al., 2021), we compute paired image-feature cosine similarity using OpenAI ViT-B/32 with its standard bicubic short-edge resize to 224, center crop, and normalization. FVD (Unterthiner et al., 2018) uses the StyleGAN-V (Skorokhodov et al., 2022) Kinetics-400 I3D TorchScript model’s 400-dimensional pre-softmax features, bilinear resizing to 224 × 224, pixel scaling to [−1, 1], and one feature vector per video. We use unbiased empirical covariances and an exact low-rank Fréchet-distance calculation. Hand-region metrics use WiLoR detections with confidence threshold 0.3 and NMS IoU threshold 0.7. We expand ground-truth boxes by 1.5×, clip them to the image boundary, and apply the same crop to the reference and prediction. Crop PSNR, SSIM (Wang et al., 2004), and VGG-LPIPS (Zhang et al., 2018) are measured at the native crop resolution, with small boundary crops padded for LPIPS. For IoU, we match unexpanded boxes by maximum total IoU within handedness classes. We divide the matched IoU sum by the larger detection count, so unmatched detections contribute zero. Frames with no detections on either side are omitted; one-sided detections receive zero. Crop metrics average hands within a frame, valid frames within a window, and then windows within a dataset/method. Crop metrics use frames with a valid GT hand detection. FVD is computed separately for each dataset/method. The Macro block reports the arithmetic mean of the four dataset-level scores for each method and metric, using unrounded values and equal dataset weights. D.3 PERCEIVE TARGETS AND METRICS Following ViDiHand (Wang et al., 2026a), we report presence-aware MPJPE-p in camera-space, root- relative, and Procrustes-aligned coordinates. A reference hand is eligible when at least one annotated joint lies inside the image at camera depth greater than 0.01 m. This is also the positive GT definition for hand visibility. Joint errors use the valid annotated joints of each eligible hand; RR requires a valid wrist, and PA additionally requires at least three joints and a nondegenerate prediction. Association and missing-hand penalties. Our model emits a hand prediction when its maximum joint-visibility probability is at least 0.5; HaMeR and Dyn-HaMR use their released hand detections. All methods are matched to reference hands of the same side by descending mesh-box IoU, using a 1.1× enlarged reference box and an IoU threshold of 0.1. An eligible hand without a match receives a canonical MANO hand in the penalized metrics. Its camera-space and RR penalties are the corresponding canonical-hand errors; its PA penalty uses the canonical RR error without Procrustes fitting. The same matching and missing-hand penalties apply to all three methods. Ordinary errors for each method use its own successfully matched eligible hands, rather than a common intersection across methods. For EgoDex-MANO, we fit MANO to the annotated 3D joints of each hand, optimizing global orientation, finger articulation, and shape with pose and shape regularization. The annotated wrist anchors the hand position. We reconstruct the fitted MANO21 joints in camera coordinates and use them as the common evaluation targets for all methods. ARCTIC, HOT3D, and EgoLive use their provided 3D hand annotations. We average windows within each dataset and then average the four datasets equally. HaMeR camera recovery. For HaMeR, we recover camera-space translation using known dataset intrinsics. Native predictions follow the official demo’s crop-to-full conversion with image-scaled focal length 5000 max(W, H)/256 (16562.5 pixels for our 848 × 480 inputs). For each detected hand in each frame, let qj be its predicted wrist-relative 3D joints and uj its native full-image 2D projections. We fit t by minimizing P j ∥πK(qj + t) −uj∥2 2 using the dataset intrinsic matrix K, including both focal lengths and the principal point, transformed to the evaluation image. Rotation, articulation, shape, and metric scale remain fixed; fitting uses only HaMeR’s own 2D predictions, with reference joints used only for scoring. We retain the native 2D detections, mesh-overlap assignments, and missed-hand penalties, so RR, PA, and visibility scores are unchanged. EgoLive’s provided 2D and 3D annotations retain a median 1.62-pixel reprojection residual under the released intrinsics; we use those intrinsics without fitting them to the reference annotations. 17
