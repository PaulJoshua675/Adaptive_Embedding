The 8-bit range is used for most of our experiments, as the widest at which every encoding compared here fits within the default input limit of first-generation SpiNNaker (Section 3.4). In earlier work (Davies et al., 2025), we showed that an SNN trained with supervised STDP classifies a single spatial pattern accurately, but that its performance degrades when it is trained on several. Large Hamming distances between the trained patterns create “don’t care” synapses, which receive conflicting evidence from different patterns and so contribute nothing to the output; the network must then rely on stronger homeostatic scaling, which sharply increases false positives. Standard binary encoding therefore prevents the network from recognising contiguous ranges of values. This matters wherever the inputs are continuous or ordinal. In network-traffic classification, for instance, packet sizes, flow durations and inter-arrival times carry meaning in their proximity: two flows of similar duration are similar events, and an encoding that maps them to distant spatial patterns discards that information before the network sees it. Other features are cyclic: time of day is the clearest case, where 23:59 and 00:00 are adjacent, and such features need an encoding whose topology reflects that. This paper examines spatial encodings that restructure the signal before it reaches the network, while keeping one spike per bit. The established alternatives are not equivalent: Gray encoding removes the cliff but preserves little global distance structure, whereas Thermometer and Johnson en- codings preserve it at the cost of a code width that grows linearly with the value range. We introduce a family of hybrid encodings, which combine a coarse magnitude code with a Gray code for fine position; the family contains all three as limiting cases of a single parameter and trades code width against preservation of semantic distance at a favourable rate. On hardware, the homeostatic factor sets a radius of tolerance in code space around each trained code word, so the encoding alone decides which values the net- work treats as similar. The same analysis explains the degra- dation observed in our earlier work (Davies et al., 2025): the summed weights of trained code words cancel wherever they disagree, and the homeostatic gain that compensates is what admits the false positives. Because a spatial code delivers all its bits at once, its width is also bounded by the number of simultaneous input events a neuron can receive: about 255 under the default configuration of first-generation SpiNNaker, and 512 on SpiNNaker2 (Mayr et al., 2019; Gonzalez et al., 2024). The hybrid construction reduces code width by an order of magnitude. To our knowledge, this is the first systematic characterisation of how the choice of spatial code governs the homeostatic scaling, and hence the tolerance and false-positive behaviour, of supervised STDP learning on neuromorphic hardware. The main contributions of this work are: • an account of how the geometry of a spatial code sets the homeostatic tolerance of a supervised STDP network (Sections 4.3.1 and 4.4); • a hybrid coarse–fine encoding family with Ther- mometer, Johnson and Gray as limiting cases (Sec- tion 3.5); • evidence that removing the Hamming cliff is neces- sary but not sufficient for semantic clustering (Sec- tions 4.1 and 4.3); • a characterisation of the per-neuron input limits on SpiNNaker and SpiNNaker2 (Section 3.4); • an exhaustive hardware evaluation of eight encodings, with code and data released (Sections 4.2–4.5). The scope of this work is deliberately narrow: we char- acterise the encodings rather than evaluate them on a task. Every experiment presents every value in the range to the trained network, so the relations reported are exact over the whole input space and a relation such as the tolerance law of Section 4.4 can be checked condition by condition. A natural dataset allows neither: its values are unevenly distributed and its features correlated, so the effect of code geometry on learning would be confounded with the data. The network (a dual-rail input layer feeding a single output neuron), the learning rule and the measurement protocol are held constant, so the encoding is the only variable, and the comparison throughout is against standard binary encoding, the representation used in our prior work. How the ranking carries over to a downstream task, where feature distributions are uneven and the encodings interact with later processing, is the subject of separate work. 2. Theoretical Background 2.1. Spatial Encoding and the Hamming Vulnerability In spatial encoding, all bits of a code word are presented to the network in the same timestep, so the network has no access to the value itself, only to which of its input synapses are active. Its response to two values therefore depends on how many bits their code words share, that is, on the Hamming distance between them. In the supervised STDP network of Davies et al. (2025), a larger Hamming distance between trained code words required a larger homeostatic scaling factor for all of them to be recognised, and the larger factor admitted more false positives.
