Algorithm 2 uses as inputs the sampling plan allocation vector (n), the sets of test and supply nodes (A, B), the sourcing-probability matrix (Q), existing data (dprior), a specified loss (L), the size of the MCMC sets of SFP rates (h0), and a number of data sets to generate (h1). Each of h1 data sets is a single simulation d of the data obtained under plan n. The h0 MCMC draws from p(γ|dprior) or p(γ|dprior, d) enable numerical integration. New data generation uses γ(j), a vector of SFP rates capturing the latent truth, and sampling plan n, where na is the number of tests allocated to test node a ∈A. Products at a are sourced from supply nodes in B according to sourcing-probability matrix Q. Element Qab ∈[0, 1] is the probability that a product from a is sourced from supply node b ∈B. P b∈B Qab = 1 for each a ∈A. The supply node associated with each test i at test node a is drawn according to the sourcing probabilities of vector Qa. A Bernoulli test result yi is generated for test i from the consolidated SFP probability of (1); the consolidated SFP probability is the SFP likelihood when accounting for test-node and supply-node SFP rates. The average loss across all h1 simulations yields the estimate of E  L(ˆγ(n), γ)  .
