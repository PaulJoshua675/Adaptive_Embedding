Preprint. A.6 DETAILS OF CROSS-CAPABILITY GRADIENT ANALYSIS We provide the computation protocol for the two gradient-based analyses in Figure 2. Figure 2b ex- amines whether the realized Mix-RL update follows the directions induced by independently trained capability experts, while Figure 2c directly measures pairwise conflicts among capability-specific local optimization directions under the same Mix-RL parameters. Expert-Guided Update Alignment. For each capability c, we fix the independently trained capa- bility expert πθc and select a fixed set of 32 samples. At a Mix-RL checkpoint θt, both the current Mix-RL policy and the corresponding expert are evaluated under identical response prefixes. Let qc,n,s and pθt,c,n,s denote the expert and Mix-RL predictive distributions, respectively, at token position s. We define the expert-matching objective as Lexp c (θt) = 1 Nc Nc X n=1 1 Tc,n Tc,n X s=1 DKL(qc,n,s ∥pθt,c,n,s) , (14) where Nc = 32 and Tc,n denotes the number of valid response positions for sample n. The corre- sponding expert-guided direction is defined as the negative gradient gexp c (θt) = −∇θLexp c (θ) θ=θt. (15) Given two adjacent Mix-RL checkpoints t < t′, the realized parameter displacement is ∆θt→t′ = θt′ −θt. (16) We measure whether this realized update follows the corresponding expert-guided direction using Ac(t →t′) = ⟨∆θt→t′, gexp c (θt)⟩ ∥∆θt→t′∥2 ∥gexp c (θt)∥2 . (17) All four capabilities are compared against the same Mix-RL parameter displacement within each checkpoint interval. Positive values indicate that the realized update moves toward the corresponding expert behavior, whereas negative values indicate movement against the expert-guided direction. For Figure 2b, checkpoint-level alignments are grouped into four training stages and summarized within each capability. Reward-Based Capability Optimization Direction. To directly analyze interactions among ca- pability objectives, we separately estimate a reward-based local optimization direction for each ca- pability under the same Mix-RL parameters. At checkpoint θt, we sample K responses {y(k) c,n}K k=1 for each input xc,n from capability c and obtain their rewards {r(k) c,n}K k=1. The group-normalized advantage is A(k) c,n = r(k) c,n −¯rc,n σc,n + ϵ , (18) where ¯rc,n and σc,n are the mean and population standard deviation of the K rewards, respectively, and ϵ = 10−6. Groups with σc,n < ϵ are discarded. Let Vc,t denote the remaining valid responses and Nc,t their total token count. At each Mix-RL checkpoint, all capability-specific direc- tions are estimated under the same shared parameters θmix,t. For each unordered capability pair (c, c′), we compute Cc,c′(t) = ⟨uc(θmix,t), uc′(θmix,t)⟩ ∥uc(θmix,t)∥2 ∥uc′(θmix,t)∥2 . (20) With four capabilities, this yields six unordered capability pairs at each checkpoint. Negative co- sine similarity indicates locally opposing optimization directions and therefore provides direct ev- idence of cross-capability gradient conflict.
