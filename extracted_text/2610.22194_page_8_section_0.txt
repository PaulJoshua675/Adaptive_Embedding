Executor subagent Setup. The base configuration is the single agent of Section 3.1. Adding the executor places that lifecycle in a separate session, so the meta agent receives artifact paths and a brief status report rather than executing the lifecycle. Both runs begin from the same base checkpoint, share the same context window, and are evaluated from snapshots taken at 11.5 hours. All other settings are identical. Result. The executor halves how often the meta agent loses its context. Over comparable elapsed time the base run compacts ten times and the executor run five (Figure 7). The composition of the meta agent’s work shows where the pressure was coming from. Shell commands fall from 58% of its recorded events to 29%, and a third of what remains is delegation to the executor. Status checks are the clearest instance of the material that leaves. The base agent issues 268 of them and spends 23.0% of its commands asking whether a job has completed. The base run rebuilds a context dominated by command output, whereas the executor run rebuilds a context containing the round’s analysis. 5.2. Analysis subagent Setup. The base configuration uses one agent to read each round’s artifacts and write the next recipe. The analysis configuration adds four subagents that read the same round from training data, failed outputs, training signals, and earlier rounds, each proposing one change. A meta agent makes the final decision. Both configurations use the dataset in Section 3.1, start from the same base checkpoint, train for three epochs under a 3M-token cap, and are evaluated on IFEval using avg@10, per-comparison settings are given in Appendix D. Neither reached the target. We therefore report the base setting over 50 rounds and the analysis setting over 30 rounds under the same time budget. Result. Analysis improves the score and reaches higher values earlier. As shown in Figure 8, the analysis run reaches 63.33 at R6, already above the best score the base run attains in 50 rounds, and climbs to 67.10 at R30. The base run’s best is 60.60 within the first 30 rounds and 62.35 across all 50, so analysis leads by 6.50 points at equal rounds and by 4.75 even when the base run is given 20 rounds more. The two runs also use the data-action families in different proportions (Figure 8, right). With analysis, repair and resupervision together account for 55% of the actions taken, whereas the base run stays within the mixture family, adjusting category proportions in every round as the single agent of Section 3.1 does.
