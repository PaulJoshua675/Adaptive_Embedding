Preprint A ADDITIONAL METHOD DETAILS A.1 SHARED WEIGHTS AND MODALITY-SPECIFIC ADAPTATION Within each diffusion expert, RGB and action use the same base self-attention Q/K/V and output projections and the same two FFN projections. The action branch adds low-rank updates to these six projections and to the text cross-attention Q and output projections. Text keys and values are shared. Each update has the form ∆Wa = (α/r)BaAa, with rank r = 128 and α = 128. Aa uses Kaiming initialization and Ba starts at zero. The pretrained base weights remain trainable. The action branch has separate affine Q/K normalization in self-attention, Q normalization and pre-normalization in text cross-attention, and adaptive normalization parameters, initialized from the RGB branch. The parameter-free layer normalizations retain the same operation in both branches. The high- and low-noise diffusion experts each have their own base weights and action adaptations. The video VAE, text encoder, and action codec are frozen.
