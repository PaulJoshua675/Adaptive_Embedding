Hierarchical Semantic Representation. We first rep- resent each product using a multimodal embedding from Marqo-FashionSigLIP [16], trained with Generalized Con- trastive Learning (GCL) on rich product signals, including product images, descriptions, categories, style, color, ma- terial, keywords, and fine-grained details, across over one million fashion products. This provides a semantically rich representation beyond text-only descriptions. Given ei ∈R1024, an MLP encoder fθ maps each prod- uct to zi = fθ(ei) ∈R32 with architecture 1024 →512 → 256 →128 →32. We apply residual quantization [19] with L = 3 codebooks of K = 64 codes. The induced hierarchy may contain small or heterogeneous clusters. We therefore purify it post- hoc, independent of RQ-VAE training. Using articleType as the anchor attribute, cluster purity is the fraction of labeled items belonging to the dominant product type: Purity(p(ℓ)) = maxa |{i ∈C(p(ℓ)) : aTi = a}| |{i ∈C(p(ℓ)) : aTi̸ = null}| . (5) We retain prefixes with |C(p(ℓ))| ≥5 and Purity(p(ℓ)) ≥ 0.80; at the finest level, we additionally require at least two items. All qualifying prefixes are retained to preserve hier- archy coverage. Relational Context. Purity does not capture how a cluster differs from nearby alternatives. For each surviving prefix p(ℓ), we compare it with its parent and up to three siblings. For categorical attribute value (a, v), we compute ∆a=v(p(ℓ), R) = pctC(p(ℓ))(a = v) −pctR(a = v), (6) where R denotes the parent or a sibling. For numeric at- tributes, we compare mean, median, minimum, maximum, and quartiles. Differences of at least 20 percentage points are retained as exclusivity constraints, identifying attributes that distinguish the target from nearby clusters. Automatic Query Generation. For each purified clus- ter, we generate Q(p(ℓ)) from its attribute distribution and relational context, targeting exhaustiveness and exclusivity. Each sub-type occupying ≥5% of the cluster receives at least one query; a catch-all query covers the remainder. At- tribute combinations covering ≥90% & ≥50% of a cluster define discriminative and coverage signatures, respectively. We use an instruction-following LLM (Gemini [41]; temperature 0.2, top-p 0.8) whose prompt includes these signatures, attribute distributions, parent/sibling context, and exclusivity constraints. It is instructed to produce com- plete shopper-style queries using discriminative attributes, verify separation from siblings, and avoid unsupported uni- versal claims. The LLM returns 6–12 queries plus cluster insights, validation checks, and a coverage map linking ma- jor product types to queries. Outputs are parsed leniently; the full prompt and schema are provided in the supplemen- tary material. Query Attribute Enrichment. For attribute-aware evalu- ation, each unique generated query is converted by the same LLM into {product_type, gender, age_group, color, pattern, material, occasion, brand, price_hint, style_ tags}. Unexpressed attributes are null, multi-valued at- tributes may contain multiple values, and brand is popu- lated only when explicitly mentioned. Duplicate queries are removed globally before enrichment.
