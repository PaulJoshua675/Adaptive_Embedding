Each encoder was kept frozen, and its scan-level representation was evaluated with the same task-specific linear-probe family used for CoFlu-Brain. Each model used its native input parcellation and feature extraction pathway. BrainGFM. BrainGFM pretrains a shared graph encoder across multiple parcellations us- ing graph contrastive learning and masked graph autoencoding (Wei et al., 2026a). We used the authors’ released pretrained checkpoint with Schaefer-100 inputs (Schaefer et al., 2018). Raw Pearson-FC rows served as node features, and FC values above 0.3 defined the graph adjacency. The encoder’s graph-level output was used as the frozen scan representation. BrainMASS. BrainMASS constructs augmented FC views by dropping BOLD observa- tions and learns with masked-ROI modeling and latent representation alignment (Yang et al., 2024). In CoFlu-Brain, each partition forms a complementary retained–dropped FC pair; multiple retained estimates are aligned, and each paired dropped-view representation is pre- dicted. We used the authors’ released Schaefer-100 checkpoint (Schaefer et al., 2018) and released downstream feature path: Transformer-encoded FC rows followed by dimensionality reduction and flattening. BrainLM. BrainLM is a masked-autoencoding foundation model for regional fMRI time series (Ortega Caro et al., 2024). We used the released 111M-parameter ViT-MAE check- point with its native 424-region input. The concatenation of the final class token and mean patch representation was used as the frozen scan feature. Large Connectome Model. The Large Connectome Model (LCM) learns connectome representations through multitask brain–environment interactions (Wei et al., 2026b).
