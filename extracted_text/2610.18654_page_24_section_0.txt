Kwai Summary Attention V2 Technical Report shares KV heads within groups of query heads (Ainslie et al., 2023). Multi-head latent attention (MLA) stores compact per-token latent states (DeepSeek-AI et al., 2024), and quantization methods such as KIVI reduce the precision of cached entries (Liu et al., 2024). These approaches reduce storage per position without removing historical positions. Other methods retain only a subset of token-level KV entries: H2O (Zhang et al., 2023) and SnapKV (Li et al., 2024b) use attention statistics to identify important positions, while StreamingLLM (Xiao et al., 2024) retains initial attention sinks together with a recent window. Another direction compresses historical context into fixed-size recurrent states rather than retain- ing token-level KV entries. Linear Transformers (Katharopoulos et al., 2020) achieve this through kernel feature maps and recurrent accumulation of key–value statistics. Subsequent designs introduce decay in RetNet (Sun et al., 2023), data-dependent gating in GLA (Yang et al., 2024), and gated delta-rule updates in Gated DeltaNet (Yang et al., 2025). Kimi Delta Attention (KDA) (Kimi Team et al., 2025) further extends Gated DeltaNet with finer-grained gating for recurrent memory updates. Related approaches include RWKV (Peng et al., 2024), with matrix-valued recurrent states, and selective state-space models such as Mamba (Gu and Dao, 2024) and Mamba-2 (Dao and Gu, 2024). In their recurrent forms, these models maintain a state size independent of context length, but access historical information through aggregated states rather than separately retained memory entries. Sequence-level aggregation represents multiple context positions with fewer memory entries that remain accessible to attention. Compressive Transformer (Rae et al., 2020) compresses older hidden-state memories, while Dynamic Memory Compression (Nawrot et al., 2024) learns adaptive KV-cache compression. Learned summary and memory representations are explored in Gist (Mu et al., 2023), ICAE (Ge et al., 2024), and UniGist (Deng et al., 2025a). AutoCompressors (Chevalier et al., 2023) uses summary vectors as soft prompts, whereas Activation Beacon (Zhang et al., 2025b) retains compressed KV activations at each layer. GMSA (Tang et al., 2026) combines group merging and layer semantic alignment in an encoder–decoder context-compression framework. Cartridges (Eyuboglu et al., 2026) instead optimizes corpus-specific KV representations offline for reuse across subsequent queries. KSA (Chu et al., 2026) interleaves Summary tokens with fixed-size text chunks. In KSA layers, text queries directly access nearby text and retrieve distant context through Summary KV, while the Summary hidden states continue to be updated across layers. A systematic study of gist-based compression identifies task-dependent limitations, particularly in synthetic recall (Deng et al., 2025b). These findings underscore the importance of evaluating retained capabilities rather than compression ratio alone. Other designs organize compressed memory at multiple resolutions. MELODI (Chen et al., 2025) combines recurrent short-term memory with further-compressed long-term memory constructed at an intermediate layer. AdmTree (Li et al., 2025) organizes gist representations into adaptive semantic trees for hierarchical context compression. H-SSA (Mao et al., 2026) inserts meta-gist tokens to summarize groups of gist tokens and support coarse-to-fine retrieval. DeepSeek-V4 (DeepSeek-AI et al., 2026) applies learned dimension-wise aggregation to text-token KV, using different compression granularities in Compressed Sparse Attention (CSA) and Heavily Compressed Attention (HCA). C- KSA instead applies dimension-wise aggregation to Summary KV, forming Meta entries used only within the layer that constructs them, rather than introducing additional tokens into the hidden-state sequence. This further reduces distant-history storage without coarsening the Summary sequence passed between layers, and permits each layer to choose its own KV compression ratio. 24
