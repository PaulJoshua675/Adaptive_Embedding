A language-conditioned system may need to select a task or skill from an instruction before any low-level control begins. The phrases “open box” and “grasp the lid and open the box” can describe the same action, whereas “close box” describes its reverse. A text retriever must use these differences without assuming a camera image or current robot state. Existing embodied systems go much further: CLIPort and PerAct use perceptual representations and control policies [5,6], while SayCan and RT-1 connect language to skill selection or action prediction [7,8]. We study that initial task-selection step, focusing on how the wording and number of reference descriptions affect retrieval accuracy. RLBench provides task definitions with alternative natural-language descriptions [1,2]. These source-authored descriptions allow a controlled comparison of gallery composition, lexical representations, and wording ambiguity. Rather than indexing the first description in each task file, we resample the indexed descriptions and test retrieval on the remaining paraphrases. This evaluation isolates instruction-to-task matching as one component of a language-conditioned robotics pipeline.
