The three terms of the next counter are mutually exclusive. The next counter is 2A −1 exactly when one of the two branch cases leads there or the machine is already halted, and p + 3 = 2A −1 exactly when p = 2A −4. When the halt bit is 1, the next counter is p, the write enables are 0 and the halt bit stays 1, so a halted state is a fixed point. The layers follow from those of the predecessors, and the longest paths end at the next counter, the next halt bit and the next memory in layer 13, whatever A. Section 6.1 says what it means for the host, with a memory image and a tape, to reproduce itself. A program P of 21 instructions decodes a run-length recipe into the byte string it describes, which makes the host a universal constructor of byte strings (Section 6.2). A program P ∗of 27 instructions also copies the recipe, so that the host emits a serialization of itself from which it is rebuilt (Section 6.3). Both programs are stated for Nhost = H8 and run on HA at every word width from 8 on (Remark 6.14). 6.1 Instances and reproduction An instance pairs a network with an initial memory and a tape, and it reproduces itself when its output rebuilds it. The serialization σ(N) of a clocked netlist N is a byte string from which N, the order of its units included, is recovered; Appendix A specifies it. Netlists with the same serialization differ only by renaming of units, and identifying such netlists, σ is injective. Definition 6.1 (Instances, framing, instantiation). Let N be a clocked netlist realizing the SUB- LEQ transducer with A = 8. For u ∈Σ∗let ⟨u⟩= λ(|u|)∥u, where λ(k) is the eight-byte little-endian encoding of k. An instance is a triple Ω= (N, m, τ) with initial memory image m ∈Σ256 and tape τ ∈Σ∗. Its initial state x0(m) ∈{0, 1}n has memory contents m, program counter 0 and all other coordinates 0, the counter and every memory byte stored most significant bit first at the coordinates the state layout names. Define ser(Ω) = ⟨σ(N)⟩∥⟨m⟩∥τ, Out(Ω) = Out(x0(m), τ) for the transducer Lev(N), and let inst be the partial map inst(⟨a⟩∥⟨b⟩∥c) = (σ−1(a), b, c), defined when a lies in the image of σ and |b| = 256. Definition 6.2 (Self-description and self-reproduction). An instance Ω= (N, m, τ) is self- describing if it halts and Out(Ω) = σ(N). It is exactly self-reproducing if it halts and Out(Ω) = ser(Ω).
