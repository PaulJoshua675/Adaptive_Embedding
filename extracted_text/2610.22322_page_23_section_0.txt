Specifically, we use Claude Sonnet 5 to generate demonstrations of crafting-task execution and record all model responses. We collect 4,791 examples from actual Minecraft interactions, including 1,677 for LOGGER, 2,380 for MINER, and 734 for SMITH. We fine-tune the monolithic agent on the full dataset and each society agent on its corresponding subset, matching the total training compute between the two settings during cold start. SFT for each model is performed on a single B200 GPU. We fine-tune all model parameters in bf16 using AdamW with a cosine learning rate schedule. Detailed settings are listed in Table 3.
