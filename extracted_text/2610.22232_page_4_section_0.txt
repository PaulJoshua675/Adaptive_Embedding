For high-frequency bands, integer wavelet coefficients are modeled directly. 3.3 Task Prompt Design The LLM processes each subband as a one-dimensional sequence. Each context or target band uses the same raster-order, channel- interleaved serialization defined in Section 3.1. As illustrated in the right panel of Figure 2, the LLM input for each subband is organized as a task prompt with two components. Rather than reusing one generic instruction across all coding steps, WaveLLM assigns each subband a task-specific prompt. The text prompt is a task-specific natural-language string that identifies the subband type, describes the available context, and states the pre- diction objective (e.g., “Context: Low-frequency structure.
