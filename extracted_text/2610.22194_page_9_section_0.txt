Furthermore, the actions that analysis unlocks often set a new best score, where a new best denotes a recipe that exceeds every earlier score in the same run. Selecting data by validation results sets a new best in 41.7% of its uses, and editing both instructions and answers in 6 of its 14 uses. The base run never takes these actions, since it stays within the mixture family, so Table 4 in Appendix C.1 reports its new-best rate only for mixture. In summary, analysis helps the meta agent read the same evidence in multiple ways, so it can better decide which supervision to change and whether the resulting examples teach the intended behavior. 5.3. Synthesis subagent Setup. The base configuration selects from the staged pool and may edit the examples it selects. Adding the synthesis subagent enables a round to generate new examples for a capability, written against that capability’s verifier and admitted to the pool only after passing that verifier. Both runs train from the same base checkpoint for three epochs under a 100M-token cap that counts generated rows, and every checkpoint is evaluated as avg@10 on IFEval and IFBench. The budget is larger than in the previous two comparisons because a smaller budget would keep the pool below its size cap, whereas new data becomes valuable only once selection can no longer improve the recipe. Result. Synthesis improves both benchmarks and reaches higher levels earlier. As shown in Figure 9 (left, middle), the synthesis run reaches a best IFEval of 81.58, compared with 78.15 for the base run, and a best IFBench of 51.95, compared with 49.02. Every IFEval checkpoint from R9 onward exceeds the best checkpoint that the base run attains over 31 rounds. The aggregate gain does not imply that every generated batch helps. The repeat_prompt capability remains near 40% for the first 8 rounds, and the batch supplied at R9 raises it to 75.6% in the same round, showing a weakness the loop diagnoses and then addresses by generating new data. By contrast, odd_even_syllables is targeted in 3 separate rounds and scores zero in every round, suggesting that supply alone cannot teach a constraint the model cannot yet follow.
