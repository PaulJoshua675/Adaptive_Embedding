I Scaling Study Details Sub-registries are constructed by including all Ground-Truth APIs for the subset under study plus propor- tionally sampled distractor APIs from all 50 ToolBench categories to reach the target size; the G1 and G2 recall curves use their respective Ground-Truth sets, and the divergence column is measured on the G1 sub- registries. Each size is run with 5 random seeds (different distractor samples); the full registry (46,984 APIs) has no randomness and is run once. Because G2’s Ground-Truth set (1,048 APIs) already exceeds the 1k target, the smallest G2 point is gold-only, slightly larger than 1k, and has zero seed variance. PtR reuses the saved stubs from the main experiment (stub generation is independent of registry size), so no additional LLM calls are made; only FAISS retrieval is recomputed per sub-registry.
