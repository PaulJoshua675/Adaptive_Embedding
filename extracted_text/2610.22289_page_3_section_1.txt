2.1 General agents and cross-environment evaluation General Game Playing studies agents that receive formal descriptions of previously unspecified games and play without algorithms engineered for each game [15]. More recent work evaluates or learns language-model agents across interactive domains: AgentBench provides eight environ- ments, while AgentGym combines a multi-environment framework, interaction trajectories, and methods for agent learning and evolution [4, 5]. Our study examines changes to a Codex-based scaffold without additional model training, with each agent variant deployed unchanged across environments. Exgentic is the closest cross-environment evaluation precedent. Bandel et al. compare five agent architectures and five backbone models across six benchmarks, using protocol wrappers to integrate the original implementations without per-environment task-solving customization [1]. In their closed-source comparison, backbone choice explains more aggregate performance variation than architecture, although architecture remains consequential within a model.
