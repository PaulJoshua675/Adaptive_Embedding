The resulting online contract is therefore simple: consume one compatible immutable snapshot, make request state ready within the latency budget, and scale prediction work with candidate fanout rather than behavioral-history reconstruction. 5.4 KV Storage and Execution Online TransX execution operates on projected cross-attention KV rather than on the model-side behavioral memory itself. Once a memory 𝑀(𝑢) 𝜏 has been constructed, each cross attention layer projects it into the KV state to be consumed by candidate-conditioned cross attention: 𝑀(𝑢) 𝜏 −→𝑉(𝑢) 𝜏 −→Pack(𝑉(𝑢) 𝜏 ), where 𝑉(𝑢) 𝜏 denotes the logical behavior memory KV and Pack(𝑉(𝑢) 𝜏 ) its physical storage representation. Bulk and nearline execution publish this KV state, and online workers retrieve, cache, and execute directly against it. This boundary separates three concerns. KV fidelity determines how accurately the projected state is represented; KV residency determines whether the state resides in on-disk storage, host memory, or GPU memory; and KV execution format determines whether compressed KV is decoded on demand or expanded once and retained for repeated attention reads. These choices affect storage, transfer, HBM footprint, and kernel cost, but they do not change the request-level semantics of the published KV. 5.4.1 KV Quantization Although the number of behavior-memory states is bounded, storing high-precision projected KV for a large active population can still create substantial storage and transfer cost. We therefore quantize behavior memory KV before publication. The deployed codec uses a calibrated orthogonal rotation followed by energy-aware precision allocation under a fixed storage budget. We observe pronounced channel anisotropy in unrotated KV projections, similar to activation outliers reported in large Transformers (Dettmers et al., 2022; Xiao et al., 2023). We therefore rotate the normalized KV into an empirical energy-aligned basis and allocate precision according to per-coordinate energy, yielding a representation better suited to low-bit quantization. Codec parameters are estimated offline from the model-training behavior memory KV and versioned with the corresponding model and projection. Bulk and nearline workers apply the codec before publishing KV, so no fitting is required on the online serving path. Appendix B.3 gives the rotation, bit-allocation, and reconstruction equations. In the measured configuration, a 4-bit-average direction payload reduces median behavior memory KV from approximately 28 KiB/user in BF16 to 8.5 KiB/user, a 3.2× reduction, with absolute test-AUC change within 2 × 10−3. Thus the physical KV footprint can be reduced substantially without changing the logical memory resolution exposed by the model. Packed versus expanded KV execution.
