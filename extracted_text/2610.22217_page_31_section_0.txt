Evidence Protocol • Apply ONLY the task section matching the current question type; ignore the others. • When the task involves sequential operations, update the working state after each step before proceeding. • Do not use dataset names, filenames, memorized examples, or external information. Task-Specific Checks Apply when answering questions about charts. • When reading values from a chart, align with the nearest labeled gridline or tick mark—do not estimate between lines. • When comparing two values, confirm whether the question asks for an absolute difference or a ratio. • When a chart has dual axes or multiple series, verify that the value is read from the correct axis and series. • When identifying a peak or extremum, cross-reference its position with both axes to confirm the exact value. Final verification: • When the answer’s magnitude seems implausible given the chart’s visual scale, re-read the value against the axis markings. • When transcribing text, verify that no visible text region was skipped by scanning page edges and corners. Apply when answering questions about presentation slide decks. • When extracting data from a multi-page document, verify that the answer comes from the page matching the question’s context rather than a visually similar page. • When the question asks about a relationship or flow, trace connecting arrows or lines in the diagram before answering. • When listing categories from a chart or table, ensure that all items are captured. Final verification: • When the answer’s magnitude seems implausible given the visual scale, re-check the relevant values. • When transcribing text, verify that no visible text region was skipped. Apply when the task is pure text recognition/OCR. Activate only for long multi-line text, multi-column layouts, or peripheral text blocks that could be overlooked. • Scan every region systematically, including the main body, headers, footers, captions, foot- notes, watermarks, stamps, and table cells. • For multi-column or multi-region layouts, transcribe each region in natural reading order and preserve completeness. • For long CJK text, read each line fully before moving to the next line; do not merge lines or skip characters. • When uncertain whether a faint or partial region contains real text, prefer preserving potentially valid text rather than omitting an entire region. Final verification: • Re-scan the four edges and every column or region of the image and confirm that no visible text line was skipped or truncated. Output Follow the output format stated in the question exactly, including any answer tags it specifies. Do not shorten, skip, or reorder the reasoning the question asks for, and never state the final answer before the checks above are done.
