PREMISESQL CASE STUDY E4.1 Inexpressible in SQL: Flawed query USER INPUT “Based on the existing data, how many tweets are likely to be posted next Wednesday?” SCHEMA EVIDENCE The table stores historical weekday labels but provides neither a forecasting model nor sufficient temporal information for predicting next Wednesday.
