Overview of Problem Setup Anticipatory workspace construction is the problem of transforming a large corpus into a structured filesystem-based workspace before downstream queries are observed. 2.2. Desiderata for Anticipatory Workspaces. A useful memory should do more than “remember” a corpus. It should reshape the corpus into an answer-facing workspace that helps future agents quickly find relevant evidence while preserving a path back to the raw source documents. As a running example, consider an enterprise corpus containing design docs, issue threads, launch notes, and customer reports for the same product. One future query may ask for a low-level implementation detail; another may ask how a user-visible behavior changed across releases; a third may ask for the exact source that supports a disputed claim. We use these examples to motivate three key desiderata. Coverage with Efficient Navigation. The memory should cover many plausible queries while reducing the need to search the raw corpus. In the enterprise example, the builder might create a release timeline, a component-level design index, and customer-facing behavior summaries, each linking the same underlying documents from a different angle.
