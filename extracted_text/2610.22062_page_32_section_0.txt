Decomposing the extraction question The prompt experiment leaves open the possibility that the single extraction question asks for two judgments at once, whether diarrhea has started and whether it is currently uncontrolled. We tested that reading by replacing the single question with two simpler ones and combining them in code rather than in the prompt. Variable A asks only whether diarrhea has begun as a side effect of trofinetide at any point up to and including the visit. Variable B asks only whether it is adequately controlled at the visit. The two were combined by a deterministic state rule that labels diarrhea present from the visit at which onset is first detected and absent from the visit at which control is first established. Ten combination rules were evaluated, varying that rule, the direction of the consensus gate and the within-window aggregation order, all at no additional inference cost, since each is a function of the same two extracted variables. The decomposition did not improve on the single question. The ten rules span 61.7% to 79.4% (Table S10, panel B), the best coming within 0.2 points of the deployed prompt and none reaching the 84.2% of the reported configuration. The onset variable is what limits them. Applied alone it scores 61.7% at precision 0.384, so it fires on 61 of the 136 negative cells, and because the state rule cannot label a visit negative until control is documented, the combination rules can only recover accuracy by suppressing harder, which collapses recall. As with the reasoning rules above, the deployed prompt already encodes this logic, since it scores active diarrhea as present and both resolved history and adequately controlled disease as absent (Note S3). Splitting that judgment into two questions and a state machine reproduced it less accurately than asking it once.
