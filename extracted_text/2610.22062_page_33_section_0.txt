Applied to the deployed prompt’s modal predictions this raised accuracy from 79.8% to 84.2%, the best F1 anywhere in the family at 0.707 (variant S1 in Table S10, panel C), matching the reported prompt from the opposite direction, by cutting false negatives rather than false positives. This is a bound and not a method. Collapsing every patient’s onset to the first on-treatment visit removes any possibility of predicting a later onset, so it assumes away the case of a patient who develops the symptom after a year. For diarrhea that assumption is nearly free, since the annotation places 35 of the 37 positive patients at their first on-treatment visit, but it is not an assumption we could carry to the other phenotypes, where onset is not concentrated at a single visit. A related benchmark makes the same point about the task. Predicting from the visit number alone, positive at 6 months and negative everywhere else, scores 82.5% on these cells, because 35 of the 47 positive cells sit at that one visit. Much of the annotated signal is carried by the timing of the visit relative to treatment start rather than by the content of the individual note, which is a property of this label set rather than a result about the model. How these experiments sit in the development process. The results above are the final stage of an iterative process and not a set of independent replications. We first searched over architectures, then over prompts, running rounds of error analysis between stages and carrying the surviving configuration forward each time. Two things changed along the way. Error analysis showed that some of the remaining error was in the data rather than in the model, so the note pull was extended from one ending in 2025 to one extending through August 2026, and the exposure anchor was replaced (Note S8). Earlier stages were therefore run on a different corpus and a different set of evaluation windows, and their numbers are not comparable to the ones reported here. Where an earlier stage and the final run disagree, we report the final run. Model builds differ between the two for the same reason. Every configuration of the final rerun ran in one session on Claude Opus 4.6 v1.154.0 and the arms are therefore mutually comparable, while the architecture comparison in Table S11 ran on the build the pipeline was originally deployed with, v1.151.0. The platform withdrew v1.151.0 before the rerun, so a byte-identical replication of the deployed configuration was not available and the two sets are reported separately rather than pooled. Supplementary Note S8. The Exposure Anchor Every follow-up window is measured from the date trofinetide was started, so that date determines which visit a note is scored against. The deployed pipeline took it from the earliest trofinetide record in the Epic order table, and the resulting windows disagreed with the expert annotation more often than the note content did. Manual review of the record explained why. Trofinetide is an oral solution dispensed by a specialty pharmacy and given at home, so the drug appears in orders, charts and correspondence well before the family gives the first dose, and the order is followed by pharmacy processing, insurance authorization and a four-week titration. In one reviewed patient the prescription reached the specialty pharmacy 73 days after the order, insurance declined coverage the same day, and the first record of the family giving the drug is at day 114. In another the order preceded the first documented dose by more than two years. In both cases the agents read every note correctly and the error was in which window the note had been placed.
