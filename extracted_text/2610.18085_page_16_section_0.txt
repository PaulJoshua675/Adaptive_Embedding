B.3 Interaction with Layer Normalization Layer-normalization interaction. Pre-LN normalizes the input to each sub-layer, which might seem to eliminate the effect of weight norm imbalance. However, layer normalization acts on the residual stream, i.e., the sub-layer input, not on the internal weight matrices. The gradient transformation law operates on the internal bilinear structure, and layer normalization does not interact with this symmetry. Specifically, the layer-normalization output ˆx := LN(x) is a fixed function of the residual stream regardless of the internal parameterization of the sub-layer, so the reparameterization (Aℓ, Bℓ) →(cAℓ, c−1Bℓ) preserves SubLayerℓ(ˆx) and hence the gradient transformation law continues to hold. To make the layer-normalization argument precise, write fA,B(X) for the sub-layer map with all other sub-layer parameters fixed. Every exact pair in Table 1 satisfies fcA,c−1B(X) = fA,B(X). The form Bg(AX) describes a ReLU MLP, but does not represent a Q–K attention pair: Both Q and K enter the logits, with (cAX)⊤(c−1BX) = (AX)⊤(BX). In Pre-LN, the residual-block map is X + fA,B(LN(X)); in Post-LN, the residual-block map is LN(X + fA,B(X)). Substituting the same sub-layer identity into either expression proves forward invariance of the whole block. Lemma 7 then gives the same inverse gradient-coordinate factors in both cases. B.4 Other Architectural Variants The following extensions and boundaries complete the catalog in Sec. 2.1. Cross-attention, mixture-of-experts, and state-space blocks are not used in the primary training comparisons. Cross-attention in encoder and decoder models. The attention pairs in Table 1 also apply when queries, keys, and values come from different sources: Their bilinear and linear compositions do not require the two input sequences to coincide. Mixture-of-experts models. Each expert in a sparse mixture-of-experts MLP (Shazeer et al., 2017; Fedus et al., 2022) with ReLU experts contains an independent (W 1 e , W 2 e ) pair. Conditional routing means a given token is processed by only k experts, but the symmetry W 1′ e := ceW 1 e , W 2′ e := c−1 e W 2 e is per-expert and forward-equivalent regardless of the routing decision: The routing gate is shared across experts and unaffected. The catalog adds E independent scalar orbits per layer, where E is the expert count. For SwiGLU experts, the exact pair is V–O with the gate fixed. GELU up–down rescaling is not an exact symmetry. State-space models. Mamba’s selective state-space block (Gu and Dao, 2023) contains an input projection W in and an output projection W out around a state-space recurrence. The input-dependent discretization step ∆ enters nonlinearly, so the recurrence is not generally homogeneous in its input. Reciprocal rescaling of the input and output projections need not preserve the function, and state-space blocks are excluded from Table 1. Any sub-block that has the form Bg(Ax) with g positively homogeneous inherits the corresponding pair. ReLU has this property; in SwiGLU, the same pair inheritance holds for the value path with the gate fixed, not for joint scaling of the gate and value projections.
