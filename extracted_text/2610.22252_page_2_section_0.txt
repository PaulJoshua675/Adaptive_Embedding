These works establish guarantees for tabular models. Extending the underlying ideas to large context and action spaces requires exploiting structure beyond individual context–action pairs. In particular, under linear reward structure, we would like the evaluation cost to reflect the feature dimension and the geometry of the target policies. This leads to the following question: Can we evaluate a collection of target policies simultaneously under linear reward structure, with only logarithmic explicit dependence on the number of policies and no dependence on the cardi- nalities of the context and action spaces in the context and reward sample bounds? In this work, we answer this question affirmatively for stochastic contextual bandits with a known feature map and a linear conditional mean reward. We consider K fixed target policies and allow reward-free queries to each policy on a shared context. We propose PRISMA, which uses reward-free policy queries on shared contexts to construct a sampling mixture and then fits a single linear reward model to evaluate all target policies. With probability at least 1 −δ, our algorithm estimates every target policy’s value to accuracy ε using e O (L2S2 + β2)(1 ∨ρ⋆) ε2 · log(K)  context draws and reward observations, where e O suppresses logarithmic factors in K, d, and 1/δ. Here, L bounds the feature norm, S bounds the reward parameter norm, and β bounds the reward noise. The instance-dependent quantity ρ⋆measures the smallest worst-case value-estimation uncertainty achievable by a mixture of the target policies, and satisfies ρ⋆≤d. We account separately for policy queries: each shared planning context requires one query to every target policy. A central challenge is to learn a useful sampling design from estimated feature moments without requiring a numerical lower bound on the eigenvalues of their second-moment matrices. We address this challenge through a regularized design objective and multiplicative concentration of regularized second moments. An adaptive doubling procedure selects the regularization scale and sample budgets without knowledge of ρ⋆. For a positive integer n, let [n] := {1, . . . , n}. For a finite set S, we denote its cardinality by |S|. We write △(S) for the set of probability distributions on a measurable space S, and △n−1 := {p ∈ [0, 1]n : Pn i=1 pi = 1} for the probability simplex over n elements. For vectors u, v, let ⟨u, v⟩:= u⊤v, and let ∥u∥2 denote the Euclidean norm. For symmetric matrices A, B of the same size, we write A ⪯B if B −A is positive semidefinite, and A ≻0 if A is positive definite. For A ≻0, define ∥u∥A := √ u⊤Au. We denote the identity matrix by I, with its dimension understood from context. The notation ess sup denotes the essential supremum with respect to the indicated probability distribution. All logarithms are natural. For nonnegative quantities a, b, we write a ≲b if a ≤Cb for a universal constant C > 0. The notation e O suppresses logarithmic factors. We consider a stochastic contextual linear bandit [7, 18, 40] with context space X, action space A, and an unknown context distribution P. The learner has sampling access to P and access to K known target policies ΠK := {π1, . . . , πK}, where each policy πi : X →△(A) maps a context to a distribution over actions. Contexts are sampled independently from P. Given a context Xt, the learner can select a policy index It ∈[K] and sample an action At ∼πIt(· | Xt).
