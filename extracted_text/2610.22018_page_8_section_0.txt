G Original DuwatBench-only context Before constructing the cleaned/rebalanced 1,195-image evaluation set, exploratory runs were con- ducted on the original DuwatBench [Patle et al., 2026]-style 1,272-row files. Those files include 20 multi-label or ambiguous true-label rows; Table 4 reports metrics after excluding them. We do not mix these numbers into the main comparison because they use a different dataset distribution and fewer models. They are nevertheless useful context: original DuwatBench is strongly Thuluth- heavy, so raw accuracy can look high even when balanced accuracy remains modest. These context runs support two design choices in the main paper. First, they motivate rebalancing: the original clean six-class subset has a 56.4% majority-class baseline because Thuluth dominates the dataset. Second, they show why prompt effects should be interpreted cautiously: GPT-4o’s alternative wording run greatly increases Diwani recall while reducing overall accuracy, suggesting that prompt changes can swap the default label rather than solve fine-grained recognition. 8
