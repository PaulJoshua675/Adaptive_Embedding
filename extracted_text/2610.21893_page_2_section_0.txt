A fixed reader answers these ques- tions individually using the same compressed con- text, and a fixed judge evaluates answer correctness against the original source context and reference answers. Our contributions are threefold. First, we intro- duce GACC-Bench, to the best of our knowledge, the first benchmark for goal-adaptive context com- pression. It contains 500 goals and 2,571 questions over 281 document and agent-trace contexts from seven collections spanning diverse domains, with all instances reviewed by human experts. Second, we design a compressor–reader–judge framework to evaluate goal-adaptive compression under dif- ferent retention budgets, with the reader and judge held fixed. Third, we evaluate ten LLM compres- sors and conduct goal ablations across six models. Our experiments show that target-goal condition- ing improves accuracy over goal-agnostic compres- sion, yet even the best-performing compressor falls substantially short of full-context performance in supporting correct answers to every question asso- ciated with a goal. 2 Related Works Context Compression with Downstream Guid- ance. Early context-compression methods select content using self-information (Li et al., 2023) or perplexity-based importance (Jiang et al., 2023). LLMLingua-2 learns task-agnostic token prun- ing (Pan et al., 2024), whereas LongLLMLin- gua and RECOMP condition compression on the downstream question (Jiang et al., 2024; Xu et al., 2024). Query-based summarization also uses ex- plicit information requests: QMSum pairs meet- ings with requests for relevant summaries (Zhong et al., 2021). For agents, ACON optimizes compres- sion guidelines using trajectories that succeed with full context but fail after compression (Kang et al., 2025). CacheNotes develops a task-aware KV- cache compression method guided by task descrip- tions shared across examples within a task fam- ily (Corallo et al., 2026). It generates compression- planning tokens to construct a reusable compressed cache before downstream queries are available. Evaluating Information Retention. Compara- tive studies assess downstream performance across compression methods and ratios (Jha et al., 2024; Zhang et al., 2025). Question-answering-based summary metrics evaluate factual consistency and information coverage (Wang et al., 2020; Durmus et al., 2020; Scialom et al., 2021). Memory bench- marks examine information use across extended interactions: LoCoMo and LongMemEval evalu- ate conversational recall and reasoning (Maharana et al., 2024; Wu et al., 2024), while MemoryA- gentBench includes test-time learning and selective forgetting (Hu et al., 2026). SUMER retrieves from uncompressed histories to answer questions (Zheng et al., 2025), allowing information absent from the current compressed context to be recovered.
