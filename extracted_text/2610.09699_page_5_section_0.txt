2.2 From CMA-ES to Modular CMA-ES The Modular CMA-ES (ModCMA) is built on the observation that CMA-ES naturally decomposes into a small number of coherent, interchangeable components, such as sampling, selection and recombination, step-size adaptation, matrix adaptation, and restarting. ModCMA exposes the algorithmic choices within these components as explicit modules, each of which can be independently configured. This design follows the Modular Evolutionary Algorithms (ModEA) paradigm introduced by van Rijn et al. (2016) and extends an earlier modular CMA-ES implementation (de Nobel et al., 2021). Following the structure shown in Algorithm 1, each component is represented by one or more modules, with several alternative options corresponding to mechanisms from the literature. For example, the Matrix Adaptation module includes options such as Covariance, Separable, and Cholesky. We use the term configuration for a complete specification of the module options together with the relevant numerical parameter settings. When referring only to different combinations of module options, with numerical parameters kept at their prescribed defaults, we use the term modular CMA-ES variant.
