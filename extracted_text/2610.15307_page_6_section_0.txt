Connectivity (zC). We adopt SynFlow [27] to evaluate global connectiv- ity using a data-free path integral. Given a structure-preserving metric R, the connectivity score is: zC = X w∈α |w| ⊙ ∂R ∂w (5) where w is a trainable weight, |w| is its absolute magnitude, R denotes the structure-preserving SynFlow objective, ∂R ∂w is the derivative of R with respect to w, and ⊙denotes the Hadamard product. This score reflects whether information can flow through the architecture without structural bottlenecks. Capacity (zP ). Parameter count provides a basic physical constraint on model capacity. We define it as: zP = L X l=1 |wl| (6) where L is the total number of layers, wl denotes the set of trainable parame- ters in the l-th layer, and |wl| denotes the number of trainable parameters in that layer. To make them comparable and learnable, CAST applies Cop- ula Alignment [22] followed by Synergy Transformation. We first use the Empirical Cumulative Distribution Function (ECDF) [28] to map each raw feature into a percentile rank.
