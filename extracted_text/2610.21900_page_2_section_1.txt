2.1 Long-Term Agent Memory and Structured Organisation External memory lets an agent read and write information outside its model parameters. Hierarchical management in MemGPT and the historical storage mechanisms studied in MemoryBank and long-term memory augmentation provide ways to retain information beyond the immediate context [7–9]. A-MEM, Mem0 and MemoryOS extend this work through memory associations, updates and hierarchical organisation [10–12]. Temporal information enters the memory itself in Zep’s knowledge graph [13], making it particularly relevant to state tracking. TEM examines how version status is carried from stored records into answer evidence. Memory processing cost is another concern; LightMem addresses it through staged operations [14]. Graph-based retrieval connects information spread across records.
