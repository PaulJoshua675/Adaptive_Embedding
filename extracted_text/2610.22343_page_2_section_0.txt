GFM features are typically constructed from and organized around the observing views, so changes in camera viewpoint can induce substantial changes in the representation even when the underlying physical scene remains unchanged. When such features are directly used as predictive states, a temporal model would account simultaneously for genuine scene evolution and camera- induced variation, although these arise from fundamentally different sources. In particular, even a static scene can undergo substantial changes in feature space as the camera moves, forcing the temporal model to predict viewpoint-dependent transformations that do not correspond to physical scene evolution. This unnecessary variation makes the latent dynamics more complex and therefore harder to predict over long horizons. FR3D (Morbitzer et al., 2026) also shows that separating ego- motion from scene forecasting can improve temporal modeling, but its predictive state still inherits the view-dependent structure of the underlying reconstruction representation. We argue that such separation should instead be built into the representation itself: the state should describe what the world is, while the camera should determine only how that world is observed. To this end, we introduce GeoState, a view-decoupled geometry state learned from pretrained GFM features. Given multi-view observations, a scene tokenizer compresses their geometry features into a compact scene state represented in a shared scene coordinate system, while the query viewpoint is in- troduced only during decoding. Specifically, a geometry decoder takes the scene state together with rays from a query camera and predicts the geometry observed from that viewpoint. Consequently, the same scene state can be queried repeatedly from different viewpoints without re-encoding the scene. This transforms view-conditioned GFM features into a representation in which scene geom- etry is explicitly separated from camera-dependent observation. Building on this representation, we formulate 3D world modeling directly in the scene-state space. The temporal model can therefore focus solely on predicting scene dynamics, while camera evo- lution is modeled independently. At inference time, a predicted future state can be decoded using either a separately predicted camera trajectory or a user-controlled camera. Our formulation also maintains a consistent scene gauge throughout temporal prediction and geometry decoding, avoid- ing the need for per-frame scale alignment during rollout. We evaluate our approach on large-scale dynamic driving scenes, using Waymo (Sun et al., 2020) for in-domain evaluation and KITTI (Geiger et al., 2012) and nuScenes (Caesar et al., 2020) for zero- shot transfer. Our approach outperforms the compared world models in depth forecasting across all reported horizons, while maintaining a consistent scale throughout the forecasting rollout. Experi- ments further demonstrate geometrically consistent querying across viewpoints and generalization across driving datasets. Ablation results show that view decoupling makes the scene representation more predictable. Together, these findings support view-decoupled geometry states derived from pretrained GFMs as an effective representation for predictive 3D world modeling. Our contributions are threefold: • We identify viewpoint coupling in geometry foundation model features as a limitation when using them as predictive world states, and introduce GeoState, a view-decoupled geometry state derived from pretrained GFM representations that separates scene content from how the scene is observed. • We develop a scene-state learning framework that realizes GeoState through a Scene To- kenizer that aggregates multi-view GFM features into a shared scene state and a query- conditioned Geometry Decoder that introduces the query viewpoint only at decoding time. • We formulate a 3D world model that predicts scene evolution directly in GeoState space while modeling camera evolution separately, and demonstrate long-horizon geometry fore- casting, geometrically consistent cross-view querying, and zero-shot generalization across driving datasets without per-frame scale alignment. 2
