The auxiliary heads are saved separately from the Hugging Face model checkpoint. 9.2.3 Hyperparameter Settings for the Hierarchical-Loss Component Ablation. Table 12 reports the hyperparameter settings used for the hierarchical-loss component ablation. Each variant is derived from the full configuration by disabling the other mechanisms, allow- ing the contribution of static weighting (SW), confidence gating (CG), and scheduled sampling (SS) to be isolated. The CE base- line disables all three mechanisms and applies uniform weighting to all SID tokens. HL w/ SW uses static level weights while dis- abling confidence gating and scheduled sampling. HL w/ CG uses confidence-based gating with uniform base weights, while disabling scheduled sampling. HL w/ SS uses scheduled sampling with uni- form base weights and no confidence gating. HL w/ SW, CG, SS corresponds to the full hierarchical-loss configuration. All variants use the same optimizer and training configuration: learning rate 2×10−5, effective batch size 16, 20 training epochs, and a cosine learning-rate schedule. Scheduled sampling, when enabled, uses an annealing period of 200,000 steps. The static level weights are (3.0, 2.0, 1.0) from the coarsest to the finest level. Confidence gating uses a floor of 0.2, 𝛾= 1.0, and an 𝛼schedule that linearly decreases from 1.0 to 0.0 over 300,000 steps. 9.2.4 Conversation Type Examples (Toys).
