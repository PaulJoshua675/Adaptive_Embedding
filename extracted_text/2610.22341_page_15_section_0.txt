A THE 3DCODEVERSE HARNESS: DESIGN AND IMPLEMENTATION A.1 COMPONENTS AND MODEL ROLES Tracks and runtimes. 3DCodeVerse Harness spans four generative tracks—static objects, artic- ulated objects, 3D scenes, and procedural graphics—backed by seven isolated language runtimes: three for static objects (Blender Python, CadQuery, and Three.js), one each for articulated mecha- nisms (URDF with Blender-authored links) and scenes (Three.js), and two for graphics (GLSL and moderngl). Each runtime specifies a strict file layout, static lint rules, a sandboxed build wrapper, canonical export formats, and a deterministic render driver, while sharing unified coordinate frames, metric units, camera rigs, and geometric tolerances. Model roles and execution invariants. Each run decouples structural planning, code synthesis, and visual evaluation into three pluggable roles: a planner, a coding agent, and a vision–language judge (Figure 7). The planner and judge operate through a unified API interface, while the coding agent executes inside an isolated workspace equipped with the harness’s spatial tools via the Model Context Protocol (MCP), alongside a single-shot mode that requests a complete file envelope through direct API calls. Every round commits raw source code from which meshes and renders are deterministically regenerated; boilerplate infrastructure (camera rigging, coordinate conversion, URDF composition, scene assembly, and shader headers) resides in the harness, and verification proceeds strictly from fast programmatic gates to blind VLM judging. A.2 PLANNING AND THE JOB GRAPH Structured specification and plan synthesis. The planner translates an open-ended request into a schema-validated structural plan: named parts with metric bounding boxes, materials, symmetry, and attachment topology for static objects; a kinematic tree with typed joints, axes, pivots, limits, and acyclic affine mimic couplings (qj = mjqi + bj) for articulated mechanisms; spatial zones, modular assets, effects, and authored cameras for scenes; and render passes, uniforms, and temporal dynamics for graphics. Each plan carries an acceptance checklist binding items to an evidence modality (measurement, visual inspection, probe, or joint sweep) and a priority (must or should), supplemented by canonical rules that normalize kinematic conventions and enforce requested dimensions (±5%), triangle budgets, grounding, and temporal motion. 15
