The Schur form is upper triangular by construction; what is informative is where the mass sits within it. For a normal operator T would be diagonal, the whole norm carried by the eigenvalues. Here almost none is: the strictly upper-triangular part accounts for a fraction 0.99 of ∥J∥F (Table 3), so the operator is nearly all feed-forward coupling between Schur modes rather than modal decay. Magnitudes are shown, and individual mode positions should not be read as structure; see the text. Appendix C. The attention schedule in detail The attention map comes apart into a shared schedule, which depends only on the tick, and the image’s features, which decide where that schedule lands. Discarding each image’s own query and substituting the population-average query at the matching tick still recovers the image’s true attention map at cosine similarity 0.936 (400 held-out images; Figs. 4 and 8). Although each image sets its own starting query, the way the query advances is nearly common to all images, so a simple predictor—the current query plus the shared average increment (R2 = 0.98 held out)—forecasts the next query, and with it the next attention map (cosine 0.996 versus 0.948 for assuming attention stays put). Predicting the schedule thus predicts where the model will look. A note on what this does and does not let one skip at run time.
