The following lemma shows the second property of the MO-MFEA that when the population size meets a specific threshold, each individual in the population will either survive or be replaced by at least one better individual that is associated with the same task, thereby ensuring that the already covered Pareto front points are never lost. The key of the proof is that for any function value w.r.t. a specific bi-objective problem, at most four of its corresponding individuals will have a positive crowding distance. Lemma 3. Let M 1, ..., M ℓbe the maximal size of the sets of incomparable solutions w.r.t. bi-objective problems A1, ..., Aℓrespectively. Consider using the MO-MFEA with population size N ≥4ℓmax{M 1, ..., M ℓ} to optimize the ℓ-task (A1, ..., Aℓ) problem. If at some iteration t the combined parent and offspring population Rt contains some solution X (and thus in particular if X ∈Pt), then at any later time s > t the parent population Ps contains a solution Y with τ(Y ) = τ(X) such that Y ⪰X. In particular, if Rt contains a Pareto optimum X w.r.t. a specific problem Ak, k ∈[1..ℓ], then any future population will contain a solution Y with f(Y ) = f(X) and τ(Y ) = τ(X). Proof. Let t ∈N and X ∈Rt with τ(X) = k, k ∈[1..ℓ]. We only need to show that Pt+1 contains an individual Y with τ(Y ) = k such that Y ⪰X. Let F k 1 be the first front for the non-dominated sorting applied to {Z ∈Rt | τ(Z) = k} (the individuals corresponding to problem Ak). If X /∈F k 1 , then there is some X′ ∈F k 1 with X′ ≻X. Note that F k 1 is a set of incompara- ble solutions with a maximum size of M k w.r.t problem Ak, and also note that each reached function value has at most four corresponding individu- als with positive crowding distance from [ZD23a, Proof of Lemma 1]. Thus, there are at most 4M k individuals in F k 1 with positive crowding distance. Hence, there is Y ∈F k 1 with f k(Y ) = f k(X′), τ(Y ) = τ(X′), cDis(Y ) > 0, and rk(Y ) ≤4M k ≤4 max{M 1, ..., M ℓ}. Then Y ≻X′, τ(Y ) = τ(X′), and φ(Y ) ≥1/(4 max{M 1, ..., M ℓ}). Therefore, Y ranks among the top 4 max{M 1, ..., M ℓ}ℓ≤N individuals in Rt with the largest scalar fitness values. Thus, Y will survive into Pt+1. Analogously, for X ∈F k 1 , if cDis(X) = 0, then there is Y ∈F k 1 with f k(Y ) = f k(X), τ(Y ) = τ(X), cDis(Y ) > 0, and rk(Y ) ≤4M k ≤4 max{M 1, ..., M ℓ}, and Y will survive into Pt+1.
