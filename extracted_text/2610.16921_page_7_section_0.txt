Hyperparameters of these backbones follow the recommendations in the original papers or the official code repositories. For each backbone B, the network is decomposed as B(Xn) = D(F(Xn)) following the principle in Section II-C. Concretely, the split between F and D is defined as follows: • EEGNet [9]: F contains the initial temporal convolu- tion and depthwise spatial convolution blocks (including batch normalization, ELU, and average pooling), which produce a compact spatio–temporal feature map. D com- prises the final separable convolution, global average pooling, dropout, and the dense classification layer that maps the pooled feature to class logits. • M-ShallowConvNet [10]: F contains the temporal con- volution and depthwise spatial convolution layers to- gether with the first batch normalization. D includes the squaring non-linearity, mean pooling, log transformation, dropout, and the final fully connected classifier. • FBCNet [11]: F is the FBCNet feature extractor that ap- plies multi-band temporal convolutions and spatial filters for each filter bank branch and outputs concatenated fea- ture maps across bands. D is the FBCNet discriminator that performs covariance-based pooling over the spatially filtered signals and projects the pooled representation to class logits through fully connected layers. • ATCNet [12]: F consists of the temporal, depthwise and spatial convolution layers, and the stacked attentional temporal convolution blocks that form the main encoder. D contains the final global average pooling, dropout, and classification layers that operate on the encoder output. • EEGConformer [13]: F is the temporal and depthwise convolution layers. D includes the remaining convolution layers, Conformer encoder, and the output linear classi- fier. • TSLANet [14]: F comprises the temporal segmenta- tion and patch embedding, and positional encoding. D consists of the stacked temporal–spectral local attention blocks, final pooling over the sequence dimension and the dense classification head. • CSPNet [15]: F includes the filter-bank temporal convo- lutions and CSP-like spatial projection layers that produce multi-band spatial features. D aggregates these features via pooling and passes them through the final fully connected classifier. • mAtt [16]: F is the multi-head Riemannian feature extractor that computes, for each window, covariance matrices, projects them to a low-dimensional subspace, and applies the matrix logarithm to obtain a stack of normalized log-SPD matrices without flattening. D vec- torizes the per-head SPD features, applies an attention mechanism to weight and aggregate the heads, and feeds the aggregated representation into an MLP classifier to produce class logits.
