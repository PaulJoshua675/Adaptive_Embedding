Cell color encodes the printed integer value; solid blue old-state outlines mark write support, dashed gray outlines mark other read coordinates, and orange new-state outlines mark actual changes. RELABEL preserves disconnected cells with the same label. LAYER grows only one boundary layer and does not overwrite label 2. STENCIL reads beyond its five-cell update ball and uses only old values. MOVE updates each row front to back, with label-2 obstacles preserved. Read counts include repeated incidences, whereas outlines show unique coordinates. These small examples are explanatory fixtures, not formal samples or model predictions. In the STENCIL panel, the old-state sums on the five support coordinates, in row order, are 4, 2, 5, 8, 3. Modulo four these become 0, 2, 1, 0, 3, changing three values. Its 22 read incidences cover ten unique coor- dinates, five outside the write support.
