E Serving and reproducibility All guards run on one cloud platform. Managed models: Gemini 3.8 Flash and Gemini 3.1 Pro through the platform’s Gemini API with a response schema; Claude Sonnet 5 through the partner API with thinking disabled (the SDK exposes no temperature for this model); GLM 5.2, gpt- oss-120b, Gemma 4 26B-A4B and Llama 4 Maverick through the platform’s OpenAI-compatible endpoint with response_format = json_schema and 8k tokens of headroom for hidden reasoning. Self-deployed models (Qwen 3.8 27B FP8, Nemotron 3.5 Lightning 30B-A3B, TS-Guard, the six small guards, a self-deployed copy of Gemma 4 26B-A4B used for the low-resource pair, and the three purpose-built guards ShieldAgent, Safiron and AgentDoG at pinned revisions) run vLLM on one RTX PRO 6000 with max-model-len 32768, greedy decoding and JSON-schema enforcement (TS-Guard uses its authors’ XML prompt and parser instead; ShieldAgent uses the Agent-SafetyBench evaluation prompt with tool definitions and a <User>/<Assistant calls the tool>/<Tool> dialogue and its [Answer] parser; AgentDoG uses its model-card trajectory prompt with [USER]/[AGENT]/[ENVIRONMENT] turns and a safe/unsafe output; Safiron uses its model-card guardian instruction with a JSON input of request, per-step actions and environment, harmless iff the output starts with “There are no risks”). Every verdict row records model id, prompt hash, token usage and latency. TS-Guard’s accuracy on the original wording (0.918) matches the released figure (0.917).
