The Right Byte First an encoding a that represents each scalar as a contiguous, nonempty sequence of symbols, let La(x) denote the stream length and ϕa map scalar boundaries to symbol boundaries. A cluster-aligned target is any set T(x) ⊆G(x), realized in the encoded stream as ϕa(T(x)). This condition constrains the supervision; a learned predictor can still deviate from it. It accommodates different compression criteria: parent- BPE, entropy-based, or fixed-rate cuts can be restricted to G(x) once their offsets are expressed in common coordi- nates. The retained-parent construction below removes only the cuts that violate cluster alignment. P1: target integrity. Every target cut is between clusters, hence between scalars. Both Ain and Bin are zero for the target by construction. This property follows from the target definition, independently of token frequency or predictor accuracy. P2: representability across encodings. Each retained scalar boundary has a direct image under ϕa, avoiding any need to remap a cut inside a scalar. For a nonempty sentence with K clusters, |T(x)| + 1 ≤K(x) ≤La(x). (1) Every target in this family is therefore representable in the encoded stream, a property that unrestricted parent cuts need not satisfy (Section 5.3). For example, the measured Odia text has 82,869 clusters and 248,774 UBE symbols. UTF-8, UTF-16, and UBE can thus represent the same target segmentation despite their different stream lengths. Vocabulary-feature transfer and the accuracy of the learned predictor remain separate questions. P3: retaining the compatible parent cuts. Let CP be the parent cut set in UTF-8 byte coordinates. The retained- parent target, denoted Tret, keeps exactly the cuts that al- ready coincide with cluster boundaries: Tret(x) = {g ∈G(x) : ϕUTF8(g) ∈CP (x)}, Nret = NP −Ain(P). (2) This is a deletion-only operation: it preserves every com- patible parent cut and neither relocates nor inserts a bound- ary. Only the surviving cuts require scalar coordinates. On the 17-language panel (Table 5), the resulting target has 0.4705 units per codepoint, compared with 0.2093 in En- glish, a ratio of 2.25×. The operation reduces the panel’s parent-unit count by 63.15% and leaves the English target unchanged. These are target counts; realized counts depend on the learned predictor. P4: invariance of position-based targets. A target de- termined solely by cluster-boundary positions is invariant, in scalar coordinates, to the span-preserving corruptions in Section 5.5. Examples include every cluster boundary and every mth cluster boundary from the start. The corruption constructor verifies equality of the complete cluster-span list; equal UTF-8 width of the substituted scalars also pre- serves offsets under UTF-8, UTF-16, and UBE. Content- dependent targets, including the retained-parent target, need not be invariant because the selection among valid cluster boundaries can change. Even for an invariant target, the learned predictor may respond differently to the edited text. Costs and interpretation. Deleting cuts both aligns and lengthens patches, requiring Stage-1 teacher representations and decoder targets to be aligned to the merged spans. A comparison that attributes a quality change specifically to cluster alignment must control for the accompanying reduc- tion in patch count. Appendix L specifies these comparison conditions. P5: the encoding determines visible boundary informa- tion. Under the released end-boundary convention, the predictor compares projections of local-encoder states hi and hi+1 to decide whether to cut after interior input posi- tion i; Appendix C specifies the BOS offset and endpoint handling. The released model satisfies three assumptions: the mLSTM local encoder is causal, vocabulary features use only suffixes ending at the current position, and the zero-temperature threshold is deterministic. Under these as- sumptions the decision is a function of the symbols through i+1, so two continuations with identical left context and the same first symbol must receive the same decision, regardless of training. For example, after a Devanagari base, vowel sign I (U+093F) extends the cluster while letter MA (U+092E) starts a new one. Both begin with UTF-8 byte E0. A target containing every cluster boundary requires opposite decisions for these continuations, which a deterministic UTF-8 predictor with one-byte lookahead cannot provide. The same ambiguity occurs for the Bengali, Oriya, Sinhala, Thai, Myanmar, and Khmer pairs in Appendix C. The obstruction applies to tar- gets that require this distinction; a subset of G(x) that omits both candidate cuts avoids it. Reproducing inherited sub- word cuts at this lookahead, which the released predictor largely does (Section 5.2), is therefore a different require- ment from recovering every cluster boundary. UBE represents these scalars with UTF-16LE symbols, ex- posing the low byte first: 3F versus 2E in the Devanagari example. Within a known 256-codepoint page, this symbol identifies the scalar and makes the distinction available at one-symbol lookahead. Different pages can still collide: U+200D ZERO WIDTH JOINER and U+090D DEVANA- GARI LETTER CANDRA E both start with low byte 0D.
