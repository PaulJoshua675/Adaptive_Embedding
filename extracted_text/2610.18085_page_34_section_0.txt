F.9 Stale Optimizer-State Checkpoint Edit The state-preserved diagnostic compares optimizer reset against a carefully co-transformed AdamW state. A second checkpoint-resume condition arises when a checkpoint is edited by an exact symmetry transform, but its AdamW moments are loaded unchanged. This mismatch can occur whenever model weights are imported, rescaled, or surgically modified while optimizer internals are treated as opaque checkpoint metadata. Design. We reuse the 31M modern RMSNorm, RoPE, SwiGLU, and GQA T5 SentencePiece WikiText-103 setting of the state-preserved diagnostic. For each of the seven paired seeds, we train the model for 5K phase-1 steps, then clone the resulting checkpoint’s model, AdamW, and scheduler states into four 2.5K-step branches: control state, surgery state stale, surgery state-covariant, and surgery state stale + Soft SAGGS. All surgery branches receive the exact λ = 0.2 all-pairs orbit edit. The stale branch leaves AdamW first and second moments in the old coordinates; the covariant branch maps first moments by the chain-rule factor and second moments by its square; the Soft branch uses the same stale optimizer state but applies Soft SAGGS at the handoff and every 50 steps. Table 13 reports the seven-seed summaries. The stale-state edit creates a small but highly consistent penalty: +0.056 ± 0.015 PPL relative to the state-preserved control over seven paired seeds, with p+ sf = 0.0078, despite an immediate handoff validation-loss change below 7.3 × 10−5. Co-transforming AdamW moments is slightly better than stale reuse by only +0.002 ± 0.001 PPL, and still remains +0.054 ± 0.015 PPL worse than control. This residual is consistent with Theorem 2: Keeping common learning rates while co-transforming moments is already insufficient for trajectory equivariance. Clipping, finite precision, and the ϵ floor can add to this effect; the contrast does not isolate their shares. Soft SAGGS removes the stale-state penalty. The stale-minus-Soft contrast is +0.062 ± 0.016 PPL over all seven seeds, with p+ sf = 0.0078, while Soft itself is −0.005 ± 0.003 PPL relative to the state-preserved control. The effect size is much smaller than in the optimizer-reset workflow of the branched checkpoint-surgery resume, but the exact checkpoint edit still changes subsequent training when moments are stale. Periodic Soft SAGGS recovers the control PPL in these runs. F.10 Partial Optimizer-State Checkpoint Edit The stale-state diagnostic treats the AdamW state as either fully stale or fully co-transformed. Real checkpoint workflows can fail in a more granular way: Optimizer-state shards may be missing or stale only for a subset of layers. This experiment tests that intermediate failure mode while keeping the forward edit exact.
