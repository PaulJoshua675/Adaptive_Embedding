I.1. Reed–Solomon decoding for OPI We use the Reed–Solomon instance and reversible decoder of Khattar et al. [13] as our baseline. Let γ be a primitive element of F212. An error word e ∈F4095 212 produces 70 syndromes Si = 4094 X j=0 ejγij, i = 1, . . . , 70. (26) This syndrome map defines a [4095, 4025, 71]212 Reed–Solomon code. The 70 twelve-bit syndromes occupy 840 qubits. Assuming the error weight is at most 35, the decoding task is to recover the error from the syndromes. Decoding proceeds in two stages: first find the positions of the errors, then recover their values in F212. The first stage packages the unknown set of error positions into a single polynomial. For each nonzero error symbol ej, include one factor 1 −γjz, giving σ(z) = Y j:ej̸=0 (1 −γjz). (27) The factor associated with position j vanishes at z = γ−j, so the roots of σ identify exactly the positions at which the error word is nonzero. The decoder’s first task is therefore to recover this locator polynomial from the syndromes. The input |s⟩supplies the first 70 syndromes, which we collect into a polynomial S(z) = S1 + S2z + · · · + S70z69.
