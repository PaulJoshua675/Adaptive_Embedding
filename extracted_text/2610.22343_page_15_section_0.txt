Table 6 summarizes their principal architectural config- urations and parameter counts. A.1.1 GEOMETRY-CONDITIONED MEMORY AND SCENE TOKENIZER Each selected GFM feature level is independently normalized and projected from 2,048 to 512 channels. The four projected features are concatenated and fused by an MLP with dimensions 2048 →2048 →512. For each spatial patch, confidence-weighted pooling of the dense point map provides a representative 3D point. Its coordinates, normalized by the scene scale, are Fourier- encoded with ten bands and concatenated with log(1 + c), where c is the pooled confidence, before projection to a 512-dimensional geometry embedding. Source-camera conditioning uses a six-dimensional rotation representation formed from the first two rotation-matrix columns and a four-band Fourier encoding of normalized translation. A camera MLP produces a 512-dimensional embedding shared by all patches in that view. The source-ray branch encodes six-dimensional Pl¨ucker coordinates with four Fourier bands and applies a convolution with kernel size and stride 16, followed by LayerNorm, to produce one 512-dimensional embedding per patch. The feature, point, camera, and ray embeddings are concatenated. A 2048 →1024 →512 fusion MLP predicts a correction to the feature embedding; their sum is normalized to form the patch memory. A bank of 512 learned queries of width 512 is updated by eight Perceiver layers, each comprising latent-to-memory cross-attention and latent self-attention. Each attention block uses eight heads, pre-normalization, residual connections, and a feed-forward network with expansion ratio four. A final LayerNorm produces S ∈R512×512. (16) In normalized scene coordinates, the ray representation is [d, ¯o×d], where ¯o is the normalized cam- era center. Query rays are Fourier-encoded with six bands and patchified by a stride-16 convolution. At 416 × 624 resolution, this produces 26 × 39 = 1,014 query tokens, which are concatenated with the 512 scene tokens to form a sequence of 1,526 tokens. The scene tokens first pass through LayerNorm, a linear projection, and two scene-only self-attention blocks. The resulting scene tokens and query-ray tokens are then processed jointly by sixteen self- attention Transformer blocks, allowing each query to retrieve view-dependent geometry from the shared scene state. Query-token representations are retained after blocks 4, 8, 12, and 16, providing multi-layer features at four stages of the decoder. These multi-layer features are subsequently processed by a DPT Feature Adapter, whose role is to transform the decoder representations into the feature interface expected by the frozen VGGT-Ω DPT head. For each level, the final query representation is fused with the corresponding intermediate representation through a learned sigmoid gate and a level embedding. Two additional Perceiver layers allow the query tokens to attend to the final scene tokens, and an independent MLP maps each level as 512 →1024 →1024 →2048. The resulting four feature maps are passed directly to the frozen VGGT-ΩDPT head to predict cam- era z-depth. The decoder receives only the scene state, query camera, and output dimensions, such that all scene information must pass through the fixed-size state bottleneck.
