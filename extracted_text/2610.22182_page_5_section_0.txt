N = VCK; each entry inherits its source image’s label. The support budget therefore counts CK labeled images, and the kernel bank contains N augmented views. The ordered query collection Q = (q1, . . . , qM) contains one deterministic view per query. Vectors are column vectors unless stated otherwise; feature matrices contain their transposes as rows. In particular, Sg ∈RN×dg and Qg ∈RM×dg contain unit global descriptors g(x) ∈Rdg. The matrix Y ∈{0, 1}N×C contains one-hot support-view labels, and T ∈RC×dg contains unit class text vectors from fixed prompts as rows. For one query q, qg = g(q)⊤∈R1×dg is its row in Qg. We write norm2 for L2 normalization of a vector and row-wise L2 normalization of a matrix. Bold symbols denote vector-, matrix-, or tensor-valued quantities; calligraphic S and Q denote ordered collections. The text matrix T defines both the initial query scores and the support scores used to form the residual target. Each CLIP score is the dot product of an image descriptor and a class text vector.
