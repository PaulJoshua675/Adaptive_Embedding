Read counts come from a sample of 726,000 fineweb-edu documents. We tokenize the sample with each model’s tok- enizer, which gives 727M–755M tokens. For each token we compute the rows it reads with our reim- plementation of the model’s address computation. The reimplementation uses each model’s per-head row offsets and table sizes, and it matches the orig- inal addresses bit for bit. We then count the reads of every row. These measurements support separating the row gain from its normalized contents in Section 4.3. D.2 Fitted codes and synthetic rank sweeps Fitted codes on trained tables. The row-level comparison evaluates the same frequency-stratified rows used for the statistical analysis, including unread-in-corpus, uniform, read-weighted and top- 4,096 sets. Fitted codebooks use 32,768 disjoint uniform fitting rows for the offline comparison and 200,000 uniform fitting rows for Qwen KL. The codebooks fitted by k-means have 256 entries of four values and 65,536 entries of eight values. Their indices require eight bits per four values and six- teen bits per eight values, respectively, giving the same two-bit code rate. Structured variants use the full-table per-head mean and top four PCs. The byte accounting includes their shared storage and all per- row side information: 16/d bpp for a bf16 scale and 64/d for four bf16 coefficients. The shared code- books and basis storage are at most 1 MB per table in these settings. For Qwen, we compare the original and com- pressed models’ next-token distributions on the same observed prefixes from 256 FineWeb-Edu documents of 1,024 tokens each. These documents come from held-out shard 001 and are disjoint from the CPU-side documents of the perturbation exper- iment below. Each looked-up row receives a de- terministic coded replacement. Intervals use 2,000 paired document-bootstrap replicates. For unequal rate points, the reported trellis-only comparison is log-linear interpolation across the 1.5-, 2- and 2.5-bit code rates. The row-level tests cover the three hashed-memory families; output KL for these variants is measured on Qwen.
