D Hypothesis Testing As we run many tests at once, some look significant purely by chance. We use the Holm correction within each group of related tests to keep the overall chance of even one false positive within that group of tests at or below 5%. We call a result significant when its Holm-adjusted p-value is below 0.05. We use the McNemar test to compare two cues within one model and language. Prompts that receive the same label under both cues carry no information about the cue, so the test uses only prompts whose label changed. It then checks whether these changes lean towards one cue more than the other. We apply it to the primary contrast, eval_explicit against deploy, on harmful and benign prompts, and to the secondary contrast, eval_log against monitor_log, on harmful prompts. Each family of 24 tests is Holm-corrected separately. We report each change as a difference in refusal rate with a 95% confidence interval from 10,000 bootstrap resamples of the prompts (Appendix J). Our null hypothesis is that, for one model in one language and one arm, the probability of refusal is the same under both cues. By using the Cochran Q Test, we extend the McNemar test to record refusal under 5 cues, for each model, language using the same prompts. The test searches for prompts whose decision changed and checks if those changes favour some cues over others. We run tests for every model and language separately on the harmful and benign prompts, and use the Holm correction within each arm (24 tests each). Our null hypothesis is that under one arm, for one model, in one language, the probability of refusal is the same under all five cues. We use logistic regression to measure how much each factor (model, language or cue) changes the odds of refusal, while holding the other factors fixed. This is expressed using an Odds Ratio. Due to the correlation between responses for the same prompt, we fit the regression with GEE, which groups each prompt’s responses together. Hence, every p-value is based on the 199 harmful (or 200 benign) distinct prompts rather than wrongly treating every response as independent. The odds ratio is the number of times higher or lower the odds of refusal are under one condition, than under the reference condition. Appendix K reports every fit. We fit the harmful and benign prompts separately, with three kinds of fit: one per model (factors: lan- guage and cue), one per language (factors: model and cue), and one pooled fit (factors: model, language and cue). Using these fits, we test: (1) Language effect per model, (2) Cue effect per model, (3) Cue effect per language, (4) Model effect per language, (5) Every Indic language vs English per model, (6) Pooled fits (model, language, cue).
