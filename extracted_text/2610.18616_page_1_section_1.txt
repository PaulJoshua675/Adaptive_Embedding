Searching text-rich knowledge graphs requires following relations while examining textual ev- idence. Predefined graph interfaces constrain what evidence agents can access, even when they write code to combine tool calls or pro- cess retrieved subgraphs. We propose direct knowledge graph interaction (DKGI), a harness in which language model agents create graph access tools directly over complete node and edge files. The agent writes Python code to follow relations, combine node sets, and select textual evidence, interleaving execution with shell search and file inspection. This lets agents process large node sets in bulk while returning selected text for the model to assess. Execu- tion feedback guides tool creation and revision, while the evolving tools determine what evi- dence the agent gathers next. On benchmark datasets spanning three domains, training-free DKGI exceeds the strongest published baseline by at least 6.7 Hit@1 points on every graph, even with a minimal harness. Controlled abla- tions show the benefits of multi-turn program- ming over shell-only access and predefined graph tools, while trajectories show agents re- vising code to extend searches or address errors. These findings highlight the value of allowing tool creation and tool use to co-evolve during graph search. Our code and data are available at https://github.com/leopoldwhite/DKGI. 1
