Let R be the reference state cloud and S the post-burn-in rollout states, standardized using reference channel means and standard deviations. For K = 64 seeded unit directions, bFR,k and bFS,k are the empirical CDFs of the projected states: c W1(R, S) = 1 K K X k=1 Z 1 0 bF −1 R,k(u) −bF −1 S,k(u) du. (18) The reference cloud retains at most 20,000 states; this calculation subsamples each cloud to at most 10,000. It measures distance to an empirical state distribution, without an exact invariant measure. Spectral distance. Spectral and segment diagnostics standardize channels using trajectories 0–7. Welch spectra use 512-point periodic Hann windows, 50% overlap, unit sampling rate, and constant detrending. Each spectrum is normalized to unit mass; px,c is the forecast spectrum and qc averages the six normalized reference spectra. The channel-mean squared Hellinger distance is H2 spec = 1 2C C X c=1 X f q px,c(f) − p qc(f) 2. (19) It lies in [0, 1] and compares spectral shape independently of total power. Correlation dimension. We estimate bdcorr from log–log slopes of empirical pair-distance proba- bilities, excluding pairs within a 30-step Theiler window. The estimator uses at most 4,096 states and 200,000 positive pair distances, taking the median slope over probability ranges [0.005, 0.05], [0.01, 0.10], and [0.02, 0.20], with 20 geometrically spaced probabilities per range. Against the dataset’s stored pooled estimate bdpool, we report ECD = bdcorr −bdpool . (20) The pooled target uses all ten original trajectories, including the test trajectory, and its own standard- ization; it is a descriptive geometric reference rather than an independent held-out estimate.
