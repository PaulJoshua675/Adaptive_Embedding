Graph-free Retrieval with Graph-Modified Embeddings Preprint B.2 Two-Hop Neighbour Blend hop2_only_neighbor_blend uses nodes at graph distance exactly two, excluding the source and its direct neighbours. It uses the same share, α, selection, and minimum-neighbour grid as the one-hop neighbour blend. The additional parameter neighbor_vectors is fixed to original: the method always averages the original embeddings of two-hop nodes. Blending already-modified neighbour vectors was deliberately not implemented because its interaction with share-based selection was not specified. Along chunk–entity–chunk paths, two hops often map a chunk to another chunk through a shared entity. The method therefore captures other texts that discuss the same entities rather than the entities themselves. B.3 Convex Neighbour Pull This anchored neighbour-attraction formulation is related to retrofitting [3], applied here to corpus-node embeddings. convex_neighbor_pull jointly adjusts node embeddings by balancing fidelity to their original textual representations against agreement between graph neighbours. A useful physical interpretation is a system of springs: each node is attached to its original position and to every adjacent node. The modified embeddings are the equilibrium of this coupled system. Objective and uniqueness. Let xi be the original embedding and zi the unknown modified embedding. Let E contain unordered edge pairs, each counted once, and let N(i) be the corresponding neighbour set. The objective is J(Z) = a X i ∥zi −xi∥2 2 + b X (i,j)∈E ∥zi −zj∥2 2. (7) Here a = anchor_weight > 0 and b = edge_weight ≥0. We use a rather than α to distinguish this penalty weight from the blending coefficient used by other transformations. Squared Euclidean distances yield a differentiable quadratic objective with linear stationarity equations. The positive anchor term makes the objective strictly convex, so its minimiser is unique. The implementation rejects nonpositive anchor weights. With a = 0 and b > 0, any embedding configuration constant within each connected component has zero energy; the minimiser is no longer unique. Closed-form coordinate update. Setting the derivative with respect to one node to zero gives a(zi −xi) + b X j∈N(i) (zi −zj) = 0, (8) and hence the weighted-average update zi ← axi + b P j∈N(i) zj a + b|N(i)| . (9) The original vector has weight a, while each neighbour has weight b. Thus, total graph influence grows with degree: the denominator is a + 3b for three neighbours and a + 60b for sixty. An isolated node remains at its original vector. Although each coordinate update has a closed form, the global solution requires solving the coupled system. 22
