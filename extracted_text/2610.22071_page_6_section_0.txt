Testing the First-Byte Bottleneck P5 establishes an information limit for specific continua- tions. We next test how this limit manifests in trained pre- dictors and natural text. The impossibility that P5 predicts for UTF-8 and UBE-BE on the pairs below holds for any deterministic predictor with this information budget; the natural-text rates characterize the trained probes. Design and metrics. We train small causal predictors with the every-cluster-boundary target T(x) = G(x) un- der UTF-8, UBE, and UBE-BE. UBE-BE preserves UBE’s routing and stream length but writes each UTF-16 code unit in big-endian order, placing the page byte first for three-byte UTF-8 scalars. All predictors use a one-layer LSTM with 512 hidden units, the same embedding-table size, and H-Net’s cosine boundary head (Hwang et al., 2026) in Bolmo’s lookahead form (Minixhofer et al., 2025), com- paring states k symbols apart (Appendix D). The probes keep Bolmo’s boundary rule but replace its mLSTM en- coder and parent-vocabulary suffix features with this LSTM. For each encoding, we train at k = 1, 2, 3 with two seeds, matching FineWeb-2 text spans within each seed (Penedo et al., 2025). For each language, training documents contain- ing one of that language’s FLORES-200 devtest sentences are excluded. Evaluation scores all predictors at the same 2,363,895 scalar ends of the 17-language panel. All evalua- tion scalars lie in the BMP, so two UBE symbols cover each next scalar. Each run takes 4,000 steps with 64 rows of up to 384 scalars, sampled from the same per-language training documents (the leading documents of each language’s first FineWeb-2 shard; Appendix D). Matching text exposure leaves computational cost unmatched because UTF-8 pro- cesses more symbol positions. The objective gives equal aggregate weight to scalar-end and within-scalar decisions. Balanced error is the mean of the missed-cluster-boundary rate and the false-cut rate at scalar ends inside clusters. To test the informa- tion limit directly, we construct a pair from each evaluation sentence with identical left context and same-page continu- ations requiring opposite decisions. A pair is correct only if both decisions are correct. The trained UBE k = 1 pre- dictors answer all 17,204 pairs correctly in each seed. For UTF-8 and UBE-BE at k = 1, the shared first symbol makes that outcome impossible for any pair, as P5 predicts. The pairs test the predicted ambiguity by construction; their frequency does not estimate its prevalence in natural text. Remaining errors. Within-scalar false cuts (0.19% of within-scalar sites for UBE at k = 1) are not an information limit: UBE-BE, with the same symbol ranges, makes few, and under all three encodings whether a position ends a scalar is a deterministic function of the encoded prefix, so a rule-based mask can remove these cuts without changing any decision at scalar ends. Cluster-internal decisions at scalar ends cannot be settled this way and are the subject of P5. Configurations that see the whole next scalar still have 0.16–0.20% balanced error at scalar ends; a post hoc analysis localizes these errors primarily to positions adjacent to zero-width joiner and non-joiner characters (Appendix D).
