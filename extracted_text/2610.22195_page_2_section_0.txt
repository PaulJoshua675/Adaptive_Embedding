HTN-Orchestrate separates result-informed task planning from local multi-agent orchestration. (a) The Planner expands ready tasks using prerequisite results and synthesizes parent results after all children return. When rebuilding is needed, supported evidence is retained to construct a new task network. (b) Each executable leaf is delegated to an Orchestrator, which dispatches workers, collects reports as they become available, and uses those reports to guide subsequent assignments and leaf synthesis. The leaf result returns to the task network for further planning and upward synthesis. mentally as prerequisite results become available, so that subsequent decomposition decisions reflect information ob- tained during execution. At the lower layer, each executable leaf subtask is delegated to an Orchestrator that schedules workers (e.g., researchers, verifiers) and uses their reports to guide investigation, verification, and synthesis. Results propagate upward through the task network under AND semantics, whereby each leaf subtask returns the result pro- duced by its Orchestrator, while each non-leaf subtask syn- thesizes its result after all its children have completed. The framework also incorporates a rebuilding mechanism that constructs a new task network conditioned on partial results from the previous epoch when execution fails or there is no plausible solution under the current task network. Our main contributions are as follows. • We propose HTN-Orchestrate, a two-layer orchestra- tion framework (Figure 1) that decouples global task planning from local subtask execution through a hier- archical task network that explicitly represents subtask hierarchies and precedence dependencies. The Plan- ner incrementally expands the network as prerequisite results become available, while each executable leaf subtask is delegated to an Orchestrator that coordinates multiple workers. • We combine result-informed planning, which defers decomposition decisions for dependent subtasks until prerequisite findings are available, with AND-semantic synthesis that propagates results upward through the task hierarchy, and a rebuilding mechanism that retains supported evidence from completed work to construct a revised task network when the current decomposition cannot resolve the task. • We evaluate HTN-Orchestrate on five benchmarks spanning web research, scientific reasoning, and re- search workflows and demonstrate that it consistently outperforms Agent Team (Apodex Team, 2026) and DeepSeek Harness (DeepSeek-AI, 2026a).
