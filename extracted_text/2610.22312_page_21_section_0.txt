B Benchmark Specification B.1 Shared conventions and read accounting The state domain and finite alphabet are those defined in Section 3.1. Each event supplies its operation and parameters. Coordinates omitted from the input list have value zero, so the list specifies the complete world. Let N1(x) contain the in-bounds coordinates at Manhattan distance one from x, and let B1(a, r) be the in-bounds Manhattan ball of radius r centered at a. Reference execution reads the current world W and produces W ′. Unless a rule explicitly specifies sequential mutation, all reads use W. Cells not selected for writing keep their values. The zero value is stored implicitly. SET(p, v) writes v at p, including zero when a cell is cleared. The canonical read list R(W, e) counts cell incidences, so repeated accesses to one coordinate can occur more than once. Its unique read support is R(W, e) = {x : x occurs in R(W, e)}. A rule also specifies a write support S(W, e): the coordinates that receive assignments, whether or not their values change. Finally, D(W, e) = {x : Ff(W, e)(x)̸ = W(x)}, (5) scan(W, e) = |R(W, e)|, (6) effect(W, e) = |D(W, e)|. (7) Thus D(W, e) ⊆S(W, e), but a large support need not produce a large effect. A SET event has scan one and effect one when W(p)̸ = v, or effect zero otherwise. Reference reads use a fixed accounting convention. Com- ponent boundary cells are counted once even if several explored cells touch them; neighborhood aggregation instead counts each incidence in a separate output sum. The definitions below specify valid rule inputs and transition semantics. Appendix B.7 gives the evaluated sampling conditions, and Appendix C.2 records the literal model-facing rule cards. B.2 Geometric selection and synchronous aggregation PAINT(a, r, u, v). For every x ∈B1(a, r) with W(x) = u, set W ′(x) = v. Other values in the ball and all values outside it are unchanged. Both u = 0 and v = 0 are valid, and u = v is a valid no-op. A radius of zero selects only the anchor. The canonical read count is |B1(a, r)|. The anchor is in bounds, r is a nonnegative integer, and both labels belong to the declared alphabet. The write support is {x ∈B1(a, r) : W(x) = u}, so selecting a ball does not imply recoloring every cell in it. The source-value predicate is true when this set is nonempty. The evaluated generator proposes only u̸ = v, making predicate truth equivalent to positive effect. Its no-op proposals select a source label absent from the ball. REFLECT(lo, hi, j). Within the inclusive box lo ≤x ≤hi, map coordinate x to x′ with x′ j = loj + hij −xj and other coordinates unchanged. Set W ′(x′) = W(x), including zero values, simultaneously for the entire box. This is a bijection, so repeating the same reflection restores the input. The read count is the box volume. A box of extent one on axis j gives an identity operation; generated reflections use at least two cells on that axis. More generally, a reflection-symmetric box can be a no-op even when that extent exceeds one. The lower and upper corners are in bounds and ordered coordinate by coordinate. Both the read and write support are the entire inclusive box, not only its occupied coordinates. Including zeros matters: reflecting a nonzero value into an empty position also clears its old position. STENCIL(a, r).
