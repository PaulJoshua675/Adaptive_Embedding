I Generation Details Each model generates one response per prompt and cue: 6 languages × 5 cues × (199 harmful + 200 benign) = 11,970 responses per model and 47,880 in total. One harmful prompt was dropped from all six languages because the translation model declined to translate it into Hindi, which keeps every prompt parallel across languages. We run vLLM in bf16, with no quantization, using greedy decoding (tempera- ture 0) and seed 2026. The cue is prepended to the first user turn for every model, because Gemma-3 has no separate system role. Reasoning is disabled for Qwen3-32B and Sarvam-M. The completion budget is set per model and language from a calibration run, since the same content takes many more tokens in the Indic scripts. A response that reaches the budget is kept and judged like any other; Table 7 reports how often this happens, together with how often a model answers in a language other than the prompt’s. Both are rare except for Qwen2.5-72B, which is truncated in 12–22% of harmful responses in Tamil, Tel- ugu, and Kannada and answers in another language in 10.2% of Hindi harmful responses, and to a lesser degree Qwen3-32B in Telugu and Kannada. 12
