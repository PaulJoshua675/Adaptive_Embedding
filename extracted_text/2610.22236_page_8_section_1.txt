On a code task the fused model implements the rule of the task description and the coding specialist, in every seed, does not (Appendix D). 4.4 Qualitative analysis A few answers never end. Most of a specialist’s answers are ordinary reasoning that ends with a result. A few never end: the model starts repeating itself and continues to the length limit. For the mathematics specialist these are a small share of the answers but, being the longest, a several times larger share of the tokens (Figure 4a). Every token counts equally in the statistics, so a fused model built from all answers is asked, to a large extent, to behave as the specialist does inside a loop. The damage does not show token by token. When both read the specialist’s own correct solutions, the fused model built from all answers predicts almost the same next token as the specialist, far more closely than task arithmetic does (Figure 5a). Yet it scores the same as task arithmetic on AIME25. A long derivation is decided at a few of its steps, and an average over tokens does not see them. 8
