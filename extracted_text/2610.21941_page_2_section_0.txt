Existing post-training approaches can be broadly categorized into four directions: adaptation, alignment, reasoning, and efficiency [12]. Such post-training approaches have also explored efficiency through model compression and knowledge distillation [13]. In this work, rather than compressing a single expert, we consolidate the knowledge of multiple specialized teacher models into a single shared speech encoder, reducing the number of deployed encoders while preserving multiple speech attributes. The resulting model replaces multiple task-specific encoders with a single backbone capable of producing semantic, speaker, language, and emotion representations. B. Learning utterance-level speech representations While self-supervised speech encoders naturally produce con- textual frame-level representations, many downstream applications require compact utterance-level embeddings that summarize an entire speech segment. Early efforts mainly focused on learning a single attribute. Semantic speech representations have received particular attention through teacher-student distillation, where speech utter- ances are aligned with multilingual sentence embedding spaces. Representative examples include SAMU-XLSR [5], SONAR [6], [7], and SENSE [8], which produce language-agnostic utterance embeddings suitable for multilingual speech-speech and speech-text retrieval. These approaches demonstrate that semantic information can be effectively transferred from powerful text encoders to speech foundation models while preserving cross-lingual generalization. Beyond semantics, several studies have investigated utterance- level representations dedicated to specific paralinguistic attributes. Speaker verification systems typically rely on speaker embeddings extracted from models such as ECAPA-TDNN [14], while language identification has similarly benefited from utterance-level embeddings trained on multilingual corpora such as VoxLingua107 [15]. More recently, speech emotion representation learning has attracted increas- ing attention, with models such as emotion2vec [16] demonstrating that large-scale self-supervised pre-training can produce transferable emotion embeddings across a wide range of downstream emotion recognition tasks. Although these representations target different speech properties, they share a common characteristic: each embedding space is op- timized independently for a single attribute. As a consequence, practical systems typically require several specialized encoders op- erating in parallel, increasing memory usage, computational cost, and deployment complexity. Only recently have a few studies begun to investigate whether multiple utterance-level representations can be jointly learned from a shared speech encoder through multi- teacher distillation [9]. These first results suggest that multiple speech attributes can coexist within a common SSL encoder, opening new perspectives for unified utterance-level representation learning. III. METHOD Figure 1 illustrates the proposed framework. A shared SSL speech encoder processes the input utterance and produces contextual hidden representations at all encoder layers. Four attribute-specific branches, corresponding to semantic content, speaker identity, language identity and emotion, independently aggregate these hidden representations through learnable layer interpolation, followed by attention pooling and a projection layer. Each branch is supervised by a frozen teacher model through cosine embedding distillation. The entire architecture is trained end-to-end while sharing a single speech encoder across all attributes. We propose a holistic multi-teacher distillation framework for learning several utterance-level speech representations with a single shared speech encoder. Let A denote the set of target attributes: A = {sem, spk, lang, emo}, corresponding respectively to semantic content, speaker identity, language identity, and emotion. Each attribute a ∈A is associated with a frozen teacher model Ta, which defines a target embedding space for that attribute. The student model consists of a shared speech foundation encoder followed by attribute-specific branches. Each branch produces one utterance-level embedding and is trained to match the corresponding teacher representation. Given a speech utterance xi, each teacher produces a target embedding ya i = Ta(xi). A. Shared encoder with attribute-specific branches The student encoder is initialized from a pretrained speech foun- dation model. Given an input utterance xi, the encoder produces a sequence of hidden representations at different layers: H(ℓ) i ∈RTi×D, where Ti is the number of frames, D is the dimension of hidden representations, and ℓ∈{1, . . . , L} denotes the encoder layer. Instead of using a fixed hidden layer for all attributes, we allow each attribute-specific branch to learn which encoder layers are most useful for its corresponding teacher. For each attribute a, we attach a dedicated branch to the shared encoder. First, each hidden layer is projected into an attribute-specific feature space: eH(ℓ) i,a = H(ℓ) i W(ℓ)⊤ a + b(ℓ) a . where the projection maps the shared hidden dimension into an attribute-specific feature space. Different speech attributes are known to emerge at different depths of SSL encoders. Lower layers mainly capture acoustic information, whereas deeper layers encode increasingly semantic information. Rather than selecting a fixed encoder layer for all attributes, we allow each branch to learn an attribute-specific interpolation over all hidden layers. To model the fact that different attributes may rely on different levels of abstraction, each branch learns a scalar score sa,ℓ for every encoder layer. These scores are converted into normalized interpolation weights using a softmax: αa,ℓ= exp(sa,ℓ) PL j=1 exp(sa,j) , L X ℓ=1 αa,ℓ= 1. The projected layer representations are then combined as: bZi,a = L X ℓ=1 αa,ℓeH(ℓ) i,a. Then a layer normalization is applied to obtain Zi,a The resulting frame-level sequence is converted into an utterance- level representation using an attribute-specific single-head self- attention module [17]: pi,a = AttentionPoolinga(Zi,a). Finally, an optional projection maps the pooled representation in order to fit to the teacher embedding dimension: zi,a = Proja(pi,a).
