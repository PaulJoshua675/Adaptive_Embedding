Motivated by approaches that shift computation across different aspects of the model training and deployment process (Lin et al., 2025; Wu et al., 2026; Suzgun et al., 2025; Zhang et al., 2025a), we study anticipatory workspace construction: the problem of augmenting and reorganizing a corpus before future queries arrive. The goal is to shift part of the costs from query time to a precomputation phase, thereby amortizing these costs across many downstream queries. To instantiate this setting, we introduce Librarian Agents, a framework built on a key asymmetry in current agentic systems: LLM agents are effective at navigating existing hierarchical filesystems, but are rarely trained to proactively construct such workspaces for future use. Librarian Agents addresses this gap by tasking a builder agent with transforming source documents into a multi-level workspace with references to the original corpus. An frozen answering agent then navigates this workspace to answer an individual user query. We formalize the builder agent’s operations as a Markov Decision Process (MDP) and directly optimize the workspace construction policy for downstream answering performance by posing it as a reinforcement learning (RL) problem on this MDP. We demonstrate the efficacy of Librarian Agents on BrowseComp-Plus, Librarian Agents improves accuracy by an average of 33 percentage points over the best performing baseline. Furthermore, for BRIGHT, a domain which our builder agent is untrained on, gains persist over baselines with an average 31 point improvement over baselines. In summary, our key contributions are: • We formulate anticipatory workspace construction as a learnable model behavior: agents should materialize useful context as an answer-facing workspace before receiving user queries. • We propose Librarian Agents, a framework where a builder agent synthesizes and organizes memory artifacts into a filesystem-based workspace for future queries. • We formulate filesystem-based workspace construction as an MDP and optimize the builder agent via reinforcement learning to improve downstream query-answering performance. • We evaluate Librarian Agents against retrieval and pre-computation baselines on BrowseComp- Plus and test zero-shot transfer on question-answering tasks derived from BRIGHT. 2.
