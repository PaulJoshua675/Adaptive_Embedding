More re- cently, several approaches directly use learned geometry representations as predictive world states. VGGT-World (Sun et al., 2026) forecasts future VGGT features, while GeoWAM (Lu et al., 2026) learns geometry-aware predictive states for autonomous driving. FR3D (Morbitzer et al., 2026) pre- dicts the latent state of a pretrained 3D reconstruction model while modeling ego-motion separately. In contrast, we remove viewpoint dependence from the geometry state itself and introduce viewpoint only as a query condition during decoding. 2.2 GEOMETRY FOUNDATION MODELS Geometry foundation models provide strong pretrained priors for multi-view 3D perception. DUSt3R (Wang et al., 2024a) formulates reconstruction through pointmap prediction, while Fast3R (Yang et al., 2025) scales joint reconstruction to larger collections of views. CUT3R (Wang et al., 2025b) introduces a persistent latent state for continuously integrating observations, and VGGT (Wang et al., 2025a) unifies camera estimation, depth, point maps, and tracking in a feed- forward architecture. VGGT-Ω(Wang et al., 2026) further strengthens this paradigm for dynamic 3D scenes, making it a natural geometry backbone for our setting. We build on its pretrained ge- ometric features and reformulate them into a compact, view-decoupled scene-level representation better suited for temporal world modeling. 2.3 COMPACT 3D REPRESENTATIONS A related line of work compresses multi-view observations into compact scene representations. LVSM (Jin et al., 2025) encodes input views into a fixed-length set of latent tokens for novel- view synthesis, while Surflo (Gu´edon et al., 2026) aggregates dense VGGT features into a fixed-size global latent representation for efficient 3D surface reconstruction. 3DRAE (Wei et al., 2026) further learns a fixed-length, view-decoupled 3D latent space that can be queried from arbitrary cameras. These works demonstrate that multi-view observations can be represented without retaining a sep- arate dense representation for each view. While they focus primarily on static scene reconstruction or novel-view synthesis, our work investigates whether such scene-level representations can serve as predictive states for temporal world modeling. 3 METHOD 3.1 METHOD OVERVIEW Our goal is to predict future scene geometry without requiring the world model to simultaneously account for variations induced by camera motion. To this end, as illustrated in Figure 1, we first con- struct a view-decoupled geometry state from multi-view observations, and then model its temporal evolution while handling camera evolution separately. GeoState learning. Given multi-view RGB observations It = {Iv t }v∈Vt, a frozen geometry foun- dation model extracts geometry-aware features Mt, with the multi-view geometry expressed in a shared scene coordinate system defined by a common anchor view. A learnable Scene Tokenizer Eϕ then aggregates Mt into a fixed-length scene state: St = Eϕ(Mt). (1) The state is not tied to any single observation viewpoint; we refer to it as a view-decoupled geometry state, or GeoState. A faithful GeoState should capture the underlying 3D scene geometry, which could be reflected in accurate and geometrically consistent depth reconstruction across different viewpoints. We therefore introduce a query-conditioned geometry decoder that reconstructs a depth map from St for a given query camera Q: bDQ = Gψ(St, Q). (2) Thus, the same GeoState can be queried from different viewpoints without re-encoding the scene. 3
