Inverted Signal Index and Ranking The second component of SSR avoids evaluating Eq. (4) over the complete registry whenever the query matches only part of it. SSR constructs the Inverted Signal Index ISI(s) = {a ∈A : s ∈Sa}, (6) and obtains the candidate set as Cq = [ s∈Sq ISI(s). (7) For every a /∈Cq, Sq ∩Sa = ∅and therefore Score(q, a) = 0. Conversely, because every IDF weight is positive, every a ∈Cq receives a positive score. Consequently, the ISI excludes only zero-scoring Agent Cards and preserves the scores and relative ordering of all positive-scoring candidates under exhaustive Structural+IDF evaluation. When fewer than K positive-scoring candidates exist, SSR returns only those candidates rather than adding zero-score Agent Cards. RQ2 verifies this positive-score ranking equivalence empirically. Candidates are ranked by descending Score(q, a), with ties resolved by descending matched-signal count and then ascending Agent Card identifier. At most the first K candidates are retained, yielding A →Cq →Pq, where Cq is the set explicitly scored after ISI lookup and Pq is the compact candidate pool presented to the LLM orchestrator. D.
