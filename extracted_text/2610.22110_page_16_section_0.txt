Multi-Variant Orthographic and Phonetic Bleed. On roots and adverbials shared across Central Nawatl varieties, the model occasionally defaults to gen- eralized Central spellings (such as yalwa and itak) rather than generating the localized Santa Ana Tlacotenco orthography with preconsonantal aspiration (yalhwa and ihtak), reflecting residual weight bias from the multi-variant base checkpoint. 3. Morphological Suffix Truncation in Future Aspect. In transitive verbal com- plexes combining directional or person prefixes with temporal adverbs (such as mustla nimitsmachtis ‘tomorrow I will teach you’), the decoder occasionally drops the final future suffix -s, yielding an uninflected or present-tense form (nimitsmachtia) despite explicit future context in the source. 7 Production Deployment and CPU Profiling A model that requires a research GPU for every query is difficult to sustain as a community-facing service. We therefore merged the selected lora_v9c_b adapter into the base checkpoint, converted the model to CTranslate2 [13], and quantized weights for int8 CPU inference. Conversion fixes one deployable artifact and removes the need to load separate adapter modules at request time. 7.1 Latency Profile Native fp32 PyTorch inference on CPU required 137.5 seconds for a representative request. This latency is unsuitable for an interactive translator and increases the period for which a billed container must remain active. On a Cloud Run allocation of 2 vCPUs and 4 GiB RAM, the CTranslate2 int8 artifact produced typical sentence latencies of 1.8 to 2.6 seconds.
