The failure initially appeared to be a quantization artifact [8], but comparisons across converted precisions showed it was precision- independent. Greedy and narrow-beam paths could terminate after a high- probability partial subword sequence even though the full form was preferred by the original evaluation setup. Increasing beam_size from 4 to 8 eliminated the observed truncations in the short-form regression set. The wider beam retained complete hypotheses long enough for the accumulated sequence score to overtake prematurely terminated candidates. This is described as beam search divergence rather than as a general CTranslate2 defect because the trigger depends on the model’s score distribution, tokenization, length normalization, and stopping behavior [14, 26]. The production API sets the beam size to 8 and runs regression probes after every model conversion. The probes include single words, morphologically long words, short clauses, both translation directions, and forms with possessive or honorific material. This test set is separate from the research test split. Its role is software validation, specifically ensuring that a numerically strong model does not become linguistically unusable after conversion. 7.3 Cloud Run Microservice Architecture The service exposes a FastAPI application within a container that includes the CTranslate2 model and the mT5 tokenizer assets. A translation request passes through four stages: 1. validate direction, input length, and Unicode text; 2. construct the direction and optional syntax prefix; 3. tokenize, decode with beam size 8, and remove model control text; 4. return the translation plus non-sensitive runtime metadata. The Cloud Run revision uses 2 vCPUs, 4 GiB RAM, and a maximum of two instances. The instance cap limits both concurrency and worst-case cost. Because model loading is expensive relative to a warm translation, the container initializes the model once at process startup rather than once per request. CORS is configured through an explicit allowlist for the web client origins that require browser access. Methods and headers are restricted to the translation interface rather than using an unrestricted wildcard in production. CORS is not authentication, so request validation, rate limiting at the surrounding platform layer, and conservative maximum input lengths remain necessary. The API does not log full translation content by default, since sentences may contain names or culturally sensitive material. 7.4 Automated Cost Controls A billing budget publishes threshold notifications to Pub/Sub.
