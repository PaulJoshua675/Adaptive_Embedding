Threshold computers. Von Neumann’s EDVAC report describes the stored-program computer with McCulloch–Pitts elements [2]. Goto’s parametron computes the majority of three inputs, an in- put inverted by reversing the polarity of its coupling [29], so parametron circuits are networks of ternary threshold units; MUSASINO-1 [30] and PC-1, of about 4,200 parametrons [31], were stored-program machines built from them, and DONUT a general-purpose computer of about 500 threshold gates [32]; see also [16]. Weighted threshold circuits of depth d are simulated by majority circuits of depth d + 1 [33, 34, 35], and Remark 5.5 is the smallest instance of that exchange. Networks as programmable computers. Recurrent networks of saturated-linear units with ra- tional weights are Turing-universal [36, 37], and programs have been compiled into neural net- works [38, 39]. A looped transformer with fixed weights executes SUBLEQ programs placed in its input [40], as does a looped ReLU perceptron [41]; a fixed transformer simulates any transformer of a class from a description in its input [42], and Loom executes compiled C programs in a looped transformer whose state holds the program [43]. A programmable neural network, a fixed-weight network with auxiliary inputs, behaves as any network of a class when those inputs carry a code of its weight matrix [12]. These use real-valued weights. The ring machine is a fixed ternary network of this kind, which evaluates any network stored in its state. Valiant’s universal circuits simulate any circuit of size n from its program bits in size Θ(n log n) [11], and intrinsic simulation between automata networks [44] builds the simulating network from the simulated one; here the simulating network is fixed.
