7 Model development and iteration We developed the pipeline on diarrhea, our development set, because expert annotation of all 18 phenotypes across every patient would be prohibitively slow, the bottleneck this pipeline relieves. The architecture was settled first, by a comparison of six extraction strategies on this development set that selected the dual-model consensus gate. Holding it fixed, we then ran that consensus configuration under five classification prompts differing only in what they count as diarrhea, alongside two rule-based methods that bound the comparison from below (Table 2). Prompt wording, the architecture comparison, and the identifiers these methods carry in the released code are in Supplementary Notes S2, S3, and S7. We selected the reported prompt on the same 183 cells we score it on. Its diarrhea accuracy is therefore an in-sample upper bound rather than a held-out estimate. The evidence that the design generalizes comes from the other 17 phenotypes. We froze the pipeline after the diarrhea work and applied it to them with only the phenotype definition substituted (Results; Supplementary Note S2). Ethical considerations This study was conducted under IRB protocol H-52222 at Baylor College of Medicine / Texas Children’s Hospital. All data remained within the institutional secure computing environment, and LLM inference was performed in-environment under enterprise data-governance controls. RESULTS Contextual reasoning improves performance and outperforms keyword matching We evaluated seven methods of increasing specificity on the identical 183-cell ground truth (Table 2). The severe-diarrhea prompt performs best. Accuracy rises with the severity threshold the prompt sets, and the severe-diarrhea prompt (Claude Opus 4.6) performs best on every headline metric except recall: 84.2% accuracy, precision 0.714, F1 0.674, κ 0.570. This is 47 percentage points over the regular-expression baseline (37.2%, indiscriminate over-flagging) and 42 points over negation-aware NLP (42.1%). Both restrictions help. Requiring diarrhea to be uncontrolled improves on counting any documented mention (79.6% against 75.2%), and stating that restriction as an explicit severity bar raises accuracy to 84.2% via precision (0.596→0.714), as the bar converts nine false positives into true negatives at the cost of one true positive. How strong is this evidence? We then asked whether these differences are real or only directional, testing each comparison with McNemar’s exact test and Holm-correcting across a pre-declared family of seven prompt comparisons (Supplementary Table S4). The reported prompt beats both rule-based methods decisively (p < 0.0001), and every prompt sits far above them on accuracy. None of the prompt-to-prompt comparisons reaches significance. The severe-diarrhea prompt wins 9 cells against the uncontrolled-diarrhea prompt the pipeline was originally deployed with (row 5 of Table 2) and loses 1, which is p = 0.021 before correction and p = 0.15 after, so it is the top of a sweep rather than a demonstrated improvement. With 183 cells and a gap of roughly 8, this cohort is too small to resolve differences of that size.
