Fashion retrieval is inherently set-valued and graded. A query such as “lightweight cotton kurtas for summer” con- strains multiple attributes, including product type, material, and season, and many catalog items may satisfy these con- straints to different degrees. Relevance is therefore compo- sitional: an item may match some attributes while violating others. A single aggregate ranking score can hide these dif- ferences. For example, two systems may achieve similar nDCG while one retrieves the correct garment in the wrong color and the other retrieves the correct color for the wrong garment. Evaluating such systems requires relevance labels that are set-valued, graded, and decomposable by attribute. Existing fashion benchmarks do not provide these prop- erties. Manual fashion retrieval datasets typically associate a query with a single target item [22, 51], penalizing other valid results. Graded set-valued annotations are possible, but expensive: ESCI contains 2.6M judgments for 130K queries [34]. Moreover, manually collected labels are tied to a particular catalog snapshot and query distribution. Au- tomatic assessment using language models [44] removes annotation cost, but typically produces an independent rel- evance score for each query–item pair and does not iden- tify which query attributes are satisfied or violated. These approaches also treat items independently, overlooking the relationships among products in the catalog. We instead observe that the catalog itself contains the structure needed to define relevance sets. Recent re- trieval and recommendation systems such as DSI [40], RI- POR [55], and TIGER [32] represent items using sequences of discrete codes learned with residual quantization [19].
