The Right Byte First E. Korean and Chinese Boundary Extension Scope and targets. Designed after the original probe, this exploratory extension examines boundary prediction in Korean and Chinese. Both targets and all 36 runs are reported, with no checkpoint or condition selected by evaluation performance. The every-cluster target is G(x); the retained-parent target keeps Qwen3 cuts at those cluster boundaries and deletes all other cuts. The retained target represents inherited subword supervision, not Korean morpheme or Chinese word annotations. Targets are computed from full-document tokenizations and grapheme segmentation before sampling rows, preserving the original context rather than retokenizing cropped spans. Data and training. For each language, we retain whole documents from the first FineWeb-2 shard until the NFC text reaches at least 8 million UTF-8 bytes. FineWeb-2’s Mandarin Han-script source, cmn_Hani, is not restricted to simplified characters; evaluation uses FLORES-200 Chinese (Simplified), zho_Hans. Korean uses kor_Hang in both corpora. Any training document containing an evaluation sentence from either language is dropped. The corpus revision, NFC normalization, grapheme library, and Qwen3 tokenizer match the pinned artifacts reported in Appendix M. Each predictor has a 513-entry, 128-dimensional embedding, a one-layer 256-unit LSTM, and the original probe’s cosine head, totaling 592,512 parameters in every condition. Training runs for 2,000 steps with 32 rows per step. Rows begin at uniformly sampled cluster starts in a uniformly selected language, with up to 128 supervised scalars and three additional scalars for lookahead. We use float32 throughout and retain the original probe’s AdamW optimizer, learning rate, schedule, clipping, and two-term loss. Text spans are identical across targets, encodings, and lookahead settings within each seed. The design therefore matches text exposure and parameter counts while allowing symbol counts and FLOPs to differ. As in the original probe, UBE-BE changes the encoded history as well as the lookahead symbols. All evaluation scalars lie in the BMP, so UTF-8 at k = 3 and UBE or UBE-BE at k = 2 see the whole next scalar on these texts. Evaluation and uncertainty. We evaluate all 1,012 devtest sentences per language in separate forward passes. The primary metric sums missed target cuts, false cuts at scalar ends, and false cuts inside scalars, then divides by the original scalar count and multiplies by 1,000. Sentence-final scalar ends are excluded from the error count; positions inside the final scalar are included. Using the original scalar count keeps the denominator independent of the number of available cut sites under each encoding. Supporting missed-boundary and scalar-end false-cut rates (Table 20) use their respective positive and negative site counts. F1 includes within-scalar false cuts, whereas the cluster-split rate counts each affected cluster once. Reported values average per-seed ratios; the “Mean” column in Table 2 then weights the two languages equally. Contrasts use 2,000 paired source-sentence bootstrap draws, shared across parallel translations, seeds, and conditions. Neither NFC evaluation set contains a multi-scalar cluster, so every evaluated scalar end is a grapheme boundary. The every-cluster target consequently has no negative scalar-end class, making balanced error undefined.
