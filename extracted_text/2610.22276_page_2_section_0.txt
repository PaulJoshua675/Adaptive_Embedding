Spatial intelligence involves perceiving and reasoning about the geometry and spatial relationships of objects, which enables agents to navigate their surroundings and interact with the physical world (Chen et al., 2024; Cheng et al., 2024). Many of these interactions require timely spatial judgments. Vision-language models (VLMs) support these capabilities by answering spatial questions grounded in visual observations. Such questions may require selecting an option that describes a spatial relation (Ray et al., 2025; Tong et al., 2024; Fu et al., 2024; Yang et al., 2026), estimating a numerical quantity such as distance (Cai et al., 2026; Yang et al., 2025a,b), or identifying a point for object placement (Zhou et al., 2025a; Yuan et al., 2024; Song et al., 2025; Cheng et al., 2025). To produce these spatial predictions, many existing VLMs retain their pretrained autoregressive text- generation capabilities (Chen et al., 2024; Cheng et al., 2024; Deitke et al., 2025; Yuan et al., 2024; Zhou et al., 2025a). Each option, numerical value, or image location is therefore represented as a token sequence that the model is trained to reproduce. This couples learning the spatial answer with learning its textual form, including formatting and boilerplate when present, introducing supervision beyond the task-relevant prediction itself. At inference, the model must generate the answer tokens sequentially, after which the resulting text must be parsed to recover the spatial prediction, adding decoding and parsing overhead. This motivates a System 1 approach to spatial understanding: using pretrained visual and linguistic knowledge to make spatial judgments directly. Jev provides a precedent for this approach by returning probabilities over specified candidates without generating answer text (TypeSafe AI, 2026). At the same time, we observe that all three common spatial output types can be represented as finite candidate sets: answer options are already finite, while numerical values and image locations can be discretized within a specified range and resolution. Building on these insights, we introduce MJev-Spatial, a multimodal decision model specifically tailored to spatial understanding. MJev-Spatial unifies the three output types by casting prediction as classification over finite candidate sets. Each class represents a supplied answer option, a numerical bin, or an image region, depending on the task. Selecting a class gives the chosen option, predicts which bin contains the target value, or predicts which region contains the target point. To choose among these classes, MJev-Spatial encodes their descriptions together with the observation and question, then reuses the final attention layer’s pretrained query and key projections to compute class scores. A softmax over these scores gives the class probabilities, without additional prediction heads or trainable parameters. At inference, each classification decision scores all its candidates in one forward pass. Furthermore, to obtain fine-grained values and coordinates without evaluating a large number of classes at once, we subdivide the selected numerical bin or image region and classify again. Numerical prediction uses up to two stages; single-point prediction uses three stages, re-encoding the selected image crop before each later decision to recover local visual detail. The final selection is decoded to a numerical value or image coordinates. Conditional tree expansion evaluates multiple region paths to extend the same trained point predictor to multiple points without additional training. Numerical and point prediction can require multiple supervised stages, with new image crops introduced between point decisions. Ground-truth answers determine the target classes and crops, allowing all stages to be jointly supervised in one teacher-forced causal forward pass. We average the stage cross-entropy losses per question so that a multi-stage example does not receive greater weight than a one-stage choice. Global length grouping and cross-GPU load balancing address the padding and workload imbalance caused by different sequence lengths and crop counts while preserving optimizer-batch membership. An audited conversion pipeline supplies 12.3M QA from existing spatial annotations for full-parameter training of the retained language backbone. Built on Qwen3.5-4B (Qwen Team, 2026), MJev-Spatial achieves the highest overall score among eight eval- uated models, leads on seven benchmarks, and outperforms its unmodified autoregressive base model on all twelve. Across all twelve benchmarks, it achieves 2.5× and 5.6× speedups over the fastest autoregressive baseline and the base model, respectively. Separate studies examine candidate scoring, visual refinement, numerical discretization, and training execution. The readout and refinement studies assess how candidate scoring with pretrained projections and crop re-encoding contribute to prediction quality and computational cost; the numerical study shows that coarser length discretization can reduce prediction error despite its lower resolution.
