Gaussian Approximation, which replaces P(w | D) with N(µ, Σ), performs below Standard. Since Informed Prior builds on this same summary, its advantage stems from the block-wise modification of N(µ, Σ). Misidentified Underspecified Features When one or more well-optimized features are predicted as underspecified, there is a gap at K = 0 between Informed Prior and Oracle Prior (e.g., table in Fig. 5c). This gap carries over into the averaged curves, as in Coffee with one underspecified feature (Fig. 3c). If a feature ϕl is incorrectly deemed underspecified, its prior moves into the underspecified block, so its prior-anchored mean is zero despite w⋆ l̸ = 0. This degrades the top-k selection until preferences supply enough information to substitute for the removed signal. Effect of Explanations Informed Prior + Informed Exp and Oracle Prior + Oracle Exp track their non-explanation counterparts with two underspecified features (Fig. 3b, Fig. 3d), but peak at small K and then decline with one (Fig. 3a, Fig. 3c). Standard + Oracle Exp plateaus below Standard in all four settings. As preferences accumulate, the posterior of wu tightens and ∥wu∥grows beyond the value of 0, causing ∥wo∥to contract under the constraint ∥w∥2 ≤1. Learning from explanation- guided queries quickly recovers information about ϕu, but collects no information about balancing against the originally optimized ϕo. For Standard + Oracle Exp, explanation-guided responses additionally carry no direct information about wε, so the spurious weights in P(w | D) are never directly corrected.
