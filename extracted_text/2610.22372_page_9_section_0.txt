Q3: Learning Efficiency. This question evaluates how data scale affects learning efficiency under the same task and preference distribution. In Figure 4, the blue curves show in-domain scaling as the number of training demonstra- tions increases. At the 2.25K scale, L1-L4 isolate data-composition effects under a comparable budget. L1, L2, and L3 use K = 2, K = 3, and K = 5 layouts, respectively, trading off layout diversity against demonstrations per layout. L4 uses the same K = 3 layout setting as L2 but adds matched no-preference missions, testing whether no-preference data helps decouple preference-conditioned behavior from task/layout cues. Finding. Across all data scales, in-domain preference-conditioned behavior is learned consistently well. For in-domain preference learning, increasing layout diversity is more effective than simply increasing the number of demonstrations. Notably, adding matched no-preference data further improves learning even without increasing layout diversity, suggesting that such data helps decouple preference-conditioned behavior from task/layout-specific cues. Figure 4 provides detailed evidence for these observations. First, the in-domain SR and SA curves are closely aligned across data scales, indicating strong in-domain preference learning: successful executions usually also satisfy the specified preferences. Second, at the fixed 2.25K scale, L1-L3 use the same demonstration budget but increase the number of layouts, and the improvement from L1 to L3 shows that broader layout coverage is more effective than denser demonstrations within fewer layouts. Third, L4 uses the same layout setting as L2 but adds matched no-preference missions; its improvement over L2 suggests that no-preference data benefits learning beyond increasing layout diversity, likely by helping separate task execution from preference-conditioned behavior. Q4: Generalization. This question evaluates two forms of generalization: task-and-layout gener- alization, where either the task or layout changes, and preference-level generalization, where both tasks and layouts change while the preference remains unchanged. In Figure 4, the red curves denote unseen-layout generalization, and the green curves denote unseen-layout-with-different-task generalization. Both settings use the same L1-L4 controlled comparisons at the matched 2.25K scale. Finding. Preference-conditioned behavior is consistently learned across settings, but jointly achieving task success and preference satisfaction remains challenging under generalization. Unseen-layout generalization benefits from increased data scale, whereas generalization to both unseen layouts and different tasks remains limited. As shown in Figure 4, SR and SA are closely aligned within each setting, suggesting that successful executions usually also satisfy the specified preference. However, under generalization, especially unseen-layout-with-different-task, both metrics remain much lower than in-domain performance. This indicates that learning preference-conditioned behavior is easier than executing it successfully together with the task under new task-layout combinations. 9
