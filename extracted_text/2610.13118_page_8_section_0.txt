3.2 Signal The signal was modeled after the emitter and receiver of the Webots e-puck. It is a single bit with no content. At each control step, the robot decides whether or not to emit. The receiver knows whether its partner emitted, from which direction the packet arrives in its own frame of reference, and with what strength, which decays with the square of the distance. As in Webots, a packet sent in one step arrives in the next, and the range is unlimited. This signal does not indicate the location of the food. A receiving robot only knows that its partner emitted the signal and from where. Whether the signal becomes associated with food or anything else depends entirely on evolution. 3.3 Control Architecture 3.3.1 Recurrent network with residual path (Res-GRU) Each robot is controlled by a recurrent network with 16 GRU units [17] and a residual input- to-output connection (Figure 2). The network receives 17 inputs. The eight proximity readings are log-transformed and scaled between 0 and 1, and the three ground readings are scaled so that 0 corresponds to the floor and 1 to the food. The signal itself carries a single bit, but the receiver perceives how it arrives. Four inputs encode this percept: a reception indicator, the sine and cosine of the bearing from which the signal arrives, and its normalized strength. The sine and cosine represent the bearing without the discontinuity of an angle at ±180°. All four inputs are zero when no signal is received. The two remaining inputs are the motivations of fear and hunger. The GRU layer follows the standard equations. The reset gate r controls how much of the previous state enters the computation of a candidate state h̃(t), and the update gate z controls how much of the state is replaced by that candidate, so that h(t) = (1 - z) h(t - 1) + z h̃(t). In Cho et al. [17] the roles of z and 1 - z are swapped, which is equivalent to renaming the gate. The output layer sums the contribution of memory and the residual pathway, which directly connects the inputs to the outputs. This pathway allows for reactive responses that do not depend on memory. The network has four outputs. The first two, with hyperbolic tangent activation, set the speed of each wheel as a fraction of the maximum. The third output determines whether the signal is emitted. The signal is transmitted when this value is positive. The fourth, with sigmoid activation, provides the control bid that is only used within EASA. In total, the network has 1,768 parameters.
