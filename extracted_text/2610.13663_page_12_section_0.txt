Evaluation protocol Run budget and thresholds. The specified run budget (50 for the PINN tasks and 250 for the SNN tasks) counts only successful iterations; see Section 3.1 for the iteration steps. The target metric threshold (accuracy above 90 % for MNIST and 93 % for Digits; a decrease in Relℎrelative to the baseline for the single-soliton GNLSE problem, a decrease in Resbvp and Rel𝑖for the GNLSE problem with a Gaussian perturbation, and a decrease in Resbvp for the Kuramoto–Sivashinsky problem) provides a reference point for the analyst but is not a stopping criterion. Each hypothesis is evaluated with three random seeds in the single-soliton problem and with a single seed in the remaining two PINN problems, where one training run takes tens of minutes. Compared configurations. In both GNLSE problems, the baseline with identity 𝐹𝐼, 𝐹𝑂transformations is compared with three agent configurations: Perplexity Sonar (sonar-pro) Perplexity AI (2026), Qwen3-30B-A3B-Instruct-2507 (qwen-qwen3-30b-a3b-instruct-2507) Qwen Team (2025), and Claude Opus 4.6 (anthropic-claude-opus-4.6); the Analyst prompt is the same for different LLMs. Because a complete agent run for the Kuramoto–Sivashinsky problem is computationally expensive, we evaluated only Claude Opus 4.6, which produced the best results on the other tasks. The comparison for this problem is therefore limited to the Claude configuration and its baseline; different LLM models are not compared with one another. The Qwen3-30B-A3B-Instruct-2507 weights Qwen Team (2025) were downloaded from the model’s public repository. In the classification tasks, pairs ⟨language model, prompt⟩ are compared: Claude Opus 4.6, Perplexity Sonar, and Qwen3-30B-A3B-Instruct-2507, each with the simple and detailed prompts defined in Section 4.3; the baseline is an argmax decoder based on the output spike rates of the LIF neurons. In the single-soliton problem, Relℎis the final characteristic of a hypothesis; the best Relℎ(mean over three internal seeds) is reported. In the GNLSE problem with a Gaussian perturbation, hypotheses are ranked by the conservation error Rel𝑖, while the boundary-value-problem residual Resbvp (4) is reported alongside it. The robustness of the best configurations was additionally tested using repeated runs (Appendix D). In the Kuramoto–Sivashinsky problem, hypotheses are ranked by the boundary-value-problem residual Resbvp (7), and the mass drift Δ(𝑢) 𝑚(8) is reported as an independent physical diagnostic. In the classification tasks, the target metric is test accuracy, but during a run accuracy is evaluated on a validation set formed from the training set so that test-set accuracy is not entered in the experiment log. To assess the effect of prompt structure, 10 complete runs, each comprising 250 iterations of agent search, were performed for every configuration. Two paired comparisons were performed for each of the three models: the simple prompt was compared with the full detailed prompt, and the detailed prompt with a coverage map was compared with its ablated version without the map. Each comparison comprised ten matched pairs of complete agent runs. Within each pair, the same trained SNN instance and identical output spike data were used, so differences between configurations were evaluated from paired differences in the maximum accuracy achieved.
