A d-bit format admits 2d bit patterns, exactly 2d−1 of which carry a zero sign bit, and every positive value is one of those, so |V| ≤2d−1 and log2|V| ≤d −1. This gives Equation (14). The per-entry bound using log2|V| is attained when the positive values are uniform over V; the looser bound using d −1 is strict for actual floating-point values. Remarks. Lemma B.1 separates the three relaxations that Equation (14) permits. The support need not be full: |V| may be smaller than 2d−1 if some bit patterns are never produced. The positive values need not be uniform. Individual entries need not be independent, and subadditivity charges no penalty for dependence. Each relaxation can only lower the entropy, so the uniform, independent model of Assumption 2.1 is the worst case for compression and therefore a valid reference rate. The bound is in fact strict. Zero is itself one of the 2d−1 patterns with a zero sign bit, so |V| ≤2d−1 −1 and log2|V| < d −1; formats that reserve patterns for infinities or NaN have still fewer finite positive values. The reference entropy in Theorem 2.2 therefore exceeds the actual tensor entropy by at least L(1 −ρ)  (d −1) −log2|V|  . This gap is exact when entries are independent and their positive values are uniform over V; nonuniformity or dependence can increase it. The corresponding per-entry gap omits the factor L.
