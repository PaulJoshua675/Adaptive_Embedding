Stage 3: Event-Centric Quality Control. To ensure the quality of the curated data, we introduce an aligned event hit mechanism for the automatic validation of refined descriptions. Specifically, we employ Gemini-2.5- Pro to extract timestamp-grounded audiovisual event tuples directly from raw videos. We then input all event tuples together with refined descriptions to GPT-4.1 [1] to verify whether each event tuple is hit in the caption. An event hit requires both audio and visual events to be entailed with consistent temporal synchronization. This process jointly assesses the accuracy of audiovisual synchronization and event attribution in captions. We discard samples with an event hit ratio below a threshold of 0.8. In this way, we build a large-scale audiovisual caption dataset, EVA-Data, which provides high-quality event-level supervision for event-centric post-training. 3.1.2 Data Statistics To guarantee both diversity and quality, we collect 100K audiovisual videos (each under 200 seconds in duration) from LLaVA-Video [58], FineVideo [9], and Shot2Story [14].
