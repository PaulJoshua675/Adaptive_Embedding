Any output vector splits as protected-plus-free, I = PU + QU, and likewise any input, I = PV + QV . Inserting these identities on the left and right of ∆W decomposes any update into four blocks, one per (input-side, output-side) combination: ∆W = PU∆WPV | {z } (1) protected→protected + PU∆WQV | {z } (2) free→protected + QU∆WPV | {z } (3) protected→free + QU∆WQV | {z } (4) free→free . (2) Freezing the top directions therefore means keeping only block (4) and discarding (1)-(3) from the update ∆W. Keeping only block (4) is exactly the two-sided projection of Eq. 1, which we restate: Π(∆W) = QU ∆W QV = (I −UkU ⊤ k ) ∆W (I −VkV ⊤ k ). (3) In particular, the updated matrix Wref +Π(∆W) acts identically to Wref on every protected input direction and produces no new component along any protected output direction: the protected singular triplets (σi, ui, vi), i ≤k, are preserved exactly. Any of blocks (1)-(3) would break this, which is why the projection must be two-sided. We fix k = ⌊r · min(dout, din)⌋with a rank fraction r close to 1 so only the low-energy tail is free, and compute Uk, Vk from Wref, the weights at the start of training (the anchor that refresh later updates, Sec. 2.3). 2.2 Projecting the Optimizer Update SST applies Π to the optimizer’s final update ∆W. The projection could instead act on the gradient before the optimizer, either alone or together with the applied update. These choices are not equivalent. For plain SGD, whose step is a scalar multiple of the gradient, projecting the gradient and projecting the update coincide. Under Adam and other stateful optimizers they differ. Adam rescales each coordinate by its running moments, and this diagonal preconditioning does not commute with Π, so a gradient confined to the free subspace can still produce an applied update with a component in the protected subspace. We compare three possible enforcement points (full equations in Appendix B.8): (1) Project the gradient: apply Π to the raw gradient before Adam, g ←Π(g). (2) Project the applied update: let Adam update its moments from the full gradient, then apply Π to the step that Adam produces (this is what SST does). 4
