Graphics. On the graphics track, the agent authors either a Shadertoy-style GLSL fragment shader (with optional multipass feedback buffers) or a moderngl Python program defining setup and per-frame render routines, while the harness injects standardized headers, uniforms, outputs, and brief-matched reference recipes (Figure 13b). Sequences are rendered at t ∈{0, 1, 2.5, 4, 6} s (clipped to the loop duration) at 1280 × 720 resolution. The deterministic frame gate measures luminance distribution, colourfulness, edge density, inter-frame motion, and pixel validity: NaN, all-black, or overexposed frames trigger hard errors, while static or flickering sequences trigger score-capping warnings. The judge evaluates multi-frame montages paired with frame telemetry, and each refinement round dispatches a unified whole-program optimization task. A.9 SKILLS The authoring skill library (§3 and §4) comprises seventeen modular bundles in the open agent- skill format, each pairing a concise instruction sheet with a code reference file bounded at 350 lines and ≈2,500 tokens (Table 4). A 28-rule routing table dynamically selects up to five highest- priority bundles per session through two complementary mechanisms: standing routes, which match the active track, runtime language, session role, and planned structural features, and diagnostic routes, which trigger on specific gate findings from the preceding round (for example, attaching threejs-shader-traps whenever the shader preflight gate fires). 21
