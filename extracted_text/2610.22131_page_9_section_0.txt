Local inference latency Local measurements use one RTX 4090, BF16, SDPA, the native Hugging Face backend, Transformers 5.14.1, and flash-linear-attention 0.4.2. Known-distribution calibration pilot The known-distribution calibration test set constructed in Section 4.2 contains 96 cases across six categories. It evaluates complete outcome distributions against exact reference probabilities. The question wording requests an outcome, while the native decision interface returns a probability for every listed option. Intern-Decision maps the ordered options to legal answer tokens and applies the candidate softmax in Equation 3; Jev supplies its native API probability map. We score these complete distributions, rather than converting a selected label into a one-hot vector or counting how often repeated sampled answers occur.
