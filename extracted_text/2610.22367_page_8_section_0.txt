For example, coset representations can make modular addition cheaper by encoding each residue as a superposition of congruent integers, which avoids conventional comparisons and corrections at the cost of an exponentially small error [17, 18], but such encodings lie outside the present framework. More generally, the task boundary, input distribution, data representations, and accuracy target make a search well posed while also encoding assumptions about how the circuit is embed- ded in a larger algorithm (in particular, which states it receives and how its outputs are consumed). The same choices that bound the search also make re- liable programmatic feedback possible: they specify what each candidate must preserve and which resource trade- offs the evaluator should reward. Within these boundaries, our results show that evaluator-guided LLM search can go beyond refining a fixed circuit to uncover new reversible algorithms and representations. Related approaches have produced new algorithms in combinatorics and linear alge- bra [19, 20]. These observations suggest a practical crite- rion for extending the approach: wherever a problem ad- mits a sufficiently expressive task interface and its correct- ness and resource costs can be evaluated cheaply enough to sustain many rounds of search, the same evaluator- guided search may provide a route to new algorithms. These results, together with related progress in rein- forcement learning and LLM-guided discovery of quan- tum error-correcting codes and encoding circuits [21–23], create an opportunity for end-to-end co-design of fault- tolerant computation. Choices that are usually made separately—the algorithm and its logical circuit, the error-correcting code and its method for universal logic, the supply of magic states, and the physical execution architecture—strongly determine one another’s costs. A programmatic evaluator that propagates logical errors, resource demand, and hardware requirements across these layers could allow an LLM search to redesign them to- gether, potentially discovering fault-tolerant algorithms and architectures that cannot be found by optimizing each layer in isolation.
