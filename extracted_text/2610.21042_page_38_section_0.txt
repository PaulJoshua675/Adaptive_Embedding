Coding rules • Lassa written by the Prompt Agent REVIEW CODING PROTOCOL Code what the paper's own work represents, not topics mentioned only in background or cited work. For array fields, code every applicable option represented across the paper's models. Model type - Use [] when the paper has no dynamic transmission model; a statistical prediction or qualitative analysis is coded Other only if it is itself a dynamic transmission model and no named type fits. - Phenomenological growth models and other dynamic transmission models that do not fit Compartmental, Branching process, or Agent / Individual based are coded Other. Code available - Code True when the paper provides code or identifies an accessible repository or archive containing code or scripts for at least one dynamic transmission model; a data-only repository or a statement that code exists without an available location is False. Transmission route - Code a route only when the paper's model represents it; background statements or citations about transmission routes do not qualify. - Transmission from rodents or other animal reservoirs to people is coded Vector/Animal to human; modeled person-to-person exposure through blood, body fluids, secretions, or excretions is coded Human to human (direct contact), and modeled sexual transmission is coded Sexual. - Modeled airborne transmission or close contact not specified as a more direct route is coded Airborne or close contact; code each route when the model explicitly represents more than one. Interventions type - Code an intervention only when the paper's model represents it as an intervention; background discussion or cited examples of control measures do not qualify. - Isolation or quarantine of people is coded Quarantine; patient care or medication is coded Treatment, while modeled hospital care or care in dedicated treatment centres is coded Hospitals or Treatment centres, respectively. - Rodent trapping, food protection, sanitation, or similar measures are coded Vector/Animal control when the model represents them as measures to reduce animal-reservoir exposure; vaccine campaigns or vaccine baiting are coded Vaccination. - A contact rate, seasonal reservoir dynamic, or saturation term is not an intervention unless the model ties it to an implemented intervention. - An explicitly modeled intervention not covered by Vaccination, Quarantine, Vector/Animal control, Treatment, Contact tracing, Hospitals, Treatment centres, Safe burials, Behaviour changes, Wolbachia replacement, Wolbachia suppression, Genetically modified mosquitoes, Mechanical removal of breeding sites, Pesticides/larvicides, Insecticide-treated nets, or Indoor residual spraying is coded Other.
