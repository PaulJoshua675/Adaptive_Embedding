The neural network acts as a parallel adap- tive feedforward compensator, such that the to- tal applied control effort is uk = ubase k (xk,xref ) − g(xk,xref ,θ). The system undergoes a three-phase deploy- ment (visually mapped in the experimental strat- egy of Figure 2): 1) Calibration (Phase 1): A baseline Proportional-Derivative (PD) controller (Kp = 0.60,Kd = 0.25) stabilizes the system to track a low-amplitude calibration sine wave (xref = 0.3sin(πk/15)) over a constrained dataset of N = 150 discrete samples. The plant is subjected to continuous Gaussian process noise wk ∼N (0,0.0252). Because the state magnitude remains small, the cubic term Bx3 k is negligible, leaving the nonlinearity hidden from offline identification. 2) Deployment (Phase 2): An offline neural net- work is trained on the Phase 1 residuals. The system is then tasked with a large-amplitude reference trajectory pushing the state into the unmapped nonlinear regime. 3) Online Adaptation (Phase 3): The network’s weights are “unfrozen” and continuously updated online via standard Backpropaga- tion. To re-establish Lyapunov stability, the gradients are bounded via clipping to enforce time-scale separation. To isolate the necessity of time-scale separa- tion and gradient bounding, we perform parallel ablation studies on the Phase 3 online adaptation mechanism. To validate the proposed taxonomy, we calculate the three errors: 1) Identification Error: Evaluated offline, this represents the divergence between the network’s prediction and the unmodeled dynamics over the calibration dataset Dof f . We quantify the estimation bias using an Estimated Bias Proxy inspired by Instrumental Variable techniques, computing the ratio of the network output’s Pearson correlation with the noisy baseline control to its correlation with the clean reference signal: Proxy = |ρ(gθ,ubase)|/(|ρ(gθ,xref )| + ε). In our evaluation, this yielded 0.041. The variance explained by this noise correlation provides an expected lower-bound on the phys- ical bias (the “Ghost Variance”), calculated as Varghost = ρ(gθ,ubase)2 · Var(gθ). This represents the footprint of the unmeasured noise that the neural network has internalized, confirming it mapped closed-loop artifacts rather than the deterministic plant dynamics. 2) Action Error (Generalization Gap).
