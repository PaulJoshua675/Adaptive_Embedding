Taken together, the theoretical analyses of sections 3.1 and the experimental illustrations show that even if two activation functions can be mapped, the models learn different features and end up in different configurations after learning. In the DeNN, the synaptic parameter (the delay) is mostly influenced by short-term dynamics, while the neuron parameter, αh j , is mostly influenced by long-term dynamics. This allows the model to learn temporal repre- sentations on different timescales. On the other hand, the ANN defined in section 2.2.1 has the same encoding (up to a minus sign) and the same decoding, which are temporal in our definitions. Lacking a true temporal represen- tation in its activation function (and thus a lesser degree of temporal representation), we expect this model to show poorer performances on a temporal dataset. Indeed, because the time variable isn’t explicitly manipulated in the ac- tivation function, its gradient is mostly spatial, and doesn’t show the variety of temporal ranges that occur in the DeNN. 4.2 Performances on benchmark datasets We show results of simulations on the N-MNIST dataset (Orchard et al., 2015) (figure 4a) and a subset of the GSC dataset (Warden, 2018) (figure 4b), where we randomly selected ten words (”down”, ”follow”, ”forward”, ”house”, ”marvin”, ”off”, ”one”, ”sheila”, ”three”, ”tree”), which is a temporal dataset, with audio samples. See table 1 for description of the architectures. Training was performed with the Adam optimizer (Kingma, 2014). While the ANN and the DeNN networks get similar performances on the N-MNIST dataset, a clear difference appears for the temporal dataset, GSC. As shown on figure 4b, the DeNN is able to get a satisfying performance from the first epoch, while the ANN slowly rises to (almost) the same performance in a few epochs. Moreover, the SNNs models appear to be behind in performances, with the adLIF model being the best amongst them. Note that if the SNNs couldn’t reach the same performances as the other models in 5 epochs, they could converge toward it with more epochs, as shown on figure E.1. It is clear from figure 4b that simulating an IF network (using the model in equation 2) on temporal datasets, with sur- rogate gradient, does not give satisfying results. However, converting a DeNN to an IF model (using model 14) allows for zero-loss conversion. The difference between the accuracy reached by the converted IF network and the DeNN is, on average, −0.00375 ± 0.0014, and is shown on figure 5. We thus show that using a higher degree of temporal representation in the neural network allows for a better rep- resentation of temporal dynamics in demanding datasets.
