Algorithm 1 REMBGO with strict function-evaluation accounting. Input: bounds l,u; population size N; evaluation budget B; elite count Ke; restart reference point xref (box midpoint on the CEC benchmark, not inserted into the initial population). Output: best solution xb and its value fb. 1: TB ←⌈(B−N)/N⌉. 2: Initialize the N candidates and evaluate them; fe ←N, cs ←0; store the global best (xb, fb). 3: for t = 1,...,TB do 4: τ ←t/TB. 5: Rank and preserve. Sort by fitness; set best xb and worst xw; compute div (4) and patience P (16); copy the Ke elites unchanged into the trial rows (R1). 6: Prepare guidance. Compute centroid c (5), sample δ and set radius Rt (6), step scale λ(τ) and jitter probability pj (15). 7: for each non-elite player i do 8: select the first active operator (R4): opposition (8) →Cauchy (9) →radius-gated core (triple-leader (10) or centroid update (11) if ∥ˆxi −ˆxb∥≤Rt, else Lévy (12)) →opponent battle (13)–(14); form the trial. 9: apply stagnation jitter with probability pj (R9); repair boundary violations by reflection and clamping (R10). 10: end for 11: Budgeted evaluation. m ←min(N, B−fe); evaluate the first m trial rows; fe ←fe+m; unevaluated trials keep their parents; restore the stored elite fitnesses. 12: Survivor selection. Apply strict one-to-one greedy parent–trial selection (R10); update (xb, fb); set cs ←0 if the best improved, else cs ←cs +1. 13: Recovery. if cs ≥P or (div < 0.05 and cs > 1) then regenerate the worst nr = round(0.30N) players by the 6/4/2 construction, set their stored fitness to +∞, and reset cs ←0 (R11). 14: if fe ≥B then break. 15: end for 16: return xb, fb.
