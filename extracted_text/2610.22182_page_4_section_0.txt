LAMP uses ProKeR’s residual kernel formulation, which transfers corrections from support images to queries according to global-feature similarities [6]. It fits a global predictor and separate regional predictors whose kernels are calibrated against the support set. Combining their outputs in class-score space preserves each branch’s feature dimensions and similarity structure; labeled validation data determine their relative contributions. Since the branches are fitted independently, their predictions can be reused when evaluating different mixtures. LAMP-F also exploits their linear dependence on the support residual to cache the combined response to prototype updates. 2.3. Patch- and region-level adaptation Selective Vision-Language Subspace Projection (SSP) uses local features to con- struct visual and class-specific language subspaces for image–text alignment without gradient optimization [7]. Both SSP and LAMP use information beyond a single global descriptor, but they integrate it differently. SSP improves cross-modal alignment through subspace projection. LAMP uses regional features from several encoder layers to fit the same support-label residual and then combines the resulting class scores. Because all branches predict the same classes, their outputs can be combined even when their feature dimensions differ. A single encoder pass per view provides all regional de- scriptors. LAMP uses generalized-mean pooling for convolutional activations [23] and kernel-mean comparisons of descriptor sets [24]. Comparisons with simpler summaries of the same layers distinguish the benefit of using multiple layers from that of retaining regional descriptor sets. 3. Method LAMP adapts CLIP by using labeled support images to correct its initial class scores. The support labels indicate which scores should increase or decrease, and visual similarity determines how these corrections transfer to a query. Global descriptors and regional features from intermediate layers capture different relationships between images, providing complementary ways to correct a prediction. LAMP combines the resulting corrections in class-score space: every branch produces one score per class, even when the branches have different feature dimensions. We first introduce the residual target and global predictor using ProKeR’s residual kernel formulation [6]. We then explain how intermediate layers provide regional descriptors, how their similarities are calibrated, and how the resulting predictors fit the same target. Validation determines the contribution of each predictor. LAMP-F further adapts the class prototypes while keeping the selected visual kernels and mixture weights fixed.
