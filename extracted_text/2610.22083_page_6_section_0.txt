A bit on which two trained code words disagree acquires equal weight on both rails and therefore contributes equal excitation and inhibition, cancelling exactly: the “don’t care” synapse of Davies et al. (2025). Classification is the firing of the output neuron within one timestep of the input, so the decision latency is fixed by the depth of the network rather than by an integration window. Each of the eight encodings has its own dual-rail pair and its own output neuron, and all eight are trained in a single simulation; the pattern generator, save neuron and teacher neuron are shared between them. 3.1.3. Deviations from the previous work Two parameters differ from Davies et al. (2025), both required by the wider code words used here. First, the output neuron’s firing threshold is scaled with the code width. A width-𝑊code delivers up to 𝑊potentiated synapses’ worth of current in a single timestep, which for wide codes exceeds the default threshold and causes the output neuron to fire without the teacher, corrupting the learned pattern; the threshold is therefore set to twice the accumulated drive, subject to a floor at the default value. Second, the STDP weight ceiling 𝑤𝑚𝑎𝑥is reduced from 20 to 2. The simulator holds synaptic weights in a fixed-point accumulator whose scaling is fixed at run time by the largest total current that could arrive at a neuron, namely 𝑤𝑚𝑎𝑥 times the fan-in (van Albada et al., 2018); a larger product consumes more integer bits and leaves fewer fractional ones, coarsening the resolution. At the widest code considered the fan-in reaches 510, two rails of 255 bits, and at the default ceiling the resulting step size is comparable to the learned weight of ≈0.37 itself, which therefore cannot be represented. Lowering the ceiling restores the fractional precision, and the learned weight is then recorded as 0.375. Neither affects what is learned: homeostasis rescales the weights afterwards, and Davies et al. (2025) note that the STDP parameter values are of little consequence for exactly this reason. A corollary is that the absolute homeostatic factors of encodings with different widths are not directly comparable, since their thresholds differ; comparisons in Section 4 are therefore made within an encoding, or after normalisation. 3.2. Application of the Encoding The encoding is applied as a pre-processing step rather than computed by the network. For a given value, the code word determines the connectivity: the generator neuron that fires at the “1” times (Section 3.1) connects to every bit of the code word equal to one, and the neuron that fires at the “0” times to every bit equal to zero. The network is therefore constructed anew for each value presented, and no population computes the mapping from value to code word. This matches the framing of the work as a pre-processing of the input signal, and it also removes the source-side spike load: each generator neuron emits one packet per presentation time, which the router fans out, rather than one packet per bit. The same mapping could be computed on-chip, by a place-coded input population with one neuron per value projecting to the bits of its own code word through fixed connectivity. Such a network would present identical activity to the encoding populations, so the results reported here do not depend on which of the two arrangements is used. 3.3. Training and Testing Procedure For each experiment a set of values is trained, one value per simulation and each on a network whose plastic weights begin at zero, and the resulting weight vectors are summed synapse by synapse, following Davies et al. (2025). This procedure makes the learned weights a linear function of the trained set; its relation to sequential learning on a single network is discussed in Section 5.1.
