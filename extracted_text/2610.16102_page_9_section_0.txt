The partial telling matters for §8, because confidence and trace are exactly what a human needs in order to re-root a result. 3.5 Indwelling and the fixed scaffold Polanyi described tools and probes as things we come to “dwell in” (Polanyi 1966, 17–18): the blind man feels the end of his stick, not its pressure on his palm. VaCoAl’s per-block feedback polynomials play this role. They are used on every read and write, they shape everything the system can distinguish, and they are never themselves the object of a query. The programme links this design choice to biology: grid-cell codes appear to reach hippocampal CA3 through a fixed projection laid down early in life, onto which later memories are orthogonalized (2026a; 2026d, citing Chandra et al. 2025). On this reading indwelling is not a mystery added to cognition. It is the ordinary condition of any substrate whose orthogonalizer is hardwired and therefore invisible to its own queries. 4 Audit–valuation complementarity: tacit knowing as an oper- ating regime In VaCoAl/PyVaCoAl the boundary between tacit and explicit is not a property of content. It is set by the operating regime and by the family of read operations available, and the regimes trade exact auditability against emergent valuation. 4.1 A relational definition Let M be a memory in operating regime ρ (for VaCoAl/PyVaCoAl: the rescue rate RR, memory depth 2m, block count N and frontier size FS), and let Q be the family of read operations that can be applied to it. We say that information I is: • explicit in (M, ρ, Q) if some query in Q returns I as a stated item; • structurally tacit in (M, ρ, Q) if I changes the output of some query in Q, but no query in Q returns I as an item. Structurally tacit information then comes in two kinds: • contingently tacit if some enlarged family Q′, run under the same regime ρ, returns I as an item; • regime-bound tacit if every family that returns I as an item requires a regime in which I no longer exists. In plain words, the definitions rest on three ideas. A query is a question put to the memory. An item is an answer that states something outright, the way a lookup returns a stored record. The regime is the way the memory is being run. In VaCoAl/PyVaCoAl the setting that matters most here is the rescue rate RR, which decides whether address collisions are repaired (Rescue mode) or tolerated (Don’t Care mode).
