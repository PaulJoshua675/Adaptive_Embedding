User simulation provides a scalable alternative to human evaluation of conversational recommender systems (CRSs) (Balog and Zhai, 2025; Zhu et al., 2024b; Zhang and Balog, 2020; Bernard and Balog, 2025). Earlier approaches relied on agenda-based control, later extended with neural generation in frameworks such as GenTUS (Afzali et al., 2023; Lin et al., 2022). LLM-based frameworks, includ- ing iEvaLM, enable more flexible interactions but raise concerns about behavioral realism, data leak- age, and controllability (Wang et al., 2023; Yoon et al., 2024; Zhu et al., 2024a). Recent approaches incorporate richer user mod- els. RecUserSim combines bounded-rationality principles with memory tracking (Chen et al., 2025a); PerCRS uses assigned personality traits (Zhao et al., 2025), while PUB infers Big-Five traits from behavioral logs (Ma et al., 2025). PEARL derives persona knowledge from user re- views (Kim et al., 2024), and CSHI offers control- lable, target-conditioned simulation (Zhu et al., 2024b). Other work investigates LLM-based and user-centric CRS evaluation and parameterized be- havioral traits (Chen et al., 2025b; Jin et al., 2024; Sekuli´c et al., 2024). SimInter differs by eliciting implicit behavioral attributes through synthetic interviews grounded in historical conversational evidence. Unlike pre- defined trait configurations or review-derived per- sonas, SimInter uses user-specific dialogue and au- dits potentially fabricated or stereotyped content before profile enrichment. Notably, while CSHI addresses target-item leakage and Per- CRS uses knowledge-graph grounding, SimInter audits interview-derived claims against historical user evidence before profile enrichment. 3 Method Figure 1 illustrates the SimInter pipeline. The method consists of six stages: (1) constructing ba- sic user profiles from historical interactions, (2) ex- tracting behavioral statistics from these profiles, (3) generating synthetic interviews between two LLM-based agents, (4) auditing the generated con- versations with an audit agent, (5) extracting im- plicit user attributes and enriching the profiles, and (6) simulating users interacting with a CRS using their enriched profiles. We instantiate the LLM- based components with Gemini 2.5 Flash (Co- manici et al., 2025) for interview generation and user simulation, Claude Haiku 4.5 (Anthropic, 2025) for auditing, Tencent Hy3 (Tencent Hy Team, 2026) for enrichment, and GPT-4o-mini (Achiam et al., 2023) as the CRS the simulated user interacts with.
