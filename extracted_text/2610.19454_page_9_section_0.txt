As shown in Table 2, AdCoEvo achieves the highest ADV, lowest CPA, and highest composite score. Compared with GPT-5.6-Terra, the best-performing foundation model overall, it increases ADV by 3.73% and reduces CPA by 3.23%. With a smaller model, domain-specific training and co-evolution can build operational capabilities aligned with delivery objectives, improving value generation and cost efficiency. In addition to delivery performance, AdCoEvo also has lower API costs. Based on actual API usage across all roles and the corresponding listed prices,3 its average API cost is CNY 0.235 per period, 65.59% lower than that of Gemini-3.1-Flash-Lite, the least expensive foundation model, and its cost per 10,000 ADV is CNY 0.0725. Lower API costs help scale advertising delivery.
