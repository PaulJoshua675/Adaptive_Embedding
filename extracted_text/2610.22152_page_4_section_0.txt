The training reward used for the Q-learning update applies costt as a fixed-multiplier Lagrangian penalty on top of the shaped proxy signal: rtrain t = ∆Rproxy t + F(st, at, st+1) −λ · costt (5) where ∆Rproxy t = Rproxy t −Rproxy t−1 and λ is fixed for the duration of training. Critically, the agent is never given Rtrue as a training signal; it learns only from Eq. 5, mirroring a deployment setting in which the true objective is precisely what is unavailable for direct supervision. The concealment exploit is a single-action behavior that is trivially reachable by random exploration; the honest delivery route requires a multi-step chain (navigate to dirt, pick up, navigate to bin, deposit) that is comparatively unlikely to be discovered before ϵ decays. To address this exploration asymmetry, we generate a fixed set of honest-policy demonstration trajectories once, before training begins, and store them in a buffer that is never subsequently written to and therefore can never be evicted by the replay buffer’s ring-buffer overwrite behavior. Each training batch is drawn as a mixture of ordinary experience and demonstration transitions at a fixed demonstration fraction. This separation is necessary: in an earlier version of this method, demonstrations were seeded into the same buffer used for ordinary experience and were silently overwritten once the total transitions exceeded the buffer’s capacity, after which the agent’s true-objective performance reverted toward the unconstrained baseline. Isolating demonstrations in a protected buffer removes this failure mode entirely. 3.5 Hyperparameters Table 1 lists the full configuration used for both the baseline and constrained agents, except where noted.
