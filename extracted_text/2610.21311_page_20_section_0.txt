The following lemma estimates the additional runtime to solve OJZJ after the OMM is solved, based on the assumption that at least one inner non-extreme Pareto front point (k+a, n+k−a), a ∈[k+1, n−k+1] is covered. The proof proceeds in two phases. In the first phase, extreme Pareto front points (k, n+k) and (n+k, k) are quickly covered from the OMM individuals via knowledge transfer. The second phase is analogous to covering the OMM problem, and the inner Pareto points (k + a, n + k −a), a ∈[k..n −k] can be covered solely through mutation among the OJZJ individuals. Lemma 11. Let n ∈[2, +∞) ∩N. Consider using the MO-MFEA with binary tournament selection, one-point crossover, standard bitwise mutation and population size N ≥8(n + 1) to optimize (OMM, OJZJ) problem. Let V2 and f V2 be defined as in Lemma 7. Assume that V2 ⊈f V2 always holds, and the Pareto front of OMM is covered. Then within an additional 96eNn prm + 864eNn(ln n + 1) 5(1 −prm) expected function evaluations, the Pareto front of OJZJ is covered (by the individuals corresponding to this task). Proof. The process of covering the Pareto front of the OJZJ problem is divided into two phases. The first phase focuses on reaching the two extreme Pareto front points (k, n+k) and (n+k, k), and the second phase focuses on covering the inner Pareto front, that is, {(k + j, n + k −j) | j ∈[k..n −k]}. For some iteration t, let St,i = {Y ∈Pt | τ(Y ) = i} for i = 1, 2. First phase. We first consider the time to reach the extreme Pareto front point (k, n+k), that is, the time to witness that 0n is included in St,2 (the set of the individuals corresponding to the OJZJ task). Since the Pareto front of OMM is covered, we have 0n ∈St,1. Let B = {Y ∈St,1 | cDis(Y ) = +∞}. Obviously, 0n ∈B. Let X1 be such a 0n in B. From the definition of crowding distance [DPAM02], we have |B| ≤4. Thus, from the scalar fitness assignment rule in Algorithm 2, we have φ(X1) ≥1/4. Analogously, we have the same bound for the expected number of iterations to witness 1n ∈St,2.
