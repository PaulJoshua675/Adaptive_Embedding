Lossy activation compression and low-precision training. Multiple methods have investigated lossy compression for activations. ActNN (Chen et al., 2021) uses randomized mixed-precision quantization and analyzes the resulting gradient variance. GACT (Liu et al., 2022) extends activation compression to generic network architectures, dynamically choosing tensor compression ratios. CompAct (Shamshoum et al., 2025) uses random projections to store low-rank activations. Low precision datatypes such as FP8 halves the storage per value compared to BF16 and offers speed-ups with hardware support (Micikevicius et al., 2022). COAT (Xi et al., 2025) targets both activation and optimizer-state memory through FP8 quantization. Hardware-accelerated 2:4 sparsity for ReLU2 activations has been investigated by Haziza et al. (2025) for training and inference where activations are pruned so only 2 of every 4 activations are nonzero. Lossless memory reduction techniques. A few methods have explored lossless activation storage with ReLU activations. BitTrain (Hosny et al., 2021) stores the nonzero activation values for training convolutional neural networks (CNNs) on CPU-based edge devices. cDMA (Rhu et al., 2018) exploits activation sparsity to reduce transfers between GPU and host memory during training for host activation caching, also for CNNs. Gist (Jain et al., 2018) compresses sparse activations with a 8-bit CSR format. BitSparse extends these methods in several ways, including the standard GPU training setup without host synchronization, dedicated fused kernels for low overhead, low precision support and sign-bit packing for higher compression. We view these as essential for adoption in the modern LLM training era. In addition, nvCOMP (NVIDIA Corporation, 2026) provides optimized codecs for general and floating data, which can be applied to activations.
