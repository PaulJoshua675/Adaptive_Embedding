AI Consilium: a Benchmark of LLM Clinical Multidisciplinary Second Opinions A PREPRINT B Formal Interactive Consilium Algorithm Algorithm 1: Interactive report review Input: clinical case C; maximum review rounds T = 5. Output: final clinical second opinion F; completed-round count q; consensus indicator c; stop reason s. Model-mediated functions: Msel, role selector; M op i , role-specific opinion generator; M rev i , role-specific reviewer; M init mod, initial-report moderator; M rev mod, revision moderator; Mfin, finalizer. 1. Select a role set R = Msel(C) with 1 ≤n = |R| ≤5 and one primary role in R. 2. For every role ri ∈R, independently obtain and freeze Oi = M op i (C, ri). 3. Produce the initial shared report R0 = M init mod(C, [(ri, Oi)]n i=1). Initialize the previous-round context P0 = ([], ∅), the complete review/revision history H, and the set of seen reports S = {R0}. 4. For t = 1, . . . , T: (a) Every role reviews the same current report: V (t) i = M rev i (C, ri, Oi, Rt−1, Pt−1). Each V (t) i contains a yes/no vote and critique; a no vote also contains revision advice. Append all reviews to H. (b) If all roles vote yes, the controller sets q = t, c = true, and s = consensus; retain R∗= Rt−1 and leave the loop. (c) Otherwise obtain ( eRt, ∆t, St) = M rev mod(C, Rt−1, {V (t) i : vote(V (t) i ) = no}), where ∆t indicates a substan- tive change and St records disposition of the objections. Append the moderator record to H and set Pt = ([V (t) i ]n i=1, (∆t, St)). (d) If ∆t is false, set q = t, c = false, s = no substantive change, and R∗= Rt−1; leave the loop. (e) Let Rt = eRt. If Rt ∈S, set q = t, c = false, s = no substantive change, and R∗= Rt; leave the loop. Otherwise add Rt to S. (f) If t = T, set q = t, c = false, s = maximum rounds, and R∗= Rt; leave the loop. 5. Generate only the clinical component F = Mfin(C, [(ri, Oi)]n i=1, R∗, H) . The controller returns (F, q, c, s) and validates that its own discussion metadata are copied unchanged into the stored record. 33
