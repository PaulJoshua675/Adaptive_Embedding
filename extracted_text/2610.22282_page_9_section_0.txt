Each row shows one prompt. For each model we show the first and last of the 13 generated frames (1280 × 704, 50 sampling steps). Both models use the same prompt and initial noise. RPO follows the prompt more closely and replaces distorted, painterly textures with coherent, realistic scenes. The remaining dimensions reveal trade-offs. RPO lowers color and appearance style relative to the base model, although it still leads the trained baselines on color. Flow-GRPO raises dynamic degree by 12.50 points but loses consistency, smoothness, aesthetic quality, color, and object-class accuracy. RPO therefore transfers reward mainly through semantic alignment, whereas Flow-GRPO trades visual quality for motion. The four Wan2.2 overall scores span only 0.81 points on one seed set, so we read the aggregate ranking as directional. CogVideoX-5B (Yang et al., 2024) and HunyuanVideo (Kong et al., 2024) serve as external references under matched prompts and scoring. Figure 5 makes these semantic gains visible on four held-out prompts, where the RPO videos follow the prompts more closely. Both checkpoints run dense attention with the same prompt, initial noise, and sampler, so they differ only in their weights.
