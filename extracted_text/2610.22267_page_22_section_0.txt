A.7 Computational Overhead Tab. S5 compares the computational cost across methods. Following CNO, we apply a stop-gradient operator on the UNet output when computing Tweedie predictions, which eliminates the need to retain UNet activations during back- propagation. As a result, DetNO achieves the same GPU memory footprint as CNO (28.3 GB) and requires the same number of extra forward passes (Nopt+1). The marginal time overhead relative to CNO (17.8 s vs. 17.7 s) stems solely from the Gram matrix computation and its matrix inversion, both of which are neg- ligible compared to the UNet forward passes. A.8 Effect of Gradient Computation Strategy. As shown in Table S6, stop-gradient already yields clear diversity gains over the baseline (MSS, VendiScore) at a marginal quality cost. Full gradient achieves moderately stronger gains (particularly in Recall and VendiScore) by propagat- ing richer second-order information through the denoising network, but at the cost of storing all intermediate UNet activations during backpropagation. Stop- gradient closes most of this gap while reducing peak memory to the level of standard inference (Tab. S5), making it the more practical default; we adopt it in Algorithm 1 and note that full gradient can be used when memory budget permits.
