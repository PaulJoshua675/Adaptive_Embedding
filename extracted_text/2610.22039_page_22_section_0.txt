Graph Credit correctly identifies that no genuine progress has been made toward a coherent solution. Case 2: Partial resolution with mixed upstream com- pletion. Task structure: A 3-node DAG in a TypeScript project. Node A refactors a shared utility module; Node B (depends on A) updates the primary consumer; Node C (de- pends on A) updates the secondary consumer. This fork struc- ture tests whether Graph Credit correctly attributes partial completion across parallel downstream nodes that share a common dependency. Agent behavior (GLM-5.2 / OpenCode): The agent refactors Node A but misses two behaviors of the origi- nal utility (edge-case handling and error propagation), im- plements Node B (primary consumer update) against the new interface, and produces an incorrect implementation of Node C that passes only 2 of 6 attributed tests. Key F2P tests and attribution: • Node A: test_util_new_api, test_util_backward_compat, test_util_edge_cases, test_util_error_handling, test_util_types, test_util_async (6 tests, 4 pass; edge_cases and error_handling fail) • Node B: test_primary_ consumer_integration, test_primary_consumer_error_path, test_primary_consumer_caching, test_primary_consumer_retry, test_primary_consumer_events, test_primary_consumer_metrics (6 tests, 5 pass) • Node C: test_secondary_consumer_basic, test_secondary_consumer_batch, test_secondary_consumer_timeout, test_secondary_consumer_fallback, test_secondary_consumer_logging, test_secondary_consumer_config (6 tests, 2 pass) Scoring comparison: • Flat-F2P: 61.1% (11/18 attributed tests pass: 4/6 for A, 5/6 for B, 2/6 for C). • Graph Credit: 55.6%. Node credits: cA = 4/6 = 0.67 (no parents), cB = min(5/6, cA) = 0.67, cC = min(2/6, cA) = 0.33. Mean = (2/3 + 2/3 + 1/3)/3 = 5/9 ≈0.556. • OverCredit: 5.6 pp. This fork exercises both branches of the recursive mini- mum. Node B’s local score (5/6) exceeds its parent’s comple- tion (cA = 2/3) and is therefore capped: flat scoring would report the primary consumer as nearly complete even though two behaviors of the utility module it consumes are still miss- ing. Node C, by contrast, already scores below its parent, so its own local completion remains the binding constraint and Graph Credit leaves it unchanged. The entire 5.6 pp Over- Credit is thus attributable to Node B—precisely the struc- turally unsupported portion of its score. Aggregate patterns. Across all 4,800 agent runs on WEAVE-Bench: • 68% of runs exhibit >0 pp OverCredit. • 23% exhibit >15 pp OverCredit (substantial phantom credit). • 8% exhibit >30 pp OverCredit (severe misrepresentation under flat scoring). • The correlation between Flat-F2P and actual Resolved is ρ = 0.69, while Graph Credit achieves ρ = 0.82—a 19% improvement in diagnostic fidelity.
