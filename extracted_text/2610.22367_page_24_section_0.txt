7 I.2. Hermitian-code decoding for HOPI HOPI requires the same phase (24) as the Reed–Solomon instance above, but its error word belongs to a 512-symbol Hermitian code over F64. A Reed–Solomon code with 512 positions would require symbols of about nine bits, since each position needs a distinct field element. A Hermitian code instead obtains 512 positions while retaining six-bit symbols by using the points (x, y) ∈F2 64 on y8 = x9 + y. (41) Polynomials in x and y are ordered by a weighted degree, the analogue of polynomial degree for Reed–Solomon codes. Here x has weight 8 and y has weight 9, so the monomial xayb has weighted degree 8a + 9b. These weights give the leading terms y8 and x9 of Equation (41) the same weighted degree, 72. Each finite point Pj = (xj, yj) is one code position. The syndrome construction is the two-variable analogue of the Reed–Solomon map above. A function ψ(x, y) assigns a field value to every position and therefore defines one parity check S(ψ) = 512 X j=1 ejψ(Pj). (42) The value S(ψ) is one syndrome symbol. This instance uses the 123 monomials ψa,b(x, y) = xayb of weighted degree 8a + 9b ≤150 [41]. We enumerate them as ψ0, . . . , ψ122 in increasing weighted degree [47]. The input |s⟩supplies the 123 symbols Sk := S(ψk), k = 0, . . . , 122. (43) This syndrome map defines a [512, 389, dmin ≥96]64 Hermitian code, so the syndrome uniquely determines every error affecting at most 47 positions. The 123 six-bit syndromes occupy 738 qubits. Beyond error weight 33, some of the syndromes that the recurrence needs have weighted degree above 150, which the input does not supply. The Feng–Rao baseline reconstructs these missing syndromes by majority voting among recurrence predictions, then uses the extended sequence to locate and evaluate the errors [39]. Our reversible implementation of this baseline uses 100 million Toffolis at a peak of 190,000 qubits, for a TQ-cost of 2.0 × 1013. The large qubit count comes from retaining the intermediate states of the recurrence updates until the circuit reverses the computation. The discovered circuit instead turns locator finding into a null-space problem for a symmetric matrix A built directly from the supplied syndromes.
