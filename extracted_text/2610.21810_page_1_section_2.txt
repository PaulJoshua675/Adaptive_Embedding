Conditional memory expands language-model ca- pacity without a proportional increase in per-token computation. It retrieves learned representations from large embedding tables, allowing a model to use only a small part of its memory for each input (Cheng et al., 2026; Liu et al., 2026). This makes higher capacity attractive under limited compute budgets, but the tables still occupy substantial stor- age. Moving them from accelerator memory to host memory changes where that cost is paid without reducing it. Compressing conditional memory presents a dif- ferent challenge from conventional LLM weight compression. Although its embedding tables con- tain learned parameters, they are accessed through sparse, input-dependent lookups rather than dense computation. Existing LLM compression meth- ods primarily target dense model weights, leaving the distinct access patterns of conditional memory largely unaddressed. Conditional memory instead requires reducing the footprint of the entire table while preserving independent access to individual rows and the information they provide to the model. Can conditional memory be stored more compactly while reconstructing only the entries needed by the current input? We propose Conditional Program (CP), a rep- resentation that stores instructions for reconstruct- ing each entry through a shared decoder. Our hy- pothesis is that a compact shared reconstruction rule, together with short row-specific codes and local scales, can preserve the signal that the model consumes from the table. An input selects which en- tries to reconstruct, so the extra work is confined to the rows it accesses. This exchanges storage across the full table for reconstruction work on a small subset, carrying the selective use of conditional memory into its compressed representation. Specifically, CP represents each row with a short code and a local scale, using a decoder shared across the table. We model normalized row con- tents as the accumulation of many small learning contributions dispersed across coordinates; when these contributions are weakly dependent and none dominates, a Gaussian source approximation fol- lows from a central-limit argument. Therefore, we encode rows in their stored coordinate system with a shared Gaussian trellis (Tseng et al., 2024b). The local scale restores the decoded vector’s norm, and independently stored row records allow the run- time to fetch and reconstruct only requested entries (Figure 1). At two bits, CP reduces table storage by roughly four- to eightfold, with most reported task scores remaining close to their original values. For a 4,096-token DeepSeek prefill from host mem- ory, its row layout reduces lookup time from 10.78 to 6.54 ms compared with a QTIP tile-window de- coder in a layout microbenchmark.
