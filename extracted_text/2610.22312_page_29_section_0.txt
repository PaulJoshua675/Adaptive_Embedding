Rule cards. The following text is taken directly from the registered rule renderers using the selected alphabets. The mathematical explanations in Appendix B supplement these literal instructions for the reader. PAINT. PAINT(a,r,u,v): simultaneously replace u by v at every coordinate x with sum_i |x_i-a_i| <= r. All other cells remain unchanged. REFLECT. REFLECT(lo,hi,axis): for every cell x in the inclusive box lo <= x <= hi, the new value at the mirrored position x’ (x’_axis = lo_axis + hi_axis - x_axis, other coordinates unchanged) is the old value at x, including 0. All writes happen simultaneously. Cells outside the box remain unchanged. STENCIL. STENCIL(a,r): simultaneously set every cell x with sum_i |x_i-a_i| <= r to (W(x) + sum W(y)) mod 4, where y ranges over the in-bounds cells at Manhattan distance 1 from x, whether or not they lie within distance r of a. Every update reads the same old world; cells farther than r from a remain unchanged. MIX. MIX(p,r): if W(p) = 0, nothing changes. Otherwise find every cell that can be reached from p by a path of at most r Manhattan-distance-1 steps whose cells all have nonzero old values (p itself counts as reached with 0 steps; a cell with old value 0 can never be entered or passed through). Then simultaneously set every reached cell x to 1 + ((W(x) + sum W(y)) mod 3), where y ranges over the in-bounds cells at Manhattan distance 1 from x, whether or not they were reached. Every update reads the old world; cells that were not reached remain unchanged. RELABEL. RELABEL(p,v): let u = W(p) (u may be 0). Find the maximal set of cells connected to p by Manhattan- distance-1 steps whose old values are all u, including p. Set every cell of that set to v. LAYER. LAYER(p,s): if W(p) = 0, nothing changes. Otherwise let u = W(p) and find the maximal Manhattan- connected set of cells with old value u, including p. If s = -1, set to 0 every cell of that set that has an in-bounds neighbor with old value 0. If s = +1, set to u every in-bounds cell with old value 0 that is a neighbor of a cell of that set. Positions outside the world are not neighbors; nothing else changes. MOVE. MOVE(v,axis,direction,k): take every cell with value v, ordered by decreasing coordinate on axis if direction=1 and increasing if direction=-1, so that the cells nearest the leading edge are handled first. In that order, move each one along axis in the sign of direction, one cell at a time and at most k cells, stopping as soon as the next cell is outside the world or nonzero (including cells already moved into). Each move clears the old cell and writes v to the new cell; values never merge, and a block of adjacent v cells therefore moves as a unit. COMPRESS. COMPRESS(axis,direction): on every line parallel to axis, independently: list the nonzero values in order starting from the destination edge (coordinate 0 if direction=-1, the highest coordinate if direction=1). Walk that list from its start; whenever two consecutive values are equal, replace them by one value equal to their sum and continue after the pair, so a merged value cannot merge again in this event. Write the resulting list back starting at the destination edge and set every remaining cell of the line to 0. A complete example. C.3 Answer extraction and diagnostic populations The answer has one field, cells, listing every nonzero coordinate–value pair. Omitted coordinates are zero. Duplicate or out-of-bounds coordinates, explicit zeros, undeclared values, and unknown fields invalidate a state. JSON parsing rejects duplicate keys and non-finite numbers; Boolean values are not integer coordinates or labels. The fixed extractor first tries the stripped response, optionally removing one enclosing code fence. Otherwise, it selects the last top-level JSON-object candidate, respecting braces inside strings. A malformed or unclosed trailing candidate fails extraction. Selection uses syntax and position, never the reference answer, and does not repair state values. Semantic EM scores the extracted state.
