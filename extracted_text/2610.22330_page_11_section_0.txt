Implementation Details For OpenWebText, LangDiT uses 12 Transformer blocks with embedding and hidden width 𝑑= 768, 12 attention heads of dimension 64, and feed-forward width 3072. For the LangFlow formulation, the input projection 𝑃maps 1536 dimensions to 768 dimensions. Transformer depth and hidden width are retained from baseline. Both the baseline and LangDiT use fused QKV projections, rotary position embeddings, GELU feed-forward layers, and zero-initialized adaptive-normalization projections. Configuration definitions and training settings are provided in Appendix C and B. 3.8.
