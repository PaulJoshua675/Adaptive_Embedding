We introduce a simple global fusion module to propagate the context feature into the obtained cross- temporal features of each agent, which can provide a compre- hensive representation of each agent for reasonable trajectory prediction. In particular, taking the observation lane feature oξ in Eq.(9) as well as the cross-temporal fusion feature fi in Eq.(11), we employ the same network architecture with the observation interaction module, and generate the final feature gi for a given agent i. E. Final Prediction Taking the final feature gi as input, our final predictor can generate normalized coordinates of multi-modal trajectories for multiple agents in a single shot. They can be transformed to absolute coordinates with the inverse operations in Eq.(1). Specifically, for providing K possible future trajectories and their probabilities of best-predicted trajectory, we equip the prediction head with K regression branches and a classifica- tion branch. The process can be formulated as follows: ˆpk i = MLP3(gi), sk i = MLP3([MLP4(ˆpk,Tp i ), gi)]), (12) where MLP3 consists of the MLP Block following a linear layer; and MLP4 is the stack of a linear layer, a ReLU function and a linear layer. Besides, ˆpk,Tp i denote the endpoint of the kth predicted trajectory of agent i. Model Training. Unlike the two-stage goal-based meth- ods [6], [32], our FFINet obtains the initial and final pre- dictions in a single shot. Therefore, we calculate the error of initial and final predictions simultaneously. Specifically, we employ Smooth l1 loss Lc reg to measure the regression distance error between the initial predictions and ground- truth trajectories. As for the final multi-modal predictions, we take the winner-takes-all (WTA) [33] strategy and back- propagate the loss of the best-predicted trajectory. Besides, we measure the regression loss Lreg across all time steps, calculate the endpoint loss Lend with the smooth l1 loss and the classification loss Lcls with the max-margin loss, as done in [19]. The total loss L can be denote as follows: L = Lreg + λLend + βLcls + γLc reg, (13) where λ, β and γ are three constant weights.
