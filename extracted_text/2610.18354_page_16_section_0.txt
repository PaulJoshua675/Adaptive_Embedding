• Cournot Duopoly is a simultaneous quantity-setting game where two firms choose outputs that jointly fix market price and profit. It isolates a single continuous best-response signal that separates models by how closely each converges toward the equilibrium quantity. • Stag Hunt is a coordination game with a risk-dominant and a payoff-dominant equilibrium. It measures whether a model favors the safer but lower-payoff option over the cooperative one when the opponent’s action is uncertain. • Vickrey Auction is a second-price sealed-bid auction where each bidder submits a value- based bid. It measures how closely a model’s bid tracks its private valuation under the auction’s truthful-bidding equilibrium. • Chicken Game is an anti-coordination game built around brinkmanship, where mutual insistence is worst for both players. It measures a model’s willingness to escalate or concede as the risk of mutual loss grows. Table C.2: The five base games G used across experiments, all played between 2 players. Fixed Model. One fixed model across all seeds N that keeps context and past outcomes across rounds t = 1, . . . , T unless otherwise stated. Per-Opponent Full-Information. Given the identity of the fixed opponent, it looks up the round-robin table (our prior) once at construction and commits to whichever candidate scores highest against that opponent, fielding it every round with no further adaptation. LLM Selector. Uses llama3.3:70b as the selecting model and relies on the Reflexion framework [21] to pick the model to field. Namely, each round it is queried once with a description of the game, an entry per portfolio model (tier and per-token price), and a log of past rounds covering its own fielded model, action, and outcome signal. It parses a JSON response giving the picked model, a confidence, and a reasoning. Prior information enters only as in-context history, a rolling log of past rounds inside the prompt, with default sampling temperature = 1.0. RouterDC. Adapted from Chen et al. [5]. Each round a frozen sentence encoder embeds the current query, built from player’s own model, action, and signal history, and the pick is whichever candidate’s trained embedding has highest cosine similarity to that query embedding. The embeddings come from a checkpoint fit offline, once per game. All prior information is folded into this pre-trained checkpoint at training time. Causal LLM Router. We follow the doubly robust regret-minimising rule of Tsiourvas et al. [26]. Each round it draws a candidate from a softmax over its current per-(candidate, opponent) belief, with a floor that keeps every candidate at nonzero pick probability. It then folds in a doubly robust correction of the observed signal, using the pick probability it assigned as its own propensity instead of fitting a separate propensity model. We use the defaults surrogate = softmax, tau = 1.0, and propensity_floor = 0.05. Thompson Sampler. It keeps a per-model Gaussian belief over the chosen signal that is refined as a running mean after every round. Each round it draws one sample per model from its current belief and fields the model with the highest draw. Additionally, we implement two non-stationary variants that change the belief update. The discounted variant (Dis. Thompson Sampler) multiplies every model’s accumulated pseudo-count by the discount factor before folding in the new observation, so older evidence decays exponentially. The sliding-window variant (SW Thompson Sampler) keeps only the W (window size) most recent observations, and drops older ones from the belief entirely. We use discount = 0.99 in the discounted variant and window = 50 in the sliding-window variant. 16
