Large Language Model (LLM) applications in- creasingly look conversational and social. Systems use multiple agents to debate answers, call tools, plan tasks, critique each other, and form judgments (Du et al., 2024; Wang et al., 2024; Guo et al., 2024). The appeal is intuitive: a group of agents should be safer than a single one, because peers can cross-check each other, expose factual errors, and converge toward the truth (Liang et al., 2024). This intuition overlooks that the channel agents use to coordinate is also an attack surface. Such an attacker needs no access to model weights or hidden states; it only has to post messages. We construct a controlled multi-agent discussion to simulate this threat and ask whether a few agents change what the rest of the agents believe, not only what they say. Ten agents discuss one factual ques- tion for 16 rounds. In the ten, k ∈{0, 1, 3} are adversarial agents (attacker), attacker-controlled agents (Douceur, 2002) that each argue for the same plausible false answer; the others are benign agents given no question-specific instructions. Be- nign agents are neither warned about the attacker nor assigned a verification role, so we measure the default behavior of an open discussion rather than that of a dedicated debate or fact-checking proto- col. For each benign agent, we record responses per round. The first is what it says in the chat, which we label as endorsing, rejecting, hedging on, or ignoring the false claim. The second is its pri- vate answer: after each round, we ask the agent the factual question in a separate call whose response is hidden from the other agents. For each benign turn, we have its private answer (true or false) with its public message (endorses the false claim or not). In two of the four combinations the chat reflects the private answer. In the other two it misleads: an agent may endorse the claim in the chat while still giving the true answer in pri- vate, or give the false answer in private while not endorsing the claim in the chat (Table 1 splits these further by public stance).
