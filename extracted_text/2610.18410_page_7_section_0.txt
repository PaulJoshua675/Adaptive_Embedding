Appendix C lists all evaluated methods and configurations. Direct retrieval. The first two rows of Figure 2 each use a single embedding collection. The plain baseline returns the nodes whose original embeddings are most similar to the query embed- ding q. One modified collection alone applies the same search to graph-modified embeddings. This comparison tests whether incorporating graph structure into the vectors makes them more useful for direct query matching. Alternating budget split. This strategy gives both spaces a share of the output. We search them independently using q and alternate between their rankings, skipping duplicate node identifiers. Two-stage fused retrieval. Here, the initial results guide the search for further evidence. The first stage retrieves 20 nodes (seeds) from the original space using q and computes m as the mean of their modified embeddings. The second stage pools candidates from an original-space search with q and a modified-space search with m, then ranks each candidate node n by the fused score s(n, α) = (1 −α) cos(q, xn) + α cos(m, zn). (4) The fusion weight α = 0.5 gives equal weight to similarity to the original query and similarity to the seeds in the modified space. The 20 highest-scoring remaining nodes complete the output. Single requery. This strategy uses the fused-stage results to refine the query for another search in the original space. It retrieves 16 seeds, selects 12 nodes using the fused score in Equation (4), and averages the latter’s original embeddings to obtain ¯x. The shifted query q′ = 0.7q + 0.3¯x (5) retrieves the final 12 nodes, giving a 16/12/12 allocation. Chained requery. This strategy adds a second query update, so the first shifted search supplies evidence for the next. It uses 6/6/14/14 nodes for seed retrieval, fused scoring, and two shifted-query searches in the original space. Each update uses the mean original embedding of the preceding stage’s results.
