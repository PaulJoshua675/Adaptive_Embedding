We train the builder agent with RL to directly maximize performance of answering agent. To densify the reward, the builder agent operates over workspace augmentations and is rewarded for change in accuracy. Because 𝑈(ℱ0) is fixed for a given initial filesystem, maximizing the cumulative dense reward is equivalent to maximizing the sparse objective, following potential-based reward shaping (Ng et al., 1999). Advantages are computed at each step, following multi-turn GRPO implementations (Baronio et al., 2025), thereby allowing earlier builder turns to receive a denser learning signal. Evaluating downstream utility after every edit can be expensive, so we train with a practical surrogate objective. We probe answerability every eight turns as seen in Figure 3 and combine changes between consecutive probes with a terminal downstream-answer reward.
