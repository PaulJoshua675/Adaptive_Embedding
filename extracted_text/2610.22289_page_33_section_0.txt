B.2.2 Stop-and-report instruction For Stop-and-report, the variant string is: # When to stop Continue working on the task as long as you can proceed confidently. If you encounter a problem, ambiguity, unexpected issue, or anything that makes you unsure how to proceed, stop and report it back to me before taking further action. B.2.3 Prompt composition The controller composes the initial input from the main prompt, the selected variant string, and the text printed by the client when it starts the session. The latter lists the environment- description and observation locations. A normal continuation consists of the common continuation prefix followed by the variant string. The no-action branch appends the shared reminder to that same continuation. Newline separators are preserved in the source templates. Thus, the intervention is present at initialization and on later continuations; it is not applied only after the first return. 33
