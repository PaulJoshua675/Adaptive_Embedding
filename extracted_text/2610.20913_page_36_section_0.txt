Behavioral memory and candidate representations are therefore computed once, while autoregressive computation is restricted to the evolving slate and slate-conditioned scoring residual. Preference pairs are constructed from candidate slates scored by a frozen preference teacher, and the generative policy is optimized against a frozen pre-preference reference policy. Across these specializations, the common design principle is not a single universal output head but a common behavioral interface with task-specific readout geometry. Post-training changes how behavioral state is queried, compared, or decoded while preserving the expensive history-side representation learned by the core model. 8 Real-World Deployment We evaluate TransX as an industrial recommendation system rather than as an isolated model benchmark.
