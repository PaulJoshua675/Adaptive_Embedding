For every target ID we proceed through the following stages: 1. Target full text. We fetch the target’s arXiv HTML (falling back to ar5iv for older papers) and parse it into {title, abstract, sections, tables, references, full text}. 2. Reference edges. We pull the target’s full reference list as structured edges from the Semantic Scholar API (Kinney et al., 2023), with per-edge citation intents, an isInfluential flag, and the cited paper’s metadata (title, abstract, year, venue, open- access PDF link). 3. Importance classification. An LLM (claude-sonnet-4-6) reads the target’s title, abstract, and body once, together with every reference and all of its collected mention snip- pets, and decides which references are sources i.e. the small subset that motivated the paper, exposed a gap it targets, supplied its conceptual foundation, or is directly extended. We get this classification from prior work done on citation importance (Cohan et al., 2019). A reference can be a source or an other. Each source receives one or more of four labels (motivates, exposes gap, foundation, extends), a short rationale, and verba- tim supporting quotes. The full prompt is given in Prompt 1. 4. Reference full text. For every source reference, we get the paper text through the process described in Step 1. 5. Summarization. We summarize the target and source documents using the idea card for- mat in Appendix A.1. For the source documents, we add two additional fields i.e. results and takeaways. The target’s own contribution is extracted separately as a gold idea used only inside the reward (the impact comparison, Section 3.1) and is never shown to the policy. 6. Consolidation. We drop targets with two or fewer source documents or no gold idea, and then join everything into one record per target. The source references become the input, and the target paper becomes the gold document. We show examples of the source reference labeling in Table 6.
