Conversational Dense Retrieval. Conversational search aims at resolving context-dependent utterances against a long and noisy dialogue history [41]. Instead of rewriting the utterance into a self- contained query [34, 39, 42], conversational dense retrieval (CDR) encodes the whole session into a single query embedding, learning to denoise the conversation in latent space and to keep only the context that reveals the current search intent [29, 53, 62]. PCDR is continually fine-tuned from a CDR checkpoint, so that it inherits the ability to denoise a long conversational context and can apply it to the user profile, preventing the profile from overloading the search intent with irrelevant information. Personalized Dense Retrieval. A similar idea is widely used in personalized dense retrieval, where various forms of user informa- tion are jointly encoded with the query: latent or ID-based user em- beddings [3, 4, 7, 10], categorical profile features [19, 65], behavioral histories such as past queries, clicks, and purchases [8, 21, 22, 28, 64], and structured textual constraints [59]. The retrieval targets range from products and videos to agent skills. Instruction-following re- trievers have also been studied with long-form personalized instruc- tions [49, 60]. In these tasks, although complicated, the information need is still clearly stated by the instructions, not demanding as much reasoning effort as inferring the search intent implied by a stand-alone user profile. None of these works conditions large-scale web passage retrieval on a persistent, unstructured natural-language profile of a specific user together with that user’s conversational history. Such natural human–agent interactions are noisier, and their personal intents are often only implied by the interactions of phrasing nuances in both profiles and dialogues, which makes dense retrieval considerably harder. Personalized Conversational Information Retrieval. Person- alized conversational information retrieval (PCIR) studies exactly this setting [1, 5]. Existing systems mostly follow the Personal- ized Conversational Query Reformulation (PCQR) paradigm: they rely on the implicit incorporation of profile statements based on the parametric knowledge of LLMs to produce a plausibly per- sonalized search query, then pass it to off-the-shelf retrievers and rerankers [14, 15, 20, 30, 40, 48]. Since such LLM-based user profile denoising that is not trained in favor of retrieval can be imper- fect [14], PCDR instead trains a retrieval model to denoise the user profile directly.
