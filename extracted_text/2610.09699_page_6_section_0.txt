The subsequent sections describe each module and its options in detail, organized by the affected algorithmic component. 3 Sampling As shown in lines 7 to 10 in Algorithm 1, the sampling procedure of the CMA-ES follows three steps; 1) a sampling of new points from a multivariate normal distribution, i.e. zi ∼N(0, I), which are then 2) transformed by A and 3) scaled by the mean m and global step size σ. Practically, each component zi,j of the mutation vector zi is generated independently. This can be done by inverse transformation sampling: first we generate a number uj ∼U(0, 1], and then use the percent-point function (PPF) of the Gaussian distribution QGauss(p) to generate the required standard normal variable: zi,j = QGauss(uj) ∼N(0, 1). In the Modular CMA-ES, five modules have been implemented that operate on the sampling component, explained in the next paragraphs. 3.1 Base Sampler In standard random sampling, the random uniform numbers that are used to construct the mutation vectors are generated using a pseudo-random number generator (PRNG). Specifically, a Mersenne- Twister general-purpose PRNG provides a source of (deterministic) randomness for generating uniformly distributed numbers. However, especially for smaller samples, random numbers generated using this method can be distributed very unevenly (Halton, 1960). Instead, Low-Discrepancy Sequences provide sequences of pseudo-randomly generated points that more evenly cover the domain (Cl´ement et al., 2023). In ES, quasi-random point sets have been used as an alternative sampling strategy Auger et al. (2005); Teytaud and Gelly (2007); de Nobel et al. (2024b), replacing the source of randomness of uj. In ModCMA, both Halton (Halton, 1960) and Sobol (Sobol’, 1967) sequences can be used instead of the standard PRNG. 3.2 Sample Transformation Instead of transforming uj to a normally distributed random sampling using the Gaussian PPF, we can transform uj to another continuous multivariate distribution. While several requirements apply to the distribution (Rudolph, 1994; Beyer, 2001), six functional distributions have been implemented (see Table 1). This is explained in more detail by de Nobel et al. (2025), which demonstrates a potential use case for non-Gaussian mutations in CMA-ES. By default, the maximum-entropy (Rudolph, 1994) Gaussian distribution is used. 3.3 Mirrored Sampling For every newly sampled point, its mirror image is added to the population by reversing its sign Brockhoff et al.
