Conclusions and Future Studies This study aims to introduce the naspaclust package which utilises the nature-inspired optimisation algorithms to improve fuzzy clustering perfor- mance, particularly FGWC. We have briefly described the implementation of the package in R software as well as providing the performance evaluation of some optimisation algorithms. This study found that the optimisation al- gorithms is proven to improve the performance of FGWC in any type of data and produce spatial patterns of the clustering results. Moreover, TLBO has the most potential to optimise FGWC in all cases. However, the available algorithms still have potential disadvantages in finding unexpected cluster formation which is not consistent with the initialised number of clusters in certain simulations. Therefore, we hope that this paper could become founda- tion for everyone wants to do GDA which needs spatial clustering techniques to improve the cluster quality.
