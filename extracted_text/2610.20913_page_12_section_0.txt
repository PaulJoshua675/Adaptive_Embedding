TransX: Technical Report 3.2 Behavior Memory Exposing all 𝑙𝑡states to every candidate reader would couple computation on the online serving path, state transfer, and cache footprint directly to history length. TransX therefore constructs a bounded, candidate-independent behavior memory 𝑀𝑡= M(𝐵𝑡) ∈R𝑛𝑡×𝑑𝑚, 𝑛𝑡≪𝑙𝑡, where M is the memory construction mechanism, 𝑛𝑡denotes the number of behavior-memory states available at request 𝑡, and 𝑑𝑚is the behavior-memory state dimension. This separates the amount of behavioral history encoded from the number of memory states exposed to prediction. Global–local memory. Our primary realization combines a high-resolution recent window with lower- resolution summaries of older behavior. Let 𝑊denote the local window size. The local branch retains the most recent encoded states, 𝐿𝑡= 𝐵𝑡[𝑙𝑡−min(𝑊, 𝑙𝑡) + 1 : 𝑙𝑡, ], while the preceding history is partitioned into causal supports and compressed into a bounded set of global summary states, 𝐺𝑡= PoolBlocks(𝐵𝑡[1 : 𝑙𝑡−𝑊, ]) . For notational simplicity, we describe the global branch in the main text as block-wise pooling over the history preceding the local window. Appendix A.2 details how the corresponding cutoff-specific block summaries are efficiently computed across events using a blocked prefix scan. Pooling may be fixed or learned, and can be applied to chunks to form block-wise summaries. After projection to a common memory width, 𝑀𝑡= 𝜓mem ([𝐺𝑡; 𝐿𝑡]) . The reader therefore receives precise access to recent behavior together with compressed coverage of longer-range history, while the number of reader-visible states remains bounded. This construction separates two quantities that are otherwise easily conflated: history support, which determines how far into the behavioral trajectory information may be drawn, and memory resolution, which determines how much of the resulting representation is exposed to the reader. A long behavioral history can therefore be encoded without requiring a proportionally longer reader sequence. Section 6 studies this distinction explicitly when scaling behavioral computation and behavior-memory resolution. Causal eligibility. Every reader-visible memory state is constructed only from behavior available at the corresponding prediction cutoff. For each memory slot 𝑀𝑡,𝑘, supp(𝑀𝑡,𝑘) ⊆{1, . . . , 𝑙𝑡}.
