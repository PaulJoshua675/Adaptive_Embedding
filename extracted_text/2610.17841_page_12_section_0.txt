Exact match after normalization scores 1.0; a query or product value of uni- sex against the other gender scores 0.7; any other mismatch scores 0.1. Age group. Ordinal, over the ordered scale {baby, toddler, kids, adult} (Myntra’s ageGroup field, e.g. "Adults-Men", is reduced to this scale by keeping only the age segment). Exact match scores 1.0; oth- erwise the score decays linearly with ordinal distance, max(0, 1 −0.35 | idx(qa) −idx(pa) |); a value outside the ordered scale scores 0.3. Color. Perceptual CIE76 ∆E distance in CIELAB [35] space between a query color and a product color, computed via a curated dictionary of ∼90 named colors mapped to representative sRGB values. Identical color strings score 1.0 directly. When both values resolve to a known color, ma(q, p) = max(0, 1 −∆E/120), taking the maximum over all query×product color pairs. When either color is not in the dictionary, the comparator falls back to sim(qa, pa). If the product has no structured baseColor, the query color list is instead compared against the product description text. Material, occasion, pattern, style. These four attributes share one comparator shape: the product’s value list is parsed from the semi-structured articleAttributes field (fab- ric/pattern/fit/occasion keys) and, when that yields noth- ing, backfilled by matching a curated domain vocabu- lary (e.g. pattern terms like "floral print", "polka dot"; style/fit terms like "slim fit", "off shoulder"; occasion terms like "business casual", "loungewear") against the product title and description. Given the resulting product value list, ma(q, p) = maxv∈qa, u∈pa sim(v, u) over all query×product value pairs. If the product has no values for the attribute at all, qa is instead compared against the raw description (and, for occasion/pattern/style, the full cat- egory path) text as a single string. Brand. Case-insensitive exact-or-substring match against the catalog’s brand field: ma(q, p) = 1.0 if either string contains the other, else 0.0. Price hint. Both query and product price are bucketed into three tiers (budget / mid-range / premium) using INR thresholds (< 700, 700–2000, > 2000, from the catalog’s list price). Matching tiers score 1.0; any mismatch scores 0.3 (rather than 0, since adjacent price tiers are a much smaller miss than an unrelated product). Optional visual grounding. When enabled, prod- uct_type, color, pattern, material, occasion, and style additionally probe a FashionCLIP image embedding of the product photo with a short attribute-specific text prompt (the attribute value plus the query’s product type as context, e.g. "striped shirt"), and the attribute’s final score is max(mtext a (q, p), mimage a (q, p)) — letting either signal recover from a missing or noisy metadata field. Aggregation. For a given query, only the subset of at- tributes A(q) actually expressed in that query’s structured representation contribute to its relevance score; the cor- responding cross-encoder weights wa are renormalized to sum to 1 over A(q) before the weighted sum is taken. A query with a multi-intent structured representation (e.g. a gift-set query implying several distinct product asks) is scored against every intent variant independently, and the best-matching variant’s score is kept — a retrieved product is credited if it satisfies at least one of the query’s intents well. 8.0.5. Cross-Encoder-Based Attribute Importance Esti- mation We estimate attribute-level importance using a cross- encoder trained on real fashion search interactions. The cross-encoder serves as an independent relevance oracle, al- lowing us to derive attribute weights without relying on the retrieval systems or evaluation metrics being compared in Fashion-RQBENCH. We use two complementary estima- tion procedures: a controlled matched-pair ablation and an independent regression-based cross-check. Cross-encoder oracle. We train a cross-encoder using the ModernBERT-large [50] architecture on a combination of proprietary internal relevance dataset (prop-rel) and a fashion-filtered subset of ESCI [34]. The model predicts binary query–product relevance, and we use its raw out- put logit as the relevance score. As ESCI’s US-locale subset spans fashion and non-fashion domains, we filter it to (query, product) pairs whose title or description con- tains fashion-specific keywords, treating products labeled exact for a given query as relevant and those labeled sub- stitute, complement, or irrelevant as irrelevant; a query may be paired with multiple products, yielding multiple query- product pairs. Combining this ESCI-filtered subset with prop-rel gives 539,849 training samples over 44,670 unique queries and 58,792 validation samples over 4,985 unique queries.
