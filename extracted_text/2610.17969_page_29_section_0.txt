Assume that the canonicalization floors are zero and every vector being normalized is nonzero. Replacing a block input h by ch for c > 0 then leaves the network’s dimensionless output unchanged because C(ch) = C(h). This invariance holds at every block-input boundary, including h0, and at the final block-output boundary because the stated head also canonicalizes the final block output. Derivation. In the zero-floor limit, positive homogeneity of RMS gives C(ch) = C(h) for every c > 0. A GCT block including entry canonicalization has the same output on h and ch wherever the block’s canonicalizations are defined. Applying this identity at the first downstream block shows that a network with the stated dimensionless head is invariant to positive rescaling at every block-input boundary, including h0. The head’s entry canonicalization also removes a rescaling at the final block-output boundary. For an output with units, the output value must change with the declared scale. Under (sℓ, ¯hℓ) 7→(csℓ, ¯hℓ), the reconstructed output changes from sℓ¯hℓto csℓ¯hℓ, while the normalized coordinate and the canonical-coordinate computation stay unchanged. This behavior is called equivariance. For unitful outputs, the corresponding statement is equivariance rather than invariance. Under the scale-state action (sℓ, ¯hℓ) 7→(csℓ, ¯hℓ), the reconstruction map R(s, ¯h) := s¯h obeys R(cs, ¯h) = cR(s, ¯h), while the canonical coordinate is fixed. The reconstruction sℓ¯hℓfollows the declared scale change exactly. F.7 Further examples of local typing rules Independent scale factors. Each element g = (g1, . . . , gK) ∈G assigns a multiplier gk to each chosen scale. Each multiplier can be chosen independently as any positive real number. Examples include the residual-stream scale of each stage, the target scale of each task head, and per-block parameter scales. A single residual-stream unit. The simplest rescaling group has one independent scale factor, K = 1. Let the single factor g rescale the residual stream of a Pre-LN block, and write Ures for the resulting stream unit. Under hℓ7→ghℓ, the identity N(ghℓ) = N(hℓ) shows that the normalizer output stays unchanged and is dimensionless. To produce an output that can be added to hℓ, the branch Fℓmust restore the stream unit through a map 1 →Ures. This declaration concerns the chosen activation rescaling and applies even when the input data, such as token identifiers, have no physical units. Sec. 2.2 generalizes the example into local typing rules. Unit types and empirical scales. We distinguish a tensor’s unit type from the tensor’s empirical scale. The type u(x) specifies how x transforms under G and can be read from the graph. The empirical scale sx is a measured magnitude with the same type as the tensor, u(sx) = u(x), making x/sx dimensionless. For example, multiplying hℓby g also multiplies the tensor’s RMS value by g, giving RMS(ghℓ) = g RMS(hℓ). The tensor and the corresponding RMS share the unit Ures, while a forward pass supplies the actual RMS value. The attention scales sQ, sK, stream scale sℓ, and characteristic loss scales Si used below are empirical scales in this sense. A single RMS scale applies to a block whose coordinates share one scalar unit. Mixed-unit tensors require separate scales for shared-unit blocks, or a unit-compatible metric. Parameters and explicit converters. Parameters follow the same rule. In y := fϕ(x), we treat ϕ as another input and declare the parameter transformation ϕ 7→ρϕ(g)ϕ. For example, in a linear map y = Wx between scalar-unit blocks, the weights must convert the input unit Uin into the output unit Uout, which requires u(W) = UoutU −1 in . Fixing these units before checking the graph makes mismatches detectable because an addition with unequal input units requires a converter. We keep unit conversion explicit by separating dimensionless mixing weights ¯W from scale converters s. The factorization W = s ¯W has u( ¯W) = 1 and u(s) = UoutU −1 in , as developed in Sec. 4. Normalization and output units. Consider N(x) := x/ RMS(x) on a nonzero shared-unit block. Here a gauge is a convention for representing tensors that differ only by the declared rescaling. Gauge fixing chooses one representative from each such family. Here we divide by RMS, which maps every cx, c > 0, to the same RMS-one tensor. We call this mapping to a fixed representative canonicalization. RMSNorm applies this division, yielding dimensionless coordinates before the learnable RMSNorm gain.
