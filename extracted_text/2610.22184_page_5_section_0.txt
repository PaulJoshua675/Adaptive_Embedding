A small per-step reward on movement goals during the dwell period, requiring the object to be settled within a 2 cm goal region in the required grasp mode. • Transition completion rsucc. A sparse success bonus for repositioning the object and settling it at the goal under the required grasp mode. • Hold quality rhold = ρt exp(−et/2.5 cm) on hold goals, which command the object to stay where it is. It rewards proximity to the hold position while the object is retained. • Arm neutrality rneutral = ρt exp(−∥qarm t −qarm def ∥/0.4). Attracts the arms toward their default configuration while the object stays held, so an arm not needed for the current grasp returns to its rest pose. • Failure penalty rfail. A single terminal penalty for a drop, sustained loss of object contact, or another physical or numerical failure (Appendix III-B). • Regularizers rreg. Five penalties for unsupported motion, excessive object speed, large actions, changes between actions, and joint-target tracking errors (Appendix III-D). Domain randomization. We train an individual expert per object over a diverse set of primitives (spheres, cubes, rectangular prisms, and cylinders). To make holding and transitions robust to unmodeled dynamics, we randomize object mass, center of mass, and contact friction, and apply random perturbation forces to the object (Appendix III-E). This drives the policy toward grasps and handoffs that stay stable under a range of physical conditions. Expert evaluation. We assess WBD-EX expert quality by regional route completion, the fraction of trials that reach every goal of a route in order before failure or timeout, where each route specifies a sequence of grasp goals across body regions. Route definitions, completion requirements, and evaluation details are given in Appendix IV. Expert evaluation omits external force perturbations but still applies object-mass, friction, and center-of-mass domain randomiza- tion. Two-stage WBD-EX training. When trained from scratch, experts for smaller and less uniformly shaped objects achieve lower regional route completion than experts for medium- large spheres. To reduce the time needed to train a WBD-EX expert for a new object, we pre-train medium-large sphere experts, which provide an effective initialization for the other primitives. We then warm-start additional object primitives from these pre-trained experts with an identical reward formulation. Warm-started experts achieve comparable or higher regional route completion than from-scratch experts at lower amortized GPU cost by sharing the faster sphere pre-training across target objects (Appendix V). C. WBD Controller Distillation WBD-EX policies generate diverse and continuous object repositioning trajectories covering contactable regions of the torso, head, and arms under randomized dynamics. We filter the trajectories to keep only valid repositioning trajectories, then balance sampling across objects and motion types with cross-body mirroring. We also sample three trajectory speed behaviors equally, using goal distances of 2–4, 4–6, and 6– 8 cm that are fixed within each trajectory, to capture both slow, deliberate and faster, dynamic repositioning behavior. See Appendix VII for additional details. These trajectories are used to train a WBD controller combining a conditional diffusion model with an inverse- dynamics network [11]. Given proprioceptive history and a five-dimensional geometry descriptor comprising log-sorted bounding-box side lengths, log volume, and sphericity, it generates keypoint motions and converts them into joint- target increments. For real objects, we compute this de- scriptor from measured dimensions. At inference, coarse commands guide generation through gradient guidance [11]. A tunable guidance weight controls how strongly denoising is steered toward the coarse motion command: larger weights emphasize command tracking, while smaller weights give greater relative influence to the learned motion prior. At each update, the diffusion model samples several candidate motions in parallel; we select the one closest to the command and convert it to refined joint commands with the inverse- dynamics model. This requires no privileged per-step object state and supports human teleoperation with tunable guid- ance. IV. EXPERIMENTS AND RESULTS We evaluate whether WBD can be used to generate whole- body dexterous data and train policies that refine imperfect motion commands into stable whole-body dexterous manip- ulation. We first report grasp and WBD-EX data generation, then evaluate a distilled WBD controller for on-body reposi- tioning in simulation and on a real Unitree G1. A shelf pick, stow, carry, and place task tests whether these skills compose into a longer manipulation sequence. A. Experimental Setup Our object set contains 15 primitives: six spheres, four cubes, three rectangular prisms, and two cylinders. All side lengths and diameters fall between 80 and 240 mm. WBD- EX uses 2.51 million simulation-stable grasps passing the dataset filters (Section III-A). Mean per-object coverage of sampled object-center positions around the torso is 90.1% using each object’s minimum bounding-box half-extent as the distance tolerance; pooled coverage is 98.4% using the mean minimum half-extent (Appendix II-D). We train one WBD-EX policy per object using the pro- cedure in Section III-B and distill a shared WBD controller from their trajectories. Expert proficiency varies with object geometry: sphere experts achieve the highest overall route completion, while experts for cubes, prisms, and cylinders still reposition across all body regions but with lower overall success rates (Appendix IV-D). Because distillation uses only trajectory segments that pass a quality filter (Appendix VII- B), less proficient experts yield valid demonstrations less efficiently, requiring more collection attempts per accepted trajectory.
