Streaming VLMs with Memory. Recent works on streaming VLMs (Xia et al., 2026; Chen et al., 2024a; Li et al., 2026; Wang et al., 2026) explore several complementary directions, including constructing higher-quality instruction-tuning data, designing architectures tailored to streaming inputs, and incorporating stronger video encoders. More recent studies (Lu et al., 2026; Shen et al., 2026) show that strong VLMs with a small local video window yield surprisingly strong performance on real-time questions on existing streaming video benchmarks. Another line of work focuses on the memory mechanisms. Some methods compress historical visual observations into textual summaries or memories (Liu et al., 2026; Guan et al., 2026; Yao et al., 2026), while others reduce the accumulated visual tokens through clustering or token merging (Zhang et al., 2024). Additional approaches organize historical information into hierarchical memory structures (Zeng et al., 2026; Zhang et al., 2026a; Xie et al., 2026; Liang et al., 2026), or maintain a fixed-size memory buffer that selectively preserves useful historical observations (Qian et al., 2025; Yao et al., 2025). Despite their differences, these methods generally address the growing streaming context by compressing historical information into a bounded token budget. In contrast, we represent long-term memory directly in model weights. Concurrent work (Chen et al., 2026) similarly moves long-term memory outside the attention context. However, it stores historical information in a separate test-time-training (TTT) branch with online-updated fast weights. In contrast, our method directly internalizes history into the VLM itself by dynamically generating low-rank parameter adaptations, without introducing a separate memory branch. Low-Rank Adaptation and Context Internalization. Low-rank adaptation (LoRA) (Hu et al., 2022) has been widely adopted as a parameter-efficient approach for adapting pretrained vision-language models (VLMs) and multi-modal large language models (MLLMs) to downstream tasks or new domains (Dettmers et al., 2023; Chen et al., 2024b; Liu et al., 2025). Recently, several works have explored using LoRA as a representation for encoding data-specific patterns (Shrestha et al., 2025; Yin et al., 2026) or contextual information (Charakorn et al., 2026, 2025). These approaches demonstrate that model parameters can be a good representation for storing information beyond conventional token-based context. However, they typically require additional optimization when adapting to a new pattern, making it difficult to apply them directly to evolving inputs. δ-mem (Lei et al., 2026) explores dynamically representing textual information through LoRA updates without test-time training. Nevertheless, it still relies on access to the historical context during inference.
