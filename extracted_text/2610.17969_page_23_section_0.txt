Corollary 3 (Invariant expressivity is preserved by gauge fixing). Under the assumptions of Thm. 4, for q = 0, pullback by C0 is an isometric bijection, in the uniform norm, between continuous functions on the compact product Q j Sj and continuous G-invariant functions on X. The proof is given in App. G.7. Any model class uniformly dense on the canonical coordinates is uniformly dense in the entire continuous invariant function class after composition with C0, which means that gauge fixing preserves the full continuous invariant function class. The mechanism is the scale-group counterpart of frame averaging and canonicalization for spatial symmetry groups, where a symmetry is likewise discharged by mapping each input to a canonical representative before an unconstrained network is applied (Puny et al., 2022; Kaba et al., 2023). The rescaling group here is abelian and acts by a positive scalar on each block. The RMS-one section is a single global slice with a unique canonical representative for each orbit. No frame averaging is needed. For the single residual-stream action, the invariant case is F(h) = f(C0(h)) and the degree-one equivariant case is F(h) = RMS(h)f(C0(h)). The dimensionless head and the explicit scale-state reconstruction are the q = 0 and q = 1 instances of the same representation theorem. The corollary covers targets that are unchanged by rescaling. Targets that depend on absolute magnitude require retaining the relevant scale information. Sec. I.5 discusses magnitude information as one possible explanation for the additive-noise results. E.6 Coupled neural units and the complete quotient When unit declarations couple different tensors, relative magnitudes can remain meaningful because two tensors with the same unit have a dimensionless RMS ratio. Thm. 5 identifies all the scale combinations that must be retained, namely the dimensionless scale monomials generated by ker A, where A collects the declared unit exponents. Keeping these combinations prevents normalization from discarding information that is unchanged by the declared rescalings. Thm. 4 uses independent rescalings, one rescaling for each block. Neural-unit declarations can instead couple several blocks to the same base units.
