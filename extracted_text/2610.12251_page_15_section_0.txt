Section 7 removes this map: held as records in the ring machine, the host carries out the same step by the dynamics, as the organism does. 6.2 Universal construction A universal constructor emits any prescribed object from a description of it. Here the objects are byte strings and the descriptions are run-length recipes. Every string has a recipe barely longer than itself, the encoder used later attains that bound, and the program P turns any recipe into the string it describes. For a byte x we write ν(x) = (−x) mod 256. Definition 6.4 (Recipe language). The set R ⊆Σ∗of recipes is generated by the grammar R ::= T ∗END, T ::= LIT | REP, END = 0x00, where a literal token LIT is a byte n with 1 ≤n ≤127 followed by n bytes, and a repeat token REP is a byte t with 129 ≤t ≤255 followed by one byte. The tag 128 occurs in no recipe. The decoding map δ: R →Σ∗is defined token by token by δ(LIT : n x1 · · · xn) = ν(x1) · · · ν(xn), δ(REP : t x) = ν(x) 256−t, δ(END) = ε, and extended by concatenation. Every payload byte is stored negated, so that a single subtraction from a zero register recovers it. Lemma 6.5 (Completeness of the recipe language). For every f ∈Σ∗there is τ ∈R with δ(τ) = f and |τ| ≤|f| + ⌈|f|/127⌉+ 1. Proof. Cut f into q = ⌈|f|/127⌉blocks of length 127, the last possibly shorter, and let τ be the literal tokens of the blocks followed by END. Each block contributes one tag byte and its own length, so |τ| = |f| + q + 1, and δ(τ) = f because ν is an involution. Proposition 6.6 (Optimality of the bound). If f ∈Σ∗has no two equal adjacent bytes, every τ ∈R with δ(τ) = f satisfies |τ| ≥|f| + ⌈|f|/127⌉+ 1. Proof. Write τ = t1 · · · tkEND. The tokens cover consecutive blocks of f, which has no two equal adjacent bytes, so a repeat token covers one byte with two and a literal token at most 127 with one more: |τ| = |f| + k + 1 and k ≥⌈|f|/127⌉. Lemma 6.7 (The encoder). Let describe(f) scan f from its first position. At position i, let ℓbe the length of the run of bytes equal to fi that starts at i, capped at 127. (i) If ℓ≥4, emit the repeat token (256 −ℓ) ν(fi) and move to i + ℓ. (ii) Otherwise let k be the least of |f|, i + 127 and the first position after i at which four equal bytes begin; emit the literal token covering fi, . . . , fk−1 and move to k. After the last byte, emit END. Then δ(describe(f)) = f and | describe(f)| ≤|f| + ⌈|f|/127⌉+ 1 for every f ∈Σ∗, with equality exactly when f contains no four equal consecutive bytes. 15
