Parameter Space for Tuning. The search space used for automated configuration is derived from the set of modules in Table 1. We consider the full configuration space with the following modifications: • Boundary handling: The Boundary Correction module is excluded, as the BBOB problems are defined on unbounded domains. • Population size: The population size parameters λ and µ are included as tunable integer parameters in [1, 50d], with the constraint µ ≤λ. All remaining modules and parameters correspond directly to those listed in Tables 1 and 2. The resulting configuration space is constructed programmatically using the ConfigSpace interface provided by ModCMA, ensuring that all sampled configurations correspond to valid algorithm instances. Algorithm Configuration. We use the SMAC framework Lindauer et al. (2022) to perform per-function configuration. For each BBOB function, SMAC is run independently with a budget of 50 000 configuration evaluations. Each evaluation corresponds to running a ModCMA configuration on a single problem instance. SMAC employs an intensification procedure in which promising configurations are evaluated on multiple instances.
