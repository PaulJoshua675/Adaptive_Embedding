F.3 Perturbations through the readout A separate perturbation experiment adds to every looked-up Qwen row an error with squared norm 0.05∥e∥2 or 0.2∥e∥2. The error lies along a cho- sen subspace: norm only, direction only, isotropic, or the top or bottom 16 right-singular directions of each head’s value or key projection. A row has the same error wherever it is read. We compare next-token distributions on identical observed pre- fixes from 256 held-out FineWeb-Edu sequences of 1,024 tokens. These come from shard 001, ex- cluding the first 400 documents used for the CPU readout analysis; KL ratios are paired on the same tokens. Qwen’s raw rows have kurtosis 2.94, while the value outputs Wve have kurtosis 93.5. At error en- ergy 0.2∥e∥2, perturbations along the top 16 right- singular directions of the value projection change the memory readout 1.6 times as much as perturba- tions along the bottom 16, yet give slightly lower KL (ratio .92 [.88, .96]). Pure norm errors incur more KL than equal-energy direction errors (direc- tion/norm .86 [.83, .88]). F.4 LongCat damage model The damage model summarizes codec error with a direction-error proxy S and a relative norm- change proxy dN. For each codec, D is the arithmetic mean over LongCat’s twelve tables of P i ∥ˆei −ei∥2/ P i ∥ei∥2. For LS-scaled codes we use S = D and dN = √ 1 −D −1; norm-restored variants retain the corresponding LS value of S and set dN = 0. For the norm-expanding family, we use S = D/(1 + D) and dN = √ 1 + D −1; a uniform multiplicative gain 1 + g gives S = 0 and dN = g. These are codec-level approximations, not direct averages of measured row angles and norm changes. The pure-direction controls set S explicitly and preserve each row’s norm. Output KL is evaluated on 32,768 FineWeb-Edu tokens, arranged as sixteen 2,048-token sequences, from the stream after its first 200,000 documents. The model is KL = c0 + k Sp + k∥dN2. (15) The offset c0 = .0021 is the KL measured after a very small pure-direction perturbation (S = 10−5) on LongCat. It represents a measured perturbation response, rather than a universal lower bound on KL; an unperturbed repeat in the same process gives zero KL. The other constants are k = .198, p = .79 and k∥= 2.19. We fit them once on 29 LongCat codec configurations, with a log-RMSE of .053. Figure 3 plots KL against S for these con- figurations. It provides a descriptive comparison with the fixed-code gain tests. The model matches the codecs it was fitted on to within about 10%. It also predicts the held-out pure direction edits, the triangles in the figure. For S from 10−5 to .3, measured KL is 0.89–1.01 times the prediction. The model fails in three cases. It overpredicts the gain of norm restoration at 1.5 bits about twofold. It underpredicts errors that inflate the norm at relative MSE .13–.3 by 1.3–2.0×. It also misses a coherent gain of ±3% on all rows by 1.5–2.0×. We fitted and checked the model on LongCat only, so we use it as a description. 23
