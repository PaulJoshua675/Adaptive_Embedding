Parity, PARk(x) = Qk i=1 xi, puts its whole spectrum at degree k and nowhere else, so sweeping k from one to six moves the target’s order through six values while the input space, the data, the primitive set and every search parameter stay fixed. We take parity over the first k of the eight inputs, so a run must also work out which inputs matter. The 6-multiplexer, in which two address inputs select one of four data inputs, is the control. Its order is 3, lower than that of PAR4 through PAR6, and its spectrum is spread rather than concentrated; as Section 3.4 explains, it is also not symmetric, which is what makes it the case where a capable learner should buy nothing. Panel (b) shows what is lost outside this domain, and why the standard benchmarks cannot serve as the instrument. There the order has to be read off an error curve, and for a target such as √x the curve descends slowly, so the answer is two, eight or undefined depending on where the tolerance is drawn. We still use two continuous targets, Nguyen-11 (xy) and Nguyen-8 (√x), chosen at the extremes of that reading with ε = 10−4, sampled at 1000 points and split in the same proportion, but only to check in Section 4.3 that the ordering found on the cube survives outside it. 3.3 Order preservation under an affine learner A linear learner is, in a specific and useful sense, no help at all; the proposition below makes that precise. Proposition 2 (Affine learners are order preserving). Let f(z) = αz + β with α̸ = 0. Then ONLε(f ◦g) = ONLε(g) for every g. Consequently a pipeline with an affine learner attains relative error ε on a target y only if the evolved program satisfies ONLε(g) ≥ONLε(y). Proof. If a polynomial p of degree d approximates g to relative error ε then αp+β has the same degree and approximates αg + β to the same relative error; the converse follows with α−1. Hence the two minimal degrees coincide. If in addition f ◦g approximates y to relative error ε, then ONLε(y) ≤ONLε(f ◦g) = ONLε(g). Figure 3 illustrates the proposition, in the same way that a plot of a non-separable problem illustrates the limits of a perceptron. Plot the target against the value of the evolved program: an affine learner is a straight line in that plane and nothing else, while a learner of capacity V is any function of the program with at most V monotone pieces. Take PAR4 and two programs a run might produce. On the left the program is the degree-1 sum of the four relevant inputs, which sorts every input into one of five groups with the target alternating between +1 and −1 across them. The best affine learner is the flat line and explains none of the variance; a learner with four monotone pieces recovers the target exactly. On the right the program is the degree-4 product. Now the affine learner is exact, but only because the program has already built the whole of the target by itself. The target and the two learner classes are the same in both panels, so the difference lies entirely in what the program supplies. Figure 3: Illustration of Proposition 2.
