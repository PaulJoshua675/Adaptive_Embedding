Generators first bid to produce a candidate solution. Verifiers then bid against one another and the submitter to assess it; if the submitter wins, the rollout terminates. Otherwise, refiners bid against one another and the submitter using the candidate and verification feedback; a winning refiner replaces the candidate and returns control to the verification stage. The submitter therefore acts as an endogenous stopping threshold: another reasoning step is purchased only when an agent values further work more highly than submitting the current answer. All agents use prompted Gemini-3.5-flash, with three prompts per role (Section D.3). A small multi-layer perceptron (MLP) estimates agent values from structural features and the output of a prompted assessor that scores the current candidates. We train the value estimator and evaluate on held-out Omni-MATH problems (Gao et al., 2025), using the domains and splits from Fisch et al. (2026). As reported in Table 2, the auction reaches 74.83% accuracy with only 0.28 refinements per problem, outperforming fixed one- and two-refinement baselines and a prompted adaptive orchestrator inspired by MALT, while incurring comparable cost. All comparisons with the auction-based method are statistically significant at 𝑝< .05 by McNemar’s test.
