For each question, the harness retrieves a memory block from the written bank, the frozen answer model answers using only that block, and the frozen judge compares the answer with the reference and weighted rubric. This scores deployable bank behavior. Directly asking a judge whether retrieved text “contains the answer” would not test whether contradictory or stale memories cause an incorrect response. 6.2 Per-chunk recall reward For chunk t, let Rt be positive probes and Pt traps.
