For a normalized credit vector u ∈Rm and clipping radius κ > 0, define z⋆= arg min z∈Rm 1 2∥z −u∥2 2 s.t. 1⊤z = 0, −κ ≤zi ≤κ. (33) The feasible set is non-empty, closed, and convex, and the objective is strictly convex, so the pro- jected vector z⋆is unique. The KKT conditions give a scalar equality multiplier λ for which the box-constrained coordinate minimizer is z⋆ i = clip(ui −λ, −κ, κ). (34) It remains to choose λ so that P i z⋆ i = 0. Define h(λ) = X i clip(ui −λ, −κ, κ). (35) The function h is continuous and non-increasing, with h(min i ui −κ) = mκ, h(max i ui + κ) = −mκ. (36) A root therefore exists by the intermediate value theorem and can be found by monotone bisection on λ ∈[min i ui −κ, max i ui + κ]. (37) The scalar root need not be unique if h is flat at zero, but every such root yields the same unique projected vector z⋆. For the small m used in our experiments, this scalar solve is negligible relative to evaluator scoring. Mean-preserving action advantages. CASI forms eA(g) i = ˆA(g) + βz(g) i . (38) Since P i z(g) i = 0, 1 m X i eA(g) i = ˆA(g). (39) Thus shaping changes only the relative action-level coefficients within the rollout. This does not imply that the shaped policy gradient equals the broadcast policy gradient, because different action spans multiply different score functions. Setting β = 0 exactly recovers ordinary broadcasting.
