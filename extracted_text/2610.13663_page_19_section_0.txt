Ablation studies 6.1. Simple and detailed prompts This ablation compares the simple and detailed SNN prompt configurations defined in Section 4.3. The detailed configuration combines the method-class taxonomy, structured Chain-of-Thought, and coverage map described by the general framework in Section 3. The full Analyst and Coder prompts are provided in Supplementary Section F. The MNIST configurations are compared in Table 2. For Claude Opus 4.6, the detailed prompt increased the mean maximum accuracy over ten matched complete runs from 91.13 ± 0.44 % to 92.15 ± 0.62 %, and the best result from 91.65 % to 92.83 %. The difference between the prompt variants is confirmed by a two-sided exact Wilcoxon signed- rank test (𝑊= 5, 𝑝= 0.0195), with the detailed prompt yielding higher accuracy in eight of ten pairs; the mean paired difference is 1.02 ± 0.90 percentage points (Table 17), meaning that the effect is comparable in magnitude to the between-run variation. Ten complete runs were performed with each prompt variant for Perplexity Sonar and Qwen3-30B-A3B-Instruct- 2507. With the simple prompt, none of the 250 decoders proposed per run outperformed the baseline, so the run maximum for both models exactly matched the baseline of 79.88 % in all ten cases. The detailed prompt changed the results of both models, but to different extents. The 90 % threshold was fixed before the run series as a reference point for MNIST; for the digits dataset, where the baseline is already 90.83 %, an analogous reference point was set at 93 % Section 4.5 and is not used in the tables in this section. For Perplexity Sonar, the individual-run maxima ranged from 90.93 % to 92.70 % (Table 15), with a mean of 91.76 ± 0.56 %, so the 90 % threshold was exceeded in all ten runs. For Qwen3-30B-A3B-Instruct-2507, the mean maximum was 85.88 ± 2.42 %, and the best run reached 89.16 % without exceeding the specified 90 % threshold.
