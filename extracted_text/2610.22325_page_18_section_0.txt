B.3 TRAINING SCHEDULE Dense4D is trained for a cumulative 686,000 steps, taking approximately 490 hours on four GH200 GPUs. We report the final checkpoint, without weight averaging. AdamW (Loshchilov & Hutter, 2019) uses weight decay 0.05 and peak learning rate 2 × 10−5, with linear warm-up and cosine decay. Gradient norms are clipped to 1.0 separately for the backbone and each head; activation checkpointing covers attention-block pairs. The final training configuration samples BEDLAM2, THuman2.1 and MammaSyn with probabilities of approximately 65 %, 22 % and 13 %, respectively. For each person, the number of input frames is sampled from S ∈{2, 3, 4, 6, 8, 12, 24} with weights 1, 1, 1, 1, 2, 3, 3. The batch contains 96 images per step, consistently packed as 24 images per GPU; the number of person sequences varies with S. Frames are sampled without replacement where the track length permits. Photometric augmentation uses colour jitter with probability 0.9 and greyscale with probability 0.05; jitter is shared across frames with probability 0.7. Brightness, contrast and saturation factors lie in [0.5, 1.5], with hue in [−0.1, 0.1]. C EVALUATION PROTOCOLS C.1 PANOPTIC STUDIO HUMANS We evaluate 40,779 human queries across all 156 clips of 150 frames, retaining the Dynamic-3DGS pseudo-labels (Luiten et al., 2024). Queries on held objects or with invalid annotations are excluded consistently across methods. The official TAPVid-3D evaluator uses benchmark intrinsics, depth- adaptive thresholds and one median rescaling per clip; scores are averaged over clips. The dataset contains 49 two-person and 107 single-person clips. SAM 3 (Carion et al., 2025) supplies person masks, and the frame with the largest mask is selected as each person’s reference. We fit one scale per person across the clip using pixel-aligned VGGT-Ω and predicted human depths on confident mask interiors. The fit selects the scale supported by the most depth ratios within 5 %, then refines it using the median inlier ratio. VGGT-Ωsets the scale only; our predicted depth supplies the track geometry, without temporal smoothing. A match is visible when its reference-space residual is below τ = 0.005. Undoing the normalisation in Eq. (2) gives a tolerance of sτ: for example, s = 2 m gives 1 cm. C.2 BASELINE IMPLEMENTATIONS All baselines use the same human queries and evaluator. 4RC. 4RC (Luo et al., 2026) encodes all 150 frames jointly and decodes each query at each target time. We project its points with its own intrinsics, then lift the resulting 2D tracks at unchanged depth using benchmark intrinsics. This gives 14.4 / 24.1 AJ / APD, versus 4.1 / 7.4 for its original camera-space points; it has no occlusion output. V-DPM. V-DPM (Sucar et al., 2026) processes pairs drawn from 14 temporal chunks of at most 11 frames, with frame zero as reference; we align scales on shared reference pixels. Confidence ≥1.5 marks visibility. We reproject each query’s predicted position at its query frame using benchmark intrinsics, giving (u, v); (uq, vq) are the supplied query pixels. Without using ground-truth 3D, we fit u −cx ≈ku(uq −cx) + bu and v −cy ≈kv(vq −cy) + bv by least squares per clip, then set k = (ku + kv)/2. We correct points as x′ = (x −z bu/fx)/k, y′ = (y −z bv/fy)/k, z′ = z, where fx, fy, cx, cy are the benchmark intrinsics.
