A fixed-point curve in the CTM not need to run the recurrence. Predicting the actual class still does, because the decision is read from the state the recurrence produces. The query’s direct effect on entropy, measured as a one-step counterfactual, is modest—it is the routing of attention, compounded over many ticks and captured by the ablations, that makes the query matter.
