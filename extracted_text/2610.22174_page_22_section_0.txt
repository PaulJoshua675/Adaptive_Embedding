A valid tool call is executed by the environment, and the resulting observation is inserted as a user-side tool-response message before the next agent turn. Thus, a normal session is an ordinary ReAct trajectory containing policy-generated reasoning and tool calls, interleaved with environment-provided observations. Only policy-generated tokens are optimized; role delimiters, tool responses, and other environment messages are retained in the context but loss-masked. Let 𝐿′ denote the maximum context length of one session and let 𝐵denote a reserved generation budget. In our experiments, 𝐿′ = 131,072 and 𝐵= 16,384 tokens. Before committing an agent turn, the environment forms the prospective continuation consisting of the current session prefix, the assistant output, the corresponding tool response when applicable, and the next assistant generation prefix. If its length exceeds 𝐿′ −𝐵, the prospective turn is discarded: neither its generated tokens nor its observation becomes part of the retained trajectory. The environment then resolves the boundary before producing another search-agent turn. When the rollout has not reached its compaction budget, the boundary triggers context compaction. We allow at most ten successful compactions per rollout. If the summary cannot be parsed, or if the compaction budget has already been exhausted, the environment instead asks the current session to terminate with a final answer: Forced-answer Message You have reached the maximum context length.
