A GILBERT BLOCKS AND THE SAFETY SET Section 3 places every routing decision on a block of visual tokens and protects a safety set Sq. This appendix gives the full construction that both generators use. We first explain why the token order matters and define the frame-sliced Gilbert order. We then define the blocks, the safety set, and the executed attention mask, and we report the resulting block and candidate counts for Wan2.2 and Stable Diffusion 3.5. Why the token order matters. A routing unit covers a contiguous run of tokens, and one draw keeps or drops a whole run as a key block. Both generators store visual tokens in raster order, which scans each latent frame row by row. A contiguous raster run is therefore a thin horizontal strip. On the 32 × 32 token grid of Stable Diffusion 3.5, a 128-token run spans four entire image rows. Its attention mass mixes tokens that lie far apart, while its vertical neighbors lie whole rows away in the sequence. As a result, a route decision on a raster run couples unrelated content, and a small spatial neighborhood cannot be expressed as a few runs.
