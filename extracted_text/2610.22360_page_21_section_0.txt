C.4 Motion-Issue Accuracy Motion Understanding four-class Exact is correct only when the binary answer and primary issue match the reviewed label. Its classes are Correct, Unnatural Motion, Incorrect Motion, and Deformation Artifacts. Four-class Macro Recall averages recall across these classes. Joint explanation recall within an issue requires both a correct rejection and an accepted explanation, and differs from binary rejection recall. C.5 Uncertainty For the ten-task main results, we use 10,000 bootstrap replicates. Native clusters are resampled independently within each task, retaining linked branches together; task scores are then averaged with equal weight. Fine-grained Geometry positives and negatives are resampled jointly by T-LESS object pair. Shared cluster draws are used across models. Table E2 reports marginal intervals, not significance tests for arbitrary model pairs. For the 400-example human comparison, 20,000 paired replicates resample source clusters within each task and apply the same draws to human and GPT-6 Astra responses. GPT-6 Astra is the fixed comparator, selected by its overall point estimate; the best model is not reselected within replicates. These intervals describe the same-subset comparison and retain the Motion Understanding input-modality difference. Generation gain intervals resample the forty input pools, retaining all sixteen candidates and final labels within each sampled input and using the same draws for Random and Oracle. The intervals characterize sampling uncertainty, not Judge bias, API drift, or changes in evidence format.
