Before timing, each variant is executed once for compilation and bitwise comparison against a dense reference. Scaled- add references are computed in FP32 and rounded to BF16. Each variant then receives three warm-up calls and 50 timed calls. We use time.perf_counter, with CUDA synchronization immediately before and after each call. The order of the three variants is rotated and reversed across iterations to reduce execution-order bias. Input generation, initial compression, buffer construction, compilation, validation, and output release are outside the timed region. A.3 Training Modded NanoGPT The base model architecture, data, hyperparameters, and training code were taken from the baseline of Phase 3 of the Modded NanoGPT project. The code was then modified to reduce memory consumption without changing behavior. BF16 precision was used for all activations, momentum and weights. Activation checkpointing was applied to the RMSNorm layers, and the final output head was computed in chunks. Optimizer fusion was also used (Jiang et al., 2021). These do not affect the training process or model outputs, but significantly reduce the memory consumption. This is done to ensure a well-optimized baseline for a fair comparison. The Muon optimizer with 12 Newton–Schulz iterations is used, along with a batch size of 256 accumulated over four microbatches of 64 sequences, each of length 1024 tokens. The timing comparison measures a complete optimizer step, including all four microbatches. LCT is applied to all matrix weights, activations, and momentum buffers. 1-D biases are excluded. Custom functions which compress cached activations are used for the feed-forward layers, attention block, and embedding block. Each type of compressed cached activation is given in Table 9. Activations make up the majority of the storage; model and optimizer states take up 767.88 MiB. In order for torch.compile to work, the code is carefully structured so critical parts are compiled, while graph breaks are used around LCT operations, since compiling LCT does not lead to speedups. 13
