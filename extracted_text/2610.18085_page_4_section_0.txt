We fix one balanced representative of each orbit (Sec. 3.1), derive what AdamW needs to keep two runs equivalent (Sec. 3.2), show that restarting both runs from the same balanced state makes the resumed runs identical (Sec. 3.3), and prove that no standard optimizer keeps two runs equiv- alent under a shared learning rate (Sec. 3.4). 3.1 Scalar Orbit Canonicalization All points on an orbit compute the same function, so any one of these points can represent the orbit. We use the point at which the two matrices of each exact pair have equal Frobenius norms. The exact restart (Sec. 3.3) and SAGGS (Sec. 4.1) both move a model to this point. Proposition 1 (Unique balanced representative of a scalar orbit). For an exact symmetry pair (Ap, Bp) with positive Frobenius norms, let A⋆ p := Ap/c⋆ p and B⋆ p := c⋆ pBp with c⋆ p := (∥Ap∥F / ∥Bp∥F)1/2. These matrices form the unique Frobenius-balanced point on the orbit, with A⋆ p F = B⋆ p F. The balancing map (Ap, Bp) 7→(A⋆ p, B⋆ p) is independent of the starting or- bit representative, idempotent, and forward-preserving. Balancing sends every point of an orbit to the same point, so two checkpoints that differ only by an orbit move end up with identical weights after balancing. 3.2 AdamW Trajectory Equivariance The gradient normalization built into Adam cannot make parameter updates equivariant. With covariantly transformed moments, Adam’s normalized direction cancels the gradient scale when ϵi = 0; a common positive ϵi generally prevents exact cancellation. Even when this cancellation is exact, two runs that start on the same orbit do not stay equivalent. Adam then applies the same update to both runs, whereas staying on the same orbit requires each parameter to move in proportion to its own scale, that is, c times more for the enlarged block and c times less for the shrunken block.
