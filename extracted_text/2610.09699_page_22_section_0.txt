For some functions, configurations fail to reach the target within the evaluation budget, resulting in large or infinite ERT values. 9.3 Interpreting the Configuration Space While the tuning results show that ModCMA can adapt effectively to different problem characteristics, they do not directly reveal which components of the algorithm drive these improvements. To gain further insight, we analyze the configurations evaluated during the SMAC Lindauer et al. (2022) runs using Shapley-based feature attribution Lundberg and Lee (2017), following the setup of Kononova et al. (2025). Data collection. During the SMAC optimization process, we evaluate many configurations. Each evaluation yields a configuration together with its performance. We collect these for all functions into a dataset of configuration–performance pairs, using the internal SMAC cost (AOCC) as the performance measure. Surrogate model. To enable feature attribution, we train a regression model that predicts a con- figuration’s performance from its parameter settings. We use a CatBoost regressor Prokhorenkova et al. (2018), a gradient-boosting model designed for handling categorical variables. We train a separate model for each function on the full set of evaluated configurations. SHAP value computation. Given the trained surrogate model (CatBoost), we compute feature attributions using the TreeSHAP method Lundberg and Lee (2017). For each evaluated configuration, SHAP assigns a contribution value to every parameter, indicating how much that parameter influences the performance. Note that a negative contribution value indicates a positive impact on performance, as the cost is minimized. SHAP values are expressed in the same scale as the surrogate model output, i.e., the SMAC cost. 22
