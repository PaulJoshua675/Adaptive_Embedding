The first group contains sparse retrieval and classical query expansion: BM25, BM25 with RM3, BM25 with Rocchio-style feedback, and BM25 over a doc2query-T5 expanded Lucene in- dex [23]. The doc2query-T5 baseline represents document-side expansion, while XViewRank keeps the sparse index unchanged and learns to combine query- side retrieval views. The second group contains LLM expansion baselines. We include Zero-shot pseudo-doc, a pseudo-document expansion baseline inspired by Query2doc [27]; unlike the original few-shot Query2doc setting, it uses no in- context demonstrations. We also include Zero-shot CoT, a chain-of-thought-style query expansion baseline following prompt-based query expansion [10]. Finally, we compare with the original Exp4Fuse setting, which fuses the original query view with the hypothesis view. The third group contains fixed fusion baselines over the same matched view set used by XViewRank. In particular, RRF over matched views uses the original view, the hypothesis view, and the same step- back view as XViewRank; therefore its comparison isolates fixed fusion from learned fusion under identical inputs. We also include a dev-tuned weighted CombSUM baseline, where nonnegative weights for the three normalized view scores are selected on the development set and then fixed for DL19 and DL20. This setup separates two questions. The original Exp4Fuse baseline measures the established two-view LLM expansion setting. The matched-view fusion base- lines measure whether the same input views are better combined by fixed rules or by the learned XViewRank scorer. 4.4 Main Results Table 1 reports the main results. Exp4Fuse uses the original and hypothesis views, following its published two-view setting. CombSUM, weighted Comb- SUM, RRF, and XViewRank all use the same original, hypothesis, and step- back views; these rows therefore provide the matched-input fusion comparison. XViewRank obtains the highest nDCG@10 and MAP among the reported meth- ods on both TREC DL 2019 and 2020. Compared with BM25, classical feedback, and document-side expansion with doc2query-T5, the gains show that generated query views provide useful additional retrieval evidence when their scores are fused carefully. Compared with fixed matched-view fusion methods, including RRF and dev-tuned weighted CombSUM, XViewRank gives higher nDCG@10 and MAP while keeping Recall@1000 nearly unchanged. We test the main com- parison against RRF with paired sign-flip tests over queries and use bootstrap confidence intervals as an additional check; because TREC DL contains few topics, we interpret significance conservatively. This pattern suggests that the learned scorer mainly improves head ranking by combining cross-view score ev- idence more effectively, rather than simply expanding the candidate pool.
