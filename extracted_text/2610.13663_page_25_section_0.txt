Baseline SNN model The Correlation Classwise Network (CCN) Sboev et al. (2025); Kunitsyn et al. (2025) was selected as the baseline model. Its architecture, input encoding, supervisory-signal delivery, and plasticity rule are adopted without modification; the agent’s modifications are restricted to the output-spike-activity decoder. Input expansion using Gaussian receptive fields (GRF) and the bagging ensemble Rybka, Davydov, Sboev, Vlasov and Serenko (2024) are not used because preliminary experiments on MNIST showed no appreciable gain. The approach is applied to two datasets: MNIST (28 × 28, 𝑁= 784 spike generators) and the scikit-learn digits Pedregosa et al. (2011) (8 × 8, 𝑁= 64). Both have ten classes, pixel values are normalized by the 𝐿1 norm of the input vector, and the number of output LIF neurons is 𝐾= 10. The network has two layers: the input layer contains 𝑁spike generators, and the output layer contains 𝐾Leaky-Integrate-and-Fire (LIF) neurons; the connections are fully connected and trainable, with no lateral connections. The input vector 𝑉= (𝑣1, … , 𝑣𝑁) is converted into an array of correlated spike sequences {𝑆𝑖}: a reference sequence 𝑆0 of length 𝑁𝑡is constructed with constant spacing 𝑁ref; component 𝑣𝑖is interpreted as the target Pearson correlation coefficient between 𝑆𝑖and 𝑆0, and 𝑆𝑖is obtained by randomly removing some spikes from 𝑆0. Supervision is implemented using two currents applied to the output LIF neurons: for a sample of class 𝑘, a positive current 𝐼exc = 107 pA, synchronized with the 𝑆0 spikes with a shift 𝜏𝑠, is applied to the corresponding neuron; the other neurons receive an inhibitory current 𝐼inh = −103 pA. The weights are adjusted using a local multiplicative STDP rule with a bounding symmetric nearest-neighbor scheme: Δ𝑤(Δ𝑡) = { 𝐴+ ⋅𝑤𝜇+ ⋅𝑒−Δ𝑡∕𝜏+, Δ𝑡> 0, 𝐴−⋅𝑤𝜇−⋅𝑒Δ𝑡∕𝜏−, Δ𝑡< 0, where Δ𝑡= 𝑡post −𝑡pre, 𝑤is the current weight, 𝐴± are the potentiation and depression amplitudes, 𝜏± are the window time constants, and 𝜇± are the exponents of the weight dependence. The values of all network and STDP-rule parameters are provided in Table 10. B.1. SNN experimental protocol MNIST data split. The standard MNIST test set, containing 10 000 samples, was not used during the agent search. The original training set of 60 000 samples was stratified into training and validation subsets at a 80:20 ratio. The parameters of each proposed decoder were estimated on the training subset, whereas the classification accuracy passed to the agent-search log was calculated only on the validation subset. After the specified search budget was exhausted, the decoder with the highest validation accuracy was selected. The selected decoder was retrained on the complete original MNIST training set and evaluated once on the standard test set. Test samples, their spike representations, and their labels were not provided to the agents and were not used to select the decoder structure or tune its hyperparameters.
