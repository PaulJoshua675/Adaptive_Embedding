Palmer 5.4 Failure Analysis: Cold Embedding Degradation In lora_v4 and lora_v6, we attempted to delimit syntactic conditioning regions using dedicated special tokens (<source>, <syntax>, and <no_syntax>). This intervention resized the shared vocabulary from 250,100 to 250,103, introducing uninitialized rows into the embedding matrix. Because standard LoRA freezes the base embedding table to conserve GPU memory, these newly added token vectors received zero gradient updates and remained fixed random vectors throughout training. Presenting the encoder with static random vectors at structurally critical positions caused total optimization failure: training loss stalled above 30.0 and dev chrF++ collapsed to 8.91. While unfreezing the full embedding table resolved the representation issue conceptually, it immediately exhausted T4 GPU memory. In lora_v5, we resolved this constraint by passing functional syntax as or- dinary text prefixes (such as nah->es: ADV HEAD NP.POSS) segmented with the existing SentencePiece vocabulary. Reusing pretrained subword representations stabilized optimization without custom checkpoint surgery and restored dev chrF++ to 51.69. All subsequent runs retain this plain-text prefix format. 5.5 Sparse and Dense Syntax Coverage To assess how annotation density affects conditioning, we compared two versions of the finite-state analyzer. In lora_v7b, the early prototype produced functional syntax tags for only 29.5% of corpus sentences. Adding these sparse prefixes yielded virtually identical development scores to the unconditioned lora_v7a con- trol (51.31 versus 51.22 chrF++) and slightly degraded directional test accuracy. Because sparse tags occurred inconsistently, the model treated them as shallow domain indicators rather than reliable syntactic grounding. In lora_v8b, once rule expansion and reconstruction filtering raised tag coverage to 95.8%, syntax conditioning produced a +1.33 chrF++ gain on complex nah →es polysynthetic targets and a +0.51 spillover gain on es →nah. This demonstrates that syntactic conditioning requires high annotation density to guide sequence generation effectively. Precision in the reconstruction filter remains critical, as inaccurate tags would inject systematic structural noise. 5.6 Final lora_v9c Ablation and Model Selection To isolate the precise contribution of dense syntactic prefixes on the final training set, we evaluated a controlled ablation where the extracted syntax tags were stripped from input sequences during training and inference (strip=True), leaving only bare source text. On the development split, the syntax-stripped control reached 58.91 chrF++, while the syntax-conditioned model (lora_v9c_b, strip=False) reached 58.46 chrF++, a minor difference of −0.45 points.
