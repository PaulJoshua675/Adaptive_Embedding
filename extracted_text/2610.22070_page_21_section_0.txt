B.2 Data Pipeline and Annotation Construction As illustrated in Figure 3-1, our data construction pipeline consists of three components: a Question Generator, an Answer Generator, and a Verifier. To construct the streaming video training dataset, we begin with an event description associated with a specific temporal interval. These descriptions are obtained either from the original annotations of the 14 datasets described in Section B.1, or from the question–answer pairs provided by TimeLens and ET-Instruct. Question Generation. We first prompt the Question Generator to generate a new question for a target event, conditioned on the full video, the event description, and its corresponding temporal interval. By observing the full video, the Question Generator can leverage both the target event and its surrounding visual context to construct a question that is grounded in the video content. The prompt explicitly controls the question type, which is sampled from four categories: open-ended, multiple-choice, Yes/No, and counting questions. Along with each generated question, the Question Generator also produces an expected answer, which is subsequently used during the verification stage. To cover different temporal reasoning scenarios, we further assign each question a randomly sampled question-timestamp type from three categories: past, real-time, and future. Given a target event spanning the interval [tstart, tend], a past question is assigned a timestamp t > tend, requiring the model to retrospectively recall an event that has already occurred. A real-time question is assigned a timestamp t ∈[tstart, tend], such that the target event is ongoing when the question is asked.
