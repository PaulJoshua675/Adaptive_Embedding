The w/o goal image configuration removes this image while retaining the initial image and instruction; hand and camera trajectories remain outputs. For multiple windows, visual subgoals are the goal images specifying intermediate stage targets. Removing the goal image from every window is distinct from retaining a final visual goal while removing only intermediate subgoals. Matched condition-ablation protocol. The with/without-goal corpus contains 188 paired genera- tions over 94 windows, with two matched seeds per window. Both settings use the same checkpoint, initial images, instructions, and sampling settings, including 50 denoising steps and CFG 2. Each window starts from its reference initial image. Only the goal-image condition is removed; the no-goal model does not receive future hand or camera states. Comparisons without a goal image.
