Two-tier: modality-asymmetric two-level rule Two-tier uses high and low thresholds with different image- and text-side multipliers: τ v H,s = bµv s + 3.0 bσv s, τ t H,s = bµt s + 2.0 bσt s, (S11) τ v L,s = bµv s + 1.5 bσv s, τ t L,s = bµt s + 1.0 bσt s. (S12) For an off-diagonal pair, the high tier accepts strong ev- idence in either modality, whereas the low tier requires agreement between modalities: M strong s,ij = 1[Av ij > τ v H,s] ∨1[At ij > τ t H,s], (S13) M weak s,ij = 1[Av ij > τ v L,s] ∧1[At ij > τ t L,s]. (S14) The final mask is M TT s,ij = ( M strong s,ij ∨M weak s,ij , i̸ = j, 0, i = j. (S15) All comparisons are strict; equality to a threshold does not trigger. The thresholds are not clipped to [−1, 1], and there is no cap on candidate count. Because the matrices in Eq. (S5) are symmetric, M TT is symmetric. The imple- mentation nevertheless uses its transpose explicitly in the t2i branch to preserve the score-axis semantics. The actual parameters are m = 0.99 and a warm-up of Tw = 500 training masker calls. The first 500 training calls update the EMA but return an all-zero mask. The 501st call first updates the EMA and then applies Eq. (S15). The con- structor parameter init threshold=0.95 is displayed in warm-up logs only and does not enter a decision. Count-matched Random At training call s, the reference inclusive run records the to- tal number of unordered pairs selected in the upper triangle, Ks = X 1≤i<j≤Bs M ref s,ij. (S17) Random replays this budget in the same training-call order. For Us = {{i, j} : 1 ≤i < j ≤Bs}, it samples exactly Ks pairs uniformly without replacement: Rs ∼Uniform{S ⊆Us : |S| = Ks}. (S18) The sampled pairs are mirrored to form a symmetric mask with a zero diagonal and are injected using the hard re- placement in Eq. (S16). Sampling uses a private CPU ran- dom generator with base seed 1. The reference and Ran- dom runs otherwise use the same training configuration and batch schedule.
