F CHAOTIC SYSTEMS We examine how model size, sampling, and fine-tuning affect point accuracy and long-run dynamics. F.1 SETUP AND FORECASTING PROTOCOLS Dataset. We train PathFM on the PANDA-72M reproduction corpus (Lai et al., 2026), GilpinLab/dataset-panda72M-repro, containing 190,006 trajectories of 4,096 steps with 3–10 state coordinates from individual DYSTS systems and skew-product combinations. Reserving trajectories involving ten parent systems leaves 156,784 training trajectories and 33,222 validation trajectories. Point evaluation uses the separate base40 and skew40 test releases. Models and training. The quantitative comparisons use the 75M and 126M PathFM families with native 256-step horizons, trained for 2M flow-matching updates followed by 100k terminal-decay updates. We train the 75M variant to approximately match PANDA’s parameter count (74.2M versus 71.6M). The 126M backbone has 12 transformer blocks and feedforward width 3,072; the 75M model uses 11 blocks and width 768. Both initialize their backbones afresh while retaining trainable input-patch embeddings. The global batch budget is 384 channel rows, with four flow draws per window. The learning rate is 10−4 after 500 warmup updates, followed by the 100k linear terminal decay to zero; weight decay is zero and EMA decay is 0.999. Main results use ten-step Euler sampling, source standard deviation 0.86, and seed 42. Training-progress evaluation. Figure 6c uses the same 2,048 fixed three-channel validation windows for both model sizes, selected randomly from the validation shard. Each window supplies 512 context steps and 256 forecast steps from a distinct held-out trajectory. We evaluate EMA weights with 16 stratified samples and ten Euler steps. Context-standardized sMAPE is averaged over channels and forecast steps, then across the 2,048 trajectories. Point forecasts.
