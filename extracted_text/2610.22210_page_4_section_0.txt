TASC preserves topology by protecting 1-isthmuses and deleting a candidate only when it is simple in both the fore- ground union and its class-specific support. Let Simple(v; A) indicate that deleting v is simple in the binary set A, and let Ist1(v; A) indicate that v is a 1-isthmus of A. A candi- date is permanently protected if it is a 1-isthmus in either U(S) or Uc(S); otherwise, delete it only if it is simple in both. Each accepted deletion therefore preserves the topol- ogy of the foreground union and class c, while leaving all other class supports unchanged. Because the predicates are evaluated on the current carrier, deletions may expose ad- ditional 1-isthmuses, which we protect when we encounter them later. We apply these predicates using the 8/4 fore- ground/background adjacency pair in 2D and 26/6 in 3D. In 2D, the 1-isthmus predicate holds when the proper neighbor- hood contains exactly two 8-connected foreground compo- nents; in 3D, we use the audited DGtal 26/6 predicate [8].
