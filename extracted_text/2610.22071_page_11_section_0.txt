Scoring Parent Models and Byte Conversions Interpreting the corruption contrasts requires three scor- ing choices to be explicit (Appendix K). First, the scored byte suffix must match the parent’s scored tokens under an explicit prefix convention: prepending the parent’s de- clared BOS raises the cost of otherwise unchanged targets by 74.2%. Second, batch composition can alter patch po- sitions and decisions in the released wrappers; it changes Bwen’s selected boundary path in 10 of 306 tested variants. We therefore score each variant in a standalone forward pass. Third, the joint byte/flag score conditions on one se- lected boundary history. It measures the cost of that path, whereas text likelihood requires marginalization over alter- native boundary histories. The same distinction holds for tokenized models: a string’s probability sums over every token sequence that decodes to it, not only the canonical one (Cao & Rimell, 2021; Chirkova et al., 2023; Vieira et al., 2025b).
