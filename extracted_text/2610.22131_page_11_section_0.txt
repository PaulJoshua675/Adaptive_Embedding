Visual game control Five described demonstrations span Snake, fruit catching, Mario, and two first-person Doom tasks. They require different local decisions: selecting a safe direction toward food, distinguishing fruit from hazards, coordinating movement and jumping, searching for health, or targeting an enemy. Screenshots provide visual evidence directly, so the controller can operate without converting every game state into a symbolic text description. Visual selection and mouse actions CAPTCHA-style visual tasks require the integration of visual perception, instruction understanding, and interactive decision making. Intern-Decision directly observes interface screenshots, identifies targets described in natural language, and completes tasks through discrete mouse movements and clicks. The model must interpret object attributes and their relationships, translate visual judgments into executable actions, and use the updated screenshot after each action to guide the next decision, forming a closed loop between perception and execution. 11
