Limitations Scope. Our evaluation covers the three text-rich KGs of STaRK, which have at most 10 entity types, 18 relation types, 1.9M entities and 39.8M edges (Wu et al., 2024b). Other KG benchmarks such as WebQSP, CWQ or GrailQA (Yih et al., 2016; Talmor and Berant, 2018; Gu et al., 2021), graphs with Freebase- or Wikidata-scale schemas, aggregation questions and the scaling of DKGI with graph size are left to future work. Where a KG is too large to scan or a question needs exact ag- gregation, purpose-built indexes, graph databases and query languages may be more suitable, and an agent could write its graph operations on top of them. A comparison with an agent in the same harness that queries a graph database through a query language such as Cypher or SPARQL (Feng et al., 2025) is also left to future work. GraphRAFT, which fine-tunes a text-to-Cypher model, enters the comparison through its published numbers. Models, baselines and data. Our main results use the proprietary models GPT-6-Luna and GPT- 6-Astra, which we accessed through an API in September and October 2026. Exact reproduction depends on the continued availability of these mod- els. Open-weight models remain to be tested. We release the code under the MIT License and the exported graphs, prompts and all trajectories under CC BY 4.0. Baseline numbers are taken from the literature and were obtained with different back- bones, budgets and evaluation code. The ablations in §3.3 hold these factors fixed. Our evaluation uses STaRK’s synthetic queries, which make up most of the benchmark. Protocol and deployment. The agent’s programs are written inline and discarded after each question. Because the agent runs arbitrary shell commands, any deployment requires a sandbox such as ours (Appendix C). Ethical Considerations We use the public STaRK benchmark (Wu et al., 2024b), whose data are released under CC BY 4.0. The code of STaRK, DCI-Agent-Lite (Li et al., 2026), the Pi coding agent and ARK is released under the MIT License, and Codex CLI under the Apache License 2.0. Our research use of these artifacts is consistent with their licenses, and our derived data keep STaRK’s CC BY 4.0 license. The code, exported graphs, prompts and trajectories that we release are intended for research on agents that search knowledge graphs. STaRK’s queries are in English, as are almost all node records. The Amazon data contain user reviews, and the MAG data contain author names and affiliations. These public data are part of the benchmark. We use them as provided by STaRK, and all personal data in this work come from the benchmark. Because the agent can execute arbitrary shell commands, we ran it in a sandbox that keeps the graph files read-only and blocks access to the network and the labels (Appendix C). We report point estimates from one evaluation per configuration and query set, with failed attempts retried as described in Appendix C. Appendix C gives the computational cost. The Amazon and Prime text-constraint tags in Appendix G were assigned by an LLM annotator, GPT-6-Luna. We used AI assistants for coding and for writing assistance. 9
