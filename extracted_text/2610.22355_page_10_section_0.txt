The pairwise-trained model exhibits steadier and more pronounced performance improvements, whereas the pointwise-trained model shows clear performance fluctuations. Pointwise rewards require the verifier to infer an implicit target state, which can introduce substantial noise into the feedback in complex reasoning scenarios. In contrast, pairwise verification directly compares the generated result with the ground-truth image, reducing reliance on target-state inference and enabling reward signals to better reflect the true visual quality. This provides more reliable supervision for policy optimization and highlights the value of pairwise verification for developing generative models into rule-governed world-modeling agents. From Easy-to-Hard and Domain Generalization. To more comprehensively evaluate the general- ization potential of the model trained with pairwise verification, we construct a more challenging Hard Dataset that is excluded from training. This dataset contains larger-scale instances and compositional tasks designed to test reasoning in more complex structured environments. As shown in Table 3 and Fig. 4, the model exhibits strong performance across out-of-distribution scenarios, including shifts in the visual domain. These results suggest that the model acquires transferable capabilities for structured reasoning and rule-governed world modeling beyond task-specific training patterns, highlighting the advantages of pairwise verification in supporting robust generalization. SFT Provides Domain-Specific Execution Priors. Tables 3 and 4 show that SFT yields substantial performance gains, which can be primarily attributed to task-domain adaptation. Since Qwen-Image-Edit- 2509 has not been specifically trained on game-based image-to-image generation tasks, it often fails to interpret the required transformation. In practice, the model tends to either the model tends to either leave the input image unchanged or distort its original structure, indicating that it lacks the task-specific action priors required for this domain. After supervised fine-tuning on our constructed game-based dataset, the generative model learns the visual style of these tasks and the corresponding rule-based transformation patterns. Although the model still often fails to produce fully correct solutions, it begins to perform meaningful operations toward the desired final state rather than generating irrelevant or destructive visual outputs, leading to clear performance improvements. These results indicate that SFT primarily equips the model with domain-specific execution ability, while subsequent reinforcement learning further endows the generative model with reasoning intelligence.
