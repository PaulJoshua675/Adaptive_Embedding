Each of these contributions is typically introduced and evaluated in isolation, often with its own implementation and experimental protocol (van Rijn et al., 2016). This fragmented development has two consequences. First, it is difficult to understand how different algorithmic components interact (van Rijn et al., 2017). For instance, the impact of a given sampling strategy may depend critically on the choice of matrix adaptation scheme or restart strategy. Second, practitioners face a practical barrier: selecting a suitable CMA-ES variant for a given application requires navigating a growing collection of specialized implementations, each with its own configuration interface and assumptions (Nikolikj et al., 2025b). As a result, many powerful ideas remain underexplored in combination, and advanced variants are less accessible to non-expert users. A natural response to this situation is to view algorithmic design itself as a compositional problem. Earlier work on Modular Evolutionary Algorithms (ModEA) (van Rijn et al., 2016) and the first version of the modular CMA-ES (de Nobel et al., 2021) followed exactly this idea: they decomposed the algorithm into a set of modules, such as sampling, selection, step-size adaptation, matrix adaptation, and restarting, with multiple interchangeable options exposed through a configurable design space. This modularization enables systematic studies of how individual components influence performance (de Nobel et al., 2021; Nikolikj et al., 2024), facilitates automated algorithm configuration and dynamic algorithm selection (Vermetten et al., 2020, 2023b; Thomaser et al., 2023a; Long et al., 2024a; Thomson et al., 2025), and lowers the barrier for implementing and testing new CMA-ES variants. The Modular CMA-ES has already been used to develop and evaluate new algorithmic ideas (Dinu et al., 2025; de Nobel et al., 2024c,b; Bonet-Monroig et al., 2023; de Nobel et al., 2025), and it is featured in several benchmarking studies (Fonseca et al., 2011; Vermetten et al., 2023c; van Stein et al., 2025; Vermetten et al., 2024, 2023a; Nikolikj et al., 2025a; Kononova et al., 2025). Moreover, the framework has been employed in studies of algorithm behaviour (Kostovska et al., 2022a; Jankovic et al., 2022; Vermetten et al., 2022b; van Stein et al., 2024a; Vermetten et al., 2022a) and in landscape-informed tuning and configuration (Kostovska et al., 2022b, 2023; Nikolikj et al., 2022; Kostovska et al., 2024). The practical value of treating the CMA-ES as a modular algorithm is demonstrated by its use in real-world optimization tasks, such as biological modeling (de Nobel et al., 2024a), mechanical engineering (Long et al., 2024b; Thomaser et al., 2023c; Long et al., 2025; Thomaser et al., 2023b) and optics (Patel et al., 2025). In this paper, we present the current incarnation of the Modular CMA-ES, denoted ModCMA, a substantially extended and reengineered framework building on these earlier efforts (van Rijn et al., 2016; de Nobel et al., 2021). ModCMA provides a unified implementation of a wide range of CMA-ES variants within a single, component-based architecture. The framework cleanly separates the algorithm into coherent modules and offers multiple options for each, resulting in fourteen implemented modules (Table 1) and over 14 million possible CMA-ES instantiations. The core is reimplemented in C++ using Eigen (Guennebaud et al., 2010) for efficient linear algebra, with a Python interface for convenient experimentation. Beyond describing the framework itself, we use ModCMA as a vehicle to study aspects of modular algorithm design and configuration. In particular, we compare different matrix adaptation mechanisms in terms of computational cost and optimization performance, and we show how automated configuration methods can exploit modularity to tailor CMA-ES variants to specific problems.
