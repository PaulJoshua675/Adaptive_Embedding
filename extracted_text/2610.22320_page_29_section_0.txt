We conducted a user study with 20 participants based on 40 example storyboards. For each storyboard, participants were asked to select the result that best balances identity consistency, prompt alignment, and scene adaptability among the four methods (Fig. 29). As shown in Fig. 28, EOS-Story was selected as the best in 52.8% of cases, outperforming the baselines. We report GPU memory usage and latency for generating 5 stories in Tab. 13. Note that StoryDiffusion is measured at 768×768 resolution, and 1P1S processes images individually rather than in batches, resulting in lower GPU usage. While EOS-Story uses slightly more memory than the baselines, its latency remains comparable, indicating that the additional memory cost does not translate into a noticeable runtime overhead.
