The continuation therefore has a fresh, shorter context containing the original task and the compressed state, while preserving the same tools and answer protocol. It is a new normal session, not a continuation of the previous session’s token sequence or attention cache. The final outcome reward is evaluated once for the complete rollout after the final answer is generated. Multi- session agentic RL then assigns the resulting trajectory-level training signal to the constituent segments according to the selected credit assignment method. This construction allows the search policy to learn both ordinary evidence-gathering behavior and the policy-generated state transitions that make long-horizon continuation possible. C.2. Rollout in Subagent Forking This section specifies the subagent forking scenario used for the multi-session setting. Unlike context compaction, which rewrites the main agent’s context, subagent forking creates additional single- session search subagents that execute assigned subtasks and return their results to a persistent main-agent session. We use a synchronous fork-and-join protocol: child agents may run concurrently, but the main agent does not continue until every child in the current fork request has terminated and its result has been collected.
