Since Q is unavailable, EMO constructs a computable direction from the context-induced distribution contrast. 3.2 EMO: Alternating Context Optimization and Logits Steering EMO alternates context estimation (E-step) and distribution refinement (M-step) per question. The EM analogy is structural: textual feedback is not a posterior expectation, and steering does not maximize a specified common likelihood. 3.2.1 E-Step: Context Optimization via Textual Gradients For each question, initialize C0 to the shared system context and generate R0 = Generate(θ, C0, q) using ordinary target-model decoding. Judge feedback guides the context update: Ck+1 = Opt  Ck, g(k) C  , g(k) C = Backward(Ck, q, Rk, Fk), (3) where k indexes rounds, Rk is the current response, and Fk is feedback from a judge without gold-answer access. Backward translates the judge’s criticism of Rk into suggested changes to Ck, producing the textual gradient g(k) C ; Opt applies this guidance to construct Ck+1. Subsequent rounds use the preceding M-step’s steered response as Rk. Rewrites update the domain role, reasoning strategies, pitfalls, and output requirements while keeping the question fixed. Feedback and rewrite prompts forbid final-answer disclosure; a pattern filter rejects suspected answer-bearing rewrites by setting Ck+1 = Ck. Target-KL improvement is an analysis assumption (Section 3.3), not guaranteed by the textual update. 3.2.2 M-Step: Distribution Contrast as Logits Steering At each decoding step, evaluate Popt = Pθ(· | Ck+1, q, y<t) and Pbase = Pθ(· | Ck, q, y<t) on the same generated prefix. Here “base” denotes the preceding context Ck, not the initial context C0; round, question, and prefix indices are suppressed. Both streams consume the newly generated prefix rather than their own independently sampled responses, isolating the effect of the context revision. Following SVDecode (Hu et al., 2026), the contrast yields: δt = JPopt log Popt Pbase = ∇zopt t KL(Popt∥Pbase), (4) where δt is the raw steering vector, zopt t contains logits under Ck+1, and JPopt is the softmax Jacobian; differentiation holds Pbase fixed. Logarithms and ratios act componentwise. For nonzero δt, an unmasked positive step locally increases divergence from the preceding- context distribution; this alone does not ensure target alignment. 4
