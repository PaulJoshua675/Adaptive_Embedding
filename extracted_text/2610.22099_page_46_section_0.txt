All position-wise visibility decisions are applied synchronously. A newly revealed position receives its proposal from the pre-transition decoder evaluation; a visible position selected to remain visible retains its existing token, even when the decoder now prefers another token. At deterministic finalization, one fresh decoder evaluation fills the remaining masks greedily and leaves already visible tokens unchanged. This finalization does not invoke the policy or contribute an action likelihood. Block-local execution. Let B be the number of response blocks and H = T/B the number of decoder calls allocated to each block. Each block receives H −1 learned transitions and one deterministic finalization. The prompt and finalized prefix remain immutable, while future blocks remain masked until they become active. For local learned step j ∈{0, . . . , H −2}, both variants target occupancy ((j + 1)/H)α within the active block. The saved policies use different time inputs: TIPSfull receives j/H, whereas TIPSblock receives (j + 1)/H, with the clock reset at each block. We preserve these checkpoint-specific conventions during evaluation. The training input contains 12,776 problems: 6,280 from GSM8K and 6,496 from MATH. We use each problem’s original dataset answer or solution as its reference response. Each reference view ends at the first EOS token, or has EOS appended when none is present, and is then capped at 256 tokens. All training problems are retained, including the 2,113 whose reference view exceeds the canvas length before truncation. Reference inclusion is not conditioned on acceptance by the generated-answer verifier. Padded positions are marked invalid for the direct supervised loss. Teacher and loss. The teacher uses the reference-token utility ut,i in equation (10). The masked-position margin is computed by subtracting the strongest non-reference logit from the reference-token logit, which preserves the sign of the margin when the reference is the decoder’s top prediction. In the implementation, valid- position utilities are transformed to (ut,i + 1)/2 and multiplied by 10 before applying the occupancy-matching offset. Consequently, the sharpness in the raw-utility convention of the main text is β = 5. Binary cross-entropy is averaged over reference-valid positions within each state and then equally over the states in the minibatch. Reference tokens and reference margins are used only to construct supervision; the student receives the decoder-derived confidence features, mask states, and time inputs. 46
