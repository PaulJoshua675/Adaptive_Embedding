All model choices are flexible. 3.1 Basic User Profiles and Behavioral Statistics Stage 1 (Basic User Profiles). We construct basic user profiles from ReDial (Li et al., 2018), treating each crowdworker as a user across both seeker and recommender roles. Of the 1,112 workers in the 11,348 ReDial dialogues, we retain the 618 with at least two conversations. Each profile contains observed movie preferences (liked, disliked, and implicitly disliked movies, derived from ReDial’s post-conversation questionnaires) and the user’s historical conversations. Stage 2 (Behavioral Statistic Extraction). We augment these profiles with rule-based behavioral statistics derived from historical interactions: ac- ceptance and rejection rates, reference style (genre, mood, actor, director, year), genre and decade dis- tributions, exploration ratio, and popularity score. Together these form a behavioral fingerprint that grounds the synthetic interview. Figure 2 shows an example. Of the 618 profiles, 543 meet our eli- gibility criteria, requiring at least one seeker-role conversation and a nonzero acceptance or implicit- rejection signal. We randomly sample 300 users from this eligible set for the full SimInter pipeline, and randomly select a subset of 100 of these users for matched ablation experiments and comparison with CSHI (§4.1). 3.2 Synthetic Interview Generation Stage 3 (Synthetic Interview Generation). Conversations often contain implicit information that provides deeper insights into users (Tigunova et al., 2019; Torbati et al., 2021). We exploit LLMs’ role-playing capabilities (Wang et al., 2024; Chen et al., 2024) to simulate interviews between two agents: an interviewee anchored to the user’s pro- file and an interviewer that elicits it. For each of the 300 sampled users, the interviewee agent receives the user’s statistical profile and one historical Re- Dial conversation in which the user acts as a seeker.
