Executable repository-level benchmarks have increasingly become a central testbed for software engineering agents. SWE-bench and its variants pair a natural-language is- sue with a repository state and an executable test oracle, enabling standardized, verifiable evaluation of generated patches (Jimenez et al. 2023; Zan et al. 2025; Deng et al. 2025). Most benchmarks, however, retain a single issue or pull request (PR) as the basic task unit. This abstraction cap- tures isolated bug fixes and localized features, but only a restricted portion of real software development. In practice, a single feature, migration, dependency upgrade, or system- atic fix often evolves across multiple PRs. These changes may be sequential, branch in parallel, or converge through later integration. The missing abstraction is therefore not merely longer context or a larger patch, but the dependency struc- ture connecting multiple changes into a coherent engineer- ing objective. WEAVE constructs executable dependency-structured tasks for verifiable evaluation and rewards. Recent work has moved beyond isolated PRs by grouping changes through release windows, temporal spans, explicit cross-references, or object-level dependencies (Thai et al. 2025; Chen et al. 2026; Jiang et al. 2026; Zhou et al. 2026). These efforts advance long-horizon software engineering, yet two coupled challenges remain. First, these aggregation sig- nals are imperfect proxies for task coherence: temporal prox- imity can merge unrelated changes, explicit references are sparse, and coarse overlap is often dominated by frequently modified utilities, configuration files, or dependency mani- fests. Moreover, a related change set does not itself define a reproducible task with a valid base state, task specification, and executable oracle. Second, current evaluation poorly cap- tures structured partial progress. Binary resolution ignores progress on unsolved tasks, while flat test- or PR-level ag- gregation overlooks dependencies and may over-credit down- stream behavior built on incomplete upstream changes.
