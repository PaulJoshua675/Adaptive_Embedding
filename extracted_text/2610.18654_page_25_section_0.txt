Kwai Summary Attention V2 Technical Report 4.2. Sparse Attention Sparse attention reduces computation by restricting the positions read by each query. Sparse Trans- former (Child et al., 2019) uses structured sparse factorizations, Longformer (Beltagy et al., 2020) combines local windows with global attention, and BigBird (Zaheer et al., 2020) additionally incorpo- rates random connections. Sliding-window attention, used in Mistral (Jiang et al., 2023), restricts each layer’s direct access to nearby tokens. Another line exploits attention sparsity in pretrained models without additional training. QUEST (Tang et al., 2024) estimates the relevance of KV-cache pages to each query and reads only the selected pages. MInference (Jiang et al., 2024) combines head-specific pattern templates with input-dependent sparse indices to accelerate prefill, while SpargeAttention (Zhang et al., 2025a) and XAttention (Xu et al., 2025) estimate attention importance to skip low-contribution computations. These methods sparsify attention through prescribed patterns or inference-time selection, without training an auxiliary routing module. Content-dependent sparse architectures integrate routing into the attention mechanism. SeerAt- tention (Gao et al., 2025) learns block-level gates by self-distilling dense attention, while DeepSeek Sparse Attention (DSA) (DeepSeek-AI et al., 2025) uses a Lightning Indexer to select individual tokens. At block granularity, MoBA (Lu et al., 2025) scores mean-pooled token keys, whereas Qwen Sparse Attention (QSA) (Qiu et al., 2026) mean-pools auxiliary index keys within micro-blocks; both attend to the selected blocks’ original-token KV. Native Sparse Attention (NSA) (Yuan et al., 2025) uses learned block compression to guide fine-grained selection and combines compressed, selected, and local attention branches. In contrast, DeepSeek-V4’s CSA (DeepSeek-AI et al., 2026) selects compressed KV entries for its remote attention. S-KSA also reduces routing to block granularity, but reuses existing KSA Summaries as aggregation queries to construct routing representations and retains original-token KV for the main attention. Learned memory tokens can also provide an interface for block retrieval. Landmark Attention (Mo- htashami and Jaggi, 2023) represents each context block with a landmark token and learns to retrieve blocks through attention to these landmarks. Simplified Sparse Attention (SSA) (Mao et al., 2026) scores gist keys and unfolds selected chunks to recover their original tokens. HiLS-Attention (Hu et al., 2026) uses landmark queries to pool token keys, then combines within-chunk attention outputs using entropy-corrected chunk weights. This allows the language-modeling loss to train routing; SAS (Li et al., 2026) similarly learns context ranking through differentiable gates inside attention normalization. In S-KSA, Summaries guide auxiliary aggregation rather than serving directly as routing keys. We train the aggregation modules and Indexer by attention distillation and use the resulting scores only for block selection. The main attention applies a single softmax over selected original tokens and local context, without using routing scores as additional attention weights. 4.3. Hybrid Architectures Hybrid architectures seek to retain the fine-grained retrieval of attention while reducing the cost of processing long contexts. A common strategy interleaves several efficient layers with a smaller number of full-attention layers. Hybrid H3 (Fu et al., 2023), Mamba-2-Hybrid (Waleffe et al., 2024), and Jamba (Lenz et al., 2025) combine state-space layers with attention, while Kimi Linear (Kimi Team et al., 2025) combines KDA with MLA. Local attention provides another complementary component: RecurrentGemma (Botev et al., 2024) and Samba (Ren et al., 2025) pair it with recurrent or state- space layers, whereas Gemma 3 (Gemma Team et al., 2025) and MiMo-V2-Flash (Xiaomi LLM-Core Team et al., 2026) interleave it with global attention.
