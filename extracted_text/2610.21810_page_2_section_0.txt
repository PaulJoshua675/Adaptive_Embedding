For an input x, let A(x) ⊆{1, . . . , N} denote the requested row addresses. N-gram-based conditional memory determines row addresses by hashing input n-grams independently for each or- der and head. Each token retrieves a fixed number of rows, so the accessed memory is EA(x) = {ei | i ∈A(x)}, |A(x)| ≪N. The resulting hidden state is passed to subsequent network layers, so errors in the retrieved embed- dings can propagate through the readout and affect the model’s final predictions. 2.2 Compressing Conditional Memory The storage footprint of a compressed table and the cost of accessing an individual row are dis- tinct quantities. Compression can reduce storage by encoding or transforming multiple rows jointly, but such representations may couple them within a larger reconstruction unit. Consequently, accessing a single row may require fetching or decoding a larger block of data. Thus, a smaller compressed table does not necessarily imply efficient access under sparse lookup.
