Contributions. Our contributions are threefold. • We frame automated SFT data research around a space of six data-engineering actions, and show that a corrected single-agent loop reaches only one of them (Sections 2 and 3). • We build AutoSFT, a multi-agent system that isolates execution, gathers proposals from comple- mentary analysis angles, and synthesizes data for capabilities the pool lacks (Section 4). • Adding each component while retraining from the base model, so its effect is attributable, widens the actions a run takes and improves the recipe, by +6.5 IFEval from analysis, +3.4 IFEval and +2.9 IFBench from synthesis, and +3.7 MBPP+ in a code domain (Section 5). 2.
