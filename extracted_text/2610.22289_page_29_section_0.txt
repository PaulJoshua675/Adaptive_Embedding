Available actions: {"id": "up"}, {"id": "down"}, {"id": "left"}, {"id": "right"} Coordinate convention: positions are given as (row, col), where row increases downward and col increases to the right. A.3 AGI Maze set description and transition messages A.3.1 Environment description The environment description is: You are playing a series of labyrinths. Your task is to solve all labyrinths using the minimal number of moves. You will be given a description of each labyrinth. Please read each description carefully. For the first few labyrinths, you will be given an open map with your position shown on it. These are tutorial labyrinths designed to help you understand the mechanics. For the remaining labyrinths, the map will be hidden. You will only be given your initial position in the labyrinth description. The initial observation is message.md containing: Please start the first labyrinth by sending the {"id":"start"} action. Available actions: {"id":"start"} The environment waits for {"id":"start"}; it does not begin the first labyrinth automati- cally. A.3.2 When a labyrinth starts A valid start action returns labyrinth_description.md, containing the environment descrip- tion used for that labyrinth in the single-labyrinth setting. It also returns state.txt, containing the same state information as in the single-labyrinth environment, with the labyrinth index added. Tutorial labyrinths additionally provide AGI Maze’s current public map and player position in map.txt. Subsequent actions update the state and, for tutorials, the map; non-tutorial labyrinths omit map.txt. A.3.3 Between labyrinths After a labyrinth is solved and another remains. The response replaces the ordinary observation files with message.md containing: You have solved the labyrinth. Please start the next labyrinth by sending the {"id":"start"} action.
