Level 2: observational guard association. For an input-visible cue, let a(z) ∈{0, 1} indicate whether the audited cue is present. Within a comparison cohort C, we measure ∆assoc(C) = E[g(x) | a(z) = 1, x ∈C] −E[g(x) | a(z) = 0, x ∈C]. (2) The cohort C can restrict comparisons to the same released label, domain, action family, or another matched context. A large contrast can nominate a cue for intervention. It remains observational be- cause z, y, and legitimate evidence in s share a data-generating process, so measured and unmeasured confounding can explain the association. Level 3: paired decision sensitivity. For a deterministic guard and transformation T(s, z) = (s, z′), we measure the paired strict-decision flip rate pflip(T) = 1 n n X i=1 ⊮[g(xi)̸ = g(T(xi))] . (3) The intervention must preserve the label and intended construct; otherwise the flip may be legitimate. For stochastic g, the target estimand is instead ∆T = 1 n n X i=1 {Pr[g(T(xi)) = 1] −Pr[g(xi) = 1]} , (4) estimated here by repeated calls in both conditions. Under stable independent draws, the signed K = 1 mean g(T(xi)) −g(xi) is unbiased for ∆T , but can be imprecise and temporally confounded when calls are not interleaved. Its unsigned flip rate is a different, descriptive disagreement estimand. Independent repeat disagreement measures stability and should not be subtracted from either quantity. A strict-decision non-flip also does not exclude changes in ordinal scores, components, rationales, or redundant feature use. This ladder combines ideas from shortcut learning, group-shift evaluation, behavioral testing, and contrast sets [Geirhos et al., 2020, Koh et al., 2021, Ribeiro et al., 2020, Gardner et al., 2020]. Our contribution is to operationalize label predictability, observational guard association, and paired decision sensitivity as a three-level audit for released agent-safety evaluations. The experiments show that strong label predictability can coexist with localized paired decision sensitivity. 3 Evaluation artifacts and audit design 3.1 Evaluation artifacts LinuxArena. LinuxArena evaluates control protocols for agents operating in live software environ- ments [Tracy et al., 2026]. We use the 932-row public sample at a pinned dataset revision. Of these, 918 rows contain extracted shell commands. Because the public sample repeats action traces under different monitor runs, we hash complete action content after removing only the monitor response. The primary diagnostic contains 576 exact-action-unique shell trajectories: 176 attack and 400 honest across ten environments. We never use the nominally unique trajectory_id as a deduplication key.
