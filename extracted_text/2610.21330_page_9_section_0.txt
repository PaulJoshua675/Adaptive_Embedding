What Generative Search Engines Like and How to Optimize Web Content Cooperatively. arXiv preprint arXiv:2510.11438 (2025). A Appendix A.1 Data Preprocessing Query cell sampling. We retain 260 U.S. base queries from Cen et al. [7] that are relevant to voter decision making and the presi- dential election. The rewriting benchmark uses 109 queries from five subcategories: Candidate positions (51), Comparison (29), Public opinion (17), Evaluation (9), and Vice president (3). To sample the election period without tying all queries to the same calendar dates, we independently select seven available collection days for each query using a fixed seed, jointly covering the full 106-day window. The Japanese set contains 12 policy issues with two opposing stance conditions plus one query without a policy stance, and we use all available collection days. The cross-day source-overlap analysis instead requires a common time span across queries, so all U.S. queries use the same seven evenly spaced dates: July 23, August 10, August 27, September 13, October 1, October 19, and November 5, 2024. The Japan overlap analysis uses all available days for each source engine. Content retrieval details. We attempt retrieval for 11,895 U.S. and 6,202 Japanese URLs. When a URL appears on multiple dates, we use its earliest observed date, and URLs are normalized by resolving archive wrappers and removing tracking parameters and fragments before deduplication. Main text is extracted using trafilatura, with readability-lxml as a fallback. The resulting success rates are 96.7% for the U.S. and 92.7% for Japan. Source-Channel Labeling. We label sources at the domain level using the four channels defined in Section 4.1. Representative exam- ples are kamalaharris.com and jimin.jp for owned/self-published, reddit.com and note.com for open-platform UGC, nytimes.com and asahi.com for earned/paid press, and fec.gov and soumu.go.jp for independent institution. Labels follow the organization control- ling the domain rather than the type of an individual page. We use claude-opus-5 with web access for initial labeling and man- ually review low-confidence and ambiguous cases. Source shares count repeated occurrences separately.
