C. Spatial-Temporal Encoding With the decomposed data representation, we leverage sep- arate encoders, including trajectory vector encoder, lane vector encoder and current position encoders, to embed position vectors and current positions of agents and lane segments. Trajectory Vector Encoder. Given a scenario with multiple agents, we take the current absolute coordinates pT i of a given target agent i as the origin of the coordinate system. Meanwhile, its heading angle θi is adopted as x-axis positive direction. We uniformly translate all position vectors of agents in this scenario to the origin and rotate them to the x-axis positive direction, which generates the normalized vectors as follows: zt i = R⊤ i (vt i −pT i ), zt j = R⊤ j (R⊤ i (vt j −pT i )), (1) where R⊤ i , R⊤ j ⊂R2×2 are the transpose of rotation matrix parameterized by θi and θj. With the normalized vectors, we firstly leverage a trajectory vector encoder with multi-scale 1D CNN layers to effectively extract the spatial features. Then, we further utilize a linear layer to gather the temporal information and obtain vector feature ev i as follows: ev i = Linear(Conv([zt i, ai]T t=1)), (2) where ai is a 1 × T binary mask to indicate if the position vector at each step is padded or not. [·, ·] indicates the concatenation operation. Lane Vector Encoder. Similarly, in a lane vector encoder, we firstly normalize the position vector vk ξ of a lane segment ξ and obtain the normalized vector zk ξ like Eq.(1). Subsequently, we adopt the Lane Graph Convolution Net- work(LaneGCN) in [19] to extract the topology information of lane segments, which can be formulated as follows: ev ξ = LaneGCN([zk ξ, aξ]), (3) where aξ denotes the attributions of lane segments, including turning and traffic light information. Cross-Temporal Aggregation With the vector and current features of the scene, we design a cross-temporal aggregation, including a current fusion module, an observation interaction module, a future feedback module and a global fusion module, to integrate the historical, current and future interaction features of multiple agents. In this section, we first introduce a relative interaction block, which is frequently reused by the observation interaction mod- ules, future interaction modules and global fusion modules. Then we describe each module sequentially. To explore the spatial correlations among agents and lanes with the decomposed relative information, we design a plug- in base block called relative interaction block. As shown in Fig. 4, we take the interaction between lane segments and their surrounding agents as an example. Firstly, a neighbor agent’s relative distance and angle are encoded and concatenated with the feature of this agent and lane segment. This process repeats on each neighbor agent of the lane segments. Secondly, we aggregate the concatenated features of all neighbors and update the raw feature of this lane segment with them. Given a lane segment ξ and its neighbor agents, this interaction process can be denoted as: oξ = I(eξ, ei, ∆pξi, θξi), ∀i ∈Gξ a2l, (5) where eξ and ei are the inherent motion feature of lane segment ξ and a neighbor agent i. Gξ a2l denotes a set of neighbor agents which connected with lane segment ξ on graph Ga2l. The detailed process can be formulated as follows: eξi = ReLU(MLP2(∆pξi) + MLP2(cos(θξi), sin(θξi))), oξi = MLP1([eξi, MLP2(eξ), ei]), oξ = MLP1(MLP2(eξ) + X i∈Gξ a2l oξi), (6) where MLP2 represents the stack of two linear layers, a ReLU function.
