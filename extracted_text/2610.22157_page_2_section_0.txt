Embedding physical constraints in the loss function greatly reduces the acceptable solution space without the need for labelled data [4]. In recent years, there has been an abundance of work applying PINNs, ranging from problems in fluid mechanics [5, 6, 7, 8, 9, 10, 11], molecular imaging [12], solid mechanics [13, 14, 15], and learning governing equations from data [16, 17, 15, 18], to cite only a few. Despite their success, a critical limitation for the real-world application of PINNs for forward modelling is that they typically require retraining even for small changes to the domain, initial conditions, or — perhaps most importantly — boundary conditions. This stems from the fact that a conventional PINN takes only the independent variables of the PDE as input into the neural network, while the initial and boundary conditions are incorporated indirectly as soft constraints in the loss function. Consequently, the network is trained to output a solution corresponding to a fixed set of conditions, and does not naturally generalise to different initial or boundary conditions [19, 11]. As a result, the fast inference times of trained PINNs cannot be easily leveraged across different problem setups, limiting their practical utility in dynamic or rapidly changing scenarios [10]. A possible solution for this limitation is to use physics informed neural operators. Neural operators aim to learn mappings between infinite-dimensional function spaces [20]; for example, a mapping from bound- ary conditions to the PDE’s solution across the whole spatiotemporal domain. One notable neural op- erator framework is the Deep Operator Network (DeepONet) [21], and its physics-informed variant, the PI-DeepONet [22]. DeepONet is grounded in the universal operator approximation theorem, which states that a neural network with a single hidden layer can approximate any non-linear continuous operator G to arbitrary accuracy [23]. The learned operator approximation ˆG maps an input function u to an output function ˆG(u), which can then be evaluated at collocation/query points y to produce ˆG(u)(y). [21] extended this framework to use deep neural networks in their unstacked DeepONet. In a DeepONet a single Branch network encodes the input function at m sensor points ξj∈[1,m], while a single Trunk network encodes the collocation/query point y = (x, t). For example, the input layer of the Branch network could depict a time-dependent boundary condition, whereas the Trunk network functions similarly to a conventional PINN, taking points within the spatiotemporal domain as input. The outputs of these subnetworks are then combined via a dot product to approximate the output function evaluated at the query point. This can be represented by the equation: ˆG(u)(y) ≈ s X k=1 bk(u(ξ1), u(ξ2), ..., u(ξm))τk(y), (1) where, bk are the Branch network outputs, τk are the Trunk network outputs, both of which are of length s. The subnetworks require no specific architecture, allowing flexible integration of different networks like feedforward, convolutional, etc. Owing to the simple, feedforward architecture of the subnetworks in the DeepONet, it is straightforward to integrate physics-informed techniques into DeepONet designs. A PI-DeepONet is trained using a loss function formulated in the same way as in PINNs [22]. A schematic of a PI-DeepONet can be seen in Figure 1. Derivative terms in the physics loss are calculated by automatic differentiation along the Trunk network, which encodes the collocation points of the output function space. The PI-DeepONet is especially attractive in scenarios where simulations are expensive, high-fidelity data are limited, and adherence to physical laws is critical for model reliability [24]. Such scenarios include real-time forecasting, uncertainty quantification, and digital twins. This is because the PI-DeepONet can be trained without labelled data, and can then eﬀiciently generate predictions across a variety of problem configurations. Overall, PI-DeepONet is one of the first physics-informed neural operator frameworks and has received substantial attention since its introduction [22], introducing a general approach that allows purely physics- informed operator learning, but broader adoption has been limited compared to data-driven neural operators. This is partly due to the extra computational burden of using automatic differentiation to calculate deriva- tives in the physics loss terms, which becomes more apparent for high-dimensional systems and when higher order derivatives are present. The high computational cost stems from the fact the number of Trunk eval- uations scales exponentially with the number of dimensions (i.e. N d), where N is the is the resolution of each coordinate axis and d is the number of spatiotemporal dimensions [25]. As a result, most research on PI-DeepONet to date has focused on low-dimensional problems, using hybrid approaches where physics constraints are combined with labelled data [26, 27, 28]. 2
