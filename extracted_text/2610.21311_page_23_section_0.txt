5 Runtime for the (LOTZ, DLTB) Problem This section focuses on another pair of structurally similar tasks that are ex- pected to yield positive knowledge transfer. We investigate a two-task opti- mization problem consisting of DLTB [ZLDD24], a complex and multimodal bi-objective benchmark, and LOTZ [LTZ04], a relatively simple yet similar bi-objective benchmark. Our analysis will show that jointly optimizing these tasks allows the runtime for DLTB to be reduced to the same order as that for LOTZ alone. 5.1 Two-Task (LOTZ, DLTB) Problem Here we formally define the two-task (LOTZ,DLTB) problem (Definition 13). The LOTZ is the bi-objective extension of the single-objective Leading- Ones problem. The first objective counts the number of leading ones, and the second objective counts the number of trailing zeros. The DLTB bench- mark is the bi-objective counterpart of the multimodal Deceptive Leading Blocks (DLB) problem [LN19].
