PremiseSQL jointly supports fine-grained premise-error analysis, ab- stention evaluation, SQL generation, paired original-query controls, and prompt-aware eval- uation, enabling a more complete assessment of premise critique in NL2SQL. 3 Method 3.1 Task Formulation Let x denote a natural language query and c the available database context, comprising the schema and any supplied auxiliary information. We asso- ciate each query–context combination (x, c) with a reference label y ∈{0, 1}, where y = 1 indicates that the query has a premise flaw that warrants critique and abstention under the assumed SQL ex- ecution conditions, and y = 0 indicates the absence of such a flaw. These flaws may concern interpreta- tion, logical consistency, required information, or the capabilities of SQL and the database, as spec- ified in Table 1. PremiseSQL assigns y = 1 to constructed flawed queries and y = 0 to their orig- inals, forming the positive and negative samples, respectively. Given a prompting setting π, the complete re- quest comprises the query x, the database context c, and the instructions specified by π.
