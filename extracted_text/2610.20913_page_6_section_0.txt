A user generates an evolving behavioral trajectory, while the stream of recommendation requests arrives on a separate clock and introduces candidate sets to be scored. The model produces predictions for these candidates before downstream selection determines which items are exposed and which responses are subsequently observed. We begin with the behavior–request–exposure–feedback process and its causal information boundary, then formulate recommendation as request-conditioned sequence transduction, in which successive user requests query cutoff-valid prefixes of the user’s evolving behavioral trajectory. Finally, we identify the resulting amortization boundary between candidate-independent behavioral-state construction and candidate-conditioned prediction.
