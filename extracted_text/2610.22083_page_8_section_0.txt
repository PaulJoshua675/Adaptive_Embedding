SpiNNaker2 The same deflection measurement on SpiNNaker2 shows a different kind of limit. Every input event reaches the neuron up to 512 simultaneous inputs, and delivery stops abruptly there: 513 inputs produce the deflection of exactly 512. The limit is the same at every synaptic weight tested and does not change when the inputs are split across several source populations, so it is a count of input events per neuron rather than a bound on current or on the traffic from a single source. The measurements were made with the default configura- tion of py-spinnaker2; whether the limit can be configured, and whether it bounds events per timestep or connections per neuron, was not established. For spatial codes the two coincide, since every bit of a code word is delivered in the same timestep. 3.4.3. Consequences for the encodings Since a code of width 𝑊delivers 𝑊input events, each limit bounds the range of values an encoding can represent. What is fixed is the cost: a spatial code requires one packet, one buffer entry and one synaptic event per bit for every decision, so enlarging the buffer accommodates a wide code but does not make it cheaper.
