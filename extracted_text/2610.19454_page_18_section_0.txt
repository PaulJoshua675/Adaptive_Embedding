C.1 Value Baselines and Advantage Estimation Each role’s independent PrefixValueModel Vϕr(h) maps the last input token’s D-dimensional hidden represen- tation before response generation through LayerNorm(D), Linear(D, 256), Tanh, and Linear(256, 1) to a scalar return. Detached input features block value-model gradients to the role language model. Before each training round, the system computes value predictions V − i , then advantages and return targets. Planner and Inspector use rr i −V − i as the advantage in Eq. (10), with regression targets bRr i = rr i . Optimizer applies GAE within each account and period, including HOLD decisions. Fixing one period, let ta,i denote the i-th decision step of account a, rO a,i its reward, ∆a,i = ta,i+1 −ta,i the number of environment steps to the next node of the same account, and ba,i ∈{0, 1} the sequence termination indicator. The recursion is δa,i = rO a,i + γ∆a,i(1 −ba,i)V − a,i+1 −V − a,i, bAO a,i = δa,i + γ∆a,iλ(1 −ba,i) bAO a,i+1, bRO a,i = bAO a,i + V − a,i. (C.1) The discount factor is γ = 1 and the GAE parameter is λ = 0.95. Each account’s final node in a period has ba,i = 1 and ∆a,i = 0, with zero terminal bootstrap value and boundary advantage. Recursion never crosses accounts or periods, even though rewards include all-account feedback. Advantages and return targets are computed over complete account-period sequences before batching and remain fixed throughout the round. C.2 Value Regression and Policy Updates The value model performs SmoothL1 regression against fixed, detached return targets bRi, averaging the per-node regression losses over the settled batch B. Each role’s first scheduled round updates only its value model. Later rounds update the value model first, then the role policy using the previously fixed action advantages. The two models maintain separate optimizers and optimizer states. Policy updates follow Eq. (11), with an entire response sharing the same action advantage. Each actor update recomputes probability ratios and masks; advantages and importance weights stay fixed during backpropagation. Responses with Z = 0 are skipped for that update. The k3 KL to the behavior policy is used only for monitoring and rollback, not in the actor objective. If KL exceeds 0.01 or the retained-token fraction falls below 0.4, the system restores the parameters and optimizer state from before that update and stops actor updates for the round. Completed value-model updates are retained.
