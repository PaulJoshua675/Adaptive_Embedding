We provide Gemini 3.7 Flash with the question and expanded evidence, withholding both the full context and the reference answer. A dedicated verification prompt, distinct from the standardised task prompts, instructs the model to answer solely from the supplied evidence, without guessing, introducing unsupported assumptions, or relying on prior knowledge. We sample three responses per instance and retain the instance only if all three satisfy the task-specific correctness criterion (Table 3). Repeated verification reduces reliance on a sin- gle successful response, but does not establish that every retained passage is necessary or that the evidence set is minimal. Evidence Retrieval Prompt You are a precise, verbatim information retrieval engine. Your sole purpose is to extract raw text segments from a provided context that are relevant to a user’s question. ### Core Constraints 1. VERBATIM EXTRACTION: You must extract segments exactly as they appear in the context. Do not correct grammar, do not remove typos, and do not paraphrase. 2. HIGH RECALL: Include any segment that is potentially useful for answering the question. If a sentence is even tangentially related, include it. 3. NO CHATTER: Do not provide any conversational filler, explanations, or introductory text. 4. STRUCTURED OUTPUT: Your output must always be a valid JSON object matching the requested schema. ### Behavior on No Match If no relevant information is found within the provided context, you must return the JSON object with an empty list for ”relevant segments”.
