Let F, F ′ be two models with identical input-output behavior, i.e. F(z) = F ′(z) for all z, evaluated under the same causal graph and the same mechanisms ci (or surrogates si). The path points γ(p) visited by the Riemann sum, and the gradients ∂γi/∂α, ∂γj/∂γi evaluated at those points (Equation 6), depend only on the graph, α(p), and ci (or si) — never on F. Hence at every path point p, ∂F(γ(p)) ∂γi = ∂F ′(γ(p)) ∂γi (19) follows directly from F ≡F ′. Since every term of Equation 3 involves F only through such partial derivatives evaluated at these shared path points, RF i = RF ′ i for every feature i and every K. □ This precondition is not an additional restriction beyond the standard axiom — it is what implementa- tion invariance means: comparing two models under one shared explanation setup, not two different setups. Changing the graph or the mechanisms is meant to change attributions. Sensitivity(a) Statement. If the input and baseline differ in exactly one feature i and yield different predictions, then feature i should receive a non-zero attribution. We prove this for the direct attribution component. Proof. Since the line integral uses a straight-line path between baseline and input, all features j̸ = i remain constant along the path, so their total derivatives vanish: dγj dα = 0, j̸ = i. (20) By the chain rule, the total derivative of the varying feature γi along the path is: dγi dα = ∂γi ∂α + X j̸=i ∂γi ∂γj dγj dα = ∂γi ∂α + X j̸=i ∂γi ∂γj · 0 = ∂γi ∂α . (21) Consequently, the direct attribution of feature i reduces to the standard integrated gradients attribution: RCIG i,direct = Z 1 0 ∂F ∂γi ∂γi ∂α dα = Z 1 0 ∂F ∂γi dγi dα dα = RIG i . (22) Since integrated gradients satisfies sensitivity(a), it follows that the direct attribution component of causal integrated gradients does as well. □ Symmetry Statement.
