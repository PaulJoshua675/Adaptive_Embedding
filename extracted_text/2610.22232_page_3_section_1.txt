2.1 Lossless Image Compression Classical lossless codecs rely on predictive filtering and entropy coding. PNG [4], JPEG-LS [19, 39], FLIF [33], JPEG2000 [34], and JPEG XL [2] represent widely used designs. The reversible 5/3 lifting transform in JPEG2000 provides a practical route to loss- less wavelet coding [6, 34]. Learned compression methods have explored causal autoregressive models such as PixelCNN and Pix- elCNN++ [30, 37], hierarchical latent-variable models [15, 28, 36], invertible flows [42, 43], residual coding [3, 29], and bit-plane de- compositions [44]. Across these approaches, the central challenge remains accurate probability estimation over high-dimensional dis- crete image signals. CALLIC [20] reports strong learned-method results through content-adaptive per-image optimization. 2.2 Wavelet-Domain Codecs Wavelets decompose an image into low-frequency structure and high-frequency detail at multiple resolutions [6, 26]. Natural-image wavelet coefficients are non-Gaussian and subband dependent [34, 38], with broader low-frequency responses and sparse, sharply peaked high-frequency coefficients. This separation makes the wavelet domain attractive for entropy modeling. WaveFormer and BVINet incorporate wavelet modules into Transformer-based video inpainting [40, 41]. Unlike these restoration models, WaveLLM uses a reversible wavelet decomposition and decoded same-level subbands for lossless entropy coding. In lossless coding, JPEG2000 established the canonical framework by combining the reversible 5/3 integer lifting transform with wavelet-domain context model- ing and arithmetic coding [34]. The lossless branches of iWave and iWave++ use reversible 5/3 wavelet coding with learned PixelCNN entropy models [24, 25]. WaveLLM studies this setting and replaces the PixelCNN-style entropy model with a shared prompted LLM over codec-defined subband tasks. 2.3 LLMs for Lossless Image Compression Beyond compressing intermediate representations produced by large models [10–13], recent LLM-based image compression directly employs pretrained language models as entropy models [5, 7, 8]. Delétang et al. demonstrated that autoregressive language model- ing can be interpreted directly as compression [7]. In image coding, two recent methods apply pretrained LLMs to lossless compression. P2-LLM keeps the problem in the pixel domain and frames com- pression as next-pixel prediction [5]. The visual-prompt method introduces a lossy reconstruction as an auxiliary cue and codes the residual with an LLM [8]. Both papers report Llama-3-8B backbones. WaveLLM takes a different route. It introduces LLM-based entropy modeling into a reversible 5/3 wavelet codec, using a 3B backbone adapted through LoRA [16]. Unlike P2-LLM, which processes a rasterized pixel stream without codec-defined structure, and the visual-prompt method, which requires an auxiliary lossy codec to generate visual embeddings, WaveLLM operates within the causal structure of the wavelet codec. It relies on decoded context that is already available at each coding stage. At the coefficient interface, it also differs from the reserved-vocabulary strategy used by P2- LLM by introducing a dedicated local value-ID space together with separate value embedding and prediction modules. 3 Method 3.1 Overall Framework WaveLLM uses a reversible color transform, a fixed 5/3 wavelet transform, a causal coding order, and arithmetic coding, while the learnable part focuses on wavelet-domain probability factoriza- tion over codec-defined subbands. These subbands are coded in a fixed causal order. 𝐿𝐿4 is coded first, followed by the three high-frequency bands at each level from the deepest level to the shallowest. For each subband, WaveLLM forms a task prompt, maps the resulting value sequence through the coding-oriented numerical interface, and uses the LLM to produce a probability distribution over coefficient values for arith- metic coding. The decoder entropy-decodes these subbands in the same order as the encoder. After each level is decoded, the inverse wavelet transform synthesizes the next shallower low-frequency band, ultimately reconstructing the original image exactly. Before entering the LLM, integer coefficient values are remapped to local value IDs to bridge the gap between wavelet-coefficient arithmetic and the language model’s embedding space.
