D.5 Optimizer-State Co-Transformation Optimizer-state co-transform ablation. SAGGS is a coordinate change on the symmetry orbit, whereas practical optimizers also maintain state variables. To separate the effect of the orbit move from the possible perturbation of optimizer state, we also evaluate a state-covariant variant. If a rebalance applies A′ := A/c and B′ := cB, then the data-gradient coordinates transform as ∇A′L = c∇AL and ∇B′L = c−1∇BL. Accordingly, for an Adam-family first-moment buffer or a Lion momentum buffer (mA, mB) we map m′ A := cmA and m′ B := c−1mB, and for Adam-family second-moment estimates (vA, vB) we map v′ A := c2vA and v′ B := c−2vB. By default, both hard and Soft SAGGS leave the optimizer buffers unchanged, so neither method needs access to the internal state of the optimizer. We use the state-covariant variant only as a diagnostic: In the Lion state ablation (Appendix F.5), this variant measures how leaving Lion’s momentum buffer in the old coordinates affects the cost of hard rebalancing. D.6 Cost, Weight Decay, and Numerical Guards Computational cost. Each rebalance computes two Frobenius norms and rescales all entries, costing O(nA+nB) per pair with O(1) tensor operations. At interval Tbal, this rebalancing adds amortized work of O((nA +nB)/Tbal) per pair per optimization step. With full-layer Q–K, V–O, and MLP pairs there are 3L pairs; independent headwise Q–K and V–O pairs give (2H + 1)L for standard H-head attention. Interaction with weight decay. A common decoupled decay factor multiplies both matrices equally and leaves their norm ratio unchanged (Zhang et al., 2019). The one-step balance-defect recursion in Eq. 22 records the contribution of this decay factor; we discuss the measured drift in Appendix H.3. Numerical skip guard. The implementation skips a pair when either norm is below δskip := 10−12, whereas Algorithm 1 states the ideal positive-norm map. For a scheduled soft event k with positive norms, let rk := log(∥A∥F / ∥B∥F) before the event and let zk be the log-ratio afterward. The implemented correction obeys, in exact arithmetic, αeff k := α1{min{∥A∥F , ∥B∥F} ≥δskip}, zk = (1 −αeff k )rk. (25) A skipped positive-norm pair has zk = rk, so the hard canonicalizer and fixed-α contraction identities apply to executed corrections.
