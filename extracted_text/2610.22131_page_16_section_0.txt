Intern-Decision: Efficient Multimodal Decision Model A. Release and Reproduction Details The public implementation documentation inspected for this draft is fixed to Git revision 2f815802058b. It identifies ordinary next-token alignment for the masked skeleton; historical same-position masked experiments are separate revisions. The published accuracy and pilot tables use XTuner, while the reported local latency uses native Hugging Face inference. A checkpoint, tokenizer, processor, calibration artifact, and backend configuration together define an evaluated system. The released evaluation procedure consists of four stages. First, verify the bundled test hashes and counts. Second, bind the correct preset temperature to the exact checkpoint through metadata and weight-shard checks. Third, run uncalibrated inference and replay the fixed temperature on the saved probabilities, retaining complete raw outputs and verifying unchanged labels. Fourth, score the pilot separately using its exact references and require 96/96 valid outputs. External-baseline adapters and historical responses are not included, so reproducing Intern-Decision rows does not automatically reproduce every baseline row.
