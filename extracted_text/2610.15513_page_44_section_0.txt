Practitioners can generate their own corpora by running the framework against their own targets. Target models and API credentials are not included. Requirements and reproduction. A single NVIDIA GPU with 8 GB VRAM suffices for the Mistral- 7B reflective model in EXL3 format at 4 bits per weight; the framework was tested on RTX 3090, RTX 4090, and A100 hardware. Commercial target models require provider credentials; open- weight targets run locally with the included serving configuration. Dependencies are pinned in requirements.txt with a Docker configuration for environment reproduction, and the reposi- tory README gives installation steps, a short single-behavior smoke test, and instructions for reproducing the ablation and for running a custom evaluation. Reproducibility notes. Exact reproduction of the reported ASR values requires the same model ver- sions we evaluated (for example GPT-4o-mini-2024-07-18, Claude-3.5-Sonnet-20241022); providers may update weights without changing the endpoint name. For locally hosted targets, EXL3 quanti- zation introduces minor numerical differences against full-precision inference that do not affect the binary success/failure classification behind ASR. Stochastic variation is inherent to evolutionary optimization, so per-behavior iteration and query counts vary across runs while per-behavior success outcomes are stable for the majority of behaviors. B Soft Success Score Formulation This appendix details the soft success score introduced in §3.4.1. Against robust models, binary success/failure signals are sparse and provide no gradient between “almost worked” and “complete failure.” For each failed attempt, REPRO computes a soft score combining four components on a 0–1 scale: soft(𝑥,𝑟) = 0.35 · 𝑝𝑐+ 0.30 · 𝑢𝑟+ 0.20 · (1 −𝑠𝑟) + 0.15 · 𝑒𝑙 (12) where: • 𝑝𝑐(partial compliance) measures content generated before the refusal point, detected via refusal pattern matching. Higher values indicate the model began complying before refusing. • 𝑢𝑟(useful content ratio) is the ratio of substantive content to refusal boilerplate, computed via keyword analysis. • 𝑠𝑟(refusal strength) is emphatic-refusal detection via categorical refusal phrases, inverted so that 1 means weak refusal and 0 means strong. • 𝑒𝑙(engagement level) measures whether the model engaged with the topic at all versus immediately refusing without acknowledgment. Weight rationale. The four weights rank components by expected informativeness. Partial com- pliance receives the largest weight because the strongest near-success signal is the model beginning to comply before the safety system interrupts. Useful content ratio is second; it captures substantive engagement even in refused responses. Refusal strength is third, carrying information but noisier (a strong refusal phrase can coexist with substantive pre-refusal content). Engagement level is the smallest, serving as a tie-breaker. Soft scores are integrated into REPRO at two points. During Pareto selection, near-miss candidates receive a fitness bonus capped at 0.1: fitness′(𝑥) = fitness(𝑥) + min(0.1, ¯𝑠𝑥· 0.2) (13)
