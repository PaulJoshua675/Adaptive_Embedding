AutoSFT: An Agentic System for Automated Data Research in Supervised Fine-Tuning Ethics statement The instruction-following pool is built from openly released datasets and the coding pool from public instruction–code corpora, cited in Section 3 and Section 5.4. Because the AutoSFT optimizes benchmark scores, it could in principle be used to inflate leaderboard numbers, and we report off- target and held-out benchmarks so that a gain from overfitting the target is visible rather than hidden. We apply an 𝑛-gram overlap check between generated data and the evaluation sets in Appendix B.4, and we report the compute and API cost of the runs in Appendix D. Reproducibility statement We will release the AutoSFT implementation, including the training and evaluation script and the agent scaffolding, as anonymized supplementary material. The fixed training script, the token budget, and the from-base retraining protocol are described in Section 2 and Section 3, and the agent roles, prompts, and skill files are given in Appendix B. The initial data pool, the per-round recipes, and the raw evaluation outputs behind every reported number are recorded in a run ledger.
