It is important to note that the input function u(j) is no longer repeated p times, as was the case with the Vanilla architecture. As a consequence, the inner product cannot be performed in the same manner due to the subnetworks’ output shapes no longer matching. Thus, the Branch network’s output must be broadcasted beforehand. This operation can be performed eﬀiciently in many Python libraries using an einsum (Einstein summation) operation. This results in the PI-DeepONet output having the desired shape (n, p, 1), which may be trivially converted to the shape (n × p, 1) of the Vanilla architecture.
