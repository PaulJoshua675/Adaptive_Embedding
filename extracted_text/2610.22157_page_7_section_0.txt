This choice highlights the dominant scaling behaviour. For a neuron in layer l with rl−1 inputs, the activation is given by: σ rl−1 X i=1 wixi + β ! , (6) where σ( ) is the activation function and β is the neuron’s bias. Assuming the computational cost is dominated by the weighted sum and treating the cost of the activation function as a constant, evaluating this neuron processes rl−1 weighted inputs and therefore has a cost proportional to rl−1. Bias additions and application of activation functions are pointwise scalar operations, which we therefore neglect. A fully connected layer with rl−1 inputs and rl neurons therefore has a cost proportional to: rl−1rl. (7) Forward pass cost For an L-layer MLP, the total cost of a forward pass is CMLP ∼ L X l=1 rl−1rl, (8) where r0 denotes the size of the MLP’s input layer. This cost model is equivalent, up to a constant factor, to the conventional floating-point operation (FLOP) count. Each weighted input contributes one multiplication and one addition, which is commonly implemented as a fused multiply-add (FMA) instruction. Dot product The DeepONet output is formed by the dot product s X i=1 biτi, (9) which processes s weighted inputs, where bi and τi are the Branch and Trunk network outputs, respectively. Thus, in accordance with this cost model, a single dot product has a cost proportional to s. A dot product is performed for every input functions and collocation point pairing, meaning the total cost is Cdot ∼nps. (10) Backward pass cost Reverse-mode automatic differentiation for a standard MLP involves two dominant operations per layer: 1. propagation of the error signal via matrix-vector multiplication, and 2. computation of weight gradients via matrix multiplication. Both operations process rl−1rl weighted products, and a summation over inputs per layer. As a result, both operations have the same asymptotic cost when measured in units proportional to the number of weighted interactions, and each are roughly equal to the total of input-weight products performed during the forward pass. Therefore, the cost of computing gradients with respect to model parameters is approximately Cbackward ≈2Cforward. (11) This approximation neglects element-wise operations (Hadamard products and activation function deriva- tives), which contribute lower cost. When automatic differentiation is used to compute physics derivatives, the computational graph is extended. The same backward-pass reasoning applies, but not every layer necessarily performs both dominant opera- tions. In particular, when differentiating with respect to input or coordinate variables (rather than model parameters), the computation of weight gradients is not required.
