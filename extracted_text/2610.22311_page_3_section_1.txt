2.1 VIDEO WORLD MODELS AND SPATIAL MEMORY Video generation has progressed from latent diffusion to scalable diffusion transformers and rectified flow (Ho et al., 2020; Rombach et al., 2022; Blattmann et al., 2023; Peebles & Xie, 2023; Esser et al., 2024), with foundation models supplying strong visual priors (Yang et al., 2024b; Kong et al., 2024; Wan et al., 2025; HaCohen et al., 2024; Ma et al., 2025; Gao et al., 2025; Team et al., 2025). Long-video methods extend these priors through progressive generation, self-rollout training, and causal chunking (Kim et al., 2024; Jin et al., 2024; Henschel et al., 2024; Xie et al., 2024; Gu et al., 2025; Chen et al., 2024a; Huang et al., 2025b; Sand.ai, 2025; Chen et al., 2025a; Liu et al., 2025a), while interactive models target controllable persistent worlds (Bruce et al., 2024; Parker-Holder et al., 2024; Alonso et al., 2024; Valevski et al., 2024; Feng et al., 2024; Zhang et al., 2025d; Che et al., 2024; Yang et al., 2024a; Yu et al., 2025b; Decart et al., 2024; Gao et al., 2026; HY-World et al., 2026; Shen et al., 2026). These directions make history management central: more context supports consistency but makes dense attention increasingly expensive. Spatial-memory methods address this tension by retrieving views, preserving revisits, or expanding reconstructed worlds (Yu et al., 2025a; Li et al., 2025; Xiao et al., 2025; Wu et al., 2025; Huang et al., 2025a; Chen et al., 2025b; Yu et al., 2024b;a; Engstler et al., 2024). Camera-aware and controllable generation (Yu et al., 2024c; YU et al., 2025; Bai et al., 2025; He et al., 2024; 2025; Yang et al., 2025c; Ren et al., 2025; Yu et al., 2026) and streaming reconstruction (Wang et al., 2024b; Leroy et al., 2024; Cabon et al., 2025; Yang et al., 2025a; Wang et al., 2024a; 2025a;b; Keetha et al., 2025) further make projectable memory practical. Velox uses this memory to route pretrained attention rather than adding a conditioning pathway or retrained memory module. 2.2 EFFICIENT ATTENTION AND CONTEXT ROUTING Long-context transformers reduce attention cost through sparsity, locality, compression, state reuse, heavy-hitter selection, and KV eviction (Kitaev et al., 2020; Zaheer et al., 2020; Beltagy et al., 2020; Wang et al., 2020; Dai et al., 2019; Liu et al., 2023; Lee et al., 2025; Jiang et al., 2024; Li et al., 2024; Zhang et al., 2023b; Kwon et al., 2023; Li & Wang, 2026), while FlashAttention is the dense IO-aware baseline (Dao et al., 2022; Dao, 2023). Video accelerators additionally exploit spatial, temporal, denoising-step, and feature regularity through adaptive sparsity, caching, and quantized attention (Zhang et al., 2025c; Xi et al., 2025; Yang et al., 2025b; Zhang et al., 2025b; Xia et al., 2025; Ding et al., 2025; Zhang et al., 2024; 2025a; Liu et al., 2024b; 2025b; 2024a; Guo et al., 2024; Nawaz et al., 2026; Feng et al., 2026). These approaches usually derive sparsity from position, cached features, or attention statistics, whereas frame-memory methods select views but retain dense attention within them. Velox connects both directions by using projective correspondence as a soft prior for region-specific attention routes, with model-derived fallback and temporal safeguards. 3 METHOD Overview. Long-horizon generation requires persistent visual history, yet dense KV attention makes every current region process all retained blocks. Velox keeps the pretrained generator and conditioning interface unchanged and modifies only the inference-time visibility relation between current query blocks and historical KV blocks.
