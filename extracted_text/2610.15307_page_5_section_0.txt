Instead, it extracts low-dimensional physical dynamics features from each architecture and learns a model-agnostic predictor with only a small number of labeled architectures. The pipeline is decoupled into two stages. First, for an architecture α, FENAS extracts raw proxy scores from four complementary physical dimensions and reshapes them through CAST: Φ(α) = CAST(zE ⊕zT ⊕zC ⊕zP ) (1) where α denotes a candidate architecture; zE, zT , zC, and zP denote the proxy scores for expressivity, trainability, connectivity, and parameter capacity, respectively; ⊕denotes feature concatenation; CAST(·) denotes the proposed Copula Alignment and Synergy Transformation operator; and Φ(α) is the re- sulting feature manifold used for prediction. Second, the constructed feature manifold is fed into a meta-predictor: ˆy = fθ(Φ(α)) (2) where fθ denotes a parameterized meta-predictor with learnable parame- ters θ, and ˆy denotes the predicted performance of architecture α. Since CAST concentrates heterogeneous proxy information into a compact feature space, fθ can be instantiated as either a nonlinear tree ensemble [2,3] or a simple linear regression model. 3.2 Pre-Training Feature Engineering The goal of pre-training feature engineering is to map a discrete architecture α into a continuous, low-dimensional, and informative vector Φ(α). This process contains two steps: extracting raw ZCP features from four complementary phys- ical dimensions and applying CAST for distribution alignment and high-order feature construction. 1) ZCPs’ Features Extraction For each architecture α, we extract scalar proxy scores zi ∈R from four dimen- sions: expressivity, trainability, connectivity, and capacity. Expressivity (zE). We adopt NASWOT [21] to measure the expressive abil- ity of an untrained architecture. Given an input batch X, let K be the binarized kernel matrix derived from activation states. The expressivity score is computed as [25]: zE = log det(K + ϵI) (3) where K denotes the activation-based kernel matrix, ϵ is a small positive perturbation for numerical stability, and I is the identity matrix.
