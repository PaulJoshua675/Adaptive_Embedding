A.15 Constructing the free-running environment Where a benchmark ships an executable environ- ment we reuse it and rebuild only the grader at turn granularity; where tools are synthetic we build the executor, state store, and grader ourselves. Both tracks end at the same per-turn reference (§4.4), so one grader serves the mixed environment, routed per example at run time. We inherit API functions and τ 2 databases where they exist and author them where they do not. An executor given arguments absent from the database returns a sentinel rather than raising, so logs still identify the step at which a failure began.
