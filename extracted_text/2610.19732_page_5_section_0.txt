If δh j [Is] is positive, we have zj[Is] > zj[Is−h], which means that between image s and image s −h, the neuron j has slowed down with respect to the other neurons of the layer. Then, α−s+ν+h+1 j either decides if neuron j should be slowed further down (α−s+ν+h+1 j > 0 and mh j [Is] > 0 implies that tj[Is] increases), or accelerated (α−s+ν+h+1 j < 0 and mh j [Is] > 0 implies that tj[Is] decreases). The α matrix containing these parameters is a (N, ν) matrix, where N is the number of neurons of the layer. The parameter α1 weights the memory of one timestep in the past, α2 is used for the memory of two timesteps in the the past, and so on until αν (note that the indices 1, ..., ν are superscripts, not exponents). This mechanism is illustrated on figure 4. This means that, for a sequence of size T images, with T > ν, α1 will be used T −1 times, while αν will be used only T −ν times. For a sequence of size T < ν, the parameter αν is not used.
