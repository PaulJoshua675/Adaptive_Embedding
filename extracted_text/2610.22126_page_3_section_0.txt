2 Background and related work A natural framework for gradient-based feature attribution is that of path methods: let F : Rn →R be a differentiable model and γ : [0, 1] →Rn a differentiable path with γ(0) = b (a baseline) and γ(1) = x (the input to explain). By the gradient theorem, R 1 0 ∇F(γ(α)) · dγ(α) dα dα = F(x) −F(b); expanding the dot product gives the feature attribution Ri, interpreted as feature xi’s effect on the model output: n X i=1 Z 1 0 ∂F(γ(α)) ∂γi(α) dγi(α) dα dα = n X i=1 Ri = F(x) −F(b). (1) Equation 1 guarantees the completeness property: attributions sum exactly to the difference in model output between the input and the baseline. Integrated gradients [Sundararajan et al., 2017] and expected gradients [Erion et al., 2021] are both instances of this framework: integrated gradients uses a straight-line path γ(α) = b + α(x −b) from a fixed baseline, approximated in practice via a K-step Riemann sum; expected gradients instead averages over a distribution of baselines to remove the sensitivity to this single fixed choice, sampling the baseline and path parameter α ∼U(0, 1) jointly to form a Monte Carlo estimator. Both methods, however, implicitly assume that features are mutually independent along the path. The incorporation of feature dependencies in local attribution methods has instead been most thor- oughly explored in the context of Shapley values. Conditional SHAP [Aas et al., 2021] and causal Shapley values [Heskes et al., 2020] are prominent examples. Conditional SHAP accounts for statis- tical dependencies by replacing the marginal feature distribution with the conditional distribution when computing Shapley values, while causal Shapley values incorporate an explicit causal graph to distinguish direct effects from indirect effects mediated through other features. Another extension of Shapley values is the Owen value, which takes into account that features belong to groups [Giménez and Puente, 2019]. The partition explainer in the shap Python package [Lundberg and Lee, 2017] computes Owen values by reducing the number of coalitions on which the marginal contributions are computed, based on an initial partitioning of the features. While incorporating dependencies is contested [Janzing et al., 2020, Aas et al., 2021], it is preferable when the goal is to understand the true data-generating process [Chen et al., 2020, Michiels et al., 2024] — a consideration especially consequential in biological discovery. To our knowledge, no prior work has extended this line of thinking to gradient-based attribution methods, which is the primary contribution of this paper. Numerous modifications to the integrated gradients algorithm have been proposed, though none address feature dependencies. Most target either attribution noise [Kapishnikov et al., 2021], the reliance on an arbitrary baseline [Erion et al., 2021], or both [Yang et al., 2023, Zhuo and Ge, 2024]. Two works are particularly relevant to ours, as they also modify the integration path: Kapishnikov et al. [2021] alters it to avoid regions of high partial derivatives, hypothesized to introduce noise, while Zhuo and Ge [2024] defines a path that follows the model’s gradient. Our work differs fundamentally from both — rather than modifying the path for numerical reasons, we do so to encode causal structure among input features. Feature attribution methods have been widely used to interpret deep learning models trained on RNA expression data and extract biologically meaningful insights [Yap et al., 2021, Janizek et al., 2023, Tang et al., 2023]. Yap et al. [2021], for instance, applied expected gradients to models trained on the GTEx RNA-seq dataset (47 tissue types) to recover genes associated with tissue identity and function, while Janizek et al. [2023] used explainability methods to assess whether unsupervised models capture meaningful gene relationships and pathways. However, most existing attribution methods ignore strong gene dependencies, potentially producing misleading attributions that fail to reflect the underlying biological structure, and their application to high-dimensional RNA expression data remains largely unexplored due to computational complexity. 3 Causal integrated and expected gradients As shown in the background section, all path methods satisfy the same completeness property and differ only in their choice of path.
