4. Benchmark Definition & Tasks. Source Dataset. We propose FASHION-RQBENCH, a benchmark for evaluating fine-grained fashion retrieval and ranking. It is constructed from the public Myntra Fashion Product Images [2] catalog, comprising 44,446 products with structured metadata, free-text descriptions, and prod- uct images. Each item is represented by a 1024-dimensional embedding generated using Marqo-FashionSigLIP [16], and assigned a 3-level SID using the RQ-VAE model de- scribed in Section 3. We exploit the hierarchical RQ- VAE SID structure to construct benchmark instances with- out manual taxonomy design. Each qualifying 1-, 2-, or 3-level SID prefix that satisfies the purity and minimum- size criteria is materialized as a cluster record. This yields 588 clusters, comprising 17, 135, and 436 clusters at levels 1, 2, and 3, respectively (Table 1). Attribute values exhibit substantial lexical diversity, supporting evaluation beyond a fixed vocabulary. Benchmark Tasks. We define four complementary tasks over the same SID hierarchy, with candidate construction and relevance labels derived deterministically, eliminating the need for an independently authored product taxonomy. For a level-3 anchor cluster, candidates receive four graded relevance levels: Exact (same level-3 prefix), Sibling (same level-2 prefix), Related (same level-1 prefix), and Irrele- vant (different level-1 prefix), with scores 3, 2, 1, and 0, respectively. Thus, a single representation defines semantic neighborhoods, evaluation instances, and graded relevance, yielding a consistent and reproducible protocol. • Query–Product Ranking. Given a natural-language query and a fixed candidate pool containing Exact, Sib- ling, Related, and Irrelevant items, rank the candidates according to relevance. We report nDCG@10 and Recall@10, both overall and for explicitly constrained at- tributes. • Hierarchical Relevance Classification. Given a query– product pair, predict one of the four relevance classes. We report accuracy and macro-F1. • Sibling Discrimination. Given one target item and closely related sibling distractors, identify the target leaf cluster. The task emphasizes fine-grained distinc- tions between semantically similar products. We report nDCG@3 and Recall@3 for ranked predictions, or binary accuracy when a single item is selected. • Query Paraphrase Robustness. We use the query groups generated by our method in Section 3 as para- phrases: since all queries from a cluster describe the same target intent by construction, we evaluate them against a shared candidate pool. This isolates sensitivity to query wording from candidate-pool variation. We measure ro- bustness using Consistency@K, the mean pairwise Jac- card overlap of top-K retrieved item sets. 5. Evaluation Framework FASHION-RQ evaluates retrieval quality at three com- plementary levels: (i) task-level performance using the hierarchy-derived relevance labels, (ii) overall query rel- evance based on attribute satisfaction, and (iii) attribute- level diagnostics that identify specific strengths and fail- ure modes. All metrics are computed from the automati- cally constructed queries, query metadata, and SID hierar- chy, without requiring additional human annotation. The four tasks use the common relevance structure defined in Section 4. Task-Level Metrics. We evaluate each task using met- rics suited to its corresponding objective as defined in Sec- tion 4. For Query–Product Ranking (T1), we report nDCG@5/10 and Recall@5/10, both overall and for ex- plicitly constrained attributes. For Hierarchical Relevance Classification (T2), we report accuracy and macro-F1, with per-class precision, recall, and F1 for additional analysis. For Sibling Discrimination (T3), we report nDCG@1/3 and Recall@1/3 to measure fine-grained target-cluster identification. For Query Paraphrase Robustness (T4), we measure retrieval stability using Consistency@5/10, defined as the mean pairwise Jaccard overlap between the top-K result sets across paraphrases, and report the mean nDCG@10 across paraphrases. Weighted Query Relevance. The hierarchy-based metrics assess whether retrieved products belong to the intended se- mantic neighborhood, but do not quantify satisfaction of the individual attributes expressed in a query. Moreover, at- tributes are not equally important in shopping intent: a user may accept a different brand, but not a different product type. We therefore introduce a weighted query relevance score that measures query-level intent satisfaction, with at- tribute weights derived from a cross-encoder trained to re- flect relevance patterns in real user data.
