Real-Time Inference Each inference update samples 16 candidate future mo- tions using 12 DDIM denoising steps. Each candidate pre- dicts keypoint displacements 100 and 200 ms into the future from the robot’s current measured configuration. Guidance specifies displacement from the current commanded config- uration to the requested configuration. These displacements are compared directly; the model also receives the joint track- ing error between commanded and measured configurations. Command chain. Let c be the current applied joint target and q the measured joint configuration. In simulation, the noisy raw expert action ˜a = a + ϵ, ϵ ∼U(−α, α)14, defines the requested configuration qreq = Π(c + 6 · 0.025 tanh ˜a), where Π applies the 0.35 rad tracking-error clamp around q and the joint limits. On hardware, qreq is the retargeted operator configuration clipped to the joint limits. The guid- ance displacement is d = FK(qreq) −FK(c), with no additional magnitude cap on this input displacement on hardware. The inverse model predicts an increment, giving ˆc = c + ∆ˆc. In simulation, ˆc is mapped back to a raw action ˆa = atanh(clip((ˆc −c)/0.025, ±0.999)), clipped to [˜a −2.5, ˜a + 2.5], and applied through the experts’ action pipeline Π(c + 0.025 tanh ˆa); this ±2.5 raw-action radius is the bounded correction in Section IV-B. On hardware, the predicted output increment is clipped to ±0.025 rad per joint; the publisher then applies its configured joint-speed limit, a 0.35 rad tracking-error limit, and the joint limits. With d ∈R24 the guidance displacement defined above, for predicted keypoint displacements ∆x5 and ∆x10 at the two future offsets, guidance minimizes D = ∥∆x5 −d/2∥2 + ∥∆x10 −d∥2. Each norm spans all keypoint coordinates in physical space. At each denoising step, the guidance weight scales a gradient step that reduces D. We select the generated candidate with the smallest summed squared error to these targets. The inverse-dynamics model then predicts a joint-target incre- ment from the selected keypoint motion and the most recent state in the same observation history used for diffusion. By the time this increment reaches the 50 Hz command publisher, the applied target may have changed. Let cobs be the applied target in that observation and ˆc the corresponding predicted target. The publisher adds the already-computed increment ˆc −cobs to its latest applied target cpub: cnew = cpub + (ˆc −cobs). (5) Between predictions, the publisher continues toward the re- sulting target without applying the same increment again. We construct observation histories from timestamped measure- ments and applied commands at the offsets in Appendix VII- A, independently of inference timing. On hardware, inference runs on an NVIDIA RTX 5090 GPU on the operator work- station and is capped at 50 Hz. With these sampler settings, one inference update took 11.8 ms median (17.3 ms 95th percentile), updates arrived at 34.9 Hz on average, and the delay from state publication to the robot’s command buffer was 50.1 ms median (73.7 ms 95th percentile), excluding sensing and motor latency.
