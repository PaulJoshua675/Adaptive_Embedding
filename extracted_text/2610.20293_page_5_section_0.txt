For a generic set function v, let ϕ(v) denote its standard Shapley allocation. Proposition 1 (Endpoint non-identifiability of the Shapley allocation). Let m ≥4 and let v : 2A → R be a set function with v(∅) = 0. The Shapley allocation ϕ(v) is not, in general, determined by the endpoint observations  v({qi}) m i=1,  v(A \ {qi}) m i=1, v(A). Proof. Choose a coalition T with 2 ≤|T| ≤m −2, which exists for m ≥4. Let F be any set function with F(∅) = 0 and define G by G(T) = F(T)+δ for some δ̸ = 0, with G(S) = F(S) for every S̸ = T. Since T is neither a singleton, an (m−1)-coalition, nor the full set, F and G agree on all listed endpoint observations. For any i ∈T, the Shapley term with predecessor set S = T \ {qi} changes by (|T| −1)!(m −|T|)! m! δ̸ = 0, while no other term for that i is affected. Hence ϕi(G)̸ = ϕi(F) and therefore ϕ(G)̸ = ϕ(F). Under additive set values, v(S) = X qi∈S ai, every contextual marginal equals ai, so Singleton, LOO, and Shapley coincide. Additional coalition evaluations are therefore redundant in the additive case. Outside this case, intermediate coalitions can contain allocation-relevant information that is not determined by endpoint observations. The proposition concerns information sufficiency for a fixed set function; whether additional surrogate coalition evaluations are accurate or useful is evaluated empirically.
