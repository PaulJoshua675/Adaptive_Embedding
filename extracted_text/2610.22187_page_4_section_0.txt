The three open models (DeepSeek V4 Flash, Qwen3.8 27B, and GLM 5.3 Flash) were self- hosted on a single fixed endpoint with the sam- pling settings recommended on their Hugging Face pages. The two proprietary models (GPT 5.6 Luna and Gemini 3.5 Flash Lite) were accessed through each provider’s own API with the default sampling settings. We ran every model at its lowest rea- soning level, low for the open models and GPT 5.6 Luna and minimal for Gemini 3.5 Flash Lite. Appendix C provides details about the model pa- rameters. 3.4 Prompts We compared zero-shot and rubric-based prompt- ing. The two prompts share the task description, scale instruction, core scoring instructions, and in- put text. The rubric-based prompt adds the rubric, instructions for scoring each dimension, and an output field for each dimension. Details about the prompts are presented in Appendix B. 3.4.1 Zero-Shot Prompt The zero-shot prompt asks the model to evaluate the target construct in the text and to return a JSON ob- ject containing a single final score on the requested scale. 3.4.2 Rubric-Based Prompt The rubric-based prompt additionally includes a task-specific rubric that decomposes each construct (i.e., political leaning, sentiment, and toxicity) into conceptually relevant dimensions (Table 3). The rubrics were tailored to each task and to each dataset’s unit of analysis, and grounded in the rele- vant literature. The model is asked to score every dimension on the requested scale and then to assign a single final score as a holistic judgment of the text as a whole. This design is intended to make the scoring process more structured. Under both prompting strategies, we analyze only the final score, so that the two prompts are compared on the same output. 3.5 Evaluation Framework We measure scale sensitivity by comparing the scores that the same model gives to the same text under two rating scale conditions that differ in ex- actly one design element.
