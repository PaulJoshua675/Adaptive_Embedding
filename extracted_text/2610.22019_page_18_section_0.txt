C.2 BASE-MODEL POST-TRAINABILITY METRICS We track four base-model post-trainability metrics during midtraining. • LoCoDiff (Mentat AI Team (AbanteAI), 2025) gives the model the full git history of a file and asks it to write the file’s final state. We use all 198 cases, zero-shot with greedy de- coding and a 16K-token generation budget, which covers the longest reference file (11.7K tokens). Exact match is the share of files reproduced byte for byte, and normalized edit distance is capped at 1.2 per case. Greedy decoding still varies slightly across runs because inference is not bit-exact, so we average both over 3 runs. • RepoBench (Liu et al., 2024) measures next-line code completion that requires context from other files in the repository. We report edit similarity in the cross-file-first setting, with greedy decoding. • Repository bits-per-byte follows Composer 2 (Cursor Research, 2026). We concatenate the files of held-out repositories and compute bits-per-byte over long windows. Our version puts the README first, orders files by dependency, keeps the file tree across windows, and does not score file headers. • Trace bits-per-byte is measured on the assistant turns of held-out agent traces, following the decisive-action bits-per-byte of Yu et al. (2026). The version in Table 4 scores only the decisive turns of DeepSWE traces, the turns that most affect the outcome, and masks tool-call formatting, which otherwise dominates the score. D PERSISTENCE OF GAINS THROUGH REINFORCEMENT LEARNING As a preliminary check on whether midtraining gains persist under RL, we run an identical short stage of RL with verifiable rewards (RLVR), 20 GRPO steps (Shao et al., 2024) over 14 verifiable environments (Appendix D.2), from N-3.5 Lightning-8K and its midtrained checkpoint after full SFT. Twenty steps is too short to measure an RL gain, so we only ask whether the midtrained model’s advantage survives the start of RL.
