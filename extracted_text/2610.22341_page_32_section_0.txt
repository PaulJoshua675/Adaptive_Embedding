D EXECUTABLE ARTICULATION AND COMPARISON WITH UWM Explicit kinematic simulation vs. latent video rollouts. Complementing the robotics application in §6, we examine how executable 3D code preserves rigid-link structure during robot manipulation compared with a frozen video world-action model, UWM (Zhu et al., 2025). Using an articulated microwave asset synthesized by GPT-6 Astra and verified by 3DCodeVerse Harness tooling (passing forward-kinematics, rigid-distance, and hinge-sweep gates across five poses), we instantiate a MuJoCo simulation alongside the native reference asset across two initial contact states and three robot control sequences—contact push, hold, and retreat—yielding 12 evaluation cases. Each rollout executes 16 matched robot action commands at 20 Hz: UWM generates three seeded video rollouts per case (36 total) from observation history and action commands, whereas code simulation steps the explicit articulated asset directly inside MuJoCo. Quantitative evaluation of structural preservation. To measure whether rollouts maintain co- herent rigid-part geometry under physical interaction, we apply a calibrated orientation-aware door- and-handle contour detector across all outputs. Calibrated prior to evaluation on 24 held-out static renders across six hinge angles and four robot poses, the detector recovers the true hinge angle within 1◦on all 20 accepted detections and abstains whenever contours degrade or become ambiguous. To isolate latent dynamics drift from autoencoder reconstruction blur, we additionally evaluate a VAE-reconstructed code control by passing every simulator render through UWM’s frozen VAE encoder and decoder. Across all 72 evaluated outputs (Table 18), both direct code simulation and VAE-reconstructed code renders satisfy the geometric criterion in 12/12 (100%) rollouts, whereas UWM predictions satisfy the criterion in only 7/36 (19.4%) rollouts (29/36 fail to preserve assessable door-and-handle contours).
