Fields with- out evidence remain unavailable, and papers whose eligibility remains unavailable are not categorized. 3.5 Semantic Categorization The Lead Agent categorizes extracted values only for papers retained after eligibility check. For a selected field, it proposes a set of categories with short descriptions (Appendices A.6 and G.6). The plan supports single-label or multiple-label assign- ment, and an Other category for values that do not fit. Researchers review and edit the plan before the Lead Agent assigns labels to each paper. Papers with no value for the field are marked unavailable. 3.6 Memory Design Researchers work in a conversation panel and a stage-specific canvas. A chat request that changes criteria or the schema is saved as a draft, and confir- mation is a canvas action (Appendices A.7 and H). Project memory stores the conversation history, cur- rent configurations, confirmed configuration snap- shots, and each stage’s status and PRISMA counts. In conversation, the Lead Agent receives its task instructions, the current request, the saved project state, and the conversation history. Its instructions give saved state precedence over superseded re- quests and distinguish drafts from confirmed con- figurations. Researchers reuse a previous project’s configuration by importing it as a draft that again re- quires confirmation. The system does not retrieve memories across projects automatically or learn preferences from corrections. To override a screening decision, researchers se- lect a confirmed criterion or guidance rule and give a reason. They also give reasons when correcting extracted values. Original decisions and values re- main in review history. A change to a confirmed configuration or reviewed record marks affected downstream outputs as outdated until rerun. 4 Experiments & Results We evaluate screening and structured information extraction separately against the expert annota- tions in PERG, a dataset released with AgentSLR (Padarha et al., 2026). Extraction uses the same expert-included papers for all methods, indepen- dently of each method’s screening predictions. 4.1 Experiment Setup Data and reference annotations. PERG is re- leased under the CC BY 4.0 license. Its annotations originate from systematic reviews conducted by the Pathogen Epidemiology Review Group at Impe- rial College London for WHO priority pathogens (Cuomo-Dannenburg et al., 2024; Nash et al., 2024; Doohan et al., 2024; Morgenstern et al., 2025; Mc- Cain et al., 2025; Naidoo et al., 2026). Screen- ing uses 5,614 title–abstract records for Lassa, Ni- pah, SARS, and Zika, with 854 expert inclusions (15.2%). All methods apply the five inclusion and six exclusion criteria specified in AgentSLR’s PERG template (Appendix B). All records are eval- uated without date filtering or deduplication. Extraction uses 178 annotated papers (79 for Ebola, 6 for Lassa, 36 for SARS, and 57 for Zika). We evaluate five fields: model type, stochastic or deterministic status, code availability, transmission routes, and interventions (Table B.2). PERG anno- tates each transmission model in a paper. Reference values are aggregated to the paper level by taking the union across models. Code availability is true if the paper reports available code for any model. Models and evaluation metrics.
