Integer wavelet coeffi- cients should not be represented as ordinary text tokens for two reasons. First, although the native Llama vocabulary is indexed by consecutive token IDs, those IDs do not encode numerical locality. Neighboring token IDs correspond to neighboring text symbols rather than neighboring coefficient values. Second, raw coefficient values include negative integers and therefore cannot be used di- rectly as valid embedding indices or classification labels. Near-zero coefficients, which are the most common values in high-frequency subbands, therefore fall near the center of this local space.
