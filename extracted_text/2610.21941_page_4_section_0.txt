B. Datasets The training data of our sentence-level multiple attribute speech encoder combines Common Voice 19 [19] and a collection of dataset annotated with emotion labels in different languages. This list of emotion datasets used in our collection is presented in Table I. From Common Voice 19, we use the 83 languages supported by BGE-M3. Common Voice is mainly used for semantic, speaker, and language supervision, while the emotion collection provides affective speech data for emotion supervision and additional non- transcribed speech. For the emotion collection, each corpus is split independently into 80% training, 10% development, and 10% test data. After preprocessing, Common Voice provides 8,205.92 hours of speech and the emotion corpora provide 92.59 hours for training. This results a total of 8,298.51 hours of training data. The emotion collection contains 31 speech emotion recognition datasets covering multiple languages, recording conditions, and emotion taxonomies. Sampling strategy In order to balance the data sources across tasks and languages, we applied a resampling strategy similar to those proposed in [5] and [8], which were used to train the SAMU-XLSR and SENSE models, respectively. This strategy computes a sampling weight for each sample. These weights are then used by the sampler to randomly select samples when constructing each training batch. D. Implementation and training details The shared speech encoder is initialized from w2v-BERT 2.0. We implement the multi-teacher model in SpeechBrain, based on the open-source SENSE implementation. All teacher embeddings are pre- computed before training in order to reduce the training cost. We fine- tune the shared w2v-BERT 2.0 encoder with Adam using a learning rate of 10−5. The task-specific modules are optimized separately with Adadelta using an initial learning rate of 1.5. Training is performed with a batch size of 14 for both training and validation. The model is trained for 17,613 iterations using 32 H100 GPUs. E. Tasks To evaluate the quality of the semantic representation learned by our approach, we assess the model on multilingual speech retrieval. We evaluate the learned speaker representations on a speaker ver- ification benchmark, and the language branch through a language identification experiment based on a classifier trained on the extracted embeddings. Last, we evaluate the emotion branch on speech emotion recognition datasets using dataset-specific classifiers. For each attribute, we compare three types of representations: the corresponding frozen teacher model, a single-task student model trained only for the considered attribute, and the proposed multi- teacher student model. This comparison allows us to quantify the impact of joint training and to evaluate whether a unified encoder can preserve attribute-specific information while sharing most of its parameters across tasks. 1) Multilingual speech retrieval: We assess the semantic branch on multilingual speech retrieval. For each experiment, we define a query set and a search set. The query set contains speech utterances, while the search set contains the corresponding translated items in another language. The objective is to retrieve the correct translation of each query from all candidates in the search set. Each query utterance is encoded into an utterance-level embedding using the semantic branch of the evaluated model. When the search set contains speech, candidate utterances are encoded with the same speech encoder. When the search set contains text, target sentences are encoded with BGE-M3. Embeddings are normalized before retrieval, and candidates are ranked according to cosine similarity. Performance is reported with Recall@1. In this work, we restrict the semantic evaluation to VoxPopuli and FLEURS. VoxPopuli is used to evaluate multilingual speech retrieval on European languages, while FLEURS is used to assess generalization to a broader multilingual setting, including unseen and low-resource languages. We compare the se- mantic branch of the proposed multi-teacher model with the semantic- only student and the SENSE teacher. 2) Speaker verification: We evaluate the quality of speaker- related information using the VoxCeleb1-O speaker verification pro- tocol [47]. Speaker embeddings are extracted from enrolment and test utterances using the speaker branch of the evaluated student models, or directly using the ECAPA-TDNN speaker teacher. For each trial pair, verification scores are computed using cosine similarity between the two utterance-level speaker embeddings. We compare the pro- posed multi-teacher model with the frozen ECAPA-TDNN speaker teacher and with a single-task speaker student trained using the same architecture but retaining only the speaker branch. Performance is reported in terms of Equal Error Rate (EER) and minimum normalized Detection Cost Function (minDCF), with Ptarget = 0.01 and CFA = CMiss = 1. 3) Language identification: To evaluate whether the language branch captures language-discriminative information, we perform a language identification experiment on VoxLingua107.
