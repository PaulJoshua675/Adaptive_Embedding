Both models are evaluated on the same examples using the same cor- rectness criteria. For numeric angle targets, a step is correct if the shortest circular difference between the predicted and target angles is at most 10◦; discrete actions require exact label matching. We report Progress and Chain Acc. separately for each chain length. For a target sequence of length n, let k be the number of consecutive correct predictions from the first step. Progress is 100k/n. Once a prediction is incorrect, that step and all subsequent steps receive no credit, even if a later prediction matches its target. For example, a three-step prediction with only its first step correct receives a Progress score of 33.3%. Chain Acc. assigns a score of 100 only when the predicted sequence has the same length as the target and every step is correct, and 0 otherwise. Both metrics are averaged over all evaluation examples of the corresponding chain length, pooling the four target types. 22
