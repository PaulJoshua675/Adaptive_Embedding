B.4 Random-Walk Endpoint Blend For each node i whose embedding is being modified, walk_endpoint launches 100 random walks starting from that same node i. It forms the graph-context vector for i as a frequency-weighted mean of the endpoint embeddings; intermediate paths are discarded. Parameter Meaning Values walk_steps Number of graph transitions per walk 2, 3 alpha Original-vector retention 0.0, 0.5, 0.8 walks_per_node Walks launched from each node 100 (fixed) walk_seed Reproducibility seed 42 (fixed) Along alternating chunk–entity paths, two transitions can return to a chunk and three can end on an entity. Other node and edge types may change this pattern. Returns to the starting node are possible unless excluded by the transition rule; that rule remains to be verified. B.5 Louvain Cluster Blend Community detection uses the Louvain family introduced by Blondel et al. [11]; the subse- quent embedding blend is the transformation evaluated here. louvain_cluster detects graph communities and moves each node towards the centroid of its community. Parameter Meaning Values resolution Controls community granularity; larger values produce smaller communities 0.5, 1.0, 2.0 alpha Original-vector retention 0.0, 0.5, 0.8 louvain_seed Reproducible partitioning seed 42 (fixed) At resolutions 0.5, 1.0, and 2.0, the graph contains respectively 20, 34, and 50 communities, with median sizes 85, 44, and 31. When α = 0, every member is mapped to its frozen original-space community centroid, eliminating within-community distinctions.
