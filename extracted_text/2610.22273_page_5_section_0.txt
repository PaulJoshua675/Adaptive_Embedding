The builder agent selects an augmentation 𝒜𝑡∼𝜋build(· | ℱ𝑡), which is applied to the filesystem to produce ℱ𝑡+1. We constrain the builder to the following discrete action types that can each be applied to different files: • CreateFile: Creates a new synthetic file by consolidating information from a subset of raw documents and/or existing synthetic files. The file has reference links to the set of sources used to construct it. • MergeFiles: Aggregates a set of related synthetic files into a higher-level summary or directory- like artifact. This action introduces hierarchy, linking to child files. • Delete: Removes redundant/unhelpful synthetic files from the active answer-facing workspace. This operation never deletes raw documents in 𝒟, preserving fallback access. • Stop: Terminates memory construction, returning the current workspace ℱ𝑡as the final memory artifact to use for the downstream answering agent. The action types here is intentionally constrained to reduce the horizon for optimization. In principle, this interface can be generalized to a broader set of atomic filesystem commands (e.g., touch, mkdir, mv, rm, etc). We describe the instantiation of these actions in the filesystem in Appendix A.8. Reward Function.
