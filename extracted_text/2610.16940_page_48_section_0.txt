K Literature Survey: Evaluation Practices in Metric Space Search To contextualize our experimental contributions, we surveyed 61 papers from the metric space near- est neighbor search literature and classified each on four evaluation-practice dimensions that our work addresses: 1. Micro-optimizations — Does the paper discuss implementation-level micro-optimizations (e.g., SIMD, cache layout, memory coalescing, bit tricks) as opposed to purely algorithmic improvements? 2. Runtime & distance counts — Does the paper measure both wall-clock runtime and the number of distance computations (or avoided/pruned computations) in its experiments? 3. Batch vs. single query — Does the paper compare or test between bulk/batch querying and single-item-at-a-time querying? 4. Query from set vs. held-out — Does the paper explicitly differentiate or test between queries drawn from the indexed dataset versus new held-out points not in the data structure?
