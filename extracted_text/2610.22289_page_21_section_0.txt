Controlled_RESET provides a more focused example. The environment description already tells the agent to reset after GAME_OVER and avoid unnecessary resets otherwise. Nevertheless, asking Codex to leave this decision to a scripted controller improves mean performance. The intervention adds no new game rule; it changes how an available rule is implemented. This does not mean that the scripted policy is optimal: as discussed in Section 6.2, a capable agent could sometimes save actions by resetting an unrecoverable attempt before GAME_OVER. The curriculum experiment provides a complementary example: additional relevant experience is not automatically beneficial. The tutorials give the agent practice applying the maze mechanics, yet they reduce target performance for both GPT-5.5-based variants at both effort settings. With GPT-5.6-sol, they help both variants at xhigh and have smaller, mixed effects at max. The benefit of additional experience therefore depends on the evaluated configuration, rather than following from its availability alone. 9.2 The amount and allocation of inference A second explanation is that the scaffold changes how much inference the agent performs and when it performs it. Asking Codex to report a difficulty may prompt additional reasoning while it formulates the report. The subsequent continuation lets it return to the task. Together, these steps may increase inference at points where the agent is uncertain, even with the model and reasoning-effort setting unchanged. Stop-and-report uses more normalized cost tokens than Baseline in every ARC-AGI-3 and AGI Maze comparison. Within each ARC-AGI-3 configuration, the ordering from Baseline through Stop-and-report and Controlled_RESET to twma_v1.61 is the same for mean score and mean cost. This pattern makes additional inference a plausible contributor to the gains, but does not establish that greater expenditure causes the improvement. Cost tokens include weighted input and output, not only useful reasoning. Better performance can also enable more expenditure: an agent reaching additional ARC-AGI-3 levels can continue working where another run has stopped. Performance and resource use should therefore be considered together when interpreting the effect of scaffolding [30]. Better use of information can itself involve additional inference, for example when the agent rereads a description or reasons about how to reorganize its observations. 9.3 Implications and future directions It remains unclear whether further gains should be sought primarily through better use of available information and tools, through additional inference (for example, in a multi-agent system), or through a combination of the two. Further analysis is needed to determine their relative contributions and whether they can be meaningfully separated. One direction is to improve the environment-agnostic agent through more explicit procedures, including adaptations of the verification and simplification ideas explored in our earlier work [9]. The objective is to obtain further gains on some environments without material regressions on others, while retaining one unchanged agent implementation. A complementary direction is to expand the general capabilities initially available to the agent. Examples include reusable task-general skills, support for symbolic reasoning through a system such as MeTTa [31], or theorem-proving tools. These additions would supply tools or procedural knowledge, rather than only change the guidance for using existing tools, but could still be provided uniformly across environments. 21
