Decide the generation approach yourself; the target states what to teach and how it is accepted, not how to produce it. # Generation Design a system prompt and few-shot demonstrations for the generation model, drawn only from pool rows or from your own candidates that already passed validation this round. Over-generate several times the required rows and discard every candidate that fails validation; when a batch is weak, diagnose why, revise the prompt, and call again rather than lower the standard. Rows must come from model API calls, not from a script that assembles responses to satisfy the verifier. # Verification Translate the target’s requirement into acceptance criteria and build a verifier for it. Programmatically checkable constraints are gated in full by that verifier; semantic fit gets one model review on the final candidate set, and read-only subagents that took no part in generation spot-check quality, diversity, and fit. Close at least one loop of generate →verify →review →revise before delivering. # Decontamination Phrase the capability requirement without reproducing evaluation wording. A benchmark score is reported as avg@k, the mean over 𝑘stochastic evaluations of one checkpoint. IFEval and IFBench use 𝑘=10 and MBPP+ uses 𝑘=3. Resource usage. We estimate the cost of a research run from the synthesis experiment, which uses the largest per-round budget of 100M tokens. Each round prepares data under agent guidance, fine-tunes one recipe, and evaluates the resulting checkpoint. Training takes about 0.8 GPU-hours per round on 8 H800 GPUs and evaluation about 0.15 GPU-hours on one, so a 20-round run costs roughly 130 GPU-hours. The research agent and the generation backend together consume about 2.6 × 108 tokens per round, counting input, output, and reasoning tokens, for an estimated API cost near USD 95 per round, or USD 1,900 over the run. The paper reports about ten distinct runs and a few hundred rounds in total, counting a shared baseline once. Scaling each experiment by its token budget gives an order-of-magnitude total of 103 GPU-hours and USD 104, with real usage varying by hardware utilization, evaluation protocol, and agent activity. 23
