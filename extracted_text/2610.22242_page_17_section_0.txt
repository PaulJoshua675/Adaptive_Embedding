A SURVICL MODEL DETAILS A.1 ARCHITECTURE We build SurvICL on top of TabICLv2 (Qu et al., 2026), which is at the time of writing the leading fully open-source model on the TabArena benchmark (Erickson et al., 2025). While refer to the original paper for the details, the key components of the TabICLv2 architecture can be summarized as follows: • Preprocessing: First, some light preprocessing is applied, including ordinal encoding of categorical columns. After the preprocessing, the model receives a fully numerical table. • Target-aware embedding: The original covariates (xij) ∈Rn×m are transformed into embeddings (zij) ∈Rn×m×128 containing one embedding vector zij ∈R128 per cell (i, j). Each embedding vector is obtained from an affine transformation applied to three cells in the same row (“repeated feature grouping”). An affine transformation of the target yi is added for the context set rows. • Column-wise embedding: Each column j of the resulting embeddings is processed in- dependently using three induced self-attention blocks that allow interactions between dif- ferent rows in the same column, resulting in a complexity of O(nm), which is linear in the number of rows, unlike a full Transformer. Crucially, the attention is designed to only retrieve information from the training set, meaning that predictions on test samples are independent of the other test samples. • Row-wise interaction: Next, three full transformer blocks allow different columns within a row to interact. Before these blocks, four extra columns with fixed values are appended, and after the blocks, the values of these four columns are concatenated and serve as row embeddings, while the other columns are discarded. • ICL transformer: After adding another embedding of the targets, the embeddings of each row interact via 12 regular transformer layers, again making sure that test samples cannot access other test samples. • Head: Finally, a multilayer perceptron (MLP) head transforms the output embeddings into 999 quantile predictions (for regression). Overall, the TabICLv2 architecture has a runtime complexity of O(n2 + nm2), and SurvICL pre- serves this complexity since it only modifies the O(nm) preprocessing and embedding parts. In addition, like other TFMs, we use ensembling, where the predictions of eight forward passes with different preprocessings and column permutations are averaged. Building on TabICLv2, we introduce the following adaptations to handle survival data: • Time normalization: We normalize observed times by their mean over the context set, yielding ˜ti = ti/¯t, where ¯tcontext is the mean duration of the observed times. This makes the time representation invariant to the choice of measurement units. During pre-training, both context and query sets are normalized and the mean ¯t is taken across context and query set. During inference (after pre-training), the mean for ¯t is taken across the context set, and the predicted quantiles are transformed back to the original time scale. • Censoring-aware target embedding: We replace the scalar target embedding with a joint representation of the observed time and event indicator. Specifically, we sum the embed- ding of the continuous time ˜ti and a learned embedding of the binary indicator δi. This representation is added to every cell embedding in context row i, allowing the column-wise encoder to distinguish observed events from censored observations. • Survival information at the ICL stage: We also encode (˜ti, δi) using a separate pair of time and event-indicator embeddings whose sum matches the dimension of the row representation. This embedding is added to context row representations before the ICL transformer. At both embedding stages, survival outcomes are supplied only for context rows. • Survival prediction: The MLP head predicts quantiles of the conditional event-time dis- tribution, using a softplus transformation to ensure that the quantiles are positive.
