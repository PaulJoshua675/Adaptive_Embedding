D BASELINE IMPLEMENTATION DETAILS All four baselines use the task-level training data and per-method GPU budgets in Tables 5–6. They use the same query videos and, for action-selection tasks, the same candidate actions and success criteria as T2-Z. The three adaptive baselines receive exactly the same test-time interaction trajec- tories as our latent optimizer. The tables give the common task-level batch specification; DINOv2 Context uses a subset of sampled trajectories for conditioning and all sampled trajectories as queries during training, whereas TTT-KQV processes them as ordered within-environment streams. D.1 STANDARD WORLD MODEL This baseline fine-tunes the BWM-initialized DiT and action encoder on pooled task trajectories without an environment latent or test-time adaptation. It uses AdamW with model learning rate 10−5, weight decay 0.01, 100 warmup updates, gradient clipping 0.5, and bfloat16.
