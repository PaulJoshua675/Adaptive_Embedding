C1 shows highest MAD (.295): memory quality is systematically better than what QA evaluation reveals. Per-trajectory scores are in Appendix I. the two evaluation methods measure fundamentally different properties of the system. C1 (LLM Compensation) shows the highest MAD (0.295 ± 0.084): intrinsic scores 82.2% while extrinsic scores only 54.5%, confirming that memory quality is systematically underestimated by response-based evalua- tion. C5 (Temporal) and C6 (Multi-Author) show the lowest intrinsic scores (59.3% and 41.5%), identifying temporal evolution and source attribution as the hardest dimensions, yet extrinsic evaluation reports near-uniform scores across all categories, masking these weaknesses. Finding 2: Difficulty and Divergence. DivRate decreases with difficulty (L1: 55%, L2: 50%, L3: 26%). At L1, intrinsic substantially exceeds extrinsic (68.0 ± 3.2 vs. 50.9 ± 4.2), meaning the system stores correct knowledge that retrieval fails to surface for QA. At L3, both scores converge near 47%, but diverge on individual trajectories in opposite di- rections (some false positives, some false negatives). MAD varies across levels (.178, .224, .103), indicating disagree- ment persists at all difficulty levels. Classification accuracy degrades sharply with difficulty (33.8 →16.5 →10.1%), confirming that the system’s ability to correctly label actions deteriorates as signal becomes more subtle. Finding 3: Category-Specific Failure Modes. Diagnostic decomposition reveals distinct failure patterns. The overall false update rate is 22.2 ± 1.2%: the system modifies facts when it should only reinforce. Update detection recall is 73.6±2.6%. Classification accuracy (whether the system cor- rectly labels the action as create/reinforce/update/supersede) is only 20.1 ± 2.7%, with C2 (4.5%) and C5 (0.4%) near zero. Confidence MAE is 0.106 ± 0.002 across all trajecto- ries. C6 (Multi-Author) shows the lowest intrinsic accuracy (41.5%), identifying multi-author source attribution as the system’s weakest dimension. These insights are invisible to extrinsic evaluation, which reports a near-uniform 42–55% across most categories (per-category/difficulty breakdowns in Appendix F). Finding 4: Actionable Diagnostics. The intrinsic metrics directly identify which pipeline stage to improve: (1) classifi- cation accuracy is 20.1% overall, meaning the system rarely assigns the correct action label even when its fact state ends up partially correct; (2) multi-author source attribution (C6: 41.5%) does not adequately leverage author identity; (3) false updates (22.2%) indicate overly aggressive modification on reinforcement signals.
