The key design choice is to measure public behavior and private belief separately: the chat only shows what agents say to the group, and private probes show what they answer when no other agent can see it. 3.1 Threat Model and Chatroom Each run is a chatroom of N=10 agents that dis- cuss one factual item for T=16 rounds; all agents in a run share the same base model. We vary the number of adversarial agents k ∈{0, 1, 3}, making 10−k benign agents. The k adversarial agents are independent that each advocate a fixed false claim whenever the topic arises; benign agents receive ordinary discussion personas and instructions that do not include the false claim. The attacker only posts messages; it does not edit weights, read hid- den states, or control benign agents, and is thus strictly weaker than the parameter-editing attacker described by Ju et al. (2026). In every round each agent speaks exactly once, in a random order that is reshuffled every round and identical across conversations (Appendix D), con- ditioning on the recent shared history (the previous H=5 rounds) and the current round. Conversa- tions start from a neutral discussion seed about the topic, so benign agents are not steered toward either answer. 3.2 Dual Private/Public Measurement We call a separate call a private probe and its output the agent’s private answer. We use belief for what the private answer is meant to reflect. Private probes. At the initial state and after ev- ery round, each benign agent answers the probe question in a separate call whose response is hid- den from the other agents and never posted to the chatroom. Because the attacker acts only in con- text, an agent’s state is its context: the probe condi- tions on the agent’s persona and its conversational memory (the same last H rounds) and asks for a private answer based on its knowledge and the discussion (Appendix A). At step 0 the memory is empty, so the initial probe is a query without conversational history. A judge labels each private answer as TRUE, MANIPULATED, MIXED, or UN- CERTAIN; an agent is infected at a step if its label is manipulated. MIXED and UNCERTAIN are never counted as infection. Public stance. Independently, a judge labels each benign utterance’s public stance toward the manip- ulated claim as ENDORSE, REJECT, HEDGE, IG- NORE/DRIFT, or UNRELATED, given the recent conversational context. Exposure. We call a benign turn exposed if at least one adversarial agent’s utterance precedes it in the transcript (i.e., the agent has had an opportunity to see and react to the claim). Public response metrics are reported over exposed benign turns, since unexposed turns have no claim to respond to. Pairing the two signals. Probes are taken only between rounds, so none captures an agent’s pri- vate answer at the moment it speaks. An agent that speaks mid-round has heard the earlier speakers of that round but not the later ones. The probe before the round has heard neither, and the probe after the round has heard both. We pair each utter- ance with the probe after the round, which covers everything the agent heard before speaking. This probe can, however, reflect later speakers: an agent that still held the true answer when it spoke may already hold the false one when probed. Two pair- ings avoid this gap: first speakers paired with the probe before the round, and last speakers with the probe after it. Our results hold on these turns (§4.2, §4.5, Appendix B). 3.3 Metrics Let B be a condition’s benign agents and ℓ(t) a agent a’s private label at step t. Final private infection (FPI).
