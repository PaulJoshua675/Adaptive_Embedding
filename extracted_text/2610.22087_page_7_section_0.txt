7 To evaluate our search engine, we used a dataset of 137 primary and secondary salivary gland tumors spanning 12 ICD-O morphologies (Fig. 2). The dataset is imbalanced, with 82% of cases concentrated in five morphologies (Fig. 2a). We excluded entities represented by only a single case but deliberately retained the three morphologies with only two cases for a both statistically and morphologically challenging task (Fig. 2b). While this search engine requires no model training, we wanted to know how well automated sourcing through ABMIL performed for each FM. We therefore sourced the region with the highest average attention at both 2×2- and 4×4-patch sizes (Fig. 2c). Neither the FM used for sourcing, nor the query size produced a relevant difference in retrieval accuracy. Averaged over all 16 configurations, 4×4 queries tended to be slightly better than 2×2 at Top-1 (50.3% vs. 48.3%, p = 0.110) and were essentially identical at Top-3 (64.3% vs. 63.8%, p = 0.691) and Top- 5 (71.5% vs. 71.2%, p = 0.831). As query size was therefore not a performance-driven decision, we selected 4×4 for the remaining analyses, as it corresponds better to the field of view a pathologist typically assesses. The pathology FM used for retrieval did affect performance (Fig. 2d). Pooled across both query sizes, Atlas2 retrieved the correct morphology at Top-1 more often than Atlas2-S (53.5% vs. 47.4%, p = 0.029) and UNI2h (53.5% vs. 47.9%, p = 0.029) but not significantly more often than Atlas2-B (53.5% vs. 48.5%, p = 0.074). There was no significant difference at Top-3 or Top-5 between Atlas2 (64.5%, 74.7%), UNI2h (61.8%, 66.9%), Atlas2-B (64.9%, 73.1%) and Atlas2-S (65.0%, 70.7%). Figure 2. Cohort composition and retrieval performance by sourcing and indexing model. (a) Evaluation cohort, beige color indicates less than ten cases. (b) Representative examples of four morphology classes. (c) Macro-averaged recall by query size and by which model the input was sourced, retrieval averaged across all models. (d) Macro- averaged recall by query size and by which model was used for retrieval, input averaged across all models.
