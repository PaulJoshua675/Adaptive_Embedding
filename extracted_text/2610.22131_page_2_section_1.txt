Decision Models. Recent decision models target fast, structured judgments: given a state, questions, and predefined answer options, they return typed decisions with probability estimates rather than free-form text. Alongside TypeSafe’s Jev [27], which supports choice, score, and binary decisions and reports using Reinforcement Learning for Calibrated Decisions (RLCD), related open implementations explore different modeling and inference strategies for structured decision-making. JevK5 [1] adapts Qwen3.5 with LoRA and derives candidate probabilities from next-token logits through a Jev-style interface. Kev [17] combines Qwen backbones with LoRA adapters and a learned pointer head, providing self-hostable models and an API for typed choices and scores. SemIf-OpenJev [26] provides a direct-scoring approach that derives option probabilities from candidate-token logits of frozen language models, with optional shared-state prefill reuse across questions. Laya [22] adopts an encoder-based, non-autoregressive architecture to produce choice, score, and yes/no decisions in a single forward pass. Within this paradigm, Intern-Decision focuses on multimodal structured decision-making, incorporating visual inputs alongside textual states and task instructions. 2
