Task-Level Differences. On the workbook task, both selected runs satisfy the evaluation criteria, but GPT-6 Astra uses 22 steps and 8,783 output tokens, compared with 37 steps and 120,831 tokens for Qwen3.8-Max. Reported reasoning accounts for 1,487 and 92,974 tokens, respectively. On the PDF task, Qwen also uses significantly more output tokens (28,268 versus 10,013). The following case studies examine how observation choices and code execution contribute to the observed differences. With only four tasks and one run per model, these results characterize the evaluated configurations rather than establish a general model ranking. 4.3.4 Case Studies The gap in real-device execution extends from basic operation to completing an entire task. We compare GPT-6 Astra and Qwen3.8-Max through earlier low-effort trajectories under the same harness on real-device tasks, separate from the selected runs in Table 5. The following cases show differences in the cost of routine operations, the selection of observation targets, and the ability to turn a task into an effective program. Large Differences in Reasoning Cost for Simple Operations. In a shopping task, Qwen produces a four-line program that captures and returns a desktop screenshot. The program returns an image, but the model response uses 2,105 output tokens, including 2,030 reasoning tokens. GPT also obtains a screenshot in another step of the same task, but its entire response uses only 124 output tokens, including 11 reasoning tokens (Figure 10). This contrast shows that a substantial reasoning-cost gap can arise even in a simple observation step. Such generation overhead can introduce substantial execution latency. Difficulty Adapting to Real-Device Conditions. On a real device, the page an agent needs to inspect may not be in the foreground. In the shopping task, Qwen is working with an Amazon browser object but requests a desktop screenshot, which shows the foreground Taobao login page. It then brings Amazon forward and captures again. GPT instead requests a screenshot directly from its selected browser page. Both models use screenshots; the contrast concerns observation scope, illustrating why the intended task target cannot be assumed to coincide with the foreground interface. 22
