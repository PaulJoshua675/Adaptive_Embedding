B.2.5 SFT COLD START To teach the models the input and output formats and establish basic navigation capability, we per- form an SFT cold start in both settings. Starting from the multimodal-alignment checkpoint of NaVILA, we render oracle trajectories on R2R-CE training episodes with Habitat’s shortest-path follower. We keep successful episodes containing 1,931 decisions (800 turns, 800 moves and 331 stops), and use Claude Sonnet 5 to annotate data. We fine-tune the monolithic agent on all data and each society agent on its own data. SFT for each model is performed on a single B200 GPU. We fine-tune all model parameters in bf16 using AdamW with a cosine learning rate schedule. Detailed settings are listed in Table 4. B.2.6 POST-TRAINING Our post-training dataset consists of 10,744 R2R-CE training episodes different from SFT. We host the Habitat environments on 2 RTX PRO 6000 GPUs. Reinforcement learning is performed on 4 B200 GPUs. Detailed settings are listed in Table 4. B.3 DEEP RESEARCH B.3.1 TASK AND ENVIRONMENT The task is open-domain deep research: given a question, the agent must browse a local web corpus with three tools and return a short final answer. We use the OpenResearcher benchmark (Li et al., 2026): the questions are the OpenResearcher-Dataset, and the corpus is the OpenResearcher-Corpus, served by a BM25 search service.
