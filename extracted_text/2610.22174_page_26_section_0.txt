A request exceeding the rollout-level fork budget is not executed; the main agent receives a tool response indicating that it should continue using search, visit, or a final answer. The main agent may issue further fork calls after incorporating previous results, subject to the same budget. Each child as a subagent receives a fresh, single-session ReAct context. It uses the base search-agent system prompt and has access only to search and visit; in particular, subagents cannot recursively invoke fork. The child user message is: Subagent User Prompt You are a research subagent created by a main search agent. Complete only the assigned task below. You may use search and visit tools. Return the final result for the main agent inside <answer></answer> tags. Assigned task: [subagent task] Final response format: <answer></answer> Every main-agent and subagent session has the same maximum context length of 131,072 tokens, a reserved generation budget of 16,384 tokens, and a maximum per-generation length of 16,384 tokens. Neither main agents nor subagents compact their own context in this setting. If a proposed turn would exceed the per-session budget, the corresponding agent receives the forced-answer message in Appendix C.1 and it then makes one final generation attempt and terminates. A child is considered successful only if a non-empty <answer>...</answer> block can be extracted. Otherwise, its session terminates as a failed subagent execution.
