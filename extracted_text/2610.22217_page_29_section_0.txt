Preprint. Evidence-Grounded Capability Skill Induction Prompt Role You are improving an expert vision-language model using evidence distilled from its own training trajectories. Input {Evidence Ledgers} containing successful and failed trajectory patterns for the current domain. Domain Guidance {Domain-Specific Guidance} specifying how the observed failure mechanisms should transfer across tasks within the domain. Objective Convert recurring success and failure patterns into a compact domain-level skill that provides reusable verification and corrective guidance. Rule Form Each task-specific rule should follow: “When [specific trigger], [verification or corrective action].” Task Routing Organize rules by task section so that only the checks relevant to the current question type are applied. Grounding Ground each task section in supporting failure evidence and, when available, contrasting successful evidence. Constraints Do not copy instance-specific answers, values, coordinates, or memorized examples. Avoid unsupported rules, unnecessary step-by-step procedures, and instructions that suppress reasoning. Prefer a small number of precise, conditionally activated rules. Required Output Objective A concise objective for the domain skill. Evidence Protocol A small set of shared rules applicable across tasks in the domain. Task-Specific Checks For each task section, a small set of trigger-conditioned verification or corrective rules. Final Verification A small set of final checks applied before producing the answer.
