A Noul judgment returns the probability that re- gion r satisfies a stated property, such as contain- ing relevant evidence. A Choice judgment returns a distribution over a finite set of options, such as source blocks or reading actions. A Score judgment returns a distribution over ordinal levels. The spec- ified objective and output type bound each source judgment. 3.2 System Two: Research Loop System Two turns an unresolved aspect of the task into a search query or evidence request. Retrieval supplies ranked candidates; an evidence request selects sources and asks System One to assess them against the requested objective. We summarize the action and its associated evidence processing, with evidence memory Et, as at = G(q, ht), (1) Ct = Candidates(at, D), (2) Zt = {J(ut, r) : r ∈Regions(Ct)}, (3) (Et+1, ot) = Gather(Et, Ct, Zt), (4) where Ct contains retrieval units selected for in- spection, ut is the evidence objective, and Zt con- tains their local judgments. Evidence requests spec- ify Ct and ut; after a search, discovery uses the original task and eligible top-K candidates, return- ing findings asynchronously. Gather merges se- lected original passages into response ot, which en- ters the research history and informs System Two’s next objective. QA and ranking use different objec- tives and gathering policies. Once an objective and its candidates are fixed, in- dependent source judgments can run concurrently. Decisions to inspect more candidates or read sur- rounding context depend on the findings already located; subsequent research actions depend on the returned evidence. Candidate Retrieval. For each query s from System Two, Hybrid BM25 combines document and maximum passage scores (Dai and Callan, 2019). For document d with scored passages P(d), we compute xD(d) = BM25(s, d) and xP (d) = maxρ∈P(d) BM25(s, ρ). We min-max normalize the two score lists separately and use their equal-weight fusion (Bruch et al., 2023): S(d | s) = 1 2 ˆxD(d) + 1 2 ˆxP (d). (5) This ranking supplies both readers and evidence discovery. 3.3 System One: Evidence Processing Evidence Localization. For QA, System Two supplies candidate sources and local evidence ques- tions about unresolved entities, relations, or facts. For each question u and source region r, a Noul judgment estimates the probability eu,r that the re- gion addresses u, while a Choice judgment gives a distribution πu,r(b) over its original text blocks b. For valid judgments and evidence threshold τloc, the located block set is L(u, r) = ( Select(πu,r), eu,r ≥τloc, ∅, otherwise, (6) where Select retains the most probable block and, when warranted by the distribution, a second block. The reader gathers and merges evidence passages around these blocks, preserving original text and source coordinates. Questions are assessed inde- pendently, so a passage can contribute one interme- diate fact to a larger chain of reasoning. Reading adapts to the findings so far. A Choice judgment selects among inspecting further candi- dates, reading surrounding context, and returning the current evidence. The reader returns when the requested questions are supported or further inspec- tion stops adding useful material. Its response may contain partial evidence, which System Two com- bines with accumulated findings to choose the next research action. Relevance Assessment. For ranking, the reader assesses source regions against the original topic q. Score judgments give distributions over four levels ℓ= 0, . . . , 3: unrelated, tangential, relevant, and highly relevant. Let Pd be the distribution with the highest expected level ¯ℓd = EPd[ℓ] across a document’s regions. The retention probability is pd = Pd(2) + Pd(3). Noul judgments select useful source pages, each a bounded text excerpt. For fully assessed candidates C, the set returned to System Two is R = {d ∈C : pd ≥θ} ∪I, (7) where θ is a permissive relevance cutoff and I con- tains incompletely assessed candidates.
