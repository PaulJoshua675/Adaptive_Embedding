We evaluate SimInter on ReDial using 300 users in the full pipeline and a matched subset of 100 users for comparisons against two baselines: STA- TISTICALONLY and CSHI. We ask four questions: do enriched users (T1) mention a more diverse set of items? (T2) express preferences correlated with population-level movie ratings? (T3) discuss movies along richer behavioral aspects? (T4) differ in surface linguistic variety? We additionally con- duct a targeted human evaluation (§4.6) and report a separate cross-CRS robustness experiment with two trained ReDial recommenders, KBRD (Chen et al., 2019) and UniCRS (Wang et al., 2022) (Appendix E). Our evaluation focuses on profile- conditioned simulated user behavior, rather than the recommendation accuracy of the underlying CRS models. 4.1 Experimental Setup FULL represents the complete SimInter pipeline, combining behavioral statistics, audited inter- views, and enriched user attributes. STATIS- TICALONLY uses only the behavioral statistics, without interview-based profile enrichment. We additionally compare against CSHI, an existing user-simulation baseline that follows a target- conditioned dialogue protocol. We run FULL on 300 ReDial users, generating four conversations per user (1,200 conversations). For matched comparisons, we select a subset of 100 users and evaluate STATISTICALONLY and CSHI on the same users, generating 400 conversations per baseline. All comparisons use the corresponding 100-user subset of FULL. We report descriptive metrics for the full 300- user cohort and conduct paired comparisons on the matched 100-user subset. For each compari- son, we compute user-level mean differences with bootstrap 95% confidence intervals (20,000 paired resamples), two-sided paired sign-flip tests (50,000 randomizations), and paired Cohen’s dz (Cohen, 2013). We apply Holm’s correction (Holm, 1979) across the original family of 24 paired metric tests, using a significance level of α = 0.05. T2 population-level correlations are reported descrip- tively. 4.2 Evaluation Tracks T1 — Item diversity. For each user, Shannon entropy of the movie-mention distribution across their four conversations. Higher entropy indicates broader coverage, reflecting whether the simulator escapes the “average user” attractor (Zhu et al., 2024a). We also report Jensen–Shannon divergence (JSD) against the movie-mention distribution of ReDial seekers. T2 — Popularity alignment. For movies the user rates or reacts to in conversation, we corre- late the simulator’s expressed preference with the movie’s mean MovieLens-25M rating (Harper and Konstan, 2015) (Pearson and Spearman). This tests whether stated preferences track population-level signal. T3 — Aspect richness.
