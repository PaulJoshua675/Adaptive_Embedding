The strict label applies to the candidate current action, not the enclosed text. All 352 strict-unsafe rows contain the marker, as do 321 of 868 safe rows. The marker alone has perfect recall but a 37.0% false-positive rate (F1 = .687). Adding the short action-prefix list yields the stronger fixed rule in Table 1. Separately, 40 of 51 exact tool names are label-pure and cover 776 rows. This explains the high grouped-CV lookup score, while its LODO collapse shows that the mapping is domain-specific. Appendix D reports lookup performance separately for tool names seen and unseen in the training domains. Because the marker carries risk-relevant provenance, its correlation is not obviously spurious. We ask whether literal tag spelling or tool identity becomes dispositive beyond the current action’s context. 4.3 AgentHarm: construction and unit weighting For AgentHarm-Traj, the released source subset determines all 731 strict labels: every harmful_steps row is strict-unsafe and every benign_steps row is strict-safe. This metadata is not necessarily shown to a guard, so it is a composition diagnostic rather than an input-visible shortcut. It nevertheless exposes a metric sensitivity. The 72 harmful interactions contribute 7.29 rows on average, versus 1.65 for 125 benign interactions. Released TS-Guard’s row-level F1 = .902 falls to .719 under equal-interaction weighting, while balanced accuracy changes from .754 to .776 (full table in the appendix). Thus the guard retains discrimination, but headline positive-class F1 answers a step-frequency-weighted question. Claims over tasks or interactions should report that unit alongside row-level performance. As a matched-context control, we group AgentHarm rows by case-folded parsed tool name and normalized arguments, retaining only groups containing both strict labels. The 16 mixed groups contain 69 rows from 39 interactions. Giving each execution group equal weight, released TS-Guard’s mean composite score is .922 in unsafe contexts and .413 in safe contexts (difference .510): the unsafe mean is higher in 11 groups and tied in five, with no reversal. All six cached hosted guards also have a positive macro difference. Thus rows with the same normalized execution signature can receive different scores across the benchmark’s label/context groups; tool identity alone is insufficient to explain guard behavior.
