B.2 Prompt Validation All prompt decisions were made on STaRK vali- dation queries with GPT-6-Luna in both harnesses, without using any test query, test trajectory or test label. A prompt-selection round compared rank- ing instructions and tool instructions. In its tool- instruction comparison on the same 450 queries (150 per dataset) for both prompts, the rg prompt re- duced the share of shell commands that run Python from 47% to 5% with Codex and from 51% to 1.5% with Pi, relative to the prompt with the same ranking instruction and our tool instruction. With Codex, the share of queries in which the agent ran any Python fell from 98% to 12%. Input tokens rose by about 110k per query with both harnesses. We then revised the ranking instruction once, which produced the final prompt. On 750 further valida- tion queries (300 from Amazon, 300 from MAG and 150 from Prime), we compared it with a base prompt whose ranking instruction allows up to 100 IDs and whose other text is the same.
