2026-10-15 Intern-Decision: Efficient Multimodal Decision Making with Autoregressive Masked Language Modeling Tong Zhu1 #, Zhe Xu1, Zefeng He1,2, Yunkai Chai1,2, Xuyang Hu1, Dehong Zheng1,3, Yun Luo1, Yafu Li1, Qi Zhang1,3 and Yu Cheng1,4 # 1Shanghai AI Lab, 2Shanghai Jiao Tong University, 3Fudan University, 4Nanyang Technological University # zhutong@pjlab.org.cn # chengyu@pjlab.org.cn Interactive agents repeatedly choose among a finite set of actions, labels, or ordinal outcomes. Generating a free-form response for each choice adds latency and complicates the interface between a model and its environment. We present Intern-Decision, a family of 0.8B, 2B, and 4B multimodal decision models that return structured choices and candidate probabilities from text and optional images. Our autoregressive masked language modeling objective places one decision placeholder per field in a complete assistant JSON skeleton. Ground-truth symbols appear only in supervision, while all fields are evaluated in a single causal forward pass using the backbone’s native language-model head. The 4B model achieves a 90.02% unweighted average accuracy across seven evaluation suites, compared with 88.74% for Jev v1.13.0. For a fixed 289-token request with three fields on one RTX 4090, mean latency is 44.16 ms for the 4B model and approximately 33–34 ms for the smaller models. On a separate 96-case known-distribution pilot, temperature scaling reduces expected multiclass Brier from 0.628 to 0.550 and expected calibration error from 0.213 to 0.089. A confidence-based handoff study on 111 public Jevbench-Hard items improves accuracy from 82/111 (73.87%) to 97/111 (87.39%) by routing 42 items to Atria-Dawn-Preview. We also describe qualitative game, visual interface, and browser demonstrations.
