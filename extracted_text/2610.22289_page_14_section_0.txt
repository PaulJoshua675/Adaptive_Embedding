7.1 Evaluation design We compare Baseline and Stop-and-report using GPT-5.5 at high and xhigh reasoning effort and GPT-5.6-sol at xhigh and max. Controlled_RESET and twma_v1.61 are additionally evaluated on ARC-AGI-3 at the same four configurations. Within each benchmark, the environment specification and configured execution conditions are held fixed across the compared agents. The Stop-and-report modification was developed through ARC-AGI-3 experimentation, while preserving the environment-agnostic implementation. AGI Maze performance was not used to select this instruction; its benefit on AGI Maze was identified in the analysis reported here. Following our earlier study [9], an evaluation block is one complete task collection evaluated with a specified agent, model, and reasoning effort. Each condition has three retained block repetitions. Individual tasks within a block use separate environment runs, with fresh workspaces and no conversation or task artifacts carried over between them. Persistence within an AGI Maze curriculum set is intentional. Repetition indices identify runs, not matched random seeds across agents. ARC-AGI-3. A block contains the 25 public games, with one independent playthrough per game. AGI Maze. A block contains all labyrinths with identifiers 0005 or 0009 in AGI Maze’s CLASSIC and EXTENDED collections [12], giving 106 targets. Each identifier contributes 53 labyrinths. The evaluation budget allowed two such batches with three repetitions each; we chose the two identifiers arbitrarily. In the single-labyrinth setting, each target is evaluated alone. In the curriculum setting, each independent run contains the seven tutorials TUTORIAL/S TAGE-01/0000.json through TUTORIAL/STAGE-07/0000.json, in that order, followed by one target. Only the target contributes to the score and completion count; resource use includes the tutorials. Each block is executed as separate 53-target 0005 and 0009 batches and paired by repetition index for analysis. Individual results for both batches are reported in Appendix C.2. Terminal-Bench. A block contains all 89 Terminal-Bench 2.1 tasks, with an independent task sandbox for each run. All 24 retained blocks contain the same task collection. 7.2 Performance measures and resource use For each setting, we report the mean block score and cost over the three repetitions. Appendix C provides the individual runs. Contrasts are descriptive differences between means; their direction alone does not establish statistical significance or non-inferiority. ARC-AGI-3. The block score is the mean benchmark-reported Relative Human Action Efficiency (RHAE) across all 25 games. RHAE combines level completion with action efficiency relative to the benchmark’s reference action counts [9, 11]. AGI Maze. We use RHAE70, an RHAE-inspired score with a reference action count equal to 70% of AGI Maze’s max_steps.
