A categorical head predicts lengths in {1, . . . , 256} independently across sites, conditional on the compact prompt. Only the length predictor is trained, using prompt-normalized cross-entropy on the reference token lengths under each backbone’s tokenizer; the original DLM remains frozen and jointly infills the allocated targets. Training protocol. Training draws from a 70/30 mixture of structured few-shot prompts (100,000 from MIT-Movie, ATIS, List Functions, and SALT) and Java editing episodes (22,128 from 28 repositories, split 21/4/3 by repository). We exclude evaluation source units, all 85 List Functions–Easy rules, SALT categories 5–6, the MIT-Movie Director field, and all 18 SWE- Refactor repositories. The Java predictor used in Section 5 is trained separately (Section C.2). For optimization, we use AdamW with weight decay 0.01, learning rates 3 × 10−5 for the copied block and normalization and 3 × 10−4 for the categorical head. We train for 1,563 steps with 64 draws per update, 5% warm-up, cosine decay, evaluating the final checkpoint. Length fidelity. For a target with reference length L⋆ j, we measure the predictor’s probability mass within r tokens of that length: Fr(ez, j) := X ℓ: |ℓ−L⋆ j |≤r πψ,j(ℓ| ez).
