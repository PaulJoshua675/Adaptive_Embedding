Vision Encoder. We use the vision encoder from the corresponding VLMs as the vision encoder to encode each of the temporal blocks into vision tokens. We also use the MLP layers or adaptor from the VLMs to convert the vision tokens into the text semantic space before we send them into the Aggregator. We denote the vision tokens from the temporal block at t as Vt. Aggregator. Visual tokens Vt in the temporal block at t are concatenated with the learnable queries Q and the corresponding text embedding Tt of the timestamp of the temporal block. These tokens are first projected to a hidden dimension of 512 and processed by a four-layer Transformer encoder aggregator with eight attention heads (64 dimensions per head), a feed-forward dimension of 2,048, pre-layer normalization, GELU activations. We learn one 512-dimensional query for each of the VLM decoder layers. The query is shared across target modules, and LoRA ranks in the same VLM decoder layer. State-Space Model. We learn a four-layer DeltaNet (Yang et al., 2024) with a hidden dimension of 512 as the state-space model. Each DeltaNet layer uses four value heads and two key heads, both with head dimension 128. Cosine-Similarity-Based Gating. We determine the gating threshold by profiling the cosine similarity score between two adjecent block from 1000 subset of video from the training data introduced in section 3.4. Across 64,426 transitions between consecutive temporal blocks, the median raw cosine distance, 1 −cos( ¯Vt, ¯Vt−1), is 0.0542. We therefore set β = 0.05, approximately the median-change operating point. The first temporal block is always retained, while each subsequent block is retained if cos( ¯Vt, ¯Vt−1) ≤β. Blocks exhibiting less visual change than this threshold receive zero weight in the residual-history aggregation, whereas the retained blocks are uniformly averaged. The Converter. For each target-module type and each LoRA rank, a separate linear output head maps the 512-dimensional representation Norm(ot) + αNorm(st) to a vector of dimension din + dout. The vector is split into one row of the LoRA factors At ∈Rr×din and Bt ∈Rr×dout. These output heads are shared across decoder layers, while layer specificity is supplied by the layer-specific learned queries. Finally, the LoRA at a particular slot s at timestamp t is calculated with ∆θt = α BT t At, where \alpha is lora_alpha, which we set to 16. LoRA Application Location. For VideoChat3-4B, we apply rank-8 generated LoRA for the MLP projections (gate_proj, up_proj, and down_proj) and self_attn.v_proj in every attention layer. For the Qwen3- VL-4B, we apply rank-8 generated LoRA for the MLP projections (gate_proj, up_proj, down_proj), and self_attn.v_proj in every attention layer. For Qwen3.5-9B, we apply rank-8 generated LoRA for the MLP projections (gate_proj, up_proj, and down_proj) in every attention layer, self_attn.v_proj in full- attention layers, and linear_attn.in_proj_qkv in linear-attention layers. For MOSS-VL-Realtime-11B, we apply rank-8 generated LoRA for the MLP projections (gate_proj, up_proj, and down_proj), and v_proj in every attention layer. We inject the generated LoRA weights into the target linear layers of the frozen base model through customized forward functions. Training Details. We build our training pipeline on top of the Llama-Factory (Zheng et al., 2024). We train MaLoW on the MaLoW-Instruct dataset introduced in Section 3.4 for 2,800 optimization steps with a total batch size of 64. Training uses four H200s, a per-device batch size of one, and 16 gradient-accumulation steps. We use AdamW with β1 = 0.9, β2 = 0.999, ϵ = 10−8, an peak learning rate of 8 × 10−5, a cosine learning-rate schedule, and a warm-up ratio of 0.1. Training is performed in bfloat16. We set the LoRA regularization factor γ to 0.01. During training, we use the state-space model in its parallel causal form. For each sample, the compact vision representations qt are arranged in chronological order and processed by the four-layer DeltaNet using the chunk-parallel gated-delta-rule kernel and an attention mask for padded blocks. We then select the output at the last valid temporal block for each history observation. This parallel computation is causally equivalent to processing the blocks recurrently while carrying the convolutional and recurrent DeltaNet states, which is the form that is used for online streaming inference.
