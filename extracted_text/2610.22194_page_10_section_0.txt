Bands give the standard deviation over evaluation repeats. 5.4. Generalization to code domain Setup. To assess whether AutoSFT remains effective beyond instruction following, we evaluate it on code generation with MBPP+2. Unlike IFEval and IFBench, MBPP+ grades only by test execution and carries no capability breakdown, so the system builds its own capability structure from only the benchmark and the pool. The backbone is Qwen3-1.7B-Base with MBPP+ target score 70, and the pool holds 742,842 Python instruction–code pairs from OPC-SFT-Stage2 [Huang et al., 2025], KodCode-v1-SFT-R1 [Xu et al., 2025], and Magicoder-OSS-Instruct-75K [Wei et al., 2024]. Each round retrains from the backbone for three epochs at sequence length 8,192 under a 100M-token budget and is evaluated using avg@3. We compare these three configurations: Base, Base + Analysis, and Base + Analysis + Synthesis. Result. Within 64 hours, Base and Base + Analysis each complete 15 rounds and Base + Analysis + Synthesis completes 6 (Figure 9, right panel). The single agent shows no sustained improvement, while Base + Analysis produces a consistent upward trend and reaches 64.8% at round 13. Adding synthesis incurs additional runtime per round but reaches 65.8% by round 6. The structure that helped in instruction following transfers to code: multi-agent analysis lifts the recipe above the single agent, and synthesis reaches a comparable peak in fewer rounds.
