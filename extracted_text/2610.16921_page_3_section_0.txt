Problem Formulation Given a labeled EEG dataset D = {(X, y)}, where y ∈L denotes the class label and X = [x1, · · · , xT ] ∈RC×T represents a trial of length T ∈N+ acquired from C ∈N+ electrodes, with xt ∈RC denoting the signal sample recorded at time step t ∈[1, T]. Online decoding methods employ slid- ing windows for continuous trials, with window length L and stride ∆. The n-th window is denoted as Xn = Xn∆:(n∆+L) ∈ RC×L, where n = 0, 1, · · · , ⌊T −L ∆⌋. We want to learn an optimal policy π∗that can be utilised during the processing of the window sequence {Xn}. At each time step, this policy dynamically decides whether the current window should be discarded or retained. And if retained, the policy must decide whether the window should be marked as the Onset, Sustain, or Offset phase of the MI event. The objective is to retain and mark an sequence of most informative windows such that the final classification accuracy based on this sequence is maximized. We formulate this problem as a Markov Decision Process (MDP) defined by the tuple (S, A, T , R, γ). State set S: At each time step n, the environment state is defined as sn = (Xn, Hn, ρn), where Xn is the cur- rent window, Hn = {Xn−k, . . . , Xn−1} denotes fixed-length historical windows (with k being the history length), and ρn = n∆ T −L ∈[0, 1] is a normalized indicator of trial progress. In the implementation, Xn and Hn are further encoded into feature vectors by neural networks, but conceptually the MDP state is characterized by (Xn, Hn, ρn) throughout this paper. Action set A: The agent executes one of the four discrete actions an ∈{0, 1, 2, 3}. Specifically, action an = 0 indicates that the current window is considered to be highly noisy and is discarded. Action an = 1 denotes that the current window is retained and marked as the Onset phase of the MI event. Action an = 2 denotes the current window is retained and marked as the Sustain phase. Action an = 3 denotes the current window is retained and marked as the Offset phase. When an = 3 is taken, or when the sliding window reaches the end of the trial, the agent terminates the current trial and triggers the final classification based on the sequence of the retained windows. State transition function T : After the agent selects an, the environment either advances the window to Xn+1 and updates (Hn+1, ρn+1), or terminates the trial. To incorpo- rate the prior knowledge that an MI event follows an On- set→Sustain→Offset temporal structure, we introduce a dis- crete phase indicator ϕn ∈{Planning, Execution, Recovery}. Importantly, ϕn is an internal phase of sensorimotor cortex rather than an additional MDP state. It is only used to constrain the legal actions given the current phase via a finite-state machine (FSM). • Planning phase. At the beginning of each trial, the agent is in the Planning phase. It has been demonstrated that subtle rhythmic changes often precede the actual onset of MI performing, representing a preparation or planning phase [22]. In this phase, the agent searches for the onset of the event, and the legal actions are APlanning = {0 (discard), 1 (Onset)}. Choosing an = 1 marks the current window as Onset and switches the phase to Execution. • Execution phase. After the first Onset has been detected, the agent enters the Execution phase, which covers the duration of the active MI. During this phase, the sen- sorimotor cortex typically exhibits a significant power reduction in the µ (8–13 Hz) and β (13–30 Hz) rhythms, a phenomenon known as ERD [22]. This reduction persists as long as the subject actively performs the imagery task. Accordingly, the legal actions are AExecution = {0, 1, 2 (Sustain)}. The agent may refine the onset boundary (action 1) or, upon confirming stable ERD patterns, select an = 2 to capture the sustained activity. Selecting an = 2 triggers the transition to the Recovery phase. • Recovery phase. After a sustained segment is established, the agent enters the Recovery phase.
