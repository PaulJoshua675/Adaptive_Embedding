3.1 Overview We propose BitSparse, an activation compression method for ReLU-like activations (e.g. ReLU2) that adopts the notation and storage conventions of Section 2.2. BitSparse stores only the nonzero values, together with small index buffers for reconstruction, so the activation cache shrinks while the feed-forward projection is still computed densely. Activations are compressed before caching and reconstructed during the backward pass, preserving values in the selected storage format. 3.2 Tile-wise sparse activation format BitSparse is a tile-based sparse representation for moderately sparse tensors. It partitions H into a regular grid of B ×B tiles, with B = 64 by default, so the grid has GM = M B  , GN = N B  (4) rows and columns. Tiles are ordered row-major, with tile (u, v) identified by t = uGN + v, giving T = GMGN tiles. Boundary tiles are logically padded with zeros so every tile has B2 = 4096 entries. The representation of H consists of three arrays: a bitmask m with one bit per activation position (including padding), a compact value array v holding only positive values, and a 32-bit prefix array p.
