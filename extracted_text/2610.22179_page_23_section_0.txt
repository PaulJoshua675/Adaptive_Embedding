(27) For a symmetric continuous distribution rounded to BF16, the sign bit is uniform and independent of the magnitude. When the fraction bits also have high conditional entropy, H(R | E) is close to eight bits and the additional saving is small. For example, for the Gaussian distribution X ∼N(0, 1) rounded to BF16, the conditional entropy is H(R | E) ≈7.9195 bits. Coding the full value therefore saves only ∆b ≈0.0805 bits per value beyond exponent-only coding. The sign–fraction byte can have lower entropy in some cases. One example is nonnegative distributions whose sign bit is always zero. This is the case for certain activation functions such as ReLU and sigmoid. Another case is if the mean of the distribution is large and all values cluster around a single exponent, e.g. N(12, 1) where values are mostly distributed between 23 and 24 so there is no pooling of mantissa values (and exponents have very low entropy). LCT does not take advantage of a low-entropy sign–fraction byte if this is the case.
