Hierarchical browser assistance We study browser use as hierarchical, closed-loop decision making rather than end-to-end free-form generation. Given a natural-language goal, a larger planner maintains cross-page context and proposes a stage-level subgoal. At each iteration, the current page evidence and a finite candidate set (e.g., click, scroll, return, or stop) are presented to Intern-Decision; the selected action is executed, and the page is observed again. The user task contains neither element identifiers nor a scripted click sequence, so local actions are chosen from the live interface. 12
