The same training setup is reused by the post-training objectives in Section 7, with task-specific reductions applied over the shared behavioral trajectory and event structure. 4.3 Dense–Sparse Hybrid Optimization TransX contains two distinct parameter regimes: densely updated network parameters and large row-sparse ID embedding tables. We optimize dense parameters with AdamW (Loshchilov and Hutter, 2019) and sparse embeddings with row-wise Adagrad (Duchi et al., 2011; FBGEMM Contributors, 2026). For an embedding table with 𝑛rows, row-wise Adagrad maintains one second-moment accumulator per row rather than one per coordinate, reducing optimizer state from 𝑂(𝑛𝑑) to 𝑂(𝑛) while preserving the within-row gradient direction. Because behavioral trajectories, event memories, and candidate branches are shared within one logical training step, all gradient contributions to the same dense parameter or embedding row are aggregated before the corresponding nonlinear optimizer update. This includes contributions from overlapping behavioral prefixes, candidate fanout, and gradient accumulation. The resulting optimizer semantics are therefore defined at the logical-step boundary and remain unchanged by the physical partitioning introduced in Section 5.2. Detailed row-wise update equations and distributed ownership mechanics are deferred to Appendix A.1. 5 Model–Infrastructure Co-Design The compute-state decomposition is useful only if its reuse structure is preserved in execution. TransX therefore maps the same hierarchy onto training and serving. In particular, training executes trajectory −→memory −→candidate fanout, without replicating shared computation, while serving maintains mutable encoder continuation state →immutable behavior memory KV →request-local computation. These components operate on different clocks and under different objectives: continuation state advances as new behavior arrives, published behavior memory changes only when refreshed state is committed, and candidate-conditioned computation is triggered by each request. The infrastructure therefore schedules, places, and scales these components independently while preserving the causal information boundary and prediction semantics of the model. 16
