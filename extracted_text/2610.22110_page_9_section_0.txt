Retain only candidates whose reconstructed stem or diag- nostic realization aligns to an ordered substring of the normalized token. 2. Possessive guard. Require overt initial no-, mo-, to-, or i- for a possessive analysis. This blocks bare nouns and coincidental stem-initial strings from receiving NP.POSS. 3. Category preference. Prefer the open-class analysis covering most surface material, except when a listed adverb matches the entire token. Preserve genuine ties for sentence-level resolution. In compact pseudo-code, the decision is: for token in sentence: candidates = fst.lookup(strip_punct(token.lower())) candidates = keep_surface_aligned(candidates, token) candidates = guard_possession(candidates, token) analysis = prefer_category(candidates, token) emit(igt(analysis), functional_labels(analysis)) Uncertain tokens remain unlabeled, while the original sentence always reaches the encoder. Illustrative Pipeline Output. To illustrate the output of this filter, consider the input sentence: axan nehwatl nitekitis ika notepostsontekosentlalil (“now I will work with my computer”) The FST analyzer and filter process each token as follows: – Token analysis: • axan →adv (temporal particle) • nehwatl →subj:1sg (emphatic subject pronoun) • nitekitis →ni-tekiti-s →subj:1sg + verb:intr + fut • ika →rel.noun (relational marker, “with”) • notepostsontekosentlalil →no-tepostsontekosentlalil →np.poss + noun (“my computer”) – Extracted functional tags: adv, subj:1sg, head, np.poss – Final encoder input string: nah->es: [SYN: ADV SUBJ:1SG HEAD NP.POSS] axan nehwatl nitekitis ika notepostsontekosentlalil This complete prefix string provides the neural encoder with high-level struc- tural guidance while preserving the exact surface subwords for translation. 4.5 IGT and Functional Syntax Projection Selected analyses are mapped to Interlinear Glossed Text (IGT) following the Leipzig Glossing Rules [5] and reflected in a small functional syntax inventory HEAD, SUBJ, OBJ, NP.POSS, ADV, CONJ, DET, REL, COP, NEG, or OPT.
