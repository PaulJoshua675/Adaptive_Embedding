D Accounting, Reproducibility, and Artifact Scope The previous four-query Top 20 pilot is superseded as the primary retrieval evaluation by the present fixed-Top-5 comparison. Its variable-length baseline lists and asymmetric overlap denominators are not pooled with the new results. Historical attempts and the original manuscript remain preserved separately. The repository contains original browser response TXT files, selected Idea2Prior Top 5 outputs, Expert JSON, and prompt hashes for all three tiers. Timing uses the selected runs, including failed requests within them but excluding replaced whole-query attempts. Browser timings are operator-reported. Unknown usage remains null in source records. Gold data and supplied answer files are public for evaluation but must not be included in a new retrieval session. Consequently, this is a released benchmark, not a hidden test set. The revision performs no new model-based retrieval, paid API benchmark, or model-judge experiment. Numerical aggregation and document checks are local. Interface validation establishes software behavior, whereas the scientific conclusions derive from the stated historical cohorts. Public native-Gemini presets, new extension model trials, full MinerU processing, and a new full-report benchmark remain outside this evaluation. For a stronger follow-up study, freeze per-item prompts, source/configuration hashes, provider aliases, request budgets, and stop rules; isolate every browser session; report all attempts and final selections; record complete usage and tool charges; and adjudicate returned- paper relevance with independent raters.
