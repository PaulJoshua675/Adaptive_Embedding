Our central finding is not simply that current VLMs are inaccurate. Rather, their errors are culturally structured: many models overuse Thuluth as a default, fail to recover Diwani, and respond unevenly to prompts that should make the visual distinctions clearer. 2 Dataset and Task Dataset. We use a cleaned 1,195-image six-style dataset. DuwatBench [Patle et al., 2026] is sup- plemented with RuFa images for Ruq’ah/Nasta’liq [Mhmoodlan, 2026] and HICMA images for Kufic/Naskh [HICMA Project, 2026], reducing the original Thuluth-heavy imbalance. Curation uses source aggregation, single-label filtering, class-balance supplementation, file-integrity checks, duplicate removal, and manifest locking. After removing one undersized image and four exact du- plicates, the final counts are Kufic 106, Naskh 218, Thuluth 216, Diwani 217, Ruq’ah 225, and Nasta’liq 213; the majority baseline falls from 56.4% to 18.8%. Thuluth and Diwani are both en- tirely DuwatBench, so their central confusion is not cross-source domain shift; other labels use mixed sources, disclosed in the appendix. Task. The task is closed-set six-way style classification: given one image, select one script style. We evaluate style recognition only, not OCR, transcription, semantic interpretation, religious- content judgment, or localization. All metrics use the same 1,195-image manifest for every model– prompt run. 3 Experimental Setup Prompt conditions. We use three prompts. Numeric lists numbered styles and requires one digit. Visual-cue adds short style descriptions. Diwani-first keeps the visual-cue framing but moves Diwani first and asks for the script name, testing whether foregrounding an under-recognized style rescues Diwani errors. We introduced this condition after early runs showed Diwani was often missed or absorbed into Thuluth; it is a diagnostic prompt, not a preferred deployment prompt. Models. We evaluate four closed/API models [OpenAI, 2026]: GPT-4o, GPT-4.1, GPT-5.5, and GPT-5.6 Terra. The open-weight set includes Qwen2.5-VL-7B/32B [Bai et al., 2025b], Qwen3-VL- 8B/32B [Bai et al., 2025a], InternVL3.5-8B/38B [Wang et al., 2025], MiniCPM-V 4.5 [Yu et al., 2025], and Gemma 4 12B-IT [Gemma Team, 2026]. Open-weight runs use greedy decoding with seed 42; closed/API runs use the most deterministic supported settings. Metrics. We report accuracy, balanced accuracy, macro-F1, per-style precision/recall/F1, and pre- diction ratio: predicted count divided by true count. The main diagnostics are Thuluth prediction ratio and Diwani recall, because early runs absorbed ornate or uncertain examples into Thuluth while missing Diwani. Paired prompt comparisons use exact McNemar tests on same-image correctness vectors; visual-cue changes with p ≥0.05 are marked not significant. 4 Results Table 1 summarizes the numeric-prompt comparison. The best closed/API numeric-prompt accuracy is 60.9% (GPT-5.5), while the best open-weight numeric-prompt accuracy is 47.2% (Gemma 4 12B-IT).
