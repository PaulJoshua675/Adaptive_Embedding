2.1. Class-level semantic adaptation Semantic adaptation adjusts a vision–language model’s class representations to a target task. CoOp and CoCoOp learn contextual prompts, while KgCoOp and ProGrad constrain prompt updates to preserve pretrained knowledge [2, 12–14]. MaPLe couples visual and textual prompts; PLOT and CAPEL use multiple prompts or class representa- tions to capture variation within a category [15–17]. TaskRes learns residual updates to class prototypes, while CLAP adapts prototypes with a text-anchoring penalty [3, 4]. These methods improve the class representations through optimization. LAMP keeps the class text vectors fixed and uses visual similarities to correct their prediction errors on the support set. Its trainable extension, LAMP-F, combines CLAP’s text anchoring with global and regional residual predictors. Cached responses account for the effects of prototype updates on both the initial query scores and the support residuals, allowing prototype adaptation to work with the selected visual predictors. 2.2. Instance-level global adaptation Instance-level adaptation draws on visual information from labeled support images. CLIP-Adapter learns transformations of global embeddings, and CLIP-LoRA updates internal attention weights through low-rank parameters [18, 19]. Both adapt visual representations through gradient optimization. Training-free methods instead adjust how frozen features are used for prediction: Tip-Adapter retrieves support labels, APE refines feature channels and affinities, and GDA estimates class statistics [5, 20, 21]. IDEA combines image similarities with similarities between image captions, and T- IDEA further learns alignment and bias correction [22].
