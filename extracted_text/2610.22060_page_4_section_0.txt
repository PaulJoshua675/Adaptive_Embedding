Prior work follows a similar global-to-local strategy, using learned holistic tokens (Zheng et al., 2025a), coarse-to-fine token sequences (Bachmann et al., 2025), or separately generated semantic codes (Lavoie et al., 2025). In our case, the global token directly discretizes the pretrained encoder’s global representation. Specifically, we use separate quantizers, Qglobal and Qpatch, for global and patch features, respectively. The fea- ture decoder Dfeat takes both global and patch tokens and reconstructs the combined target y = (yglobal, y1:N) using the feature loss Lfeat. This yields a discrete global token zglobal, which we model jointly with the patch tokens using the following factorization: pϕ(zglobal, z1:N | c) = pϕ(zglobal | c) N Y i=1 pϕ(zi | zglobal, z<i, c). (1) where c denotes the class label or text prompt. During inference, the generator first samples the global token and then samples patch tokens conditioned on both global and external conditions. Combined training objective. We train the tokenizer and pixel decoder jointly using the feature and pixel losses described above. Following prior work on semantic preservation during tokenizer training (Chen et al., 2026a; Du et al., 2026), we also include an ℓ2 regularizer Lreg between the last-layer features h and ˆh of the trainable and frozen encoders. The weights λreg and λpix balance the loss terms, and sg stops gradients at the pixel decoder input. Once the tokenizer is trained, we keep it fixed and train an autoregressive generator on its tokens using teacher forcing. We combine the cross-entropy loss for the global token with the average loss over patch tokens, weighted by λglobal and λpatch, respectively.
