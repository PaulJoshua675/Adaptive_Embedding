Intern-Decision: Efficient Multimodal Decision Model Autoregressive and Masked Prediction. Autoregressive language models such as GPT-3 [5] predict tokens conditioned on a causal prefix, whereas BERT [8] reconstructs masked tokens using bidirectional context. Hybrid approaches explore combinations of these paradigms: UniLMv2 [3] combines autoencoding and partially autoregressive objectives through pseudo masking, while GLM [9] combines bidirectional encod- ing of the corrupted input with autoregressive reconstruction of masked spans. Mask-Predict [12] predicts masked target tokens in parallel and iteratively refines uncertain predictions. For classification, PET [24] uses pattern–verbalizer pairs for cloze-based prediction and distills the resulting models into a sequence classifier, while LM-BFF [11] performs prompt-based fine-tuning with label words and demonstrations, reusing the pretrained masked-language-model head. Intern-Decision formulates structured decisions as autoregressive masked language modeling, combining answer placeholders with next-token-aligned prediction in a causal multimodal model. Its native language-model head scores candidates for all requested fields in a single forward pass, without iterative refinement or answer feedback. Calibration and selective computation. Temperature scaling fits a positive scalar to adjust predictive confidence while preserving the most likely label [13]. Brier scoring evaluates the full predictive distribution [4], complementing accuracy and binned calibration error. Confidence-based routing and cascading use uncertainty to allocate requests between models with different costs [6, 7]. Our evaluation separates hard-label calibration from an exact-distribution pilot and reports one escalation operating point rather than an optimized routing policy. 3. Input construction and causal readout The released compiler places the state and ordered decision schema in the user turn, then appends an assistant JSON skeleton with one reserved <decision> token per field.
