Existing approaches for test-time compute scaling in vision-language models comprise chain- of-thought traces, latent reasoning tokens, searching over candidate answers, and test-time reinforcement learning (Zhang et al., 2024b; Qin et al., 2025; Xu et al., 2025; Singh et al., 2025; Wan et al., 2026). These methods usually come with higher inference costs as each generated token requires a full forward pass and expands the context window. To address this limitation, depth recurrence (Geiping et al., 2025; McLeish et al., 2025) has been explored as an alternative for test-time scaling in language models. Depth recurrence allocates test-time compute to iterating a block of layers rather than generating tokens, thereby maintaining smaller context sizes and a smaller memory overhead independent of reasoning length. But depth recurrence has also gained traction in visual understanding. Here, recurrent VLM archi- tectures are built in two ways: first, either by starting from a recurrent language model and post-hoc adding a vision backbone, or, second, by looping an existing VLM without removing any of its layers. The first approach is i.a. adopted by HIVE (Zhang et al., 2026), which extends a recurrent language model pretrained from scratch by a vision backbone.
