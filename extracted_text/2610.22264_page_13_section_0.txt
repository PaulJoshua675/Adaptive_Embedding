The rewrite and its boundaries are generated in one completion, with | appearing only between adjacent nonempty spans. The separator is not a generation stop token. Tokenizer character offsets align each extracted span with its rollout tokens, keeping the partition consistent with the policy loss. A valid partition requires a valid answer wrapper, nonempty spans, and full coverage of valid answer content tokens with consistent offsets and token counts. SCOPE uses uniform GRPO token weights for malformed wrappers, empty or missing spans, and consecutive or trailing separators. Truncation, incomplete coverage, alignment failures, and token count mismatches also trigger this fallback. We handle one benign end of sequence (EOS) mismatch separately. If the completion mask has exactly one extra trailing placeholder relative to the tokenized prompt text, we retain the aligned prefix. The extra token receives zero weight.
