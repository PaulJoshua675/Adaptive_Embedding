The perturbation code reconstructs both the control and shuffled rank- ings through one dedicated inference path. We therefore report paired changes within that path rather than comparing its absolute scores with the separately archived main run in Table 1. Is the overlap depth important? Table 6 varies the overlap depth used to compute the Jaccard features. The results are stable from τ = 50 to τ = 1000, and τ = 500 is not a fragile choice. This also indicates that the overlap signal captures a broad property of view agreement rather than a narrow artifact of one cutoff. Why use a small MLP scorer? Table 7 compares learned fusion models us- ing the same matched view runs. Linear scores uses only the three normalized BM25 scores. Linear scores+overlap adds the three query-level overlap constants. These additive constants cannot directly change document order within a query; any difference from Linear scores arises because retraining changes the learned coefficients on the score features. Linear overlap weights instead adds explicit products between scores and overlaps, which provides a direct linear interac- tion but proves unstable in this experiment.
