Agentic MLE Post-Training 4.1. Hierarchical Agentic SFT Long-horizon MLE optimization requires general tool-use, coding skills, and domain-specific decision making. We therefore use two-stage hierarchical agentic SFT. In the first stage, coding and tool-use trajectories from diverse agentic tasks are used to learn basic tool-use and code revision capabilities. The second stage adopts teacher trajectories from MLE domain and literature-derived scientific tasks to improve algorithm design, experimental analysis, and iterative optimization. Complementary MLE demonstrations. MLE adaptation data cover both task initialization and sustained optimization. For trajectories whose first complete solution executes successfully and reaches a quality threshold, we extract the interaction prefix from task start through the corresponding execution feedback as an initial-solution trajectory, typically covering task understanding, algorithm design, and code generation. We also use long-horizon optimization trajectories from complete interactions, covering solution construction, feedback analysis, iterative revision, and final submission selection. In addition, analysis sub-agent trajectories are adopted to train the model for independent data analysis and result diagnosis. Outcome-guided supervision selection. Long-horizon MLE trajectories can contain effective ex- ploration and failure recovery, but may also include misguided decisions or continued degradation after reaching a strong solution. Therefore, we use execution results of submitted solutions to select high-quality trajectories and the segments used for supervision. For trajectories that pass a quality threshold, we identify the first best-performing submission and measure the subsequent performance degradation. When the post-peak degradation exceeds a threshold, we use the first best-performing submission as the anchor for retaining a trajectory prefix; otherwise, we use the last submission. The prefix ends at a complete tool-interaction boundary near the anchor. This removes degraded tails while preserving useful exploration and failure recovery before the peak. Supervision samples and training objective. To preserve multi-turn context dependencies, each supervision sample combines existing interaction context with a continuous sequence of subsequent model actions and environment feedback from the selected MLE interactions. When context com- paction occurs, the retained history and summary form the conditioning context for subsequent samples. Training loss is applied only to newly generated reasoning, text responses, and tool-call tokens, while tool feedback and inherited interaction history are used only as conditioning context and masked out from the loss. Details of outcome-guided filtering, score normalization, and the SFT objective appear in Appendix C.1. 4.2. Windowed Interaction Reinforcement Learning Building on SFT, we further optimize the long-horizon decision policy using execution feedback from the model’s own exploration. In MLE, solution quality is available only after training and evaluation, and each result depends on multiple rounds of analysis, code revision, and tool interaction. We introduce Windowed Interaction RL (WIRL), which groups consecutive model decisions made between successive experiment results into an execution window 𝑢𝑚. Each window is conditioned on the accumulated interaction history and associated with the outcome of the corresponding experiment launched through the execute_code tool (Sec. 3.2). The first window starts from the initial task state. This allows policy updates to use feedback from completed experiments without waiting for the entire task trajectory to finish. 5
