F.2 AGGREGATION RULES For a model m, let Sm be the number of responses in which m is selected. A two-element response contributes one support to each selected model, while a Tie contributes no support. We report the normalized support rate Rm = Sm P m′∈M Sm′ , M = {Ours, OmniNFT, LTX-2}. (21) For the pairwise comparison between Ours and a baseline b, a response counts as an Ours win when Ours is selected and b is not selected. It counts as a baseline win when b is selected and Ours is not selected. Responses selecting both systems or Tie are excluded from that pairwise denominator. The pairwise win rate is therefore POurs>b = WOurs>b WOurs>b + Wb>Ours . (22) The mean pairwise Jaccard agreement is 42.3% for audio-video consistency and 44.3% for overall quality. This medium overlap is acceptable for a comparison task with substantial subjectivity and allowed near-ties. Because the task is subjective, we additionally construct a fully consistent subset in which all three annotators select the same set for the same prompt and question, and report its model support rates below. F.3 BENCHMARK-WISE RESULTS Table 19 reports support rates and the pairwise win rates of Ours against each baseline. The results use all 300 completed judgments.
