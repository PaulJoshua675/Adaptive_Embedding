5.1 Experimental Setting We implement our algorithm in Python, using Gurobi as the ILP solver [17], and conduct all experiments on a machine equipped with an Intel Xeon Gold 5220 CPU @ 2.20 GHz. The number of available masks is set to 𝐾= 3 for the 7 nm node and 𝐾= 4 for the 5 nm node. The minimum edge-to-edge template spacing is 𝑑min = 50 nm. The feasible templates include 1-hole and 2-hole 1-D straight templates. The weights in the ILP objective are set to 𝑤𝑐= 1 and 𝑤𝑡= 0.01, following [6]. The GNN model comprises 2 interleaved half-convolutions [14] with all embeddings projected to dimension 64, followed by a 2- layer MLP with sigmoid activation. It is trained on a single NVIDIA A100 GPU using the Adam optimizer with a learning rate of 1×10−3 for 200 epochs, completing in approximately 46 s. Details of the training and test sets are provided in Section 5.2. 5.2 Benchmark Details Training Set. Following [15], we generate 20 synthetic layouts at the 7 nm node using design rules extracted from the open-source ASAP7 process design kit (PDK). Each layout contains approxi- mately 3,000 vias, yielding a training set of roughly 60,000 vias in total. Label generation follows the procedure in Section 4.2, taking approximately 1 hour. Test Set. To evaluate the generalizability of our method across different designs within the same technology node as well as across different technology nodes, we construct a diverse test set as fol- lows. • 7 nm Node (Synthetic): 12 synthetic layouts generated following [15] using design rules from the ASAP7 PDK. • 7 nm Node (Open-source Processor Design): 12 layouts extracted from a RISC-V BOOM core design [18] generated by Chipyard [19] using the ASAP7 PDK, reflecting realistic design patterns from an open-source processor. • 5 nm Node (Industrial): 11 clips from industrial logic SoC designs to evaluate cross-node generalization. The full test datasets and layout generation scripts are available at https://github.com/fengyu-neu/DSA-MP-Benchmark. 5.3 Result Analysis We evaluate our method against state-of-the-art decomposition ap- proaches on two configurations: DSA with triple patterning lithog- raphy (DSA-TPL) at the 7 nm node, and DSA with quadruple pat- terning lithography (DSA-QPL) at the 5 nm node.
