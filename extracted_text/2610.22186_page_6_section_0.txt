To address this issue, we represent a caption as a sequence of modality-grounded events: E = (e1,e2,...,eK), ek = (mk,τk,ck,dk), mk ∈{vis,aud}, (1) where mk denotes the modality, τk denotes the event type, ck denotes the character, and dk denotes the event content. Based on this event-centric representation, we further define the reference structures to support the event- centric reward calculation. For a reference caption y⋆, we denote its reference event set as E⋆= E⋆ aud ∪E⋆ vis, where E⋆ m = {em i }Nm i=1 is the set of modality-specific reference events for m ∈{aud,vis}. This event set is used to evaluate event coverage and character attribution. In addition, we denote by Q⋆= {q⋆ i }M i=1 the set of audio-to-visual synchronization queries, where each query consists of an audio event, a set of candidate visual events, and the reference synchronized visual indices. This query set is used to evaluate cross-modal temporal synchronization. Based on the above event formulation and definitions, we devise three event-centric reward components to achieve fine-grained alignment (as shown in Fig. 4): Global Event Completeness. Global event completeness measures whether the generated caption covers the reference audio and visual events that should be described in the video. Given a reference event set E⋆= E⋆ aud ∪E⋆ vis, where E⋆ m = {em i }Nm i=1 denotes the modality-specific events for m ∈{aud,vis}, we define an LLM-evaluated coverage indicator: Im cov(em i ,y) = ( 1, if Covers(y,em i ), 0, otherwise, m ∈{aud,vis}. (2) Here, Covers(y,em i ) indicates that the event content of em i is semantically supported by the generated caption y. The global event completeness reward is defined as event recall over all reference audio and visual events: Rcomp(y,E⋆) = P m∈{aud,vis} PNm i=1 Im cov(em i ,y) P m∈{aud,vis} Nm . (3) Intra-Event Attribution. Event completeness alone does not guarantee that a caption assigns events to the correct entities. For example, a caption may mention the correct speech content but attribute it to the wrong speaker. To address this issue, we introduce an intra-event attribution reward that evaluates whether each character-bearing reference event is both covered and associated with the correct character. Given the reference event set E⋆= E⋆ aud ∪E⋆ vis, where E⋆ m = {em i }Nm i=1 denotes the modality-specific events for m ∈{aud,vis}, we define an LLM-evaluated attribution indicator for each valid event with an explicit character: Im attr(em i ,y,y⋆) = ( 1, if Matches(y,y⋆,em i ), 0, otherwise, m ∈{aud,vis}. (4) Here, Matches(y,y⋆,em i ) indicates that the generated caption y and the reference caption y⋆attribute the event content dm i to the same underlying character. The attribution reward is computed as Rattr(y,y⋆,E⋆) = P m∈{aud,vis} PNm i=1 δm i,charIm cov(em i ,y)Im attr(em i ,y,y⋆) P m∈{aud,vis} PNm i=1 δm i,char , (5) where δm i,char = I[cm i̸ = ∅] indicates whether the event has an explicit character. Character-free events are not counted in this reward. Inter-Event Synchronization.
