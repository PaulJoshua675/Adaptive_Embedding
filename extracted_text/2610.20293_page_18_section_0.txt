H HISTORICAL SERVED-VALUE OBSERVATIONAL AUDIT This audit addresses a different question from the counterfactual fidelity analysis above. Historical downstream value V0 is observed on served traffic, whereas the evaluated checkpoint generates its own action set. Consequently, the audit does not provide arbitrary counterfactual values V0(S) and is not used as action-level ground truth. Real-context replay. For 4,486 target queries, the SFT checkpoint generates eight rollouts and a deterministic request-level hash selects one fixed action set. The full set is replayed using that request’s original user and geographic context. Successful replay and matched historical V0 are both available for 3,540 requests. Because zero-auction outcomes are a normal structural outcome of the replay path, we report value ranking on the 1,438 auction-positive requests and analyze auction activation separately.
