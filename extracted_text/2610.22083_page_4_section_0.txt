Topological Analysis The structural utility of these schemes is best understood through their distinct topological properties, as defined in digital logic theory (Mano and Ciletti, 2012). Thermometer encoding enforces linear boundary conditions on the se- mantic space, wherein the minimum and maximum values are maintained at maximal Hamming distance. Conversely, Johnson encoding imposes a periodic topology; by forming a ‘twisted ring’, the encoding identifies the semantic extremes 0 and 𝑁−1 as adjacent, regardless of the code width 𝑊. This cyclic property makes Johnson encoding a natural candidate for quantities with circular continuity, such as orientation, phase or time of day, whereas Thermometer encoding suits bounded magnitudes. These schemes must, however, be distinguished by which property they preserve. All three guarantee local smooth- ness: values adjacent under the metric each is designed for differ in a single bit, eliminating the cliff of Section 2.2. Only Thermometer and Johnson additionally preserve global structure, each exactly under its own metric: 𝐻(𝑐𝑖, 𝑐𝑗) = 𝑑lin(𝑖, 𝑗) for Thermometer and 𝐻(𝑐𝑖, 𝑐𝑗) = 𝑑cyc(𝑖, 𝑗) for Johnson. Gray encoding offers no such guarantee. Its re- flected construction places every value 𝑖a single bit from 2𝑊−1−𝑖, however far apart the two are, so that the extremes 0 and 2𝑊−1 differ in one bit; Hamming distance therefore carries little information about semantic separation beyond immediate neighbours. Removing the Hamming cliff is therefore necessary but not sufficient for the clustering behaviour sought here, and Section 4.1 quantifies the gap between the two properties. These three codes are not, however, exclusive alternatives: the reflected construction of Section 3.5 interpolates be- tween them and contains all three as limiting cases. 2.5. Relation to Other Low-Latency Representations Spatial binary codes are one of several ways to give a spiking network a fast decision about a scalar (Auge et al., 2021). They are distinguished from the others by three properties: when the decision becomes available, how many input events it costs, and how the distance between code words relates to semantic separation (Table 1). Latency coding, or time to first spike, represents a value by when a single spike occurs (Mostafa, 2017; Göltz et al., 2021). It is frugal in events, one per input neuron, and preserves proximity naturally, since close values fire at close times; but the decision cannot be taken until the latest spike that could carry information has had time to arrive, so its latency is bounded by the encoding window rather than by the depth of the network. Rank-order coding (Thorpe and Gautrais, 1998) reads information from the order in which a population fires. It is equally frugal, but it encodes the relative ordering of several inputs rather than the magnitude of one, and it too must wait for that order to be established. Both trade time for events. Spatial codes make the opposite trade: every bit is delivered in the same timestep, so the decision follows within a fixed number of timesteps of the input, and the cost is paid in width instead. Population coding with Gaussian receptive fields (Bohte et al., 2002) preserves semantic proximity through over- lapping graded fields, and is usually read out in time, the strength of each field becoming the latency of its spike. Binarised and presented spatially, it becomes a window of 𝑘 active neurons that moves with the value, and its Hamming distance at semantic separation 𝑑is 2 min(𝑑, 𝑘): proximity is preserved within the width of a field and lost beyond it, every pair of values further apart than 𝑘being equidistant. One-hot, or place, coding is the limiting case 𝑘= 1, in which every pair of distinct values lies at distance 2 and code distance carries no information about separation at all. A place-coded population is nevertheless the natural input layer from which a spatial code can be computed on-chip, and in a single-rail arrangement it costs only one event per value; the dual-rail wiring used here, in which every bit must be presented, removes that advantage. The spatial codes studied in this paper differ from all of these in that distance in code space, rather than in time, carries semantic separation, and they differ from one another in how much of it survives. Thermometer and Johnson preserve it exactly and globally, where a population window preserves it only within its own width, and the hybrid con- struction introduced here preserves it globally at a fraction of the width. It is this global structure, rather than local smoothness alone, that homeostatic tolerance turns into a semantic interval. 3. Methods 3.1. Network Architecture The network follows the supervised STDP arrangement of Davies et al. (2025). A code word is presented as a dual- rail spatial pattern: for each bit, one neuron fires if the bit is 1 and a second fires if it is 0, so exactly one of the two rails is active per bit and the whole code word is presented within a single simulation timestep.
