Preprint The measured sparse path is a native Triton indexed block-sparse attention implementation rather than a dense call with a Python mask. Current queries are reordered once per chunk, KV caches are stored in global-aligned Gilbert order, and the kernel consumes routed block lists with a runtime route-length bound. The previous chunk is always retained within the route budget, while current-chunk local neighbors and reference-frame blocks act as deterministic safeguards. Frustum slab state is prepared asynchronously with a two-chunk freshness lag, so chunk c normally consumes geometry through chunk c −2. In the reported timing traces, DiT denoising and asynchronous geometry construction run concurrently on one H200. We evaluate quality on all 158 cases of the WBench navigation split (Ying et al., 2026). The three LingBot-based rows use identical generated cases and the Gemini judge for VLM-scored metrics. Published WBench rows use the official Doubao judge, so judge-dependent values should not be compared across these two groups. We therefore include an API-free average that excludes VLM-scored setting metrics and is comparable across judge backends. 4.2 ATTENTION SCALING OVER 48 CHUNKS Figure 3 reports 48-chunk timing traces. Under the same single-H200 asynchronous setting, chunk denoising time decreases from approximately 7.19 s to 2.96 s, corresponding to a 2.43× speedup.
