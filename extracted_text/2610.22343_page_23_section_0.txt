A.8 ADDITIONAL QUANTITATIVE RESULTS A.8.1 SINGLE-VIEW-CONTROLLED BASELINE COMPARISON The main GeoState evaluation uses the synchronized FRONT, FRONT LEFT, and FRONT RIGHT images at each observed timestamp, whereas our compared methods use a single image. To control for this difference in input-view count, we re-evaluate GeoState on the same 100 Waymo evaluation windows using only FRONT. Both the frozen GFM and the Scene Tokenizer therefore receive four historical images in total, one from each observed timestamp. The model checkpoints, timestamps, query cameras, metric-scale calibration, and LiDAR masks remain unchanged. Table 9 compares this FRONT-only variant with the external forecasting baselines from Table 1. Under predicted future cameras, FRONT-only GeoState outperforms FR3D, VGGT-World, and DINO-Foresight in both AbsRel and δ1 at every reported horizon. At t+2.0 s, it obtains an Ab- sRel of 0.143 and a δ1 of 0.813, compared with 0.152/0.800 for FR3D, 0.213/0.731 for VGGT- World, and 0.243/0.663 for DINO-Foresight. This comparison removes the additional side-view observations available to the main GeoState configuration, while GeoState continues to use a single context-derived scale rather than per-target-frame alignment. The performance advantage over the external forecasting baselines therefore cannot be attributed solely to using three camera views per observed timestamp.
