Background: Encodings and Byteification Written units and encodings. We use cluster to mean a UAX #29 extended grapheme cluster (Hadley, 2025), opera- tionalized by regex’s \X on text in Unicode Normalization Form C (NFC). All codepoints in our normalized text are scalars. A cluster can contain several scalars, each repre- sented by one or more encoded symbols. Grapheme clusters do not necessarily coincide with linguistic characters or or- thographic syllables. We therefore distinguish scalar, cluster, and symbol counts throughout. Word-spacing conventions are distinct from grapheme struc- ture. Korean regularly separates eojeols, spacing units that can contain multiple morphemes, whereas Chinese gener- ally leaves word boundaries unmarked by spaces (Lee et al., 2026a; Hwang et al., 2026). In neither language do whites- pace boundaries define subword segmentation; Unicode grapheme and word boundaries are also distinct (Hadley, 2025). We therefore distinguish whitespace-adjacent gaps from other scalar gaps when analyzing the Korean/Chinese extension. UBE uses disjoint UTF-8 and UTF-16LE byte alphabets, with 256 symbols each (Kim & Jung, 2026). One- and two-byte UTF-8 scalars stay in UTF-8; three-byte scalars in the Basic Multilingual Plane (BMP) use two UTF-16LE byte symbols; supplementary scalars use four UTF-16LE symbols. A UBE symbol identifies both a byte value and its encoding route; lookahead is measured in symbols. The encoding changes stream length and byte order but does not itself prevent a learned predictor from cutting inside a scalar or cluster. Boundary counts. We compare segmentations in com- mon text coordinates. For a nonempty sentence, let C be its set of interior cut offsets in NFC UTF-8 bytes.
