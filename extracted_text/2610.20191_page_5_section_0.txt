Evaluation Metrics Following prior studies [1], [2], [13], we assess accuracy using Jaccard and F1 for set overlap and PRAUC for predic- tion ranking, and safety using DDI Rate, the proportion of potentially interacting predicted medication pairs. To report the overall performance, we introduce SafeScore: SafeScore = PRAUC + F1 + Jaccard 3 · (1 −DDI). (29) Higher SafeScore indicates a better accuracy-safety trade-off. C. Implementation Details We split the dataset into training, validation, and test sets with a ratio of 8:1:1. To avoid information leakage, all memory statistics and prior distributions are constructed only from the training set. For K(L1), the minimum anchor support thresh- old τa, anchor–medication support threshold τam, conditional frequency threshold τp, anchor–medication hospital-coverage threshold τh, and anchor hospital-coverage threshold τha are set to 30, 10, 0.02, 4, and 5, respectively. For K(L2), the local anchor support threshold τ (L2) a , local anchor–medication support threshold τ (L2) am , local conditional frequency threshold τ (L2) p , and residual magnitude threshold τ (L2) ∆ are set to 8, 4, 0.10, and 0.12, respectively. These thresholds are used as reliability filters for memory construction rather than primary model-selection hyperparameters. During candidate generation, the candidate depth B is set to 60, and the weak-experience decay factors are set to γ(L1) weak = γ(L2) weak = 0.42. Since B and the weak-experience decay factors directly affect candidate recall and noise, we analyze them in the parameter study. All other parameters are selected on the validation set and kept fixed during testing. For fair comparison, all baselines use the same data split, medication vocabulary, DDI file [8], [9], and random seed. All experiments are conducted on a single NVIDIA GeForce RTX 3090 GPU with 24GB of memory.
