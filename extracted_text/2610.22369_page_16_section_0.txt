Dream- Sim (Fu et al., 2023) uses version 0.2.1 with its default ensemble of DINO, CLIP and OpenCLIP ViT-B/16 features. All fidelity metrics compare the decoded output with the uncached sample in RGB, and videos are read back from their saved MP4 files. PSNR and SSIM are computed on 8-bit values scaled to [0, 1] at full resolution, SSIM with the default 7×7 uniform window of scikit-image on each color channel. LPIPS (Zhang et al., 2018) uses the AlexNet backbone, and DreamSim re- sizes its input to 224 × 224. For video, every metric is computed per frame against the same frame of the uncached clip, averaged over all frames (65 on HunyuanVideo, 81 on Wan2.1), and then av- eraged over prompts. Samples are generated one at a time (batch size 1). SoftCache, SeaCache and TeaCache run in our sampler, which times the denoising loop between two CUDA synchronizations, once per sample. Every speedup divides the latency of an uncached run by the method’s latency, both measured the same way on the same GPU. Attention runs through PyTorch SDPA and no model is compiled. We instead take the first 100 prompts of a fixed low-discrepancy reordering of the manifest, which spreads the draw evenly over the set with no seed to choose.
