This divergent colour distortion fundamentally disrupts the intrinsic RGB ratios across the dynamic range, highlighting a deficiency in colour constancy and necessitating the integration of cross-channel coupled tone mapping. Since the current loss function configuration does not have a colour loss integrated, this would strongly benefit the reduction of channel-based colour discrepancies between the well-lit images and the predicted maps from the LLIE module. In this case, the loss function would receive a new term, namely a colour-focused loss. Standard spatial losses penalize the necessary brightness enhancements in low-light processing. To decouple intensity from colour, RGB channels for each pixel are treated as a 3D vector. By comput- ing the cosine similarity between the input vector (vin i ) and output vector (vout i ) across all N pixels, the colour loss (Lcolour) selectively penalizes chromatic angular deviation while ignoring magnitude shifts, preserving intrinsic RGB ratios.
