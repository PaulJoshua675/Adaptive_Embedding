Cost of Random Choice. Random Choice gives the lowest token usage among the compared systems. Each mini-call contains the catalog of method classes as input and one JSON decoder configuration as output; at about 800 input and 120 output tokens per call and 347 calls per run, the run requires 0.28 M input and 0.042 M output tokens. These values are 40 and 14 times smaller than the Analyst token counts of the Qwen agent with the detailed prompt (11.20 M and 0.58 M).
