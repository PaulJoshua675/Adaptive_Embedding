To record a website walkthrough, the agent iterates over seven navigation targets, clicks each target, and reads the active section from the DOM. An assertion checks that the resulting section matches the intended target before the loop continues. The program handles all seven visits and checks without returning to the model between iterations (Figure 3b). Result-Dependent Execution. Conditional logic lets the program respond to what happens during execution. It can inspect command output or application state, check a result, and decide whether to continue. Such decisions can remain within the program when their conditions are computable, rather than requiring the model to interpret each intermediate result. A local check can determine whether a GUI action should proceed. Before sending an email reply, the agent copies the draft from the interface and compares it with a saved version after trimming leading and trailing whitespace. Its program clicks Send only if the texts match and reports a mismatch otherwise. The recorded execution follows the matching branch, but delivery is not verified within this step (Figure 3c). Observation Preparation. Programs can gather and organize evidence for the next model decision. They can collect multiple views, crop relevant regions, or arrange images into a visual summary. This extends code execution from performing actions to preparing observations that the model can then interpret. While inspecting a three-dimensional object, the agent collects 25 views, crops the relevant region from each, and assembles a numbered contact sheet. It opens this sheet and requests one new visual observation. The program collects and arranges views for the model’s visual judgment (Figure 4a). Executable Verification. Programs can check both intended changes and content that should remain unchanged. After editing two slide backgrounds, the agent compares the original and saved presentation packages. It checks the expected changes, verifies that the other 64 original package entries are unchanged, and compares slide content outside the background elements. These assertions make selected preservation requirements explicit, but do not replace independent evaluation (Figure 4b). These examples show a useful division of work: programs execute locally specified operations and checks, while the model chooses the procedure and interprets evidence that still requires judgment. 10
