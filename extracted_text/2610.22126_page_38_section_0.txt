J Isolating the value of CIG’s formulation beyond graph access A possible concern is that CIG’s advantage is simply a readout of having access to the causal graph, not of correctly using it. We address this on Dyngen with a test of instance-level specificity that a fixed, shared graph cannot explain on its own. Because the Dyngen causal graph is identical across cells, a graph-driven attribution method would be expected to produce similar TF importance across cells. In contrast, cells undergoing different state transitions should be explained by different sets of transition-specific TFs. For each transition, we therefore restrict the analysis to cells undergoing that transition and compare the attribution ranks of its known causal TFs against those of all other genes. CIG consistently prioritizes the causal TFs for all six transitions, with significant enrichment in every case (Figure J.1). DeepSHAP shows significant prioritization in two of the six transitions, while integrated gradients does not show significant enrichment in any transition. K Robustness to causal graph misspecification We test how CIG’s attribution quality degrades when the supplied causal graph is imperfect, using three corruption types applied at 25%, 50%, and 75% of edges: removing true edges, adding spurious edges (cycle-safe, never removing a true edge), and reversing the direction of existing true edges. We apply this to both the synthetic SCM/CATE benchmark (Section 4.1) and the Dyngen gene-regulatory network (Section 4.2). On the synthetic benchmark, we measure the Spearman correlation between CIG’s attribution and the true CATE ranking (root-cause features), averaged over 5 seeds, across feature counts 100–1000. Adding spurious edges or reversing edge direction has no effect when the corrupted graph is fed to the oracle SCM mechanisms directly, since the oracle’s forward pass only ever reads its hardcoded true-parent columns; for these two corruption types we instead re-fit a learned surrogate for each perturbed graph, matching how the method is used in practice. Edge removal is tested directly on the oracle mechanisms, as in the main benchmark. Figures K.1–K.3 show results across the full feature sweep, one figure per corruption type. On Dyngen, whose network separates backbone genes (the core transcription-factor cascade driving the simulated differentiation trajectory) from housekeeping (HK) genes (background genes uninvolved in any transition), we apply the same three corruption types to each community separately and report the normalized TF-recovery AUC metric used for the main Dyngen results (uncorrupted baseline: 97.76 ± 3.18).
