Ablation study To validate the core contributions of TSE-RL, an ablation study is conducted on the EEGNet backbone. The results are reported in Table VI across settings and datasets. The comparison starts from a supervised baseline that disables RL, the history encoder, and the FSM-based action mask, which corresponds to EEGNet (Baseline-full) operating on all windows without window optimization. RL is then enabled while keeping both the history encoder and the action mask disabled, yielding a minimal policy that uses only the current- window feature and the trial-progress indicator. Two inter- mediate variants are further evaluated by adding either the FSM-based action mask or the history encoder. And the full model then enables RL, the history encoder, and the action mask simultaneously. Overall, Table VI shows that RL alone improves performance over the supervised baseline, indicating the benefit of learning an time-window optimization policy. Adding either the FSM-based action mask or the history encoder provides further gains, and enabling both consistently achieves the highest accuracy across all datasets and settings. H. Sensitivity analysis To assess the robustness of TSE-RL to hyperparameters, a sensitivity analysis is performed with respect to the window length L, stride ∆, and history length k on the EEGNet backbone. The default configuration in the main experiments is L = 1.0 s, ∆= 0.1 s, and k = 5. Fig. 4 varies these hyperparameters within practical ranges (L ∈[0.6, 1.4] s, ∆∈ [0.04, 0.4] s, and k ∈[3, 9]) and reports accuracy along with the retained-window ratio (retained windows divided by all candidate windows). This ratio is reported because changing L or ∆alters the number of candidate windows per trial, making raw window counts incomparable. Overall, Fig. 4 reveals that TSE-RL demonstrates considerable stability around the default parameter configuration, with only moderate performance vari- ation under perturbations of L, ∆, and k.
