Partitioning cells by the two agents’ votes shows that cells where both agree No are the most accurate against the expert labels (84.3%, 113/134), cells where both agree Yes are the least accurate (52.3%, 23/44), and split votes fall between them (72.7%, 8/11). The low accuracy of “both Yes” cells is the threshold-disagreement effect described in the main-text error analysis. The agents confidently and defensibly detect documented diarrhea that the reviewer scored as sub-threshold, so positive calls are exactly the cells a deployment should route for human adjudication. Why the reported configuration’s run-to-run SD is zero. Prompt V2’s accuracy in main-text Table 2 carries an SD of 0.0 because its confusion matrix is identical in all three runs, at 30 true positives, 124 true negatives, 12 false positives and 17 false negatives. This is a property of the aggregation step and not evidence that the prompt is deterministic. At the note level the consensus call does move, flipping on 7, 9 and 8 of the 2,260 classified notes across the three run pairs, and on 3, 4 and 3 of the 1,404 notes that fall inside the annotated patients’ evaluation windows. None of those flips changes a cell. Aggregation marks a patient–timepoint Yes if any note in the six-month bucket receives a positive call, so a flip on a note whose bucket already holds another positive is absorbed. The deployed prompt V0 flips on 15, 11 and 10 notes over the same pairs, and one of its cells does move. The zero is therefore correct arithmetic at the cell level while the underlying note-level classification remains stochastic, and it should not be read as prompt stability. Decoding parameters and the independence of the runs. No seed and no sampling parameters were set in any of the 42 model- invocation nodes, so temperature, top-p, top-k and the token limit took platform defaults throughout, as the main-text Methods states. The three runs are therefore independent draws rather than replays of a single run. We verified this on the response strings themselves, since the platform exposes no per-call telemetry. Under V2, Agent 1 returned byte-identical text on 2,243 of the 2,260 notes and Agent 2 on 2,251, whereas a cached or memoized path would return identical strings everywhere. Byte differences outnumber label flips, so part of the run-to-run variation is wording that leaves the YES/NO verdict unchanged. Supplementary Note S2.
