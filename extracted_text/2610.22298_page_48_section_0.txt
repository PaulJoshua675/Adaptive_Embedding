AI Consilium: a Benchmark of LLM Clinical Multidisciplinary Second Opinions A PREPRINT E Instructions for Physician Evaluation of Medical Consensus Reports Purpose of the assessment The purpose of the assessment is to evaluate the quality of an already generated medical consensus report, rather than to reassess the patient or the source article. The physician rater should assign numeric scores in the spreadsheet and, when needed, provide a concise explanation of the main deficiencies. • Evaluate only what is explicitly stated in the consensus report and supported by the source clinical case. • Do not infer missing information on behalf of the report author. If a relevant fact, test result, diagnosis, or explanation is absent, treat it as absent. • Do not assign a high score solely because the text is fluent or well-structured if it contains fabricated data, weak clinical logic, or an unsafe management strategy. • All numeric scores in the spreadsheet must be 0, 1, 2, or 3. Files to be reviewed 1. Open the PDF or text file of the consensus report from the folder corresponding to the relevant specialty. 2. Open the spreadsheet file for the same specialty. The specialty is indicated at the top of the worksheet. 3. Identify the row corresponding to the case number. The row identifier should match the beginning of the consensus report filename. 4. When verification of a fact is required, refer to the clinical case description, tables, investigation results, and other source data included in the case file. Structure of the spreadsheet assessment Each case contains three evaluated report components. The same eight criteria are repeated for each component. Scores assigned to one component should not be transferred automatically to another component: a strong final conclusion does not compensate for weak reasoning, and strong reasoning does not compensate for an inadequate final conclusion.
