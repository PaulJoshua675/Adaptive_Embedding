A.2 More Implementation Details A.2.1 Details about the Construction of Reference Structures We filter 6.4K videos from EVA-Data, all of which achieve a 100% hit ratio in Stage 3 of the annotation pipeline, ensuring highly accurate event-level supervision signals. To facilitate efficient reward computation for both GRPO training and rollout, we construct reference structures for these 6.4K selected videos. Specifically, this involves extracting audiovisual event units E⋆from the ground-truth captions y⋆and formulating audio-to-visual synchronization queries Q⋆. We employ the reward judge LLM, Qwen3.5-27B [33], prompting it to sequentially extract audio events and visual events from the given caption to form a unified event list E⋆. Each extracted audio event serves as a separate query. We input the complete ground-truth caption along with all the extracted visual events into the LLM, prompting it to select the temporally synchronized visual events corresponding to the current audio event (i.e., the current query) from all the input visual events. Each visual event is assigned a unique index based on its chronological extraction order (i.e., the first extracted visual event has an index of 1). Since all visual events are extracted sequentially, we discard audio events whose matched visual event index span exceeds 5.
