MemoRAG uses global memory to guide evidence access, and MemOS considers knowledge access across the memory lifecycle [18, 19]. KG-RAG combines knowledge-graph retrieval and question decomposition for multi- hop question answering without additional training [20]. CTRN addresses complex time constraints through implicit temporal and relational representations [21]. MGIT models temporal dependencies at multiple granularities [22]. These graph-based question- answering methods are relevant to TEM’s use of structured evidence. Our focus is the management of fact versions as conversations update a state, including how the resulting status information reaches the generator. 2.2 Long-Term Memory Evaluation and Retrieval Augmentation LongMemEval and LoCoMo evaluate cross-session information use, fact updates and temporal reasoning [23, 24]. LongBench covers a broader set of long-context tasks [25]. Lost in the Middle shows that the position of relevant information can affect model performance [26]. For state tracking, finding a relevant passage does not settle which version answers the question. We study this choice in controlled update tasks and evaluate hybrid retrieval on public multi-session questions. RAG and dense retrieval provide the basis for accessing external evidence [27, 28]. Self-RAG evaluates evidence, RAPTOR organises it hierarchically, and interleaved retrieval supports chain-of-thought reasoning [29–31]. LLMLingua, LongLLMLingua and RECOMP reduce the input passed to the generator [32–34]. TEM retains version order and state attributes alongside retrieved facts, allowing the generator to interpret the selected evidence in its temporal context. 3 Temporal State Tracking Memory TEM stores each fact with its provenance and places successive values in a version group. Source order determines the status of each version. Retrieval then selects the facts to include in the answer evidence.
