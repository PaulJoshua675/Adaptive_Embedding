A.5 Extraction In the schema S, fj, τj, and δj denote a field’s name, JSON-compatible type, and description. Fields may also have value constraints. The Ex- traction Agent reads the PDF text with pypdf and inserts a page marker before the text of each page. The schema checks cover field presence, declared types, and value constraints. Proposed excerpts are matched against normalized PDF text, and a located excerpt is recorded with the page on which it is found. A.6 Categorization For a selected field fj with nonempty extracted values Vj, the Lead Agent proposes the cate- gory plan Kj = fLLM(fj, sample(Vj), m), where sample(Vj) takes the first 150 distinct values in record order, each shortened to 300 characters, and m selects single-label or multiple-label assignment. It has at most five categories, fewer when the field has few distinct values, and includes an Other cat- egory within that limit when some values fit none. Returned labels are normalized when they match approved names. Multiple-label responses contain- ing other labels are rejected. Papers with no value for the field are marked as unavailable. Saved out- puts keep the field, mode, category descriptions, and per-paper assignments. A.7 Interface, Memory, and Revision The interface combines a project sidebar, a con- versation panel, and a stage-specific canvas for editing configurations and inspecting results. For example, the chat request add a field for sam- ple size edits the schema draft. Researchers can run screening or extraction on samples of one to five papers, kept separate from full-run out- puts. In conversation, the Lead Agent’s context is Pchat = Ptask⊕Sproject⊕Hproject, which concate- nates task instructions and the current request with the saved project state and the conversation history. Configurations that can be imported from a previ- ous project are its search setup, criteria, schema, and category plan. Edits submitted against an older project revision are rejected. AgentSLR’s screening tem- plate states the PERG criteria, and all three meth- ods use these 11 rules: AgentSLR runs its pub- lished template unchanged, and ReviewPilot and the single-prompt baseline receive the same rules as an inclusion list and an exclusion list. There are five inclusion criteria: (1) the target pathogen; (2) En- glish; (3) peer-reviewed original research, with systematic reviews and meta-analyses given spe- cial consideration; (4) human subjects, or animal studies that report transmission or vector parame- ters; and (5) at least one of ten content types (out- break details, a transmission model, transmission, timing, severity or genetic parameters, overdisper- sion, seroprevalence, risk factors, or vector param- eters). There are six exclusion criteria: (1) an- other pathogen; (2) non-English; (3) conference abstracts, posters, or correspondence; (4) in-vitro work only; (5) animal-only studies without trans- mission parameters; and (6) laboratory outbreaks.
