As a promising direction in retrieval-augmented generation (RAG), retrieval over text-rich knowl- edge graphs (KGs) rather than flat documents is increasingly used to help large language models (LLMs) answer questions and ground answers in evidence. Unlike flat document retrieval, KG re- trieval must jointly exploit nodes (breadth-oriented) and traverse along relations (depth-oriented). Bal- ancing between the search breadth and depth is a long standing challenge for KG retrieval (Polonuer et al., 2026). With the advances of agents, several recent studies (Sun et al., 2024; Yu et al., 2025) delegate such tasks to retrieval agents which have autonomy to balance search breadth and depth with- out a pre-specified number of node searches or hops. However, these agents’ retrieval process is driven primarily by textual similarity and graph structure, which can still favor evidence that is only associated with the query but not necessary for answering it. For example, consider the ques- tion, “Which medicine should this patient avoid?” A similarity-based retriever may return a clinical note stating, “The patient currently takes several medicines, including aspirin and metformin,” be- cause it contains many words similar to the query. However, this information does not answer the question. Another record may simply state, “Al- lergy: amoxicillin.” Although this short record has no textual overlap with the question, it provides the key evidence needed to answer the question. This illustrates why textual similarity alone is not enough to make a substantive contribution to the answer. In this study, we advocate for a causal retrieval agent, which has autonomy, but more importantly, is able to retrieve evidence that is “causally relevant” to answering the query, rather than merely textually similar. In this study, we operationalize the causal relevance using two complementary criteria: • Consequential: does adding the retrieved evi- dence materially increase answerability? • Essential: does removing the retrieved evi- dence materially reduce answerability? This operationalization is inspired by recent work on faithful rationale evaluation (DeYoung et al., 2020; Yu et al., 2019).
