The repeated text concentrates the mathematics statistics on a few directions, so each layer moves toward the coding specialist wherever the two share inputs (Proposition 3.1). The loss is confined to hard mathematics: with all answers, the fused model still matches the coding specialist on both code benchmarks and is slightly ahead of the mathematics specialist on MATH-500 (Table 7). 4.5 Ablation study Which answers. Figure 4b varies only the answers that enter the statistics. With every answer of the specialists, the fused model is no better than task arithmetic on AIME25, and both fall short of the mathematics specialist scored in the same format. Removing the looping answers alone brings it level with the specialist and recovers every hard problem that the model built from all answers loses. Keeping only correct answers, which discards many more, changes nothing further: a finished but wrong answer is still an example of the specialist reasoning normally. Checking the code answers by running their tests, as the final model does, changes code accuracy by no measurable amount (Table 3). Whose text. On-policy distillation in the strict sense uses text written by the student. We let a fused student answer the same problems and compute the statistics either from the student reading its own answers or from the mathematics specialist reading them, the closed-form analogue of the trained objective. Neither improves on the specialist’s own answers with the looping ones removed (Figure 4b). Reweighting and mined problems. Weighting mathematics three to one in Equation (1) recovers most of the loss, but at the coding specialist’s expense: the share of its update that the fused layers fail to reproduce nearly doubles (Figure 5b). Statistics from mined hard problems give no clear gain. Selection removes the cause; the other remedies compensate for it. The merge rule. On MATH-500 and the two code benchmarks, task arithmetic, a low-rank variant of it and the closed form all keep both specialists’ gains and cannot be told apart (Table 3). The rules separate only on hard problems (Figure 4b). Number format. Reinforcement learning moves each weight by about one step of the 16-bit format the models are released in. The closed-form update is not made of whole steps, and rounding to that format measurably distorts it (Appendix B), so fused models are stored in 32-bit floats and evaluated in float16. The format matters at the scale of our comparisons: the mathematics specialist scores several points higher on AIME25 in its released format than in float16 (Table 5). 9
