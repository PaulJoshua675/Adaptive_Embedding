Comparison of uniform token weighting in GRPO and semantic span weighting in SCOPE. A T2I evaluator provides a single reward for the image. Standard GRPO derives an advantage for the completion and applies it across token positions. However, compositional prompt edits are naturally organized into semantic phrases whose boundaries need not align with tokenizer positions. SCOPE preserves the same advantage for the completion and derives a shared coefficient for each semantic span from shifts in policy log probabilities. This coefficient modulates all token updates within the span. composition holistically, without direct attribution to constituent spans or tokens. This exposes a fundamental credit assignment bottleneck: uniform token-level updates fragment coherent compositional edits across arbitrary subword boundaries, yet estimating dense per-span rewards incurs prohibitive rendering overhead. To bridge this gap, we introduce Semantic Bounded Credit Optimization for Prompt Engineering (SCOPE), a GRPO-compatible objective that modulates token updates across semantic spans. The rewriter outputs a prompt rewrite and its semantic partition, mapped onto rollout tokens. SCOPE pools shifts in token log probabilities between the current and old policies within each span to derive a detached coefficient. This coefficient reweights the contribution of the shared advantage to each token loss in the clipped GRPO surrogate. The objective retains a loss for each valid token and a single advantage for each completion. SCOPE uses the existing rendering and reward pipeline, without separate rewards or advantages for individual spans, additional image renders, or a learned critic. Moreover, SCOPE serves as a strict generalization of standard GRPO, seamlessly recovering uniform token updates when span modulation is neutralized (β = 0). Across Qwen-Image, SD3, and FLUX.1-dev, SCOPE consistently outperforms vanilla GRPO on GenEval [13] and T2I-CompBench [18]. Ablations favor pooling policy shifts within semantic spans over weighting individual tokens, and semantic boundaries over random boundaries or fixed windows. The token weighting comparison tests the contribution of pooling over semantic units. The random and fixed window controls test the contribution of semantic boundaries beyond grouping neighboring tokens. Together, these comparisons separate semantic structure from generic reweighting. Overall, we make three contributions: • We identify semantic credit fragmentation in T2I prompt rewriting with RL. A single signal per completion, derived from the image, drives updates to tokenizer positions. Compositional edits form coherent semantic spans whose boundaries need not align with the subword boundaries imposed by the tokenizer. • We introduce SCOPE, an objective compatible with GRPO that pools policy log probability shifts within semantic spans to assign shared token weights. It retains one advantage per completion without separate span rewards or advantages, additional image renders, or a learned critic. • We demonstrate that SCOPE consistently outperforms the vanilla GRPO baseline on GenEval and T2I-CompBench. These gains hold across three frozen T2I backbones: Qwen-Image, SD3, and FLUX.1-dev. 2
