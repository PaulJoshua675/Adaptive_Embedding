Limitations and Future Directions In addition to the introductions of this package, this study still has some limitations. First, the experiment in this study is only limited to the default features of the optimisation algorithms because the goal is to introduce the naspaclust package in R. Furthermore, we also only use benchmark data that have been used in previous studies using FGWC as the algorithms. Thus, the limitations open many possibilities to continue the optimisa- tion algorithms in FGWC studies. Firstly, one may apply these algorithms to solve real-world problems that require the clustering algorithm at the re- gional level using different optimised FGWC. Using spatial information may give more insight into the clustering results. Considering the features avail- able in the naspaclust package, one can implement the enhancement version of optimisation algorithms such as in GSA, HHO and TLBO based on Sec- tion 2. Furthermore, the modification can also be done based on distance using the available distance features in the rdist package (Blaser, 2020). Other modifications that can be made are from randomisation terms such as in IFA, FPA, and GSA, or the update inertia weight in PSO.
