It is more flexible than a GUI agent. Its commands and scripts can use loops, branches, and variables. Recent coding agents also let the model decide part of how it organizes its work, for example by summarizing earlier context when it grows long (Anthropic, 2025; OpenAI, 2025). What a CLI agent cannot do is operate an application that can only be used through its graphical interface. Agent frameworks such as OpenClaw support more than the shell, but they also come without built-in GUI control (Sun et al., 2026). Multi-Agent Hybrid Systems. Some recent systems combine GUI and programmatic control by divid- ing the work among several agents. For example, an orchestrator splits a task into subtasks and sends each one to either a GUI operator or a programmer (Song et al., 2026). Each sub-agent has its own fixed interface. The GUI operator sees screenshots and acts through GUI operations, and the programmer writes and runs code. In terms of Eq. (1), while sub-agent k handles a subtask, qt and pt are limited to its own sets Qk and Ak. Together, the sub-agents cover the same interfaces as a GCUA. The difference is where the choice of interface is made. In these systems, the orchestrator makes it once per subtask. In a GCUA, a single model makes it at every step, and one program can combine several interfaces. 2.3 Why Now: The Route Flip to Code Execution In 2026, the frontier began to shift from clicking toward programming, and the shift is visible in vendor documentation rather than only in benchmark scores. With the release of GPT-6 Astra, OpenAI’s computer-use guide began recommending that models write and run short programs, for example with PyAutoGUI or Playwright, rather than rely primarily on the earlier computer tool for mouse and keyboard actions (OpenAI, 2026b). The guide’s examples reflect this shift: the computer tool still targets the previous model (i.e., GPT-5.6 Sol), while code-execution examples use GPT-6 Astra. A similar pattern appears on OSWorld-v2, where frontier agents perform more actions through code, APIs, and file operations rather than clicks (Yuan et al., 2026).
