Frontier Computer Use. OpenAI positions GPT-6 Astra for difficult end-to-end work and describes computer use as a new frontier in speed, accuracy, and safety. It recommends code execution for computer-use tasks while retaining the structured computer tool as an alternative (OpenAI, 2026c;b). In Codex, Computer Use can see and operate graphical user interfaces on macOS and Windows, support workflows spanning multiple applications, and, on macOS, run scoped background tasks while the user continues working elsewhere (OpenAI, 2026a). Anthropic also provides computer use in Claude Cowork and Claude Code: Claude first reaches for the most precise tool, such as connectors to services like Slack or Google Calendar, and can directly control the browser, mouse, keyboard, and screen when no connector is available. Its Dispatch feature further lets users assign tasks from a phone and open the completed work on a computer (Anthropic, 2026b). Despite these capabilities, the public releases leave key implementation details and execution trajectories unavailable, making their system designs difficult for the community to reproduce and study systematically. Computer-Use Agents. Prior open CUA models remain largely GUI-centric. UI-TARS and UI-TARS-2 (Qin et al., 2025; Wang et al., 2025a), OpenCUA (Wang et al., 2025b), ScaleCUA (Liu et al., 2025), EvoCUA (Huang et al., 2026), and Fara (Microsoft, 2026) release open models for computer use and report strong results on relevant benchmarks.
