Part of the effectiveness of language models is that they perform statistical generalization and operate on statistical inferences that are not guaranteed to be true 100%. Finally, our setup fine-tunes a model to learn new facts. The impact of this setup on hallucinations was studied by Gekhman et al. (2024). Ovadia et al. (2024) find that models struggle to learn new facts in fine-tuning. Mecklenburg et al. (2024) investigate what composition of pretraining data leads to successful learning of new facts. Zhao et al. (2025) also show the effects of different types of pretraining data on new fact learning and that new facts are difficult to learn in composition (a case of what we call entailment). This work does not address how known facts can be leveraged for new facts. In summary, there is much work on entailment, factual recall and linguistic generalization, but, to our knowledge, the question of which known facts a model can build new facts on has not been addressed. We address it in a fine-tuning setting and find that whether facts are active, that is, whether new relations built on them generalize, is predicted better by how linearly readable they are before fine-tuning than by whether the model can recall them. This sheds light on how facts are represented in language models and how this representation supports learning and generalization. 3 METHOD We study how well a new relation generalizes when it is built on a relation the pretrained model already knows, and whether this depends on how linearly readable the known relation is. We start by giving definitions and clarifying notation. Pretrained relation. We call the existing relations in the pretrained language models pretrained relations. These relations form the existing knowledge of the model. Concretely, take the relation C that maps entities to their continent (Paris →Europe, Tokyo →Asia). We ask the model for a pretrained-relation answer with a prompt that stops where the answer begins, the relation’s query template. For the continent relation, the model should continue “Paris is located in” with “Europe.” In the next paragraph, we’ll describe how we construct new relations that are statistically related to these pretrained relations. Our metrics only use the first token of the answers to the relations. Thus, answers sharing their first token form one effective answer, which we shorten to answer from now on. We write E for the set of these answers and, for a particular pretrained relation R, write eR(u) ∈E for subject u’s answer. For example, for the continent relation C, we have eC(Paris) = Europe. New relation. To study how models learn new facts that relate to their existing knowledge, we build a new relation on top of each pretrained relation R. It should depend on R, but be unknown to the model. We get both by relabeling R’s answers at random with words from a label set A; e.g., animal names such as “zebra,” “crab” and “boar.” The next paragraph describes how we build these sets. For each R, we draw a subset L ⊆A with |L| = |E|, the number of R’s answers, and a bijection π: E →L, both uniformly at random. The new relation Rπ maps each subject u to π(eR(u)), so subjects that share a pretrained-relation answer share a label. E.g., if R maps Paris → Europe and Tokyo →Asia, and π(Europe) = crab and π(Asia) = zebra, then Rπ maps Paris → crab and Tokyo →zebra. Label sets. We build a label set from one WordNet 3.0 noun category, such as noun.animal, by a deterministic algorithm, the label-set algorithm. It keeps names that truly belong to the category, are common in English and are not hyponyms of one another, so each prompt has one correct label. Each kept name’s first token must also differ from every other kept name’s under the tokenizer of every model the label set is used with, since we score only first tokens. Each relation’s labels exclude names that are taxonomic neighbors of its subjects or answers (Appendix F). Hold-out protocol. For each relation, we split subjects into fine-tuning subjects T and held-out subjects H. The split includes at least one held-out subject and at least four fine-tuning subjects per answer.
