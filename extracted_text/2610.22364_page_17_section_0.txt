The environment-latent optimizer uses learning rate 0.03 and zero weight decay. Latents are independently initialized from U(0, 1) and clipped to [0, 1] after training updates. Test-time adaptation. For a held-out environment, a 32-D latent is optimized from its test- time interaction trajectories; all shared weights stay frozen. Query outcomes never enter this up- date. Both simulation and real-world main evaluations use 40 latent updates with learning rates 3.0, 1.5, 0.5, 0.15, each for ten updates. The resulting latent is reused across query actions from that environment. Exact task-specific execution configurations are released with the code.
