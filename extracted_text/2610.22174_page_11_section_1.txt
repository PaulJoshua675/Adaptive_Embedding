LLM Agents. LLM agents extend LLMs with tool use and environment interaction to work au- tonomously (Feng et al., 2026; Li et al., 2025; Wang et al., 2024; Wu et al., 2026). ReAct constructs a general agent loop of reasoning, acting, observing environment feedback, and continuing until task completion (Yao et al., 2022). To handle complex and long-horizon tasks, recent systems develop agent harnesses that manage execution beyond the basic ReAct loop (OpenClaw, 2026; Works, 2026), incorporating context compaction (Nguyen et al., 2025), multi-agent system (Chen et al., 2026a), subagent forking (Team et al., 2026), and other forms of context and workflow management (Chen et al., 2025; Kim et al., 2025; Shi et al., 2026; Xu et al., 2026c; Yang et al., 2026; Zhang et al., 2026a). 11
