5. Discussion 5.1. Implications for training-free adaptation LAMP improves adaptation by combining complementary features from different encoder layers. The final global descriptor provides image–text alignment, while inter- mediate feature maps supply additional visual information for the target task. Controls with matched search budgets show that descriptors from multiple layers outperform an ensemble built from the final global feature. Likewise, pooling several feature maps outperforms pooling only the deepest map. In the pooling study, regional centroids and whole-map descriptors retain most of the accuracy gain. These compact representations offer useful options for applications with limited storage or strict latency requirements. Calibration and task-specific mixing determine how each layer contributes to pre- diction. Calibration is particularly effective for RN50 on EuroSAT, and the selected layer weights vary across datasets and backbones. LAMP-F adds prototype adaptation, with the largest gains when few support images are available. Caching the response to prototype changes makes their evaluation inexpensive relative to constructing the regional predictors. The results highlight the value of the visual information already present in a frozen encoder and show how to use it through complementary residual corrections. 5.2. Limitations Using features from multiple layers increases storage requirements and kernel computation costs. On ImageNet at 16 shots, LAMP increases latency at batch size one from 14.22 to 64.83 ms on ViT-B/16 and from 14.81 to 65.86 ms on RN50 (Table 10). Dense fitting requires O(N2) storage and O(N3) factorization per branch; LAMP-F also stores prototype responses.
