Qwen’s chat template still emits an empty <think></think> block at the start of the assistant turn. We treat that block as part of the prompt, so the training loss is computed only on the answer that follows it. We use gemma-4-31B-it (Gemma Team, 2026) as the judge for MASK, MT-Bench and AlpacaEval, validated against human annotation. Both training objectives are implemented as custom trainers on top of TRL (von Werra et al., 2020), and all generation tasks use vLLM (Kwon et al., 2023). We train on 8 H200 GPUs and evaluate on 4 H100 GPUs. Adversarial data We leverage Herbster et al. (2026)’s training data, which consists of 50 self- reporting scenarios where the model is placed in a fictional prior, e.g., missing a vulnerability in a code review, and is questioned by the user. Each scenario carries two system prompts, one where the model is instructed to lie about the prior action, and the other where the model is instructed to be truthful. The evaluated model generates five completions for each variant, and each is scored by gpt-oss-120b (OpenAI, 2025) that returns a verdict indicating whether the completion followed its assigned condition (honest/dishonest). We keep only completions whose verdict matches their con- dition, dropping scenarios left with no usable dishonest completion. These are then paired within each scenario to form (y+, y−) contrast pairs, along with the dishonest system prompt (x) as adver- sarial context. This yields the final Dadv consisting of 216 rows of on-policy training data over 45 scenarios for Llama-3.3-70B-Instruct and 224 rows across 47 scenarios for Qwen3.6-27B. Utility data We initially trained with ultrachat 200k (Ding et al., 2023), following the origi- nal CAT paper (Xhonneux et al., 2024). This corpus was generated with ChatGPT, and training on it degraded model’s general ability. We therefore use on-policy1 utility data for both models: Magpie-Llama-3.3-Pro-500K-Filtered (Magpie Alignment, 2026) for Llama-3.3-70B-Instruct, and for Qwen3.6-27B a corpus we generate ourselves with the Magpie pipeline (Xu et al., 2025). Be- cause the choice of corpus has a large effect on capability preservation, we ablate it on both models. Training configuration All runs use QLoRA: 4-bit NF4 base weights with bfloat16 compute, and LoRA adapters with r = 64, αLoRA = 16 and dropout 0.1 on all linear projections. The maximum sequence length is 1024 and the effective batch size is 16.
