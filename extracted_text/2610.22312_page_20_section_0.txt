GT Bench evaluates graph algorithms across graph structures and input representations, and GTA uses representation selection and task decomposition to improve performance (Xu et al., 2026e). CDCR-SFT trains models to construct causal graphs and reason over variable-level dependencies (Li et al., 2025d). TAG-AD evaluates contextual and structural anomalies in text-attributed graphs (Xu et al., 2025a); LLM-GOOD combines LLM filtering with graph neural networks for data-eﬀicient out-of-distribution detection (Xu et al., 2025b). ReMindRAG uses graph traversal and replay of earlier traversals to retrieve relevant knowledge (Hu et al., 2025). These tasks differ in their outputs, but all make the organization of information part of the reasoning problem. Executable problems also support evaluation beyond a binary task outcome. AlgoWorlds distinguishes feasi- ble decisions from globally optimal ones using exact solutions to combinatorial problems (Xu et al., 2026d). QUITE evaluates SQL rewrites for semantic equivalence and execution eﬀiciency, using database feedback during rewriting (Song et al., 2025). TerminalTraj constructs agent trajectories in Dockerized environments and pairs them with executable validation code (Wu et al., 2026). A related line changes how reasoning is organized or learned. DyFlow constructs and revises workflows from intermediate feedback (Wang et al., 2025c); CogWriter combines hierarchical planning with monitoring and revision for constrained long-form generation (Wan et al., 2025). CoAct uses online task allocation to parallelize LLM-agent execution (Peng et al., 2026). Context-CoT synthesizes and filters reasoning traces grounded in supplied context for fine-tuning (Jin et al., 2026), while AdaThinkV learns when explicit reasoning improves video answers enough to justify its additional response length (Tian et al., 2026). Grid-Bench evaluates the complete spatial state produced by a supplied transition sequence. History length counts events in this specification; task-local reads and changes describe reference execution. These quantities organize the conditions under which predictions are compared. The formal sequence studies above address how models realize sequential mappings, complementing the output-level evaluation of spatial states. A.5 Contextual robustness and evaluation Controlled changes to an input provide another way to characterize model behavior. Adaptive Distraction uses tree search to construct task-irrelevant context while preserving the original question and answer (Wang et al., 2025b). JevOut optimizes natural context additions to redirect decisions under answer-preservation constraints (Xu et al., 2026c). Query-agnostic attacks on LLM retrieval show that document edits can also change which evidence reaches a model (Li et al., 2026a). Cross-Lingual Pitfalls searches for bilingual questions that expose performance discrepancies (Xu et al., 2025c), and BICAUSE uses aligned Chinese and English causal statements to examine sensitivity to language and causal word order (Wang et al., 2025a). These studies vary the presentation surrounding a reasoning problem; Grid-Bench varies the supplied events and spatial configurations that determine its reference outcome. Evaluation design also determines which aspects of a system become observable. AutoBench-V generates images and visual questions to construct evaluations for requested capabilities (Bao et al., 2024). AD-LLM separates anomaly detection, data augmentation, and model selection into distinct tasks (Yang et al., 2025). Within logical reasoning, FineLogic distinguishes final accuracy from stepwise soundness and representation- level evidence (Zhou et al., 2025). Agent evaluations make similar distinctions: FORTIS separately checks skill selection and execution within permitted actions (Li et al., 2026d), while Counterfactual Trace Auditing compares paired trajectories to identify behavioral changes that pass rates can miss (Zhou et al., 2026b). Representational analyses and interventions address different questions from output scoring. BiasLens mea- sures associations among concepts in model representations (Gao et al., 2025); Treble Counterfactual VLMs uses causal interventions to study modality shortcuts associated with hallucination (Li et al., 2025c). Inside the Unfair Judge similarly studies scoring biases through representations and interventions in LLM judges (Xu et al., 2026b). Work on the checkability boundary places candidate generation with the LLM and ac- ceptance with an independent semantic checker (Zhou et al., 2026a).
