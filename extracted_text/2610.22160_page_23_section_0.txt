Each optimization round generates one response using two context-conditioned model streams. Including the initial generation, EMO@k uses N = 2k + 1 target-model generation equivalents and produces k + 1 candidates. Section 4.4 matches this budget to N independent samples for SC/BoN; the accounting excludes judge/rewrite calls, response- length differences, and latency. Judge throughput is not a bottleneck: with CUDA graphs, the 122B FP8 judge sustains ∼22 concurrent scoring workers per 4-GPU instance. Self-consistency and Best-of-N baselines. The SC/BoN comparison shares the sampling pool of the top-p experiments: for each question we draw n=10 i.i.d. samples at temperature 0.6, top-p 0.95, with the same per-model generation budget and the same seeds {0, 1, 2} as the EMO sampling runs. BoN@N selects, among the first N samples, the one with the highest judge score (the same scoring engine and prompt as EMO’s judge-select, ties broken toward the earlier sample) and reports its rule-based correctness. SC@N takes a majority vote over the extracted final answers of the first N samples (the same extraction rules as the main scoring pipeline); a sample whose answer cannot be extracted abstains, and if all N abstain the first sample’s rule-based verdict is used. On a vote tie, the answer with the highest total judge score among the tied candidates is selected. pass@N is the oracle upper bound shared by SC and BoN (any of the first N samples correct). B.4 Full Experimental Results B.4.1 AIME-2025 and AIME-2026 Reported Separately Table 8 reports AIME-2025 and AIME-2026 separately (the main paper merges the two 30-problem sets). Because each year has only 30 problems, one problem corresponds to 3.3 points; small differences should be interpreted in light of this coarse resolution. EMO more than doubles Qwen3-8B’s Base accuracy on both editions (16.7→43.3 on 2025, 23.3→50.0 on 2026), whereas the Llama models remain near zero. For Llama-3.2-3B, even pass@5 reaches only 3.3 and 6.7 on the two editions. Thus a perfect selector over these pools would still solve few questions: the principal observed limitation is candidate generation. Low baseline accuracy provides headroom but does not ensure that four feedback-guided updates can access correct solutions. B.4.2 Accuracy vs. Iteration for All Models Figures 3–8 plot the accuracy of the judge-selected response (solid lines) and the pass@n oracle upper bound (dashed lines) against the EMO iteration n, for all 8 models on each of the six datasets. All curves are computed from the greedy main experiments, with the baseline (grey dashed line) scored under the same unified judge. Across the 44 (model, task) pairs with a non-saturated gain (≥2 points), iteration 2 already realizes on average about half of the final gain of EMO, and on saturated tasks (GSM8K for the Qwen3 family) the curve flattens after a single iteration.
