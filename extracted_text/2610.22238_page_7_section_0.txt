We further observe that in MDM, a query of the score function pθ,i actually provides pθ,i′ for all i′ ∈Bt. We therefore propose the Rao-Blackwellized increment, which calculates bδt,j as the average over all i ∈Bt\ eBt,j: bδt,j = 1 nt −kj + 1 X i∈Bt\ e Bt,j log pθ,i(xi|zj) pθ,i(xi|y) . We now characterize the query complexity of SIRS. We treat the query {pθ,i(·|Y t−1)}i∈Bt as a single query of the score function, so the query complexity of SIRS with and without Rao- Blackwellized increment can be unified by the following proposition: Proposition 4.1. Let Nt be the number of queries to the score function in the unmasking step t. Then E[Nt] ≤(1 + 2B)e2B. Proof. In step t, the proposal probability requires 1 query of the score function. Every proposed XBt is accepted with probability exp(E[clipB(c W)|XBt] −B) ≥exp(−2B), so it takes no more than e2B rounds in expectation for a proposal to be accepted.
