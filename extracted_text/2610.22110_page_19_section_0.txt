Single-Variant Specialization for Masewalkopa 19 baseline, high scores on mixed-corpus benchmarks can easily mask severe struc- tural failure on authentic regional speech. We have termed this failure variant fragmentation. To resolve this issue, this paper demonstrated the process and effectiveness of specializing an existing sequence-to-sequence model to a specific regional variety: Masewalkopa (nhn), spoken in Santa Ana Tlacotenco. Using a relatively small community corpus of 2,665 curated pairs, a stratified evaluation split that strictly measures sentential syntax, and 192 authentic elder-transcribed narrative targets integrated through asymmetric backtranslation, we adapted a 1.2-billion-parameter checkpoint on a single GPU. The resulting specialized system (lora_v9c_b) achieved 58.46 dev chrF++ and 58.20/57.90 directional test chrF++, gaining over 28 points over the initial multi-variant baseline. Beyond aggregate metric gains, my experimental ablations and failure analyses provide concrete architectural takeaways for indigenous and polysynthetic NMT: 1. Subword embedding constraints in LoRA: Introducing new special tokens while freezing the shared embedding matrix creates an untrained bottleneck that stalls model convergence. Conditioning the translation encoder using plain- text syntactic prefixes reuses the pretrained subword space and completely recovers model performance. 2. Density in morphosyntactic conditioning: Sparse functional syntax tags act merely as shallow domain indicators, whereas high-coverage tags (95.8%) generated by a rule-based finite-state analyzer provide explicit structural guidance that improves translation on complex polysynthetic targets (+1.33 chrF++). 3. Decolonial and multi-faceted evaluation: Character overlap metrics alone cannot detect whether a translation respects local autonomy. Combining diagnostic morphological probes, length-normalized Domesticating Bias Scores (DBS), and blind human ratings verified that the specialized model actively prefers sovereign community vocabulary over colonial Spanish substitutions. 4. Accessible CPU deployment: Merging low-rank adapter weights and ap- plying 8-bit CTranslate2 quantization reduced inference latency from 137.5 seconds down to 1.8–2.6 seconds per request. Widening the beam search to 8 resolved search-space truncations on short lexical inputs, enabling responsive and cost-bounded deployment on serverless CPU infrastructure. 9.1
