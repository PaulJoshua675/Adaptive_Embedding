Direct tool use. Retrieve-then-reason meth- ods (Jiang et al., 2023b; Luo et al., 2024b; Kim et al., 2023; He et al., 2024; Mavromatis and Karypis, 2025; Li et al., 2025b) retrieve reason- ing paths or subgraphs from the KG and reason over them. In KG agents such as ToG (Sun et al., 2024; Ma et al., 2025), the LLM steers a prede- fined beam search over entities and relations, and StructGPT (Jiang et al., 2023a), Graph-CoT (Jin et al., 2024), GoG (Xu et al., 2024) and Plan-on- Graph (Chen et al., 2024a) give it other sets of predefined graph functions. GRA (Dragic et al., 2026) explores hybrid KGs through seven prede- fined Unix-style tools such as ls, cat and grep. Code over a graph interface. Semantic parsing maps a question to SPARQL, an S-expression or a program executed on the KG (Liang et al., 2017; Cao et al., 2022; Li et al., 2023; Gu et al., 2023; Luo et al., 2024a), and Xiong et al. (2024) build these logical forms interactively through knowledge-base APIs. KG-Agent (Jiang et al., 2025) fine-tunes a small model to generate programs that call pre- defined tools. Code-on-Graph (Ding et al., 2026) represents the schema as Python classes and gen- erates code that processes graph objects provided by a subgraph retriever. On STaRK, AvaTaR (Wu et al., 2024a) optimizes the prompt of an agent that composes predefined functions in Python. Agents that create their own tools. Outside KGs, CodeAct agents (Wang et al., 2024a) act through executable Python, and other methods cre- ate tools as code (Cai et al., 2024; Yuan et al., 2024; Wang et al., 2024b; Wölflein et al., 2025). CREATOR (Qian et al., 2023), Self-Debug (Chen et al., 2024b) and PyVision (Zhao et al., 2025) re- fine code using execution feedback. Live-SWE- agent (Xia et al., 2025a) creates tools within a minimal bash scaffold to solve software issues. SMITH (Tam et al., 2026) jointly trains tool cre- ation and use with reinforcement learning and reuses tools across tasks, whereas DKGI is training- free and creates and revises tools within a task. Graph-as-Code (Finkelshtein et al., 2026) itera- tively writes and executes code over a table of node features, neighbor lists and labels for node classification. For entity search over typed, multi- relational KGs, DKGI is to our knowledge the first harness that lets agents implement graph operations over complete node and edge files. 5
