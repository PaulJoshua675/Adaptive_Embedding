If, on average, the ||⟨z⟩||2 is longer than expected, the step size is increased; if shorter, it is decreased. 6. Mean-xNES step-size adaptation (m-XNES) (Krause et al., 2017): This variant modifies the xNES approach by basing the step-size update on the movement of the search distribution’s mean m, rather than aggregating over all offspring. Specifically, the difference between m(g) and m(g+1) scaled by µeff is used to update σ. 7. xNES with log normal prior Step size adaptation (lp-xNES) (Krause et al., 2017): This method follows the principle of self-adaptation by explicitly sampling step sizes for each individual in the population. In each generation, a set of λ trial step sizes, σ ∈Rλ, is drawn from a log-normal distribution centered on the current step size σ(g). Each sampled step size is then used to generate one candidate solution. After selection, the step sizes associated with the top-performing candidates are combined using a log-weighted average κ = w · logσ. The step-size is then updated via σ = σ(1−cs)ecsκ. 8. Self-Adaptation (SA) (Beyer and Sendhoff, 2008): Another self-adaptive operator, this is a weighted version of the operator for the Covariance Matrix Self-Adaptation (CMSA) ES. Similar to the previous method, lp-xNES, the method samples λ individual step sizes σ for each candidate solution from a log-normal distribution centered on the current global step size σ(g). Based on the method from Ahrari et al. (2017) to correct for elitism, the global step size is updated via: σ = σ Qµ j=1 σwi j Qλ j=1 σ1/λ j This method uses a lower µ = ⌊λ/4⌋by default. Note that although several of these methods were explicitly developed for the CMA-ES, a few were not. Specifically, the SA was developed for the CMSA algorithm Beyer and Sendhoff (2008), and the three xNES methods were originally developed for natural evolution strategies. However, as demonstrated in (Krause et al., 2017), they are not incompatible with the CMA-ES. Nevertheless, these mechanisms may overlap in their behavior, potentially introducing unnecessary complexity from an algorithmic configuration perspective (de Nobel et al., 2021). 5.2 Matrix Adaptation As explained in detail in Section 2.1, the main strength of CMA-ES lies in its invariance to affine transformations of the search space, achieved by learning the dependencies between the d variables. This is done by estimating a positive-definite covariance matrix C, which determines the orientation and scaling of the iso-density contours of the mutation distribution to form an arbitrarily rotated and scaled hyper-ellipsoid.
