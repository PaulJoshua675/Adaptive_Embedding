Results cover three DLMs; additional length-prediction diagnostics appear in Section B.4. 4.3 Predicting Target Lengths The preceding experiments assume oracle target lengths, whereas infilling in practice generally requires predicting them. To evaluate the learned-allocation setting of Section 3.1, we train length predictors on structured few-shot tasks and Java edits (Section B.4). On List Functions–Easy, we fix D = 4 and vary J ∈{1, 2, 4, 8} across three DLMs, comparing oracle lengths against sampled predictions with the same content generator and standard infilling (β = 0). Figure 7 reports downstream accuracy and sensitivity to length errors. The learned predictors capture useful information about the required output lengths. They assign 40–46% probability mass to the reference length, compared with approximately 27% for a prior constructed from visible demonstration lengths (Section B.4). This indicates that the compact canvas contains useful predictive information about the missing output lengths. Despite this improvement over the length prior, learned allocation remains a gap for reliable downstream infilling. Sampling predicted lengths retains only 35–48% of oracle-length per-target accuracy (Figure 7, top). To examine this sensitivity directly, we impose offsets Lj = L⋆ j + ∆, where L⋆ j is the reference token length. One-token underallocation harms LLaDA and Nemotron more than overallocation, while dQwen3.5 is sensitive to errors in either direction (Figure 7, bottom). These findings identify accurate length allocation as a remaining challenge for practical multi-target infilling. 11
