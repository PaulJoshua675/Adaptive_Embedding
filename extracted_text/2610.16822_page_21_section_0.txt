E Design Rationale and Parameter Sensitivity DTA-GT uses three structurally defined update paths for the node’s own state, predecessor context, and successor context. The number of experts follows this decomposition of directed computational context. A node-dependent router learns adaptive mixing weights over the three contexts from the current node representation. This allows each node to combine its local state with upstream and downstream information according to the prediction task. The four directional stages provide complementary information throughout the encoder. Node initial- ization represents local directed roles, and Magnetic spectral encoding supplies a global orientation- sensitive prior. Structural attention organizes interactions by directed node-pair relations, while the MoE-FFN adapts each node update to its self, predecessor, and successor contexts. Together, these stages preserve computational direction from the input representation through pairwise interaction and feature updates. Source and branching nodes distribute information along downstream paths, whereas converging and sink nodes summarize upstream computation. These roles motivate separate predecessor and successor contexts, with the learned gate adapting their relative contributions at each node. The routing diagnostics in Appendix B examine how these weights vary across node roles and prediction targets. Baseline sources and reproduction strategies are described in Appendix A.
