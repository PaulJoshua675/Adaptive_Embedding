In our implementation, this advantage is formed from the full-set surrogate reward ˆR0(A(g)). Given action credits {c(g) i }m i=1, we first center them within each rollout: d(g) i = c(g) i −1 m m X j=1 c(g) j , m X i=1 d(g) i = 0. (11) We then normalize the centered credits using a scale shared across the rollout group: sd = Std  {d(g) i }i,g  , u(g) i = d(g) i sd + ϵ, (12) where ϵ > 0 is a numerical stabilizer. Using a common scale avoids separately normalizing away between-rollout differences in relative-credit magnitude before projection. To bound the action-level adjustment while preserving its zero-sum structure, we project u(g) onto Zκ = ( z ∈Rm : X i zi = 0, ∥z∥∞≤κ ) . The Euclidean projection has the coordinate form z(g) i = clip  u(g) i −λg, −κ, κ  , X i z(g) i = 0, (13) where κ > 0 is the clipping radius and λg is obtained by monotone bisection. Appendix C gives the projection derivation. The resulting action-level advantage is eA(g) i = ˆA(g) + βz(g) i , (14) where β ≥0 controls the strength of credit-aware shaping. Since P i z(g) i = 0, 1 m m X i=1 eA(g) i = ˆA(g). (15) Thus the shaping term changes relative action-level coefficients while preserving their within-rollout mean. This does not imply equality with the broadcast policy gradient, because different action spans multiply different score functions. Setting β = 0 recovers the Broadcast advantage assignment. For structured generations, tokens belonging to action qi receive eA(g) i , while shared reasoning and formatting tokens retain the base rollout advantage ˆA(g). We treat this as structured advantage assignment rather than causal token attribution. 3.5 COMPUTATIONAL COST All methods use one LLM generation and m cached retrievals; they differ in the number of frozen- evaluator scores required for credit construction. The empty coalition is fixed by convention and is not scored.
