A MIDTRAINING DATA This appendix documents every source in the blend, including how it is collected, filtered, and weighted, and Appendix B lists the full training settings. We plan to release data-processing scripts and training-set metadata in a future version. A.1 ISSUE–PR For PRs linked to an issue, an LLM judge checks whether the issue and the PR match. The judge reads the full issue and PR text, the final patch, and the paths of the changed files, and labels each pair as clean or assigns one of seven failure modes, namely a revert, an incidental issue link, a wrong issue reference, a partial fix, an issue with no clear action, an underspecified issue, or a PR that does much more than the issue asks. We keep clean pairs and remove pairs that cannot be fixed. We repair the others by linking the PR to the correct issue, narrowing its scope, keeping it as a PR-only example, or splitting it from unrelated changes. For PRs without a linked issue, we remove those that change only README files or three lines or fewer. A.2 REPOSITORIES The repository data starts from the code repositories in the Nemotron 3 pretraining corpus (NVIDIA, 2025), a deduplicated collection of public repositories with permissive licenses, and covers 14 lan- guages (Table 12). Connectedness. For each language, we parse the references that link one file to another, such as imports in Python, includes in C and C++, and module paths in Go. A repository’s connected fraction is the share of its code files that import another file in the repository, and we keep repositories where this share is at least 20%. For Ruby we lower the threshold to 10%, because Rails autoloading hides most references from static parsing. We exclude languages with little cross-file structure that parsing can recover, such as Shell, R, and Swift, as well as markup and configuration languages. Serialization. The code files follow the README in depth-first order over the import graph, so the files of each connected component stay together and each file sits near the files it imports.
