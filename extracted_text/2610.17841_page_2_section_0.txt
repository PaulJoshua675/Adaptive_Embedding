Overview of FASHION-RQ. The framework leverages an RQ-VAE hierarchy to automatically generate natural-language queries and graded relevance sets, with Exact, Sibling, Related, and Irrelevant relationships. The resulting benchmark supports four complementary retrieval tasks, while weighted query relevance and attribute-level metrics evaluate overall intent satisfaction and fine-grained attribute matching. fix form increasingly specific groups. We repurpose this structure not as an index for retrieval, but as an automatic annotation mechanism. However, vanilla RQ-VAE does not guarantee that a code corresponds to a single seman- tic attribute, which can produce heterogeneous clusters. We therefore introduce an attribute exclusivity loss that encour- ages each quantization level to specialize to a coherent at- tribute, making the resulting hierarchy suitable for defin- ing relevance sets. A prefix then defines a relevance set, its length controls granularity, and the shared-prefix length between an item and the target prefix provides graded rele- vance without a hand-authored taxonomy. Building on this hierarchy, we filter clusters that are too small or heterogeneous to serve as relevance sets and com- pute each retained cluster’s relational context: the attributes that distinguish it from its parent and sibling clusters. A language model then verbalizes this structured evidence into shopper-style queries. Importantly, the language model generates the query but does not determine relevance; rel- evance is inherited deterministically from the semantic ID (SID) [32] structure. We instantiate this framework on the public Myntra Fashion Product Images catalog [2], containing 44,446 items, and construct FASHION-RQBENCH: 588 clus- ters across three granularity levels and 5,380 attribute- enriched queries. The benchmark provides four comple- mentary tasks: query–product ranking, hierarchical rele- vance classification, sibling discrimination, and paraphrase robustness. We additionally introduce a weighted query- relevance score and per-attribute scores to distinguish over- all retrieval quality from fine-grained attribute satisfaction.
