Together, this context is either available as a prior (e.g. through existing game-specific runs across models), or gathered post-hoc by observing the game outcome ξi,t at the end of each round. Traditional routing and sampling methods fail to make best use of this context. Existing methods either encode the entire context (e.g. game instructions, history) as a whole, as form of vector embedding (RouterDC), without an underlying form or structure, or rely entirely on the observed game outcome (Thompson Sampler) with no regard to the strategic scenario (captured by the game instructions) we are dealing with. A better selector should infer game-specific strategic cues, and map selection choices to their implications for future game states. It should build an understanding of the performance of its own portfolio models, and the opponent under the current scenario. 5.2 Games as Strategic Testbeds We saw that best-performing models vary noticeably across the 5 evaluated games, each setup capturing a particular strategic scenario (a model-to-model interplay) (Table 2). Moreover, an observation can be made that games vary in difficulty (i.e. complexity). For example, one can say that identifying the equilibrium strategy would require higher model reasoning capabilities in a game like Cournot Duopoly (an economic profit game) than in Colonel Blotto, which relies on a simple per-battlefield resolution rule (the larger number wins). Empirically, this idea is reflected in the correlation between model scale and performance, which is the highest in Cournot Duopoly (Pearson’s r = 0.66), and much lower in games like Stag Hunt (r = 0.12) and Colonel Blotto (r = 0.24) (Figure D.3). Mathematically, there are an infinite number of normal- and extensive-form games that range in complexity and the strategic interplay captured.
