Validation-set loss was used as the optimization objective; Area under the receiver operating characteristic curve (AUC) was excluded, as it saturated on the small validation split before the model converged. The optimized configuration was then evaluated via five-fold cross- validation. Once the final models were trained, attention weights and per-patch scores were computed across all tumor cases in a single forward pass. Because tumor is spatially contiguous whereas isolated high-scoring patches usually reflect noise, scores were averaged over each patch's 3×3 grid neighborhood before ranking. From these smoothed scores, we reconstructed the top spatially coherent 2×2 (1024×1024-pixel) and 4×4 (2048×2048-pixel) squares per case. FAISS index The database indices were built per FM using FAISS (25). Per-patch embeddings were first concatenated into a single matrix together with a parallel array of patch identifiers for metadata mapping. Each embedding was L2-normalized to unit length so that inner-product equals cosine- similarity. We used an IVFPQ structure, which combines two complementary approximations. First, an inverted file index (IVF) partitions the embedding space into √N Voronoi cells whose centroids are learned by k-means; at query time only the cells nearest a query are scanned, avoiding an exhaustive comparison against every vector. Second, product quantization (PQ) splits each vector's residual from its assigned centroid into M contiguous sub-vectors. Each sub-vector is then replaced by its nearest centroid index from a learned 256-entry subspace codebook. The sub- vector length is held constant at 16 dimensions across all FMs so that quantization granularity remains comparable; M is set accordingly yielding a fixed 64× compression ratio (24 for Atlas2- S, 48 for Atlas2-B, 96 for UNI2h, and 128 for Atlas2). Both the IVF centroids and the PQ codebooks were trained on a random subsample of the corpus (50×√N, >100,000) before the full set was added in batches. Vectors were inserted with sequential integer IDs equal to their row position, so a single metadata array maps each FAISS ID directly to its filename. Retrieval A query region is either sourced by our ABMIL model or by a pathologist. For a query, capture magnification and scanning specification (magnification and MPP) need to be specified. The scanning MPP defines the physical tissue area represented by one pixel at the original scan resolution; multiplying it by the ratio of scanning to capture magnification yields the effective tissue-per-pixel of the query image. This ensures that query and database patches represent tissue at the same physical scale prior to embedding. The query region is divided into non-overlapping 512 × 512-pixel patches and embedded by a FM, yielding n descriptors, each L2-normalized to unit length. These n descriptors are pooled adaptively to avoid diluting distinct morphologies while still consolidating redundant ones. If the pairwise cosine similarity is above 0.8 the query is treated as homogeneous and all descriptors are averaged into a single re-normalized query vector. For a heterogeneous query, the descriptors are greedily clustered: proceeding through the descriptors in order, the first seeds a cluster and every remaining within 0.8 cosine similarity of that seed is merged into it, and the cluster mean is re- normalized to a query centroid; the pass repeats until all descriptors are assigned. The number of queries equals the number of clusters formed, between one and the descriptor count. The threshold, governing both the homogeneity gate and cluster merging, is tunable.
