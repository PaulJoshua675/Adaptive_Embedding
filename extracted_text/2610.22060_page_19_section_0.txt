PSNR and SSIM compare each reconstruction with its input pixel by pixel, so they penalize small shifts of texture and detail that humans barely notice, and they correlate poorly with human perceptual judgments (Zhang et al., 2018). Distribution-level metrics instead ask whether the images look like real images, and they favor feature supervision. Feature targets improve rFDr6 for three of the four encoders, and the same feature-supervised tokenizers give lower gFID in the controlled ablations (Tab. 11), the best gFDr6 among discrete generators (Tab. 1), and higher human-preference reward-model scores (Fig. 5). The lower paired pixel fidelity is therefore a trade-off rather than a free improvement. Feature-supervised tokens discard some input detail, and not all of it need be perceptually irrelevant, but for generation the trade-off favors feature supervision in the distribution-level and reward-model evaluations above. C.4 Token Structure Measurement Spatial-dependence diagnostic. The spatial dependence in Fig. 3b measures how informative one patch token is about an adjacent patch token in the same image. Rather than estimating MI between complete categorical token IDs, we use a component-wise proxy based on the tokenizer’s binary code representation. Each patch token is represented by 16 bits. For each pair of patch positions at a given offset, we estimate the MI, in bits, between pairs of these bits from their joint occurrence frequencies across 25K class-balanced ImageNet training images. We average these estimates over the 256 bit pairs, over all position pairs of the offset, and over the four cardinal directions.
