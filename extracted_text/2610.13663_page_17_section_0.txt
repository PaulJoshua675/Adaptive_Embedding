PINN results: single soliton The first PINN problem (GNLSE, 𝛼= 0.1, 𝛽= 0) has an analytical solution and therefore provides a transparent test of the framework: the agent can embed the explicit form of the one-soliton solution in the 𝐹𝐼, 𝐹𝑂blocks, and the resulting metrics reflect the correctness of such a “hinted” representation rather than an independent search for a nontrivial technique. The results are summarized in Table 5. Because each agent run includes its own three-seed identity baseline, each reduction factor is calculated against the baseline from the same run. The best Claude Opus 4.6 hypothesis gives Relℎ= 2.21 ⋅10−5, a 2491-fold reduction from 5.51 ⋅10−2. The best sonar-pro hypothesis reduces Relℎfrom 4.69 ⋅10−2 to 1.97 ⋅10−4 (238×), while Qwen3-30B-A3B-Instruct-2507 reduces it from 4.85 ⋅10−2 to 8.86 ⋅10−3 (5.48×). Because the problem permits substitution of the analytical formula, these figures should not be interpreted as a measure of a complex search; the substantive test is deferred to the second problem. The best sonar-pro configuration is tw_nonlinear_pinn_core. Its 𝐹𝐼supplies a normalized traveling-wave coordinate, normalized time, and a local nonlinearity-density feature; 𝐹𝑂uses the analytical traveling-wave amplitude and phase and interprets the MLP outputs as bounded amplitude and phase corrections. The best Claude Opus 4.6 configuration, PCDS-LCC-EXP-NLOG-MIXCROSS, uses seven analytical features, including normalized and logarithmic envelopes and two amplitude–time cross-features, while 𝐹𝑂applies time-gated exponential amplitude and additive phase corrections with separate envelope weights. The best Qwen configuration, LogPhaseHybridNorm, normalizes the analytical soliton coordinate at the input and reconstructs the field from the analytical amplitude and carrier phase multiplied by learned complex corrections. Thus, all three best configurations exploit the known soliton structure in both the representation and the reconstruction. A detailed analysis of the hypotheses is provided in Appendix C. 5.5.
