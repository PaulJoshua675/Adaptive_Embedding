This comparison separates how much specialization is visible from how readily it changes. We use latent susceptibility for a specific response pattern: learners matched on selected endpoint measurements respond differently to the same subsequent learning intervention. The term names the response property, including its time course, not its cause. Formation history is a candidate cause. To test one source of the short-horizon difference, we intervene on optimizer state: information retained from earlier gradients by the algorithm that updates model weights. This separates the observed response pattern from a causal account of which persistent components modify it and when. The paper follows three questions. What selects and redirects the favored target? What presently supports a formed specialization? What determines the response of learners that appear similar under selected measurements? Each question requires a different counterfactual comparison. We study formation by copying one checkpoint and changing only acquisition or update allocation, current support by changing those condi- tions after specialization has formed, and latent susceptibility by matching selected endpoint measurements before applying the same next intervention and exchanging candidate persistent-state components. Small shared-representation networks make these comparisons possible because saved learners, experience sequences, optimizer components, and complete trajectories can be controlled across conditions. The results connect each question to an intervention. Acquisition and updating are competing controls over specialization; formation and current support can be separated; and optimizer condition changes when route-dependent responses become visible. Under a long common opposing condition, the selected allocation endpoints become similar. The following sections develop the comparisons supporting these conclusions. 2 Experimental approach: measuring and intervening on specialization An unequal endpoint does not identify why the inequality formed. A learner may encode one target more accurately because that target was observed more precisely, because its error received more update weight, because limited capacity forced competition, or because a feedback loop kept supplying experiences consistent with the existing allocation. Comparing separately trained learners would confound these possibilities with initialization and data-order variation. We therefore construct counterfactuals from the same saved learner and change one part of the learning process at a time. The shared bottleneck makes the allocation problem observable. The targets can improve jointly early in training, but beyond a capacity-determined floor, further improvement in one target can trade off against improvement in another. Acquisition interventions change the quality of target information while normalizing input variance, whereas update interventions change how reconstruction errors enter the loss. Evaluation then uses common held-out inputs, so a measured allocation difference cannot be attributed merely to giving one condition an easier test set. After formation, we either remove or symmetrize the current learning conditions to distinguish formation from present support. For the susceptibility question, we additionally match selected endpoint measurements, apply the same future pulse, and exchange optimizer components while holding model weights fixed. The systems are deliberately small not as miniature substitutes for natural learners, but because these causal comparisons require checkpoint-level control that is difficult to obtain in larger observational settings. 2.1 A shared bottleneck and two kinds of selection The central experiment asks a model to recover two artificial signals, A and B, from noisy observations. Each signal contains three numbers. An encoder transforms the six observed components into a code containing only two numbers; two separate linear predictors, or readout heads, use that same code to reconstruct A and B. This narrow intermediate layer is the shared bottleneck. The signals contain both correlated and target-specific information: we generate standard Gaussian A and independent Gaussian ϵ, and set B = ρA + p 1 −ρ2ϵ with ρ = 0.35.
