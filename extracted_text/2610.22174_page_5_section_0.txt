Mosaic: Multi-Session Agentic Reinforcement Learning • C1: For successful trajectories, using more sessions incurs a higher execution cost and hence results in a lower advantage, whereas using fewer sessions should result in a higher advantage. • C2: For unsuccessful trajectories, using fewer sessions may suggest insufficient exploration or execution, especially on challenging tasks, and should thus result in a lower advantage. Conversely, unsuccessful trajectories that conduct more sessions should receive a higher advantage. • C3: Task outcome reward must remain the dominant signal. When two trajectories have the same session counts, the trajectory with lower reward should receive a lower advantage. Using more sessions alone should not allow an unsuccessful trajectory to outrank a successful one. Together, these constraints encourage the policy to use enough sessions to complete the task, but no more than necessary, which represents a desirable objective for multi-session agentic RL.
