In practice, this assumption is enforced by imposing a maximum response length. 1.2 Token generation as a Markov decision process The token generation process can be modeled as an undiscounted indefinite-horizon Markov decision process (MDP). Let the state space S consist of sequences of tokens whose prefix is a valid prompt, and the action space A be the space of tokens. The idea is to use the state to store the prompt and all the tokens generated thus far, and to use the action to represent the next generated token: st ≜(x, y<t), at ≜yt. The initial state is chosen as s0 = x. At time t, the action at is determined by the policy as at ∼π(· | st). The transition dynamics are deterministic: st+1 = (x, y≤t) is the concatenation of st and at unless at = EOS, the end-of-sequence token. If at = EOS, the next state st+1 becomes an absorbing state associated with no reward. The original reward function R induces a token-level reward r: S × A →R. During token generation, if at = EOS, then r(st, at) = R(x, y≤t), where y≤t denotes the completed response including the terminal EOS token, so that |y| = t + 1; otherwise r(st, at) = 0. In other words, the reward is sparse and assigned only at the last decoding step.
