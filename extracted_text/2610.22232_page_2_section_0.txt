In this paper, we argue that the accuracy of probability modeling is determined not only by the modeling capacity of the entropy model itself, but also by the predictability of its input. In other words, better entropy coding should not be attributed solely to a stronger model. It also requires an input representation that is more structured, more homogeneous, and thus easier to predict. When heterogeneous signal patterns are entangled within a single sequence, the entropy model must continuously adapt to sharply different statistical regimes, which makes accurate probability esti- mation intrinsically more difficult. By contrast, when the input is reorganized into simpler components with clearer statistical regu- larity, the same model can solve a substantially easier prediction problem. Based on this insight, we propose to perform probability predic- tion and entropy coding in the wavelet domain. As the work most closely related to ours, we compare three LLM-based methods in Fig. 1. The pixel-domain method directly models pixels [5], requiring the entropy model to handle pixel distributions from different fre- quency components. The residual-domain method models residuals instead [8], which reduces the difficulty of probability modeling to some extent. In our method, we first transform the image into the wavelet domain and decompose it into progressively organized fre- quency subbands [6, 26, 34]. This decomposition separates coarse low-frequency structures from directional high-frequency details across multiple resolutions [26, 34], thereby converting a highly het- erogeneous prediction problem into a collection of more structured and statistically homogeneous subproblems. Nevertheless, combining the wavelet domain with an LLM is far from natural. Pretrained LLMs are designed for discrete text tokens, whereas wavelet coefficients are numerical symbols from visual sig- nals. To bridge this gap, we design a dedicated interface that makes wavelet-domain entropy coding compatible with the LLM backbone. Specifically, we introduce a coding-oriented numerical adaptation mechanism that maps wavelet coefficients into a compact local symbol space, equips them with trainable value embeddings, and predicts valid coefficient values through a dedicated value predic- tion head. This design preserves numerical validity while enabling the pretrained LLM to operate effectively on wavelet-domain sym- bols. Another challenge arises from the fact that different wavelet subbands still exhibit distinct statistical characteristics [34, 38]. Training an independent entropy model for each subband would significantly increase model complexity and undermine the practi- cality of LLM-based coding. To address this issue, we further pro- pose a prompt-based adaptive entropy coding strategy, where one shared entropy model is reused across different subbands through task prompts. By conditioning the shared backbone on subband identity and decoded context, the same model adapts its probability predictions to different subband distributions without requiring separate models. In this way, the proposed framework achieves both subband-specific modeling flexibility and parameter efficiency. Building on the above designs, we present WaveLLM, a wavelet- domain LLM-based entropy model for lossless image compression. The contributions of this work are threefold. • We note the importance of input predictability in lossless image compression and decompose each image into multiple wavelet subbands. The resulting subbands have distinct coefficient statis- tics that can be modeled separately. • We design a dedicated interface between wavelet-domain signals and an LLM pretrained on language data. It maps coefficients to compact local IDs, uses a dedicated value embedding module, and predicts valid coefficient values over the local range through a dedicated value head. • We propose a task-prompt mechanism for adaptive modeling of different subbands. By conditioning the shared backbone on sub- band identity and decoded context, WaveLLM adapts to distinct subband statistics without requiring separate models.
