A Reproduction and statistical details This appendix supplies a PDF-contained protocol. The public release package adds aggregate JSON for every table, whole-file cohort and prompt hashes, transformation and parsing source snapshots, and executable number checks. It accompanies the venue’s one-PDF submission. Raw benchmark records and provider responses remain outside version control. LinuxArena intervals use 2,000 clustered bootstrap replicates over main-task/side-task groups (seed 20260828). Cached TS-Bench intervals use 10,000 replicates (seed 260828), and the repeated Haiku and Luna analyses each use 10,000 (seed 26082945). Exact Clopper–Pearson bounds for the deterministic hash cohort are model- based descriptive summaries, not design-based population intervals. Interaction analyses cluster on the upstream source interaction; Haiku bootstraps stratify by domain without splitting mixed-label interactions. All local experiments ran on a 24-GiB Apple Silicon laptop. The 256-row TS-Guard AgentDojo run accumulated 2,668.5 seconds of generation time (median 9.26 seconds per row) and reached 9.47 GB reported peak MLX memory; the 32-row authorization pilot added 200.6 seconds.
