The statistics below come from an early filtered snapshot of 859,176 trajectories. Scaffold labels name the agent interface, not the task domain. For example, a software-engineering task can use shell commands, file-editing tools, or both. We downsample general tool-use data, mainly taubench react, to give more weight to software engineering.
