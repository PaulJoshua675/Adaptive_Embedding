Long-Term Memory for Language Agents. Prior work explores endowing language models with persistent, stateful memory to support continuous operation. For instance, recent works propose to cache conversational histories (Wang et al., 2023; Zhong et al., 2023; Uddin et al., 2026), manage virtual context windows via memory tiers (Packer et al., 2023), and unify short- and long-term memory directly within the agent’s policy (Yu et al., 2026b; Xu et al., 2025). However, these approaches primarily focus on an agent retaining its own historical context. Librarian Agents addresses a different setting, in which the memory is written over an external corpus ahead of time and judged by how well another agent answers from it. Compute Reallocation. Our approach aligns with emerging literature on reallocating computation across time to improve test-time scaling (Lin et al., 2025; Wu et al., 2026; Yan et al., 2026; Yu et al., 2026a; Li et al., 2026a). Other approaches formalize test-time compute optimization as meta- reinforcement learning optimization to adaptively allocate tokens (Qu et al., 2025b) or utilize self- curated test-time curricula to reinforce successful strategies (Hübotter et al., 2025). To our knowledge, Librarian Agents is the first to treat corpus organization as a policy optimized for downstream answers, training a builder to do once what an answering agent would otherwise repeat for every query. Our hyperparameters explicitly control how construction cost and query-time cost are weighed against answer accuracy. 4. Discussion, Limitations, and Future Work We study the capability of anticipatory directed curation, in which agents can proactively reorganize their context into a memory artifact optimized for future queries they encounter. To instantiate this capability, we rely on an asymmetry for agents today, where agents are trained to navigate a filesystem for a given task, yet do not pre-construct workspaces for future queries that they might encounter. Our novel framework, Librarian Agents, introduces a builder agent that creates a synthetic filesystem that an answering agent can navigate. Librarian Agents yields consistent improvements on BrowseComp-Plus and BRIGHT, outperforming existing retrieval methods on both in-domain and out-of-distribution evaluations. Our evaluation is limited to question answering over static corpora, and maintaining anticipatory memories as documents change remains an open problem. The builder agent also operates over a large file context, which may limit scalability, though pairing Librarian Models with clustering or retrieval could extend the framework to larger domains. Since no finite set of synthesized artifacts can anticipate every query, compression may discard details needed for needle-in-a-haystack tasks; we preserve reference links for fallback access, but deciding when to bypass the synthetic filesystem remains a challenge. A natural extension is a filesystem that updates from its own traffic, treating each answered query as evidence of what the next reader will need. Future work could also let the builder compose atomic filesystem commands, of which its current four actions are special cases. 5.
