Our analysis will show that jointly optimizing these tasks allows the runtime for OJZJ to be reduced to the same order as that for OMM alone. 4.1 Two-Task (OMM, OJZJ) Problem Here we formally define the two-task (OMM,OJZJ) problem (Definition 6). The OMM benchmark is a classic bi-objective problem where the two objec- tives conflict, seeking to maximize the counts of zeros and ones, respectively. The OJZJ benchmark introduces multimodality: its first objective is a Jump function with gap size k on the number of ones, and its second is a mirror Jump function on the number of zeros. Definition 6. Let n ∈N and k ∈[2..n]. For any X ∈{0, 1}n. The two- task problem (OMM,OJZJ) is to simultaneously maximize f 1 = (f 1 1, f 1 2) : {0, 1}n →R2 and f 2 = (f 2 1, f 2 2) : {0, 1}n →R2, where f 1 1(X) = |X|1, f 1 2(X) = |X|0, and f 2 1(X) =    k + |X|1, if |X|1 ≤n −k or X = 1n, n −|X|1, else, f 2 2(X) =    k + |X|0, if |X|0 ≤n −k or X = 0n, n −|X|0, else, for any X ∈{0, 1}n. From Definition 6, we see that OJZJ and OMM share a similar landscape in the inner part as well as two extremes, that is, for solutions with the number of ones in [k..n −k] ∪{0, n}. From [GL10, DZ21], we know that the Pareto set is {0, 1}n for OMM and {X ∈{0, 1}n | |X|1 ∈[k..n −k] ∪{0, n}} for OJZJ, the Pareto front is M 1 = {(a, n −a) | a ∈[0..n]} for OMM and M 2 = {(k + a, n + k −a) | a ∈[k..n −k] ∪{0, n}} for OJZJ, and the maximal size of the set of incomparable solutions is M 1 = n + 1 for OMM and M 2 = n + 1 for OJZJ. 4.2 Runtime Analysis In the following lemma, we give an estimate on the scalar fitness of an indi- vidual associated with a Pareto front point that has at least one of its Pareto 13
