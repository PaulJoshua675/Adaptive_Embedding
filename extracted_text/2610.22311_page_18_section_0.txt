A global Gilbert query block can cross latent-frame boundaries, so Velox first divides it into frame-local rectangular fragments. For fragment Bi,t, define its valid token set as Vi,t = {u ∈Bi,t | f ⋆ t,u exists}. If the resulting query block does not reach the coverage threshold, the router follows the model-derived path in Eq. (13). Implementation path. The GPU procedure has two logical passes. The first counts valid samples for every source-frame, target-frame, and target-token tuple and selects f ⋆ t,u. The second compacts only winner-frame samples and computes segmented quantiles. This ordering makes the source cache bounded, avoids cross-frame depth mixing, and supplies block-aligned Q-depth without reconstructing the noisy target chunk. The reported configuration uses kwarp = 2 and (plo, phi) = (10, 90). It does not apply the optional source-to-target pose gate or the experimental warp occluder. B.4 RUNTIME PATH AND TIMING SCOPE The measured sparse path is a Triton indexed block-sparse attention implementation, not a Python masking wrapper around dense attention. Queries are reordered once per chunk into the global- aligned Gilbert token order, and KV caches are written directly in that layout so that the hot kernel loads contiguous KV tiles without a per-call host permutation. The kernel supports rectangular current-query versus growing-history attention, consumes the routed block lists produced by the fused-score scheduler, and uses a runtime route-length bound so later chunks do not trigger new compiler specializations. Section D gives the full kernel path. Frustum slab geometry is built asynchronously. After a chunk is decoded, a worker thread on a dedicated CUDA stream updates reconstruction state, records chunk cameras, builds stored frustum slabs, refreshes multiwarp frame caches, and prepares the Velox state for a later chunk while the main stream continues DiT denoising. The implementation uses a two-chunk freshness lag. Chunk c normally consumes geometry through chunk c −2, which is sufficient because frustum slab overlap changes gradually. The worker is the sole writer to the geometry objects. The main stream waits only on a completion event when a future state is needed.
