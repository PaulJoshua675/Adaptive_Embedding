A. Agent Discovery and Routing Large-scale agent ecosystems require mechanisms for dis- covering suitable capabilities from machine-readable descrip- tions [1], [2]. Recent work increasingly frames this problem as retrieval or routing. One approach [12] combines capa- bility announcement with task-driven discovery and scalable indexing. Tool-to-Agent Retrieval [8] embeds tools and parent agents in a shared vector space, while Agent-as-a-Graph [9] combines vector retrieval with explicit graph structure. MoMA [13] and ACE-Router [10] instead study learned routing over heterogeneous models, tools, or agents. These works establish candidate pre-selection as an im- portant scalability mechanism. Our focus is complementary: we formulate candidate-context scalability for Agent Card discovery and propose SSR as a deterministic, training-free, field-derived retrieval mechanism that separates registry-scale retrieval from the compact candidate context presented to the LLM orchestrator. B. Tool and Skill Retrieval under Context Constraints Tool retrieval provides the closest neighboring litera- ture. ToolRet [5] formulates large-scale tool retrieval as an information-retrieval problem, PORTS [6] aligns retrieval with downstream tool selection, ToolDreamer [14] addresses lexical–semantic mismatch, and ToolScope [7] combines tool consolidation with context-aware filtering. Other methods make retrieval adaptive. Dynamic Tool De- pendency Retrieval (DTDR) [15] updates retrieval as the tool- calling plan evolves, ToolQP [16] decomposes requests into iterative retrieval queries, and SkillRet [17] extends retrieval to large libraries of reusable agent skills. Recent work on adaptive shortlist depth [18] further treats candidate count as a decision variable governing the trade-off between retrieval coverage and LLM selection. This literature shows that candidate pre-selection and retrieval-first orchestration are established ideas. Our contri- bution is therefore not the retrieve-then-shortlist pattern itself, but its explicit formulation and systems-level characterization for Agent Card discovery. C. Retrieval Foundations SSR builds on established information-retrieval principles. Sparse methods such as BM25 use lexical matching and term- weighted inverted indexes [11], whereas dense approaches such as DPR [19] and ColBERT [20] learn semantic represen- tations that reduce dependence on exact lexical overlap. RAG [21] illustrates the broader retrieval-first principle of selecting external evidence before language-model generation. SSR does not claim novelty for IDF weighting, sparse retrieval, or inverted indexing. Its specific design derives deter- ministic unigram and bigram signals from capability-bearing Agent Card fields, weights matched signals with IDF, and uses an Inverted Signal Index to restrict scoring to structurally matching candidates.
