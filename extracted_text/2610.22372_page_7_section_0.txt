LIBERO-SinglePref. This suite evaluates single-preference learning and execution. It contains 100 tasks and serves as the foundation for evaluating personalization. LIBERO-PrefScale. This suite evaluates how preference learning scales across demonstrations, tasks, and layouts. It supports controlled analysis of preference acquisition and generalization across tasks and layouts. It contains 100 tasks. LIBERO-PrefConflict. This suite evaluates policy behavior when preferences conflict with other preferences or with the task goal. Preference-preference conflicts pair the same layout and task with mutually conflicting single preferences, while task-preference conflicts pair no-preference task data with task-incompatible preference data. It contains 48 tasks. LIBERO-PrefCompose. This suite evaluates multi-preference learning and preference composition in a controlled two-preference setting. For each aligned layout-task pair, it provides four conditions: no preference, PA, PB, and PA +PB, enabling controlled comparisons for composition and multi-preference learning. It contains 64 tasks. LIBERO-ComprePref. This suite rewrites prompts over tasks from the other suites so the preference must be inferred from contextual language rather than read from a separate explicit field. It includes explicit task-preference mixtures, where key preference words are preserved, and implicit preference reasoning, where contextual cues imply the preference without naming it. For example, “Put both the alphabet soup and the cream cheese box in the basket. Preference: speed up” becomes “Put both the alphabet soup and the cream cheese box in the basket. Guests will use them immediately.” Similarly, “Pick the mug by its handle” is conveyed as “The mug just came out of the microwave—the body is too hot to touch.” ComprePref reuses existing tasks, so its contextual prompts do not add to the 312-task count or the base-suite counts in Figure 2(a).
