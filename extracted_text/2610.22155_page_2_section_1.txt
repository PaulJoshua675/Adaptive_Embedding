Many real-world interactive scenarios require decisions to be made under strict temporal constraints. For example, when purchasing a highly demanded ticket, detecting availability is not enough: an agent must observe the changing interface and act before the opportunity disappears. Such sce- narios require real-time streaming capabilities, where a model continuously perceives an evolving environment and produces timely actions in response to newly arriving information. Recently, a growing family of real-time streaming models, such as GPT-Realtime (OpenAI, 2025) and Gemini Live (Google, 2026a), has begun to make this setting practically possible. In contrast to asyn- chronous models that process inputs only after they are fully received, these models can consume streaming inputs and react to new information with low latency. Unlike previous benchmarks that evaluate models in static environments (Zhang et al., 2026; Tan et al., 2026) where the environment does not continuously evolve, evaluating streaming models re- quires dynamic settings that test whether models can perceive and act effectively under strict tempo- ral constraints. However, existing evaluations of real-time systems largely focus on capabilities such as streaming perception, conversational quality, and interruption handling (Lin et al., 2026; Lu et al., 2026b), with limited coverage of interactive tasks in which actions affect subsequent environment states and delayed execution can change the outcome. We first characterize real-time streaming capability along three complementary dimensions: tem- poral state awareness, adaptive deliberation, and time-aware action selection. These dimensions capture an agent’s ability to track relevant changes and information freshness, adjust deliberation to the available time, and select actions that remain useful when executed. Building on this framework, we introduce Realtime-Bench, comprising 50 interactive game and web tasks in which evolving states and limited opportunities make success depend on both action choice and timing. We evaluate 12 frontier models spanning standard asynchronous models, streaming models and decision models.
