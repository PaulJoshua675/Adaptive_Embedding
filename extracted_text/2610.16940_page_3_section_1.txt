3.1 Metric Spaces and the Doubling Dimension A metric space (X, d) is a set X equipped with a distance function d : X × X →R≥0 satisfying non-negativity, identity of indiscernibles (d(x, y) = 0 ⇐⇒x = y), symmetry, and the triangle inequality. Given a finite dataset S ⊂X, the doubling constant c is the minimum value such that every ball of radius r centered on a point in S can be covered by at most c balls of radius r/2 [6, 37]. The doubling dimension is dimD = log2 c. Crucially, c is a property of the dataset, not of the ambient space: data lying on a low-dimensional manifold embedded in RD can have small c even when D is large. Cover tree query complexity is O(c6 log n), parametrized by c rather than D— this is what makes cover trees effective in high dimensions, unlike KD-trees whose performance degrades exponentially with D. 3.2 Cover Tree Invariants A cover tree is a leveled tree in which each node stores a single data point. Intuitively, each level represents a different resolution: the root sees the dataset at coarse scale, and deeper nodes refine the picture. Three structural invariants govern parent-child relationships (Definition 1 of Beygelzimer et al. [7]): 1. Leveling invariant. Every node p has an integer level(p), and every child q satisfies level(q) = level(p) −1. Each level down is a finer resolution. 2. Covering invariant. Define the covering distance covdist(p) = blevel(p). For each child q of p, d(p, q) ≤covdist(p). No child lies beyond its parent’s covering radius. 3. Separating invariant. Define the separation distance sepdist(p) = blevel(p)−1. For dis- tinct children q1, q2 of p, d(q1, q2) > sepdist(p). No two siblings are too close together. 3
