For an affine normalization γ ⊙N(x) + β, the output unit is the unit of γ, provided that the bias β is assigned the same unit. Activations and transition scales. The rectified linear unit (ReLU) is positively homogeneous and satisfies ReLU(cx) = cReLU(x) for c ≥0. Under the positive rescalings in G, the ReLU output scales by the same factor as the ReLU input, preserving the scalar unit. Standard non-homogeneous activations, including sigmoid, tanh, GELU, and SiLU, require dimensionless argu- ments. The formula for each function contains a fixed transition scale. Changing a unitful input’s units can move the same underlying value to a different part of the nonlinear response curve. Evaluating the nonlinear response at x/s avoids this change because x and s rescale together. Unit-consistent forms are GELUs(x) := xΦ(x/s) and SiLUs(x) := xσ(x/s) with u(s) = u(x).
