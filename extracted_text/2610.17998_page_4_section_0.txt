Based on findings on deep convolutional networks [29], we use the deepest convolutional layer, which provides lower spatial resolution but richer semantic representations and more discriminative saliency maps. 3.2 Experience Packing and Replay We propose an SNN-adapted EPR strategy that uses SAMs to identify and store the most salient image patch instead of the full input. Each buffer exemplar contains the extracted patch, its original coordinates (top, left), the class label, the aggregated SAM heatmap used for selection and optionally a SAM history for offline explanation-drift analysis. For each input, we compute an aggregated SAM heatmap H ∈RHsam×Wsam at the target layer and bilinearly upsample it to the input resolution, yielding Hfull ∈R32×32 for CIFAR images. We then scan the image with a sliding window of size P × P, with P = 24 by default, and compute the saliency score of each candidate patch: s(top,left) = top+P X h=top left+P X w=left Hfull(h, w). (6) During replay, the patch is placed back into a zero-valued canvas of the original input size at its stored coordinates (top∗, left∗). After each task, the memory buffer is updated using a temporary ring buffer Mt of recent samples from the current task. For Task 1, the model computes the SAM heatmap, extracts the most salient patch, reconstructs its padded version, and stores the exemplar only if the prediction is correct or if the ground-truth class appears among the top-3 predictions. For later tasks, the same procedure is applied to new samples, while stored exemplars may optionally be reprocessed with the updated model to track explanation drift. We refer to this EPR-inspired variant [23] as EPR-SP. As an ablation, we also consider BASE-EPR, where the samples in Mt are drawn uniformly at random from the current task training set. At training stage i, the model is optimized using current-task mini-batches Bi ⊂Di and replay minibatches Bmem sampled from the previously stored patches.
