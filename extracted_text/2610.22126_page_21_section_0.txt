Only the first two parents are used regardless of how many parents the node actually has in the DAG; any additional parents receive a true structural weight of exactly zero — this only matters for nodes with more than two parents. If a node has fewer than two parents, this case degenerates to the linear assignment above. Input features are sampled according to these assignments with additive exogenous Gaussian noise. Targets are generated as a random linear combination of a randomly chosen 20% subset of the input features, with added Gaussian noise. The reported metric is the sample-wise Spearman correlation (averaged over 100 samples) between the local attributions and the individual conditional average treatment effects (CATEs), computed either over all input features (Figure F.1) or over root nodes only (left panel of Figure 3). Conditional SHAP is implemented assuming a multivariate Gaussian distribution over the inputs, which allows the conditional distribution of any feature subset to be computed in closed form [Aas et al., 2021]. Background samples are drawn from these conditional distributions. Causal Shapley values directly use the available structural causal model to sample from the interventional distribution implied by the do-operator, avoiding the need for distributional approximations. Specifically, the expectation E[F | do(XS = xS)], (24) which appears in the computation of causal Shapley values, is evaluated by running the structural causal model (including exogenous noise) with features S fixed to xS and all remaining features drawn from the background dataset. The model output is averaged over these background samples. Both methods are implemented using the PermutationExplainer from the shap package [Lund- berg and Lee, 2017] with 10 permutations and 50 background samples. For experiments with 464 or more features, where runtime became prohibitive, these were reduced to 4 permutations and 10 background samples. As a result, the exponential scaling of exact Shapley-value computation is not fully visible in the runtime plot (right panel of Figure 3): maintaining comparable approximation quality at higher feature counts would require increasing, not decreasing, these parameters, so the measured curve underestimates the true asymptotic gap. Both causal integrated gradients and integrated gradients use 100 steps for the Riemann sum and a zero baseline. Causal expected gradients uses 10 random baselines and 10 steps for each baseline. Root-node intuition. The intuition behind the root-node results is best illustrated with a simple example. Consider a model F with two equally contributing features x1 and x2, where x1 fully causes x2 (i.e. x1 →x2 →F, x1 →F): • Conditional SHAP gives R1 = R2, since it does not account for the direction of the dependency and therefore does not preferentially attribute importance to the root node x1. • Causal Shapley values give R1 > R2, since they take into account the direction of the dependency but still attribute some importance to x2, because they consider a situation where x1 is not set to a value, in which case x2 does have an effect on F. • Causal integrated gradients gives R2 = 0, correctly identifying that x2 contributes no independent effect beyond what is already captured by x1.
