The system follows the dominant architectural pattern shared by virtually all contemporary memory systems, Hindsight (La- timer et al. 2026), Mem0 (Chhikara et al. 2025), Ariadne- Mem (Zhu et al. 2026), and commercial agent memory ser- vices alike: (1) extract structured observations from artifacts (documents, emails, meeting transcripts), (2) embed them, (3) retrieve related existing facts via vector search, (4) clas- sify the relationship via LLM (create, update, reinforce, con- flict, or skip), and (5) synthesize into evolving facts with history. This extract-embed-classify-synthesize pipeline rep- resents the current state of the art; despite surface differences in implementation details (confidence stepping in Hindsight, entropy-aware gating in AriadneMem, Add/Update/No-op in Mem0), the core information flow is shared. The specific system is not the contribution; any system implementing this pattern could be substituted. Our goal is to demonstrate what the benchmark reveals about this class of systems, not to evaluate a particular implementation. We adopt a two-layer terminology: observations are static, atomic factual statements extracted from a single artifact (typed into categories such as decisions, commitments, or milestones), while facts are the evolving, synthesized knowl- edge units that the system maintains over time. Observa- tions are immutable once extracted; facts are the persistent memory that gets created, reinforced, updated, or superseded as new observations arrive. Not all observations aggregate into facts: some are too granular or transient (e.g., a one- time action item), and evaluating observations in isolation would only measure extraction completeness and atomicity, not whether the system forms and maintains correct knowl- edge. Other systems use different terms for similar concepts (Hindsight calls atomic extractions “facts” and synthesized summaries “observations”; Mem0 uses “memories” for both layers without distinction), but the underlying two-layer pat- tern, extraction followed by aggregation, is shared. Intrinsic evaluation targets the fact layer, as this is the knowledge state that determines system behavior. Each fact maintains a numeric confidence score (0–1), strengthened by +0.1 per reinforcing observation and ad- justable by the LLM on create, update, or supersede deci- sions. A temporal guard prevents stale observations from overwriting newer knowledge: if an observation is older than the matched fact’s last update, update and supersede deci- sions are automatically downgraded to reinforce. Facts track a full chronological history (statement, confidence, change type, and trigger observation at each step), enabling intrinsic evaluation to inspect the complete evolution path. The sys- tem additionally tracks the number of distinct contributing authors per fact, counting unique contributors across support- ing observations, which enables C6 (multi-author) evalua- tion. Retrieval uses hybrid search combining BM25 (Robert- son and Zaragoza 2009) keyword matching (weight 0.3) with k-NN vector similarity (weight 0.7) over 1024-dimensional embeddings. All LLM classification and synthesis calls use temperature 0 for deterministic outputs; remaining variance across runs comes from the embedding retrieval layer. The system runs on cloud-hosted LLM APIs for both extraction and synthesis (prompts and models in Appendices B, D). Across all 30 trajectories (Table 3), the mean absolute divergence between intrinsic and extrinsic evaluation is 0.168 ± 0.025 (over 16 percentage points), with 44% of trajectories exceeding the τ = 0.15 threshold (N=11 runs). Using a stricter pass/fail criterion (≥0.5 vs. <0.5), in 21±4% of trajectories one eval- uation method passes while the other fails, meaning a practi- tioner relying on extrinsic evaluation alone would reach the wrong conclusion about system correctness in roughly 1 out of 5 cases (Cohen’s κ = 0.118, barely above chance), con- firming the two evaluation methods carry largely independent signal. A Pearson correlation between intrinsic and extrin- sic scores across all 330 paired evaluations is r = 0.423 (p < 10−15), so r2 ≈0.18: only 18% of the variance in one score is explained by the other, 82% independent. The signed mean divergence is +0.118 ± 0.029, indicating in- trinsic scores are systematically higher than extrinsic: the system’s memory is on average better than what QA evalua- tion reveals.
