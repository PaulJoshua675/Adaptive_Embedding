These results support the effectiveness of the proposed task prompt. 4.4.2 Numerical Interface. Using the native Llama vocabulary in place of the value interface increases the rate by +0.07/+0.08 bpsp (row c). Neighboring coefficients may map to distant token IDs, and language-trained embeddings introduce a domain gap. The native 128K vocabulary also defines a less compact probability space. The proposed local value interface avoids these issues and yields more stable coefficient modeling. 4.4.3 Context Design. We test two context variants: same-level 𝐿𝐿𝑙only (row d, +0.03/+0.06 bpsp on Kodak/CLIC.pro) and same- level plus parent HF bands (row e, +0.23/+0.27 bpsp). Using only 𝐿𝐿𝑙causes a small loss because it provides most of the useful low- frequency context. Adding parent-level HF bands is more harmful, likely because the longer sequence weakens local attention and the coarser scale is less aligned with the target statistics. These results support the current design based on same-level decoded context. 4.4.4 Low-Frequency MED Residuals. Omitting MED residual cod- ing for 𝐿𝐿4 (row f, +0.01/+0.03 bpsp on Kodak/CLIC.pro) causes a small but consistent loss. Figure 5 shows that 𝐿𝐿4 itself contributes only about 0.016 bpsp to the Kodak01 total rate.
