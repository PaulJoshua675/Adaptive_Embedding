The learning rate is linearly warmed up over the first 10% of training steps and then follows a cosine decay schedule. The default DTA-GT model uses embedding dimension d = 180, backbone depth L = 10, and loss weights λmse = 1, λrank = 0.2, and λaux = 0.001. This default configuration was set a priori by following the model scale and optimizer choices commonly used in closely related Transformer-based predictors, including NAR-Former [14], NAR-Former V2 [15], and NN-Former [16]. We use the same configuration across all tasks and budgets without task- or budget-specific tuning. The shared configuration is (q, k, L, d) = (0.25, 4, 10, 180) for both benchmarks, both prediction targets, and all reported NAS training budgets. The q sensitivity experiment is reported alongside the Magnetic mechanism analysis in Appendix B.1 and Table 6. That experiment and the k, L, and d experiments below assess sensitivity around the configuration fixed a priori; we retain the same defaults for the main comparisons without task- or budget-specific parameter selection. Each experiment changes one parameter while keeping the remaining settings fixed. We evaluate k ∈ {1, 2, 4}, L ∈{4, 7, 10, 12}, and d ∈{150, 180, 210} under the lowest training budget of each task. E.1 Retained Spectral Modes After decomposing the Magnetic Laplacian, we order the eigenvectors by ascending eigenvalue and retain the first k low-frequency modes, giving Pmag ∈Cn×k. Each retained mode contributes real and imaginary channels that preserve its orientation-dependent phase information, and the spectral aggregation module combines the resulting k components into the node representation. The parameter k therefore controls the resolution of the global spectral basis together with its storage and aggregation cost. We use k = 4 as a compact basis for the evaluated architecture graphs and compare it with k = 1 and k = 2 below. E.2 Model Depth and Width The encoder depth L and hidden dimension d form the two standard model-scaling axes considered in our controlled sweeps. The former changes the number of stacked directional encoder blocks, while the latter changes the width of node states and learnable projections. Both parameters affect representational capacity and computation, and we vary them one at a time while keeping the remaining configuration fixed. Depth. Each DTA-GT encoder layer composes direction-dual structural attention with the node- adaptive self, predecessor, and successor context update. The depth L therefore determines how many times pairwise structural interaction and direction-sensitive feature updating are repeated before graph readout.
