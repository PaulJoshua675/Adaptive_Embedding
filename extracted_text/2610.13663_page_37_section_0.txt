Methods from different classes may be combined. **All** methods are implementable using pure NumPy. ↪ ### 1. k-Nearest Neighbors (kNN) For each test example, find the k nearest neighbors in train_spikes and assign the class by voting. Metrics: Euclidean, Manhattan, Chebyshev, and inverse-distance-weighted voted (1/d). ↪ **Tip:** Apply Z-normalization before classification and select k using leave-one-out validation on the training data. ↪ ### 2. Mahalanobis Distance Calculate class centroids and covariance matrices, then assign each example to the class with the minimum Mahalanobis distance. Implementable in Numpy via `np.linalg.inv` (or `np.linalg.pinv` for robustness). ↪ **Tip:** Apply ridge regularization `Cov_c + eps * I` with eps ~ 1e-4...1e-1. You may also use a pooled covariance matrix instead of the class-specific one. ↪ ### 3. Naive Bayes (Gaussian NB) Estimate \mu_c and \sigma_c for each neuron and class. Calculate the log-likelihood of each class as the sum of log-Gaussian probabilites, then select the class with the highest log-posterior using argmax. ↪ **Tip:** Apply variance smoothing: \sigma^2 = max(\sigma^2, \epsilon). ### 4. Discriminant Analysis (LDA / QDA) LDA: general covariance matrix + linear discriminant functions. QDA: class-specific covariances. Fisher LDA: projection onto the axis of maximum interclass variance. All variants can be implemented using NumPy linear algebra. **Tip:** For LDA, solve the generalized eigenvalue problem S_w^-1 @ S_b for example using `np.linalg.eigh`. ### 5. Prototypes / Centroids Calculate a centroid for each class, then assign each example to the class with the minimum Euclidean or cosine distance. ↪ Options: L1/L2 normalization, weighted centroids, and median centroids for robustness.
