(2) Throughout, x and z denote arbitrary image views; the arguments of a kernel deter- mine whether each view comes from the support or query collection. Let Kg(x, z) = kβg(g(x), g(z)). Evaluating a kernel on two ordered collections gives the matrix of all pairwise similarities. The matrix Gg = Kg(S, S) records similarities among support entries, while Hg = Kg(Q, S) links queries to support entries. We solve a linear system for the coefficient matrix αg, which has one coefficient per support entry and class. The matrix Gg accounts for relationships among the support entries, so their coefficients are determined jointly. Multiplication by Hg transfers the fitted corrections to each query. With regularization parameter λ > 0 and identity matrix IN ∈RN×N, αg = (IN + Gg/λ)−1RT, Fglobal(Q) = F0(Q) + Hgαg. (3) Thus Hgαg supplies the class-score adjustment added to the CLIP prior. The solve has an equivalent quadratic characterization: it keeps the coefficients close to the support residual target while penalizing the squared kernel-space norm of the correction. This penalty couples the coefficients through Gg, yielding the linear system in Eq. (3). Since (IN + Gg/λ)−1 = λ(Gg + λIN)−1, λ controls both regularization and correction amplitude. All branches use this parameterization with the unscaled CLIP prior. 3.2.
