Method Given a page image, its reference document, and a set of sampled full-page outputs, P2TPO assigns a single coefficient to each generated token. Reference alignment identifies corresponding elements across outputs. UAP converts matched and missing outcomes into element coefficients; SCR redistributes eligible matched coefficients within their generated blocks, while whole-element omissions use a separate boundary route. These local terms combine with a shared page coefficient and enter the policy update. Generation and policy updates retain full-page autoregressive conditioning. 2.1.
