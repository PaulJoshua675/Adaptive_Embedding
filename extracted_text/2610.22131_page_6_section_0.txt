Calibration test set construction This evaluation-only test set measures whether the model assigns appropriate probabilities to all possible outcomes of a stated random experiment. For example, a fair die requires probability 1/6 on each real face and zero on impossible faces. Selecting one plausible face does not establish a correct predictive distribution. Similarly, the Monty Hall questions ask where the prize is, with doors as outcomes; they do not ask whether switching is the best action. The set is constructed from 24 mechanism families in six categories. Each family has two settings, which vary numerical parameters or the observation protocol. Each setting is emitted with canonical and reversed option order, yielding 6 × 4 × 2 × 2 = 96 cases, 16 per category. The two order variants share the same state, question, and reference distribution. There are therefore 48 paired settings rather than 96 independent trials. Appendix C gives the family inventory and concrete input/reference examples. For each setting, a deterministic Python generator specifies the sample space, priors, independence assump- tions, and observation or selection mechanism. It computes the exact distribution using rational arithmetic: counting and enumeration for finite outcomes, conditional-probability formulas for observed evidence, a forward recursion for hidden states, and combinatorial or dynamic-programming calculations for sequential processes. References are not Monte Carlo estimates or model-generated answers. Construction checks enforce probabilities in [0, 1], an exact sum of one, matching option keys, unique IDs, and equivalent reversed-order pairs. Rebuilding from the archived generator reproduces the evaluated input and reference files byte for byte. Inputs contain only the state and typed questions.
