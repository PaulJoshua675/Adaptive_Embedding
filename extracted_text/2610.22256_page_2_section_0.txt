Caching ReLU activations for backpropagation is expensive: most entries are exact zeros, and every stored value carries a redundant sign bit. BitSparse caches only the nonzero values and reconstructs them with optimized Triton kernels. We present BitSparse, a GPU-native format for lossless compression of sparse activations using a bitmask and compact nonzero values. Custom Triton kernels compress activations during the forward pass and reconstruct them as needed during backward. A shared value buffer avoids host synchronization. BitSparse supports the ReLU and ReLU2 activations with optimized kernels for minimum overhead. Figure 1 illustrates the approach. Our contributions are: • A GPU activation-storage scheme for ReLU and squared ReLU, with tile-parallel reconstruction, integration into feed-forward backpropagation and a preallocated buffer to avoid host synchronization. • An information-theoretic analysis of sparse activation storage, together with compression ratios and break-even sparsity thresholds for the implemented representation. • Evaluations spanning activation sparsity, codec throughput, MLP comparisons, and language-model for- ward/backward workloads. BitSparse reduces peak allocated memory by up to 48% in an MLP, and reduces the memory per token by approximately 31% for Modded-NanoGPT and 30% for Nemotron-H, with minimal runtime overhead. 2
