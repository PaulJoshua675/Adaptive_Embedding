All statistical tests used α = 0.05, with Holm correction applied within each family of comparisons; the composition of each family is stated at the relevant test below. We compared FMs via leave-one-out cross-validation across query-source model and index model. For 2×2 and 4×4 contiguous regions, we report macro-averaged recall over all classes at k = 1, 3, 5; a retrieval is positive if at least one case of the correct class appears among the k results. Model pairs were compared via paired t-test on per-case recall differences, Holm-corrected across the six pairs, within each depth and region scope (2×2, 4×4, pooled). We additionally evaluated 4×4 regions selected by a pathologist, reporting recall at k = 1, 3, 5 for all classes (compared with the same paired t-test) and precision, recall, and F1 at k = 1 for the five classes with ≥ 10 cases, tested as described below. Within each index model, we compared Chamfer score AUC for correct vs. incorrect retrievals, pooling each query's top-5 with a case-level bootstrap (2,000 resamples of 137 queries, jointly across models). Precision, recall, and F1 at k = 1 used the same bootstrap. Between-model differences were tested on the resulting bootstrap difference distribution, Holm-corrected across six pairs per metric; each model's AUC was also tested against chance (0.5) via one-sided Wald test on bootstrap standard error, Holm-corrected across four models. For the seven classes with ≥ 5 cases, chance was defined as the hypergeometric probability that k random draws without replacement yield at least one positive retrieval; each class's aggregate hit count was tested against this null with a one-sided exact binomial test. A class was called significant only if this held for all four indexing models, Holm-corrected across the 21 class-by- depth combinations.
