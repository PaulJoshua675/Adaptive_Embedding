In our study, Stop-and-report changes when Codex returns to an external controller, which resumes the conversation while the environment remains active. Even with the model and reasoning-effort setting fixed, this may change how long the agent continues working and when additional inference is used. We therefore examine inference expenditure as one possible contributor to the observed performance differences. 3 Environment-Agnostic Framework EnvTraverse connects agents and environments through a common interaction contract. Each environment describes the task and how to interact with it, while the agent determines how to solve the task. The same agent can be connected to different environments without modification. New agents and environments can be integrated independently through the framework’s interfaces; agents need not use Codex or an LLM. Figure 1 summarizes the interaction contract. 3.1 Interaction contract Initialization. The environment provides an environment description: text explaining the task, the goal to be achieved, and how the agent can interact with the environment. It may also provide supplementary files, such as documentation, helper programs, or initial observations, which are made available in the agent’s workspace. We treat these files as part of the environment description. The environment determines how much information about its rules and state the description provides. Actions and observations. At each step, the agent submits an action encoded as JSON. The environment defines the valid action structures and their meaning. In response, it returns an observation consisting of an arbitrary set of named files. The contract does not prescribe their formats: observations may contain text, images, or other data. An action may also reference files in the agent’s designated workspace that are accessible to the server-side infrastructure. Termination. The environment decides when the interaction session ends and indicates this in its response. Once the session is terminal, no further actions are accepted. Termination does not necessarily indicate success; its meaning and the criteria for accomplishing the task are defined by the environment. After initialization, interaction follows an agent-initiated request–response pattern: the environment does not send unsolicited observations. This restriction concerns communication, not whether the environment continues to evolve between requests. The environment description, action semantics, observation formats, and termination rules are part of the environment specification. They are held fixed when comparing agents; changes to them define a new version of the environment specification. 5
