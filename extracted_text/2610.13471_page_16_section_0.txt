S3 Additional REMBGO component diagnostics Restart-reference behaviour on symmetric bounds. The partial restart (R11) regenerates part of its group as mul- tiplicative neighbours of a reference point xref. On the symmetric CEC2022 bounds xref defaults to the box midpoint, which is the origin, so the multiplicative rule xref ⊙(1+0.3U [−1,1]D) returns the origin unchanged and that subgroup injects identical zero vectors. A matched diagnostic replaced the reference subgroup with an alternative non-degenerate reference and re-ran REMBGO under identical seeds; the alternative reference produced no detectable change on the isotropic benchmark. Failure to detect a difference is not evidence of equality; the reported benchmark results are stated as conditional on the implemented behaviour, and this diagnostic does not alter the parent-relative records or the application study, which never uses the symmetric-box reference. Coordinate-normalization cancellation. The normalized decaying neighbourhood radius (R3) combines range nor- malization with the temporal decay ρ(τ) = 1.5 −0.7τ. For the idealized rule with εR = 0, if every coordinate has the same range s then R0 = ∥xb −xw∥2 δ ρ(τ)/s and the membership condition ∥xi −xb∥2/s ≤R0 reduces exactly to ∥xi−xb∥2 ≤∥xb−xw∥2 δ ρ(τ), so the scale cancels. The implemented form keeps the regularizer εR = 10−12 inside the norm; nevertheless, on the isotropic CEC2022 box the runs with and without range normalization were bit-identical for every tested seed, function and budget. Thus, only the temporal-decay contribution is active in these isotropic CEC2022 tests, and range normalization neither helps nor harms; it is retained because it becomes active on anisotropic domains outside the CEC2022 specification.
