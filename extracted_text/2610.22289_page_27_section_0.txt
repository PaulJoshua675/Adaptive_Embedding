General action conventions: - `RESET`: start or restart play. - `ACTION1`: usually direction-like, commonly up. - `ACTION2`: usually direction-like, commonly down. - `ACTION3`: usually direction-like, commonly left. - `ACTION4`: usually direction-like, commonly right. - `ACTION5`: game-specific interaction, such as use, select, rotate, attach, detach, confirm, or execute. - `ACTION6`: coordinate-based interaction; provide `x` and `y`, with origin at the top-left. - `ACTION7`: usually undo. These are only conventions. Infer the real effect of each action from observations. The valid actions can change during play; check `available_actions` in metadata before choosing. ## 3. Provided Artifacts Each observation step may provide: - `metadata.txt`: JSON metadata with current state, level progress, available actions, and the action that produced the observation. - `final.txt`: the final settled visual frame as a `64 x 64` ASCII grid of hexadecimal color indices. - `final.png`: PNG rendering of `final.txt`. - `intermediate_XX.txt`: optional intermediate visual frame from an animation or transition. - `intermediate_XX.png`: PNG rendering of the corresponding `intermediate_XX.txt`. ASCII files represent the exact visual frame data. PNG files are generated from the corresponding ASCII frames and are provided so you can see the game as humans are meant to see it. ## 4. Provided Helper Programs Use `ascii_to_png.py` to convert any ASCII frame dump into a PNG image: The same file also provides reusable functions for scripts and notebooks: - `parse_ascii_grid(path)`: read an ASCII frame dump into a NumPy array. - `frame_to_rgb_array(frame, scale=8)`: convert a NumPy frame array to an RGB NumPy array. - `convert_ascii_to_png(input_path, output_path, scale)`: convert an ASCII frame file directly to PNG. Use these helpers for simulated, reconstructed, or extracted ASCII frames when you need to inspect them visually. PNG inspection is especially useful for understanding object identity, animations, small visual differences, and mismatches between prediction and reality.
