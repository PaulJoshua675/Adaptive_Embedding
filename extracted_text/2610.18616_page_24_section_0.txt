An rg call is a shell call that runs rg or grep as a search, ex- cluding file listings and calls that also run Python. We use the successful rg calls that are followed by another turn. An output is truncated if head-and- tail truncation (§2.4) shortens it, and the outcome is whether the next turn runs a Python program. The model sees at least 14.8 KB / 16.4 KB of every truncated output, so we compare the 9,475 / 5,699 truncated outputs with the 1,577 / 2,169 untrun- cated outputs of at least 4 KB. Because truncated and untruncated calls occur at different points of a trajectory, we compare them within each of the five trajectory segments, weight the segments by their number of truncated calls and drop segments with fewer than 20 calls on either side, which removes the first segment with GPT-6-Luna. With both mod- els, the next turn runs Python more often after a truncated output than after an untruncated one of at least 4 KB (66.8% vs. 59.3% with GPT-6-Luna and 76.1% vs. 40.1% with GPT-6-Astra, Table 9). Text-constraint tags. GPT-6-Luna, run with rea- soning effort high, labels each query from two in- puts, the query text and the names of the node and relation types. A query has a text constraint if checking one of its requirements needs a node’s own text. The LLM annotator tags 96% of the Amazon and 57% of the Prime queries as having an additional text constraint. We treat all MAG queries as text-constrained based on their topic de- scriptions. On Amazon, H@1 is 8.1 points higher on text-constrained queries than on the 60 relation- only queries, and on Prime it is 2.1 points lower. H Error Analysis We assign every query that Full DKGI in Pi an- swers incorrectly on the full test sets (7,108 queries per backbone) to one of four categories, using the outputs as the model saw them. A query is an empty answer if the run ends in a failure, in output other than the requested JSON object or in an empty list. Otherwise, it is a ranking error if a gold node is returned at rank 2 or lower, a selection error if an output that the model saw showed a gold record and the returned list misses every gold node, and a search miss in all remaining cases.
