Addressing these limitations requires a unified, code-grounded represen- tation for executable task construction, dependency-aware evaluation, and verifiable learning signals. We introduce WEAVE, a framework for weaving real- world code evolution into executable, dependency-structured tasks for benchmarking and training code agents. As illus- trated in Figure 1, WEAVE starts from verified atomic PRs, identifies code-grounded relations through typed change loci calibrated by repository-local frequencies, and organizes re- lated changes into bounded dependency DAGs. Each DAG is instantiated as a reproducible repository-level task with a unified specification and executable oracle, while remain- ing evaluator-side metadata unavailable to the agent. Beyond task construction, the DAG provides a common interface for measuring and learning from structured progress. We introduce Graph Credit, a deterministic and test-grounded metric that complements binary resolution by rewarding dependency-consistent partial completion. The same struc- ture supports dense, verifiable rewards for reinforcement learning, while the constructed corpus provides long-horizon trajectories for supervised fine-tuning. WEAVE thereby uni- fies executable task construction, structure-aware evaluation, and agent training over realistic multi-PR software evolution. To assess both the benchmarking and training utility of WEAVE, we conduct a four-part empirical study covering task construction, agent evaluation, supervised fine-tuning, and reinforcement learning. WEAVE yields 3200 training tasks and 300 held-out benchmark tasks spanning six pro- gramming languages. Its code-grounded aggregation pro- duces more coherent task groupings and a higher executable- task yield than temporal and coarse-overlap baselines. Eval- uations of eight software engineering agents further show that Graph Credit exposes structurally inconsistent credit obscured by flat scoring. Under matched supervised-token budgets, WEAVE-based supervision improves downstream agent performance, while graph-structured rewards outper- form binary and flat-reward baselines. Together, these results establish dependency-structured tasks as a principled foun- dation for both evaluating and improving code agents. Contributions. Our contributions are threefold: • Executable dependency-structured task construction. We introduce WEAVE, a framework that constructs bounded dependency DAGs from verified PR histories using repository-calibrated typed change loci, and instan- tiates each graph as a unified executable task. • Structure-aware evaluation and verifiable credit. We introduce Graph Credit, a deterministic, test-grounded metric for evaluating dependency-consistent partial progress. By conditioning credit on upstream resolution, it complements binary and flat scoring while providing a dense, verifiable signal for agent optimization. • Empirical validation for benchmarking and training. Extensive experiments show that WEAVE yields coherent executable tasks, captures progress missed by structure- agnostic evaluation, and provides effective supervision and verifiable rewards for training code agents. 2
