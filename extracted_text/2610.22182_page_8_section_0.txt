Support and query images use the same support reference, so each query is calibrated independently of other queries in its batch. The global branch retains its uncentered kernel. 3.4. Fitting and selecting the residual mixture Different layers can assign different similarities to the same pair of images. Each branch therefore provides a distinct way to transfer the shared support residual to queries. Let B = {g, 1, 2, 3} index all branches, with Kg = Kg and Kℓ= bKℓfor ℓ= 1, 2, 3. This notation covers both the uncentered global kernel and the calibrated regional kernels. Each branch b ∈B uses its own kernel matrices and is fitted independently: Gb = Kb(S, S), Hb = Kb(Q, S), αb = (IN + Gb/λ)−1RT. (9) Each branch fits the same RT through its own Gb, then produces the correction ∆b(Q) = Hbαb ∈RM×C. For a single query, write Hb(q) = Kb(q, S) ∈R1×N and ∆b(q) = Hb(q)αb ∈R1×C. Different depths therefore use their own image relationships to predict corrections to the same class scores. Independent fitting preserves these distinct relationships, while the common C-dimensional output allows the predictions to be fused with each layer’s native feature dimension retained. The weight vector w = (w1, w2, w3)⊤ sets the relative contributions of the regional branches, and ρ balances their combined correction against the global correction.
