B.3 State-dependent regions and boundaries Here adjacency always means an in-bounds axis-neighbor edge, not diagonal contact. For any set C, its external vertex boundary is ∂C = {y ∈X \ C : ∃x ∈C, y ∈N1(x)}. (9) Boundary coordinates are unique: a cell adjacent to several members of C still contributes one element to ∂C. MIX(p, r). With alphabet {0, . . . , M −1} and K = M −1 ≥2, an empty anchor gives a no-op. Otherwise, find the set S reachable from p by at most r axis-neighbor steps through cells with nonzero old values. Empty cells cannot be entered or crossed. The nonzero support is conserved by the core event, but interleaved SET operations may change occupancy. The target is |S|; reference reads count P x∈S(1 + |N1(x)|), or one for an empty anchor. Unlike STENCIL, this rule changes both support discovery and arithmetic. The region is a graph-distance ball in the occupied subgraph, not all occupied cells within a Manhattan ball. A coordinate can be geometrically close but unreachable within r steps because intervening empty cells block every short path. At radius zero only the anchor is updated, although its neighbors are still read. The selected generator proposes nonzero anchors and targets the size of this reached region (Appendix B.7). RELABEL(p, v). Find the maximal axis-connected component C containing p whose cells have value W(p), and set every cell in C to v. The rule permits an empty-component anchor, deletion by v = 0, and an unchanged label. The read count is |C| + |∂C|, where ∂C is the in-bounds external vertex boundary. The component is identified entirely in the old world, so touching a component of the destination label after recoloring does not expand this event’s write support. The next event can, however, encounter the combined component. Appendix B.7 specifies the narrower proposal policy used to sample these valid transitions. LAYER(p, s). An empty anchor is a no-op. Otherwise let C be the seed’s maximal equal-valued component with value u. For s = −1, erase every cell of C with an in-bounds empty neighbor. For s = +1, fill every empty cell of ∂C with u. Reads are simultaneous. Out-of-world positions are not empty neighbors: growing [0, 1, 0] yields [1, 1, 1], and subsequent erosion leaves it unchanged. Growth and erosion are therefore not inverses. Reference reads count |C| + |∂C|, or one at an empty anchor. For erosion, the write support is {x ∈C : N1(x) ∩W −1(0)̸ = ∅}; for growth it is ∂C ∩W −1(0). Erosion can split a component, whereas growth can join same-label components through a newly filled cell. Neither operation overwrites another nonzero label. Both signs have positive effect precisely when the old external boundary contains an empty cell. The reference discovers the component and its boundary before writing, so a newly filled cell does not trigger another layer of growth within the event. B.4 Ordered motion and line aggregation MOVE(v, j, s, k). Select the original entities of nonzero value v. For direction s = +1, process them in decreasing coordinate on axis j; for s = −1, use increasing order. Each moves at most k one-cell steps, stopping before a boundary or a currently occupied cell. Earlier moves are visible to later ones. Each move clears its origin and writes v at its destination, without merging. Different axis-parallel lines are independent. 22
