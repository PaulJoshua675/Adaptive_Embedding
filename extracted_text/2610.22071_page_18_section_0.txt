It describes the target segmentation rather than a learned predictor’s realized cuts. Parameter arithmetic. The recorded Bwen configuration has hidden width 4,096, an output vocabulary of 520 identifiers, and 151,680 parent-embedding rows. The byte input embedding and untied output head each have shape 520 × 4,096. The parent-vocabulary table has shape 151,680 × 4,096, and the measured complete model contains 8,313,169,056 parameters. Extending both alphabet-facing tables to 1,032 rows adds 2(1,032 −520) × 4,096 parameters, or 4.19 million (0.0505%). The parent-vocabulary embedding accounts for 621.3 million (7.47%). These parameter counts exclude optimizer state and activation memory and do not quantify per-symbol computation. Different patch-count conventions. The float32 audit counts interior cuts plus one final text unit and excludes the separate BOS patch. The bfloat16 patch-count diagnostic instead sums boundary flags, including the forced BOS flag but suppressing the final text byte’s flag because lookahead is unavailable. These conventions give the same numerical count when interior cuts agree: each adds one to the number of interior cuts. The diagnostic’s comparison with ordinary parent-token counts therefore requires no additional BOS adjustment.
