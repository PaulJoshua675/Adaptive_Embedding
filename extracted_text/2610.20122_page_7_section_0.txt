The default XViewRank configuration uses this pointwise objective because it is simple, stable across TREC DL years, and does not require test-year-specific model selection. 4 Experiments 4.1 Datasets and Evaluation We evaluate on the MS MARCO passage collection with TREC DL 2019 and TREC DL 2020 topics [6, 5]. Retrieval is performed with Pyserini BM25 [20]. Following our experimental protocol, BM25 uses k1 = 0.9 and b = 0.4. All methods return up to 1,000 documents per query. We report nDCG@10, MAP, and Recall@1000. For MAP and Recall@1000, relevance is binarized at grade 2 for TREC DL, following the strict relevance setting commonly used for binary passage-retrieval metrics. We also include a zero-shot transfer check on FiQA and NFCorpus, where the MS MARCO-trained scorer is applied without dataset- specific retraining. XViewRank is trained with MS MARCO passage training relevance labels and selected on a 2,000-query MS MARCO development sample. After removing training queries without a positive pooled candidate and excluding development- query overlap, the final training pool contains 6,317 queries and 9,040,208 query- document candidates, including 6,602 positives. Both generated views are avail- able for every retained training query. The development sample has no query overlap with the TREC DL 2019 or 2020 topics. TREC DL 2019 and 2020 are used only as held-out test sets, and their qrels are not used for model selection. Hyperparameters and model checkpoints are selected using the development set, and the same selected configuration is then applied to both test years. 4.2 LLM Views and Implementation Details All LLM-generated query views and LLM expansion baselines use GPT-4o mini. For XViewRank, the hypothesis and step-back views are generated once, cached, and reused by every method requiring the same view text. The XViewRank scorer uses the score-overlap representation described in Section 3.2 and is se- lected exclusively on the 2,000-query development split; neither DL19 nor DL20 qrels are used for model or hyperparameter selection. The exact prompts, de- coding parameters, retrieval settings, training configuration, and evaluation con- ventions are reported in Appendix A.
