The setup is based on Track 3 of the Modded NanoGPT project (Jordan et al., 2024a), with optimizations to reduce the baseline memory usage; Appendix A.3 gives the details. The LCT run uses a 64 MiB shared OverflowBuffer. Final validation losses are 3.27978 with LCT and 3.27981 without LCT, within nondeterministic rounding error. Ablations and checkpoint analysis. Table 6 compares compression configurations in a short run, reporting time per training step, peak memory, and effective compression ratio. Activation compression reduces peak memory from 16058 to 12103 MiB (24.6%), with a 7.2% increase in time. Further compressing weights and momentum buffers saves another 138.4 MiB. Table 10 isolates the shared OverflowBuffer: it reduces step time by 2.3% at a small memory cost. Figure 4 tracks feed-forward weight and momentum exponent distributions across checkpoints. Their magnitudes shift by roughly 26 = 64. Table 11 reports the corresponding checkpoint compression ratios. The compression ratios are extremely consistent beyond the first few steps, reaching the 1.4382 limit of the CLEAN scheme. The first steps are slightly worse because many values are zero-initialized. 6.4 Fine-tuning larger models A 4B parameter Qwen3-4B model (Qwen-Team, 2025) is fine-tuned to investigate the performance on a larger model, where parameters and momentum buffers make up a more significant portion of the memory usage. Full-parameter fine-tuning in BF16 is used for all weights, activations, and momentum. Without compression, momentum and parameters use around 8 GiB of memory each. Full setup details are given in Appendix A.4. Table 7 compares standard tuning and LCT across sequence lengths from 500 to 3500 tokens. At 500 and 1000 tokens, LCT reduces peak memory by 22.1% and 23.8%, respectively, with step-time increases of 8.0% and 6.7%. The uncompressed baseline runs out of memory for the tested sequence lengths above 1000 tokens. This extends the largest supported sequence length by 3.5×, demonstrating the effectiveness of compression and how it can be used to train longer sequences on the same hardware. 7
