This block policy retains recent evidence while limiting changes to reusable context prefixes. Streaming models maintain the retained history within their sessions, while asynchronous models resubmit the retained context. To maximize cache reuse and reduce inference latency, we preserve the order and content of retained messages and remove older history only in blocks when the reten- tion limits are exceeded. This keeps the shared context prefix stable across consecutive decisions, allowing models to reuse cached computation where supported. Both mechanisms implement the same logical history policy. A.4 MODEL CONFIGURATION Standard Asynchronous Models and Real-time Streaming Models. Our standard asynchronous models include GPT-6-Astra, GPT-5.6 Sol, Gemini 3.8 Flash, Claude Opus 5, Claude Fable 5.1, DeepSeek V4.1 Flash, and Kimi-K3.
