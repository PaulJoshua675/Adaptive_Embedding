B DATA DETAILS B.1 TASK SYNTHESIS COMPARISON Table 6 compares recent CUA task- and environment-synthesis pipelines across five dimensions: task grounding, application scaling, authentic artifact integration, cross-application task support, and executable evaluation. The comparison is organized along the axis of synthesis coverage rather than data scale or maturity. The broader contribution of OS-Helix is to extend exploration-grounded task generation toward artifact-grounded executable desktop-state construction: the pipeline jointly addresses K/E/C grounding, application scaling, authentic artifact-backed state initialization, and executable rule-based evaluation within a single coherent framework. Concretely, an application– artifact compatibility graph organizes valid pairings of application configurations and supported artifact types or file formats, enabling reproducible initial states to be instantiated systematically. The evaluator pipeline verifies persistent terminal outcomes rather than constraining the action se- quence, supporting diverse task objectives and evaluation criteria across application domains and providing the infrastructure for subsequent hybrid-policy training. Cross-application task synthesis is currently realized as a limited prototype, reflected by the partial symbol in the table; extending this component into a larger and more systematically characterized collection remains an explicit direction for future work. Works such as Qwen-CUA and Qwen-UI- Agent have demonstrated more extensive coverage of long-horizon and cross-application workflows at scale, and those dimensions represent clear avenues for subsequent expansion of OS-Helix.
