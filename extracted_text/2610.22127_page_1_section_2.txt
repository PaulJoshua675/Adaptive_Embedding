Personalization of Large Language Models (LLMs) adapts LLMs to user or group preferences (Salemi et al., 2024; Zhang et al., 2025b). Due to increasing demand for AI-assisted user-centric applications, Personalization of LLMs has become an important research direction. Most methods use dense LLMs (Zhang et al., 2025b), offering little interpretability 1Code and data: https://github.com/copenlu/ persona_moe_explain of localizing important model components encod- ing distinct personalized features due to the poly- semanticity of encoding multiple orthogonal con- cepts into a single neuron (Olah et al., 2020). Re- cent work on developing intrinsically interpretable LLMs suggests that wider, more sparse LLMs en- able their neurons to capture more disentangled features and reduce polysemanticity (Yang et al., 2025b). Mixture-of-Experts (MoE) LLMs offer a scalable solution for wider and sparser networks by replacing a dense FFN block in the MLP layer with a set of experts of the same size, using a sparse rout- ing mechanism to select a subset of these experts to process each input token (Shazeer et al., 2017). This mechanism enables MoE LLMs to offer better interpretability for downstream tasks by achieving lower polysemanticity (Herbst et al., 2026), where experts encode distinct task-specific features. Moti- vated by these observations, we utilize MoE LLMs for personalization and subsequent interpretability analysis, addressing research questions covering polysemamticity of MoE LLMs for personalization (RQ1, §6.2), identifying distinct personalized fea- tures encoded via experts during personalization (RQ2, §6.3), and localizing unique routing paths for distinct personalized features (RQ3, §6.4). (2025) on MoE LLMs align- ment, we adapt the MoE LLMs towards personal- ization using a two-stage parameter-efficient fine- tuning (PEFT) (§4.1), on a large-scale personaliza- tion dataset covering diverse preferences for user groups, MULTIFACETED COLLECTION (Lee et al., 2024). We then train a sparse autoencoder- based (Bricken et al., 2023; Huben et al., 2024) architecture crosscoder (Minder et al., 2025) on paired personalized and non-personalized activa- tions to identify interpretable personalization la- tents.
