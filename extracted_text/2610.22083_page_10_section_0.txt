Width and input activity Because every bit costs one spike packet per classifica- tion, width is the number of input events per decision. On event-driven hardware the dynamic energy of a computation grows with the number of events it involves (Furber, 2012; Davidson and Furber, 2021), so width bounds the input contribution to that energy; energy itself was not measured here. Width is also the number of buffer entries each decision occupies on the receiving core (Section 3.4). 4. Results 4.1.
