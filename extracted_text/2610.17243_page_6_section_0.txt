Sentiment quality, interlinking, network reliability, and generated-answer quality were outside the scope of this experiment. 4:38 PM 7 Discussion 7.1 Architectural benefits The redesign provides three practical benefits. First, it establishes a single semantic path for scheduled monitor- ing and question-driven discovery. As a result, evidence collected for a question is filtered and represented consis- tently with the rest of the corpus. Second, it separates deterministic semantic state from optional generative syn- thesis. Database rows, event confidence, entity canonical- ization, and cluster membership can be inspected inde- pendently of a model-generated answer. Third, it gives downstream applications a stable relational and object- level contract instead of coupling them to source formats. The architecture is also suitable for incremental mod- ernization. Rule-based NER can be replaced by a trans- former model; lexical ranking can be replaced by hybrid sparse-dense retrieval; SQLite can be migrated to a server database; and connected-component clustering can be replaced by a time-aware or learned method. Because each responsibility is localized, these changes need not alter all consumers simultaneously. 6
