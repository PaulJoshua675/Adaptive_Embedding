Besides, in this paper, for any X ∈{0, 1}n, we use |X|1 = Pn i=1 Xi to denote the number of ones in X, and |X|0 = Pn i=1(1 −Xi) for the number of zeros in X. 3 Theoretical Properties of the MO-MFEA Before we analyze the runtime of the MO-MFEA on two-task bi-objective optimization problems, this section will discuss the general theoretical prop- erties of the MO-MFEA on any ℓ-task multi-objective optimization problem. As discussed before, in the first generation, each task has a similar number of associated individuals in the population, that is, the computing resources for all tasks are balanced. We may expect that this balanced status always holds for all future iterations. The following lemma shows that it is true. The key reason is that the algorithm assigns contiguous integers as factorial ranks (i.e., 1, 2, 3, . . . ) separately to individuals of each task. Consequently, when only the top N individuals with the largest scalar fitness (that is, smallest factorial ranks) survive, this contiguous ranking ensures that a roughly equal number of survivors are retained for each task. Lemma 1. Let c ∈R, b ∈N. Then ⌊(b + 1)c⌋−⌊bc⌋∈[⌊c⌋..⌈c⌉]. Proof. Let bc = ⌊bc⌋+ θ, where θ ∈[0, 1). Then ⌊(b + 1)c⌋−⌊bc⌋= ⌊⌊bc⌋+ θ + c⌋−⌊bc⌋= ⌊θ + c⌋. Since ⌊c⌋≤⌊θ + ⌊c⌋⌋≤⌊θ + c⌋≤⌊θ + ⌈c⌉⌋= ⌊θ⌋+ ⌈c⌉= ⌈c⌉, this lemma is proved. Lemma 2. Consider using MO-MFEA with population size N to optimize an ℓ-task problem. Let Pt be the population in the t-th iteration, and let St,i = {X ∈Pt | τ(X) = i}, i ∈[1..ℓ]. Then for any i ∈[1..ℓ], |St,i| ∈[⌊N/ℓ⌋..⌈N/ℓ⌉] and φ(St,i) = {1/j | j ∈[1..|St,i|]}. Proof. For P0, it is easy to see that |S0,i| = {Xj ∈P0 | j ∈[⌊(i −1)N/ℓ⌋+ 1..⌊iN/ℓ⌋]} for i ∈[1..ℓ]. From Lemma 1, we know that |S0,i| ∈[⌊N/ℓ⌋..⌈N/ℓ⌉]. In the following, we will prove that from |St,i| ∈[⌊N/ℓ⌋..⌈N/ℓ⌉], we also have |St+1,i| ∈[⌊N/ℓ⌋..⌈N/ℓ⌉]. Let S′ t,i = {X ∈Rt | τ(X) = i}, i ∈[1..ℓ]. Then |S′ t,i| ≥|St,i| ≥⌊N/ℓ⌋. Since ⌊N/ℓ⌋·ℓ≤N, we know that all individuals with factorial rank less than ⌊N/ℓ⌋+ 1, that is, with scalar fitness larger than 1/(⌊N/ℓ⌋+ 1) will survive to Pt+1. Then |St+1,i| ≥⌊N/ℓ⌋.
