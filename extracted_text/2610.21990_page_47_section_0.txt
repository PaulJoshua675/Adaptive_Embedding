Parameter-wise Learning Rates. Differential learning rates are employed for backbone and task- specific components. The ResNet backbones [28] are optimized with a learning rate scaled by 0.1 relative to the base rate, while newly introduced fusion and prediction layers are trained with the full base learning rate. This strategy enables stable fine-tuning of pretrained representations while allowing faster convergence of randomly initialized layers. Learning Rate Scheduling. A cosine annealing schedule is employed with Tmax = 10K for the PST900 dataset [8] and Tmax = 20K for CART [25]. Tmax controls the duration (in iterations) over which the learning rate gradually decreases from the initial value η0 to the minimum value ηmin. The minimum learning rate is ηmin = 1 × 10−7. Compared to step decay, co- sine annealing avoids abrupt learning rate drops, which can destabilize training.
