Implementation Details C.1. Rollout in Context Compaction This section specifies the context compaction scenario used for the multi-session setting. The inference retains the standard ReAct interaction protocol, but converts a long execution into a sequence of sessions whenever the current working context can no longer safely accommodate another agent turn. All sessions are generated by the same policy. In the on-policy configuration used in our experiments, the compaction summary is also generated by the policy and is therefore optimized as a separate training segment. Each rollout begins with a standard agentic search session. The policy model receives the following system instruction, together with the original user question and the native function schemas for two tools, search and visit. The schemas are provided through the model’s chat template. The agent may invoke at most one tool in each turn. Base System Prompt You are a deep research assistant.
