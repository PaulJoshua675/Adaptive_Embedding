B Experimental and Evaluation Protocol B.1 Base, Implicit, and Explicit Prompts We provide the prompt templates used for the three prompting settings in our experiments: Base, Im- plicit, and Explicit. All prompts follow a unified input format consisting of the database schema and the natural language question. Base Prompt. The database schema is as follows: {schema} Question: {question} Generate SQL to answer the question. { "sql": string or null, "reason": string } Return structured JSON only. Implicit Prompt. The database schema is as follows: {schema} Question: {question} The question may contain errors. You must assess its validity before answering. Generate SQL to answer the question. { "sql": string or null, "is_valid": boolean, "reason": string } Return structured JSON only. 11
