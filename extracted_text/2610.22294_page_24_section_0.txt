For each prompt family, we retain the same target as D grows and evaluate the reference completion u⋆under both demonstration contexts. We report its example reward per target token: R(u⋆) |T| = log P1(u⋆) −log P0(u⋆) |T| . The reward generally increases with D, indicating that additional demonstrations provide greater relative support for the reference answer. Because P0 masks demonstration outputs for DLMs but removes them from causal prompts, reward magnitudes are not directly comparable across these interfaces. Greater support for a reference answer does not, however, guarantee a larger gain from guidance. At D = 1, SST-2 exposes only one class code, while a single List Functions or SALT demonstration may be compatible with several rules.
