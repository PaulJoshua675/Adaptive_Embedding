Transformers (Vaswani et al., 2017) serve as the stan- dard architecture for large language models (Radford et al., 2019; Touvron et al., 2023). Each Transformer layer consists of a multi-head self-attention block and a multi-layer perceptron (MLP). The attention block is built from query, key, value, and output projections, and the MLP is based on rectified linear units (ReLU) or Swish-gated linear units (SwiGLU) (Shazeer, 2020). Several of these weight matrices form pairs whose scales can be traded against each other without changing the output. For example, attention compares queries and keys through the product (W Q)⊤W K of the query and key matrices, so replacing (W Q, W K) with (cW Q, c−1W K) for any c > 0 leaves every attention score, and hence every prediction, unchanged. We call a pair of matrices (A, B) an exact symmetry pair when replacing the pair with (cA, c−1B) preserves the model’s function for every c > 0. Rescaling the exact symmetry pairs of a model in this way yields a whole set of parameterizations that all compute the same function, which we call a symmetry orbit. These parameterizations represent the same function but lead to different training trajectories. The reason is that the gradients scale inversely to the weights: Multiplying A by c multiplies its gradient by c−1, and multiplying B by c−1 multiplies its gradient by c. A gradient-descent step moves the enlarged matrix c2 times less, relative to its size, than in the original model and its shrunken partner c2 times more, so the two models no longer compute the same function after the step. Figure 1 illustrates this effect. Concretely, symmetry orbits in a Transformer arise from attention query–key (Q–K) and value–output (V– O) pairs, ReLU up–down projections, and the linear value–output path of SwiGLU (Sec. 2). This inverse gradient-scaling law holds for all of these pairs and fol- lows from the chain rule (Dinh et al., 2017, Theorem 3).
