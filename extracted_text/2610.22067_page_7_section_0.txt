We can achieve this by using a generalised linear model (GLM; Nelder & Wedderburn, 1972) with a logit link to estimate how each predictor relates to expected score, accounting for the other predictors, task, and choice of LLM. For the expected score y ∈[0, 1] of LLM m on question q, we specify E[y | q, m] = σ  αt + αm + K X k=1 βk xk(q)  (4) where σ(z) = 1/(1 + e−z) is the logistic function, which keeps predicted means between zero and one. Here, K = 4 is the number of predictors, and xk(q) is the value of predictor k (context length, evidence scope, evidence dispersion, or reasoning depth) after the log transformation and standardisation described in Section 5.1. The intercept terms αt and αm account for baseline dif- ferences across tasks and LLMs, respectively, with t denoting the task of question q. The attribute coefficients βk are shared across tasks and LLMs. We fit the model using fractional logistic regression (Papke & Wooldridge, 1996). Uncertainty is estimated using the question-clustered standard errors described in Section 5.1. Each βk represents the change in the logit of the expected score per standard deviation of the logged predictor, holding the other predictors fixed. We also report contrasts between fitted predictions in percentage points (pp), holding other predictors fixed. The interquartile contrast ∆25→75 averages, over all questions, the predicted score change when a predictor moves from its within-task 25th to its 75th percentile; tasks with tied quartiles contribute zero. For RQ2, we extend the model with interactions between context length, L, and another attribute j: E[y | q, m] = σ  αt + αm + K X k=1 βk xk(q) + γLj xL(q) xj(q)  (5) The slope for context length on the logit scale is then βL+γLjxj. The coefficient γLj measures how much this slope changes per standard deviation of the logged attribute j. We fit one such model for each of scope, dispersion, and depth, and distinguish these logit-scale interactions from score-scale contrasts in RQ2. We call the model without interaction terms (Equation 4) the additive GLM.
