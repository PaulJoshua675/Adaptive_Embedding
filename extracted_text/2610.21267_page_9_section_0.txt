Limitations Cold start. TRACER indexes a dataset D of graded trajectories (§3.3), so a registry with no usage history has no trie to consult and every step falls to the vector fallback, where accuracy is far below the rest of the run: presenting the full reg- istry on those steps instead would raise it by 38 points on average (Table 16). The method there- fore assumes a deployment that has already logged successful runs. How quickly a trie becomes useful as trajectories accumulate is the obvious next mea- surement, and one our fixed-size corpora cannot answer. Trie key depth. We key the trie on the full current-turn prefix (§3.3) and did not tune that choice. A shorter key is not obviously worse (§5.6), so the depth we use may not be the best one. Free-running episodes are terminated by the grader. An episode ends when the grader con- firms completion or at a cap of 20 steps (§4.4); the agent never judges for itself that it is done. Task success therefore measures whether the front-end supplies the tools needed to reach the goal, not whether an agent built on it would know when to stop. Selection accuracy discards ordering freedom. Several tools can often be called in different orders and still complete a task, but accuracy is scored against one recorded ordering, so a valid alterna- tive counts as wrong. Accept-sets (§4.6) and free- running task success, which asks only whether the goal was reached, bound the distortion.
