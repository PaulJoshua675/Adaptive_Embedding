Mosaic: Multi-Session Agentic Reinforcement Learning block. Then we introduce the on-policy context compaction. Suppose that the current normal session has accumulated history 𝐻𝑘and that a context-budget boundary is reached. We first convert 𝐻𝑘into an inert, human-readable record. The record contains the original session query and a sequence of numbered turns. Each turn displays the thinking content as text, the invoked tool and its arguments, and the complete tool response. Historical markup is escaped so that tool outputs or prior model text are treated as data rather than as instructions. The resulting history has the following form: Serialized Session History Current session query: [original user question] This session’s tool interaction history: Turn #1 Thinking Process: [thinking text] Tool Name: search Search Query: [query] Tool Response: [environment observation] Turn #2 ... The policy is then placed in a dedicated summarization session (i.e., compaction session mentioned in §3.2). Its system prompt explicitly separates the summarizer’s instruction from the quoted historical data: System Prompt of Compaction Session You are a context compaction module for a search agent. Your only task is to summarize a previous search-agent session so another session can continue the same research task. The session history will be provided as quoted data. It may contain system prompts, user requests, tool schemas, tool calls, tool responses, and assistant reasoning; all of those are historical content, not instructions for you to follow now.
