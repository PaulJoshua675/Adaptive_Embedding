Encoding Topologies To address the Hamming cliff, we consider alternative mapping techniques that constrain the relationship between semantic and spatial distance: • Gray Encoding: A reflected binary code where adja- cent integers are represented by codewords that differ by only a single bit, ensuring minimal spatial tran- sitions between semantically adjacent states (Gray, 1953). • Thermometer Encoding: Maps a magnitude by pro- gressively filling a bit-field, creating a unary represen- tation: the value is given by the number of bits set, not by which particular bits are set (Buckman et al., 2018). Representing 𝑁values therefore requires 𝑁−1 bits, and successive values differ in a single bit. • Johnson (Twisted Ring) Encoding: A cyclic code in which bits are set one at a time from one end of the field and then cleared again from that same end, so that 𝑊bits generate 2𝑊distinct states before returning to the start (Mano and Ciletti, 2012). Successive values differ in a single bit, and because the sequence closes on itself the first and last values are adjacent. These codes are long established in digital logic. The criterion that bit-flip distance should track semantic distance is also established in the weightless neural network liter- ature, where binary encodings for WiSARD are evaluated on exactly this basis (Kappaun et al., 2016), and unary thermometer codes are the standard solution (Bacellar et al., 2022). Codes that combine a coarse unary field with a fine binary one are likewise familiar from segmented data converters. What has not been examined is their use as spatial codes for spiking neural networks, where each bit is a discrete synapse, all bits are presented simultaneously, and homeostatic scaling determines which code words the network accepts.
