Stakeholder responses are scripted for reproducibility, as switching the user-simulation model can shift measured agent success rates by sev- eral percentage points [14]. A small model maps questions to topics, while each stakeholder’s knowledge, miscon- ceptions, and conditions for disclosing information are fixed in advance. The scripts incorporate limited patience, requirements for supporting evidence, dependencies on prior conversations, temporary unavailability, and contact restrictions. Agents must infer stakeholder roles and communication constraints from customer documents. 3.4 Admission Anchors and Anti-Gaming Validation Each task included in FDE-Gym must satisfy four predefined scoring anchors (Figure 3). (1) The reference solution must score at least 0.95. (2) The do-nothing baseline must score 0. (3) The literal solution, which implements exactly what the task instruction asks for without seeking any further constraint, must score at most 0.2. This condition holds even when the sponsor’s request identifies the right problem, because the constraints omitted from the task instruction still determine the outcome. The only exception is a task in which the sponsor’s request is both correct and complete; there the literal solution coincides with the reference solution and must score at least 0.95, so that distrusting the sponsor is never a universally rewarded strategy. (4) Shortcut strategies must score at most 0.8. These strategies include overfitting to historical data, guessing round-number thresholds, and deferring all uncertain decisions to humans. Scores are capped near zero if an agent attempts to bypass customer controls or manipulate the grader. The graders were tested against more than 270 shortcut and bypass strategies. Agents that solve tasks using only customer documents and data are scored on the same basis as those that interact with stakeholders. 3.5 Expert Review and the Online Platform Industry experts cross-reviewed and iteratively refined each task. Their total contribution to the development of FDE-Gym exceeded 10,000 hours. FDE-Gym also provides an online platform (fde-gym.com) where human par- ticipants use the same workspaces, interact with the same stakeholders, and are evaluated by the same graders as agents. A human baseline is currently being collected there under recorded conditions from industry experts working on the L3 tasks.
