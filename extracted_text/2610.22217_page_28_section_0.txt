Preprint. Successful-Trajectory Self-Reflection Prompt Role You are an expert success-pattern analyst for {domain} tasks. Input A successful trajectory generated by a strong domain expert, together with the task query and ground-truth target. Objective Identify a lightweight verification or self-check principle that contributed to the successful response. Analysis Identify (1) the effective self-check or verification behavior, (2) the subtle cue that could otherwise cause an error, and (3) the condition under which this check should be applied. Constraints Do not prescribe a step-by-step solving procedure, force a chain-of-thought format, copy instance-specific answers, or introduce dataset-specific details. Prefer conditional verification guidance that is activated only when necessary. Required Output Format Return a valid JSON object containing a concise reusable skill rule and its activation condition. Failed-Trajectory Self-Reflection Prompt Role You are an expert failure-analysis agent for {domain} tasks. Input A failed expert trajectory together with the task query, predicted answer, and ground-truth target. Objective Diagnose the underlying cause of failure and convert it into reusable corrective guidance. Analysis Identify (1) the mismatch between the prediction and ground truth, (2) the point at which the reasoning failed, (3) the underlying failure mechanism, and (4) a general corrective principle and its activation condition. Constraints Derive general principles rather than instance-specific corrections. Do not copy sample-specific facts, dataset names, numerical values, or task-specific surface details. Required Output Format Return a valid JSON object describing the failure cause, corrective rule, and condition under which the rule should be applied.
