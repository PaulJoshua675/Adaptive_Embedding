D EVIDENCE ANNOTATION PROCEDURE For sources that provide reference evidence, we use those annotations directly. For the remaining sources, we identify supporting evidence through retrieval, expansion, and sufficiency validation, as described below. Initial evidence retrieval. We prompt Gemini 2.5 Pro with the question and chunked source con- text to extract verbatim passages potentially useful for answering the question. The resulting pas- sages form a candidate evidence set rather than verified supporting evidence. The retrieval prompt is shown at the end of this appendix. Evidence expansion.
