Multi-turn attacks such as Crescendo [33] and indirect prompt injection via external data sources [14] operate in threat models outside REPRO’s single-turn scope and are not directly comparable. 2.3 Automated Prompt Optimization A parallel line of work develops general-purpose prompt optimizers for helpful tasks rather than adversarial ones. Khattab et al. [18] developed DSPy, which compiles declarative LM calls into self- improving pipelines; its MIPROv2 optimizer uses Bayesian optimization for instruction selection and bootstrap demonstration filtering. Agrawal et al. [1] introduced GEPA (Genetic-Pareto), a prompt optimizer that incorporates natural-language reflection to learn high-level rules from trial and error, using Pareto selection to maintain diverse candidates. Both target helpful objectives (task accuracy, instruction-following quality), leaving open the question of whether the same optimization machinery can be specialized to adversarial objectives. OpenRT [38] is a concurrent open-source framework that integrates 37 attack methods spanning white-box gradients, multi- modal perturbations, and multi-agent strategies, and evaluates 20 frontier models including GPT-5.2, Claude Haiku 4.5, and Gemini 3 Pro. Notably, OpenRT includes EvoSynth, a program evolutionary attack method that achieves 100% ASR on 18 of 20 evaluated models, the highest individual-method performance in their framework. OpenRT provides infrastructure for running existing and new attacks at scale; REPRO differs in operating as a standalone single-turn optimizer that discovers attacks autonomously rather than orchestrating pre-existing methods. REPRO answers this question affirmatively: it inherits the core ingredients of modern prompt optimization (population-based search, Pareto selection, reflective improvement) and specializes them to the adversarial regime by replacing helpfulness metrics with (ASR, XFER, detectability, length), introducing semantic crossover as a multi-parent recombination operator, adding Thompson Sampling for strategy selection, and replacing generic self-reflection with structured failure analysis driven by a refusal taxonomy. 2.4 Framework Comparison Table 1 consolidates the comparison between REPRO and the most directly comparable automated jailbreak frameworks along the dimensions that determine applicability to black-box security testing: access mode, search strategy, mutation mechanism, whether the method uses crossover, the optimization objective, and reported ASR.
