S-KSA S-KSA uses fused block scoring and a sparse KV-tile schedule to support query-dependent access to original text. The scoring optimization also applies during decoding. Fused block scoring. Using separate kernels for dot products and head aggregation requires storing intermediate scores in GPU memory. To reduce this memory traffic, we compute block scores with a fused kernel that performs dot products and combines weighted head scores on chip. KV-tile scheduling. For each query group, we map its selected remote blocks and local windows to KV tiles and construct a conservative schedule of tiles to visit. The schedule skips inactive KV tiles, while per-query masks enforce block selection, local visibility, and causality within the scheduled tiles. We supply this schedule and the masks to the FlashAttention forward kernel for tiled prefill execution. Decoding. Gathering selected KV entries into temporary buffers incurs extra memory reads and writes before attention computation. To avoid this overhead during decoding, we use a custom sparse kernel that reads directly from the KV cache using the selected block indices. 3. Experiments Our experiments examine whether continued pretraining can adapt Hybrid KSA to more aggressive KV compression and sparse original-text access while retaining its capabilities. We first evaluate C-KSA with Full attention, then add S-KSA to the compressed backbone, assessing long-context retrieval, general capabilities, and inference efficiency. We further analyze the effects of compression granularity, block size, teacher pooling, and routing on model performance. Unless otherwise stated, all experiments and analyses use the 1.9B model. 11
