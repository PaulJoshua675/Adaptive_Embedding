Details of Marginal Information Gain Calculation We compute marginal information gain for each non-terminal training session from the change in the actor’s likelihood of the ground-truth answer across that session. For a session 𝑠, the rollout records two boundary token streams, ℎ− 𝑠and ℎ+ 𝑠. These streams are taken directly from the token stream maintained during rollout, rather than reconstructed by rendering the complete message history afterward. Their meanings depend on the session type: • Normal session. ℎ− 𝑠is the chat-template prompt at the start of the session, and ℎ+ 𝑠is that prompt followed by the complete session response. • Compaction session. ℎ− 𝑠contains the full available history immediately before compaction session. After the generated summary is injected into the new prefix in the next session, the resulting session prompt forms ℎ+ 𝑠. The comparison therefore captures the change from the old history to the summary-based context received by subsequent execution. • Subagent session. ℎ− 𝑠is the main agent’s context before the forking turn. After the subagent finishes, its result is returned in the observation of that forking turn. Then the resulting main-agent context forms ℎ+ 𝑠. Terminal sessions are excluded from marginal information gain computation and receive only the trajectory-level advantage. For either boundary context ℎ∈{ℎ− 𝑠, ℎ+ 𝑠}, we append the same fixed continuation containing the ground-truth answer 𝑦∗.
