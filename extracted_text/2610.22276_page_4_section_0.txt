Following Jev (TypeSafe AI, 2026), it predicts by selecting candidates rather than generating text. We first explain how one classification framework handles answer options, numerical values, and image locations, including coarse-to-fine refinement and multi-point prediction. We then describe the shared model architecture and the training recipe. 3.1 Unified Classification Framework for Spatial Intelligence Given ordered images I = (I1, . . . , Im) and a spatial question q, the model predicts an option, a number with a declared unit, or a point in normalized image coordinates. Each candidate is a possible answer for the current decision. For a choice question, it is one of the supplied options; for a numerical or point question, it identifies an interval or region in which the target is predicted to lie. This lets all three output types use the same candidate-classification rule. At stage t, a deterministic task controller constructs candidates Ct = {ct,1, . . . , ct,Kt} from the question and preceding selections and visual refinements h<t. A choice question ends after this decision. For numerical and point prediction, the selected class determines the next candidate set and any new image crop. The final class is decoded to an exact value or interval midpoint for numerical tasks, or a region center for pointing. Each classification decision scores all current candidates in one forward pass, with no answer-token generation or text parsing. A complete prediction can require several such decisions: numerical tasks use up to two stages and single-point prediction uses three. Multi-point prediction evaluates additional branches of the same spatial hierarchy.
