Algorithm 1 Document Generation with Verification Input: Trajectory T with states {s0, . . . , sn} Each state si has claims Ci (expected memory state, used by scorer) and docClaims ˆCi (new info for this document) Input: Generator pool M = {m1, . . . , m6}, Judge pool J = {j1, j2, j3} Input: Style references RAMI, REnron Output: Verified document set DT 1: for each state si ∈T do 2: m ←M[i mod |M|] // rotate model 3: r ←SelectStyle(type(si), diff(T), R) 4: for k = 1 to 3 do 5: if diff(T) = L3 then 6: h ←SelectHost(domain(T), R) 7: dk ←Inject(m, ˆCi, h) 8: else 9: dk ←Generate(m, ˆCi, r, diff(T)) 10: end if 11: V ←V j∈J h Entail(j, dk, ˆCi) ∧¬Halluc(j, dk, T) i 12: if V = true then 13: DT ←DT ∪{dk}; break 14: else 15: m ←M[(i + k) mod |M|] 16: end if 17: end for 18: end for 19: DT ←DT ∪GenerateNoise(M, cat(T), domain(T)) 20: Constraint: ∀m ∈M : |{d ∈DT : gen(d) = m}|/|DT | ≤0.3 21: return DT For style-grounded generation, documents are typed (meeting notes, email, architecture review, status update, executive briefing) and matched to style references from a curated set of 12 AMI meeting summaries (Carletta et al. 2005) and 12 Enron emails (Klimt and Yang 2004) selected for diversity in length, formality, and structure. Document length and noise scale with difficulty: • L1: 200–400 words, no noise claims, target claims nearly explicit. • L2: 400–800 words, 2–3 unrelated noise claims, target claims embedded in context. • L3: 600–1000 words, 4–5 noise claims, subtle and am- biguous signal. For L3 trajectories, host documents are selected from unre- lated domains (e.g., product design meetings, energy pipeline discussions) to ensure no semantic overlap with the trajec- tory topic, making scoring unambiguous: any relevant fact the system extracts must come from the injected section. 4.3 Verification Pipeline The verification criterion (Algorithm 1, line 6) requires unan- imous agreement from 3 independent judge models (different from the generators), following the multi-judge grounding methodology of (Uddin et al. 2026) and (Roig 2025). Each judge assesses: (1) all target claims are inferable from the document, (2) no extra factual information beyond the tra- jectory is introduced, and (3) the document reads naturally. Additionally, documents underwent human review, with 11% requiring content corrections (forward leakage, narra- tive contradictions, cross-document inconsistencies, numeric mismatches) and 28% requiring scaffolding removal (code fences, LLM preamble such as “generated email about...” or “injected claims into...”) that does not affect extraction. 5 Evaluation Framework We evaluate each system using both intrinsic and extrinsic metrics on the same trajectories, enabling direct measure- ment of their divergence. 5.1 Intrinsic Metrics After processing all artifacts for a trajectory T, we compare the system’s fact store F against the expected claims Ci at each state si. Let Entail(f, c) = 1 if fact f entails claim c (determined by embedding similarity > 0.8 followed by LLM judge verification). Claim coverage at state si: Cov(si) = |{c ∈Ci : ∃f ∈F, Entail(f, c) = 1}| |Ci| (1) Fact accuracy across the trajectory: Acc(T) = 1 |T| |T |−1 X i=0 Cov(si) (2) Update detection recall, where U = {si : ai ∈ {update, supersede}} is the set of states requiring a change: UDR(T) = |{si ∈U : changed(F, si−1, si)}| |U| (3) False update rate, where R = {si : ai = reinforce}: FUR(T) = |{si ∈R : changed(F, si−1, si)}| |R| (4) Additionally, we report fact count (number of active facts per trajectory, detecting duplication or loss) and confidence MAE ( 1 |T | P i |cexpected(si) −cactual(si)|). 5.2 Extrinsic Metrics For each trajectory, we generate diagnostic questions whose answers depend on the final memory state. The system re- trieves relevant facts via its standard retrieval mechanism, then an LLM generates an answer. A judge model scores each answer as YES (1.0), PARTIAL (0.5), or NO (0.0) against the expected answer derived from ground-truth claims. 5.3 Divergence Metric The key metric is mean absolute divergence (MAD) be- tween intrinsic and extrinsic scores: MAD = 1 N X T |Acc(T) −Extr(T)| (5)
