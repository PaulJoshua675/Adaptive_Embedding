OmniVerifier-C1: Decomposed Graded Verifier for Rule-Governed Generative World Modeling Lemma A.2 (The graded reward perfectly preserves the quality ordering). For the decomposed graded reward rc(x) = z(x) K , (11) the ranking accuracy satisfies Accrank(rc) = 1. (12) Proof. Since rc is a strictly increasing affine function of z, for any pair x, x′ with z(x)̸ = z(x′) we have (rc(x) −rc(x′))(z(x) −z(x′)) = (z(x) −z(x′))2 K > 0, (13) where the strict inequality uses K > 0 and z(x)̸ = z(x′). Hence the event (rc(x)−rc(x′))(z(x)−z(x′)) > 0 holds with probability one conditional on z(x)̸ = z(x′), and Accrank(rc) = 1. Lemma A.3 (The binary reward only ranks perfect-vs-imperfect pairs). For the discrete binary reward rd(x) = 1[z(x) = K], (14) the event (rd(x) −rd(x′))(z(x) −z(x′)) > 0 (15) holds if and only if exactly one of the two samples attains the perfect quality level K. Proof. Conditioning on z(x)̸ = z(x′), there are exactly three disjoint cases: (i) Exactly one sample is perfect. Without loss of generality, suppose z(x) = K and z(x′) < K. Then rd(x) −rd(x′) = 1 and z(x) −z(x′) = K −z(x′) > 0, so the product is strictly positive. The case z(x′) = K, z(x) < K is symmetric. (ii) Both samples are imperfect, i.e. z(x) < K and z(x′) < K. Then rd(x) = rd(x′) = 0, so rd(x)−rd(x′) = 0 and the product vanishes, even though z(x)̸ = z(x′). (iii) Both samples are perfect. This case violates z(x)̸ = z(x′) and is excluded. The product is strictly positive only in case (i), which proves the claim. Theorem A.4 (Ranking advantage of decomposed graded verification).
