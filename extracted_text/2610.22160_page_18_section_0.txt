A one-step, three-token example shows that context improvement need not imply useful steering. Take Q = (1, 0, 0)⊤, Pbase = (0.2, 0.3, 0.5)⊤, and Popt = (0.25, 0.65, 0.10)⊤. The context update improves target KL from −log 0.2 to −log 0.25. At α = 0.1, all tokens pass the confidence threshold, and Eq. 18 gives δ ≈(−0.0436, 0.2443, −0.2007)⊤. Nevertheless, Γ = ⟨Q −Popt, δ⟩≈−0.1714 < 0. The context update increases the correct token’s probability, but the contrast favors a competing token strongly enough that further extrapolation raises target KL. This constructed example illustrates the logical need for Assumption 2; it is not an experimental result.
