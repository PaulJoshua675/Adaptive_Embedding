The resulting profile is informative but noisy: informa- tion that is decisive for one question may distract retrieval for the next, and the relevant profile statements cannot be determined in advance. This problem is amplified by the prevailing approach for exploit- ing user profiles: Personalized Conversational Query Reformulation (PCQR) [14, 15, 20, 30, 40, 48]. Given the full conversation history and the user profile, PCQR employs Large Language Models (LLMs) to generate a personalized and de-contextualized self-contained query to submit to off-the-shelf ad-hoc retrievers. However, pre- vious studies [20, 40] showed that this process can cause over- personalization query drift, where LLMs incorporate weakly related profile phrases into the rewritten query. As profiles grow through continued interaction, this problem becomes increasingly severe. We argue that this limitation arises from the intermediate rewrit- ten query. First, personalization must be verbalized through explicit profile phrase injection in the discrete token space, which cannot fully express implicit, retrieval-relevant meanings. For example, a user’s interest in technology may imply science fiction when search- ing for books or futuristic when searching for clothing. Second, queries generated by zero-shot LLMs are not directly optimized for retrieval. Even when the selected profile phrases are relevant, inserting them into the query does not necessarily produce a good search query. To overcome these limitations, we propose Personalized Con- versational Dense Retrieval (PCDR), which performs retrieval- aware user profile denoising directly in the dense retriever’s latent embedding space. PCDR jointly encodes the conversation history and user profile into a single query embedding, allowing implicit personal information to influence retrieval without being explicitly verbalized in a rewritten query. Trained with a small number of per- sonalized relevance judgments from the iKAT 2023–2025 datasets, PCDR learns to condition the encoding of the contextual dense embedding only on the relevant parts of the user profile that are also useful for search. This can be viewed as an implicit user profile denoising process that is optimized directly for the retrieval task. We further distill knowledge from personalized human rewrites to stabilize training. Figure 2 illustrates the two-stage continual train- ing that produces PCDR from a base Qwen3 0.6B embedding model. Visualization analysis illustrates that PCDR focuses on fewer but more essential profile signals than explicit profile phrase selection. We evaluate PCDR by incorporating it in a search system par- ticipating in the online interactive track of iKAT 2026. The results show that for complex real-world information needs, PCDR alone produces effective personalized retrieval results, while combining it with heterogeneous retrievers provides further improvements. 2
