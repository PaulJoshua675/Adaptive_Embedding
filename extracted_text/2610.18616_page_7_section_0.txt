We trace this process in the 7,108 trajectories of Full DKGI with GPT-6-Luna on the full test sets (Figure 2). The agent searches first and then writes pro- grams. A trajectory starts with file reads and rg searches, and Python makes up 8.2% of the calls be- tween 20% and 40% of a trajectory and 83.3% of the calls in its last 20% (Figure 2a). The agent writes 4.0 programs per query on average. Of all programs, 75.0% contain a full node scan and 35.5% a one-hop traversal. In 42.3% of the queries, a program contains scoring or ranking, a multi-hop traversal or a set operation (Figure 2b). The two operation types in blue have counterparts among the predefined graph tools, as neighbors performs a one-hop traversal and get_node looks up a node by its ID. Programs reuse IDs from earlier outputs and code from earlier programs. Of all programs, 48.4% contain a node ID shown in the output of an earlier turn, and almost all of these programs check the IDs (48.0% of all programs, Figure 2b).
