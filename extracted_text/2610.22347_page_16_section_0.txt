Speculative Forcing for Efficient Autoregressive Video Generation A IMPLEMENTATION DETAILS We retain the released backbone configurations except for the denoising policies evaluated in this work. For LongLive (Yang et al., 2025a), we use an attention sink of 3 latent frames, a local attention window of 12 latent frames, and 3 latent frames per chunk. Short and long videos contain 81 and 477 frames, respectively. For Lingbot-World 2.0 (Gao et al., 2026), we use the 1.3B Causal-Fast model with an attention sink of 6 latent frames, a local attention window of 18 latent frames, and 4 latent frames per chunk. Each benchmark video contains 253 frames. Lingbot-World 2.0 additionally receives a per-frame camera trajectory encoded through Pl¨ucker embeddings derived from relative camera-to-world poses. We retain the original camera-conditioning pathway, including per-video translation normalization by the maximum translation magnitude. For the main results, the training- free thresholds (τred, τstab) are (0.497, 0.327) for 5-second LongLive videos, (0.357, 0.235) for 30-second LongLive videos, and (0.375, 0.300) for Lingbot-World 2.0. We retain the original denoising schedules so that early commitment operates on the intermediate clean estimates supervised during distribution-matching training. In our configurations, LongLive and Lingbot-World 2.0 share the shifted timesteps [1000.0, 937.5, 833.3, 625.0], obtained from a 1000-step flow-matching schedule with a shift of 5.0. A token accepted at step k undergoes exactly the first k steps of this schedule. Uniform-step baselines use the same prefixes, allowing us to compare token-wise acceptance with a shared exit step along the same trained denoising trajectory. The learned verifier reads hidden states from the generator’s final transformer block without an additional backbone forward. The head consists of layer normalization and three 3D convolutions with channel dimensions 1536 →96 →48 →1. The first two convolutions use 3 × 3 × 3 kernels with GELU activations, and the last uses a 1×1×1 kernel. The head’s output is average-pooled over 2 × 2 × 2 token blocks and expanded back to the original grid using nearest-neighbor interpolation. The head has 4.11M parameters and is shared across denoising steps. We train only the head using the smooth-ℓ1 loss and Adam with a learning rate of 10−3 and batch size 4. Within each chunk, accepted tokens retain the layer-wise keys and values computed at their accep- tance step, while active tokens update theirs as denoising continues. The cache can therefore contain KV states from different denoising steps. Once the chunk is complete, the generator performs a clean forward pass over the assembled output at timestep 0, refreshing the KV states of all tokens regard- less of their acceptance steps. Subsequent chunks thus attend to history states computed from the completed clean output. We apply spatiotemporal smoothing to each verifier’s score map before thresholding at every veri- fication step. Spatial smoothing uses a normalized 9 × 9 Gaussian kernel with a standard deviation of 1.0 token and reflect padding, applied independently to each latent frame. Temporal smoothing then averages scores over the current and subsequent latent frames within the same chunk, using Gaussian weights with a standard deviation of 1.0 latent frame. Only tokens that have not yet been accepted are forwarded through the generator at subsequent denoising steps. We reduce execution overhead through shared indexing and in-place KV updates. We also merge each chunk’s clean pass with the next chunk’s first denoising pass while preserving timestep conditioning, attention dependencies, and KV update order. All baselines use the same applicable execution optimizations for fair throughput comparisons. B EVALUATION DETAILS B.1 EVALUATION METRICS We follow VBench (Huang et al., 2023) for 5-second videos and VBench-Long (Huang et al., 2024) for 30-second videos for LongLive, reporting all 16 dimensions. For Lingbot-World 2.0, we aggre- gate six quality dimensions using VBench’s official normalization and weights, excluding temporal flickering because intended camera motion can produce frame-to-frame pixel changes. Following Reward Forcing (Lu et al., 2025), we measure Drift as the standard deviation of imaging-quality scores across non-overlapping 2-second segments, averaged over videos. We use VBench’s MUSIQ model and preprocessing, with 7 complete segments per Lingbot evaluation and 15 segments per 30-second LongLive evaluation.
