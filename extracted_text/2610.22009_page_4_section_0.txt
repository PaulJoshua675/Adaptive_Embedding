Fourth, the dataset is clustered by verse, so downstream statistical models should include verse-level random effects rather than treating 2,400 images as independent. Implications. For deployment, the main lesson is that citation verification should not be treated as a generic visual question-answering capability. Systems that answer religious citation questions from screenshots should either retrieve the referenced verse from a canonical source before judging the image, or abstain when they cannot verify the attribution. Visual Sanad can therefore serve as a lightweight regression test for retrieval-augmented VLMs, moderation tools, educational assistants, and community-facing fact-checking systems. Community relevance. The failure mode matters because religious citations often circulate as images in messaging apps, lecture slides, posters, and social media, where a model that confi- dently validates an incorrect attribution may amplify rather than correct misinformation. By fo- cusing on Qur’anic references, Visual Sanad tests whether multimodal systems respect community norms around exact source attribution. Reproducibility. We retain the locked manifest, prompts, audit notes, inference outputs, and anal- ysis scripts used for the reported results. Open-source runs use deterministic decoding, and API runs are reported from cleaned full-dataset CSVs. 6
