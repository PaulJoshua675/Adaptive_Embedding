Conversational Search systems resolve a user’s information need through multiple turns of natural-language interaction [17, 63]. Personalized Conversational Search systems additionally condition conversational retrieval on a profile of persistent facts about the user. The TREC Interactive Knowledge Assistance Track (iKAT) [5] targets this problem by providing human-curated information- seeking conversations accompanied by user profiles consisting of natural-language statements. This year, iKAT 2026 introduced an interactive task that requires the participating retrieval system to interact with the same simu- lated user [51] across multiple conversation sessions. Submitted systems should continuously extract new persistent user facts and append them to the profile throughout these sequential interactions. The profile therefore grows monotonically as the dialogue unfolds. This accumulation comes at a cost. Long-term memory mecha- nisms for conversational agents are typically designed to add new information more readily than they consolidate or remove it [52, 66].
