Each candidate is expressed as text: choice tasks retain the supplied option content, numerical tasks specify values or intervals with their units, and pointing tasks name cells relative to the current image region, such as “top-left” or “center”. These descriptions provide the candidate content that the VLM contextualizes with the observation and question. We instantiate MJev-Spatial with Qwen3.5-4B (Qwen Team, 2026). Its vision encoder and merger convert the images into visual tokens, which are encoded together with the question, preceding refinement history, and current candidate descriptions in a causal sequence. Each candidate description ends with an option-end marker, and the complete candidate list ends with a decision marker. After the first 31 language layers, the hidden state at each option-end marker represents that candidate in the context of the observation, question, and preceding candidates. The hidden state at the decision marker incorporates the full candidate set and serves as the decision representation. The markers reuse existing vocabulary entries, so no new embeddings are introduced. Section A.2 gives the exact sequence layout. FreeRet finds that the final MLP can shift representations toward lexical prediction at the expense of semantic matching (Zhu et al., 2026d). Motivated by this observation, we compute candidate scores before this transformation using the final full-attention layer’s pretrained query and key projections. The decision representation supplies the query, and each candidate representation supplies a key. Because candidate representations are causally ordered, training deterministically shuffles options, while evaluation follows the benchmark’s specified ordering protocol. 3.3 Training Recipe We convert existing spatial annotations into 12.3M training QA and supervise all refinement stages of each question in one language-backbone forward pass. Length grouping and cross-GPU load balancing reduce padding and workload imbalance. Training data. Our training corpus contains 12.3M question–answer pairs converted from RefSpatial (Zhou et al., 2025a), SAT (Ray et al., 2025), SenseNova-SI (Cai et al., 2026), VSI-590K-image (Yang et al., 2025a), and VST-P (Yang et al., 2025b). The training data cover multiple-choice spatial question answering (7.1M QA), point localization (3.5M QA), length estimation (1.6M QA), angle estimation (120K QA), and counting (38K QA). These totals count original QA before expansion into decision stages. See Table 7 in Appendix B for the source-by-task breakdown, with conversion and validation details provided in the same appendix. Joint stage supervision. Every supervised decision uses categorical cross-entropy over its current can- didate set. A choice question has one target class, whereas numerical and point questions can contain a sequence of target classes; point refinement also introduces image crops between stages. The annotated answer determines the complete target path and any corresponding crops before training. We serialize the stages in causal order, with each target choice and any subsequent crop placed after the corresponding deci- sion position. Earlier decisions therefore cannot attend to later choices or crops, while teacher forcing allows all stage losses to be evaluated in a single language-backbone forward pass.
