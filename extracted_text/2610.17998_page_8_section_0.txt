At the same K, EPR-SP uses 44% less memory than BASELINE. The gap narrows as K decreases, with EPR-SP outperforming BASELINE at the tightest CIFAR10 budget. BASELINE recovers the lead on TIL accuracy while EPR-SP retains a forget- ting advantage, suggesting the occurrence of a buffer-saturation effect in which additional low-resolution samples yield diminishing returns compared to full- resolution ones. These results confirm that in the presence of stringent memory constraints, as in the case of neuromorphic hardware, SAM-guided patch replay can obtain better results than standard replay. 5.2 Comparison Under Equal Sample Budgets Figure 3 further highlights the practical benefit of patch-based replay when the memory budget is extremely limited. When performance is plotted against the number of stored samples per class, the BASELINE generally achieves higher accuracy than EPR-SP at the same nominal number of samples, especially as the buffer size increases. However, an EPR-SP sample requires only about 56% of the memory of a full image, therefore the resulting performance gap is relatively small compared to the memory savings. Overall, EPR-SP preserves competitive TIL and CIL accuracy while reducing the storage cost by 44%. This suggests that, in highly memory-constrained settings, EPR-SP offers a favorable trade- off: it sacrifices only a limited amount of accuracy while enabling a much more compact replay buffer. This behavior is particularly relevant for neuromorphic and embedded scenarios, where memory is often a stronger constraint than raw computational capacity.
