A neural network transforms its input into intermediate features before making a prediction. When several prediction tasks use those same features, they use a shared representation. For example, object recognition and distance estimation can draw on the same internal description of an image. The representation must then preserve information useful for both purposes. With limited capacity, which information remains readily accessible? We study this question through reconstruction: several predictors try to recover different target signals from one internal code. We call the relative inequality in their readout precision representational specialization. The object of study is thus a functional bias—which targets are more precisely recoverable—that can shape what later predictors can learn or use. Such inequality is well established. Features with matched computational roles can acquire different repre- sentational strength because of complexity, prevalence, learning order, or position (Lampinen et al., 2024). Learning one useful feature or information source can also suppress learning another, as studied under gradient starvation and modality competition (Pezeshki et al., 2021; Huang et al., 2022). These findings motivate a further question: how does an observed specialization depend on the processes that form it, sustain it, and change it? A condition that creates a bias need not be the condition currently keeping it in place. To investigate these processes, we vary two parts of learning separately. Acquisition determines how precisely each target is observed; updating determines how strongly each reconstruction error contributes to changing the model.
