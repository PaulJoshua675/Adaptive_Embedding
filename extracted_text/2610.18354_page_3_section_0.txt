However, we argue that discriminative signal in strategic selection largely comes from evolving game history (actions and outcomes), and two consecutive rounds with near identical embeddings can call for opposite model choices. In the absence of routing methods that explicitly model this structure, we also consider bandit-style per-round feedback [2, 29] as a paradigm suited to a non-stationary interactive signal. 3 Strategic LLM Selection 3.1 What is Strategic Selection? In multi-agent systems, a setting is non-strategic if the objective concerns only the overall performance of the system or its performance-cost trade-off. A setting is strategic if it also accounts for the interaction between agents, including how they communicate, coordinate, and negotiate. Modelling this interaction can produce systems that are more reliable and efficient. In a cooperative setting, it improves the coordination between agents [12]. In a competitive setting, it gives the deployer more control over the interaction with an opponent and helps steer the interaction toward the deployer’s preferences. For example, for a given business, the reward of the negotiation, the cost of using AI, and the consistency (i.e. associated risk) of the results can all matter at varying levels. 3.2 Problem Formulation We formalise strategic LLM selection as a repeated, contextual, general-sum game with two layers: a base game that fielded models play, and a selection meta game that the deployers play. Strategic selection focuses on the meta layer, a two-player game with i indexing the player (deployer) and −i its opponent. Repeated games are played over rounds t = 1, . . . , T, where each round t is associated with context xi,t ∈X (e.g. game setup, instructions, past history). Deployer i’s set of pure strategies (meta game actions) Si is defined as the set of models {1, . . . , Mi} in its portfolio. In each round, i selects a model si,t ∼σi(· | xi,t), where σi ∈∆(Si) is a mixed strategy (i.e. selection policy). Per-round context xi,t is then passed down to the fielded model to produce the base game action si,t(xi,t) →ai,t. The base game (i.e. of fielded models si,t against s−i,t) produces a utility vi,t at an inference cost ci,t (tokens spent), as well as a net gain of gi,t that captures their trade-off. Together, player i’s game outcome is denoted as ξi,t = (si,t, ai,t, gi,t). Drawing from the online learning literature, each selector maintains an adaptive parameter vector θi,t that updates after each round based on observed context xi,t and game outcome ξi,t: si,t ∼σi(· | xi,t; θi,t), θi,t+1 = UPDATE(θi,t, xi,t, ξi,t).
