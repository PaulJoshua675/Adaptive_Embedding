SNN classification results The agent configurations on MNIST are compared in Table 2. For Claude Opus 4.6, the detailed prompt raises the mean maximum accuracy over ten runs paired by seed from 91.13 ± 0.44 % to 92.15 ± 0.62 %, and the best result from 91.65 % to 92.83 %. It gives the higher run maximum in eight of the ten pairs, and the two-sided exact Wilcoxon signed-rank test yields 𝑊= 5, 𝑝= 0.0195, which remains significant after the Holm correction over the six tests of Section 4.6. The paired gain averages 1.02 ± 0.90 percentage points (Table 17), so for this model the effect is comparable to the spread between runs. For Perplexity Sonar and Qwen3-30B-A3B-Instruct-2507, none of the 250 decoders proposed per run under the simple prompt outperformed the baseline, so the run maximum for both models matched the baseline of 79.88 % in all ten runs (std = 0.00). The detailed prompt lifted both models above the baseline, though to different extents: for Perplexity Sonar, the individual-run maxima ranged from 90.93 % to 92.70 % with a mean of 91.76 ± 0.56 %, so the 90 % reference point was exceeded in all ten runs, whereas for Qwen3-30B-A3B- Instruct-2507 the mean maximum was 85.88 ± 2.42 % and the best run reached 89.16 % without crossing it. For both models the prompt effect is significant by the same paired test (𝑊= 0, 𝑝= 0.00195, the minimum attainable value at 𝑛= 10; Tables 15 and 13). On the scikit-learn digits dataset, the effect of the detailed prompt depended on the analyst model. For Claude Opus 4.6, the mean run maximum increased from 95.07 ± 0.52 % to 96.12 ± 0.66 %, with all ten runs reaching 93 %. For Perplexity Sonar, the mean changed from 93.44 ± 0.57 % to 93.31 ± 0.93 %, while the number of runs reaching 93 % decreased from 9/10 to 8/10, although the best observed result increased from 93.89 % to 94.17 %.
