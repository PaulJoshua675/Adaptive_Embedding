Stoch deter - Code Stochastic when the model's transmission events or case generation are stochastic; probabilistic fitting, MCMC estimation, or confidence intervals alone do not make the transmission process stochastic. - When a paper presents separate deterministic and stochastic transmission versions, such as deterministic fitted trajectories alongside simulations from a stochastic version, code both Stochastic and Deterministic. Code available - Data-only repositories and code offered only on request without accessible model code are coded False. Transmission route - Explicit transmission through bodily fluids, infected or deceased people, or contaminated objects is coded Human to human (direct contact); close-range airborne or droplet spread without specified physical transfer is coded Airborne or close contact. - Code Vector/Animal to human only when the model represents transmission from an animal or vector to a human, not when an animal reservoir is mentioned without being modeled as a route. - Code Sexual when sexual transmission is represented as a route; also code Human to human (direct contact) only if that route is separately represented. Interventions type - Ring vaccination and other vaccination strategies represented in the model are coded Vaccination; vaccination mentioned only in background or as a response not represented in the model is not coded. - Code Contact tracing for modeled identification or tracing of contacts, and Quarantine for modeled restriction of exposed contacts; code both when both are represented, while isolation of cases alone is coded Other. - Code Treatment centres when the model represents Ebola treatment centres specifically; hospital admission, hospital care, or hospital transmission represented without a specific treatment-centre component is coded Hospitals. - Code Treatment when the model represents a therapeutic treatment as an intervention, not merely hospital care or treatment-centre admission. - Code Behaviour changes when the model explicitly represents changes such as reduced contact or social distancing as an intervention, not merely when a change in transmission is observed or inferred. - Interventions represented in the model that fit no named option, including case isolation alone, infection-control procedures or PPE, and public-health education, are coded Other. Coding rules • SARS written by the Prompt Agent REVIEW CODING PROTOCOL Code what the paper's own work represents, not background, citations, or general discussion, and record every applicable option across models. Code model_type whenever a dynamic transmission model is present, using Other if no named type fits; leave an array empty only when the paper has no represented value for that field. Model type - Code Other for a dynamic transmission model that does not fit Compartmental, Branching process, or Agent / Individual based, such as a phenomenological growth model. - Back-projection, MCMC, regression, or spatial mapping alone is not a dynamic transmission model type; classify any dynamic transmission model used alongside these methods, and use Other if the only dynamic transmission model is a non-listed form. Stoch deter - Code Stochastic when randomness governs infection or transmission, even if the model reports expected-value or otherwise deterministic-looking outputs. - MCMC, parameter distributions, or probabilistic observation and error models alone do not make transmission Stochastic; code Deterministic when the transmission process itself is deterministic. Code available - An open-access license, article access, or a description of model methods does not establish code availability; code is available only when the paper supplies model code or identifies an accessible code repository or archive. Transmission route - Code airborne, aerosol, or droplet transmission and close-contact or proximity transmission as Airborne or close contact unless the model explicitly represents direct person-to-person contact, which is coded Human to human (direct contact). - Code an explicitly sexual transmission route as Sexual and an explicitly represented animal-to-human or vector-to-human route as Vector/Animal to human. 36
