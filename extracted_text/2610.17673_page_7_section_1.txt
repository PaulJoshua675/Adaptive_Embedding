In this paper, we tackle the problem of over-personalization caused by the excessive integration of user profile terms in existing person- alized conversational query reformulation. We propose to perform user profile denoising in a latent semantic space, optimized di- rectly for retrieval performance. In this way, more precise user information is integrated into the latent representation of the con- versational information need to enhance search. Specifically, we train PCDR, which performs retrieval-aware user profile denoising directly in the dense retriever’s embedding space. Initialized from a conversational dense retriever, PCDR requires only a small set of previous-year iKAT relevance judgments, augmented by light distillation from personalized human-rewrite embeddings. Online evaluation on the iKAT 2026 interactive runs shows that PCDR alone can produce satisfying tailored search results, and combining it with heterogeneous retrievers yields further improvements. Our visualization analysis further illustrates that the profile denoising goes beyond shallow semantic relevance. Future work includes removing the reliance on distillation from human query rewrites, so that PCDR is trained from relevance signals alone and no longer needs rewritten queries at any stage. It also includes scaling training with synthesized end-to-end personalized conversational retrieval datasets and studying continual adaptation from ad-hoc search to conversational search and ultimately personalized conversational search.
