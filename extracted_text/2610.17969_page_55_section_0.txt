We repeat the from-scratch comparison on Tiny-ImageNet-200 with a ViT-S, images with 4× the CIFAR pixel area, and 200 classes (Table 16). Patch size 8 preserves the same 8 × 8 patch-token grid as the CIFAR model with patch size 4 instead of increasing the token count. GCT has the highest clean top-1 accuracy, 59.2%, compared with 56.4% for LayerScale. The contrast and input-scale results follow the pattern in Table 15. The noise comparison differs. GCT scores 48.4%, compared with 48.2% for nGPT and 46.2% for QK-Norm. The noise ordering changes under the combined change in dataset, resolution, and backbone. NormFormer reaches 43.2% clean top-1 accuracy, about 12 percentage points below most other baselines under this shared recipe. We report this result under the shared recipe, without architecture-specific retuning. The cause of the gap remains unresolved. GCT has the highest measured accuracy in each column of Table 16. Across both vision datasets, GCT combines the highest measured clean accuracy with strong photometric and input-scale robustness. These observations complement the internal-rescaling tests in language modeling, while the dataset-dependent noise results distinguish scale robustness from robustness to arbitrary input perturbations.
