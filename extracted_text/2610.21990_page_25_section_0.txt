3.2 Modalities 3.2.1 Synthetic low-light adaptation algorithm To show that semantic segmentation on low-light images can be improved using additional modal- ities, it required a robust real-environments informed synthesis pipeline. The current methods are limited in terms of: input data format (relying on the RAW format), noise modeling (linear noise used as implicit), global histogram matching (introducing unwanted artifacts, as colour and lumi- nance information are not separated), and fixed parameter configuration (controlling environment variables is impossible). As a result, VesperMUSE framework proposes a novel pipeline for obtaining synthetic low-light images from RGB data. The algorithm aims to achieve a physics-informed degradation, accounting for the effect low-light conditions have on the visual representations. Real-World Illumination Distribution.
