The game, Minecraft Java Edition 1.20.4, ran in survival mode on Easy difficulty in a randomly generated world, with cheat commands disabled and no human input during the run. Beyond a brief note that they were working as a team of four, the agents’ instructions about the game consisted of a single paragraph: “The objective is to defeat the Ender Dragon, starting from the spawn of the session’s shared Minecraft survival world. [. . . ] This is the only criterion. Any means of meeting it within the rules of survival mode is permitted, and the players decide how to share the work.” Their other instructions are the same as for any environment: verify the result of each action, build reusable tools, record lessons in a memory shared by the team, and report outcomes honestly. 2.1. Agents and tools Each of the five agents, the four players and the Observer, is an instance of the same general-purpose coding agent, run with Gemini 4 Argon on its own cloud machine. Each has the tools it uses for software work, including a code workspace with version control, a shell, file editing and web search, and a persistent memory with a private part and a part shared by the team. The agent compacts its context when it grows too long, as it does for software work; the instructions ask agents to keep in memory what must survive a compaction, such as work in progress and next steps. None of the 2,839 programs the players ran during the session (2,783 before the win) made a network request or referred to a web source, and neither their chat nor the Observer’s report mentions one. Players interact with the game only through a command-line client. It sends a JavaScript program to the player’s Mineflayer bot on the game server, waits up to a timeout that the agent chooses (60 seconds by default), and prints what the program logged and returned. The program runs as the body of an asynchronous function that receives the bot, with the pathfinding plugin loaded and no helpers added.
