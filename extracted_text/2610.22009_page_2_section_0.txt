Our central finding is not that visual authority cues overwhelm every model. Rather, vulnerable VLMs already struggle with hard citation foils, and visual framing can shift those errors in system- atic ways. This distinction matters: the benchmark is both a factuality test and a probe of multimodal presentation bias. 2 Dataset: Visual Sanad Source text. We use the AlQuran Cloud en.sahih edition as the source for English verse text and references [Islamic Network, 2026]. Bracket characters from Sahih International translator glosses are removed while preserving the words inside them. Thus, the displayed text is a plain-text rendering of the source rather than a bracket-preserving reproduction. Base verses and factual states. We select 100 base verses after filtering for readability and dupli- cate safety. Each base verse is paired with four factual states: 1. Valid: the displayed reference is the true reference. 2. Near-neighbor: the displayed reference is a nearby ayah in the same surah. 3. Same-surah far: the displayed reference is a farther ayah in the same surah. 4. Cross-surah lexical: the displayed reference is from another surah with lexical overlap. Invalid foils are screened with exact, character-level, and asymmetric token-containment checks to avoid cases where the target quote is effectively embedded in the foil. Visual conditions. Each quote–reference pair is rendered under six image conditions: plain, decorative, islamic_authority, decorative_islamic_authority, neutral_authority, and decorative_neutral_authority. Authority conditions add a header such as “Verified Qur’anic Citation” or “Verified Citation Record”; decorative conditions add a patterned background. The final dataset has 100 × 4 × 6 = 2,400 images. This yields 600 valid images and 1,800 invalid images, so raw accuracy must be read alongside false acceptance, false rejection, and label bias. Audit. The dataset was audited in three passes before locking. Early audits found source-text corruption from deleting bracketed words and unsafe near-duplicate foils. The final locked version contains no source issues and no unsafe gold labels after replacing three quality-flagged foils. Ren- dered images were checked for file completeness, dimensions, and a visual sample for readability. 3 Experimental Setup Task. Models receive one rendered image and must return VALID, INVALID, or ABSTAIN. The main metric is false-accept rate on invalid trials: the percentage of invalid quote–reference pairs labeled VALID. We also report false-reject rate on valid trials and discrimination, computed as 100− false accept −false reject; a constant VALID model scores near 25% raw accuracy but near-zero discrimination. Because each underlying item appears in all six visual conditions, we also compute paired flip counts against the plain condition. Prompts. We use two prompts. The natural prompt asks the model to decide whether the dis- played quote belongs to the displayed reference. The de-biased prompt adds one cautionary instruc- tion: “Do not treat decorative design, religious-looking borders, or verification headers as evidence that the citation is correct.” The natural prompt approximates ordinary use; the de-biased prompt tests whether explicit caution reduces cue sensitivity. Models and decoding. We evaluate GPT-4o, GPT-4.1, GPT-5.5, GPT-5.6-Terra [OpenAI, 2026], Qwen2.5-VL-7B/32B [Bai et al., 2025b], Qwen3-VL-8B/32B [Bai et al., 2025a], InternVL3.5- 8B/38B [Wang et al., 2025], MiniCPM-V 4.5 [Yu et al., 2025], and Gemma 4 12B-IT [Gemma Team, 2026]. Each completed model–prompt pair is run over all 2,400 images. Open-source runs use greedy deterministic decoding with do_sample=False and fixed seed 31.
