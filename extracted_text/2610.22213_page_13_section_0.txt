4.3 Dimension-Independent Bounds Eq. (7) exhibits an explicit dependency on the dimensionality d, which can lead to vacuous general- ization bounds for high-dimensional problems [18, 44]. To address this issue, we consider loss functions of the structure f(w; z) = ℓ(y, w, ϕ(x) ), (37) where ϕ : X 7→Z is a feature map and ℓ: R2 7→R+. This structure is based on the linear predictor and the target, and thus applies to a broad range of regression problems [22, 44]. Furthermore, we assume a fast decay of eigenvalues for the kernel function induced by ϕ(·), which is widely used in the analysis of kernel learning methods [3, 45, 57]. Assumption 4. Let {λk} denote the nonincreasing sequence of eigenvalues of K(x, x′) = ⟨ϕ(x), ϕ(x′)⟩. We assume that these eigenvalues admit a polynomial decay of degree p > 1, i.e., there exists β > 0 such that λk ≤βk−p for all k ∈N. For problems with the structure (37) when the weight vector w and the data ϕ(x) are controlled by norms, a localization analysis using Assumption 4 enables the following dimension-independent bound on the uniform deviation between the empirical and population gradients [35].
