Code renders from our harness guide video generation with Gemini Omni Flash 1.1 for robot manipulation scenes (top) and Seedance 2.5 for a GPT-6 Astra scene (bottom). 6 APPLICATIONS OF 3D CODING Robotics. 3D coding enables the construction of articulated assets and scenes with explicit geometry and physical constraints for simulated robot tasks. Programs encode rigid-link geometry, joint axes, and joint limits as editable parameters, supporting programmatic checks and controlled variation of object dimensions, articulation, and initial poses. These task instances can be executed in simulations to generate robot interactions and observations. To provide a preliminary evaluation, we import an articulated asset validated and exported with 3DCodeVerse tools into MuJoCo and compare rendered observations with frozen UWM (Zhu et al., 2025) predictions across 12 cases spanning two assets, two contact states, and three control sequences, using complete scene state for rendering and image history with matched robot commands for UWM. Code renders and their UWM VAE reconstructions each pass a fixed door-and-handle geometry check in 12/12 outputs, versus 7/36 UWM predictions. These results show that 3D code can help generate articulated assets and scenes for robotics simulation with explicit geometry and physical constraints. Video generation. 3D coding provides an editable interface for controlling the spatial and temporal conditions of video generation. Programs specify scene layout, object articulation and motion, and camera trajectories. We render generated 3D scenes using programs and harness them as reference videos, using the full sequences to condition Gemini Omni Flash (Google DeepMind, 2026) and Seedance 2.5 (ByteDance Seed, 2026). The rendered videos supply spatial and temporal guidance, while the video models are used to refine visual appearance. We present paired reference and generated frames to examine how the specified layout, object motion, and camera trajectories are preserved. This application connects explicit scene programs with video synthesis. 7
