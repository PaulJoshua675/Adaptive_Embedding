This property is crucial for post-training generative models, where the effectiveness of reinforcement learning hinges on the accuracy and stability of the reward signal. 5 Experiments In this section, we conduct comprehensive experiments to demonstrate the advantages of the Decomposed Graded Verifier as a generative reward model and the superiority of the pairwise verification mechanism in rule-governed world modeling scenarios. 5.1 Experiment Setup Training Datasets. For traditional text-to-image tasks, we use textual prompts from ShareGPT-4o- Image (Chen et al., 2025), the same data source used for verifier training. For rule-governed world modeling scenarios, we construct six game-based tasks to comprehensively evaluate generative models’ abilities in path planning, logical reasoning, geometric construction, pattern induction, character recogni- tion, and spatial reasoning . • Maze & Maze-Hard. Find a valid path from the red start circle to the blue end cross without touching or crossing any black walls. Maze-Hard contains larger-scale maze instances. • Sudoku & Sudoku-Hard. Fill the blanks in a 4 × 4 Sudoku grid so that each row, column, and 2 × 2 subgrid contains {1, 2, 3, 4} exactly once. Sudoku-Hard contains more blanks. • Auxiliary Line Construction & Auxiliary Line Construction-Hard. Draw auxiliary lines in a geometric figure. The hard setting requires multiple compositional constructions. • Sequence Prediction & Sequence Prediction-Hard. Predict the next geometric figure from shape or color patterns. The hard setting requires simultaneous color-shape changes. • Word Search & Word Search-Hard. Locate the target word in an N × N grid, where each row contains one character in the correct order. The hard setting corresponds to a larger N. • 3D Projection & 3D Projection-Hard. Generate the specified 2D orthographic view of a 3D structure, such as the top, front, or side view. The hard setting uses larger 3D structures. Training Details. For traditional text-to-image tasks, we adopt Stable-Diffusion-3.5-medium and FLUX.1- dev (Labs et al., 2025) as the backbone generative models. For rule-governed world-modeling scenarios, we use Qwen-Image-Edit-2509 (Wu et al., 2025) as the backbone. All models are trained for 200 steps using the DiffusionNFT algorithm (Zheng et al., 2025) on 16 NVIDIA A800-80G GPUs. 5.2 Text-to-Image Generation Graded Rewards Are Better than Binary Rewards.
