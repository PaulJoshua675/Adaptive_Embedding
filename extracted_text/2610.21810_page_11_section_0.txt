A.2 Output fidelity and statistics Each domain is tokenized with the model’s own tokenizer and cut into 2,047-token chunks: 128 per domain for web, code, math, chat and multi5 (262,016 tokens), and 16 per language for the 15 languages of multi15 (491,280 tokens), 880 chunks per setting. Documents are normally truncated to 4,000 characters, and those under 200 characters are dropped; short multi15 language sets fall back to untruncated documents. Statistics. All intervals are 95% percentile boot- strap intervals with seed 0. Task scores and ben- efit retained use 2,000 item-bootstrap replicates; KL uses 2,000 replicates over 2,047-token chunks, paired across settings for ratios; paired task differ- ences use 10,000 item replicates. A.3 Quantizers and encoding The trellis uses a 16-bit state, two values per step and tail-biting with two Viterbi passes. Its HYB table is built from a 512-entry k-means codebook of a 2-D standard Gaussian. The code scale factor is .95 at 2–3 bits, .90 at 3.5 bits and .85 at 4 bits on DeepSeek and Qwen; LongCat uses 1.0 at 2 bits and the same values above; at 1.5 bits the fac- tors are 1.0 and 1.05. The rate is b + 16/d bpp; the shared lookup table is not counted for DeepSeek and Qwen and adds about 6 × 10−6 bpp for Long- Cat. RTN stores a minimum and a scale per group, counted as 2 × 16 bits. NVFP4 has an e4m3 scale per 16 values and one fp32 scale per table (4.5 bpp); MXFP4 has a power-of-two scale per 32 values (4.25 bpp). Encoding cost and software. Encoding the 2- bit CP table takes about 3.1 h on 4 H200 GPUs for DeepSeek (about 12 GPU-hours), 0.83 h on 4 GPUs for Qwen, and 5.18 h summed over Long- Cat’s 12 tables. Software is PyTorch 2.14.0 and Transformers 5.17.0. The k-means table is not bit- reproducible across independent encodes, so the LS controls reuse the stored symbols of the norm- restoration tables. The Qwen RTN baseline keeps its scale and minimum in fp32 although its rate counts them as bf16. The table sizes in the main results are logical code and metadata sizes. SSD files may also re- quire page padding (Appendix G.1). The shared decoder state is negligible for these tables; omitting its few kilobytes does not change any displayed rate. The RTN metadata convention above is a storage- accounting convention: Qwen’s evaluated imple- mentation actually retains those values in fp32.
