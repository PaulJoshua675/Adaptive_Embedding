Equal weighting is the unit-agnostic reference. The manual λsup = 100 rule is tuned at κ = 1 and transferred. Uncertainty weighting, gradient-norm balancing, and NTK-trace balancing adapt from scale-sensitive training statistics. None of these baselines explicitly performs unit conversion, and each baseline degrades for at least one off-reference unit system. Equal weighting reaches a worst-case relative L2 error of 2.973 across Burgers and Helmholtz because equal loss weights conflate unit conversion with task preference. The NDA-typed objective types the output head and divides each term by an observable characteristic scale from App. H. The NDA-typed objective is invariant by construction and remains in the low-error range across κ, with worst case 0.015. The same objective also performs comparably at the reference scale without tuning, adaptivity, or access to the solution. This benchmark applies the loss-aggregation rule of Sec. 2.2 end-to-end, typing both the output head and every loss term. Practitioner guides for PINNs already recommend nondimensionalizing a problem before training (Wang et al., 2023). The typed objective derives this nondimensionalization step directly from the loss-aggregation rule. Thm. 2 shows that every invariant linear alternative whose weights depend only on these characteristic scales must use the same inverse-unit factors. Any remaining scale dependence is restricted to dimensionless groups. Cor. 1 shows that the fixed-αi rule is unique in this class when the declared loss units vary independently. Typing and adaptivity also compose. Applying LRA on top of the nondimensionalized terms, denoted NDA-typed + LRA in Table 17, retains unit-system invariance with worst case 0.005 across κ. This combination lets adaptation adjust dimensionless task preferences after unit conversion, demonstrating compatibility between typing and adaptive weighting.
