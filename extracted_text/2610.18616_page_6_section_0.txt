As a training-free method, DKGI also outper- forms the strongest trained system, GRASP, in H@1 and MRR, on MAG with GPT-6-Luna and on all three datasets with GPT-6-Astra. With GPT-6- Luna in Pi, its margins on MAG are 5.2 H@1 and 1.5 MRR points. With GPT-6-Astra in Pi, its H@1 margins over GRASP are 8.2, 9.0 and 6.7 points on Amazon, MAG and Prime, respectively. Appendix D gives the compar- ison on the test subset. 3.3 Ablation Study Section 3.2 compares DKGI with published sys- tems that differ from it in model, training and graph access. To identify which components of DKGI account for its accuracy, we fix the model (GPT-6- Luna), the harness (Pi), the budgets and the prompt apart from its tool section (Appendices B.1 and C), and vary which actions at (§2) the agent can take. All variants run on the test subset (Table 3). The 2 × 2 design crosses graph access with Python. With predefined graph tools. The agent has four graph tools based on ARK (Polonuer et al., 2026). search ranks nodes by BM25 over their names and summaries, get_node returns the record of an ID, get_schema returns the schema, and neighbors returns at most 20 one-hop neighbors of a node, with optional relation, type and keyword filters. In Graph tools, each graph access is a single call to one of these tools, as in ARK, Graph-CoT and ToG (Polonuer et al., 2026; Jin et al., 2024; Sun et al., 2024). In Graph tools + code, the agent writes and revises Python programs that reach the graph through client calls to the four tools. AvaTaR and KG-Agent also compose predefined tool calls in code (Wu et al., 2024a; Jiang et al., 2025). With the graph files. Full DKGI has the graph files, a shell and Python. In Shell only, the agent combines Pi’s read tool and shell commands such as rg, sed and sort with bash pipelines, loops and arithmetic, while python3, awk, perl and node are blocked. One program restricts Full DKGI to the shell com- mands of Shell only and a single Python run per query, so the agent writes all of its Python opera- tions before it sees the output of any of them. Con- trol variants. Retrieval only removes neighbors from Graph tools, and No edges removes the edge files from Full DKGI. In the closed-book probes (Appendix F), the model answers once from its own knowledge, with STaRK node IDs (the ID probe) or, on MAG and Prime, with entity names mapped to IDs offline (the name probe). With Python, the agent outperforms predefined graph tools in overall H@1. With the shell but no Python (Shell only), the agent scores 68.3 overall H@1, below Graph tools (72.8), and it is also lower on every dataset and in overall R@20 and MRR. It prints entire records (an Amazon product record includes all of its reviews) and follows relations by searching the edge files with rg. With Python, Full DKGI reaches 75.2, 2.4 points above Graph tools, and its MRR is also higher (78.9 vs. 77.6). The lead comes from MAG and Prime.
