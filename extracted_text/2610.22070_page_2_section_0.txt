At each step, the model takes the current observation and user query as input and performs inference using the updated LoRA weights that encode historical information. By separating historical memory from the input context, MaLoW preserves the model’s capacity to attend to current observations while retaining information from the past (Fig. 1-2), with only modest inference overhead. Specifically, MaLoW employs a recurrent HyperNetwork (Ha et al., 2017) to efficiently generate the LoRA weights that encode historical information. At each time step, the incoming video clip and its textual context are first compressed into a compact representation, which is then used to update a set of recurrent hidden states. To model the temporal dynamics of these hidden states, MaLoW maintains two parallel branches: a state-space model (Yang et al., 2024) for modeling local temporal dependencies, and a gated summation branch for preserving global historical semantics. The resulting states are mapped through a linear projection to the LoRA weights used by the VLM. To facilitate training, we further construct MaLoW-Instruct, a comprehensive streaming video dataset containing 381K question-answer (QA) pairs over 56K videos, by adapting public offline video understanding datasets to the streaming setting. To evaluate our framework, we conduct extensive experiments across benchmarks and settings. MaLoW demonstrates state-of-the-art results on streaming video benchmarks, including OVO-Bench (Niu et al., 2025), StreamingBench (Lin et al., 2026) and StreamArena (Zhang et al., 2026d). On the backward split of OVO-Bench, for example, MaLoW outperforms prior memory approaches by 3.9%–11.8% across different video backbones, while incurring modest latency overhead. Across base VLMs ranging from 0.8B to 11B parameters, MaLoW yields consistent performance gains. Beyond streaming video understanding, we further extend MaLoW to the Vision-Language-Action (VLA) setting, where incorporating historical observations and action trajectories improves the action success rate on Simpler (Li et al., 2025) WidowX by 9.3%. Our contributions are summarized as follows: • We propose MaLoW, a new streaming memory framework that internalizes historical context into evolving LoRA weights, introducing a distinct design in which history is represented as weights while current observations remain as input. • We develop a recurrent HyperNetwork that incrementally updates LoRA memory from streaming video and other context. We also construct MaLoW-Instruct, a large-scale training dataset for streaming video understanding, which we will release publicly. • We demonstrate that MaLoW achieves competitive results across streaming video benchmarks, attains consistent gains over diverse base VLMs, and generalizes to VLA settings. 2
