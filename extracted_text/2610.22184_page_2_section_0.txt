None treats it as a general capability in which contact is established and released with any link to move an object across diverse regions of the body. Viewed through this lens, whole-body dexterous ma- nipulation has a useful parallel in dexterous hands, with the limbs and torso taking the roles of fingers and palm. Recent dexterous-hand work shows that strong capabilities emerge from learning to move objects through dense se- quences of intermediate targets, whether by pre-training on anygrasp-to-anygrasp transitions [11] or by tracking hand– object subgoals from human motion through regrasps and finger gaiting [12]. Extending this principle to humanoids introduces a challenge: a dexterous hand with many fingers can often reposition some fingers while the others support the object [13], [14], whereas a humanoid using two arms has fewer independent supports. Releasing one arm may require the other to brace the object against the torso, and changing grasps can require rapid reconfiguration and rolling or sliding contact. This additional complexity calls for a different approach to repositioning across body regions than these existing methods. We introduce Whole-Body Dexterity (WBD), a frame- work for learning whole-body dexterous manipulation through mode-constrained re-grasping (Fig. 2) and deploying it on a real humanoid. We first generate a diverse set of whole-body grasps, then use them to initialize reinforcement- learning experts, WBD-EX. Experts learn to move objects between grasps toward goals specified by an object position and a target grasp mode: a left-arm, both-arm, or right-arm grasp. Transitions allow brief contact loss during movement but require a stable hold in the target mode at goals, so the experts learn how to hand off objects between arms, enabling repositioning across difficult regions such as behind the back and on top of the shoulders. We distill expert trajectories into a controller that uses an object geometry descriptor to refine motion commands into stable whole- body object repositioning, without privileged object state. Our main contributions are: 1) A whole-body grasp generation method defined over mode-typed contact configurations, formulated for ar- bitrary open-link articulated rigid-body systems and demonstrated on a humanoid robot. 2) WBD-EX, per-object repositioning experts built on a mode-constrained re-grasping formulation that uses the diverse grasp dataset. 3) A distillation procedure that turns these experts into a controller conditioned on proprioception and object geometry, refining coarse commands into dexterous manipulation of diverse objects in simulation and on a real humanoid.
