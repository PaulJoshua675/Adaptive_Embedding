Each requested row must be independently reconstructible, while the address function and all remaining model parameters re- main fixed. 3 Conditional Programs 3.1 Conditional Program Representation We propose Conditional Program (CP), a com- pressed representation that preserves the selective access pattern of conditional memory. Rather than storing each embedding directly, CP represents each row with a short code and a reconstruction rule shared across the table. Specifically, each row ei is represented by a code ci and a local scale αi, and reconstructed through a shared function f: ˆei = αif(ci). (6) The reconstruction function is shared across the table, while each row retains only its code and scale. Since reconstruction is performed only for requested rows, CP exchanges storage across the full table for computation on a small subset. The key challenge is to construct a shared re- construction rule that accurately represents diverse learned embeddings using short codes. We sepa- rate each row’s magnitude from its contents and define the normalized vector zi = √ d ei/∥ei∥2. For a code rate b, let Cb denote the set of admissible codes. A natural encoding objective is to select a code whose reconstruction best approximates the normalized row: c∗ i = arg min c∈Cb ∥zi −f(c)∥2 2. (7) At low bit rates, the quality of this approximation depends on how well the shared reconstruction rule captures the statistical properties of the source. This motivates a source model for the normalized mem- ory rows. 3.2 Gaussian Source Modeling Conditional-memory embeddings are learned through repeated updates from diverse inputs and contexts. In hashed n-gram memories, for exam- ple, multiple n-grams may map to the same row, allowing different training signals to contribute to a shared representation (Cheng et al., 2026; Liu et al., 2026). When such contributions are dis- tributed across many coordinates, an approximately isotropic direction provides a useful intuition for the resulting representation. In high dimensions, isotropically distributed directions exhibit approxi- mately Gaussian coordinate statistics after normal- ization (Diaconis and Freedman, 1987). Motivated by this intuition, we model the nor- malized row contents using a common Gaussian source while keeping row magnitudes separate. Specifically, we approximate the coordinate dis- tribution of zi by a standard Gaussian distribution N(0, 1).
