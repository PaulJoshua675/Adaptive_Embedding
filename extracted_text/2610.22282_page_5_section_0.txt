At inference, RPO removes all masks and runs dense attention with the original deterministic sampler. 4.1 ATTENTION-MASS ROUTING The central challenge is to expose a stochastic action without adding a policy head or perturbing the sampler. A routed attention layer already decides how much each query attends to each key, so we let this attention propose the routes. At routed level t, a scoring pass runs the dense attention of every routed layer ℓ∈L and measures how much attention query block q places on key block j. (3) Here αℓ,h i (p, p′) is the dense attention weight from query token p to visual key token p′ in head h of layer ℓ, renormalized over the visual keys, H is the number of heads, and Qq and Kj hold the tokens of blocks q and j. Thus mi,ℓ,q,j is the share of block q’s attention that falls on block j, and zi,u,j averages its logarithm over the routed layers, so one decision serves all of them. The dense option ∗takes the log of the total mass as its logit. The action ai,u ∈Cq ∪{∗} picks a candidate block or dense attention, and T > 0 is a temperature. Intuitively, candidate blocks that already receive much attention are likely to be picked, while the random draw still explores alternatives. For a single routed layer at T = 1, the dense option has probability 1/(2 −mi,ℓ,q,q), so a query block whose attention is already local mostly stays dense. The scoring pass carries no gradient. The draw is therefore an exploration proposal that changes only as the generator itself changes. A keep ratio κ sets the number of candidates Ku = ⌈κ(|Cq| + 1)⌉that a sparse query block keeps, where |Cq| + 1 counts the options of the draw. We perturb every logit in Equation 3 with independent Gumbel noise and rank the options. If the dense option ranks first, query block q attends densely. Otherwise it keeps its safety block and the Ku highest-ranked candidates. For Ku = 1, this is an exact draw from π, and for larger Ku it extends the draw to Ku candidates without replacement. The executed mask µt i applies these routes in every routed layer and head, while the anchor layers stay dense. The generator’s own attention thus decides which blocks stay visible, and no extra parameters define the action. 5
