This motivates a more fundamental question: Can complementary representations improve general-purpose time-series reasoning? We hypothesize that general-purpose time-series reasoning benefits from exposing the model to com- plementary views of the same signal, each preserving different information and inducing different invariances. Rather than requiring a single representation to simultaneously retain all information relevant to downstream reasoning while suppressing nuisance variation, this formulation allows dis- tinct views to provide different inductive biases. We instantiate this principle with two visual repre- sentations: a standard line plot and a normalized delay embedding. The line plot preserves absolute amplitudes, axis ranges, and measurement scales, providing the information required for questions grounded in observed values. In contrast, delay embeddings reconstruct a time series as a trajectory in phase space using time-lagged observations, revealing geometric structure associated with the underlying dynamics (Takens, 2006). We normalize this representation before rendering it as a two- dimensional view, thereby factoring out affine changes in amplitude while retaining the geometry of the temporal trajectory. Our central hypothesis is that combining these complementary views is par- ticularly useful beyond basic perception, where reasoning, prediction, and decision-making require models to exploit temporal structure while remaining grounded in the observed measurements. Building on this representational principle, we design a dual-tower TSLM in which each visual view is processed by a dedicated encoder. We retain Qwen3-VL’s native vision encoder, initialized from SigLIP-2 (Tschannen et al., 2025), to process line plots, and introduce a dedicated DINOv3 encoder (Sim´eoni et al., 2026) for delay embeddings, allowing each view to develop a specialized visual representation before interacting with the language model. The resulting visual features are compressed into a compact set of tokens, 230 for the line plot and 64 for the delay embedding, and concatenated as input to the language model. Beyond this input-level fusion, we adopt Deep- Stack (Meng et al., 2024) to inject multi-level visual features into the early language-model layers, enabling the complementary representations to interact with language processing throughout the network. This architecture provides a compact realization of our central hypothesis while retaining the distinct inductive biases of the two visual views. To test our representational hypothesis and evaluate the resulting dual-tower TSLM, we conduct ex- periments on TSRBench (Yu et al., 2026a), TSExam (Cai et al., 2024), and ChatTS (Xie et al., 2025). Built on Qwen3-VL-8B (Bai et al., 2025), our model achieves 53.2% overall accuracy on TSRBench, substantially narrowing the gap to GPT-5 with text and visual input (55.6%) while surpassing the strongest evaluated dedicated TSLM (36.7%). It also outperforms the compared general-purpose and specialized baselines on TSExam and ChatTS numerical alignment. To assess the contribu- tion of the complementary view, we compare against a plot-only variant trained under the same setup. Adding the delay embedding raises overall TSRBench accuracy from 45.2% to 53.2%, an 8.0-percentage-point improvement, with gains in reasoning, prediction, and decision-making while leaving perception nearly unchanged. Controlled evaluation-time interventions further reveal dis- tinct invariance profiles: the delay-only model maintains nearly unchanged accuracy under positive rescaling and offset shifts, whereas the plot-only model, whose representation retains the measure- ment frame, is substantially more sensitive to these transformations.
