Queries with gold documents in both sets are dis- carded. We randomly hold out 10,000 seen docu- ment queries for testing and 10 % of the remaining queries for validation, using the rest for training. Hierarchical k-means Semantic IDs: DSI (Tay et al., 2022) and NCI (Wang et al., 2022). Both assign identifiers by recursive k-means over document embeddings. The remaining difference between the two methods is architectural. 2. Product Quantization Semantic IDs: ULTRON-PQ (Zhou et al., 2022), in which every identifier token is a quantized code of a document embedding. 3. RQ and RQ-VAE Semantic IDs: Residual quantization DocID is first used in MEVI (Zhang et al., 2023); RQ-VAE DocID is first used in generative recommendation by TIGER (Rajput et al., 2023). We adopt the identifier under the DSI architecture so that it differs from the hierarchical k-means base- lines only in how identifiers are constructed. 4. Textual IDs: In addition, we include two non-numeric baselines to contrast numeric identifiers with text-derived ones: ULTRON- URL (Zhou et al., 2022), which assigns each document a title- and URL-derived string, and SEAL (Bevilacqua et al., 2022), which as- signs no identifier at all and instead generates document substrings resolved through an FM- index. Our method remains com- petitive by performing only query-to-DocID opti- mization: it achieves 69.11% Hit@1 on NQ320K and 75.51% Hit@1, and maintains comparable re- sults on other metrics.
