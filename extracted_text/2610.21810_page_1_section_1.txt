Conditional memory expands language-model capacity through selective lookup, but the full embedding table must remain available for ev- ery possible input. We introduce Conditional Program (CP), a compressed representation that reconstructs only the rows an input re- quests. CP represents each row by a short code and a local scale, with a reconstruction program shared across the table. We instan- tiate this representation with a Gaussian trel- lis, norm restoration and independently decod- able row records. CP’s two-bit code lowers out- put KL by 41–63% relative to 2-bit round-to- nearest. Analysis across three trained n-gram memory families shows that Gaussian-like co- ordinate statistics coexist with learned relation- ships among rows; at matched storage budgets, the shared trellis outperforms the fitted code- books and low-rank residual variants we test. For DeepSeek, it reduces table storage from 203 GB to 51 GB, leaving room for larger work- loads when the table is kept on GPU. 1
