Model the feature dependencies needed to evaluate those gradients. 3.1 Incorporating dependencies in the path function In standard path methods, each path variable γi depends only on α, meaning attributions reflect only the direct effect of each feature on the model output. To incorporate indirect effects, we allow γi to depend on other path variables γj. This modification is best understood through the chain rule diagram, which for standard integrated gradients with n features takes the form of the black edges in the left panel of Figure 2, with xi = γi(α). x1 x2 · · · xn α F γ1 γ2 γn x1 x2 α F1 γ1 γ2 Figure 2: Chain rule diagrams illustrating the reparametrization of path functions to incorporate causal dependencies. Left: general n-feature case. Right: two-feature example. Black edges are standard path method dependencies; blue edges are the causal dependencies introduced by our reparametrization. Note that since the chain rule diagram is a directed acyclic graph (DAG), any dependency we add between input features must be directed — determining which feature causes the other — and must not introduce a cycle. We continue with the most general case of a fully connected DAG, with features ordered topologically: if xu depends on xv, then u > v. Such dependencies are represented as blue edges in the left panel of Figure 2, and under this ordering the individual path functions become xi = γi(x1, . . . , xi−1, α): each feature’s path depends on all features that causally precede it, plus α. With the modified path variables, computing the attributions in Equation 1 requires an additional application of the chain rule. We illustrate this with a simple example: a function F1 that depends only on x2, where x2 itself depends on x1, as shown in the right panel of Figure 2. Expanding the left-hand side of Equation 1 for this example gives: Z 1 0 ∂F1 ∂γ2 dγ2 dα dα = Z 1 0 ∂F1 ∂γ2 ∂γ2 ∂α dα + Z 1 0 ∂F1 ∂γ2 ∂γ2 ∂γ1 dγ1 dα dα, (2) where the first term is the direct attribution of x2 and the second is the indirect attribution of x1 through x2. Generalizing to a fully connected DAG with n features, the attribution of feature i is: Ri = Z 1 0 ∂F ∂γi ∂γi ∂α dα + X j>i Z 1 0 ∂F ∂γj ∂γj ∂γi dγi dα dα = Ri,direct + Ri,indirect, (3) where the first term captures the direct effect of xi and the second captures its indirect effect through all features that depend on it. This formulation applies to any DAG that represents model and input dependencies: missing edges simply correspond to zero terms ( ∂γj ∂γi = 0 if xj does not depend on xi). Additionally, any DAG can be reordered to match the topological ordering (see Appendix A for why this choice does not affect attributions). One subtlety is that the indirect terms use the full derivative dγi dα , meaning part of the indirect effect of xi may itself pass through features that xi depends on. In other words, this formulation attributes only indirect effects that are one hop long (also referred to as first-order). We provide an extension to multi-hop indirect effects in Appendix A.
