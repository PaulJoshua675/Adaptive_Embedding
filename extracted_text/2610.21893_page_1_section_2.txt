Large language models (LLMs) (Singh et al., 2025; Yang et al., 2025; Xu et al., 2026) are increasingly deployed for long-horizon tasks (Yao et al., 2023; Yang et al., 2024), where accumulated instructions and intermediate findings can exceed the available context budget. Coding assistants such as Codex CLI and Claude Code already use context com- paction in long sessions. Claude Code also allows users to specify the focus of compaction. At com- pression time, users may know their next objective even when the specific questions needed to pur- sue it are unknown. We define a goal as a high- level description of the intended future use of a source context. Goal-adaptive compression aims to preserve information for multiple subsequent questions associated with that goal. Prior work has studied query-aware (Jiang et al., 2024; Xu et al., 2024), query-agnostic (Pan et al., 2024), and task-aware (Corallo et al., 2026) com- pression. However, it remains unclear how reliably a compressed context supports multiple withheld questions for a context-specific goal, and whether gains depend on which goal guides compression. In a motivating experiment, we use DeepSeek- V4-Pro (Xu et al., 2026) to compress each con- text separately for each associated goal and eval- uate each compressed context on questions asso- ciated with all goals for that context. Figure 1 reports changes in question-level accuracy relative to goal-agnostic compression: matched-goal com- pression consistently improves accuracy, whereas most mismatched-goal conditions reduce it. These results indicate that the gains from goal-guided compression are goal-specific. Motivated by these findings, we introduce GACC-Bench to evaluate Goal-Adaptive Context Compression in LLMs. We generate source- grounded questions with reference answers and supporting evidence, group them by shared down- stream objectives, and formulate a high-level goal for each group. After quality control, each source context is paired with one or more goals and their associated questions.
