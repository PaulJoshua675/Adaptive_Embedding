Expected Running Time (ERT) We report the expected running time (ERT). Let ∆f = f(x) −f⋆denote the precision to the optimum. For a given target precision ∆ftarget, ERT measures the expected number of function evaluations required to reach ∆f ≤∆ftarget. Specifically, we have R independent runs, and let s denote the number of runs that successfully reach the target. Then, let Ti be the number of function evaluations required to reach the target if successful, and let B denote the evaluation budget for unsuccessful runs. The ERT is then defined as ERT = PR i=1 Ti + PR−s i=1 B s , (13) Lower ERT values indicate better performance, and, if s = 0, ERT = ∞. Results Figure 2 presents the ERT achieved by each matrix adaptation mechanism on the benchmark functions, for a target precision of ∆ftarget = 10−9. The official cma implementation (Pycma) is included as a baseline. Ideally, we expect its performance to align with that of the Covariance strategy in ModCMA, as both implement the same algorithm. However, Pycma is a highly optimized and customized version of CMA-ES. It includes several implementation-specific enhancements, such as mechanisms for handling neutrality and repairing strategy parameters, none of which are present in ModCMA. Despite these differences, the empirical performance of ModCMA with Covariance matrix adaptation aligns well with Pycma across most benchmarks. Minor differences can be observed on multimodal functions, such as f4, f15, f18, and f21. However, this variability is likely due to the inherent randomness in optimizing multimodal functions with sample-based optimization heuristics. Turning to the other matrix adaptation strategies, several patterns emerge. On functions f1 and f6, the None strategy (i.e., no matrix adaptation) performs well, and on f3 its performance is comparable to that of the other strategies. However, since all methods struggle with f3, a highly multimodal function, meaningful performance differences are hard to observe and analyze. On other multimodal functions, such as f17 and f21, the None strategy also seems to perform as well as the other methods, suggesting that on these landscapes, matrix adaptation is less important. The Separable strategy, as expected, excels on separable functions but fails on non-separable ones. A clear illustration of this is the performance contrast between f2 (separable) and f10 (a rotated, non-separable version of f2). The Separable method performs well on f2 but poorly on f10, highlighting its limitations. Among the more computationally efficient matrix adaptation methods, Cholesky and Matrix show no significant performance drop across most benchmarks. In fact, both the Cholesky and Matrix adaptation methods are able to find optimizers for d > 10 on f13, which neither the Covariance nor the Pycma methods are able to do. While already clearly demonstrated in the original works (Beyer and Sendhoff, 2017; Krause et al., 2016), each of these methods is indeed a viable alternative to the computationally more demanding Covariance method. In general, the CMSA strategy tends to be somewhat slower across the board in terms of ERT. The same holds for the Natural Gradient approach. Importantly, neither of these methods is tailored for the CSA step-size adaptation strategy, which is used for all methods in this evaluation. This mismatch may partially explain their comparatively lower performance. Still, it is worth noting that on functions f7, f11, f13, and f14, the Natural Gradient method often achieves the lowest ERT among all evaluated strategies. 18
