C.4 Commercial Comparisons Commercial systems do not disclose their training data, so overlap with our ground-truth benchmarks cannot be ruled out. We therefore evaluate SUPRA-Tex without additional fine-tuning on a separate set of 45 images, comprising real photographs sourced online or contributed by users and synthetic images generated by image generation models such as GPT-Image-2. We compare end-to-end with the five commercial systems in Table 4: Hunyuan3D (v3.1), Hyper3D (Rodin-2.5 Extremely High), Tripo (H3.1), Meshy (v7.1), and Hi3D (v3.0), using their most advanced configurations and accessed after September 24, 2026. Hyper3D is listed as Rodin in the table. We use two-view conditioning only for commercial comparisons, combining the reference image with a back view synthesized from it through the interface in Appendix G.1. We submit only the original reference image to each commercial system. Auxiliary-view synthesis is also supported by commercial workflows such as Meshy’s multi-view mode, which can generate missing views from a single image (Zoey, 2026). The 3D generator receives projected PBR observations rather than photographs, so generalization to real inputs depends on the fine-tuned 2D material estimator and accurate placement of the surface observations. In the absence of ground- truth geometry and cameras, paired reconstruction metrics are unavailable. We instead assess three criteria: alignment with the input image, including text, logos, and color layout; PBR plausibility; and overall visual quality. We collected 512 valid pairwise evaluations, each comprising one participant’s judgments on all three criteria for SUPRA-Tex versus one commercial system on a given input case. Each participant evaluated at most one model pair per case. For each of the five commercial systems and each criterion, Table 4 reports SUPRA-Tex’s wins divided by the total number of non-tied votes, pooled across evaluations. Qwen3.8-27B assigns each result a score from 0 to 10 using the rendered outputs. Table 4 reports both human preferences and VLM ratings. D 2D Material Evaluation D.1 2D Material Prediction We evaluate F2D directly in image space, before 3D projection, sparse encoding, or completion. The evaluation includes all 100 objects of DTC-Tex and all 110 objects of Complex-Tex, using each object’s designated reference view. Predictions use one deterministic step at native 1024 × 1024 resolution, CFG 1, and seed 42. All 210 cases complete successfully, with no exclusions. The auxiliary normal output is generated but is not scored here. Targets and metric domains. We reuse the benchmark’s existing reference-view PNG targets without resizing or inverse display/gamma conversion. Each image is independently composited onto black using its own alpha, when present. Albedo PSNR and albedo, metallic, and roughness MAE use the GT foreground (α > 0.5). Albedo full-image PSNR uses the mean squared error over all RGB pixels with unit data range. Albedo SSIM uses the full image with a 7 × 7 window and unit data range; VGG-LPIPS also uses the full image. None of the full-image metrics masks prediction pixels with the GT foreground. Metallic and roughness predictions are read from the red and green channels of the MRA output. Metrics are computed per object and averaged separately within each dataset. Metrics are computed in the stored PNG encoding; metallic and roughness MAE therefore measure encoded-value differences rather than physical-linear material error. Results. The measured foreground PSNR is approximately 19–20 dB, so these results do not establish near-ground-truth observation accuracy. Full-image PSNR is 28.25 and 28.19 dB on DTC-Tex and Complex-Tex, respectively.
