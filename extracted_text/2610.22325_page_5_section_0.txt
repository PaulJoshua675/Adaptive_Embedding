All HPMs share the reference virtual camera’s origin and axes, and both outputs use the same normalised scale. The network predicts in this normalised space; absolute body size and camera distance are not recovered. Observations of the same surface point have equal HPM targets, providing a shared coordinate for correspondence across time. The union of these targets samples the person’s surface at the reference time, bringing together the body, clothing and hair seen across the input clip. It includes regions hidden in the reference image but observed elsewhere, without fitting a body or surface template. The network learns to reproduce this common reference surface. 3.2 CROP-AWARE PREDICTION We construct the image intrinsics Kt from ft, assuming square pixels, zero skew and an image-centred principal point. The crop embedding supplies this geometry to the network: an MLP maps ct to one additional token per image (Fig. 2). This token joins the patch tokens from a ViT image encoder before the first attention block. The aggregator alternates attention within and across frames to process all observations jointly. Two dense heads read the aggregator features: the HPM head predicts reference-time surface coordinates ˆXt, and the depth head predicts depth ˆDt for each input image. Each head also predicts a confidence map. The reported model receives all four crop parameters. As expected after homography rectification, fixing the centre-ray inputs to (0, 0, 1) while retaining crop zoom leaves reconstruction and tracking unchanged at reported precision (Appendix D.1). We initialise the ViT image encoder and aggregator with pretrained VGGT-Ωweights (Wang et al., 2026). The HPM decoder uses weights from VGGT-Ω’s dense prediction head. Its final layer is initialised from scratch to predict 3D coordinates. The depth head’s final layer is initialised from scratch, and the crop embedding MLP’s final layer is initialised to zero.
