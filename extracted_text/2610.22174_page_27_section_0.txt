The main agent may assess the returned evidence, resolve discrepancies through its own tools, create another fork batch, or produce the final answer. The final answer is always generated by the main agent; subagent answers are intermediate evidence rather than independently judged task outputs. Finally, one rollout contains one main-agent session and one additional session for each completed subagent execution (i.e., subagent sessions mentioned in §3.2). Thus, if the rollout creates 𝑀 subagents in total, it produces 𝑀+ 1 training segments. Each segment retains its own prompt, generated tokens, and loss mask. The main-agent segment records the fork calls and the aggregated subagent observations. Each child segment records only its own search-and-visit trajectory and is linked to the parent by its fork index. C.3. LLM-as-Judge We use an LLM-as-Judge to score each trajectory. If a trajectory produces a final answer in the required format, we use the following prompt template to compute its trajectory-level reward: Prompte Template for LLM-as-Judge You are an expert evaluator. Given a question, a ground truth answer, and a predicted answer, judge whether the predicted answer correctly and completely matches the ground truth answer for the question. Accept equivalent wording, aliases, abbreviations, and semantically identical answers. Reply with only a number: 1 if correct, 0 if incorrect. Question:{question} Ground Truth Answer:{ground_truth} Predicted Answer:{answer} When multiple ground-truth answers are acceptable, we format them as a list with one ‘- answer‘ entry per line. We set temperature to 0.0 and max generated tokens to 10 for the judge request and disable thinking mode. D. Experimental Details D.1.
