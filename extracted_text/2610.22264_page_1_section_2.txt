Text-to-image (T2I) generation models [6, 8, 15, 16, 34, 36, 40–43, 54, 55, 60] turn language into visual content, with prompts serving as the primary interface for controlling generation. Small wording changes can determine whether an image preserves object counts, binds colors correctly, or places objects in the intended spatial relation. As diffusion and flow generators grow larger, retraining or lightly adapting the visual decoder is often expensive and risks image quality [1, 5, 7, 11, 12, 20, 26, 29, 30, 38, 39]. Prompt adaptation offers a cheaper alternative by improving the language interface while keeping the image generator fixed. Prompt optimization with a frozen generator can be formulated as a reinforcement learning problem. A language policy rewrites the input prompt, the T2I model renders an image, and an evaluator assigns a scalar reward based on the requested composition. Recent methods [15, 34, 55] exploit this feedback loop to improve T2I alignment while keeping the visual backbone fixed. GRPO converts rewards from grouped rewrites into an advantage for each completion without requiring a learned critic [28, 46]. The objective applies this advantage across token positions without accounting for semantic span boundaries. Compositional prompt edits to objects, attributes, counts, spatial relations, and scene context form coherent phrases that can span several subword tokens. Tokenizer boundaries reflect subword segmentation and need not coincide with these semantic units. An object description can combine an identity, a count, and an attribute, while a relation phrase links multiple objects.
