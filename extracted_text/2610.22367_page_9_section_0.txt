9 METHODS A classical function cannot generally be applied directly within a quantum algorithm, because quantum evolution must be reversible. Instead, a function f is embedded in a reversible map |x⟩|y⟩7−→|x⟩|y ⊕f(x)⟩. A natural model for these subroutines is the kickmix circuit model of Babbush et al. [8], which augments reversible classical computation with measurement-based uncomputation (MBU) and diagonal sign gates. Despite these additional operations, kickmix circuits remain efficiently classically simulable. This allows candidate circuits to be tested for their action on coherent quantum superpositions, providing the reliable correctness signal needed for evolutionary search. Circuits that implement the same specification can have very different time and space requirements. We use Toffoli count and peak qubit count as proxies for these costs. Toffoli gates require expensive non-Clifford resources, so their count tracks a large part of the logical work and often the runtime [24, 25]. The peak qubit count measures the data and ancillas that must coexist during execution and therefore approximates the required logical processor footprint [26]. The two resources also typically trade against each other: additional ancillas can avoid recomputation, while recycling ancillas can reduce space at the cost of additional gates. We multiply these quantities to obtain the TQ-cost, which provides a single objective for comparing such designs. Together, the correctness tests and TQ-cost define a constrained optimization problem over circuit-generating programs. Motivated by recent advances in coding and reasoning agents and LLM-guided algorithmic discovery, we use an LLM to propose coordinated, task-specific redesigns within an evolutionary search [20, 27, 28]. Circuit model and validity A compilation task specifies a reversible action on computational-basis states: a permutation π and, when needed, a Boolean phase g. A circuit may use a ancilla qubits, but must return them to zero: V |x⟩|0a⟩= (−1)g(x) |π(x)⟩|0a⟩. (10) Every ancilla must return to |0⟩because quantum operations must be unitary, and thus reversible. For a numerical approximation, the required output relation may instead specify an error bound; interface preservation, phase correctness, and ancilla uncomputation remain exact. We separately allow some circuits to fail on a bounded fraction of inputs drawn from a stated distribution; this fraction is the failure budget. Following Babbush et al. [8], the kickmix model permits three classes of operation: 1. classical reversible gates: X, CNOT, Toffoli, and swap; 2. diagonal sign gates: Z, CZ, CCZ, and global sign flips; and 3. destructive X-basis measurements. Before any measurement, the evolution of a computational-basis input is simple. Reversible gates update its stored bit string, while diagonal gates update only its sign, so the state remains of the form (−1)ϕ |x⟩. A classical simulator therefore need only track the current bits x and the sign ϕ, rather than a full state vector. The operations apply phase kickback while mixing basis states, giving kickmix its name. To illustrate why uncomputation is costly, consider a temporary AND. A Toffoli computes t = uv into an ancilla. After t has been used, applying the same Toffoli again returns that qubit to zero: |u, v⟩|0⟩ Toffoli −−−−→|u, v⟩|uv⟩ use uv −−−−→|u, v⟩|uv⟩ Toffoli −−−−→|u, v⟩|0⟩. (11) Computing and uncomputing this temporary AND therefore costs two Toffolis. MBU, introduced by Gidney [29], replaces the second Toffoli with a destructive X-basis measurement and a cheap phase correction. Measuring t produces a uniformly random outcome r and releases the ancilla, which can be restored to |0⟩: |u, v⟩|0⟩ Toffoli −−−−→|u, v⟩|uv⟩ use uv −−−−→|u, v⟩|uv⟩ X-measure r −−−−−−−−−→(−1)ruv |u, v⟩|0⟩ CZ if r=1 −−−−−−→|u, v⟩|0⟩. (12) Because CZ is Clifford, the temporary AND is computed and cleared using only one Toffoli. By linearity, the same reasoning applies component by component when the retained bits are in superposition.
