In this work, we presented MaLoW, a new memory framework for streaming VLMs. Rather than repeatedly injecting compressed or retrieved history into the input context, MaLoW represents history as LoRA weights while keeping the current observation as input. This separation provides a natural way to carry long-term information forward without revisiting the full video stream or continually expanding the context window. It also yields a lightweight memory patch: the base VLM architecture and parameters remain unchanged, while only the compact LoRA weights evolve over time. To realize this design, we developed a recurrent HyperNetwork that incrementally updates LoRA weights, together with MaLoW-Instruct, a large-scale streaming video dataset containing 381K QA pairs over 56K videos. MaLoW achieves strong results across streaming video understanding benchmarks, with substantial gains on memory-critical tasks and only modest inference overhead. We further show that the same memory mechanism transfers to VLA models, where incorporating historical context improves action success. We hope that MaLoW offers a useful perspective on long-term memory for streaming VLMs: beyond asking what information should be stored or retrieved, we can also reconsider where memory should reside, in this case, directly within evolving model weights.
