Motivated by this property, we explicitly introduce the ground-truth image as an additional visual input to the verifier, which simplifies the verification process and enables the verifier to produce more accurate and reliable reward signals for rule-governed generative world modeling. Formally, given an initial visual state x and a rule-based instruction c, the generative model πθ is required to understand the underlying rules and perform rule-governed reasoning to produce a resulting image y ∼πθ(y | x, c) , which can be viewed as a visual prediction of the target final state. Similar to the traditional text-to-image setting, the instruction c can be decomposed into K fine-grained sub-questions Q = {q1, q2, . . . , qK}, each assessing whether the resulting image y satisfies a specific sub-rule or achieves a corresponding sub-goal. Definition1: Pointwise Verification. As shown in Fig. 2, the pointwise verifier takes (x, c, y) as input. For each sub-question qk, it must first infer the corresponding target state from the initial visual state x and the underlying rules c, denoted as zk = T (qk, x, c). The verifier then assesses whether the resulting image y is consistent with this internally inferred target state zk. Accordingly, the pointwise verification score is defined as Spoint = 1 K PK k=1 J (qk, y, zk), and its deviation from the true score consists of both reasoning error and judgment error: ϵpoint = ϵreasoning + ϵjudge. Definition2: Pairwise Verification. In contrast, pairwise verification explicitly incorporates the ground- truth image y∗as an additional visual input, with the verifier taking (x, c, y, y∗) as input. For each sub-question qk, the verifier compares the generated image y against the ground-truth image y∗and assigns a corresponding score, hence the name pairwise verification. By avoiding internal target-state inference, the pairwise verification score is defined as Spair = 1 K PK k=1 J (qk, y, y∗), and its deviation from the true score is reduced to the judgment error: ϵpair = ϵjudge.
