Thermometer and John- son offer exact distance preservation at an event count that grows linearly with the number of represented values, while the block size of the hybrids controls how much global structure and neighbourhood contiguity is kept for a given width. The choice is therefore not simply between “accurate” and “compact” codes, but between combinations of semantic topology, tolerance resolution and per-decision event load. In practice, this suggests a simple rule: choose a cyclic or linear code to match the topology of the variable; use Thermometer or Johnson when the range fits within the input limit; and otherwise use the smallest block size whose width, from Eq. Limitations The evaluation uses synthetic values over a single range at a time, one network architecture, and first-generation SpiNNaker for every result except the input-capacity mea- surements. The experiments ran slower than real time, so the processing cost of wide codes, which would bound the rate of decisions at real time, was not measured. On SpiNNaker2 we established the limit of 512 input events per neuron but not its origin: whether it can be configured, and whether it limits events per timestep or connections per neuron, remain open. The results are also drawn from a single output neuron; the tolerance law is derived per neuron and should extend to a layer of independently trained neurons, but this is not demonstrated here. The weight vectors for multiple trained values are ob- tained by training each value separately and summing, not by presenting the values sequentially or interleaved to a single plastic network. This is a deliberate idealisation: it makes the learned vector an exact linear function of the trained set, which is what allows the coherence ratios of Section 4.3 to be predicted from pairwise Hamming distances alone (Section 4.3.1). Sequential STDP would not be linear in the same way. The nearest-pair rule pairs each presentation only with its nearest post-synaptic spike, so the update a value induces depends on what has already been learned, and the weight ceiling of 2 would clip bits on which several trained values agree: at a learned weight of about 0.375 per value, synapses shared by six or more values would saturate, and the coherent scaling of 𝑓(1)∕𝑛would cease to hold. Whether on-chip sequential learning converges to the summed vector for small trained sets, and how it departs from it for large ones, remains to be tested. No downstream dataset or multi-feature classification problem is evaluated, and the introduction explains why: the exhaustive protocol that makes the relations above exact is not available on a natural dataset. The consequence is that nothing here shows how the encodings behave when several features are presented together. One difficulty is already visible from the tolerance law: if features are concatenated into one code word, the Hamming distance is the sum of the per-feature distances and the tolerance radius applies to that sum, so a large deviation in one feature can be offset by exact agreement in the others. A multi-feature classifier built on these encodings would need either per-feature detectors with their own radii or a weighting across features, and the choice between them is an open design question. The hybrids do not fully reproduce their parents’ be- haviour. Their accepted sets are fragmented into up to 𝐵 runs by the Gray fine field, and their false positives, though confined near the trained cluster, are less tightly concentrated than Thermometer’s. The block size therefore trades not only correlation but neighbourhood contiguity, and smaller blocks should be preferred where contiguity matters. The tolerance law is exact only to the resolution of the homeostatic search: rounding the factor upwards can admit one further Hamming shell wherever the predicted radius falls just short of an integer, which occurred mostly in the widest code, and a finer search would be needed to exploit Thermometer’s full precision. Finally, the hybrid construc- tion resembles the segmented thermometer-plus-binary ar- chitectures of data-converter design, and the contribution here is the Gray fine field with reflected block ordering and its characterisation in a neuromorphic setting, rather than the two-level idea itself. 6. Conclusions Spatial encoding removes the latency of rate coding but makes classification depend on the geometry of the code. For a dual-rail network with a single output neuron on first- generation SpiNNaker, homeostatic scaling sets a Hamming radius around each trained code word, and the encoding alone decides what that radius means: a contiguous interval of values for Thermometer and Johnson, wrapping at the ends of the range for the cyclic codes, and a scattered set of values for Binary and Gray. The encodings commonly proposed against the Ham- ming cliff are therefore not equivalent. Gray removes the cliff but discards global distance structure, and pays for it in homeostatic margin as trained sets grow; Thermometer and Johnson preserve that structure at a width that grows with the value range. The hybrid construction introduced here contains all three as limiting cases of a single block-size parameter and trades width against preservation of semantic distance at a favourable rate: the cyclic hybrid at 𝐵= 8 accepts no untrained value as the trained cluster grows, in 19 bits where Johnson needs 128. Width matters because it is the number of input events paid on every decision, and both platforms bound it: on SpiNNaker by a configurable buffer of the simulation soft- ware, which by default silently truncates codes wider than 255 bits during training, and on SpiNNaker2 by a limit of 512 input events per neuron. The hybrid construction re- duces width by roughly an order of magnitude while leaving the radius of the detected neighbourhood unchanged.
