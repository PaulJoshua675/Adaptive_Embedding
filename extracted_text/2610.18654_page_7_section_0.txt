Cache Structure and Updates To support efficient decoding, we design a compact KV cache structure for C-KSA (Figure 5). This structure allows each text query to read all visible KV entries through a single contiguous slice, avoiding per-step concatenation of cache segments. Each C-KSA layer maintains two components: an Attention KV Cache and a Summary Ring Buffer. The illustration uses 𝑘𝑠= 2, 𝑊= 4, and 𝑘𝑚= 4, with 𝑇𝑖, 𝑆𝑐, and 𝑀𝑔denoting text, Summary, and Meta KV entries, respectively. Cache layout. The Attention KV Cache stores keys and values in separate tensors with the same layout: the current chunk, a local text ring, and remote history, followed by free slots (Figure 5a). The current chunk reserves 𝑘𝑠text slots, and the local ring reserves 𝑘𝑠𝑊slots for 𝑊preceding complete chunks. Remote history contains Meta entries followed by fewer than 𝑘𝑚Summaries awaiting compression. The visible KV entries are contiguous along the sequence dimension, allowing each text query to read them with a single slicing operation. The Summary Ring Buffer stores the local chunks’ Summary KV and auxiliary compression state. While a chunk remains in the local window, text queries attend to its original-text KV rather than its Summary KV. When the chunk leaves the window, its Summary KV enters remote history.
