LLM weight quantization. GPTQ (Frantar et al., 2023) and AWQ (Lin et al., 2024) use calibration activations to guide rounding or scaling, while QuIP, QuIP#, QuaRot and SpinQuant use coor- dinate transformations to make weights easier to quantize (Chee et al., 2023; Tseng et al., 2024a; Ashkboos et al., 2024; Liu et al., 2025). AQLM learns additive codebooks (Egiazarian et al., 2024); QTIP combines incoherence processing with trel- lis coding (Tseng et al., 2024b), and HIGGS uses Gaussian-optimal grids (Malinovskii et al., 2025). CP applies Gaussian trellis coding to frozen lookup rows without rotation, restoring each row’s norm and storing it independently for selective access. Because quantization can affect factual answers even when perplexity changes little (Jaiswal et al., 2024; Namburi et al., 2023; Dutta et al., 2024), we evaluate absolute task scores alongside output KL. Embedding-table compression. Row-wise low- bit quantization is established for recommender embeddings (Guan et al., 2019; Khudia et al., 2021); other approaches use low-precision train- ing, frequency-based mixed precision, or structures fixed during training (Yang et al., 2020; Li et al., 2023, 2024; Shi et al., 2020; Yin et al., 2021; Desai et al., 2022; Tsang and Ahle, 2023). For LLM in- put embeddings, CARVQ combines grouped resid- ual VQ with a corrective MLP trained for each model (Gou et al., 2025). The hashed tables stud- ied here share rows among colliding n-grams. CP compresses these already trained tables using their row values, with a shared decoder, no model re- training and no frequency-based bit allocation. Conditional-memory structure and placement. TN-gram replaces hashed tables with a tensor de- composition during pretraining (Zhou et al., 2026); TF-Engram and CXL-based systems address mem- ory placement and access (Ma et al., 2026b,a). TF-Engram’s hash-based compression shares slots between n-grams, whereas CP numerically com- presses the rows of an existing table. SCONE stores n-gram embeddings computed by a separate model off the accelerator (Yu et al., 2025). Product-key memories and memory layers retrieve rows through learned key search (Lample et al., 2019; Berges et al., 2024); the tables studied here use hashes of input tokens. 7
