The same few-step AR recipe underlies real-time interactive world models, which additionally con- dition generation on actions or camera trajectories (Team et al., 2026; Gao et al., 2026; He et al., 2026; Wang et al., 2026; Seo et al., 2026; AlayaWorld Team et al., 2026). These generators produce a clean latent estimate at every denoising step, not only the last, so an intermediate estimate can serve as a final output. Adaptive Denoising. Caching methods accelerate diffusion by reusing intermediate computation across denoising steps (Ma et al., 2023; Chen et al., 2024b; Selvaraju et al., 2024; Zhao et al., 2025; Liu et al., 2025a), including reuse selected per token (Zou et al., 2025) and, in AR video generation, per chunk or by local motion (Ma et al., 2026; Xu et al., 2026). Spatially adaptive samplers redistribute computation within the schedule, with RAS recomputing only the regions the model attends to (Liu et al., 2026) and HSA evaluating each token at a different number of steps along the same noise schedule (Chu & Patel, 2026). In both cases every token is carried to the end of the schedule, so no token is ever declared finished, and the error left by the computation that was skipped has to be kept bounded by periodic full updates. Substituting a previous output also weakens as the schedule shortens, since distilled samplers leave fewer steps over which one output can stand in for the next (Zou et al., 2026). In Self Forcing-style generators, DSA and Surprise Forcing select denoising depth for an entire frame or chunk, assigning the same number of steps to settled and unsettled regions (Le et al., 2026; Shi et al., 2026). Speculative Forcing instead treats intermediate clean estimates as drafts that can be committed at different steps according to token-wise convergence (Figure 2). It draws on draft verification in speculative decoding (Leviathan et al., 2023; Chen et al., 2023; Zhang et al., 2024), without adopting its exact acceptance rule. Committed tokens receive no further denoising updates, while their cached keys and values remain as context for the remaining tokens. 3 METHOD Speculative Forcing allows individual tokens to stop denoising at different steps. Accepted drafts are fixed as output, while their cached keys and values provide context for tokens that continue denoising (Section 3.2). To determine when to accept each draft, we introduce two verifiers that predict convergence from latent estimates or the generator’s intermediate features (Section 3.3). 3.1 PRELIMINARIES Autoregressive video diffusion. Autoregressive (AR) video diffusion models generate a video as a sequence of latent chunks {c1, c2, . . . }, each containing one or more consecutive frames. The joint distribution is factorized as p(c1, c2, . . . ) = Q t p(ct | c<t), where each conditional distribution is modeled through a diffusion process. At inference, the model generates each chunk by progressively denoising Gaussian noise conditioned on previously generated chunks. We consider generators that use clean history Ht = c<t as conditioning and cache its keys and values to avoid recomputing history features during subsequent generation. 3
