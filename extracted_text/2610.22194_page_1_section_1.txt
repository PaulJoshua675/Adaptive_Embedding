LLM agents now run long workflows with little human oversight, and several systems use them to automate parts of AI research itself [Lu et al., 2026, Tang et al., 2025, Hu et al., 2025, Wen et al., 2026]. What makes such a loop searchable is that every proposal can be evaluated automatically, and post-training has this property, so recent benchmarks evaluate agents on it [Rank et al., 2026, Chen et al., 2026a]. Given control of the whole training stack, agents converge on one part: across the runs audited by PostTrainBench [Rank et al., 2026], they adopt supervised fine-tuning (SFT) and spend most of their remaining effort revising the training data. This agrees with a broader finding that a carefully curated dataset can match or outperform a much larger one [Zhou et al., 2023a, Chen et al., 2024, Muennighoff et al., 2025], and that data selection and arrangement affect downstream performance directly [He et al., 2025a, Agarwal et al., 2025]. Recent systems therefore treat the data as the main search object [Wu et al., 2026, Luo et al., 2026, Zhao et al., 2026, Kulikov et al., 2026]. Each existing system gives the agent a single kind of control, selecting rows from a fixed pool or calling a generator. We ask whether an automated agent can instead command the full space of operations that an experienced data engineer uses.
