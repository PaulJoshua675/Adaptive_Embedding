Planner and Optimizer construct leave-one-out advantages using Eq. (8), normalizing with an exponential moving average of within-group return standard deviations; candidate groups with overly small return variance receive zero advantages. Inspector uses each candidate branch’s return minus that of the branch without a diagnosis. Both share the previous period’s feedback, so their difference depends only on next-period outcomes. These advantages stay fixed throughout offline optimization. Policy optimization uses the sequence-level objective in Eq. (9).
