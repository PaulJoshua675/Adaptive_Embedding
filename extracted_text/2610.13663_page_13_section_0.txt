Results 5.1. Summary across five tasks The final results obtained by applying the same agent framework to five tasks are summarized in Table 1. Accuracy (higher is better) is used for the classification tasks, whereas a relative error or physical diagnostic (lower is better) is used for the PINN tasks. The improvement over the baseline is expressed in task-specific units: for classification tasks, the absolute accuracy increase Acc−Accbase is reported in percentage points, whereas for PINN tasks the error- reduction factor Errbase∕Err is reported. The accuracy values and improvements shown in the table are rounded to integers. The corresponding unrounded accuracies are 79.88 and 92.83 % for MNIST (Table 2) and 90.83 and 96.67 % for digits (Table 19). For the GNLSE soliton with a Gaussian perturbation, Table 1 reports the conservation error Rel𝑖. For the Kuramoto–Sivashinsky problem, it reports the mass drift Δ(𝑢) 𝑚, an independent physical diagnostic recorded alongside the optimized boundary-value-problem residual Resbvp; the latter decreases by a factor of 9.3 in the same run (Table 7). Each row compares a single best agent result with the corresponding identity baseline from the same analyst run. For the GNLSE soliton with a Gaussian perturbation, robustness was additionally evaluated over ten independent trainings. These runs give Rel𝑖= (1.65±0.18)⋅10−1 for the baseline, (1.42±0.59)⋅10−3 for the configuration selected by Resbvp, and (1.60 ± 0.81) ⋅10−3 for the configuration selected by Rel𝑖. The corresponding reductions relative to the baseline mean are 116× and 103×, respectively (Table 11).
