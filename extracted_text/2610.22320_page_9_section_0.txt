Although the blended scene feature xn sc in- corporates visual information from the identity image xid, explicit feature re- placement may still fail to blend naturally into the surrounding scene context. Built upon [30], we enable each scene to dynamically attend to identity features during self-attention (Fig. 3 (3)). After extracting size-aligned key and value ˜Kn id and ˜V n id from the identity image feature xid, we concatenate them with the corre- sponding key and value from the scene features xn sc: Kn sc,id = Concat(Kn sc, ˜Kn id), V n sc,id = Concat(V n sc, ˜V n id). (4) 4 Experiments Implementation Details. We use the SDXL-base-1.0 checkpoint for all ex- periments and set the number of denoising steps to 50. We extract binary mask through the Otsu algorithm [21], which is commonly used [30]. Adaptive Identity Preservation is applied only to the decoder layers of the unet, with a transition from Identity Anchoring to Identity-Aware Self-Attention at step t=9, motivated by the observation that global layout forms in early denoising steps while fine- grained details emerge later [37]. The weighting coefficient λ is fixed at 0.55 in all experiments. All experiments are conducted on an NVIDIA A6000 GPU. Benchmarks. Consistory+ [17] spans subjects across diverse categories (e.g., humans, animals, nature). To evaluate generation performance under more com- plex spatial contexts, we introduce an extended version, Consistory+_+, by adding diverse framing phrases covering “shot size,” “camera angle,” and “com- position.” We first collect framing-related descriptors from prior scene-structure studies [15], filtering out those unlikely to be visually reflected in generated im- ages. To automatically assign appropriate descriptors, we instruct GPT-4o [10] to classify each subject and apply framing tags only to animate ones (e.g., humans, animals), for which such cues are perceptually more salient and semantically aligned [27]. Further details are provided in the supplementary material. Metrics. We evaluate text-to-image alignment using CLIP-T [39]. For subject similarity, we employ CLIP-I [24] and DreamSim [6], following [8,17].
